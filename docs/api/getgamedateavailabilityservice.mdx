# GetGameDateAvailabilityService

The `GetGameDateAvailabilityService` is a Spring service class responsible for determining which dates within a specified range have scheduled games. It provides a read-only transactional operation that queries the database for distinct game start times and returns a list of date availability responses.

## Purpose

This service solves the problem of efficiently checking game availability across a date range. Instead of querying for each individual date, it performs a single database query to retrieve all distinct start times within the range, then maps them to local dates in the Singapore timezone (Asia/Singapore). This approach minimizes database round trips and provides a clear, boolean availability indicator for each date.

## Public Methods

### `execute(LocalDate fromDate, LocalDate toDate)`

Determines the availability of games for each date within the specified range.

| Parameter | Type | Description |
|-----------|------|-------------|
| `fromDate` | `LocalDate` | The start date of the range (inclusive) |
| `toDate` | `LocalDate` | The end date of the range (inclusive) |

**Returns:** `List<GameDateAvailabilityResponse>` - A list of responses, one for each date in the range, indicating whether games are available on that date.

**Throws:**
- `IllegalArgumentException` - If `toDate` is before `fromDate`
- `ResourceNotFoundException` - If the database query fails or returns unexpected results

## Implementation Details

### Timezone Handling

The service uses a fixed timezone of `Asia/Singapore` (SGT) for all date-time conversions. This ensures consistent behavior regardless of the server's default timezone.

### Date Range Processing

1. **Validation**: Checks that `toDate` is not before `fromDate`
2. **Instant Conversion**: Converts the date range to `Instant` objects for database querying. The `toDate` is extended by one day to include the entire end date
3. **Database Query**: Executes a single query to find all distinct start times within the range
4. **Date Mapping**: Converts each `Instant` to a `LocalDate` in SGT timezone
5. **Response Generation**: Iterates through each date in the range and creates a `GameDateAvailabilityResponse` indicating whether games exist for that date

### Error Handling

The service uses `ServiceOperationExecutor.execute()` to wrap the database operation, providing consistent error handling and logging. If the operation fails, a `ResourceNotFoundException` is thrown.

## Usage Example

```java
@Autowired
private GetGameDateAvailabilityService availabilityService;

// Check availability for the next 7 days
LocalDate today = LocalDate.now();
LocalDate nextWeek = today.plusDays(7);

List<GameDateAvailabilityResponse> availability = 
    availabilityService.execute(today, nextWeek);

availability.forEach(response -> {
    System.out.println(response.getDate() + ": " + 
        (response.isAvailable() ? "Games available" : "No games"));
});
```
