# GetGameDateAvailabilityService

The `GetGameDateAvailabilityService` is a Spring service class responsible for determining the availability of games within a specified date range. It provides a read-only transactional operation that checks which dates in a given range have associated game start times, returning a list of date-availability pairs.

This service is part of the game features module and implements the `IGetGameDateAvailabilityService` interface. It uses the `GameRepository` to query distinct game start times and processes them against the requested date range.

## Key Characteristics

- **Thread-safe**: Uses `ServiceOperationExecutor` for safe execution of repository operations
- **Read-only transaction**: Marked with `@Transactional(readOnly = true)` for optimal performance
- **Time zone aware**: Operates in Singapore Time (SGT, `Asia/Singapore`)
- **Non-sealed class**: Extends the sealed interface `IGetGameDateAvailabilityService`

## Constructor

| Constructor | Description |
|-------------|-------------|
| `GetGameDateAvailabilityService(GameRepository gameRepository)` | Creates a new instance with the required game repository dependency |

## Public Methods

### `execute(LocalDate fromDate, LocalDate toDate)`

Determines game availability for each date in the specified range.

| Parameter | Type | Description |
|-----------|------|-------------|
| `fromDate` | `LocalDate` | The start date of the range (inclusive) |
| `toDate` | `LocalDate` | The end date of the range (inclusive) |

**Returns**: `List<GameDateAvailabilityResponse>` - A list of date-availability pairs for each day in the range

**Throws**:
- `IllegalArgumentException` - If `toDate` is before `fromDate`
- `ResourceNotFoundException` - If the repository query fails (wrapped by `ServiceOperationExecutor`)

**Example usage**:
```java
GetGameDateAvailabilityService service = new GetGameDateAvailabilityService(gameRepository);
List<GameDateAvailabilityResponse> availability = service.execute(
    LocalDate.of(2024, 1, 1),
    LocalDate.of(2024, 1, 7)
);
```

## Internal Logic

1. **Validation**: Checks that `toDate` is not before `fromDate`
2. **Time conversion**: Converts the date range to `Instant` objects in SGT timezone (extends end date by one day to include full day)
3. **Repository query**: Retrieves distinct game start times within the range using `ServiceOperationExecutor`
4. **Date extraction**: Converts each start time to a `LocalDate` in SGT timezone
5. **Availability check**: Iterates through each day in the range and creates a `GameDateAvailabilityResponse` indicating whether games exist for that date

## Dependencies

- `GameRepository` - Data access layer for game entities
- `ServiceOperationExecutor` - Utility for executing service operations with error handling
- `GameDateAvailabilityResponse` - Response DTO containing date and availability flag
- `ResourceNotFoundException` - Custom exception for resource not found scenarios
