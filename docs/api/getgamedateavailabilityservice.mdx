# GetGameDateAvailabilityService

## Purpose

The `GetGameDateAvailabilityService` class is a Spring service that provides functionality to check the availability of game dates within a specified date range. It queries the database for distinct game start times and returns a list of dates with their availability status (whether games exist on those dates). This service is particularly useful for calendar views or date pickers where users need to see which dates have scheduled games.

## Class Details

- **Package**: `com.upmatches.app.features.game.services`
- **Type**: `non-sealed class` implementing `IGetGameDateAvailabilityService`
- **Annotations**: `@Service`, `@Transactional(readOnly = true)`
- **Dependencies**: `GameRepository`

## Public Methods

### `execute`

```java
public List<GameDateAvailabilityResponse> execute(LocalDate fromDate, LocalDate toDate)
```

Retrieves the availability of game dates within the specified date range.

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `fromDate` | `LocalDate` | The start date of the range (inclusive) |
| `toDate` | `LocalDate` | The end date of the range (inclusive) |

#### Returns

| Type | Description |
|------|-------------|
| `List<GameDateAvailabilityResponse>` | A list of `GameDateAvailabilityResponse` objects, each containing a date and a boolean indicating whether games exist on that date |

#### Exceptions

| Exception | Condition |
|-----------|-----------|
| `IllegalArgumentException` | If `toDate` is before `fromDate` |
| `ResourceNotFoundException` | If the database query fails or returns unexpected results |

#### Behavior

1. **Validation**: Checks that `toDate` is not before `fromDate`. Throws `IllegalArgumentException` if validation fails.
2. **Time Zone Conversion**: Converts the date range to Singapore Time (SGT, `Asia/Singapore`) and converts to `Instant` objects for database querying.
3. **Database Query**: Retrieves distinct game start times within the specified range using `GameRepository.findDistinctStartTimesBetween()`.
4. **Date Extraction**: Extracts unique dates from the retrieved start times.
5. **Response Generation**: Iterates through each day in the date range and creates a `GameDateAvailabilityResponse` indicating whether games exist on that date.

## Internal Logic

### Time Zone Handling

The service uses a fixed time zone of `Asia/Singapore` (SGT) for all date conversions:

```java
private static final ZoneId SGT = ZoneId.of("Asia/Singapore");
```

### Date Range Calculation

The end date is extended by one day to ensure inclusive coverage:

```java
Instant toInstant = toDate.plusDays(1).atStartOfDay(SGT).toInstant();
```

### Error Handling

Uses `ServiceOperationExecutor.execute()` to wrap the database operation with standardized error handling and logging, converting any exceptions to `ResourceNotFoundException`.

## Usage Example

```java
// Inject the service
private final GetGameDateAvailabilityService availabilityService;

// Check availability for a week
LocalDate from = LocalDate.of(2024, 1, 1);
LocalDate to = LocalDate.of(2024, 1, 7);
List<GameDateAvailabilityResponse> availability = availabilityService.execute(from, to);

// Process results
availability.forEach(response -> {
    System.out.println(response.getDate() + ": " + (response.isAvailable() ? "Games available" : "No games"));
});
```

## Dependencies

- `GameRepository`: Repository for accessing game data
- `ServiceOperationExecutor`: Utility for executing service operations with standardized error handling
- `GameDateAvailabilityResponse`: DTO for returning date availability information
