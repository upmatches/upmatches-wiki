# JacksonConfiguration

The `JacksonConfiguration` class is a Spring `@Configuration` class that provides a customized `ObjectMapper` bean for the entire application. It centralizes the configuration of Jackson's serialization and deserialization behavior, ensuring consistent JSON processing across all REST endpoints and services.

## Purpose

This configuration addresses common JSON processing requirements in modern Spring Boot applications:

- **Java 8 Date/Time Support**: Registers the `JavaTimeModule` to properly serialize and deserialize `java.time` objects (e.g., `LocalDate`, `LocalDateTime`, `ZonedDateTime`).
- **ISO 8601 Date Formatting**: Disables timestamp-based date serialization, forcing Jackson to use ISO 8601 string representations (e.g., `"2024-01-15T10:30:00"` instead of numeric timestamps).
- **Lenient Deserialization**: Prevents failures when encountering unknown JSON properties, making the API more resilient to changes.
- **Empty String Handling**: Treats empty strings as `null` objects during deserialization, which is useful for handling form submissions and partial updates.

## Bean Definitions

| Bean Name | Return Type | Scope | Description |
|-----------|-------------|-------|-------------|
| `objectMapper` | `ObjectMapper` | Singleton | Primary `ObjectMapper` bean with custom configuration for the entire application. |

### `objectMapper()`

Creates and configures the primary `ObjectMapper` instance used throughout the application.

**Configuration Details:**

| Feature | Setting | Effect |
|---------|---------|--------|
| `JavaTimeModule` | Registered | Enables serialization/deserialization of Java 8 date/time types |
| `WRITE_DATES_AS_TIMESTAMPS` | Disabled | Dates are serialized as ISO 8601 strings instead of numeric timestamps |
| `FAIL_ON_UNKNOWN_PROPERTIES` | Disabled | Unknown JSON properties are ignored during deserialization |
| `ACCEPT_EMPTY_STRING_AS_NULL_OBJECT` | Enabled | Empty strings are treated as `null` values during deserialization |

**Example Usage:**

```java
@Service
public class UserService {
    private final ObjectMapper objectMapper;

    public UserService(ObjectMapper objectMapper) {
        this.objectMapper = objectMapper;
    }

    public User parseUser(String json) {
        return objectMapper.readValue(json, User.class);
    }
}
```

## Dependencies

- **Spring Framework**: `@Configuration`, `@Bean`, `@Primary` annotations
- **Jackson**: `ObjectMapper`, `DeserializationFeature`, `SerializationFeature`
- **Jackson JSR310**: `JavaTimeModule` for Java 8 date/time support

## Notes

- The `@Primary` annotation ensures this `ObjectMapper` bean takes precedence over any other `ObjectMapper` beans in the application context.
- This configuration is particularly useful for applications that work with ISO 8601 date formats and need to handle flexible JSON payloads from various clients.
