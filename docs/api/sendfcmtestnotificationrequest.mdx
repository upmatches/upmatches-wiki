## Overview

The `SendFcmTestNotificationRequest` class is a Java record that represents a request to send a Firebase Cloud Messaging (FCM) test notification. This class is part of the `com.upmatches.app.features.notification.requests` package and is used to encapsulate the necessary data for sending a test notification, including device information, notification type, and game details.

## Class Details

The `SendFcmTestNotificationRequest` record includes several fields with validation constraints to ensure that the data provided is valid and within expected limits. It also contains a method to verify that at least one target (either a device token or an email) is provided for the notification.

## Public Methods

### `isTargetProvided`

This method checks if either the `deviceToken` or `email` is provided, ensuring that there is a valid target for the notification.

| Method Name       | Parameters | Return Type | Description                                                                 |
|-------------------|------------|-------------|-----------------------------------------------------------------------------|
| `isTargetProvided` | None       | `boolean`   | Returns `true` if either `deviceToken` or `email` is provided, `false` otherwise. |
