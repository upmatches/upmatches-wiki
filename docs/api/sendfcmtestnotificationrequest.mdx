# SendFcmTestNotificationRequest

The `SendFcmTestNotificationRequest` is a Java record that serves as a data transfer object (DTO) for sending test Firebase Cloud Messaging (FCM) notifications. It encapsulates all the necessary fields required to construct and send a test push notification to a specific device or email address.

This record is designed to be used in conjunction with validation constraints to ensure that the request payload is complete and valid before processing. It supports both device token-based and email-based notification delivery, with the requirement that at least one of these targets is provided.

## Record Definition

```java
public record SendFcmTestNotificationRequest(
    String deviceToken,
    String email,
    NotificationType type,
    String gameTitle,
    String venue,
    Integer courtCount,
    LocalDate date,
    LocalTime startTime,
    LocalTime endTime,
    String skillLevel,
    String gameUrl,
    Integer badge
)
```

## Fields

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `deviceToken` | `String` | `@Size(max = 512)` | The FCM device token to send the notification to. Must not exceed 512 characters. |
| `email` | `String` | `@Email`, `@Size(max = 254)` | The email address to send the notification to. Must be a valid email format and not exceed 254 characters. |
| `type` | `NotificationType` | `@NotNull` | The type of notification to send. Must not be null. |
| `gameTitle` | `String` | `@NotBlank`, `@Size(max = 120)` | The title of the game. Must not be blank and must not exceed 120 characters. |
| `venue` | `String` | `@Size(max = 120)` | The venue where the game takes place. Must not exceed 120 characters. |
| `courtCount` | `Integer` | `@Min(1)`, `@Max(20)` | The number of courts for the game. Must be between 1 and 20 (inclusive). |
| `date` | `LocalDate` | None | The date of the game. |
| `startTime` | `LocalTime` | None | The start time of the game. |
| `endTime` | `LocalTime` | None | The end time of the game. |
| `skillLevel` | `String` | `@Size(max = 60)` | The skill level required for the game. Must not exceed 60 characters. |
| `gameUrl` | `String` | `@Size(max = 2048)` | The URL to the game details page. Must not exceed 2048 characters. |
| `badge` | `Integer` | `@Min(0)`, `@Max(999)` | The badge number to display on the app icon. Must be between 0 and 999 (inclusive). |

## Validation Methods

### `isTargetProvided()`

```java
@AssertTrue(message = "Either deviceToken or email must be provided")
public boolean isTargetProvided()
```

This custom validation method ensures that at least one of the two target fields (`deviceToken` or `email`) is provided and non-blank. The validation will fail if both fields are null or blank.

**Returns:** `boolean` - `true` if either `deviceToken` or `email` is provided and non-blank; `false` otherwise.

## Usage Example

```java
// Create a request with a device token
SendFcmTestNotificationRequest request = new SendFcmTestNotificationRequest(
    "fcm-device-token-123",
    null,
    NotificationType.GAME_REMINDER,
    "Sunday Pickup Basketball",
    "Community Sports Center",
    2,
    LocalDate.of(2024, 3, 15),
    LocalTime.of(14, 0),
    LocalTime.of(16, 0),
    "Intermediate",
    "https://example.com/game/123",
    5
);

// The request will pass validation because deviceToken is provided
```

## Validation Summary

The record enforces the following validation rules:

- **Target Requirement:** At least one of `deviceToken` or `email` must be provided (non-blank).
- **Email Format:** If `email` is provided, it must be a valid email address.
- **Field Lengths:** String fields have maximum length constraints to prevent excessively large payloads.
- **Numeric Ranges:** `courtCount` must be between 1 and 20, and `badge` must be between 0 and 999.
- **Required Fields:** `type` and `gameTitle` are required (non-null and non-blank respectively).
