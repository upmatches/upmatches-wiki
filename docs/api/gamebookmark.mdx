# GameBookmark

The `GameBookmark` entity represents a user's bookmark for a specific game. It is a JPA entity mapped to the `game_bookmarks` table and enforces a unique constraint on the combination of `game_id` and `user_id`, ensuring that a user can bookmark a game only once.

## Purpose

This entity is used to persist and manage the relationship between a `User` and a `Game` when the user bookmarks a game. It stores the timestamp of when the bookmark was created and provides a static factory method for creating new bookmark instances.

## Entity Details

| Field          | Type     | Description                                                                 |
|----------------|----------|-----------------------------------------------------------------------------|
| `id`           | `UUID`   | Primary key, auto-generated using UUID strategy.                            |
| `game`         | `Game`   | Many-to-one relationship to the `Game` entity. Cannot be null.              |
| `user`         | `User`   | Many-to-one relationship to the `User` entity. Cannot be null.              |
| `bookmarkedAt` | `Instant`| Timestamp of when the bookmark was created. Set automatically on persist.   |

## Table Constraints

- **Table name**: `game_bookmarks`
- **Unique constraint**: `(game_id, user_id)` – prevents duplicate bookmarks for the same game by the same user.

## Public Methods

### `create(Game game, User user)`

Creates a new `GameBookmark` instance with the specified game and user.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| `game`    | `Game` | The game to be bookmarked.           |
| `user`    | `User` | The user who is bookmarking the game.|

**Returns**: `GameBookmark` – a new bookmark entity instance.

**Note**: The `bookmarkedAt` field is automatically set to the current time when the entity is persisted (via the `@PrePersist` callback).

## Usage Example

```java
Game game = gameRepository.findById(gameId).orElseThrow();
User user = userRepository.findById(userId).orElseThrow();

GameBookmark bookmark = GameBookmark.create(game, user);
gameBookmarkRepository.save(bookmark);
```

## Dependencies

- **Lombok**: Uses `@Getter` and `@NoArgsConstructor(access = AccessLevel.PROTECTED)` to generate getters and a protected no-arg constructor.
- **Jakarta Persistence**: Standard JPA annotations for entity mapping.
- **Java Time**: Uses `java.time.Instant` for timestamp storage.
