# GameBookmark

The `GameBookmark` entity represents a user's bookmark for a specific game within the application. It is a JPA entity mapped to the `game_bookmarks` database table and enforces a unique constraint on the combination of `game_id` and `user_id`, ensuring that a user can bookmark a particular game only once.

## Purpose

This entity is used to persist and manage the relationship between users and games they wish to bookmark. It captures the moment when the bookmark was created and provides a static factory method for safe object creation.

## Entity Details

| Property       | Type      | Description                                                                 |
|----------------|-----------|-----------------------------------------------------------------------------|
| `id`           | `UUID`    | Primary key, auto-generated using UUID strategy.                            |
| `game`         | `Game`    | The bookmarked game (Many-to-One relationship).                             |
| `user`         | `User`    | The user who created the bookmark (Many-to-One relationship).               |
| `bookmarkedAt` | `Instant` | Timestamp indicating when the bookmark was created (set automatically).     |

## Database Mapping

- **Table name**: `game_bookmarks`
- **Unique constraint**: Ensures no duplicate bookmarks for the same game and user combination (`game_id`, `user_id`).

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `create` | `GameBookmark` | `Game game`, `User user` | Static factory method that creates a new `GameBookmark` instance with the provided game and user. The `bookmarkedAt` field is automatically set upon persistence via the `@PrePersist` callback. |

## Usage Example

```java
Game game = gameRepository.findById(gameId).orElseThrow();
User user = userRepository.findById(userId).orElseThrow();

GameBookmark bookmark = GameBookmark.create(game, user);
gameBookmarkRepository.save(bookmark);
```

## Notes

- The `bookmarkedAt` field is set automatically before the entity is persisted and cannot be updated after creation.
- The `@NoArgsConstructor(access = AccessLevel.PROTECTED)` annotation ensures that direct instantiation is restricted, encouraging the use of the static `create()` method.
- The unique constraint on `(game_id, user_id)` prevents duplicate bookmarks at the database level.
