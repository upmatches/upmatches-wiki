## Overview

The `GameBookmark` class is an entity representing a bookmark for a game by a user. It is part of the `com.upmatches.app.features.game.entities` package and is used to persist bookmark data in the database. This class is annotated with JPA annotations to map it to the `game_bookmarks` table, ensuring that each bookmark is unique per game and user combination.

## Class Details

### Annotations

- `@Entity`: Specifies that the class is an entity and is mapped to a database table.
- `@Table`: Provides the table name and unique constraints for the entity.
- `@Getter`: Lombok annotation to generate getter methods for all fields.
- `@NoArgsConstructor`: Lombok annotation to generate a no-argument constructor with protected access.

### Fields

- `UUID id`: The unique identifier for each bookmark, automatically generated.
- `Game game`: The game that is bookmarked, represented as a `ManyToOne` relationship.
- `User user`: The user who bookmarked the game, also represented as a `ManyToOne` relationship.
- `Instant bookmarkedAt`: The timestamp when the bookmark was created, set automatically before persisting.

## Public Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `create` | `Game game`, `User user` | `GameBookmark` | Static method to create a new `GameBookmark` instance for a given game and user. |

### Method Details

#### `create(Game game, User user)`

- **Parameters:**
  - `game`: The `Game` object that is being bookmarked.
  - `user`: The `User` object who is bookmarking the game.
- **Return Type:** `GameBookmark`
- **Description:** This static method initializes a new `GameBookmark` object with the provided game and user, setting up the necessary relationships.

### Lifecycle Callback

- `@PrePersist void onCreate()`: This method is automatically called before the entity is persisted to the database, setting the `bookmarkedAt` field to the current timestamp.
