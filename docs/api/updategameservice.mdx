## Purpose of the Class

The `UpdateGameService` class is a Spring service responsible for handling the update operations on `Game` entities. It ensures that all necessary validations and authorizations are performed before updating a game. The service also manages the publishing of events related to game updates.

## Public Methods

### `execute`

Executes the update operation for a game.

| Parameter | Type                     | Description                                                                 |
|-----------|--------------------------|-----------------------------------------------------------------------------|
| `id`      | `UUID`                   | The unique identifier of the game to be updated.                            |
| `request` | `UpdateGameRequest`      | The request object containing the new values for the game properties.       |

| Return Type    | Description                                                                 |
|----------------|-----------------------------------------------------------------------------|
| `GameResponse` | A response object representing the updated state of the game for the viewer. |

### Method Details

- **Transactional**: The `execute` method is annotated with `@Transactional`, ensuring that the update operation is atomic and consistent.
- **Auditable**: The method is also annotated with `@Auditable`, which logs the action of updating a game for auditing purposes.
- **Authorization**: The method checks if the user is authorized to update the game and ensures that immutable fields are not altered.
- **Event Publishing**: After a successful update, a `GameNotificationEvent` is published to notify other components of the change.

### Helper Methods

- **`resolveVenue`**: Determines the venue for the game update.
- **`resolveSkillLevelFrom`**: Resolves the starting skill level for the game.
- **`resolveSkillLevelTo`**: Resolves the ending skill level for the game.
- **`resolveCurrency`**: Determines the currency for the game pricing.
- **`resolvePricing`**: Resolves the pricing strategy for the game update, considering structured pricing, legacy pricing fields, and existing game pricing.
