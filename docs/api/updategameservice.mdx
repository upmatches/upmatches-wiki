# UpdateGameService

The `UpdateGameService` class is a Spring service responsible for handling game update operations in the UpMatches application. It implements the `IUpdateGameService` interface and provides a comprehensive update workflow that includes authorization checks, field validation, and notification publishing.

## Purpose

This service manages the complete lifecycle of updating a game entity, ensuring:
- Only authorized users (game organizers) can update games
- Immutable fields are protected from modification when participants are active
- Slot counts remain valid relative to active participants
- All related entities (venue, skill levels, pricing) are properly resolved
- Notifications are sent to relevant parties after successful updates

## Public Methods

### `execute`

```java
@Transactional
@Auditable(action = "GAME_UPDATED", resourceType = "GAME", resourceIdExpression = "#args[0]")
public GameResponse execute(UUID id, UpdateGameRequest request)
```

Updates an existing game with the provided changes.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to update |
| `request` | `UpdateGameRequest` | The update request containing modified fields |

**Returns:**

| Type | Description |
|------|-------------|
| `GameResponse` | The updated game data formatted for the viewer |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | When the game or related entities cannot be found |
| `AuthorizationException` | When the user is not authorized to update the game |
| `IllegalArgumentException` | When validation checks fail (e.g., slots below active count) |

**Workflow:**

1. **Authentication**: Resolves the current user's ID
2. **Game Retrieval**: Finds the game or throws `ResourceNotFoundException`
3. **Authorization Checks**:
   - Verifies the user is the game organizer
   - Ensures visibility hasn't changed
   - Validates immutable fields when active participants exist
   - Confirms new slot count is >= active participants
4. **Entity Resolution**: Resolves venue, skill levels, and pricing from the request or falls back to existing values
5. **Game Update**: Applies all changes to the game entity
6. **Persistence**: Saves the updated game to the repository
7. **Notification**: Publishes a `GameNotificationEvent` with type `GAME_UPDATED`
8. **Response**: Returns a formatted `GameResponse`

## Private Helper Methods

### `resolveVenue`

```java
private Venue resolveVenue(Game game, UpdateGameRequest request)
```

Resolves the venue for the update. Returns the requested venue if provided, otherwise keeps the existing venue.

### `resolveSkillLevelFrom`

```java
private SkillLevel resolveSkillLevelFrom(Game game, UpdateGameRequest request)
```

Resolves the minimum skill level. Returns the requested level if provided, otherwise keeps the existing value.

### `resolveSkillLevelTo`

```java
private SkillLevel resolveSkillLevelTo(Game game, UpdateGameRequest request)
```

Resolves the maximum skill level. Returns the requested level if provided, otherwise keeps the existing value.

### `resolveCurrency`

```java
private Currency resolveCurrency(Game game, UpdateGameRequest request)
```

Resolves the currency for pricing. Creates a new `Currency` instance from the request or existing game data.

### `resolvePricing`

```java
private Pricing resolvePricing(Game game, UpdateGameRequest request)
```

Resolves the pricing for the update with the following precedence:
1. Structured `pricing` object from the request (if supplied)
2. Legacy `price` and optional `currency` fields from the request (for backward compatibility)
3. Existing pricing on the game entity

## Usage Example

```java
// Inject the service
private final UpdateGameService updateGameService;

// Update a game
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UpdateGameRequest request = new UpdateGameRequest(
    null, // venueId (keep existing)
    null, // skillLevelFromId (keep existing)
    null, // skillLevelToId (keep existing)
    null, // pricing (keep existing)
    20,   // slots (update to 20)
    null, // startTime (keep existing)
    null, // endTime (keep existing)
    null, // gameType (keep existing)
    "Updated game details" // remark
);

GameResponse response = updateGameService.execute(gameId, request);
```
