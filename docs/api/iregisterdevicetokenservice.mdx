# IRegisterDeviceTokenService Interface

## Purpose

The `IRegisterDeviceTokenService` interface defines the contract for registering a device token within the notification system of the UpMatches application. It serves as the abstraction layer for persisting or associating a device token with a user or device, enabling push notification delivery.

This interface is declared as a **sealed interface**, meaning only explicitly permitted classes (in this case, `RegisterDeviceTokenService`) can implement it. This design enforces a controlled hierarchy and ensures that the registration logic is centralized and not extended arbitrarily.

## Interface Definition

```java
public sealed interface IRegisterDeviceTokenService permits RegisterDeviceTokenService {
    void execute(RegisterDeviceTokenRequest request);
}
```

## Method Summary

| Method | Description |
|--------|-------------|
| `void execute(RegisterDeviceTokenRequest request)` | Executes the device token registration process using the provided request data. |

## Method Details

### `execute`

```java
void execute(RegisterDeviceTokenRequest request)
```

**Description:**  
Performs the core operation of registering a device token. The implementation is responsible for handling the request, which typically includes the device token string, user identifier, and possibly platform information (e.g., iOS, Android). The method does not return a value; any success or failure handling is expected to be managed within the implementation or through exceptions.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `RegisterDeviceTokenRequest` | The request object containing the device token and associated metadata required for registration. |

**Returns:**  
`void` – This method does not return a value.

**Throws:**  
The interface does not declare any checked exceptions, but implementations may throw runtime exceptions (e.g., `IllegalArgumentException` for invalid requests, or persistence-related exceptions).

## Usage Example

```java
// Assuming an instance is obtained via dependency injection
IRegisterDeviceTokenService service = new RegisterDeviceTokenService();

// Create a request with the device token
RegisterDeviceTokenRequest request = new RegisterDeviceTokenRequest(
    "fcm-token-abc123",
    "user-456",
    DevicePlatform.ANDROID
);

// Execute registration
service.execute(request);
```

## Implementation Notes

- The interface is **sealed**, restricting implementation to `RegisterDeviceTokenService` only.
- The `RegisterDeviceTokenRequest` class is expected to contain at minimum a device token string and user identifier.
- Implementations should handle token persistence, deduplication, and any necessary validation.
- This interface follows the **Command Pattern**, encapsulating the registration operation into a single method.
