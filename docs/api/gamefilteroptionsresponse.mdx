# GameFilterOptionsResponse

The `GameFilterOptionsResponse` class is a Java record that encapsulates the available filter options for game search or listing functionality. It provides a structured response containing all possible filter criteria that users can apply when searching for games, such as venues, skill levels, start times, and game types.

## Purpose

This record serves as a data transfer object (DTO) that aggregates all filterable attributes into a single response. It is typically returned by an API endpoint that provides the initial set of filter options for the game search UI, allowing the frontend to populate dropdowns, checkboxes, or other filter controls.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `venues` | `List<VenueResponse>` | Available venues where games can be played |
| `skillLevels` | `List<SkillLevelResponse>` | Available skill levels for game participation |
| `availableStartTimes` | `List<String>` | Available start times for games (e.g., "09:00", "10:00") |
| `gameTypes` | `List<GameType>` | Available game types (e.g., SINGLES, DOUBLES, MIXED) |

## Usage Example

```java
// Example of creating a GameFilterOptionsResponse
GameFilterOptionsResponse filterOptions = new GameFilterOptionsResponse(
    List.of(tennisVenue, basketballVenue),
    List.of(beginnerLevel, intermediateLevel),
    List.of("09:00", "10:00", "11:00"),
    List.of(GameType.SINGLES, GameType.DOUBLES)
);
```

## Dependencies

- `VenueResponse` - Represents a venue with its details
- `SkillLevelResponse` - Represents a skill level with its details
- `GameType` - Enumeration of available game types

## Notes

- This record is immutable by design, ensuring thread-safety and predictable behavior
- The `availableStartTimes` list contains string representations of time slots
- All lists are guaranteed to be non-null when properly constructed
