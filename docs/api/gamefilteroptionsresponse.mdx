# GameFilterOptionsResponse

The `GameFilterOptionsResponse` is a Java record that encapsulates the available filter options for game search or listing functionality. It provides a structured response containing all possible filter criteria that users can apply when searching for games, such as venues, skill levels, start times, and game types.

## Purpose

This record serves as a data transfer object (DTO) that aggregates various filter options into a single response. It is typically returned by an API endpoint that provides the available filter choices to the frontend, allowing users to narrow down game searches based on their preferences.

## Record Structure

As a Java record, `GameFilterOptionsResponse` is an immutable data carrier with automatically generated constructor, accessor methods, `equals()`, `hashCode()`, and `toString()`.

### Components

| Component | Type | Description |
|-----------|------|-------------|
| `venues` | `List<VenueResponse>` | Available venues for game filtering |
| `skillLevels` | `List<SkillLevelResponse>` | Available skill levels for game filtering |
| `availableStartTimes` | `List<String>` | Available start times for games (e.g., "09:00", "10:00") |
| `gameTypes` | `List<GameType>` | Available game types (e.g., SINGLES, DOUBLES) |

## Usage Example

```java
// Creating a filter options response
GameFilterOptionsResponse filterOptions = new GameFilterOptionsResponse(
    venues,           // List<VenueResponse>
    skillLevels,      // List<SkillLevelResponse>
    startTimes,       // List<String>
    gameTypes         // List<GameType>
);

// Accessing individual filter options
List<VenueResponse> availableVenues = filterOptions.venues();
List<SkillLevelResponse> availableSkillLevels = filterOptions.skillLevels();
List<String> availableTimes = filterOptions.availableStartTimes();
List<GameType> availableGameTypes = filterOptions.gameTypes();
```

## Related Components

- **VenueResponse**: Represents venue data used in the venues filter
- **SkillLevelResponse**: Represents skill level data used in the skill levels filter
- **GameType**: Enum defining different types of games (e.g., SINGLES, DOUBLES)

## Notes

- The record is immutable by design, ensuring thread safety and predictable behavior
- All fields are required and cannot be null (standard Java record behavior)
- The `availableStartTimes` field uses `String` type to allow flexible time format representation
