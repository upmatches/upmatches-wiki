# ShareLinkUrlBuilder

The `ShareLinkUrlBuilder` class is a Spring service that constructs various types of URLs for sharing resources within the application. It implements the `IShareLinkUrlBuilder` interface and provides methods to generate shareable links for web and mobile platforms.

## Purpose

This class centralizes URL generation logic for shareable links, ensuring consistency across different platforms (web and mobile) and resource types. It uses configuration properties from `JwtProperties` and `ShareLinkProperties` to build properly formatted URLs.

## Constructor

| Parameter | Type | Description |
|-----------|------|-------------|
| `jwtProperties` | `JwtProperties` | Configuration properties containing mobile callback scheme |
| `shareLinkProperties` | `ShareLinkProperties` | Configuration properties containing base URLs |

## Public Methods

### `buildShareUrl(String code)`

Builds a generic share URL using the base URL and a unique code.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | The unique share code to append to the URL |

**Returns:** `String` - A complete share URL in the format `{baseUrl}/{code}`

### `buildWebUrl(ResourceType resourceType, String resourceId)`

Constructs a web-based URL for a specific resource type and identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of resource being shared (e.g., profile, post) |
| `resourceId` | `String` | The unique identifier of the resource |

**Returns:** `String` - A web URL in the format `{webBaseUrl}/{resourceType.path}/{resourceId}`

### `buildMobileUrl(ResourceType resourceType, String resourceId)`

Generates a mobile deep link URL using the mobile callback scheme.

| Parameter | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of resource being shared (e.g., profile, post) |
| `resourceId` | `String` | The unique identifier of the resource |

**Returns:** `String` - A mobile deep link URL in the format `{mobileCallbackScheme}://{resourceType.path}/{resourceId}`

## Usage Example

```java
// Assuming Spring dependency injection
@Autowired
private ShareLinkUrlBuilder urlBuilder;

// Build a generic share URL
String shareUrl = urlBuilder.buildShareUrl("abc123");
// Result: "https://example.com/share/abc123"

// Build a web URL for a profile
String webUrl = urlBuilder.buildWebUrl(ResourceType.PROFILE, "user456");
// Result: "https://example.com/profile/user456"

// Build a mobile deep link
String mobileUrl = urlBuilder.buildMobileUrl(ResourceType.POST, "post789");
// Result: "myapp://post/post789"
```

## Dependencies

- `JwtProperties` - Provides the mobile callback scheme for deep linking
- `ShareLinkProperties` - Provides base URLs for web and share links
- `ResourceType` - Enum defining resource types and their URL path segments

## Notes

- The class is declared as `non-sealed`, allowing further subclassing if needed
- All methods use string constants for path separators to ensure consistency
- The service is thread-safe as it has no mutable state
