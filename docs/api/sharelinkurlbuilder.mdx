# ShareLinkUrlBuilder

The `ShareLinkUrlBuilder` class is a Spring service responsible for constructing various types of URLs used in the share link feature of the application. It implements the `IShareLinkUrlBuilder` interface and provides methods to generate share URLs, web URLs, and mobile deep link URLs based on the provided parameters.

## Purpose

This class centralizes URL building logic for share links, ensuring consistency across different URL formats (web, mobile, and generic share links). It leverages configuration properties (`JwtProperties` and `ShareLinkProperties`) to obtain base URLs and scheme information, making the URL generation configurable and environment-agnostic.

## Constructor

| Constructor | Description |
|-------------|-------------|
| `ShareLinkUrlBuilder(JwtProperties jwtProperties, ShareLinkProperties shareLinkProperties)` | Initializes the builder with required configuration properties for JWT and share link settings. |

## Public Methods

### `buildShareUrl(String code)`

Generates a generic share URL using the base URL from configuration and the provided code.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | The unique share code to append to the base URL. |

**Returns:** `String` - The complete share URL in the format `{baseUrl}/{code}`.

### `buildWebUrl(ResourceType resourceType, String resourceId)`

Constructs a web-based URL for a specific resource type and identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of resource (e.g., profile, post) which determines the path segment. |
| `resourceId` | `String` | The unique identifier of the resource. |

**Returns:** `String` - The complete web URL in the format `{webBaseUrl}/{resourceType.path}/{resourceId}`.

### `buildMobileUrl(ResourceType resourceType, String resourceId)`

Creates a mobile deep link URL using the mobile callback scheme from JWT configuration.

| Parameter | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of resource (e.g., profile, post) which determines the path segment. |
| `resourceId` | `String` | The unique identifier of the resource. |

**Returns:** `String` - The complete mobile URL in the format `{mobileCallbackScheme}://{resourceType.path}/{resourceId}`.

## Dependencies

- **JwtProperties**: Provides the mobile callback scheme used in mobile URL construction.
- **ShareLinkProperties**: Supplies the base URL and web base URL for share and web URL generation.
- **ResourceType**: An enum that defines the path segment for different resource types.

## Usage Example

```java
// Assuming dependencies are injected
ShareLinkUrlBuilder urlBuilder = new ShareLinkUrlBuilder(jwtProperties, shareLinkProperties);

// Build a share URL
String shareUrl = urlBuilder.buildShareUrl("abc123");
// Result: "https://example.com/share/abc123"

// Build a web URL for a profile
String webUrl = urlBuilder.buildWebUrl(ResourceType.PROFILE, "user456");
// Result: "https://example.com/profile/user456"

// Build a mobile deep link
String mobileUrl = urlBuilder.buildMobileUrl(ResourceType.POST, "post789");
// Result: "myapp://post/post789"
```

## Notes

- The class is declared as `non-sealed`, indicating it is part of a sealed class hierarchy (likely implementing `IShareLinkUrlBuilder`).
- All URL components are joined using the `PATH_SEPARATOR` (`/`) and `MOBILE_SCHEME_SEPARATOR` (`://`) constants.
- The `ResourceType` enum is expected to provide a `path()` method that returns the appropriate URL path segment for each resource type.
