# Coordinate

The `Coordinate` class is a Java record that represents a geographic coordinate pair consisting of latitude and longitude. It is designed as a value object within the venue feature of the application, ensuring that all coordinate instances are valid and immutable.

## Purpose

- **Encapsulation of Geographic Data**: Provides a structured way to handle latitude and longitude values.
- **Validation**: Ensures that latitude and longitude are within valid ranges (-90 to 90 for latitude, -180 to 180 for longitude).
- **Immutability**: As a Java record, `Coordinate` is immutable, making it safe for use in concurrent environments and as a key in collections.

## Public Methods

| Method | Description | Parameters | Return Type |
|--------|-------------|------------|-------------|
| `Coordinate(BigDecimal latitude, BigDecimal longitude)` | Constructor that validates and creates a new `Coordinate` instance. | `latitude` - The latitude value (must be between -90 and 90).<br/>`longitude` - The longitude value (must be between -180 and 180). | `Coordinate` |
| `create(BigDecimal latitude, BigDecimal longitude)` | Static factory method to create a `Coordinate` instance. | `latitude` - The latitude value.<br/>`longitude` - The longitude value. | `Coordinate` |
| `toString()` | Returns a string representation of the coordinate in the format "latitude, longitude". | None | `String` |

## Usage Example

```java
import java.math.BigDecimal;

public class Example {
    public static void main(String[] args) {
        Coordinate coord = Coordinate.create(
            new BigDecimal("40.7128"),
            new BigDecimal("-74.0060")
        );
        System.out.println(coord.toString()); // Output: 40.7128, -74.0060
    }
}
```

## Validation Rules

- **Latitude**: Must be between -90 and 90 (inclusive).
- **Longitude**: Must be between -180 and 180 (inclusive).
- **Null Values**: Both latitude and longitude must not be null.

If any validation fails, an `IllegalArgumentException` is thrown with a descriptive message.
