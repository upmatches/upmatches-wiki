# Coordinate

The `Coordinate` class is a Java record that represents a geographic coordinate pair consisting of latitude and longitude. It ensures that the provided values are within valid geographic ranges and provides a factory method for creating instances.

## Purpose

This value object is designed to encapsulate a location's latitude and longitude coordinates. It validates the input to ensure that latitude is between -90 and 90 degrees and longitude is between -180 and 180 degrees. The class is immutable and provides a clean, type-safe way to represent geographic coordinates in the venue feature of the application.

## Constructor

The canonical constructor of the `Coordinate` record performs validation on the provided latitude and longitude values.

| Parameter | Type | Description |
|-----------|------|-------------|
| `latitude` | `BigDecimal` | The latitude value, must be between -90 and 90 (inclusive) |
| `longitude` | `BigDecimal` | The longitude value, must be between -180 and 180 (inclusive) |

**Throws:**
- `IllegalArgumentException` if either parameter is `null`
- `IllegalArgumentException` if latitude is outside the range [-90, 90]
- `IllegalArgumentException` if longitude is outside the range [-180, 180]

## Public Methods

### `create`

```java
public static Coordinate create(BigDecimal latitude, BigDecimal longitude)
```

Factory method to create a new `Coordinate` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `latitude` | `BigDecimal` | The latitude value |
| `longitude` | `BigDecimal` | The longitude value |

**Returns:** `Coordinate` - A new validated Coordinate instance

**Throws:** Same validation exceptions as the constructor

### `toString`

```java
@Override
public String toString()
```

Returns a string representation of the coordinate in the format "latitude, longitude".

**Returns:** `String` - The coordinate as a comma-separated string (e.g., "40.7128, -74.0060")

## Accessor Methods

As a Java record, `Coordinate` automatically provides the following accessor methods:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `latitude()` | `BigDecimal` | Returns the latitude value |
| `longitude()` | `BigDecimal` | Returns the longitude value |

## Usage Example

```java
import java.math.BigDecimal;

// Create a coordinate for New York City
Coordinate nyc = Coordinate.create(
    new BigDecimal("40.7128"),
    new BigDecimal("-74.0060")
);

// Access values
BigDecimal lat = nyc.latitude();
BigDecimal lon = nyc.longitude();

// String representation
String coordString = nyc.toString(); // "40.7128, -74.0060"
```
