# NotificationResponse

The `NotificationResponse` class is a Java record that serves as a Data Transfer Object (DTO) for representing notification data in API responses. It encapsulates the essential fields of a `Notification` entity and provides a static factory method to convert from the entity to this response format.

## Purpose

- **API Response Representation**: Provides a clean, immutable representation of notification data for REST API responses.
- **Data Transformation**: Converts `Notification` entity objects into a format suitable for serialization (e.g., JSON).
- **Separation of Concerns**: Decouples the internal entity model from the external API contract.

## Record Fields

| Field        | Type      | Description                                      |
|--------------|-----------|--------------------------------------------------|
| `id`         | `UUID`    | Unique identifier for the notification           |
| `type`       | `String`  | Notification type (e.g., "LIKE", "MATCH")        |
| `title`      | `String`  | Short title of the notification                  |
| `message`    | `String`  | Detailed message content                         |
| `resourceType` | `String` | Type of resource associated (e.g., "USER", "POST") |
| `resourceId` | `UUID`    | ID of the associated resource                    |
| `isRead`     | `Boolean` | Whether the notification has been read           |
| `readAt`     | `Instant` | Timestamp when the notification was read         |
| `createdAt`  | `Instant` | Timestamp when the notification was created      |

## Public Methods

### `fromNotification(Notification notification)`

Converts a `Notification` entity into a `NotificationResponse` DTO.

**Parameters:**

| Parameter      | Type           | Description                          |
|----------------|----------------|--------------------------------------|
| `notification` | `Notification` | The entity to convert to a response  |

**Returns:**

| Type                   | Description                                      |
|------------------------|--------------------------------------------------|
| `NotificationResponse` | A new instance populated with entity data        |

**Example Usage:**

```java
Notification notification = notificationService.findById(notificationId);
NotificationResponse response = NotificationResponse.fromNotification(notification);
```

## Usage Notes

- This record is immutable by design, making it thread-safe and suitable for caching.
- The `type` field is converted from an enum to a string representation for API consumption.
- All timestamps use `java.time.Instant` for precise time representation.
- The `isRead` field uses `Boolean` (object) rather than `boolean` (primitive) to allow null values if the read status is unknown.
