# NotificationResponse

The `NotificationResponse` class is a Java record that serves as a Data Transfer Object (DTO) for representing notification data in API responses. It encapsulates the essential fields of a `Notification` entity and provides a static factory method for converting entity instances into response objects.

## Purpose

- **Data Transfer**: Transfers notification data from the backend to the client in a structured, immutable format.
- **Decoupling**: Separates the internal entity representation (`Notification`) from the external API response, allowing changes to the entity without affecting the API contract.
- **Convenience**: Provides a clean, read-only view of notification attributes such as ID, type, title, message, timestamps, and read status.

## Record Definition

The record is defined with the following components:

| Field          | Type      | Description                                      |
|----------------|-----------|--------------------------------------------------|
| `id`           | `UUID`    | Unique identifier for the notification.          |
| `type`         | `String`  | Notification type (e.g., "LIKE", "MESSAGE").     |
| `title`        | `String`  | Short title of the notification.                 |
| `message`      | `String`  | Detailed message content.                        |
| `resourceType` | `String`  | Type of resource associated (e.g., "USER", "POST"). |
| `resourceId`   | `UUID`    | ID of the associated resource.                   |
| `isRead`       | `Boolean` | Whether the notification has been read.          |
| `readAt`       | `Instant` | Timestamp when the notification was read (nullable). |
| `createdAt`    | `Instant` | Timestamp when the notification was created.     |

## Public Methods

### `fromNotification(Notification notification)`

Converts a `Notification` entity into a `NotificationResponse` DTO.

| Parameter      | Type           | Description                                      |
|----------------|----------------|--------------------------------------------------|
| `notification` | `Notification` | The entity to convert. Must not be null.         |

**Returns**: `NotificationResponse` — a new instance populated with data from the provided entity.

**Example usage**:
```java
Notification notification = notificationService.findById(id);
NotificationResponse response = NotificationResponse.fromNotification(notification);
```

## Notes

- The `type` field is derived from the entity's `NotificationType` enum using `.name()`.
- The `readAt` field may be `null` if the notification has not been read yet.
- This record is immutable by design, ensuring thread safety and consistency in API responses.
