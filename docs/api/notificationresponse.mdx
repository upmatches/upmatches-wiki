# NotificationResponse

The `NotificationResponse` record is a Data Transfer Object (DTO) used to represent a notification in API responses. It encapsulates all relevant fields of a `Notification` entity in a read-only, serializable format, ensuring that internal entity details are not exposed directly to clients.

This record is typically returned by REST controllers when clients request notification data, providing a clean and immutable view of the notification.

## Record Components

The following table describes each component (field) of the `NotificationResponse` record:

| Field          | Type         | Description                                                                 |
|----------------|--------------|-----------------------------------------------------------------------------|
| `id`           | `UUID`       | Unique identifier of the notification.                                      |
| `type`         | `String`     | The type of notification (e.g., "LIKE", "MESSAGE", "MATCH").                |
| `title`        | `String`     | Short title or subject of the notification.                                 |
| `message`      | `String`     | Detailed message content of the notification.                               |
| `resourceType` | `String`     | The type of resource associated with the notification (e.g., "USER", "POST").|
| `resourceId`   | `UUID`       | Identifier of the related resource.                                         |
| `isRead`       | `Boolean`    | Whether the notification has been read by the user.                         |
| `readAt`       | `Instant`    | Timestamp when the notification was read (nullable).                        |
| `createdAt`    | `Instant`    | Timestamp when the notification was created.                                |

## Public Methods

### `fromNotification`

```java
public static NotificationResponse fromNotification(Notification notification)
```

Creates a `NotificationResponse` instance from a `Notification` entity. This is the primary factory method used to convert domain entities into API response objects.

**Parameters:**

| Parameter      | Type           | Description                              |
|----------------|----------------|------------------------------------------|
| `notification` | `Notification` | The notification entity to convert.      |

**Returns:** `NotificationResponse` — A new response object populated with data from the given notification.

**Example usage:**

```java
Notification notification = notificationService.findById(notificationId);
NotificationResponse response = NotificationResponse.fromNotification(notification);
```
