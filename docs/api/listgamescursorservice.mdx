# ListGamesCursorService

The `ListGamesCursorService` class is a Spring service that provides cursor-based pagination for listing games. It implements the `IListGamesCursorService` interface and is responsible for fetching, filtering, and paginating game data with support for geolocation, time-based filters, and user-specific joinability information.

## Purpose

This service enables efficient, cursor-based pagination of game listings with the following capabilities:
- Filter games by date/time ranges, skill levels, venues, and geographic location
- Compute bounding boxes for location-based queries
- Resolve authenticated user context for personalized responses
- Calculate participant counts and joinability status for each game
- Generate cursor-based pagination tokens for efficient navigation

## Public Methods

### `execute`

```java
@Transactional(readOnly = true)
public CursorPagedResponse<GameResponse> execute(
    ListGamesCursorFilterRequest filter,
    String cursor,
    int size)
```

Executes the cursor-based pagination query with optional filters.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `filter` | `ListGamesCursorFilterRequest` | Optional filter criteria (date range, location, skill levels, venues). If null, an empty filter is used. |
| `cursor` | `String` | Encoded cursor token for pagination. Null for the first page. |
| `size` | `int` | Maximum number of results to return per page. |

**Returns:**

| Type | Description |
|------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing the list of games and an optional next cursor token. |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Wraps any underlying data access exceptions |
| `IllegalArgumentException` | If filter validation fails (e.g., incomplete location fields, invalid date range) |
