# ListGamesCursorService

The `ListGamesCursorService` class is a Spring service that provides cursor-based pagination for listing games. It implements the `IListGamesCursorService` interface and handles filtering games based on various criteria such as location, date/time, skill levels, and venues. The service uses a cursor-based approach for efficient pagination through large result sets.

## Purpose

This service is designed to:
- Retrieve a paginated list of games visible to a user (or anonymous viewer)
- Apply complex filtering criteria including geolocation, time ranges, skill levels, and venues
- Compute participant counts and joinability status for each game
- Support cursor-based pagination for efficient navigation through results
- Handle both authenticated and anonymous user scenarios

## Public Methods

### `execute`

```java
@Transactional(readOnly = true)
public CursorPagedResponse<GameResponse> execute(
    ListGamesCursorFilterRequest filter,
    String cursor,
    int size)
```

Executes the main query to retrieve a paginated list of games based on the provided filter criteria and cursor.

| Parameter | Type | Description |
|-----------|------|-------------|
| `filter` | `ListGamesCursorFilterRequest` | Filter criteria for the games query. Can be `null` for no filtering. |
| `cursor` | `String` | Encoded cursor string for pagination. `null` for the first page. |
| `size` | `int` | Maximum number of games to return in this page. |

| Returns | Description |
|---------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing the list of games and the next cursor for pagination. |

**Behavior:**
- If `filter` is `null`, an empty filter is used (no filtering applied).
- Validates cross-field constraints (e.g., location fields must be provided together).
- For authenticated users, includes joinability information and viewer-specific game details.
- For anonymous users, returns basic game information without joinability data.
- Returns `null` for the next cursor if there are no more results.
