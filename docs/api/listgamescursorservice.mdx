# ListGamesCursorService

The `ListGamesCursorService` class is a Spring service that provides cursor-based pagination for listing games. It implements the `IListGamesCursorService` interface and handles filtering, sorting, and pagination of game data with support for location-based queries, time ranges, skill levels, and venue filters.

## Purpose

This service enables efficient retrieval of game listings with cursor-based pagination, allowing clients to fetch games in pages while maintaining consistent ordering. It supports complex filtering including:
- Location-based filtering with bounding box calculations
- Date and time range filtering
- Skill level and venue filtering
- Participant count aggregation
- Joinability status computation for authenticated users

## Public Methods

### `execute(ListGamesCursorFilterRequest filter, String cursor, int size)`

Executes a cursor-based paginated query for games with optional filtering.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `filter` | `ListGamesCursorFilterRequest` | Filter criteria (can be null for no filtering) |
| `cursor` | `String` | Encoded cursor for pagination (null for first page) |
| `size` | `int` | Maximum number of results to return |

**Returns:** `CursorPagedResponse<GameResponse>`

**Throws:** `ResourceNotFoundException` if the operation fails

**Behavior:**
1. Resolves the current authenticated user (if any)
2. Decodes the cursor to determine the starting point
3. Validates cross-field constraints in the filter
4. Executes the query with all applicable filters
5. Aggregates participant counts for returned games
6. Computes joinability status for authenticated users
7. Maps game entities to response DTOs
8. Generates the next cursor for subsequent pages

## Internal Methods

### `computeBoundingBox(ListGamesCursorFilterRequest f)`

Computes a bounding box for location-based filtering.

**Parameters:**
- `f`: Filter request containing latitude, longitude, and radius

**Returns:** `BoundingBox` record with lat/lng min/max values

### `emptyFilter()`

Creates an empty filter request with all null fields.

**Returns:** `ListGamesCursorFilterRequest` with all null values

### `toMinutes(LocalTime time)`

Converts a `LocalTime` to total minutes since midnight.

**Parameters:**
- `time`: Time to convert (can be null)

**Returns:** Integer representing minutes, or null if input is null

### `validateCrossFields(ListGamesCursorFilterRequest f)`

Validates cross-field constraints in the filter request.

**Throws:** `IllegalArgumentException` if:
- Location fields are partially provided
- `toDate` is before `fromDate`

### `runQuery(UUID userId, Optional<GameCursor.Value> decoded, ListGamesCursorFilterRequest f, int size)`

Executes the actual database query with all applied filters.

**Parameters:**
- `userId`: Current user ID (null for anonymous)
- `decoded`: Decoded cursor value
- `f`: Filter request
- `size`: Page size

**Returns:** `List<Game>` of matching games

### `floorAtNow(Instant dateFloor)`

Returns the later of the provided date floor and current time.

**Parameters:**
- `dateFloor`: Date floor instant (can be null)

**Returns:** `Instant` representing the effective floor time

### `countParticipants(List<Game> games)`

Counts active participants for a list of games.

**Parameters:**
- `games`: List of games to count participants for

**Returns:** `Map<UUID, Long>` mapping game IDs to participant counts

**Static Methods:**

| Method | Description |

| `empty()` | Creates an empty bounding box with all null fields |

## Usage Example

```java
// Create filter for games within 10km of a location
ListGamesCursorFilterRequest filter = new ListGamesCursorFilterRequest(
    new BigDecimal("1.3521"),  // latitude
    new BigDecimal("103.8198"), // longitude
    BigDecimal.TEN,             // radius in km
    null,                       // fromDate
    null,                       // toDate
    null,                       // fromTime
    null,                       // toTime
    null,                       // skillLevelIds
    null                        // venueIds
);

// Execute query
CursorPagedResponse<GameResponse> response = service.execute(
    filter,
    null,  // first page
    20     // page size
);

// Use nextCursor for subsequent pages
String nextCursor = response.nextCursor();
```
