## Overview

The `ShortLink` class is an entity representing a shortened link in the system. It is used to map a short code to a specific resource, track the number of clicks, and store metadata about its creation and updates. This class is part of the `com.upmatches.app.features.sharelink.entities` package and is annotated with JPA annotations to map it to a database table named `short_links`.

## Public Methods

The `ShortLink` class provides the following public methods:

### `create`

Creates a new instance of `ShortLink` with the specified parameters.

| Parameter    | Type          | Description                                      |
|--------------|---------------|--------------------------------------------------|
| `code`       | `String`      | The unique code representing the short link.     |
| `resourceType` | `ResourceType` | The type of resource the link points to.       |
| `resourceId` | `String`      | The identifier of the resource.                  |
| `createdBy`  | `User`        | The user who created the short link.             |

**Returns:** `ShortLink` - A new instance of the `ShortLink` class.

## Annotations and Lifecycle Methods

- **`@Entity`**: Specifies that the class is an entity and is mapped to a database table.
- **`@Table(name = "short_links")`**: Specifies the name of the database table.
- **`@Id`**: Marks the field as a primary key.
- **`@GeneratedValue(strategy = GenerationType.UUID)`**: Specifies that the ID should be generated as a UUID.
- **`@Column`**: Maps a field to a column in the database table.
- **`@Enumerated(EnumType.STRING)`**: Specifies that the `resourceType` should be persisted as a string.
- **`@ManyToOne`**: Defines a many-to-one relationship with the `User` entity.
- **`@JoinColumn(name = "created_by")`**: Specifies the foreign key column for the `createdBy` relationship.
- **`@PrePersist`**: Lifecycle callback method that sets `createdAt` and `updatedAt` before the entity is persisted.
- **`@PreUpdate`**: Lifecycle callback method that updates `updatedAt` before the entity is updated.
