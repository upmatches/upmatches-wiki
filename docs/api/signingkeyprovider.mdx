# SigningKeyProvider Interface

The `SigningKeyProvider` interface defines a contract for providing Elliptic Curve (EC) signing keys used in JSON Web Token (JWT) signing operations. This interface is part of the authentication services layer and is designed to work with the Nimbus JOSE + JWT library.

## Purpose

This interface abstracts the retrieval of signing keys and their identifiers, enabling flexible key management strategies. Implementations can source keys from various backends such as:

- Static key stores
- Key management systems (KMS)
- Hardware security modules (HSM)
- Dynamic key rotation services

## Interface Definition

```java
package com.upmatches.app.features.auth.services;

import com.nimbusds.jose.jwk.ECKey;

public interface SigningKeyProvider {
    ECKey getSigningKey();
    String getSigningKeyId();
}
```

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getSigningKey()` | `ECKey` | Returns the Elliptic Curve signing key used for JWT signing operations. The returned key should be a valid, ready-to-use EC key instance. |
| `getSigningKeyId()` | `String` | Returns a unique identifier for the current signing key. This identifier is typically included in the JWT header as the `kid` (Key ID) claim for key lookup during verification. |

## Usage Example

```java
// Example implementation
public class ConfigurableSigningKeyProvider implements SigningKeyProvider {
    private final ECKey signingKey;
    private final String keyId;
    
    public ConfigurableSigningKeyProvider(ECKey signingKey, String keyId) {
        this.signingKey = signingKey;
        this.keyId = keyId;
    }
    
    @Override
    public ECKey getSigningKey() {
        return signingKey;
    }
    
    @Override
    public String getSigningKeyId() {
        return keyId;
    }
}
```

## Dependencies

This interface requires the Nimbus JOSE + JWT library, specifically the `com.nimbusds.jose.jwk.ECKey` class. Ensure the following dependency is included in your project:

**Maven:**
```xml
<dependency>
    <groupId>com.nimbusds</groupId>
    <artifactId>nimbus-jose-jwt</artifactId>
    <version>9.37.3</version>
</dependency>
```

**Gradle:**
```gradle
implementation 'com.nimbusds:nimbus-jose-jwt:9.37.3'
```

## Security Considerations

- **Key Rotation**: Implementations should support key rotation to maintain security best practices
- **Key Protection**: Ensure signing keys are stored securely and never exposed in logs or error messages
- **Thread Safety**: Implementations should be thread-safe as signing operations may occur concurrently
- **Key Validation**: The returned `ECKey` should be validated before use to ensure it meets cryptographic requirements
