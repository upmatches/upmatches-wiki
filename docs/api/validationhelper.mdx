# ValidationHelper

The `ValidationHelper` class is a utility class designed to centralize common validation logic for API request parameters. It provides static methods to validate pagination parameters (both offset-based and cursor-based) and sort field parameters, ensuring that incoming requests meet the application's constraints before they are processed further.

This class is declared as `final` and has a private constructor to prevent instantiation, following the standard utility class pattern in Java.

## Methods

### `validatePaginationParameters(int page, int size)`

Validates offset-based pagination parameters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `int` | The page number (zero-indexed). Must be >= 0. |
| `size` | `int` | The number of items per page. Must be > 0 and <= 1000. |

**Throws:**
- `IllegalArgumentException` if `page` is negative.
- `IllegalArgumentException` if `size` is <= 0 or > 1000.

### `validateCursorPaginationParameters(int size)`

Validates cursor-based pagination parameters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `size` | `int` | The number of items per page. Must be > 0 and <= 1000. |

**Throws:**
- `IllegalArgumentException` if `size` is <= 0 or > 1000.

### `validateSortBy(String sortBy, String... allowedFields)`

Validates that the `sortBy` parameter matches one of the allowed field names.

| Parameter | Type | Description |
|-----------|------|-------------|
| `sortBy` | `String` | The field name to sort by. Cannot be null or empty. |
| `allowedFields` | `String...` | Varargs of allowed field names for sorting. |

**Throws:**
- `IllegalArgumentException` if `sortBy` is null or empty.
- `IllegalArgumentException` if `sortBy` does not match any of the `allowedFields`.

## Usage Example

```java
// Validate offset-based pagination
ValidationHelper.validatePaginationParameters(0, 20);

// Validate cursor-based pagination
ValidationHelper.validateCursorPaginationParameters(50);

// Validate sort field
ValidationHelper.validateSortBy("createdAt", "createdAt", "updatedAt", "name");
```

## Notes

- The default maximum page size is set to `1000` items per page.
- This class is thread-safe as it contains no mutable state.
- All methods throw `IllegalArgumentException` with descriptive error messages to aid in debugging.
