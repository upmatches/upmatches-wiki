## Overview

The `ValidationHelper` class is a utility class designed to provide validation methods for pagination and sorting parameters. It ensures that the parameters used in pagination and sorting operations meet the expected criteria, preventing common errors such as invalid page numbers or unsupported sorting fields.

## Public Methods

### `validatePaginationParameters`

Validates the pagination parameters to ensure they are within acceptable limits.

| Parameter | Type | Description |
|-----------|------|-------------|
| `page`    | `int` | The page number to validate. Must be greater than or equal to 0. |
| `size`    | `int` | The size of the page to validate. Must be greater than 0 and less than or equal to 1000. |

**Throws**: `IllegalArgumentException` if the parameters are out of bounds.

### `validateCursorPaginationParameters`

Validates the size parameter for cursor-based pagination.

| Parameter | Type | Description |
|-----------|------|-------------|
| `size`    | `int` | The size of the page to validate. Must be greater than 0 and less than or equal to 1000. |

**Throws**: `IllegalArgumentException` if the size is out of bounds.

### `validateSortBy`

Validates the `sortBy` parameter to ensure it is not null or empty and is among the allowed fields.

| Parameter     | Type     | Description |
|---------------|----------|-------------|
| `sortBy`      | `String` | The field to sort by. Cannot be null or empty. |
| `allowedFields` | `String...` | A varargs list of allowed fields for sorting. |

**Throws**: `IllegalArgumentException` if `sortBy` is null, empty, or not in the list of allowed fields.
