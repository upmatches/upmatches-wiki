## Purpose

The `ValidationHelper` class is a utility class designed to provide validation methods for pagination and sorting parameters. It ensures that the input parameters for pagination and sorting are within acceptable ranges and formats, preventing potential errors in data retrieval operations.

## Public Methods

### `validatePaginationParameters`

Validates pagination parameters to ensure they are within acceptable ranges.

| Parameter | Type | Description |
|-----------|------|-------------|
| `page`    | `int` | The page number to validate. Must be greater than or equal to 0. |
| `size`    | `int` | The size of the page to validate. Must be greater than 0 and less than or equal to 1000. |

**Return Type:** `void`

**Exceptions:** Throws `IllegalArgumentException` if the parameters do not meet the criteria.

### `validateCursorPaginationParameters`

Validates the size parameter for cursor-based pagination.

| Parameter | Type | Description |
|-----------|------|-------------|
| `size`    | `int` | The size of the page to validate. Must be greater than 0 and less than or equal to 1000. |

**Return Type:** `void`

**Exceptions:** Throws `IllegalArgumentException` if the size does not meet the criteria.

### `validateSortBy`

Validates the `sortBy` parameter to ensure it is not null or empty and is among the allowed fields.

| Parameter    | Type     | Description |
|--------------|----------|-------------|
| `sortBy`     | `String` | The field to sort by. Cannot be null or empty. |
| `allowedFields` | `String...` | A varargs parameter representing the fields that are allowed for sorting. |

**Return Type:** `void`

**Exceptions:** Throws `IllegalArgumentException` if `sortBy` is null, empty, or not among the allowed fields.
