# SecurityHeadersFilter

## Purpose

The `SecurityHeadersFilter` is a Spring Boot servlet filter that automatically adds essential security headers to every HTTP response. It extends `OncePerRequestFilter` to guarantee that the headers are applied exactly once per request, even if the filter is invoked multiple times in the filter chain.

This filter is registered with the highest precedence (offset by 5) to ensure that security headers are set before any other filters or controllers process the request. By setting these headers, the application helps protect against common web vulnerabilities such as clickjacking, MIME-type sniffing, cross-site scripting (XSS), and information leakage.

## Security Headers Applied

The filter sets the following HTTP response headers:

| Header | Value | Purpose |
|--------|-------|---------|
| `X-Content-Type-Options` | `nosniff` | Prevents MIME-type sniffing, forcing the browser to use the declared content type. |
| `X-Frame-Options` | `DENY` | Prevents the page from being displayed in an iframe, mitigating clickjacking attacks. |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | Controls how much referrer information is sent with requests. Sends the full URL for same-origin requests, and only the origin for cross-origin requests. |
| `X-Permitted-Cross-Domain-Policies` | `none` | Restricts cross-domain policy files (e.g., `crossdomain.xml`) from being loaded. |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=()` | Disables access to sensitive device features (camera, microphone, geolocation) by default. |
| `Content-Security-Policy` | `default-src 'none'; frame-ancestors 'none'` | Restricts resource loading to only same-origin sources and prevents framing of the page. |
| `Server` | (empty) | Removes the server header to prevent information leakage about the server software. |
| `X-Powered-By` | (empty) | Removes the `X-Powered-By` header to prevent information leakage about the technology stack. |

## Class Details

### Package
`com.upmatches.app.features.auth.filters`

### Annotations
- `@Component` – Marks this class as a Spring bean for automatic detection.
- `@Order(Ordered.HIGHEST_PRECEDENCE + SecurityHeadersFilter.ORDER_OFFSET)` – Ensures this filter runs before all other filters in the chain.

## Public Methods

### `doFilterInternal`

```java
protected final void doFilterInternal(
    HttpServletRequest request,
    HttpServletResponse response,
    FilterChain filterChain
) throws ServletException, IOException
```

This is the core method that applies the security headers to every HTTP response.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The incoming HTTP request (not modified by this filter). |
| `response` | `HttpServletResponse` | The HTTP response to which security headers are added. |
| `filterChain` | `FilterChain` | The filter chain to continue processing the request. |

**Returns:** `void`

**Throws:**
- `ServletException` – If an error occurs during filter processing.
- `IOException` – If an I/O error occurs during filter processing.

**Behavior:**
1. Sets all security headers on the response object.
2. Calls `filterChain.doFilter(request, response)` to continue processing the request through the remaining filters and the controller.

## Usage

This filter is automatically applied to all HTTP requests in the Spring Boot application because it is annotated with `@Component`. No additional configuration is required.

To customize or extend this filter, you can:
- Modify the constant values to adjust header values.
- Override the `shouldNotFilter` method to exclude certain paths from security header processing.
- Add additional security headers as needed.

## Example Response Headers

After this filter processes a request, the HTTP response will include headers similar to:

```
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Referrer-Policy: strict-origin-when-cross-origin
X-Permitted-Cross-Domain-Policies: none
Permissions-Policy: camera=(), microphone=(), geolocation=()
Content-Security-Policy: default-src 'none'; frame-ancestors 'none'
Server:
X-Powered-By:
```
