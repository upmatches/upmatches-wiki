## Purpose

The `SecurityHeadersFilter` class is a custom filter in a Spring application that adds several security-related HTTP headers to the response. This filter is designed to enhance the security of web applications by preventing various types of attacks such as clickjacking, MIME type sniffing, and cross-origin information leakage. It extends the `OncePerRequestFilter` class, ensuring that the filter is executed once per request.

## Public Methods

The class contains the following public method:

### `doFilterInternal`

This method is overridden from the `OncePerRequestFilter` class and is responsible for adding security headers to the HTTP response.

| Parameter   | Type                      | Description                                                                 |
|-------------|---------------------------|-----------------------------------------------------------------------------|
| `request`   | `HttpServletRequest`      | The HTTP request object.                                                    |
| `response`  | `HttpServletResponse`     | The HTTP response object to which headers will be added.                    |
| `filterChain` | `FilterChain`           | The filter chain to pass the request and response to the next filter.       |

#### Return Type

- `void`: This method does not return any value.

#### Exceptions

- `ServletException`: If an exception occurs that interferes with the filter's normal operation.
- `IOException`: If an input or output exception occurs.

## Security Headers Added

- **X-Content-Type-Options**: Set to `nosniff` to prevent MIME type sniffing.
- **X-Frame-Options**: Set to `DENY` to prevent clickjacking by disallowing the page to be displayed in a frame.
- **Referrer-Policy**: Set to `strict-origin-when-cross-origin` to control the amount of referrer information sent with requests.
- **X-Permitted-Cross-Domain-Policies**: Set to `none` to prevent cross-domain policy files from being loaded.
- **Permissions-Policy**: Configured to disable features like camera, microphone, and geolocation.
- **Content-Security-Policy**: Configured to disallow all sources by default and prevent frame ancestors.
- **Server**: Set to an empty string to hide server information.
- **X-Powered-By**: Set to an empty string to hide technology stack information.
