## Purpose

The `EmailContentRenderer` class is a utility class designed to assist in generating HTML content for email notifications. It provides methods to wrap email content in a styled HTML template, create call-to-action buttons, and build detailed tables for email notifications based on the type of notification and context provided.

## Public Methods

### `wrap`

Wraps the provided title, body, details, and call-to-action (CTA) HTML into a styled email template.

| Parameter   | Type   | Description                                      |
|-------------|--------|--------------------------------------------------|
| `title`     | String | The title of the email.                          |
| `body`      | String | The main body content of the email.              |
| `detailsHtml` | String | The HTML content for additional details.       |
| `ctaHtml`   | String | The HTML content for the call-to-action button.  |

| Return Type | Description                          |
|-------------|--------------------------------------|
| String      | The complete HTML content for the email. |

### `buildCtaButton`

Creates an HTML button for a call-to-action link.

| Parameter | Type   | Description                       |
|-----------|--------|-----------------------------------|
| `gameUrl` | String | The URL to be linked by the button.|

| Return Type | Description                          |
|-------------|--------------------------------------|
| String      | The HTML content for the CTA button. |

### `buildDetailsTable`

Builds an HTML table containing details based on the notification type and context.

| Parameter | Type             | Description                                  |
|-----------|------------------|----------------------------------------------|
| `type`    | NotificationType | The type of notification.                    |
| `context` | EmailContext     | The context containing details for the email.|

| Return Type | Description                          |
|-------------|--------------------------------------|
| String      | The HTML content for the details table. |

## Usage

The `EmailContentRenderer` class is used to format and render email content dynamically based on the notification type and context. It ensures that all HTML content is safely escaped to prevent XSS attacks and provides a consistent styling for all emails sent by the application.
