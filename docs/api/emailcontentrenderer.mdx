# EmailContentRenderer

The `EmailContentRenderer` class is a utility for generating HTML email content for the Upmatches application. It provides methods to create structured, styled email templates with consistent formatting, including headers, body text, detail tables, and call-to-action buttons.

This class is designed to work with `NotificationType` and `EmailContext` objects to produce context-aware email content, such as game reminders and notifications.

## Features

- Generates HTML email content with a consistent wrapper template
- Escapes HTML to prevent XSS vulnerabilities
- Creates styled detail tables for email content
- Builds call-to-action buttons with customizable URLs
- Supports different notification types with varying detail levels
- Formats dates, times, and court counts in a human-readable format

## Public Methods

### `wrap`

Generates a complete HTML email wrapper with the provided components.

| Parameter | Type | Description |
|-----------|------|-------------|
| `title` | `String` | The email title (will be HTML-escaped) |
| `body` | `String` | The email body text (will be HTML-escaped) |
| `detailsHtml` | `String` | Pre-formatted HTML for the details section |
| `ctaHtml` | `String` | Pre-formatted HTML for the call-to-action button |

**Returns:** `String` - The complete HTML email content

### `buildCtaButton`

Creates an HTML call-to-action button linking to a game URL.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameUrl` | `String` | The URL for the game (will be HTML-escaped) |

**Returns:** `String` - HTML for the button, or empty string if URL is null/blank

### `buildDetailsTable`

Generates an HTML table with details based on the notification type and context.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification |
| `context` | `EmailContext` | The email context containing relevant data |

**Returns:** `String` - HTML table with details, or empty string if parameters are null

## Usage Examples

### Basic Email Generation

```java
EmailContext context = new EmailContext(
    "Soccer Match",
    "Central Park Field 3",
    LocalDate.of(2024, 3, 15),
    LocalTime.of(14, 0),
    LocalTime.of(16, 0),
    "Intermediate",
    2
);

String details = EmailContentRenderer.buildDetailsTable(
    NotificationType.GAME_REMINDER_1_DAY,
    context
);

String cta = EmailContentRenderer.buildCtaButton("https://upmatches.com/game/123");

String emailHtml = EmailContentRenderer.wrap(
    "Game Reminder",
    "Your game is tomorrow!",
    details,
    cta
);
```

### Game Reminder (3 Days Before)

For `GAME_REMINDER_3_DAYS` notifications, the details table only includes the date and court count:

```java
EmailContext context = new EmailContext(
    null,  // gameTitle not needed
    null,  // venue not needed
    LocalDate.of(2024, 3, 18),
    null,  // startTime not needed
    null,  // endTime not needed
    null,  // skillLevel not needed
    3
);

String details = EmailContentRenderer.buildDetailsTable(
    NotificationType.GAME_REMINDER_3_DAYS,
    context
);
```

## Internal Methods

The following private methods support the public API:

| Method | Description |
|--------|-------------|
| `appendRowIfPresent` | Appends a table row only if the value is non-null and non-blank |
| `appendRow` | Appends a formatted table row with HTML-escaped label and value |
| `formatDate` | Formats a `LocalDate` to "EEEE, d MMM yyyy" pattern (e.g., "Monday, 15 March 2024") |
| `formatTimeRange` | Formats a time range (e.g., "2:00 PM – 4:00 PM") or a single time |
| `formatCourts` | Formats court count with singular/plural (e.g., "1 court" or "3 courts") |

## Security Considerations

- All user-provided text is HTML-escaped using `HtmlUtils.htmlEscape()` to prevent XSS attacks
- The class is `final` and has a private constructor to prevent instantiation
- Null and blank checks are performed on all inputs to prevent errors
