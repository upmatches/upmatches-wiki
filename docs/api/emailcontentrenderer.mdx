# EmailContentRenderer

The `EmailContentRenderer` class is a utility for generating styled HTML email content for the Upmatches application. It provides methods to create consistent, visually appealing email templates with support for dynamic content such as game details, call-to-action buttons, and formatted date/time information.

This class is designed to be used as a stateless utility, with all methods being static and the constructor private to prevent instantiation.

## Features

- Generates HTML email content with consistent styling
- Supports different notification types with customizable detail tables
- Provides formatted date and time display
- Includes call-to-action button generation
- Handles HTML escaping for security
- Supports multiple game details (venue, date, time, skill level, court count)

## Public Methods

### `wrap(String title, String body, String detailsHtml, String ctaHtml)`

Wraps the provided content into a complete HTML email template.

| Parameter | Type | Description |
|-----------|------|-------------|
| `title` | `String` | The email title (will be HTML-escaped) |
| `body` | `String` | The email body text (will be HTML-escaped) |
| `detailsHtml` | `String` | Pre-formatted HTML for details section (can be null) |
| `ctaHtml` | `String` | Pre-formatted HTML for call-to-action button (can be null) |

**Returns:** `String` - Complete HTML email content

**Example:**
```java
String emailHtml = EmailContentRenderer.wrap(
    "Game Reminder",
    "Your game is coming up soon!",
    detailsTableHtml,
    ctaButtonHtml
);
```

### `buildCtaButton(String gameUrl)`

Creates an HTML call-to-action button linking to a game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameUrl` | `String` | The URL for the game (will be HTML-escaped) |

**Returns:** `String` - HTML for the button, or empty string if URL is null/blank

**Example:**
```java
String buttonHtml = EmailContentRenderer.buildCtaButton("https://upmatches.com/game/123");
```

### `buildDetailsTable(NotificationType type, EmailContext context)`

Builds an HTML table with game details based on the notification type and context.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification (determines which fields to display) |
| `context` | `EmailContext` | The email context containing game details |

**Returns:** `String` - HTML table with details, or empty string if no valid data

**Behavior by NotificationType:**
- **GAME_REMINDER_3_DAYS**: Displays only date and court count
- **Other types**: Displays game title, venue, date, time range, and skill level

**Example:**
```java
EmailContext context = new EmailContext(
    "Friendly Match",
    "Central Park Courts",
    LocalDate.of(2024, 3, 15),
    LocalTime.of(14, 0),
    LocalTime.of(16, 0),
    "Intermediate",
    2
);

String detailsHtml = EmailContentRenderer.buildDetailsTable(
    NotificationType.GAME_INVITATION,
    context
);
```

## Private Helper Methods

The class includes several private methods for internal formatting:

- `formatDate(LocalDate date)` - Formats a date as "Monday, 15 March 2024"
- `formatTimeRange(LocalTime startTime, LocalTime endTime)` - Formats time range as "2:00 PM – 4:00 PM"
- `formatCourts(Integer count)` - Formats court count as "2 courts" or "1 court"
- `appendRowIfPresent(StringBuilder rows, String label, String value)` - Adds a row if value is not null/blank
- `appendRow(StringBuilder rows, String label, String value)` - Adds a formatted table row

## Usage Example

```java
// Create email context
EmailContext context = new EmailContext(
    "Weekend Tournament",
    "Sports Complex A",
    LocalDate.of(2024, 3, 20),
    LocalTime.of(10, 0),
    LocalTime.of(12, 30),
    "Advanced",
    4
);

// Build components
String detailsTable = EmailContentRenderer.buildDetailsTable(
    NotificationType.GAME_INVITATION,
    context
);

String ctaButton = EmailContentRenderer.buildCtaButton(
    "https://upmatches.com/game/456"
);

// Generate complete email
String emailHtml = EmailContentRenderer.wrap(
    "You're Invited!",
    "You have been invited to join a game.",
    detailsTable,
    ctaButton
);
```

## Security Considerations

- All user-provided content is HTML-escaped using `HtmlUtils.htmlEscape()` to prevent XSS attacks
- Null and blank values are handled gracefully, returning empty strings where appropriate
- The class is immutable and thread-safe as all methods are stateless
