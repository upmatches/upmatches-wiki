## Purpose

The `SendFcmTestNotificationService` class is a Spring service designed to send Firebase Cloud Messaging (FCM) test notifications and emails in a development environment. It handles the creation and dispatch of notifications based on different types of events related to games, such as player actions and game updates. The service integrates with Firebase for push notifications and a Resend client for email notifications.

## Public Methods

### `execute`

Executes the process of sending a test notification based on the provided request.

| Parameter | Type                                  | Description                                      |
|-----------|---------------------------------------|--------------------------------------------------|
| `request` | `SendFcmTestNotificationRequest`      | The request object containing notification details.|

| Returns   | Type                       | Description                                      |
|-----------|----------------------------|--------------------------------------------------|
|           | `FcmTestNotificationResponse` | The response containing the result of the notification dispatch.|

### `resolveTitle`

Resolves the title of the notification based on the notification type.

| Parameter | Type             | Description                                      |
|-----------|------------------|--------------------------------------------------|
| `type`    | `NotificationType` | The type of notification to determine the title for.|

| Returns   | Type     | Description                                      |
|-----------|----------|--------------------------------------------------|
|           | `String` | The resolved title for the notification.         |

### `resolveBody`

Resolves the body content of the notification based on the notification type and other parameters.

| Parameter   | Type             | Description                                      |
|-------------|------------------|--------------------------------------------------|
| `type`      | `NotificationType` | The type of notification to determine the body for.|
| `gameTitle` | `String`         | The title of the game involved in the notification.|
| `courtCount`| `int`            | The number of courts involved in the notification.|
| `date`      | `LocalDate`      | The date related to the notification.            |

| Returns   | Type     | Description                                      |
|-----------|----------|--------------------------------------------------|
|           | `String` | The resolved body content for the notification.  |

### `sendPush`

Sends a push notification to a device using Firebase Cloud Messaging.

| Parameter     | Type             | Description                                      |
|---------------|------------------|--------------------------------------------------|
| `deviceToken` | `String`         | The device token to send the notification to.    |
| `type`        | `NotificationType` | The type of notification being sent.             |
| `title`       | `String`         | The title of the notification.                   |
| `body`        | `String`         | The body content of the notification.            |
| `badge`       | `Integer`        | The badge count for the notification.            |

| Returns   | Type     | Description                                      |
|-----------|----------|--------------------------------------------------|
|           | `String` | The message ID of the sent push notification.    |

### `sendEmail`

Sends an email notification using the Resend client.

| Parameter | Type             | Description                                      |
|-----------|------------------|--------------------------------------------------|
| `email`   | `String`         | The recipient's email address.                   |
| `type`    | `NotificationType` | The type of notification being sent.             |
| `title`   | `String`         | The subject of the email.                        |
| `body`    | `String`         | The body content of the email.                   |
| `context` | `EmailContext`   | The context for the email content.               |

| Returns   | Type     | Description                                      |
|-----------|----------|--------------------------------------------------|
|           | `String` | The email ID of the sent email notification.     |
