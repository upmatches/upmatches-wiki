# SendFcmTestNotificationService

## Purpose

The `SendFcmTestNotificationService` class is a Spring service, active only in the `dev` profile, designed for testing Firebase Cloud Messaging (FCM) push notifications and Resend email notifications. It provides a controlled environment for developers to simulate various notification types (e.g., player joined, game updated, reminders) without relying on real user interactions. The service constructs and sends both push notifications (via FCM) and HTML emails (via Resend) based on a provided request, returning a response containing the message IDs and notification details.

## Public Methods

### `execute`

```java
public FcmTestNotificationResponse execute(SendFcmTestNotificationRequest request)
```

Processes a test notification request by sending a push notification and/or an email based on the request parameters.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `SendFcmTestNotificationRequest` | The request object containing notification type, device token, email, and other details. |

**Returns:** `FcmTestNotificationResponse` - A response object containing the message ID, email ID, notification type, title, body, and badge count.

**Throws:** `ExternalServiceException` - If FirebaseMessaging or Resend client is unavailable, or if sending the notification fails.

## Internal Methods

### `resolveTitle`

```java
String resolveTitle(NotificationType type)
```

Resolves the notification title based on the notification type.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification to send. |

**Returns:** `String` - The corresponding title for the notification type.

### `resolveBody`

```java
String resolveBody(NotificationType type, String gameTitle, int courtCount, LocalDate date)
```

Resolves the notification body/message based on the notification type and parameters.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification to send. |
| `gameTitle` | `String` | The title of the game (used in some notification types). |
| `courtCount` | `int` | The number of courts (used in reminder notifications). |
| `date` | `LocalDate` | The date of the game (used in reminder notifications). |

**Returns:** `String` - The formatted body message for the notification.

## Notification Types

The service supports the following notification types, each with a specific title and body template:

| Notification Type | Title | Body Template |
|-------------------|-------|---------------|
| `PLAYER_JOINED` | A player joined your game | "A new player joined %s." |
| `PLAYER_LEFT` | A player left your game | "A player left %s." |
| `PLAYER_WARNING_MISMATCH` | Skill-level warning | "A player joined your game." |
| `GAME_FULL` | Your game is full | "Your badminton game has max out." |
| `GAME_UPDATED` | Game updated | "%s has been updated." |
| `GAME_REMOVED` | Game cancelled | "Your badminton game has been cancelled." |
| `PLAYER_REMOVED_FROM_GAME` | You were removed from a game | "You have been removed from a badminton game." |
| `GAME_REMINDER_3_DAYS` | Upcoming games in 3 days | "You have %d %s on %s." |
| `GAME_REMINDER_1_DAY` | Upcoming game tomorrow | "Your game starts on %s." |

## Dependencies

- **FirebaseMessaging**: Used for sending push notifications to mobile devices.
- **Resend**: Used for sending HTML email notifications.
- **UserRepository**: Used to look up user information for badge count calculation.
- **NotificationRepository**: Used to count unread notifications for badge display.
- **EmailContentRenderer**: Utility class for building HTML email content.
- **ResendProperties**: Configuration properties for the Resend email service.

## Error Handling

The service throws `ExternalServiceException` in the following scenarios:

1. **FirebaseMessaging unavailable**: When the FirebaseMessaging bean is not available in the application context.
2. **Resend unavailable**: When the Resend client is not available in the application context.
3. **Push notification failure**: When FirebaseMessaging fails to send the push notification.
4. **Email failure**: When Resend fails to send the email.

## Usage Example

```java
// Create a test notification request
SendFcmTestNotificationRequest request = new SendFcmTestNotificationRequest(
    NotificationType.PLAYER_JOINED,
    "device-token-123",
    "user@example.com",
    "Badminton Game",
    "Sports Hall",
    2,
    LocalDate.now().plusDays(1),
    LocalTime.of(14, 0),
    LocalTime.of(16, 0),
    "Intermediate",
    5,
    "https://example.com/game/123"
);

// Execute the service
FcmTestNotificationResponse response = sendFcmTestNotificationService.execute(request);

// Access the response
String messageId = response.messageId();
String emailId = response.emailId();
String title = response.title();
String body = response.body();
```
