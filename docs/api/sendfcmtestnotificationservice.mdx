## Purpose

The `SendFcmTestNotificationService` class is a Spring service designed to send test notifications via Firebase Cloud Messaging (FCM) and emails using the Resend service. It is specifically configured to operate in a development environment, as indicated by the `@Profile("dev")` annotation. This service facilitates testing of notification functionalities by sending push notifications to devices and emails to specified addresses.

## Public Methods

### `execute`

Executes the process of sending a test notification based on the provided request.

| Parameter | Type                                      | Description                                      |
|-----------|-------------------------------------------|--------------------------------------------------|
| request   | `SendFcmTestNotificationRequest`          | The request containing notification details.     |

| Returns   | Type                                      | Description                                      |
|-----------|-------------------------------------------|--------------------------------------------------|
|           | `FcmTestNotificationResponse`             | The response containing the result of the operation. |

## Method Details

### `execute(SendFcmTestNotificationRequest request)`

- **Purpose**: Sends a test notification based on the provided request. It determines the type of notification, constructs the message, and sends it either as a push notification or an email, or both.
- **Parameters**:
  - `request`: An instance of `SendFcmTestNotificationRequest` containing details such as notification type, game title, court count, date, device token, and email.
- **Returns**: An instance of `FcmTestNotificationResponse` containing the message ID, email ID, notification type, title, body, and badge count.

### Private Helper Methods

The class also contains several private helper methods that assist in constructing and sending notifications:

- **`buildEmailContext`**: Constructs an `EmailContext` object based on the notification type and other parameters.
- **`sendPush`**: Sends a push notification using Firebase Messaging.
- **`sendEmail`**: Sends an email using the Resend service.
- **`hasValue`**: Checks if a given string is non-null and non-blank.
- **`resolveBadge`**: Determines the badge count for the notification.
- **`countUnreadCapped`**: Counts unread notifications for a user, capped at a maximum value.
- **`resolveTitle`**: Resolves the notification title based on the notification type.
- **`resolveBody`**: Resolves the notification body based on the notification type and other parameters.
- **`buildData`**: Constructs a data map for the notification.
- **`isGameResource`**: Checks if the notification type is related to a game resource.
- **`resourceIdPlaceholder`**: Generates a placeholder resource ID for the notification.
- **`resolveCourtCount`**: Determines the court count for the notification.
- **`resolveDate`**: Determines the date for the notification.
- **`courtLabel`**: Returns the appropriate label ("court" or "courts") based on the count.
- **`formatDate`**: Formats a date using the specified date formatter.
