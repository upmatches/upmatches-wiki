# SendFcmTestNotificationService

## Purpose

The `SendFcmTestNotificationService` class is a Spring service bean, active only in the `dev` profile, designed for testing Firebase Cloud Messaging (FCM) push notifications and Resend email notifications. It provides a controlled environment for developers to send test notifications of various types (e.g., player joined, game updated, reminders) without relying on real user data or external triggers.

This service implements the `ISendFcmTestNotificationService` interface and is responsible for:
- Constructing notification payloads (title, body, badge count) based on the requested `NotificationType`.
- Sending push notifications via Firebase Cloud Messaging to a specified device token.
- Sending HTML email notifications via the Resend API to a specified email address.
- Generating deterministic placeholder data for testing purposes (e.g., game titles, dates, resource IDs).

## Public Methods

### `execute(SendFcmTestNotificationRequest request)`

The main entry point for sending a test notification. It processes the request, resolves notification content, and sends both push and email notifications as requested.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `SendFcmTestNotificationRequest` | The request object containing test notification parameters (type, device token, email, game details, etc.) |

**Returns:** `FcmTestNotificationResponse` - A response object containing the message ID, email ID, notification type, title, body, and badge count.

**Throws:** `ExternalServiceException` if FirebaseMessaging or Resend beans are unavailable, or if sending fails.

## Internal Methods

### `resolveTitle(NotificationType type)`

Resolves the notification title based on the notification type.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification to send |

**Returns:** `String` - The resolved title for the notification.

### `resolveBody(NotificationType type, String gameTitle, int courtCount, LocalDate date)`

Resolves the notification body/message based on the notification type and parameters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification to send |
| `gameTitle` | `String` | The title of the game (used in some notification types) |
| `courtCount` | `int` | The number of courts (used in reminder notifications) |
| `date` | `LocalDate` | The date of the game (used in reminder notifications) |

**Returns:** `String` - The resolved body message for the notification.

### `resolveBadge(SendFcmTestNotificationRequest request)`

Resolves the badge count for the notification. If a badge is explicitly provided in the request, it is used. Otherwise, if an email is provided, the badge count is calculated from the user's unread notifications (capped at 999).

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `SendFcmTestNotificationRequest` | The test notification request |

**Returns:** `Integer` - The badge count, or `null` if no badge should be set.

### `resolveCourtCount(NotificationType type, Integer requested)`

Resolves the court count for the notification. If a court count is explicitly provided, it is used. Otherwise, defaults to 3 for 3-day reminders and 1 for all other types.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification |
| `requested` | `Integer` | The requested court count (may be null) |

**Returns:** `int` - The resolved court count.

### `resolveDate(NotificationType type, LocalDate requested)`

Resolves the date for the notification. If a date is explicitly provided, it is used. Otherwise, defaults to 3 days from now for 3-day reminders and 1 day from now for all other types.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification |
| `requested` | `LocalDate` | The requested date (may be null) |

**Returns:** `LocalDate` - The resolved date.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `FirebaseMessaging` | `ObjectProvider` | Firebase Cloud Messaging client for sending push notifications |
| `Resend` | `ObjectProvider` | Resend email client for sending email notifications |
| `ResendProperties` | Configuration | Properties for Resend email configuration (from name, address) |
| `UserRepository` | Repository | Data access for user lookup by email |
| `NotificationRepository` | Repository | Data access for counting unread notifications |

## Usage Example

```java
// Create a test notification request
SendFcmTestNotificationRequest request = new SendFcmTestNotificationRequest(
    NotificationType.PLAYER_JOINED,
    "device-token-123",
    "test@example.com",
    "Saturday Badminton",
    "Sports Hall",
    2,
    LocalDate.now().plusDays(1),
    LocalTime.of(14, 0),
    LocalTime.of(16, 0),
    "Intermediate",
    5,
    "https://app.example.com/game/123"
);

// Execute the test notification
FcmTestNotificationResponse response = sendFcmTestNotificationService.execute(request);
```

## Notes

- This service is only active when the `dev` Spring profile is enabled.
- The service uses `ObjectProvider` for FirebaseMessaging and Resend beans, allowing graceful handling when these beans are not available.
- All resource IDs generated for test notifications are deterministic UUIDs based on the notification type namespace.
- The badge count is capped at 999 to prevent excessively large badge numbers.
- Email notifications use HTML templates rendered by `EmailContentRenderer`.
