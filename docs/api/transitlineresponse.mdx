# TransitLineResponse

The `TransitLineResponse` is a Java record class designed to represent a simplified view of a transit line associated with a specific station. It is used as a Data Transfer Object (DTO) to expose transit line information in API responses, typically within a venue or transit context.

## Purpose

This record serves as a lightweight, immutable data carrier that extracts and flattens relevant fields from a `StationLine` entity. It is particularly useful for:

- Returning transit line details (code, name, color) along with the station number in a single response.
- Decoupling the internal entity structure from the API contract.
- Improving performance by avoiding serialization of full entity graphs.

## Record Components

| Field           | Type      | Description                                      |
|-----------------|-----------|--------------------------------------------------|
| `code`          | `String`  | The unique code identifying the transit line.    |
| `name`          | `String`  | The human-readable name of the transit line.     |
| `color`         | `String`  | The color associated with the transit line.      |
| `stationNumber` | `Integer` | The station number along the transit line.       |

## Public Methods

### `fromStationLine(StationLine stationLine)`

Creates a `TransitLineResponse` instance from a `StationLine` entity.

**Parameters:**

| Parameter      | Type           | Description                                      |
|----------------|----------------|--------------------------------------------------|
| `stationLine`  | `StationLine`  | The source entity containing transit line and station number data. |

**Returns:**

| Type                   | Description                                      |
|------------------------|--------------------------------------------------|
| `TransitLineResponse`  | A new `TransitLineResponse` populated with data from the provided `StationLine`. |

**Example Usage:**

```java
StationLine stationLine = stationLineRepository.findById(stationLineId);
TransitLineResponse response = TransitLineResponse.fromStationLine(stationLine);
```

## Notes

- This record is immutable and thread-safe by design.
- The `fromStationLine` factory method assumes that `stationLine.getTransitLine()` is not null. Ensure proper null handling in the calling code if necessary.
- The record is intended for read-only API responses and should not be used for database persistence.
