# TransitLineResponse

The `TransitLineResponse` is a Java record class used to represent a simplified view of a transit line associated with a specific station. It is primarily designed for API responses, providing a lightweight data transfer object (DTO) that includes the transit line's code, name, color, and the station number on that line.

## Purpose

This record serves as a response model for endpoints that need to return transit line information in a concise format. By using a record, it automatically provides `equals()`, `hashCode()`, `toString()`, and accessor methods, reducing boilerplate code. The static factory method `fromStationLine()` converts a `StationLine` entity into this response object, ensuring a clean separation between the persistence layer and the API layer.

## Record Components

| Component       | Type      | Description                                      |
|-----------------|-----------|--------------------------------------------------|
| `code`          | `String`  | The unique code identifying the transit line.    |
| `name`          | `String`  | The human-readable name of the transit line.     |
| `color`         | `String`  | The color associated with the transit line.      |
| `stationNumber` | `Integer` | The station's number or order on this line.      |

## Public Methods

### `fromStationLine(StationLine stationLine)`

Creates a `TransitLineResponse` instance from a `StationLine` entity.

| Parameter      | Type           | Description                                      |
|----------------|----------------|--------------------------------------------------|
| `stationLine`  | `StationLine`  | The entity containing transit line and station data. |

**Returns:** `TransitLineResponse` — A new response object populated with data from the provided entity.

**Example usage:**

```java
StationLine stationLine = stationLineRepository.findById(stationLineId);
TransitLineResponse response = TransitLineResponse.fromStationLine(stationLine);
```

## Usage Notes

- This record is immutable by design, making it safe for use in concurrent environments.
- The `fromStationLine()` method extracts data from the nested `TransitLine` entity within the `StationLine` object, so ensure that the `StationLine` entity is properly loaded with its associated `TransitLine` before calling this method.
- The `stationNumber` field represents the station's position on the transit line (e.g., stop number or order index).
