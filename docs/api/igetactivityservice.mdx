# IGetActivityService Interface

The `IGetActivityService` interface defines the contract for retrieving a single activity by its unique identifier. It is a sealed interface, meaning only the explicitly permitted class `GetActivityService` can implement it. This design enforces a controlled and secure implementation hierarchy, ensuring that the activity retrieval logic is centralized and cannot be extended arbitrarily.

## Purpose

- **Sealed Contract**: Restricts implementation to a single class (`GetActivityService`), preventing unauthorized or unintended implementations.
- **Single Responsibility**: Provides a clear, focused method for fetching an activity by its UUID.
- **Type Safety**: Returns a strongly-typed `ActivityResponse` object, ensuring consistent data handling across the application.

## Interface Definition

```java
public sealed interface IGetActivityService permits GetActivityService {
    ActivityResponse execute(UUID id);
}
```

## Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `execute` | `UUID id` – The unique identifier of the activity to retrieve. | `ActivityResponse` | Executes the retrieval of an activity by its UUID. Returns the corresponding `ActivityResponse` object. |

## Usage Example

```java
// Assuming GetActivityService is properly instantiated
IGetActivityService activityService = new GetActivityService();
UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
ActivityResponse response = activityService.execute(activityId);
```

## Notes

- The `execute` method is the sole entry point for retrieving an activity by ID.
- The interface is sealed to `GetActivityService` only; no other class may implement it.
- The `ActivityResponse` class is expected to contain the activity data returned from the service.
