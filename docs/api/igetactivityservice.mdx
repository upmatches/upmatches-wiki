# IGetActivityService Interface

The `IGetActivityService` interface defines the contract for retrieving a single activity by its unique identifier. It follows a sealed interface pattern to restrict implementation to a specific service class, ensuring controlled extensibility and type safety within the activity domain.

## Purpose

This interface serves as the abstraction layer for the "get activity by ID" use case. By sealing the interface, the design enforces that only `GetActivityService` can implement it, preventing unintended implementations and promoting a clear, single-responsibility architecture.

## Interface Definition

```java
public sealed interface IGetActivityService permits GetActivityService {
    ActivityResponse execute(UUID id);
}
```

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `execute(UUID id)` | Retrieves an activity based on the provided unique identifier. | `id` - The UUID of the activity to retrieve. | `ActivityResponse` - The response object containing the activity data. |

## Usage Example

```java
// Assuming dependency injection provides an implementation
IGetActivityService getActivityService = new GetActivityService();

UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
ActivityResponse response = getActivityService.execute(activityId);
```

## Implementation Notes

- The interface is **sealed**, meaning only the class `GetActivityService` is permitted to implement it.
- The `execute` method expects a non-null `UUID` parameter.
- The returned `ActivityResponse` object contains the activity details if found, or may indicate an error state depending on the implementation.

## Related Components

- `GetActivityService` - The sole permitted implementation of this interface.
- `ActivityResponse` - The response data transfer object returned by the `execute` method.
