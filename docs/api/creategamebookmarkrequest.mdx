## Overview

The `CreateGameBookmarkRequest` class is a Java record used to encapsulate the data required to create a game bookmark request. This class is part of the `com.upmatches.app.features.game.requests` package and utilizes Java's record feature to provide an immutable data structure with minimal boilerplate code.

## Purpose

The primary purpose of the `CreateGameBookmarkRequest` class is to serve as a data transfer object (DTO) that carries the necessary information to bookmark a game within the application. It ensures that the `gameId` is provided and is not null, leveraging Jakarta Bean Validation for input validation.
