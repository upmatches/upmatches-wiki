# CreateGameBookmarkRequest

The `CreateGameBookmarkRequest` is a Java record class used as a Data Transfer Object (DTO) for creating a new game bookmark. It encapsulates the necessary input data required when a user wants to bookmark a specific game.

## Purpose

This record serves as the request payload for bookmark creation endpoints. By using a Java record, it provides an immutable data carrier with automatic `equals()`, `hashCode()`, and `toString()` methods. The class leverages Jakarta Bean Validation to ensure that the provided game identifier is never null.

## Record Definition

```java
public record CreateGameBookmarkRequest(@NotNull UUID gameId)
```

## Fields

| Field    | Type   | Validation | Description                                      |
|----------|--------|------------|--------------------------------------------------|
| `gameId` | `UUID` | `@NotNull` | The unique identifier of the game to be bookmarked |

## Constructor

The record automatically generates an all-arguments constructor:

```java
public CreateGameBookmarkRequest(UUID gameId)
```

## Usage Example

```java
// Creating a new bookmark request
UUID gameUuid = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
CreateGameBookmarkRequest request = new CreateGameBookmarkRequest(gameUuid);

// Accessing the game ID
UUID id = request.gameId();
```

## Validation

The `@NotNull` annotation on the `gameId` field ensures that:
- The game identifier must be provided and cannot be `null`
- Validation is typically enforced at the controller level using `@Valid` annotation
- A `ConstraintViolationException` will be thrown if validation fails

## Related Components

- **Controller**: Typically used in REST controllers as a `@RequestBody` parameter
- **Service**: Passed to service layer methods for processing bookmark creation
- **Entity**: The `gameId` is used to create or reference a `GameBookmark` entity in the database
