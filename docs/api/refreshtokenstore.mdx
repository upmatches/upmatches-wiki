## Purpose

The `RefreshTokenStore` class is a service responsible for managing refresh tokens in a Redis data store. It provides functionality to store, validate, rotate, and revoke refresh tokens associated with user sessions. This class is part of an authentication feature and relies on Redis for token storage and retrieval.

## Public Methods

### `store`

Stores a refresh token for a specific user.

| Parameter   | Type   | Description                  |
|-------------|--------|------------------------------|
| `userId`    | `UUID` | The unique identifier of the user. |
| `refreshToken` | `String` | The refresh token to be stored. |

| Return Type |
|-------------|
| `void`      |

### `validateAndRotate`

Validates the provided refresh token and rotates it by generating a new one.

| Parameter     | Type     | Description                  |
|---------------|----------|------------------------------|
| `refreshToken` | `String` | The refresh token to be validated and rotated. |

| Return Type                  |
|------------------------------|
| `ValidationResult` or `null` |

### `revokeAllForUser`

Revokes all refresh tokens associated with a specific user.

| Parameter | Type   | Description                  |
|-----------|--------|------------------------------|
| `userId`  | `UUID` | The unique identifier of the user. |

| Return Type |
|-------------|
| `void`      |

## Additional Information

- **Hashing**: The class uses SHA-256 to hash refresh tokens before storing them in Redis.
- **Serialization**: It uses Jackson for serializing and deserializing token entries.
- **Redis Operations**: The class performs various Redis operations such as storing values, setting expirations, and managing sets of token hashes.
