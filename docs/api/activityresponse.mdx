# ActivityResponse Record

The `ActivityResponse` record is a Data Transfer Object (DTO) used to represent an `Activity` entity in API responses. It provides a simplified, immutable view of an activity, exposing only the essential fields: `id`, `referenceId`, and `name`. This record is designed to decouple the internal entity structure from the external API contract.

## Purpose

- **API Response DTO**: Transforms an `Activity` entity into a lightweight, serializable format suitable for REST API responses.
- **Immutability**: As a Java `record`, all fields are final and the class is inherently immutable, ensuring thread-safety and data integrity.
- **Mapping Convenience**: Provides a static factory method `fromActivity()` to easily convert an `Activity` entity into a response object.

## Record Components

| Field         | Type      | Description                                      |
|---------------|-----------|--------------------------------------------------|
| `id`          | `UUID`    | Unique identifier for the activity.              |
| `referenceId` | `Integer` | External reference identifier for the activity.  |
| `name`        | `String`  | Human-readable name of the activity.             |

## Public Methods

### `fromActivity(Activity activity)`

Converts an `Activity` entity into an `ActivityResponse` record.

| Parameter  | Type       | Description                          |
|------------|------------|--------------------------------------|
| `activity` | `Activity` | The source activity entity to convert. |

**Returns**: `ActivityResponse` — a new record instance populated with the activity's `id`, `referenceId`, and `name`.

**Example Usage**:
```java
Activity activity = new Activity(UUID.randomUUID(), 1001, "Morning Jog");
ActivityResponse response = ActivityResponse.fromActivity(activity);
// response.id() -> UUID
// response.referenceId() -> 1001
// response.name() -> "Morning Jog"
```
