# ActivityResponse Record

The `ActivityResponse` record is a Data Transfer Object (DTO) used to represent an `Activity` entity in API responses. It provides a lightweight, immutable representation of an activity, exposing only the fields that are safe and necessary for external clients.

## Purpose

- **Encapsulation**: Hides internal entity details while exposing a clean, stable API contract.
- **Immutability**: As a Java `record`, all fields are final and the object is thread-safe.
- **Conversion**: Provides a static factory method to convert an `Activity` entity into a response object.

## Record Fields

| Field         | Type        | Description                                      |
|---------------|-------------|--------------------------------------------------|
| `id`          | `UUID`      | Unique identifier for the activity.              |
| `referenceId` | `Integer`   | External reference ID (e.g., from a third-party system). |
| `name`        | `String`    | Human-readable name of the activity.             |

## Public Methods

### `fromActivity(Activity activity)`

Converts an `Activity` entity into an `ActivityResponse` DTO.

**Parameters:**

| Parameter  | Type       | Description                          |
|------------|------------|--------------------------------------|
| `activity` | `Activity` | The source entity to convert from.   |

**Returns:** `ActivityResponse` — a new immutable response object with the same `id`, `referenceId`, and `name` as the provided entity.

**Example Usage:**

```java
Activity activity = new Activity(UUID.randomUUID(), 12345, "Morning Jog");
ActivityResponse response = ActivityResponse.fromActivity(activity);
// response.id() -> UUID
// response.referenceId() -> 12345
// response.name() -> "Morning Jog"
```

## Notes

- This record is part of the `com.upmatches.app.features.activity.responses` package.
- It is designed for use in REST API controllers or service layers where entity objects should not be directly exposed.
- The `fromActivity` method ensures a consistent mapping between the domain model and the API response layer.
