# ActivityResponse Record

The `ActivityResponse` record is a Data Transfer Object (DTO) used to expose activity data from the API layer. It provides a simplified, immutable representation of an `Activity` entity, ensuring that internal entity details are not leaked to external consumers.

## Purpose

- **Data Transfer**: Converts `Activity` entities into a lightweight response format suitable for serialization (e.g., JSON).
- **Encapsulation**: Hides internal entity fields and methods, exposing only the necessary attributes (`id`, `referenceId`, `name`).
- **Immutability**: As a Java record, all fields are final and the class is thread-safe by default.

## Fields

| Field         | Type      | Description                                      |
|---------------|-----------|--------------------------------------------------|
| `id`          | `UUID`    | Unique identifier for the activity.              |
| `referenceId` | `Integer` | External reference identifier (e.g., from a third-party system). |
| `name`        | `String`  | Human-readable name of the activity.             |

## Public Methods

### `fromActivity(Activity activity)`

Converts an `Activity` entity into an `ActivityResponse` instance.

**Parameters:**

| Parameter  | Type       | Description                          |
|------------|------------|--------------------------------------|
| `activity` | `Activity` | The source activity entity to convert. |

**Returns:**

| Type               | Description                                      |
|--------------------|--------------------------------------------------|
| `ActivityResponse` | A new `ActivityResponse` populated with data from the provided `Activity`. |

**Example Usage:**

```java
Activity activity = new Activity(UUID.randomUUID(), 1001, "Morning Run");
ActivityResponse response = ActivityResponse.fromActivity(activity);
// response.id() -> UUID
// response.referenceId() -> 1001
// response.name() -> "Morning Run"
```

## Notes

- The record automatically generates `equals()`, `hashCode()`, `toString()`, and accessor methods (e.g., `id()`, `referenceId()`, `name()`).
- This class is part of the `com.upmatches.app.features.activity.responses` package and is intended for use in REST API controllers or service layers.
