# ActivityResponse Class

The `ActivityResponse` class is a record in the `com.upmatches.app.features.activity.responses` package. It is designed to provide a simplified and immutable representation of an `Activity` entity, which can be used for transferring data across different layers of an application, such as from the backend to the frontend.

## Purpose

The primary purpose of the `ActivityResponse` class is to encapsulate the essential details of an `Activity` object in a form that is easy to handle and transmit. This class leverages Java's record feature to automatically generate boilerplate code such as constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods.

## Public Methods

The `ActivityResponse` class provides the following public method:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `fromActivity` | `Activity activity` | `ActivityResponse` | Converts an `Activity` object into an `ActivityResponse` object. |

### Method Details

#### `fromActivity`

- **Parameters:**
  - `activity`: An instance of the `Activity` class from which the `ActivityResponse` is created.

- **Return Type:** 
  - Returns an instance of `ActivityResponse` containing the `id`, `referenceId`, and `name` extracted from the given `Activity` object.

This method is static and can be called without creating an instance of `ActivityResponse`. It serves as a factory method to facilitate the conversion from an `Activity` entity to an `ActivityResponse` record.
