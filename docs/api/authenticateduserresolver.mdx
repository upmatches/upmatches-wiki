# AuthenticatedUserResolver

The `AuthenticatedUserResolver` class is a Spring service that provides a centralized way to extract the authenticated user's ID from the current security context. It implements the `IAuthenticatedUserResolver` interface and is designed to work with OAuth2 JWT tokens in a Spring Security environment.

## Purpose

This service resolves the currently authenticated user's UUID from the JWT token stored in the Spring Security context. It offers two methods:
- A **required** variant that throws an exception if no valid authentication is found
- An **optional** variant that returns an empty `Optional` when authentication is unavailable

This pattern allows callers to choose between strict authentication requirements and more flexible handling of unauthenticated requests.

## Public Methods

### `requireUserId()`

Returns the UUID of the currently authenticated user, throwing an exception if no valid authentication is present.

| Aspect | Details |
|--------|---------|
| **Return Type** | `UUID` |
| **Throws** | `AuthenticationException` - if no authentication exists, the principal is not a JWT, or the token's subject is not a valid UUID |

**Behavior:**
1. Retrieves the `Authentication` object from `SecurityContextHolder`
2. Validates that authentication exists and the principal is a `Jwt` instance
3. Parses the JWT's subject claim as a UUID
4. Throws `AuthenticationException` with descriptive messages for each failure case

### `optionalUserId()`

Returns an `Optional<UUID>` containing the authenticated user's ID, or empty if no valid authentication is present.

| Aspect | Details |
|--------|---------|
| **Return Type** | `Optional<UUID>` |

**Behavior:**
1. Retrieves the `Authentication` object from `SecurityContextHolder`
2. Returns `Optional.empty()` if no authentication exists or the principal is not a `Jwt`
3. Attempts to parse the JWT's subject claim as a UUID
4. Returns `Optional.empty()` if parsing fails (e.g., invalid UUID format)

## Usage Example

```java
@Service
public class GameService {
    private final AuthenticatedUserResolver userResolver;

    public GameService(AuthenticatedUserResolver userResolver) {
        this.userResolver = userResolver;
    }

    public void createGame() {
        // Strict authentication required
        UUID userId = userResolver.requireUserId();
        // ... create game for userId
    }

    public Optional<Game> findGameForCurrentUser() {
        // Optional authentication - works for both authenticated and anonymous users
        Optional<UUID> userId = userResolver.optionalUserId();
        return userId.flatMap(this::findGameByUserId);
    }
}
```

## Error Handling

The class uses two custom exception messages defined as constants:
- `MSG_NO_AUTH`: "No valid authentication found." - thrown when authentication is missing or the principal is not a JWT
- `MSG_INVALID_SUBJECT`: "Invalid user ID in token subject: %s" - thrown when the JWT subject cannot be parsed as a UUID

Both methods handle the `IllegalArgumentException` from `UUID.fromString()` gracefully, either by rethrowing as `AuthenticationException` (in `requireUserId()`) or returning `Optional.empty()` (in `optionalUserId()`).
