## Purpose

The `AuthenticatedUserResolver` class is a service component in a Spring application that provides methods to resolve the authenticated user's ID from the security context. It implements the `IAuthenticatedUserResolver` interface and is responsible for extracting the user ID from a JWT token present in the authentication context. This class is crucial for applications that need to identify users based on their authentication tokens.

## Public Methods

### `requireUserId`

This method retrieves the user ID from the current authentication context. It throws an `AuthenticationException` if no valid authentication is found or if the user ID in the token subject is invalid.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type | Description |
|-------------|-------------|
| `UUID`      | The user ID extracted from the JWT token subject. |

### `optionalUserId`

This method attempts to retrieve the user ID from the current authentication context. It returns an `Optional<UUID>` which is empty if no valid authentication is found or if the user ID in the token subject is invalid.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type     | Description |
|-----------------|-------------|
| `Optional<UUID>`| An optional containing the user ID if available, otherwise empty. |
