## Purpose

The `AuthenticatedUserResolver` class is a service component in a Spring application that provides methods to resolve the authenticated user's ID from the security context. It implements the `IAuthenticatedUserResolver` interface and is designed to handle authentication scenarios using JWT (JSON Web Tokens). The class offers methods to either require or optionally retrieve the user ID from the authentication token.

## Public Methods

### `requireUserId`

This method retrieves the user ID from the current authentication token. It throws an `AuthenticationException` if no valid authentication is found or if the token's subject is invalid.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type | Description |
|-------------|-------------|
| `UUID`      | The user ID extracted from the JWT subject. |

**Exceptions:**

- `AuthenticationException`: Thrown if no valid authentication is found or if the token's subject is invalid.

### `optionalUserId`

This method attempts to retrieve the user ID from the current authentication token. It returns an `Optional<UUID>`, which will be empty if no valid authentication is found or if the token's subject is invalid.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type      | Description |
|------------------|-------------|
| `Optional<UUID>` | An optional containing the user ID if present and valid, otherwise an empty optional. |
