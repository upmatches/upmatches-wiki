# AuthenticatedUserResolver

The `AuthenticatedUserResolver` class is a Spring service that provides a centralized way to extract the authenticated user's ID from the current security context. It implements the `IAuthenticatedUserResolver` interface and is designed to work with OAuth2 JWT tokens in a Spring Security environment.

## Purpose

This service resolves the currently authenticated user's UUID from the JWT token stored in the Spring Security context. It offers two methods:
- A **required** variant that throws an exception if no valid authentication is found
- An **optional** variant that returns an empty `Optional` when authentication is missing or invalid

This pattern allows different parts of the application to handle authentication status appropriately—either enforcing authentication or gracefully handling unauthenticated requests.

## Public Methods

### `requireUserId()`

Returns the UUID of the currently authenticated user, throwing an exception if no valid authentication is found.

| Aspect | Details |
|--------|---------|
| **Return Type** | `UUID` |
| **Throws** | `AuthenticationException` if no authentication exists, the principal is not a JWT, or the token's subject is not a valid UUID |

**Usage Example:**
```java
@Autowired
private AuthenticatedUserResolver userResolver;

public void someSecuredMethod() {
    UUID userId = userResolver.requireUserId();
    // Use userId for database operations, etc.
}
```

### `optionalUserId()`

Returns an `Optional<UUID>` containing the authenticated user's ID, or an empty `Optional` if no valid authentication is present.

| Aspect | Details |
|--------|---------|
| **Return Type** | `Optional<UUID>` |
| **Returns** | `Optional.empty()` if no authentication exists, the principal is not a JWT, or the token's subject is not a valid UUID |

**Usage Example:**
```java
@Autowired
private AuthenticatedUserResolver userResolver;

public void someOptionalMethod() {
    Optional<UUID> userId = userResolver.optionalUserId();
    userId.ifPresent(id -> {
        // Perform user-specific operations
    });
}
```

## Error Handling

Both methods handle two error scenarios:

1. **Missing or Invalid Authentication**: When `SecurityContextHolder.getContext().getAuthentication()` returns `null` or the principal is not a `Jwt` instance.
2. **Invalid Subject Format**: When the JWT's subject claim cannot be parsed as a valid `UUID`.

The `requireUserId()` method throws an `AuthenticationException` with descriptive messages in both cases, while `optionalUserId()` silently returns `Optional.empty()`.
