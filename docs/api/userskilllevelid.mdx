# UserSkillLevelId

The `UserSkillLevelId` class is a **composite primary key** used in a JPA/Hibernate entity relationship. It represents the unique identifier for a join table that links a `User` to a `SkillLevel`. This class is annotated with `@Embeddable`, allowing it to be embedded as a composite key in another entity.

## Purpose

In a many-to-many relationship between `User` and `SkillLevel` entities, this class serves as the composite key for the association table. It combines:
- **userId** (UUID) – Identifies the user
- **skillLevelId** (Long) – Identifies the skill level

This design follows JPA best practices for modeling join tables with additional attributes or when the relationship itself needs to be an entity.

## Key Design Decisions

1. **Serializable Implementation**: Required by JPA for composite keys to allow caching and distributed operations.

2. **UUID for User ID**: Provides globally unique identifiers, suitable for distributed systems and preventing ID collisions.

3. **Long for Skill Level ID**: Uses a numeric type for skill level identifiers, which is efficient for database indexing and foreign key relationships.

4. **Equals and HashCode Override**: Essential for composite keys to work correctly with JPA's identity management and collection operations.
