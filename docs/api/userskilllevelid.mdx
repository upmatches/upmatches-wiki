## Overview

The `UserSkillLevelId` class is a **composite primary key** entity used in the UpMatches application. It represents the unique identifier for the association between a `User` and a `SkillLevel`. This class is annotated with `@Embeddable` from Jakarta Persistence, making it embeddable within another entity class.

### Purpose

- **Composite Key Definition**: Defines a two-field primary key consisting of a `userId` (UUID) and a `skillLevelId` (Long).
- **JPA Embeddable**: Allows this composite key to be embedded in a JPA entity, enabling the creation of a many-to-many or one-to-many relationship table between users and skill levels.
- **Serializable**: Implements `Serializable` to support JPA's requirement for composite key classes to be serializable.
- **Equality and Hashing**: Provides proper `equals()` and `hashCode()` implementations based on both fields, ensuring correct behavior in collections and JPA contexts.

## Important Notes

- The class is immutable in the sense that it has no setters; fields are only set via the constructor.
- The `equals()` method uses `instanceof` pattern matching (Java 16+ feature) for type checking.
- Both fields are used in the `equals()` and `hashCode()` implementations to ensure proper identity semantics.
- The default constructor is required by JPA and should not be used directly in application code.
