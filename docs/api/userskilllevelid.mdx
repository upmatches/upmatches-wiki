# UserSkillLevelId

The `UserSkillLevelId` class is a **composite primary key** used in the `UserSkillLevel` entity. It is annotated with `@Embeddable` from Jakarta Persistence (JPA), allowing it to be embedded as a primary key in another entity.

This class implements `Serializable` and provides the necessary `equals()` and `hashCode()` methods required by JPA for composite key identification.

## Purpose

- Defines a composite key consisting of a `userId` (UUID) and a `skillLevelId` (Long).
- Enables JPA to uniquely identify a `UserSkillLevel` record in the database.
- Follows best practices for embeddable IDs by overriding `equals()` and `hashCode()`.

## Fields

| Field          | Type   | Description                                      |
|----------------|--------|--------------------------------------------------|
| `userId`       | UUID   | The unique identifier of the user.               |
| `skillLevelId` | Long   | The unique identifier of the skill level.        |
