## Overview

The `UpdateActivityRequest` class is a Java record used to encapsulate the data required for updating an activity within the application. It is part of the `com.upmatches.app.features.activity.requests` package. This class leverages Java's record feature to provide an immutable data structure with built-in methods for data access. The primary purpose of this class is to validate and hold the necessary information for an activity update request.

## Class Definition

The `UpdateActivityRequest` class is defined as a record, which is a special kind of class in Java introduced to model immutable data. It automatically provides implementations for common methods like `equals()`, `hashCode()`, and `toString()`.

## Public Methods

The `UpdateActivityRequest` class provides the following public methods:

| Method Signature | Description |
|------------------|-------------|
| `String name()`  | Returns the name of the activity to be updated. |

## Parameters

The `UpdateActivityRequest` class has the following parameter:

| Parameter | Type   | Description                                                                 |
|-----------|--------|-----------------------------------------------------------------------------|
| `name`    | String | The name of the activity. It must not be blank and can have a maximum length of 100 characters. |

## Annotations

The class uses the following annotations for validation:

- `@NotBlank`: Ensures that the `name` field is not null or empty.
- `@Size(max = 100)`: Ensures that the `name` field does not exceed 100 characters in length.

These annotations are part of the Jakarta Bean Validation API, which helps in validating the constraints on the fields of the record.
