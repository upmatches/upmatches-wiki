# Update Activity Request

The `UpdateActivityRequest` class is a Java record used to encapsulate the data required for updating an existing activity. It serves as a Data Transfer Object (DTO) for the activity update endpoint, ensuring that incoming requests contain valid and properly formatted data before being processed by the application.

## Purpose

This record provides a structured way to receive and validate activity update requests. By using Jakarta Bean Validation annotations, it enforces constraints on the input data at the API boundary, reducing the need for manual validation logic in service layers.

## Record Definition

```java
public record UpdateActivityRequest(
    @NotBlank
    @Size(max = 100)
    String name
) {}
```

## Fields

| Field | Type | Validation Constraints | Description |
|-------|------|------------------------|-------------|
| `name` | `String` | `@NotBlank`, `@Size(max = 100)` | The updated name for the activity. Must not be blank and must not exceed 100 characters. |

## Validation Rules

- **@NotBlank**: The `name` field must not be `null`, empty, or contain only whitespace characters.
- **@Size(max = 100)**: The `name` field must not exceed 100 characters in length.

## Usage Example

```java
// Creating a valid update request
UpdateActivityRequest request = new UpdateActivityRequest("Updated Activity Name");

// Accessing the field
String activityName = request.name();
```

## Related Components

- **ActivityController**: The REST controller that accepts `UpdateActivityRequest` as a request body parameter.
- **ActivityService**: The service layer that processes the update request and persists the changes.
- **Activity Entity**: The JPA entity that represents the activity in the database.
