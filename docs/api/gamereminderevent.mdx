## Overview

The `GameReminderEvent` class is a Java record that represents an event for game reminders within the application. It is part of the `com.upmatches.app.features.notification.events` package. This class is designed to encapsulate the details of a game reminder, specifically the unique identifier of the game and the type of notification associated with the reminder.

## Purpose

The primary purpose of the `GameReminderEvent` class is to serve as a data structure for passing information about game reminder events. It leverages Java's record feature to provide an immutable and concise way to store and access the event data.

## Public Methods

The `GameReminderEvent` class, being a record, automatically provides the following public methods:

### Constructor

| Method Signature | Description |
|------------------|-------------|
| `GameReminderEvent(UUID gameId, NotificationType type)` | Constructs a new `GameReminderEvent` with the specified game ID and notification type. |

### Accessor Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `gameId()` | `UUID` | Returns the unique identifier of the game associated with this reminder event. |
| `type()` | `NotificationType` | Returns the type of notification for this reminder event. |

## Parameters

The constructor of the `GameReminderEvent` class takes the following parameters:

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId`  | `UUID` | The unique identifier of the game for which the reminder is set. |
| `type`    | `NotificationType` | The type of notification to be sent for the game reminder. |

## Return Types

The accessor methods return the following types:

- `UUID`: Represents the unique identifier of the game.
- `NotificationType`: Enum representing the type of notification.
