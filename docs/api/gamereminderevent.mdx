# GameReminderEvent

The `GameReminderEvent` record is a data carrier used within the notification system of the UpMatches application. It encapsulates the essential information required to trigger a game reminder notification. This event is typically published to an event bus or message queue and consumed by a notification handler that processes the reminder logic.

## Purpose

- **Event-Driven Notification**: Serves as the payload for a game reminder event, enabling decoupled communication between the game scheduling system and the notification delivery system.
- **Immutable Data Transfer**: As a Java `record`, it provides a concise, immutable data structure with automatically generated constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods.
- **Type Safety**: Uses the `NotificationType` enum to specify the kind of reminder (e.g., upcoming game, game start, etc.), ensuring type-safe event handling.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game for which the reminder is being sent. |
| `type` | `NotificationType` | The type of notification to be delivered (e.g., `GAME_REMINDER`, `GAME_START`). |

## Usage Example

```java
import com.upmatches.app.features.notification.enums.NotificationType;
import java.util.UUID;

// Create a new game reminder event
UUID gameId = UUID.randomUUID();
GameReminderEvent event = new GameReminderEvent(gameId, NotificationType.GAME_REMINDER);

// Access the components
UUID id = event.gameId();
NotificationType notificationType = event.type();
```

## Related Components

- **NotificationType Enum**: Defines the various types of notifications supported by the system.
- **Notification Handler**: The consumer that processes `GameReminderEvent` instances and triggers the actual notification delivery (e.g., push notification, email, SMS).
