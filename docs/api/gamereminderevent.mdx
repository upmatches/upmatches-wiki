# GameReminderEvent

The `GameReminderEvent` is a Java record that represents a notification event for a game reminder. It is part of the notification system within the `com.upmatches.app` application, specifically designed to encapsulate the data required to trigger or process a reminder notification related to a game.

This record is immutable and provides a concise way to carry the necessary information—namely, the unique identifier of the game and the type of notification to be sent.

## Purpose

- **Encapsulation of Event Data**: Bundles the game ID and notification type into a single, immutable object.
- **Event-Driven Architecture**: Used as a payload in event-driven systems (e.g., message queues, event buses) to trigger reminder notifications.
- **Type Safety**: Leverages Java records to ensure that the data structure is clear and type-safe.

## Record Components

The `GameReminderEvent` record has two components:

| Component | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game for which the reminder is being sent. |
| `type` | `NotificationType` | The type of notification to be dispatched (e.g., push, email, in-app). |

## Usage Example

```java
import com.upmatches.app.features.notification.enums.NotificationType;
import java.util.UUID;

// Create a new GameReminderEvent
UUID gameId = UUID.randomUUID();
GameReminderEvent event = new GameReminderEvent(gameId, NotificationType.PUSH);

// Access the components
System.out.println("Game ID: " + event.gameId());
System.out.println("Notification Type: " + event.type());
```

## Notes

- The `NotificationType` enum is defined in the `com.upmatches.app.features.notification.enums` package and contains the possible notification types (e.g., `PUSH`, `EMAIL`, `IN_APP`).
- As a record, `GameReminderEvent` automatically provides `equals()`, `hashCode()`, `toString()`, and accessor methods (`gameId()`, `type()`).
- This class is immutable and thread-safe by design.
