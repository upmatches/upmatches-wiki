# GameReminderEvent

The `GameReminderEvent` is a Java record that encapsulates the data required to trigger a game reminder notification. It serves as a lightweight, immutable data carrier within the notification system of the application. This record is typically used in event-driven architectures to publish or consume reminder events for scheduled games.

## Purpose

- **Event Data Model**: Represents a specific notification event for reminding users about an upcoming game.
- **Immutability**: As a Java record, it provides automatic `equals()`, `hashCode()`, `toString()`, and a canonical constructor, ensuring thread-safe and predictable behavior.
- **Type Safety**: Uses the `NotificationType` enum to specify the kind of reminder (e.g., push, email, in-app).

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game for which the reminder is being sent. |
| `type` | `NotificationType` | The type of notification to be delivered (e.g., `PUSH`, `EMAIL`, `IN_APP`). |

## Usage Example

```java
import com.upmatches.app.features.notification.enums.NotificationType;
import java.util.UUID;

// Create a new game reminder event for a push notification
GameReminderEvent event = new GameReminderEvent(
    UUID.fromString("123e4567-e89b-12d3-a456-426614174000"),
    NotificationType.PUSH
);

// Access the record components
UUID gameId = event.gameId();
NotificationType type = event.type();
```

## Notes

- The `NotificationType` enum is defined in the `com.upmatches.app.features.notification.enums` package and should contain values relevant to the application's notification channels.
- This record is part of the `com.upmatches.app.features.notification.events` package and is intended for use within the notification subsystem.
