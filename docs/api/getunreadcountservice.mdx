# GetUnreadCountService

## Purpose

The `GetUnreadCountService` class is a Spring service component responsible for retrieving the count of unread notifications for the currently authenticated user. It implements the `IGetUnreadCountService` interface and provides a transactional read-only operation that queries the notification repository for unread notifications.

This service is part of the notification feature in the UpMatches application and follows a clean architecture pattern by separating the business logic from the data access layer.

## Class Details

| Property | Value |
|----------|-------|
| **Package** | `com.upmatches.app.features.notification.services` |
| **Annotations** | `@Service` |
| **Modifiers** | `public non-sealed` |
| **Implements** | `IGetUnreadCountService` |

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `NotificationRepository` | Constructor Injection | Repository for accessing notification data |
| `IAuthenticatedUserResolver` | Constructor Injection | Service to resolve the currently authenticated user's ID |

## Public Methods

### `execute()`

Retrieves the count of unread notifications for the currently authenticated user.

| Aspect | Details |
|--------|---------|
| **Signature** | `public UnreadCountResponse execute()` |
| **Transactional** | `@Transactional(readOnly = true)` |
| **Returns** | `UnreadCountResponse` - A response object containing the unread notification count |
| **Throws** | May throw exceptions from `userResolver.requireUserId()` if no authenticated user is found |

**Behavior:**
1. Resolves the authenticated user's ID using `userResolver.requireUserId()`
2. Queries the `notificationRepository` for the count of notifications where:
   - `recipientId` equals the resolved user ID
   - `isRead` is `false`
3. Wraps the count in an `UnreadCountResponse` object using the static factory method `UnreadCountResponse.of()`

## Usage Example

```java
// Inject the service
private final GetUnreadCountService getUnreadCountService;

// Use the service
UnreadCountResponse response = getUnreadCountService.execute();
long unreadCount = response.getCount(); // Assuming getCount() method exists
```

## Notes

- The service is declared as `non-sealed`, allowing it to be extended by other classes while maintaining the sealed interface hierarchy.
- The `@Transactional(readOnly = true)` annotation optimizes database access by allowing the underlying database to use read-only connections when supported.
- This service follows the command pattern where a single `execute()` method encapsulates the entire operation.
