# GetUnreadCountService

## Purpose

The `GetUnreadCountService` class is a Spring service component responsible for retrieving the count of unread notifications for the currently authenticated user. It implements the `IGetUnreadCountService` interface and provides a transactional read-only operation that queries the notification repository for unread notifications.

This service is part of the notification feature in the UpMatches application, enabling efficient retrieval of unread notification counts without modifying any data.

## Class Details

| Attribute | Value |
|-----------|-------|
| **Package** | `com.upmatches.app.features.notification.services` |
| **Annotations** | `@Service` |
| **Modifiers** | `public non-sealed` |
| **Implements** | `IGetUnreadCountService` |

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `NotificationRepository` | Constructor Injection | Repository for accessing notification data in the database |
| `IAuthenticatedUserResolver` | Constructor Injection | Service to resolve the currently authenticated user's ID |

## Constructor

### `GetUnreadCountService(NotificationRepository, IAuthenticatedUserResolver)`

Initializes the service with required dependencies.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `notificationRepository` | `NotificationRepository` | Repository for notification data access |
| `userResolver` | `IAuthenticatedUserResolver` | Service to resolve authenticated user identity |

## Public Methods

### `execute()`

Retrieves the count of unread notifications for the currently authenticated user.

**Annotations:** `@Transactional(readOnly = true)`

**Returns:**

| Type | Description |
|------|-------------|
| `UnreadCountResponse` | Response object containing the count of unread notifications |

**Behavior:**

1. Resolves the authenticated user's ID using `userResolver.requireUserId()`
2. Queries the notification repository for the count of notifications where:
   - `recipientId` matches the authenticated user's ID
   - `isRead` is `false`
3. Wraps the count in an `UnreadCountResponse` object using the static factory method `UnreadCountResponse.of()`

**Example Usage:**

```java
// Inject the service
private final GetUnreadCountService getUnreadCountService;

// Execute the service
UnreadCountResponse response = getUnreadCountService.execute();
long unreadCount = response.getCount(); // Assuming getCount() method exists
```

## Transactional Behavior

The method is marked with `@Transactional(readOnly = true)`, which:

- Ensures the database operation runs within a read-only transaction context
- Optimizes performance by allowing the database to use read replicas or read-optimized connections
- Prevents any accidental data modifications during the query execution

## Error Handling

The service relies on `userResolver.requireUserId()` to obtain the authenticated user's ID. If no authenticated user is found, this method is expected to throw an appropriate exception (e.g., `AuthenticationException` or `IllegalStateException`), which will propagate to the caller.
