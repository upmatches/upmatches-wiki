# AuditEvent

The `AuditEvent` class is a JPA entity that represents an auditable action or event within the application. It is used to record detailed information about user or system actions, including the actor, action type, outcome, and contextual metadata such as IP address, user agent, and request payload.

This entity is mapped to the `audit_events` database table and is designed to be immutable after creation (fields are not updatable). It leverages Lombok's `@Getter` for read-only access and a protected no-args constructor for JPA compliance.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `Long` | Auto-generated primary key (identity strategy). |
| `uuid` | `UUID` | Unique, non-nullable, and immutable identifier for the event. |
| `occurredAt` | `Instant` | Timestamp of when the event occurred (set automatically on persist). |
| `actorId` | `UUID` | Identifier of the actor who performed the action (user or system). |
| `actorType` | `AuditActorType` | Enum indicating the type of actor (e.g., USER, SYSTEM). |
| `action` | `String` | Description of the action performed (e.g., "LOGIN", "UPDATE_PROFILE"). |
| `category` | `AuditCategory` | Enum categorizing the event (e.g., AUTH, DATA_MODIFICATION). |
| `outcome` | `AuditOutcome` | Enum indicating the result of the action (e.g., SUCCESS, FAILURE). |
| `resourceType` | `String` | Type of resource affected (e.g., "User", "Order"). |
| `resourceId` | `String` | Identifier of the affected resource. |
| `ipAddress` | `String` | IP address of the client that initiated the action. |
| `userAgent` | `String` | User agent string from the client's request. |
| `correlationId` | `String` | Correlation ID for tracing related events across services. |
| `requestPayload` | `String` | JSON payload of the request (stored as JSONB in the database). |
| `errorCode` | `String` | Error code if the action resulted in an error. |
| `errorMessage` | `String` | Error message if the action resulted in an error. |

## Public Methods

### `create`

```java
public static AuditEvent create(
    UUID actorId,
    AuditActorType actorType,
    String action,
    AuditCategory category,
    AuditOutcome outcome,
    String resourceType,
    String resourceId,
    String ipAddress,
    String userAgent,
    String correlationId,
    String requestPayload,
    String errorCode,
    String errorMessage)
```

Creates a new `AuditEvent` instance with the provided parameters. This is the primary factory method for constructing audit events.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `actorId` | `UUID` | Identifier of the actor. |
| `actorType` | `AuditActorType` | Type of actor (e.g., USER, SYSTEM). |
| `action` | `String` | Description of the action. |
| `category` | `AuditCategory` | Category of the event. |
| `outcome` | `AuditOutcome` | Outcome of the action. |
| `resourceType` | `String` | Type of resource affected (nullable). |
| `resourceId` | `String` | Identifier of the affected resource (nullable). |
| `ipAddress` | `String` | Client IP address (nullable). |
| `userAgent` | `String` | Client user agent (nullable). |
| `correlationId` | `String` | Correlation ID for tracing (nullable). |
| `requestPayload` | `String` | JSON request payload (nullable). |
| `errorCode` | `String` | Error code (nullable). |
| `errorMessage` | `String` | Error message (nullable). |

**Returns:** `AuditEvent` - A new, fully populated audit event instance.

## Lifecycle Callbacks

### `onCreate`

```java
@PrePersist
void onCreate()
```

Automatically called by JPA before the entity is persisted. It sets the `uuid` to a random UUID and the `occurredAt` timestamp to the current instant if they are not already set. This ensures that every audit event has a unique identifier and a precise timestamp.

## Usage Example

```java
AuditEvent event = AuditEvent.create(
    userId,
    AuditActorType.USER,
    "LOGIN",
    AuditCategory.AUTH,
    AuditOutcome.SUCCESS,
    null,
    null,
    "192.168.1.1",
    "Mozilla/5.0...",
    "corr-123",
    null,
    null,
    null
);
auditEventRepository.save(event);
```
