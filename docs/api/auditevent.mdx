# AuditEvent

The `AuditEvent` class is a JPA entity that represents an auditable action within the system. It captures detailed information about user or system actions, including who performed the action, what action was taken, the outcome, and contextual metadata such as IP address, user agent, and correlation IDs. This entity is designed to support comprehensive audit logging for security, compliance, and debugging purposes.

## Entity Details

- **Package:** `com.upmatches.app.features.audit.entities`
- **Table:** `audit_events`
- **Annotations:** `@Entity`, `@Table`, `@Getter` (Lombok), `@NoArgsConstructor(access = AccessLevel.PROTECTED)`

## Public Methods

### `create`

```java
public static AuditEvent create(
    UUID actorId,
    AuditActorType actorType,
    String action,
    AuditCategory category,
    AuditOutcome outcome,
    String resourceType,
    String resourceId,
    String ipAddress,
    String userAgent,
    String correlationId,
    String requestPayload,
    String errorCode,
```

Creates a new `AuditEvent` instance with the specified parameters. This is the primary factory method for constructing audit events.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `actorId` | `UUID` | Identifier of the actor performing the action |
| `actorType` | `AuditActorType` | Type of actor (USER, SYSTEM, API, etc.) |
| `action` | `String` | Description of the action performed |
| `category` | `AuditCategory` | Category of the audit event |
| `outcome` | `AuditOutcome` | Result of the action (SUCCESS, FAILURE, etc.) |
| `resourceType` | `String` | Type of resource affected (nullable) |
| `resourceId` | `String` | Identifier of the affected resource (nullable) |
| `ipAddress` | `String` | IP address of the actor (nullable) |
| `userAgent` | `String` | User agent string from the request (nullable) |
| `correlationId` | `String` | Correlation ID for tracing (nullable) |
| `requestPayload` | `String` | Request payload as JSON string (nullable) |
| `errorCode` | `String` | Error code if action failed (nullable) |
| `errorMessage` | `String` | Error message if action failed (nullable) |

**Returns:** `AuditEvent` - A new instance with all fields set according to the provided parameters.

## Lifecycle Callbacks

### `onCreate`

```java
@PrePersist
void onCreate()
```

Automatically called before the entity is persisted to the database. This method:
- Generates a random `UUID` if one hasn't been set
- Sets the `occurredAt` timestamp to the current time if not already set

## Usage Example

```java
AuditEvent event = AuditEvent.create(
    userId,
    AuditActorType.USER,
    "LOGIN",
    AuditCategory.AUTHENTICATION,
    AuditOutcome.SUCCESS,
    "User",
    userId.toString(),
    "192.168.1.1",
    "Mozilla/5.0...",
    UUID.randomUUID().toString(),
    null,
    null,
    null
);
auditEventRepository.save(event);
```
