# AuditEvent

The `AuditEvent` class is a JPA entity that represents an auditable action within the system. It captures detailed information about user or system actions, including who performed the action, what action was taken, the outcome, and associated metadata such as IP address, user agent, and request payload.

This entity is mapped to the `audit_events` database table and is designed to be immutable after creation (all fields are either `final` or set only during construction/persistence).

## Purpose

- **Audit Trail**: Provides a comprehensive record of all significant actions for compliance, security, and debugging purposes.
- **Immutable Records**: Once created and persisted, audit events should not be modified, ensuring the integrity of the audit log.
- **Flexible Metadata**: Supports a wide range of metadata including actor details, resource information, request payloads, and error details.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `Long` | Auto-generated primary key (database identity). |
| `uuid` | `UUID` | Unique identifier for the event, generated automatically if not provided. |
| `occurredAt` | `Instant` | Timestamp of when the event occurred, set automatically on persist. |
| `actorId` | `UUID` | Identifier of the actor who performed the action. |
| `actorType` | `AuditActorType` | Type of actor (e.g., USER, SYSTEM, API). |
| `action` | `String` | Description of the action performed (e.g., "LOGIN", "CREATE_USER"). |
| `category` | `AuditCategory` | Category of the audit event (e.g., AUTHENTICATION, DATA_MODIFICATION). |
| `outcome` | `AuditOutcome` | Result of the action (e.g., SUCCESS, FAILURE). |
| `resourceType` | `String` | Type of resource affected (e.g., "User", "Order"). |
| `resourceId` | `String` | Identifier of the affected resource. |
| `ipAddress` | `String` | IP address of the client that performed the action. |
| `userAgent` | `String` | User agent string from the client request. |
| `correlationId` | `String` | Correlation ID for tracing related events across services. |
| `requestPayload` | `String` | JSON representation of the request payload (stored as JSONB in database). |
| `errorCode` | `String` | Error code if the action failed. |
| `errorMessage` | `String` | Error message if the action failed. |

## Methods

### `create`

```java
public static AuditEvent create(
    UUID actorId,
    AuditActorType actorType,
    String action,
    AuditCategory category,
    AuditOutcome outcome,
    String resourceType,
    String resourceId,
    String ipAddress,
    String userAgent,
    String correlationId,
    String requestPayload,
    String errorCode,
    String errorMessage)
```

Creates a new `AuditEvent` instance with the provided details.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `actorId` | `UUID` | Identifier of the actor. |
| `actorType` | `AuditActorType` | Type of actor. |
| `action` | `String` | Action description. |
| `category` | `AuditCategory` | Event category. |
| `outcome` | `AuditOutcome` | Action outcome. |
| `resourceType` | `String` | Type of affected resource (nullable). |
| `resourceId` | `String` | Identifier of affected resource (nullable). |
| `ipAddress` | `String` | Client IP address (nullable). |
| `userAgent` | `String` | Client user agent (nullable). |
| `correlationId` | `String` | Correlation ID (nullable). |
| `requestPayload` | `String` | JSON request payload (nullable). |
| `errorCode` | `String` | Error code (nullable). |
| `errorMessage` | `String` | Error message (nullable). |

**Returns:** `AuditEvent` - A new audit event instance.

### `onCreate` (Lifecycle Callback)

```java
@PrePersist
void onCreate()
```

Automatically called by JPA before persisting the entity. Sets the `uuid` and `occurredAt` fields if they are null.

```java
    "LOGIN",

```

## Database Mapping

- **Table**: `audit_events`
- **Primary Key**: `id` (auto-increment)
- **Unique Constraint**: `uuid`
- **JSON Column**: `request_payload` uses PostgreSQL JSONB type for efficient querying of request data.

## Notes

- The entity uses Lombok's `@Getter` to generate getters for all fields.
- The `@NoArgsConstructor(access = AccessLevel.PROTECTED)` ensures that JPA can create instances via reflection while preventing direct instantiation.
- All fields are immutable after creation (no setters exposed).
- The `uuid` and `occurredAt` fields are automatically populated if not explicitly set, ensuring every event has a unique identifier and timestamp.
