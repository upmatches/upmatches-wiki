## Overview

The `HealthCheckController` class is a Spring Boot REST controller designed to provide a simple health check endpoint for the application. It is part of the `com.upmatches.app.features.health.controllers` package. This controller is responsible for handling HTTP GET requests to verify that the service is running and accessible.

## Public Methods

### healthCheck

The `healthCheck` method is a public endpoint that responds to HTTP GET requests. It returns a response indicating the service status.

| Method Signature | Description |
|------------------|-------------|
| `public ResponseEntity<ApiResponse<String>> healthCheck(HttpServletRequest request)` | Handles GET requests to the health check endpoint and returns a status message. |

#### Parameters

| Parameter | Type                      | Description                              |
|-----------|---------------------------|------------------------------------------|
| `request` | `HttpServletRequest`      | The HTTP request object containing request details. |

#### Return Type

| Type                                | Description                                      |
|-------------------------------------|--------------------------------------------------|
| `ResponseEntity<ApiResponse<String>>` | A response entity containing the status and message of the service. |

## Constants

The class defines two constants used in the response:

- `STATUS_OK`: A `String` constant with the value `"OK"`, indicating the service status.
- `MESSAGE`: A `String` constant with the value `"Service is running"`, providing a message about the service state.
