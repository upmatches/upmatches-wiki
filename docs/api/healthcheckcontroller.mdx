# Health Check Controller

The `HealthCheckController` is a REST controller that provides a simple health check endpoint for the UpMatches application. It is used to verify that the service is running and accessible, returning a standardized API response with a status of "OK" and a confirmation message.

## Location

- **Package:** `com.upmatches.app.features.health.controllers`
- **Base URL:** `/api/v1/public/health`

## Public Methods

| Method | HTTP Method | Endpoint | Description |
|--------|-------------|----------|-------------|
| `healthCheck(HttpServletRequest request)` | `GET` | `/api/v1/public/health` | Returns a health check response indicating the service is running. |

### `healthCheck`

```java
public ResponseEntity<ApiResponse<String>> healthCheck(HttpServletRequest request)
```

**Description:**  
This method handles GET requests to the health check endpoint. It returns a standardized `ApiResponse` object containing:
- **Status:** `"OK"`
- **Message:** `"Service is running"`
- **Path:** The request URI from the incoming HTTP request

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The incoming HTTP request, used to extract the request URI for the response. |

**Returns:**

| Type | Description |
|------|-------------|
| `ResponseEntity<ApiResponse<String>>` | HTTP 200 OK response containing the health check data wrapped in an `ApiResponse` object. |

## Response Example

```json
{
  "status": "OK",
  "message": "Service is running",
  "path": "/api/v1/public/health"
}
```

## Usage

This endpoint is typically used by:
- **Load balancers** to verify service availability
- **Monitoring tools** (e.g., Prometheus, Grafana) for uptime checks
- **CI/CD pipelines** to confirm successful deployment
- **Client applications** to check connectivity before making other API calls

## Dependencies

- `com.upmatches.app.shared.responses.ApiResponse` - Shared response wrapper for consistent API output
- `jakarta.servlet.http.HttpServletRequest` - Jakarta Servlet API for accessing request details
- `org.springframework.http.ResponseEntity` - Spring Framework HTTP response entity
- `org.springframework.web.bind.annotation.*` - Spring Web annotations for REST controller mapping
