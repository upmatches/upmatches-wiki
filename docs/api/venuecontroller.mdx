# VenueController

The `VenueController` class is a REST controller that exposes endpoints for managing venues in the UpMatches application. It provides functionality for listing venues with pagination and importing venues via CSV file uploads. The controller is secured with role-based access control for administrative operations.

## Endpoints

### List Venues

Retrieves a paginated list of venues sorted alphabetically by name.

**HTTP Method:** `GET`  
**Endpoint:** `/api/v1/venues`

#### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | Integer | `0` | The page number to retrieve (zero-indexed) |
| `size` | Integer | `20` | The number of items per page |

#### Response

Returns a paginated response containing venue data.

**Status Code:** `200 OK`

**Response Body:**

```json
{
  "success": true,
  "message": "Venues retrieved successfully.",
  "data": {
    "content": [
      {
        "id": "string",
        "name": "string",
        "address": "string",
        "city": "string",
        "state": "string",
        "zipCode": "string",
        "phone": "string",
        "website": "string",
        "latitude": 0.0,
        "longitude": 0.0
      }
    ],
    "page": 0,
    "size": 20,
    "totalElements": 100,
    "totalPages": 5
  },
  "path": "/api/v1/venues"
}
```

#### Example Request

```bash
curl -X GET "http://localhost:8080/api/v1/venues?page=0&size=20" \
  -H "Accept: application/json"
```

---

### Import Venues

Uploads a CSV file to import venues into the system. This endpoint requires ADMIN role.

**HTTP Method:** `POST`  
**Endpoint:** `/api/v1/venues/imports`  
**Content-Type:** `multipart/form-data`

#### Request Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `file` | MultipartFile | Yes | CSV file containing venue data |

#### Response

Returns the result of the import operation.

**Status Code:** `201 Created`

**Response Body:**

```json
{
  "success": true,
  "message": "Venues imported successfully.",
  "data": {
    "totalRecords": 50,
    "successfulImports": 48,
    "failedImports": 2,
    "errors": [
      {
        "row": 15,
        "message": "Invalid zip code format"
      },
      {
        "row": 32,
        "message": "Duplicate venue name"
      }
    ]
  },
  "path": "/api/v1/venues/imports"
}
```

#### Example Request

```bash
curl -X POST "http://localhost:8080/api/v1/venues/imports" \
  -H "Authorization: Bearer <token>" \
  -F "file=@venues.csv"
```

## Security

The import endpoint is secured with Spring Security and requires the `ADMIN` role. The list endpoint is publicly accessible.

## Dependencies

- **IListVenuesService**: Service interface for retrieving paginated venue data
- **IImportVenuesService**: Service interface for processing venue imports from CSV files
- **ValidationHelper**: Utility class for validating pagination parameters

## Error Handling

The controller returns appropriate HTTP status codes and error messages for invalid requests:

- `400 Bad Request`: Invalid pagination parameters (e.g., negative page number)
- `401 Unauthorized`: Missing or invalid authentication token for import endpoint
- `403 Forbidden`: Non-admin user attempting to access import endpoint
- `500 Internal Server Error`: Unexpected server errors during processing
