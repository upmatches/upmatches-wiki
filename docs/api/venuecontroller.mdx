# Venue Controller

The `VenueController` class is a REST controller that exposes endpoints for managing venues in the UpMatches application. It provides functionality for listing venues with pagination and importing venues via CSV file upload. The controller is secured with role-based access control for administrative operations.

## Endpoints

### List Venues

Retrieves a paginated list of venues sorted by name.

**HTTP Method:** `GET`  
**Endpoint:** `/api/v1/venues`  
**Authentication:** None required

#### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | Integer | `0` | Page number (zero-indexed) |
| `size` | Integer | `20` | Number of items per page |

#### Response

Returns a paginated response containing venue data.

**Status Code:** `200 OK`

**Response Body:**
```json
{
  "success": true,
  "message": "Venues retrieved successfully.",
  "data": {
    "content": [
      {
        "id": "string",
        "name": "string",
        // ... other venue fields
      }
    ],
    "page": 0,
    "size": 20,
    "totalElements": 100,
    "totalPages": 5
  },
  "path": "/api/v1/venues"
}
```

### Import Venues

Uploads a CSV file to import venues into the system.

**HTTP Method:** `POST`  
**Endpoint:** `/api/v1/venues/imports`  
**Authentication:** Required (ADMIN role only)  
**Content-Type:** `multipart/form-data`

#### Request Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `file` | MultipartFile | Yes | CSV file containing venue data |

#### Response

Returns the result of the import operation.

**Status Code:** `201 Created`

**Response Body:**
```json
{
  "success": true,
  "message": "Venues imported successfully.",
  "data": {
    "importedCount": 50,
    "failedCount": 2,
    "errors": [
      {
        "row": 5,
        "message": "Invalid venue name"
      }
    ]
  },
  "path": "/api/v1/venues/imports"
}
```

## Error Handling

The controller uses standard HTTP status codes for error responses:

| Status Code | Description |
|-------------|-------------|
| `400 Bad Request` | Invalid pagination parameters or file format |
| `401 Unauthorized` | Missing or invalid authentication |
| `403 Forbidden` | User does not have ADMIN role |
| `500 Internal Server Error` | Unexpected server error |

## Security

- The `createVenueImport` endpoint is protected with `@PreAuthorize("hasRole('ADMIN')")` annotation, restricting access to users with the ADMIN role.
- The `listVenues` endpoint is publicly accessible.

## Dependencies

The controller depends on two service interfaces:

- `IListVenuesService` - Handles venue listing with pagination
- `IImportVenuesService` - Handles venue import from CSV files

## Validation

Pagination parameters are validated using `ValidationHelper.validatePaginationParameters()` before processing the request. This ensures that page and size values are within acceptable ranges.
