## Purpose

The `VenueController` class is a Spring Boot REST controller responsible for handling HTTP requests related to venue operations. It provides endpoints for listing venues and importing venue data. The controller leverages services to perform these operations and ensures that the requests are properly validated and authorized.

## Public Methods

### listVenues

Handles GET requests to retrieve a paginated list of venues.

| Parameter | Type                | Description                                     |
|-----------|---------------------|-------------------------------------------------|
| page      | Integer (optional)  | The page number to retrieve (default is 0).     |
| size      | Integer (optional)  | The number of venues per page (default is 20).  |
| request   | HttpServletRequest  | The HTTP request object.                        |

**Returns:** `ResponseEntity<ApiResponse<PagedResponse<VenueResponse>>>`  
A response entity containing a paginated response of venues and a success message.

### createVenueImport

Handles POST requests to import venue data from a file. This operation is restricted to users with the 'ADMIN' role.

| Parameter | Type               | Description                                      |
|-----------|--------------------|--------------------------------------------------|
| file      | MultipartFile      | The file containing venue data to be imported.   |
| request   | HttpServletRequest | The HTTP request object.                         |

**Returns:** `ResponseEntity<ApiResponse<VenueImportResponse>>`  
A response entity containing the result of the import operation and a success message.
