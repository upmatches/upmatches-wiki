# VenueController

The `VenueController` class is a REST controller that handles venue-related HTTP requests. It provides endpoints for listing venues with pagination and importing venue data via file upload. The controller is part of the UpMatches application's venue management feature and is secured with role-based access control for administrative operations.

## Endpoints

### List Venues

Retrieves a paginated list of venues sorted by name.

**HTTP Method:** `GET`  
**Path:** `/api/v1/venues`

#### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | Integer | `0` | Page number (zero-based) |
| `size` | Integer | `20` | Number of items per page |

#### Response

Returns a paginated response containing venue data.

**Status Code:** `200 OK`

**Response Body:**
```json
{
  "data": {
    "content": [
      {
        "id": "string",
        "name": "string",
        "address": "string",
        "city": "string",
        "state": "string",
        "zipCode": "string",
        "phone": "string",
        "website": "string",
        "latitude": 0.0,
        "longitude": 0.0
      }
    ],
    "page": 0,
    "size": 20,
    "totalElements": 100,
    "totalPages": 5
  },
  "message": "Venues retrieved successfully.",
  "path": "/api/v1/venues",
  "timestamp": "2024-01-01T00:00:00Z"
}
```

### Import Venues

Imports venue data from an uploaded file. This endpoint requires ADMIN role.

**HTTP Method:** `POST`  
**Path:** `/api/v1/venues/imports`  
**Content-Type:** `multipart/form-data`

#### Request Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `file` | MultipartFile | Yes | The file containing venue data to import |

#### Response

Returns the import operation result.

**Status Code:** `201 Created`

**Response Body:**
```json
{
  "data": {
    "importedCount": 50,
    "failedCount": 2,
    "errors": [
      {
        "row": 15,
        "message": "Invalid venue name format"
      }
    ]
  },
  "message": "Venues imported successfully.",
  "path": "/api/v1/venues/imports",
  "timestamp": "2024-01-01T00:00:00Z"
}
```

## Security

- The `listVenues` endpoint is publicly accessible (no authentication required).
- The `createVenueImport` endpoint requires the user to have the `ADMIN` role.

## Dependencies

The controller depends on two service interfaces:

| Service Interface | Description |
|-------------------|-------------|
| `IListVenuesService` | Handles the business logic for retrieving paginated venue data |
| `IImportVenuesService` | Handles the business logic for importing venue data from files |

## Validation

The controller uses `ValidationHelper.validatePaginationParameters()` to ensure that pagination parameters (`page` and `size`) are valid before processing the request. Invalid parameters will result in a validation error response.
