# LeaveGameService

The `LeaveGameService` class is a Spring service component responsible for handling the logic when a user leaves a game. It ensures that only active participants can leave a game, updates the participant's status, and publishes a notification event to inform other players.

## Purpose

This service encapsulates the business logic for a user to exit a game they have previously joined. It performs the following key operations:

1. **Validates the user's active participation** in the specified game.
2. **Updates the participant's status** to indicate they have left.
3. **Persists the change** to the database.
4. **Publishes a notification event** to alert other game participants.

## Public Methods

### `execute(UUID id)`

Processes the leave game request for the currently authenticated user.

| Aspect | Details |
|--------|---------|
| **Annotations** | `@Transactional`, `@Auditable(action = "GAME_LEFT", resourceType = "GAME", resourceIdExpression = "#args[0]")` |
| **Parameters** | `id` (`UUID`) - The unique identifier of the game to leave |
| **Returns** | `void` |
| **Throws** | `ResourceNotFoundException` - If the user is not an active participant of the specified game |

#### Method Flow

1. **Resolve User**: Retrieves the authenticated user's ID via `userResolver.requireUserId()`.
2. **Find Participant**: Queries the repository for an active participant record matching the game ID and user ID.
3. **Validate Participation**: If no active participant record is found, throws a `ResourceNotFoundException` with a descriptive message.
4. **Update Status**: Calls `participant.leave()` to update the participant's status.
5. **Persist**: Saves the updated participant record using `ServiceOperationExecutor.execute()` with `UPDATE` operation status.
6. **Publish Event**: Creates and publishes a `GameNotificationEvent` with type `PLAYER_LEFT`, including the game ID, user ID, and game title (if available).

## Error Handling

| Scenario | Exception | Message |
|----------|-----------|---------|
| User is not an active participant | `ResourceNotFoundException` | `"User '{userId}' is not an active participant of game '{gameId}'."` |

## Usage Example

```java
@Autowired

// User leaves a game
leaveGameService.execute(gameId);
```
