## Purpose

The `LeaveGameService` class is a Spring service responsible for handling the logic when a user decides to leave a game. It ensures that the user is an active participant of the game before allowing them to leave, updates the participant's status, and publishes a notification event to inform other components of the change.

## Public Methods

### `execute`

Executes the process of a user leaving a game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id`      | `UUID` | The unique identifier of the game from which the user wants to leave. |

| Return Type | Description |
|-------------|-------------|
| `void`      | This method does not return any value. It performs the operation of updating the participant's status and publishing an event. |

## Detailed Description

- **Transactional**: The `execute` method is annotated with `@Transactional`, ensuring that the operations within the method are executed within a transaction. This guarantees that either all operations succeed or none are applied, maintaining data consistency.

- **Auditable**: The method is also annotated with `@Auditable`, which logs the action of leaving a game. The `resourceIdExpression` is used to dynamically capture the game ID for auditing purposes.

- **Exception Handling**: If the user is not an active participant in the game, a `ResourceNotFoundException` is thrown, indicating that the user cannot leave a game they are not part of.

- **Event Publishing**: After successfully updating the participant's status, a `GameNotificationEvent` is published to notify other components or services that a player has left the game. This event includes details such as the game ID, user ID, notification type, and game title.

This service is crucial for maintaining the integrity of game participation data and ensuring that all relevant parties are informed of changes in participant status.
