# LeaveGameService

The `LeaveGameService` class is a Spring service responsible for handling the logic when a user leaves a game. It ensures that only active participants can leave a game, updates the participant's status, and publishes a notification event to inform other players.

## Purpose

- **Game Participation Management**: Manages the process of a user leaving a game, including validation of active participation.
- **Audit Logging**: Uses the `@Auditable` annotation to log the action for auditing purposes.
- **Event Publishing**: Publishes a `GameNotificationEvent` to notify other participants that a player has left.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameParticipantRepository` | Repository | Data access for game participant records |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user |
| `ApplicationEventPublisher` | Spring | Publishes application events for notification |

## Constructor

### `LeaveGameService(GameParticipantRepository, IAuthenticatedUserResolver, ApplicationEventPublisher)`

Initializes the service with required dependencies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `participantRepository` | `GameParticipantRepository` | Repository for game participant data |
| `userResolver` | `IAuthenticatedUserResolver` | Resolver for the authenticated user |
| `eventPublisher` | `ApplicationEventPublisher` | Publisher for application events |

## Public Methods

### `execute(UUID id)`

Processes the leave game request for the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to leave |

**Behavior:**
1. Retrieves the authenticated user's ID via `userResolver.requireUserId()`.
2. Looks up the active participant record for the given game and user.
3. Throws `ResourceNotFoundException` if the user is not an active participant.
4. Calls `participant.leave()` to update the participant's status.
5. Saves the updated participant record using `ServiceOperationExecutor`.
6. Publishes a `GameNotificationEvent` with type `PLAYER_LEFT`.

**Throws:**
- `ResourceNotFoundException` if the user is not an active participant of the specified game.

**Transactional:** Yes, the entire operation is wrapped in a database transaction.

**Auditable:** Yes, logs the action as `GAME_LEFT` with the game ID as the resource identifier.

## Example Usage

```java
@Autowired
private LeaveGameService leaveGameService;

public void handleLeaveGameRequest(UUID gameId) {
    leaveGameService.execute(gameId);
}
```

## Error Handling

The service throws a `ResourceNotFoundException` with a descriptive message when the user is not an active participant:

```
User '<userId>' is not an active participant of game '<gameId>'.
```

## Notification Details

When a player successfully leaves a game, a `GameNotificationEvent` is published with:
- **Game ID**: The ID of the game being left
- **User ID**: The ID of the user who left
- **Notification Type**: `PLAYER_LEFT`
- **Game Title**: The name of the game's activity (if available)
