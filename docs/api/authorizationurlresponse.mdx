# AuthorizationUrlResponse

The `AuthorizationUrlResponse` class is a Java record that encapsulates the authorization URL returned by an authentication service. It provides a simple, immutable data structure for transferring the authorization endpoint URL from the server to the client.

## Purpose

This record is used in the authentication flow to communicate the URL that the client should redirect the user to for authorization. It is typically returned by an API endpoint that initiates the OAuth2 or similar authorization process.

## Record Structure

| Field | Type | Description |
|-------|------|-------------|
| `authorizationUrl` | `String` | The full URL to which the user should be redirected for authorization |

## Public Methods

### `of(String authorizationUrl)`

Creates a new `AuthorizationUrlResponse` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorizationUrl` | `String` | The authorization URL to wrap |

**Returns:** `AuthorizationUrlResponse` - A new instance containing the provided URL.

## Usage Example

```java
// Creating an authorization URL response
AuthorizationUrlResponse response = AuthorizationUrlResponse.of("https://auth.example.com/authorize?client_id=123&redirect_uri=/callback");

// Accessing the URL
String url = response.authorizationUrl();
```

## Notes

- This is a Java record, so it automatically provides `equals()`, `hashCode()`, and `toString()` methods.
- The record is immutable once created.
- The static factory method `of()` provides a convenient way to instantiate the record.
