## Overview

The `AuthorizationUrlResponse` class is a simple Java record used to encapsulate an authorization URL. This class is part of the `com.upmatches.app.features.auth.responses` package and provides a static factory method for creating instances of the record.

## Purpose

The primary purpose of the `AuthorizationUrlResponse` class is to store and provide access to an authorization URL. This is typically used in authentication workflows where a client needs to redirect a user to an authorization server.

## Public Methods

The class provides the following public method:

| Method Signature | Description |
|------------------|-------------|
| `public static AuthorizationUrlResponse of(String authorizationUrl)` | A static factory method that creates a new instance of `AuthorizationUrlResponse` with the specified authorization URL. |

### Method Details

#### `of`

- **Parameters:**

  | Name              | Type   | Description                          |
  |-------------------|--------|--------------------------------------|
  | `authorizationUrl`| String | The authorization URL to be encapsulated in the response. |

- **Returns:** `AuthorizationUrlResponse` - A new instance of `AuthorizationUrlResponse` containing the provided authorization URL.

This method is a convenient way to create instances of `AuthorizationUrlResponse` without directly invoking the constructor, adhering to the factory method design pattern.
