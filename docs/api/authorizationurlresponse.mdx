# AuthorizationUrlResponse

The `AuthorizationUrlResponse` class is a Java record that encapsulates the authorization URL returned by an authentication service. It provides a simple, immutable data carrier for the URL that clients should redirect users to for OAuth or similar authorization flows.

## Purpose

This record is used in the authentication module of the UpMatches application to standardize the response format when an authorization URL is generated. It ensures type safety and immutability, making it suitable for use in API responses and service layers.

## Record Structure

The record has a single component:

| Field | Type | Description |
|-------|------|-------------|
| `authorizationUrl` | `String` | The full authorization URL to which the user should be redirected |

## Public Methods

### `of(String authorizationUrl)`

A static factory method that creates a new `AuthorizationUrlResponse` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorizationUrl` | `String` | The authorization URL to wrap in the response |

**Returns:** `AuthorizationUrlResponse` — a new instance containing the provided URL

**Example usage:**

```java
AuthorizationUrlResponse response = AuthorizationUrlResponse.of("https://auth.example.com/authorize?client_id=123");
String url = response.authorizationUrl(); // "https://auth.example.com/authorize?client_id=123"
```

## Inherited Methods

As a Java record, `AuthorizationUrlResponse` automatically provides:

- `authorizationUrl()` — accessor method for the record component
- `equals(Object o)` — value-based equality comparison
- `hashCode()` — hash code based on the component value
- `toString()` — string representation of the record

## Usage Notes

- This record is immutable; once created, the authorization URL cannot be changed.
- The static factory method `of()` provides a convenient way to create instances without using the `new` keyword.
- The record is ideal for use in REST API responses where the authorization URL needs to be serialized to JSON.
