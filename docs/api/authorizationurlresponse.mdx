# AuthorizationUrlResponse

The `AuthorizationUrlResponse` class is a Java record that encapsulates the authorization URL returned by an authentication service. It provides a simple, immutable data carrier for the URL string that clients can use to redirect users for OAuth or similar authorization flows.

## Purpose

This record is used in the authentication module of the UpMatches application to standardize the response format when an authorization URL is generated. It ensures type safety and immutability, making it easy to pass the URL between different layers of the application.

## Record Definition

```java
public record AuthorizationUrlResponse(String authorizationUrl)
```

The record has a single component:
- `authorizationUrl` (String): The full URL to which the user should be redirected for authorization.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `of(String authorizationUrl)` | `AuthorizationUrlResponse` | Static factory method to create a new instance of the record. |

### Method Details

#### `of(String authorizationUrl)`

Creates a new `AuthorizationUrlResponse` instance with the provided authorization URL.

**Parameters:**
- `authorizationUrl` (String): The authorization URL to wrap.

**Returns:**
- `AuthorizationUrlResponse`: A new record instance containing the provided URL.

**Example Usage:**

```java
AuthorizationUrlResponse response = AuthorizationUrlResponse.of("https://auth.example.com/authorize?client_id=123");
String url = response.authorizationUrl(); // "https://auth.example.com/authorize?client_id=123"
```

## Notes

- Since this is a Java record, it automatically provides:
  - A canonical constructor
  - `equals()`, `hashCode()`, and `toString()` methods
  - An accessor method `authorizationUrl()` (without the `get` prefix)
- The record is immutable, making it thread-safe and suitable for use in concurrent environments.
- The static factory method `of()` follows a common Java pattern for creating instances, providing a clean API.
