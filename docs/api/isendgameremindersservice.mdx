# ISendGameRemindersService

The `ISendGameRemindersService` is a **sealed interface** that defines the contract for sending game reminder notifications. It is part of the notification feature in the `com.upmatches.app` application and is designed to be implemented exclusively by the `SendGameRemindersService` class.

## Purpose

This interface provides a single method for executing the sending of game reminders based on a specified notification type and a time window (minimum and maximum hours ahead of the game). The sealed nature of the interface ensures controlled inheritance, allowing only the permitted implementation (`SendGameRemindersService`) to fulfill this contract.

## Method Summary

| Method | Description |
|--------|-------------|
| `execute` | Sends game reminder notifications for a given type within a specified time range. |

## Method Details

### `execute`

```java
int execute(NotificationType type, long minHoursAhead, long maxHoursAhead)
```

Sends game reminder notifications based on the provided parameters.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification to send (e.g., push, email, SMS). This is an enum defined in `com.upmatches.app.features.notification.enums`. |
| `minHoursAhead` | `long` | The minimum number of hours ahead of the game time to send reminders. |
| `maxHoursAhead` | `long` | The maximum number of hours ahead of the game time to send reminders. |

**Returns:**

| Type | Description |
|------|-------------|
| `int` | The number of reminders successfully sent. |

**Exceptions:**

This method does not declare any checked exceptions. However, implementations may throw runtime exceptions for issues such as invalid parameters or service failures.

## Usage Example

```java
// Assuming you have an instance of ISendGameRemindersService
ISendGameRemindersService reminderService = new SendGameRemindersService();

// Send push notifications for games happening between 2 and 24 hours from now
int sentCount = reminderService.execute(NotificationType.PUSH, 2, 24);
System.out.println("Sent " + sentCount + " reminders.");
```

## Implementation Notes

- The interface is **sealed**, meaning only the `SendGameRemindersService` class is permitted to implement it.
- The `NotificationType` enum should be consulted for available notification types.
- The `minHoursAhead` and `maxHoursAhead` parameters define a range; reminders are sent for games whose start time falls within this window.

## Related Components

- `SendGameRemindersService` - The sole implementation of this interface.
- `NotificationType` - Enum defining the types of notifications that can be sent.
