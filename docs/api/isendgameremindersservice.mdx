# ISendGameRemindersService Interface

## Purpose

The `ISendGameRemindersService` interface defines a contract for sending game reminder notifications to users. It is a sealed interface, meaning only the `SendGameRemindersService` class is permitted to implement it. This design ensures controlled extension and enforces a single implementation path for game reminder notification logic.

The interface provides a single method to execute the sending of reminders based on a specified notification type and a time window defined by minimum and maximum hours ahead of the game event.

## Interface Definition

```java
package com.upmatches.app.features.notification.services;

import com.upmatches.app.features.notification.enums.NotificationType;

public sealed interface ISendGameRemindersService permits SendGameRemindersService {

    int execute(NotificationType type, long minHoursAhead, long maxHoursAhead);

}
```

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(NotificationType type, long minHoursAhead, long maxHoursAhead)` | `int` | Executes the sending of game reminders for the specified notification type within the given time window. Returns the number of reminders sent. |

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification to send (e.g., push notification, email, SMS). |
| `minHoursAhead` | `long` | The minimum number of hours ahead of the game event to send reminders. |
| `maxHoursAhead` | `long` | The maximum number of hours ahead of the game event to send reminders. |

## Return Value

- **Type:** `int`
- **Description:** The number of game reminders successfully sent.

## Usage Example

```java
// Assuming implementation is injected via dependency injection
ISendGameRemindersService reminderService = new SendGameRemindersService();

// Send push notifications for games happening between 24 and 48 hours from now
int remindersSent = reminderService.execute(NotificationType.PUSH, 24, 48);
System.out.println("Sent " + remindersSent + " game reminders.");
```

## Implementation Notes

- This interface is **sealed**, allowing only `SendGameRemindersService` to implement it.
- The `execute` method is the sole contract method, simplifying the interface to a single responsibility.
- The `NotificationType` enum should be imported from `com.upmatches.app.features.notification.enums.NotificationType`.
- The time window (`minHoursAhead` to `maxHoursAhead`) allows filtering games that are within a specific timeframe for reminder delivery.
