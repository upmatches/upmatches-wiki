# CreateGameService

## Purpose

The `CreateGameService` class is a Spring service responsible for handling the creation of new games within the application. It orchestrates the entire game creation workflow, including:

- Authenticating the user and verifying their identity
- Validating user eligibility (onboarding status, Singpass authentication)
- Resolving associated entities (activity, venue, skill levels)
- Checking for overlapping game schedules
- Creating the game entity with appropriate pricing and configuration
- Optionally adding the organizer as a participant
- Generating a share link for the newly created game
- Returning a comprehensive game response

This service implements the `ICreateGameService` interface and is annotated with `@Service` and `@Transactional` to ensure database consistency.

## Public Methods

### `execute`

```java
@Transactional
@Auditable(action = "GAME_CREATED", resourceType = "GAME", resourceIdExpression = "#result?.id")
public GameResponse execute(CreateGameRequest request)
```

Creates a new game based on the provided request. This method performs all necessary validations, entity lookups, and persistence operations.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateGameRequest` | The request object containing all game creation details |

**Returns:**

| Return Type | Description |
|-------------|-------------|
| `GameResponse` | A response object containing the created game details, participant count, share link, and viewer-specific information |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `SingpassRequiredException` | When the user has not completed Singpass authentication |
| `OnboardingRequiredException` | When the user has not completed their profile onboarding |
| `OverlappingGameException` | When the user already participates in another game that overlaps with the requested time slot |
| `ResourceNotFoundException` | When any referenced entity (activity, venue, skill level) is not found |

**Behavior:**

1. Resolves the authenticated user's ID
2. Looks up the activity, venue, and skill level entities
3. Validates the user's ability to create games (Singpass, onboarding)
4. Checks for overlapping games if the user wants to join as organizer
5. Creates the pricing configuration (custom or flat rate)
6. Builds and persists the `Game` entity
7. Optionally creates a `GameParticipant` record for the organizer
8. Generates a share link for the game
9. Returns a `GameResponse` with all relevant data
