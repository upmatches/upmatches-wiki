## Purpose

The `CreateGameService` class is a service component in a Java application that handles the creation of game entities. It is responsible for validating user permissions, checking for overlapping games, and saving new game instances to the repository. Additionally, it manages the creation of share links for the newly created games.

## Public Methods

### `execute`

Executes the process of creating a game based on the provided request. This method is transactional and auditable, ensuring that the creation process is logged and can be rolled back if necessary.

| Parameter | Type                      | Description                                      |
|-----------|---------------------------|--------------------------------------------------|
| request   | `CreateGameRequest`       | The request object containing game details.      |

| Return Type    | Description                                      |
|----------------|--------------------------------------------------|
| `GameResponse` | The response object containing the game details. |

## Method Details

- **`execute(CreateGameRequest request)`**: This method performs several key operations:
  - Retrieves the user ID of the organizer and checks if they are authorized to create a game.
  - Validates that the user has completed onboarding and is authenticated via Singpass.
  - Checks for overlapping games if the user intends to join as an organizer.
  - Constructs a `Game` object with the provided details and saves it to the repository.
  - Creates a share link for the game and returns a `GameResponse` object containing the game details and participant count.

## Exceptions

- **`SingpassRequiredException`**: Thrown if the user is not authenticated via Singpass.
- **`OnboardingRequiredException`**: Thrown if the user has not completed onboarding.
- **`OverlappingGameException`**: Thrown if the user is already participating in an overlapping game.
- **`ResourceNotFoundException`**: Thrown if a resource required for game creation is not found.
