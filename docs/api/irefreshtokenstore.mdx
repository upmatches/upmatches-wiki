# IRefreshTokenStore Interface

The `IRefreshTokenStore` interface defines the contract for managing refresh tokens in the authentication system. It provides methods for storing, validating, rotating, and revoking refresh tokens associated with user accounts.

This interface is a **sealed interface**, meaning it can only be implemented by the `RefreshTokenStore` class. This design ensures that all refresh token operations follow a consistent implementation pattern and prevents unauthorized implementations.

## Interface Definition

```java
public sealed interface IRefreshTokenStore permits RefreshTokenStore {
    // Methods defined below
}
```

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `store` | Stores a new refresh token for a specific user | `UUID userId` - The unique identifier of the user<br/>`String refreshToken` - The refresh token to store | `void` |
| `validateAndRotate` | Validates an existing refresh token and generates a new one (rotation) | `String refreshToken` - The refresh token to validate and rotate | `ValidationResult` - Contains the validation status and new token if valid |
| `revokeAllForUser` | Revokes all refresh tokens associated with a specific user | `UUID userId` - The unique identifier of the user whose tokens should be revoked | `void` |

## Method Details

### `store(UUID userId, String refreshToken)`

Stores a refresh token in the system, associating it with the specified user. This method is typically called after successful authentication to persist the refresh token for future use.

**Parameters:**
- `userId` - The UUID of the user who owns the refresh token
- `refreshToken` - The refresh token string to store

**Returns:** Nothing

### `validateAndRotate(String refreshToken)`

Validates the provided refresh token and, if valid, rotates it by generating a new token. Token rotation is a security best practice that invalidates the old token and issues a new one, reducing the risk of token theft.

**Parameters:**
- `refreshToken` - The refresh token string to validate

**Returns:** `ValidationResult` - An object containing:
- Whether the token is valid
- A new refresh token if validation succeeded
- Any error information if validation failed

### `revokeAllForUser(UUID userId)`

Revokes all active refresh tokens for the specified user. This method is typically called when:
- A user changes their password
- A user logs out from all devices
- An administrator invalidates a user's sessions
- Suspicious activity is detected on the account

**Parameters:**
- `userId` - The UUID of the user whose tokens should be revoked

**Returns:** Nothing

## Usage Example

```java
// Store a refresh token
refreshTokenStore.store(userId, "eyJhbGciOiJIUzI1NiIs...");

// Validate and rotate a refresh token
ValidationResult result = refreshTokenStore.validateAndRotate("eyJhbGciOiJIUzI1NiIs...");
if (result.isValid()) {
    String newToken = result.getNewToken();
    // Use the new token
}

// Revoke all tokens for a user
refreshTokenStore.revokeAllForUser(userId);
```

## Related Types

- `RefreshTokenStore` - The only permitted implementation of this interface
- `ValidationResult` - The result type returned by the `validateAndRotate` method
- `UUID` - Used to uniquely identify users in the system
