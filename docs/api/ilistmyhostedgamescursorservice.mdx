# IListMyHostedGamesCursorService Interface

The `IListMyHostedGamesCursorService` interface defines the contract for retrieving a cursor-paginated list of games hosted by the current user. It is a **sealed interface**, meaning only the permitted implementation (`ListMyHostedGamesCursorService`) can implement it. This design enforces a single, well-defined implementation and prevents unauthorized extensions.

## Purpose

This interface is part of the game management feature in the application. It provides a standardized way to fetch a user's hosted games using cursor-based pagination, which is more efficient and reliable for large datasets compared to offset-based pagination. The cursor represents a pointer to a specific item in the result set, allowing the client to request the next page of results.

| Method | Description |

## Method Details

### `execute`

```java
CursorPagedResponse<GameResponse> execute(String cursor, int size)
```

Retrieves a paginated list of games hosted by the current user, using cursor-based pagination.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The cursor indicating the starting point for the next page of results. Pass `null` or an empty string to retrieve the first page. |
| `size` | `int` | The maximum number of items to return in the response. Must be a positive integer. |

**Returns:**

| Return Type | Description |
|-------------|-------------|
| `CursorPagedResponse<GameResponse>` | A response object containing the requested page of games, along with pagination metadata (e.g., next cursor, total count). |

**Example Usage:**

```java
// Get the first page of 10 hosted games
CursorPagedResponse<GameResponse> firstPage = service.execute(null, 10);

// Get the next page using the cursor from the previous response
CursorPagedResponse<GameResponse> nextPage = service.execute(firstPage.getNextCursor(), 10);
```

## Related Types

- **`CursorPagedResponse<GameResponse>`**: The generic response wrapper that contains the paginated results and metadata.
- **`GameResponse`**: The data transfer object representing a single game in the response.
- **`ListMyHostedGamesCursorService`**: The sole permitted implementation of this interface.
