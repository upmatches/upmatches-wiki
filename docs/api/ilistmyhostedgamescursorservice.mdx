# IListMyHostedGamesCursorService

The `IListMyHostedGamesCursorService` is a **sealed interface** that defines the contract for retrieving a cursor-paginated list of games hosted by the current user. It is part of the game features package and works with cursor-based pagination to efficiently fetch large result sets.

This interface is sealed to permit only the `ListMyHostedGamesCursorService` implementation, ensuring controlled extension and a clear single point of implementation.

## Interface Definition

```java
public sealed interface IListMyHostedGamesCursorService 
    permits ListMyHostedGamesCursorService
```

## Methods

### `execute`

Retrieves a cursor-paginated list of games hosted by the current user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The cursor string indicating the starting point for pagination. Pass `null` or empty string to retrieve the first page. |
| `size` | `int` | The maximum number of items to return in the response. Must be a positive integer. |

| Returns | Description |
|---------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing a list of `GameResponse` objects, along with cursor information for subsequent requests. |

## Usage Example

```java
// Inject the service
private final IListMyHostedGamesCursorService listMyHostedGamesService;

// Retrieve the first page of hosted games
CursorPagedResponse<GameResponse> firstPage = listMyHostedGamesService.execute(null, 20);

// Use the cursor from the response to get the next page
String nextCursor = firstPage.getNextCursor();
if (nextCursor != null) {
    CursorPagedResponse<GameResponse> nextPage = listMyHostedGamesService.execute(nextCursor, 20);
}
```

## Related Types

- `CursorPagedResponse<GameResponse>` - The response wrapper containing paginated results and cursor metadata.
- `GameResponse` - The data transfer object representing a game.
- `ListMyHostedGamesCursorService` - The sole permitted implementation of this interface.
