## Purpose

The `IListMyHostedGamesCursorService` interface is part of the `com.upmatches.app.features.game.services` package. It defines a contract for services that provide paginated access to a list of games hosted by a user. This interface is designed to be implemented by classes that need to fetch game data in a cursor-based pagination format, which is useful for efficiently handling large datasets.

## Public Methods

The interface declares the following public method:

| Method Signature | Description |
|------------------|-------------|
| `CursorPagedResponse<GameResponse> execute(String cursor, int size)` | Fetches a paginated list of games hosted by the user. |

### Method Details

#### `execute`

- **Description**: This method retrieves a paginated list of games hosted by the user, starting from a specified cursor position and limited to a specified number of entries.
- **Parameters**:
  | Name   | Type   | Description |
  |--------|--------|-------------|
  | `cursor` | `String` | The cursor indicating the starting point for pagination. |
  | `size`   | `int`    | The number of game entries to retrieve. |
- **Returns**: 
  - **Type**: `CursorPagedResponse<GameResponse>`
  - **Description**: A response object containing the paginated list of `GameResponse` objects and pagination metadata.
