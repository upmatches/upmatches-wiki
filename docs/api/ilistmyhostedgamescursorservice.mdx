# IListMyHostedGamesCursorService

The `IListMyHostedGamesCursorService` is a **sealed interface** that defines the contract for retrieving a cursor-based, paginated list of games hosted by the currently authenticated user. It serves as the abstraction layer for the `ListMyHostedGamesCursorService` implementation.

## Purpose

This interface is part of the game management feature within the application. It provides a standardized way to fetch a user's hosted games using cursor-based pagination, which is more efficient and reliable than traditional offset-based pagination for large, frequently updated datasets.

## Sealed Interface

The interface is declared as `sealed`, meaning only the explicitly permitted class (`ListMyHostedGamesCursorService`) can implement it. This design enforces a single, controlled implementation and prevents unauthorized extensions.

## Method Summary

| Method | Description |
|--------|-------------|
| `execute(String cursor, int size)` | Retrieves a paginated list of games hosted by the current user, starting from the specified cursor position. |

## Method Details

### `execute`

```java
CursorPagedResponse<GameResponse> execute(String cursor, int size)
```

Executes the query to fetch a cursor-based paginated list of the current user's hosted games.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The cursor indicating the starting point for the page. Pass `null` or empty string to retrieve the first page. |
| `size` | `int` | The maximum number of items to return in the response. Must be a positive integer. |

**Returns:**

| Type | Description |
|------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing a list of `GameResponse` objects and a cursor for the next page (if available). |

**Usage Example:**

```java
// Get the first page of hosted games (10 items)
CursorPagedResponse<GameResponse> firstPage = service.execute(null, 10);

// Get the next page using the cursor from the previous response
CursorPagedResponse<GameResponse> nextPage = service.execute(firstPage.getNextCursor(), 10);
```

## Related Types

- **`CursorPagedResponse<T>`**: A generic wrapper that contains the list of items and the cursor for the next page.
- **`GameResponse`**: The data transfer object representing a game's details.
- **`ListMyHostedGamesCursorService`**: The sole permitted implementation of this interface.
