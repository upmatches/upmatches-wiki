# LogAspect

The `LogAspect` class is a Spring AOP (Aspect-Oriented Programming) aspect that provides centralized logging, metrics collection, and request tracing for service and controller methods in the application. It automatically intercepts method executions, logs their performance, records metrics to Micrometer, and manages MDC (Mapped Diagnostic Context) for request tracing.

## Purpose

- **Automatic Logging**: Logs method execution time and status (success/failure) for all public methods in service and controller packages.
- **Performance Monitoring**: Tracks slow method executions and logs warnings when methods exceed configurable thresholds.
- **Metrics Collection**: Records execution times and success/failure rates to Micrometer for monitoring and alerting.
- **Request Tracing**: Generates and manages unique request IDs in MDC for distributed tracing across HTTP requests.
- **Error Handling**: Wraps checked exceptions in `MethodExecutionException` while allowing runtime exceptions and errors to propagate naturally.

## Configuration

The aspect is enabled by default but can be disabled via configuration:

```yaml
app:
  logging:
    aspect:
      enabled: true  # Set to false to disable the aspect
```

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `logExecution(ProceedingJoinPoint)` | `Object` | Main advice method that intercepts service and controller method executions |

### logExecution

Intercepts method executions and provides:
- Request ID generation and MDC management
- HTTP context extraction (method, endpoint)
- Execution time measurement
- Success/failure logging with configurable thresholds
- Micrometer metrics recording
- Exception handling and wrapping

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `joinPoint` | `ProceedingJoinPoint` | The join point representing the intercepted method execution |

**Returns:**
- The result of the intercepted method execution

**Throws:**
- `Throwable` - Propagates errors and runtime exceptions; wraps checked exceptions in `MethodExecutionException`

## Internal Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `initRequestId()` | `String` | Generates an 8-character uppercase request ID from a UUID |
| `currentHttpRequest()` | `HttpServletRequest` or `null` | Retrieves the current HTTP request from request context |
| `resolveComponent(ProceedingJoinPoint)` | `String` | Determines if the intercepted method belongs to a controller or service component |
| `recordMetrics(String, Long, boolean)` | `void` | Records execution metrics to Micrometer with component and status tags |
| `logSuccess(String, Long)` | `void` | Logs successful execution with info or warning level based on threshold |
| `logFailure(String, Long, Throwable)` | `void` | Logs failed execution with error details |

## MDC Context Management

The aspect manages the following MDC keys:

| MDC Key | Description | Set When |
|---------|-------------|----------|
| `requestId` | Unique request identifier | First intercepted method in request chain |
| `method` | Short method signature | Every intercepted method |
| `httpMethod` | HTTP method (GET, POST, etc.) | When HTTP context is available |
| `endpoint` | Request URI path | When HTTP context is available |

## Metrics

The aspect records Micrometer timer metrics with the following tags:

| Tag | Values | Description |
|-----|--------|-------------|
| `component` | `controller`, `service` | Type of component being executed |
| `status` | `success`, `failure` | Execution outcome |

## Logging Behavior

- **Success (fast)**: Logged at INFO level with method name and duration
- **Success (slow)**: Logged at WARN level when duration exceeds `slowExecutionThresholdMs`
- **Failure**: Logged at ERROR level with method name, duration, exception type, and message

## Dependencies

- Spring AOP (`@Aspect`, `@Pointcut`, `@Around`)
- Micrometer (`MeterRegistry`)
- SLF4J (`Logger`, `MDC`)
- Jakarta Servlet API (`HttpServletRequest`)
- Spring Web (`RequestContextHolder`)

## Usage Example

```java
@RestController
public class UserController {
    
    @GetMapping("/users/{id}")
    public User getUser(@PathVariable Long id) {
        // This method will be automatically logged and monitored
        return userService.findById(id);
    }
}
```

The aspect will automatically:
1. Generate a request ID and add it to MDC
2. Log the HTTP method and endpoint
3. Measure execution time
4. Log success/failure with duration
5. Record metrics to Micrometer
6. Clean up MDC context after execution
