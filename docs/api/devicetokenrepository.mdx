import com.upmatches.app.features.notification.entities.DeviceToken;
import org.springframework.data.jpa.repository.JpaRepository;

## Overview

The `DeviceTokenRepository` interface is a part of the notification feature in the application. It extends the `JpaRepository` interface provided by Spring Data JPA, which offers CRUD operations and additional query methods for the `DeviceToken` entity. This repository is responsible for managing device tokens associated with users, which are crucial for sending notifications to specific devices.

## Public Methods

The following table documents the public methods available in the `DeviceTokenRepository` interface:

| Method Signature | Description |
|------------------|-------------|
| `List<DeviceToken> findByUserId(UUID userId)` | Retrieves a list of `DeviceToken` objects associated with a specific user identified by `userId`. |
| `Optional<DeviceToken> findByUserIdAndDeviceToken(UUID userId, String deviceToken)` | Finds a specific `DeviceToken` for a user based on the `userId` and `deviceToken`. Returns an `Optional` containing the `DeviceToken` if found. |
| `void deleteByUserIdAndDeviceToken(UUID userId, String deviceToken)` | Deletes a `DeviceToken` associated with a specific `userId` and `deviceToken`. |
| `void deleteByDeviceToken(String deviceToken)` | Deletes a `DeviceToken` based solely on the `deviceToken`. |

## Parameters and Return Types

The following table provides details on the parameters and return types for each method:

| Method | Parameters | Return Type |
|--------|------------|-------------|
| `findByUserId` | `UUID userId` | `List<DeviceToken>` |
| `findByUserIdAndDeviceToken` | `UUID userId`, `String deviceToken` | `Optional<DeviceToken>` |
| `deleteByUserIdAndDeviceToken` | `UUID userId`, `String deviceToken` | `void` |
| `deleteByDeviceToken` | `String deviceToken` | `void` |

This documentation provides a concise overview of the `DeviceTokenRepository` interface, detailing its purpose and the methods available for managing device tokens within the application.
