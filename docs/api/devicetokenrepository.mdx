# DeviceTokenRepository

The `DeviceTokenRepository` interface provides data access operations for managing device tokens associated with user accounts in the notification system. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD operations while defining custom query methods for token management.

## Purpose

This repository handles the persistence layer for `DeviceToken` entities, enabling:
- Retrieval of all device tokens for a specific user
- Lookup of specific token-user combinations
- Removal of individual tokens or user-specific token associations

## Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `findByUserId` | `UUID userId` | `List<DeviceToken>` | Retrieves all device tokens registered for a given user |
| `findByUserIdAndDeviceToken` | `UUID userId`, `String deviceToken` | `Optional<DeviceToken>` | Finds a specific device token associated with a user, returning empty if not found |
| `deleteByUserIdAndDeviceToken` | `UUID userId`, `String deviceToken` | `void` | Removes a specific device token for a given user |
| `deleteByDeviceToken` | `String deviceToken` | `void` | Deletes a device token regardless of which user it belongs to |

## Usage Example

```java
@Service
public class NotificationService {
    private final DeviceTokenRepository deviceTokenRepository;
    
    public NotificationService(DeviceTokenRepository deviceTokenRepository) {
        this.deviceTokenRepository = deviceTokenRepository;
    }
    
    public List<DeviceToken> getUserTokens(UUID userId) {
        return deviceTokenRepository.findByUserId(userId);
    }
    
    public void removeToken(UUID userId, String token) {
        deviceTokenRepository.deleteByUserIdAndDeviceToken(userId, token);
    }
}
```

## Notes

- The repository uses `UUID` as the primary key type for `DeviceToken` entities
- All custom query methods are automatically implemented by Spring Data JPA based on method naming conventions
- The `deleteByDeviceToken` method is useful for cleaning up tokens when a device is unregistered or a token becomes invalid
