# DeviceTokenRepository

The `DeviceTokenRepository` interface provides data access methods for managing device tokens associated with user accounts. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD operations and defines custom query methods for token management.

## Purpose

This repository handles the persistence and retrieval of device tokens used for push notifications. It enables:
- Looking up all tokens for a specific user
- Finding a specific token for a user
- Removing tokens when users log out or devices are unregistered

## Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `findByUserId` | `UUID userId` | `List<DeviceToken>` | Retrieves all device tokens registered for a given user |
| `findByUserIdAndDeviceToken` | `UUID userId`, `String deviceToken` | `Optional<DeviceToken>` | Finds a specific device token for a user, returning empty if not found |
| `deleteByUserIdAndDeviceToken` | `UUID userId`, `String deviceToken` | `void` | Removes a specific device token for a user |
| `deleteByDeviceToken` | `String deviceToken` | `void` | Removes a device token regardless of which user it belongs to |

## Usage Example

```java
@Service
public class DeviceTokenService {
    private final DeviceTokenRepository repository;
    
    public DeviceTokenService(DeviceTokenRepository repository) {
        this.repository = repository;
    }
    
    public List<DeviceToken> getUserTokens(UUID userId) {
        return repository.findByUserId(userId);
    }
    
    public void removeToken(UUID userId, String token) {
        repository.deleteByUserIdAndDeviceToken(userId, token);
    }
}
```

## Notes

- The repository uses `UUID` as the primary key type for device token entities
- All custom query methods are automatically implemented by Spring Data JPA based on method naming conventions
- The `deleteByDeviceToken` method is useful for cleaning up tokens when devices are factory reset or tokens expire
