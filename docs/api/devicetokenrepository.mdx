import com.upmatches.app.features.notification.entities.DeviceToken;
import org.springframework.data.jpa.repository.JpaRepository;

## Purpose

The `DeviceTokenRepository` interface is a part of the notification feature in the application. It extends the `JpaRepository` interface, providing CRUD operations for `DeviceToken` entities. This repository is responsible for managing device tokens associated with users, which are crucial for sending notifications to specific devices.

## Public Methods

The following table documents the public methods available in the `DeviceTokenRepository` interface:

| Method Signature | Description | Parameters | Return Type |
| ---------------- | ----------- | ---------- | ----------- |
| `List<DeviceToken> findByUserId(UUID userId)` | Retrieves a list of device tokens associated with a specific user. | `userId` (UUID): The unique identifier of the user. | `List<DeviceToken>` |
| `Optional<DeviceToken> findByUserIdAndDeviceToken(UUID userId, String deviceToken)` | Finds a specific device token for a user. | `userId` (UUID): The unique identifier of the user. `deviceToken` (String): The device token string. | `Optional<DeviceToken>` |
| `void deleteByUserIdAndDeviceToken(UUID userId, String deviceToken)` | Deletes a specific device token associated with a user. | `userId` (UUID): The unique identifier of the user. `deviceToken` (String): The device token string. | `void` |
| `void deleteByDeviceToken(String deviceToken)` | Deletes a device token regardless of the user. | `deviceToken` (String): The device token string. | `void` |

This interface leverages Spring Data JPA's capabilities to simplify database interactions for device token management, ensuring efficient and effective notification delivery.
