## Purpose

The `GameParticipantRepository` interface is a part of the `com.upmatches.app.features.game.repositories` package and extends the `JpaRepository` interface provided by Spring Data JPA. It is designed to manage `GameParticipant` entities, which represent participants in a game. This repository provides various methods to perform CRUD operations and custom queries on `GameParticipant` entities, allowing for efficient data retrieval and manipulation based on game and participant criteria.

## Public Methods

The following table documents the public methods available in the `GameParticipantRepository` interface:

| Method Name | Parameters | Return Type | Description |
|-------------|------------|-------------|-------------|
| `countByGameIdAndStatus` | `UUID gameId`, `ParticipantStatus status` | `long` | Counts the number of participants in a specific game with a given status. |
| `countByGameIdsAndStatus` | `Collection<UUID> gameIds`, `ParticipantStatus status` | `List<GameParticipantCount>` | Returns a list of game IDs and their respective participant counts for the specified status. |
| `findByGameIdAndUserIdAndStatus` | `UUID gameId`, `UUID userId`, `ParticipantStatus status` | `Optional<GameParticipant>` | Finds a participant by game ID, user ID, and status. |
| `findByGameIdAndStatus` | `UUID gameId`, `ParticipantStatus status` | `List<GameParticipant>` | Retrieves a list of participants for a specific game and status. |
| `findByGameIdAndStatusOrderByJoinedAtAsc` | `UUID gameId`, `ParticipantStatus status` | `List<GameParticipant>` | Retrieves a list of participants for a specific game and status, ordered by their joining time in ascending order. |
| `findByUserIdAndStatusFetchGame` | `UUID userId`, `ParticipantStatus status` | `List<GameParticipant>` | Finds participants by user ID and status, fetching associated game details where the game is not deleted. |
| `existsByGameIdAndUserIdAndStatus` | `UUID gameId`, `UUID userId`, `ParticipantStatus status` | `boolean` | Checks if a participant exists for a given game ID, user ID, and status. |
| `hasOverlap` | `UUID userId`, `Instant start`, `Instant end` | `boolean` | Determines if there is an overlap of active participant status within scheduled games for a given user and time range. |

## Nested Interface

The `GameParticipantRepository` interface contains a nested interface `GameParticipantCount`:

### GameParticipantCount

This interface is used to project the results of the `countByGameIdsAndStatus` query. It provides the following methods:

| Method Name | Return Type | Description |
|-------------|-------------|-------------|
| `getGameId` | `UUID` | Returns the ID of the game. |
| `getCount` | `Long` | Returns the count of participants for the game. |
