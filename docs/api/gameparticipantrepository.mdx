# GameParticipantRepository

The `GameParticipantRepository` interface provides data access methods for managing game participants in the UpMatches application. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD operations and defines custom query methods for participant-related operations such as counting participants by status, checking for scheduling conflicts, and retrieving participants with associated game data.

## Interface Definition

```java
public interface GameParticipantRepository extends JpaRepository<GameParticipant, UUID>
```

The repository works with `GameParticipant` entities and uses `UUID` as the primary key type.

## Methods

### countByGameIdAndStatus

Counts the number of participants in a specific game with a given status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `long` - The count of participants matching the criteria

### countByGameIdsAndStatus

Counts participants across multiple games by status, grouped by game ID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameIds` | `Collection<UUID>` | A collection of game unique identifiers |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipantCount>` - A list of game ID and count pairs

### findByGameIdAndUserIdAndStatus

Finds a specific participant by game, user, and status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `Optional<GameParticipant>` - The matching participant, if found

### findByGameIdAndStatus

Retrieves all participants for a game with a specific status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants

### findByGameIdAndStatusOrderByJoinedAtAsc

Retrieves participants for a game with a specific status, ordered by join time ascending.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants ordered by join time

### findByUserIdAndStatusFetchGame

Retrieves participants for a user with a specific status, eagerly fetching the associated game data. Only returns participants whose games have not been deleted.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants with game data loaded

### existsByGameIdAndUserIdAndStatus

Checks if a specific participant exists for a game, user, and status combination.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to check |

**Returns:** `boolean` - `true` if the participant exists, `false` otherwise

### hasOverlap

Checks if a user has an active, scheduled game that overlaps with a given time range. This method is useful for preventing scheduling conflicts.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user |
| `start` | `Instant` | The start of the time range to check |
| `end` | `Instant` | The end of the time range to check |

**Returns:** `boolean` - `true` if there is an overlapping game, `false` otherwise

## Inner Interface: GameParticipantCount

A projection interface used by the `countByGameIdsAndStatus` method to return game ID and participant count pairs.

### Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getGameId()` | `UUID` | Returns the game's unique identifier |
| `getCount()` | `Long` | Returns the count of participants |
