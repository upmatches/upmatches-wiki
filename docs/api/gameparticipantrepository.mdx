# GameParticipantRepository

The `GameParticipantRepository` interface provides data access methods for the `GameParticipant` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD operations and defines custom query methods for managing game participants, including counting participants by status, checking for scheduling conflicts, and fetching participants with related game data.

## Interface Definition

```java
public interface GameParticipantRepository extends JpaRepository<GameParticipant, UUID>
```

## Methods

### countByGameIdAndStatus

Counts the number of participants in a specific game with a given status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `long` - The count of participants matching the criteria

### countByGameIdsAndStatus

Counts participants by status for multiple games simultaneously, returning results grouped by game ID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameIds` | `Collection<UUID>` | A collection of game unique identifiers |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipantCount>` - A list of objects containing game ID and participant count

### findByGameIdAndUserIdAndStatus

Finds a specific participant by game, user, and status combination.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `Optional<GameParticipant>` - The matching participant, if found

### findByGameIdAndStatus

Retrieves all participants for a specific game with a given status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants

### findByGameIdAndStatusOrderByJoinedAtAsc

Retrieves participants for a specific game with a given status, ordered by when they joined (ascending).

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants sorted by join time

### findByUserIdAndStatusFetchGame

Finds all participants for a user with a specific status, eagerly fetching the associated game data. Excludes games that have been soft-deleted (`deletedAt IS NULL`).

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants with their game data loaded

### existsByGameIdAndUserIdAndStatus

Checks whether a specific participant exists for a given game, user, and status combination.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to check |

**Returns:** `boolean` - `true` if the participant exists, `false` otherwise

### hasOverlap

Checks if a user has an active participation in a scheduled game that overlaps with a given time range. This method is useful for preventing scheduling conflicts.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user |
| `start` | `Instant` | The start of the time range to check |
| `end` | `Instant` | The end of the time range to check |

**Returns:** `boolean` - `true` if there is an overlapping active participation, `false` otherwise

## Inner Interface: GameParticipantCount

This inner interface defines the projection for the `countByGameIdsAndStatus` query method.

### Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getGameId()` | `UUID` | Returns the game's unique identifier |
| `getCount()` | `Long` | Returns the participant count for the game |
