## Purpose

The `GameParticipantRepository` interface is a part of the `com.upmatches.app.features.game.repositories` package. It extends the `JpaRepository` interface, providing a set of methods to interact with `GameParticipant` entities in the database. This repository is responsible for managing game participants, including counting participants by game and status, finding participants by various criteria, and checking for overlapping game schedules.

## Public Methods

### `countByGameIdAndStatus`

Counts the number of participants for a specific game and status.

| Parameter | Type                      | Description                      |
|-----------|---------------------------|----------------------------------|
| `gameId`  | `UUID`                    | The ID of the game.              |
| `status`  | `ParticipantStatus`       | The status of the participants.  |

| Return Type |
|-------------|
| `long`      |

### `countByGameIdsAndStatus`

Counts the number of participants for multiple games and a specific status.

| Parameter  | Type                      | Description                      |
|------------|---------------------------|----------------------------------|
| `gameIds`  | `Collection<UUID>`        | The IDs of the games.            |
| `status`   | `ParticipantStatus`       | The status of the participants.  |

| Return Type                  |
|------------------------------|
| `List<GameParticipantCount>` |

### `findByGameIdAndUserIdAndStatus`

Finds a participant by game ID, user ID, and status.

| Parameter | Type                      | Description                      |
|-----------|---------------------------|----------------------------------|
| `gameId`  | `UUID`                    | The ID of the game.              |
| `userId`  | `UUID`                    | The ID of the user.              |
| `status`  | `ParticipantStatus`       | The status of the participant.   |

| Return Type                  |
|------------------------------|
| `Optional<GameParticipant>`  |

### `findByGameIdAndStatus`

Finds participants by game ID and status.

| Parameter | Type                      | Description                      |
|-----------|---------------------------|----------------------------------|
| `gameId`  | `UUID`                    | The ID of the game.              |
| `status`  | `ParticipantStatus`       | The status of the participants.  |

| Return Type                  |
|------------------------------|
| `List<GameParticipant>`      |

### `findByGameIdAndStatusOrderByJoinedAtAsc`

Finds participants by game ID and status, ordered by the time they joined.

| Parameter | Type                      | Description                      |
|-----------|---------------------------|----------------------------------|
| `gameId`  | `UUID`                    | The ID of the game.              |
| `status`  | `ParticipantStatus`       | The status of the participants.  |

| Return Type                  |
|------------------------------|
| `List<GameParticipant>`      |

### `findByUserIdAndStatusFetchGame`

Finds participants by user ID and status, fetching associated game details.

| Parameter | Type                      | Description                      |
|-----------|---------------------------|----------------------------------|
| `userId`  | `UUID`                    | The ID of the user.              |
| `status`  | `ParticipantStatus`       | The status of the participants.  |

| Return Type                  |
|------------------------------|
| `List<GameParticipant>`      |

### `existsByGameIdAndUserIdAndStatus`

Checks if a participant exists by game ID, user ID, and status.

| Parameter | Type                      | Description                      |
|-----------|---------------------------|----------------------------------|
| `gameId`  | `UUID`                    | The ID of the game.              |
| `userId`  | `UUID`                    | The ID of the user.              |
| `status`  | `ParticipantStatus`       | The status of the participant.   |

| Return Type |
|-------------|
| `boolean`   |

### `hasOverlap`

Checks if there is an overlap in scheduled games for a user within a specified time range.

| Parameter | Type                      | Description                      |
|-----------|---------------------------|----------------------------------|
| `userId`  | `UUID`                    | The ID of the user.              |
| `start`   | `Instant`                 | The start of the time range.     |
| `end`     | `Instant`                 | The end of the time range.       |

| Return Type |
|-------------|
| `boolean`   |

## Nested Interface: `GameParticipantCount`

The `GameParticipantCount` interface is used to represent the count of participants for a specific game.

### Methods

- `UUID getGameId()`: Returns the ID of the game.
- `Long getCount()`: Returns the count of participants.
