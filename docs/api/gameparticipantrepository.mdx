# GameParticipantRepository

The `GameParticipantRepository` interface provides data access methods for the `GameParticipant` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD operations and defines custom query methods for managing game participant records, including status-based filtering, overlap detection, and aggregated counting.

## Interface Definition

```java
public interface GameParticipantRepository extends JpaRepository<GameParticipant, UUID>
```

The repository works with `GameParticipant` entities keyed by `UUID` primary keys.

## Methods

### countByGameIdAndStatus

Counts participants in a specific game with a given status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `long` - The number of participants matching the criteria.

---

### countByGameIdsAndStatus

Counts participants grouped by game for multiple game IDs with a specific status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameIds` | `Collection<UUID>` | A collection of game unique identifiers |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipantCount>` - A list of objects containing `gameId` and `count` for each game.

---

### findByGameIdAndUserIdAndStatus

Finds a specific participant by game, user, and status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `Optional<GameParticipant>` - The matching participant, if found.

---

### findByGameIdAndStatus

Retrieves all participants for a game with a specific status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants.

---

### findByGameIdAndStatusOrderByJoinedAtAsc

Retrieves participants for a game with a specific status, ordered by join time ascending.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants ordered by `joinedAt` ascending.

---

### findByUserIdAndStatusFetchGame

Finds participants by user ID and status, eagerly fetching the associated game entity. Filters out games where `deletedAt` is not null.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to filter by |

**Returns:** `List<GameParticipant>` - A list of matching participants with their game data loaded.

---

### existsByGameIdAndUserIdAndStatus

Checks if a participant record exists for a specific game, user, and status combination.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |
| `status` | `ParticipantStatus` | The participant status to check |

**Returns:** `boolean` - `true` if a matching record exists, `false` otherwise.

---

### hasOverlap

Checks if a user has an active, scheduled game that overlaps with a given time range. Considers only participants with `ACTIVE` status in games with `SCHEDULED` status that have not been deleted.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user |
| `start` | `Instant` | The start of the time range to check |
| `end` | `Instant` | The end of the time range to check |

**Returns:** `boolean` - `true` if an overlapping game exists, `false` otherwise.

---

## Inner Interface: GameParticipantCount

A projection interface used by the `countByGameIdsAndStatus` method to return aggregated results.

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getGameId()` | `UUID` | The unique identifier of the game |
| `getCount()` | `Long` | The number of participants in the game |
