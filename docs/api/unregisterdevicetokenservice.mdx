# UnregisterDeviceTokenService

## Purpose

The `UnregisterDeviceTokenService` is a Spring service class responsible for removing a device token associated with a specific user. This is typically used when a user logs out, uninstalls the app, or explicitly requests to stop receiving push notifications on a particular device.

The service ensures that only the authenticated user can unregister their own device tokens, providing security and preventing unauthorized token removal.

## Class Details

| Property | Value |
|----------|-------|
| **Package** | `com.upmatches.app.features.notification.services` |
| **Type** | `non-sealed class` |
| **Implements** | `IUnregisterDeviceTokenService` |
| **Annotations** | `@Service` |

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `DeviceTokenRepository` | Repository | Data access layer for device token persistence |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's ID |

## Constructor

### `UnregisterDeviceTokenService(DeviceTokenRepository deviceTokenRepository, IAuthenticatedUserResolver userResolver)`

Creates a new instance of the service with the required dependencies.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceTokenRepository` | `DeviceTokenRepository` | Repository for managing device token data |
| `userResolver` | `IAuthenticatedUserResolver` | Service to resolve the authenticated user |

## Public Methods

### `execute(String deviceToken)`

Unregisters (deletes) the specified device token for the currently authenticated user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceToken` | `String` | The device token to be removed |

**Return Type:** `void`

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown if the device token is not found for the authenticated user |

**Behavior:**

1. Resolves the authenticated user's ID using `userResolver.requireUserId()`
2. Executes the deletion operation via `ServiceOperationExecutor.executeVoid()`
3. The operation is wrapped in a `@Transactional` context to ensure data consistency

**Example Usage:**

```java
@Autowired
private UnregisterDeviceTokenService unregisterDeviceTokenService;

// Unregister a device token
unregisterDeviceTokenService.execute("device-token-12345");
```

## Transactional Behavior

The `execute` method is annotated with `@Transactional`, meaning:

- The operation runs within a database transaction
- If an exception occurs, the transaction is rolled back
- The deletion is atomic and consistent

## Error Handling

The service uses `ServiceOperationExecutor.executeVoid()` to handle errors consistently:

- On success: The device token is deleted from the database
- On failure: A `ResourceNotFoundException` is thrown, indicating the token was not found for the user

## Security Considerations

- The service resolves the authenticated user before performing any operation
- Only the authenticated user's device tokens can be unregistered
- The `IAuthenticatedUserResolver` ensures proper authentication context
