# UnregisterDeviceTokenService

The `UnregisterDeviceTokenService` is a Spring service class responsible for removing a device token associated with a specific user. It ensures that when a user unregisters a device (e.g., during logout or device removal), the corresponding push notification token is deleted from the database.

This service is part of the notification feature and works in conjunction with the `DeviceTokenRepository` and an authenticated user resolver to securely identify the current user.

## Class Overview

- **Package:** `com.upmatches.app.features.notification.services`
- **Annotations:** `@Service`
- **Modifier:** `non-sealed`
- **Implements:** `IUnregisterDeviceTokenService`

## Constructor

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceTokenRepository` | `DeviceTokenRepository` | Repository for managing device token persistence |
| `userResolver` | `IAuthenticatedUserResolver` | Resolves the currently authenticated user's ID |

## Public Methods

### `execute(String deviceToken)`

Deletes the device token for the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceToken` | `String` | The device token to unregister |

**Return Type:** `void`

**Behavior:**
1. Retrieves the authenticated user's UUID via `userResolver.requireUserId()`.
2. Delegates the deletion to `ServiceOperationExecutor.executeVoid()` which:
   - Calls `deviceTokenRepository.deleteByUserIdAndDeviceToken(userId, deviceToken)`.
   - Uses `DELETE` as the operation status.
   - Throws a `ResourceNotFoundException` if the deletion fails (e.g., token not found).

**Transactional:** Yes (`@Transactional`)

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `DeviceTokenRepository` | Repository | Spring Data repository for device token CRUD operations |
| `IAuthenticatedUserResolver` | Interface | Resolves the currently authenticated user's identity |
| `ServiceOperationExecutor` | Utility | Executes service operations with standardized error handling |

## Exceptions

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown when the device token cannot be found for the given user |

## Usage Example

```java
@Autowired
private UnregisterDeviceTokenService unregisterDeviceTokenService;

public void logoutUser(String deviceToken) {
    unregisterDeviceTokenService.execute(deviceToken);
}
```
