# UnregisterDeviceTokenService

The `UnregisterDeviceTokenService` is a Spring service class responsible for removing a device token associated with a specific user. This is typically used when a user logs out, uninstalls the app, or wants to stop receiving push notifications on a particular device.

## Purpose

This service ensures that when a device token is unregistered, it is properly removed from the database. The operation is performed within a transactional context to maintain data integrity. The service resolves the currently authenticated user and deletes the token only if it belongs to that user, providing a layer of security.

## Class Details

| Aspect | Description |
|--------|-------------|
| **Package** | `com.upmatches.app.features.notification.services` |
| **Type** | `non-sealed` class implementing `IUnregisterDeviceTokenService` |
| **Annotations** | `@Service`, `@Transactional` |
| **Dependencies** | `DeviceTokenRepository`, `IAuthenticatedUserResolver` |

## Constructor

### `UnregisterDeviceTokenService(DeviceTokenRepository deviceTokenRepository, IAuthenticatedUserResolver userResolver)`

Creates a new instance of the service with the required dependencies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceTokenRepository` | `DeviceTokenRepository` | Repository for managing device token persistence |
| `userResolver` | `IAuthenticatedUserResolver` | Resolver to obtain the currently authenticated user |

## Public Methods

### `execute(String deviceToken)`

Unregisters (deletes) the specified device token for the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceToken` | `String` | The device token to be removed |

**Return Type:** `void`

**Behavior:**
1. Resolves the currently authenticated user's ID using `userResolver.requireUserId()`
2. Executes the deletion operation via `ServiceOperationExecutor.executeVoid()`
3. If the token does not exist for the user, a `ResourceNotFoundException` is thrown

**Exceptions:**
- `ResourceNotFoundException` - Thrown when the device token is not found for the specified user

## Usage Example

```java
@Autowired
private UnregisterDeviceTokenService unregisterDeviceTokenService;

public void handleUserLogout(String deviceToken) {
    try {
        unregisterDeviceTokenService.execute(deviceToken);
        // Token successfully removed
    } catch (ResourceNotFoundException e) {
        // Token not found - handle accordingly
    }
}
```
