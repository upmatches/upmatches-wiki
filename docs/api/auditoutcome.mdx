# AuditOutcome Enum

The `AuditOutcome` enum is part of the `com.upmatches.app.features.audit.enums` package. It defines the possible outcomes for audit events within the application, providing a standardized way to represent the result of an audited operation.

## Purpose

This enum is used to categorize the result of an audit log entry. It helps in tracking and analyzing the success or failure of operations, as well as cases where access was explicitly denied. By using a dedicated enum, the application ensures type safety and consistency when recording audit outcomes.

## Enum Constants

| Constant  | Description                                                                 |
|-----------|-----------------------------------------------------------------------------|
| `SUCCESS` | Indicates that the audited operation completed successfully.                |
| `FAILURE` | Indicates that the audited operation failed due to an error or exception.   |
| `DENIED`  | Indicates that the audited operation was denied, typically due to authorization or permission issues. |

## Usage Example

```java
import com.upmatches.app.features.audit.enums.AuditOutcome;

public class AuditService {
    public void logAuditEvent(String action, AuditOutcome outcome) {
        // Record the audit event with the given outcome
        System.out.println("Action: " + action + ", Outcome: " + outcome);
    }
}
```

## Related Components

- **Audit Log Service**: Typically uses this enum when creating audit log entries.
- **Security Filters**: May set the outcome to `DENIED` when access is rejected.
- **Error Handlers**: May set the outcome to `FAILURE` when an operation throws an exception.
