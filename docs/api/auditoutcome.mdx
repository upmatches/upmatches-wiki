## Overview

The `AuditOutcome` enum is part of the `com.upmatches.app.features.audit.enums` package. It is used to represent the possible outcomes of an audit operation within the application. Enums in Java are a special type of class that represents a group of constants (unchangeable variables, like `final` variables).

## Enum Constants

The `AuditOutcome` enum defines three constants:

- **SUCCESS**: Indicates that the audit operation was completed successfully.
- **FAILURE**: Indicates that the audit operation failed.
- **DENIED**: Indicates that the audit operation was denied.

## Usage

Enums are used to define a set of named values. In the context of `AuditOutcome`, these values represent the possible results of an audit process. This can be particularly useful for controlling the flow of an application based on the outcome of an audit.
