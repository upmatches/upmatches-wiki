# AuditOutcome

The `AuditOutcome` enum is part of the `com.upmatches.app.features.audit.enums` package. It defines the possible outcomes for an audit event within the application. This enum is used to standardize and represent the result of an auditable action, such as a login attempt, data modification, or access control check.

## Purpose

The primary purpose of `AuditOutcome` is to provide a clear, type-safe set of constants that describe the result of an audit event. By using an enum, the application ensures that only valid outcomes are recorded, reducing errors and improving code readability.

## Enum Constants

| Constant  | Description                                                                 |
|-----------|-----------------------------------------------------------------------------|
| `SUCCESS` | Indicates that the audited action completed successfully.                   |
| `FAILURE` | Indicates that the audited action failed due to an error or invalid input.  |
| `DENIED`  | Indicates that the audited action was denied, typically due to permissions. |

## Usage

This enum is typically used in audit logging components, where each auditable event is recorded with its outcome. For example:

```java
AuditOutcome outcome = AuditOutcome.SUCCESS;
```
