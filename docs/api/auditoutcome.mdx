# AuditOutcome

The `AuditOutcome` enum is part of the `com.upmatches.app.features.audit.enums` package. It defines the possible outcomes for an audit event within the application.

## Purpose

This enum provides a standardized set of outcomes that can be associated with audit log entries. It is used to categorize the result of an audited action, such as a user login attempt, a data modification request, or an access control check.

## Enum Constants

| Constant  | Description                                                                 |
|-----------|-----------------------------------------------------------------------------|
| `SUCCESS` | Indicates that the audited action completed successfully.                   |
| `FAILURE` | Indicates that the audited action failed due to an error or invalid input.  |
| `DENIED`  | Indicates that the audited action was denied, typically due to insufficient permissions or security constraints. |

## Usage

This enum is typically used as a field in an audit log entity or event class. For example:

```java
public class AuditEvent {
    private AuditOutcome outcome;
    // other fields...
}
```

The enum values can be compared directly:

```java
if (auditEvent.getOutcome() == AuditOutcome.SUCCESS) {
    // handle success case
}
```
