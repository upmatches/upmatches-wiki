# ISkillLevelService Interface

The `ISkillLevelService` interface defines the contract for retrieving skill levels associated with specific activities. It serves as the abstraction layer between the controller and the concrete implementation (`SkillLevelService`), promoting loose coupling and testability within the application's skill level management module.

## Sealed Interface

This interface is declared as `sealed`, meaning only explicitly permitted classes can implement it. In this case, the only permitted implementation is `SkillLevelService`. This design pattern ensures controlled extensibility and provides compile-time safety when working with the service layer.

## Methods

### `getSkillLevelsByActivity`

Retrieves a list of skill level responses for a given activity.

| Parameter    | Type       | Description                                      |
|--------------|------------|--------------------------------------------------|
| `activityId` | `UUID`     | The unique identifier of the activity to query.  |

| Returns                      | Description                                                                 |
|------------------------------|-----------------------------------------------------------------------------|
| `List<SkillLevelResponse>`   | A list of `SkillLevelResponse` objects representing the skill levels found. |

**Example Usage:**

```java
ISkillLevelService skillLevelService = new SkillLevelService();
UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
List<SkillLevelResponse> skillLevels = skillLevelService.getSkillLevelsByActivity(activityId);
```
