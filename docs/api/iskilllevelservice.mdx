# ISkillLevelService Interface

The `ISkillLevelService` interface defines the contract for retrieving skill level data associated with specific activities. It serves as the abstraction layer between the presentation layer and the concrete implementation (`SkillLevelService`), promoting loose coupling and testability within the application.

## Sealed Interface

This interface is declared as `sealed`, meaning only the explicitly permitted class (`SkillLevelService`) can implement it. This design ensures controlled extension and provides compile-time safety for the service hierarchy.

## Methods

### `getSkillLevelsByActivity`

Retrieves a list of skill level responses for a given activity.

| Parameter    | Type       | Description                                      |
|--------------|------------|--------------------------------------------------|
| `activityId` | `UUID`     | The unique identifier of the activity to query.  |

| Returns                | Description                                                      |
|------------------------|------------------------------------------------------------------|
| `List<SkillLevelResponse>` | A list of `SkillLevelResponse` objects representing the skill levels associated with the specified activity. |

**Example usage:**

```java
ISkillLevelService skillLevelService = new SkillLevelService();
UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
List<SkillLevelResponse> skillLevels = skillLevelService.getSkillLevelsByActivity(activityId);
```
