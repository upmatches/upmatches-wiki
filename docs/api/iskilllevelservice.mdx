## Purpose

The `ISkillLevelService` interface is part of the `com.upmatches.app.features.skilllevels.services` package. It defines the contract for services that handle operations related to skill levels within the application. This interface is designed to be implemented by classes that provide specific functionalities for managing skill levels associated with different activities.

## Public Methods

### `getSkillLevelsByActivity`

Retrieves a list of skill levels associated with a specific activity.

| Parameter   | Type   | Description                              |
|-------------|--------|------------------------------------------|
| `activityId`| `UUID` | The unique identifier of the activity.   |

| Return Type                      | Description                                      |
|----------------------------------|--------------------------------------------------|
| `List<SkillLevelResponse>`       | A list of skill level responses for the activity.|
