# ApiResponse\<T\>

The `ApiResponse` record is a generic, standardized wrapper for all API responses in the UpMatches application. It ensures consistent JSON serialization across the entire API surface, providing a predictable structure for both successful and error responses.

## Purpose

- **Standardization**: Every endpoint returns the same envelope, making client-side parsing predictable.
- **Clarity**: Distinguishes between success and failure via the `success` boolean.
- **Metadata**: Includes a timestamp and the request path for debugging and logging.
- **Null Safety**: Uses `@JsonInclude(JsonInclude.Include.NON_NULL)` to omit null fields from the JSON output, keeping responses compact.

## Record Components

| Field     | Type      | Description                                                                 |
|-----------|-----------|-----------------------------------------------------------------------------|
| `success` | `Boolean` | `true` for successful operations, `false` for errors.                       |
| `data`    | `T`       | The actual response payload (null on errors).                               |
| `message` | `String`  | Human-readable message (e.g., "User created" or "Invalid credentials").     |
| `timestamp` | `Instant` | ISO-8601 timestamp of when the response was generated.                    |
| `path`    | `String`  | The request URI path that generated this response.                          |

## Factory Methods

### `success(T data, String message, String path)`

Creates a successful API response.

| Parameter | Type      | Description                                      |
|-----------|-----------|--------------------------------------------------|
| `data`    | `T`       | The response payload (can be any object).        |
| `message` | `String`  | A success message (e.g., "Operation completed"). |
| `path`    | `String`  | The request URI path.                            |

**Returns**: `ApiResponse<T>` with `success = true`.

**Example**:
```java
ApiResponse<User> response = ApiResponse.success(
    new User("john_doe"),
    "User retrieved successfully",
    "/api/users/123"
);
```

### `error(String message, String path)`

Creates an error API response.

| Parameter | Type      | Description                                      |
|-----------|-----------|--------------------------------------------------|
| `message` | `String`  | A descriptive error message.                     |
| `path`    | `String`  | The request URI path where the error occurred.   |

**Returns**: `ApiResponse<T>` with `success = false` and `data = null`.

**Example**:
```java
ApiResponse<Void> response = ApiResponse.error(
    "User not found",
    "/api/users/999"
);
```

## Usage in Controllers

```java
@RestController
@RequestMapping("/api/users")
public class UserController {

    @GetMapping("/{id}")
    public ApiResponse<User> getUser(@PathVariable Long id) {
        try {
            User user = userService.findById(id);
            return ApiResponse.success(user, "User found", "/api/users/" + id);
        } catch (UserNotFoundException e) {
            return ApiResponse.error(e.getMessage(), "/api/users/" + id);
        }
    }
}
```

## JSON Output Examples

**Success Response**:
```json
{
  "success": true,
  "data": { "id": 1, "name": "John Doe" },
  "message": "User retrieved successfully",
  "timestamp": "2025-03-15T10:30:00Z",
  "path": "/api/users/1"
}
```

**Error Response**:
```json
{
  "success": false,
  "message": "User not found",
  "timestamp": "2025-03-15T10:30:00Z",
  "path": "/api/users/999"
}
```

## Notes

- The `@JsonInclude(JsonInclude.Include.NON_NULL)` annotation ensures that `data` is omitted entirely from error responses, keeping the payload minimal.
- Timestamps are generated at the moment of response creation using `Instant.now()`.
- The record is immutable by design (Java records are final and all fields are private final).
