# ApiResponse

The `ApiResponse` class is a generic Java record designed to standardize the structure of API responses across the application. It provides a consistent format for both successful and error responses, including a timestamp and the request path for traceability.

## Purpose

- **Standardization**: Ensures all API endpoints return responses in a uniform JSON structure.
- **Clarity**: Distinguishes between success and failure via the `success` boolean.
- **Traceability**: Includes a `timestamp` and `path` to help with debugging and logging.
- **Flexibility**: The generic type `T` allows any data type to be returned as the payload.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `success` | `Boolean` | Indicates whether the request was successful (`true`) or failed (`false`). |
| `data` | `T` | The payload of the response. `null` for error responses. |
| `message` | `String` | A human-readable message describing the result. |
| `timestamp` | `Instant` | The exact time the response was generated (UTC). |
| `path` | `String` | The request path that generated this response. |

## Public Methods

### `success(T data, String message, String path)`

Creates a successful API response.

| Parameter | Type | Description |
|-----------|------|-------------|
| `data` | `T` | The response payload. |
| `message` | `String` | A success message. |
| `path` | `String` | The request path. |

**Returns**: `ApiResponse<T>` — a response with `success` set to `true`.

### `error(String message, String path)`

Creates an error API response.

| Parameter | Type | Description |
|-----------|------|-------------|
| `message` | `String` | An error message describing what went wrong. |
| `path` | `String` | The request path. |

**Returns**: `ApiResponse<T>` — a response with `success` set to `false` and `data` set to `null`.

## Usage Example

```java
// Successful response
ApiResponse<User> response = ApiResponse.success(user, "User found", "/api/users/123");

// Error response
ApiResponse<Void> errorResponse = ApiResponse.error("User not found", "/api/users/999");
```

## JSON Serialization

Due to the `@JsonInclude(JsonInclude.Include.NON_NULL)` annotation, any field that is `null` (such as `data` in error responses) will be omitted from the serialized JSON output. This keeps the response payload clean and minimal.
