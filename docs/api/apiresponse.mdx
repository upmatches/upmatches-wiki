## Purpose of the ApiResponse Class

The `ApiResponse` class is a generic record designed to standardize the structure of API responses within the application. It provides a consistent format for both successful and error responses, including metadata such as a success flag, a message, a timestamp, and the request path. The class leverages Java's record feature to simplify data encapsulation and immutability.

## Public Methods

The `ApiResponse` class includes two static factory methods to create instances of the response for success and error scenarios.

### success

Creates a successful `ApiResponse` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `data`    | `T`  | The data payload of the response. |
| `message` | `String` | A message describing the success. |
| `path`    | `String` | The path of the API endpoint that was called. |

**Returns:** `ApiResponse<T>` - A new instance of `ApiResponse` indicating a successful operation.

### error

Creates an error `ApiResponse` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `message` | `String` | A message describing the error. |
| `path`    | `String` | The path of the API endpoint that was called. |

**Returns:** `ApiResponse<T>` - A new instance of `ApiResponse` indicating an error occurred.
