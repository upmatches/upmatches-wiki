# IUserService Interface

The `IUserService` interface defines the contract for user profile management operations within the UpMatches application. It serves as the abstraction layer between the presentation layer and the concrete implementation (`UserService`), ensuring loose coupling and adherence to the Dependency Inversion Principle.

## Purpose

This sealed interface restricts implementation to only the `UserService` class, providing a controlled and secure way to manage user profiles. It encapsulates the core user operations: retrieving, completing, updating, and deleting user profiles.

## Interface Definition

```java
public sealed interface IUserService permits UserService {
    // Methods defined below
}
```

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getProfile()` | `UserProfileResponse` | Retrieves the current user's profile information |
| `completeProfile(CompleteProfileRequest request)` | `UserProfileResponse` | Completes the initial user profile setup with required information |
| `updateProfile(UpdateProfileRequest request)` | `UserProfileResponse` | Updates existing user profile fields |
| `deleteUser()` | `void` | Permanently deletes the user account and associated data |

### Method Details

#### `getProfile()`
- **Purpose**: Fetches the complete profile of the currently authenticated user
- **Parameters**: None
- **Returns**: `UserProfileResponse` containing all user profile data
- **Throws**: May throw authentication exceptions if user is not logged in

#### `completeProfile(CompleteProfileRequest request)`
- **Purpose**: Finalizes the initial user registration by providing mandatory profile information
- **Parameters**: 
  - `request` (CompleteProfileRequest): Contains required fields such as name, bio, preferences, etc.
- **Returns**: `UserProfileResponse` with the completed profile data
- **Throws**: Validation exceptions if required fields are missing or invalid

#### `updateProfile(UpdateProfileRequest request)`
- **Purpose**: Modifies specific fields of an existing user profile
- **Parameters**:
  - `request` (UpdateProfileRequest): Contains only the fields to be updated
- **Returns**: `UserProfileResponse` with the updated profile data
- **Throws**: Validation exceptions if update data is invalid

#### `deleteUser()`
- **Purpose**: Removes the user account and all associated data from the system
- **Parameters**: None
- **Returns**: void
- **Throws**: Authentication exceptions if user is not logged in; may throw data integrity exceptions if deletion fails

## Usage Example

```java
// Inject the service
private final IUserService userService;

// Get current profile
UserProfileResponse profile = userService.getProfile();

// Complete initial profile
CompleteProfileRequest completeRequest = new CompleteProfileRequest(
    "John Doe", 
    "Software developer", 
    List.of("coding", "hiking")
);
UserProfileResponse completedProfile = userService.completeProfile(completeRequest);

// Update specific fields
UpdateProfileRequest updateRequest = new UpdateProfileRequest();
updateRequest.setBio("Updated bio");
UserProfileResponse updatedProfile = userService.updateProfile(updateRequest);

// Delete account
userService.deleteUser();
```

## Related Components

- **`UserService`**: The sole implementation class for this interface
- **`CompleteProfileRequest`**: Request DTO for initial profile completion
- **`UpdateProfileRequest`**: Request DTO for profile updates
- **`UserProfileResponse`**: Response DTO containing user profile data
