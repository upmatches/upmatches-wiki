## Overview

The `IUserService` interface is part of the `com.upmatches.app.features.user.services` package. It defines a contract for user-related operations, specifically focusing on user profile management. This interface is designed to be implemented by classes that provide concrete functionality for managing user profiles, such as retrieving, completing, updating, and deleting user profiles.

## Public Methods

The `IUserService` interface declares the following public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `getProfile` | None | `UserProfileResponse` | Retrieves the current user's profile. |
| `completeProfile` | `CompleteProfileRequest request` | `UserProfileResponse` | Completes the user's profile with the provided details. |
| `updateProfile` | `UpdateProfileRequest request` | `UserProfileResponse` | Updates the user's profile with new information. |
| `deleteUser` | None | `void` | Deletes the current user's profile. |

### Method Details

- **`getProfile`**: This method is used to fetch the current user's profile. It returns a `UserProfileResponse` object containing the user's profile information.

- **`completeProfile`**: This method takes a `CompleteProfileRequest` object as a parameter, which contains the necessary details to complete a user's profile. It returns a `UserProfileResponse` object reflecting the updated profile.

- **`updateProfile`**: This method accepts an `UpdateProfileRequest` object, allowing for modifications to the user's existing profile. It returns a `UserProfileResponse` object with the updated profile data.

- **`deleteUser`**: This method deletes the current user's profile. It does not return any value.
