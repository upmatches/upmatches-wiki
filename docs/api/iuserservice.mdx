# IUserService Interface

The `IUserService` interface defines the contract for user profile management operations within the UpMatches application. It serves as the abstraction layer between the controller and the concrete implementation (`UserService`), ensuring a clean separation of concerns and promoting testability.

## Purpose

This sealed interface establishes a clear API for managing user profiles, including:
- Retrieving the current user's profile
- Completing an initial profile setup
- Updating an existing profile
- Deleting a user account

By using Java's `sealed` keyword, the interface restricts implementation to only the `UserService` class, providing compile-time safety and a controlled extension point.

## Interface Definition

```java
public sealed interface IUserService permits UserService {
    // Method declarations
}
```

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getProfile()` | `UserProfileResponse` | Retrieves the profile of the currently authenticated user |
| `completeProfile(CompleteProfileRequest request)` | `UserProfileResponse` | Completes the initial profile setup with the provided information |
| `updateProfile(UpdateProfileRequest request)` | `UserProfileResponse` | Updates the existing user profile with new information |
| `deleteUser()` | `void` | Deletes the currently authenticated user's account |

### Method Details

#### `getProfile()`
- **Purpose**: Fetches and returns the complete profile data for the authenticated user.
- **Parameters**: None
- **Returns**: `UserProfileResponse` containing the user's profile information

#### `completeProfile(CompleteProfileRequest request)`
- **Purpose**: Finalizes the initial profile creation process by adding required details that were not provided during registration.
- **Parameters**: 
  - `request` (`CompleteProfileRequest`): Contains the necessary data to complete the user's profile
- **Returns**: `UserProfileResponse` with the updated profile after completion

#### `updateProfile(UpdateProfileRequest request)`
- **Purpose**: Allows the user to modify their existing profile information.
- **Parameters**:
  - `request` (`UpdateProfileRequest`): Contains the fields to be updated in the user's profile
- **Returns**: `UserProfileResponse` reflecting the applied changes

#### `deleteUser()`
- **Purpose**: Permanently removes the authenticated user's account and associated data from the system.
- **Parameters**: None
- **Returns**: `void`

## Usage Example

```java
// Inject the service
private final IUserService userService;

// Get current profile
UserProfileResponse profile = userService.getProfile();

// Complete initial profile
CompleteProfileRequest completeRequest = new CompleteProfileRequest(/* ... */);
UserProfileResponse completedProfile = userService.completeProfile(completeRequest);

// Update profile
UpdateProfileRequest updateRequest = new UpdateProfileRequest(/* ... */);
UserProfileResponse updatedProfile = userService.updateProfile(updateRequest);

// Delete user
userService.deleteUser();
```

## Related Components

- **`UserService`**: The sole implementation of this interface
- **`CompleteProfileRequest`**: Request DTO for profile completion
- **`UpdateProfileRequest`**: Request DTO for profile updates
- **`UserProfileResponse`**: Response DTO containing user profile data
