## Purpose

The `CreateNotificationService` class is a part of the notification feature in the application. It is responsible for creating notifications for users. This service interacts with the `NotificationRepository` to persist notifications and with the `UserRepository` to validate the existence of the recipient user. It ensures that notifications are created and saved in a transactional context, providing a robust mechanism for handling notification creation.

## Public Methods

### `execute`

This method is responsible for creating and saving a notification for a specified user. It ensures that the recipient user exists and then creates a notification with the provided details.

| Parameter      | Type                      | Description                                                                 |
|----------------|---------------------------|-----------------------------------------------------------------------------|
| `recipientId`  | `UUID`                    | The unique identifier of the user who will receive the notification.        |
| `type`         | `NotificationType`        | The type of the notification to be created.                                 |
| `title`        | `String`                  | The title of the notification.                                              |
| `message`      | `String`                  | The message content of the notification.                                    |
| `resourceType` | `String`                  | The type of resource associated with the notification.                      |
| `resourceId`   | `UUID`                    | The unique identifier of the resource associated with the notification.     |

#### Return Type

- **`Notification`**: Returns the created `Notification` object after it has been successfully saved in the repository.

#### Exceptions

- **`ResourceNotFoundException`**: Thrown if the recipient user is not found in the `UserRepository`.
