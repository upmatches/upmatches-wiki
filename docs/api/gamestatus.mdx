# GameStatus Enum

The `GameStatus` enum defines the possible states a game can be in within the UpMatches application. It is used to track the lifecycle of a game from its creation through completion or cancellation.

## Package Location

`com.upmatches.app.features.game.enums`

## Enum Values

| Value | Description |
|-------|-------------|
| `SCHEDULED` | The game has been created and scheduled for a future date/time. |
| `STARTED` | The game is currently in progress. |
| `EXPIRED` | The game has ended or passed its scheduled time without being completed. |
| `CANCELLED` | The game was cancelled before it started. |

## Usage

This enum is typically used in game-related entities and services to determine the current state of a game and control what actions are allowed. For example:

- A game can only transition from `SCHEDULED` to `STARTED` when the scheduled time arrives.
- A game in `STARTED` state cannot be cancelled.
- `EXPIRED` and `CANCELLED` are terminal states.

## Example

```java
GameStatus status = GameStatus.SCHEDULED;

if (status == GameStatus.STARTED) {
    // Allow gameplay actions
} else if (status == GameStatus.CANCELLED) {
    // Notify players
}
```
