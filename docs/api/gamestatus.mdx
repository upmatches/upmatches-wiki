# GameStatus Enum

The `GameStatus` enum defines the possible states a game can be in within the UpMatches application. It is used to track the lifecycle of a game from its creation to its conclusion.

## Purpose

This enum provides a type-safe way to represent the current status of a game. It ensures that only valid status values are used throughout the application, preventing errors from string-based status handling.

## Enum Values

| Value       | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `SCHEDULED` | The game has been created and is scheduled to take place at a future time.  |
| `STARTED`   | The game is currently in progress.                                          |
| `EXPIRED`   | The game has ended or its scheduled time has passed without being started.  |
| `CANCELLED` | The game has been cancelled before it started.                              |

## Usage

This enum is typically used in game-related entities and services to manage game state transitions. For example:

```java
GameStatus currentStatus = game.getStatus();

if (currentStatus == GameStatus.SCHEDULED) {
    // Allow players to join
} else if (currentStatus == GameStatus.STARTED) {
    // Track live game events
}
```
