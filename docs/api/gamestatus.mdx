## Purpose

The `GameStatus` enum is part of the `com.upmatches.app.features.game.enums` package. It represents the various states that a game can be in within the application. Enumerations in Java are a special type of class that is used to define collections of constants. In this case, `GameStatus` defines four possible states for a game: `SCHEDULED`, `STARTED`, `EXPIRED`, and `CANCELLED`.

## Enum Constants

The `GameStatus` enum contains the following constants:

| Constant   | Description                                                                 |
|------------|-----------------------------------------------------------------------------|
| SCHEDULED  | Indicates that the game is scheduled to occur at a future time.             |
| STARTED    | Indicates that the game has begun and is currently in progress.             |
| EXPIRED    | Indicates that the game has ended and is no longer active.                  |
| CANCELLED  | Indicates that the game has been cancelled and will not take place.         |

## Usage

Enums are typically used in switch statements or for controlling the flow of a program based on the state of an object. The `GameStatus` enum can be used to manage game state transitions and ensure that the application logic handles each state appropriately.
