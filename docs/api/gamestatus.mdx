## Overview

The `GameStatus` enum is part of the `com.upmatches.app.features.game.enums` package. It represents the various states a game can be in within the application. Enums in Java are a special type of class that represents a group of constants (unchangeable variables, like final variables).

## Enum Constants

The `GameStatus` enum defines the following constants:

- **SCHEDULED**: Indicates that the game is scheduled to occur at a future date and time.
- **STARTED**: Indicates that the game has commenced.
- **EXPIRED**: Indicates that the game has ended and is no longer active.
- **CANCELLED**: Indicates that the game has been cancelled and will not take place.
