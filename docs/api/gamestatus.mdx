# GameStatus Enum

The `GameStatus` enum represents the possible states of a game within the application. It is used to track and manage the lifecycle of a game from its creation to its conclusion.

## Purpose

This enum provides a type-safe way to define and handle the different statuses a game can have. It ensures that only valid status values are used throughout the codebase, reducing errors and improving code readability.

## Enum Values

| Value       | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `SCHEDULED` | The game has been planned and is set to occur at a future date and time.    |
| `STARTED`   | The game is currently in progress.                                          |
| `EXPIRED`   | The game has ended or its scheduled time has passed without being started.  |
| `CANCELLED` | The game has been cancelled and will not take place.                        |

## Usage

The `GameStatus` enum is typically used in game-related entities, services, and controllers to represent and transition between game states. For example:

```java
GameStatus currentStatus = GameStatus.SCHEDULED;
// Later, when the game starts:
currentStatus = GameStatus.STARTED;
```
