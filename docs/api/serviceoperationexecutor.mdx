## Purpose

The `ServiceOperationExecutor` class is a utility class designed to execute operations with robust exception handling. It provides methods to execute operations that may interact with databases or external services, ensuring that exceptions are handled appropriately and consistently. This class is particularly useful in scenarios where operations need to be executed with traceability and error management.

## Public Methods

### `execute`

Executes a given operation with specified exception handling.

| Parameter        | Type                      | Description                                                                 |
|------------------|---------------------------|-----------------------------------------------------------------------------|
| `operation`      | `Supplier<T>`             | The operation to be executed.                                               |
| `operationType`  | `OperationStatus`         | The type of operation being executed, used for logging and exception messages. |
| `exceptionFactory` | `ExceptionFactory`      | Factory to create exceptions for specific error scenarios.                  |

**Return Type:** `T` - The result of the operation.

### `executeVoid`

Executes a given void operation with specified exception handling.

| Parameter        | Type                      | Description                                                                 |
|------------------|---------------------------|-----------------------------------------------------------------------------|
| `operation`      | `Runnable`                | The operation to be executed.                                               |
| `operationType`  | `OperationStatus`         | The type of operation being executed, used for logging and exception messages. |
| `exceptionFactory` | `ExceptionFactory`      | Factory to create exceptions for specific error scenarios.                  |

**Return Type:** `void` - This method does not return a value.
