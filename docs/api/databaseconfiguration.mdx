# DatabaseConfiguration

The `DatabaseConfiguration` class is a Spring Boot configuration class responsible for creating and configuring the primary `DataSource` bean for the application. It provides a robust, production-ready database connection pool using HikariCP, with automatic driver detection, database-specific optimizations (PostgreSQL and H2), and integrated monitoring via Micrometer.

## Purpose

This class serves as the central point for database connectivity setup. It reads configuration from `DatabaseProperties`, resolves the appropriate JDBC driver based on the URL, applies connection pool sizing and timeout settings, and configures database-specific optimizations for PostgreSQL and H2 databases. It also integrates with Micrometer for metrics collection and provides comprehensive logging of the final configuration.

## Dependencies

- **Spring Boot**: `@Configuration`, `@EnableConfigurationProperties`, `@ConditionalOnProperty`
- **HikariCP**: Connection pooling
- **Micrometer**: Metrics collection
- **SLF4J**: Logging

## Configuration Properties

The class relies on properties bound to `DatabaseProperties` and `HikariProperties`. Key configuration points include:

| Property | Description | Default |
|----------|-------------|---------|
| `app.database.enabled` | Enable/disable the datasource | `true` |
| `app.database.url` | JDBC URL | Required |
| `app.database.username` | Database username | - |
| `app.database.password` | Database password | - |
| `app.database.driver-class-name` | JDBC driver class (optional) | Auto-detected |
| `app.database.hikari.*` | HikariCP pool settings | See defaults below |

## Public Methods

### `dataSource()`

Creates and returns the primary `DataSource` bean.

| Aspect | Details |
|--------|---------|
| **Return Type** | `javax.sql.DataSource` |
| **Bean Name** | `dataSource` |
| **Primary** | Yes |
| **Condition** | `app.database.enabled=true` (default) |
| **Throws** | `IllegalStateException` if JDBC URL is not configured |

**Configuration Process:**
1. Validates that the JDBC URL is configured
2. Resolves the JDBC driver class name (auto-detected or explicitly configured)
3. Creates a `HikariConfig` with:
   - JDBC URL, username, password
   - Auto-commit disabled (`false`)
   - Read-only disabled (`false`)
4. Applies pool sizing (max pool size, minimum idle)
5. Applies timeout settings (connection, idle, max lifetime, leak detection)
6. Applies database-specific optimizations:
   - **PostgreSQL**: TCP keep-alive, application name, prepared statement caching, batched inserts
   - **H2**: DB close delay, cache size, lock timeout
7. Configures monitoring (Micrometer metrics)
8. Logs the complete configuration summary
9. Returns a new `HikariDataSource`

## Private Methods

### `resolveDriverClassName(String jdbcUrl)`

Resolves the JDBC driver class name.

| Parameter | Type | Description |
|-----------|------|-------------|
| `jdbcUrl` | `String` | The JDBC URL |
| **Returns** | `String` | The driver class name |

If a driver class is explicitly configured in properties, it is used. Otherwise, the driver is auto-detected from the JDBC URL.

### `getDriverClassName(String jdbcUrl)`

Determines the driver class name from the JDBC URL.

| Parameter | Type | Description |
|-----------|------|-------------|
| `jdbcUrl` | `String` | The JDBC URL |
| **Returns** | `String` | The driver class name |
| **Throws** | `IllegalArgumentException` | If the JDBC URL is unsupported |

Supported JDBC URL prefixes: `jdbc:h2:`, `jdbc:postgresql:`, `jdbc:mysql:`

### `getDatabaseType(String jdbcUrl)`

Returns the database type name from the JDBC URL.

| Parameter | Type | Description |
|-----------|------|-------------|
| `jdbcUrl` | `String` | The JDBC URL |
| **Returns** | `String` | Database type name or "UNKNOWN" |

### `resolvePoolName()`

Generates a unique pool name based on active Spring profiles.

| Returns | Description |
|---------|-------------|
| `String` | Pool name with profile suffix if profiles are active |

Format: `HikariPool-{profiles}` or `HikariPool` if no profiles are active.

### `applyPoolSizing(HikariConfig config)`

Applies minimum idle and maximum pool size settings.

| Parameter | Type | Description |
|-----------|------|-------------|
| `config` | `HikariConfig` | The HikariCP configuration |

### `getMaximumPoolSize()`

Returns the configured maximum pool size.

| Returns | Default |
|---------|---------|
| `int` | `10` |

### `getMinimumIdle()`

Returns the configured minimum idle connections.

| Returns | Default |
|---------|---------|
| `int` | `10` |

### `applyTimeouts(HikariConfig hikariConfig)`

Applies all timeout settings to the HikariCP configuration.

| Parameter | Type | Description |
|-----------|------|-------------|
| `hikariConfig` | `HikariConfig` | The HikariCP configuration |

### `getInitializationFailTimeout()`

Returns the initialization fail timeout.

| Returns | Default |
|---------|---------|
| `long` | `-1` (fail fast) |

### `getConnectionTimeout()`

Returns the connection timeout in milliseconds.

| Returns | Default |
|---------|---------|
| `long` | `30000` (30 seconds) |

### `getIdleTimeout()`

Returns the idle timeout in milliseconds.

| Returns | Default |
|---------|---------|
| `long` | `600000` (10 minutes) |

### `getMaxLifetime()`

Returns the maximum lifetime of a connection in milliseconds.

| Returns | Default |
|---------|---------|
| `long` | `1800000` (30 minutes) |

### `applyPostgreSQLOptimizations(HikariConfig hikariConfig, String applicationName)`

Applies PostgreSQL-specific optimizations.

| Parameter | Type | Description |
|-----------|------|-------------|
| `hikariConfig` | `HikariConfig` | The HikariCP configuration |
| `applicationName` | `String` | Application name for PostgreSQL |

Optimizations include:
- TCP keep-alive enabled
- Application name set
- Server version assumption
- Batched inserts rewriting
- Prepared statement caching (queries and size)
- Time statistics disabled

### `resolveApplicationName()`

Resolves the application name from Spring properties.

| Returns | Description |
|---------|-------------|
| `String` | Application name with optional profile suffix |

Uses `spring.application.name` property or defaults to `"upmatches"`.

### `applyH2Optimizations(HikariConfig hikariConfig)`

Applies H2-specific optimizations.

| Parameter | Type | Description |
|-----------|------|-------------|
| `hikariConfig` | `HikariConfig` | The HikariCP configuration |

Optimizations include:
- DB close delay
- DB close on exit
- Cache size
- Lock timeout

### `applyMonitoring(HikariConfig config)`

Configures Micrometer metrics tracking.

| Parameter | Type | Description |
|-----------|------|-------------|
| `config` | `HikariConfig` | The HikariCP configuration |

If a `MeterRegistry` bean is available, it creates a `MicrometerMetricsTrackerFactory` for metrics collection.

### `logConfigurationSummary(HikariConfig config, String driver, String applicationName)`

Logs the complete configuration summary at INFO level.

| Parameter | Type | Description |
|-----------|------|-------------|
| `config` | `HikariConfig` | The HikariCP configuration |
| `driver` | `String` | The JDBC driver class name |
| `applicationName` | `String` | The application name |

Logs include:
- Pool name
- Pool size (min/max)
- Timeouts (connection, idle, max lifetime)
- Leak detection threshold
- Database URL (masked)
- Driver class
- Application name

### `maskSensitiveUrl(String url)`

Masks sensitive information (username/password) in JDBC URLs for logging.

| Parameter | Type | Description |
|-----------|------|-------------|
| `url` | `String` | The JDBC URL |
| **Returns** | `String` | Masked URL or "N/A" |

## Usage Example

```java
// The DataSource is automatically created by Spring Boot
// when app.database.enabled=true (default)

// application.yml configuration:
app:
  database:
    url: jdbc:postgresql://localhost:5432/mydb
    username: myuser
    password: mypassword
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 30000
      idle-timeout: 600000
      max-lifetime: 1800000
```

## Logging

The class provides detailed INFO-level logging of the datasource configuration, including:
- Initialization message with database type
- Complete HikariCP configuration summary
- Metrics integration status
- Database-specific optimizations (debug level for H2)

Sensitive information in JDBC URLs (credentials) is masked in logs for security.
