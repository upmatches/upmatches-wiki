## Purpose

The `DatabaseConfiguration` class is a Spring configuration class responsible for setting up and managing the database connection pool using HikariCP. It configures the data source based on the provided database properties and environment settings, applying optimizations for specific database types like PostgreSQL and H2. Additionally, it integrates with Micrometer for monitoring purposes if a `MeterRegistry` is available.

## Public Methods

The class exposes the following public method:

### `dataSource`

This method configures and returns a `DataSource` bean, which is the primary interface for interacting with the database.

| Parameter | Type   | Description                     |
|-----------|--------|---------------------------------|
| None      | N/A    | This method does not take any parameters. |

| Return Type | Description                                |
|-------------|--------------------------------------------|
| `DataSource`| A configured `HikariDataSource` instance.  |

### Method Details

- **`dataSource`**: Configures a `HikariDataSource` based on the application properties and environment. It sets various properties such as JDBC URL, username, password, driver class name, pool sizing, and timeouts. It also applies database-specific optimizations and monitoring configurations. If the database URL is not configured, it throws an `IllegalStateException`.
