# GameParticipant

The `GameParticipant` entity represents a user's participation in a game within the UpMatches application. It tracks the lifecycle of a participant from joining a game to leaving it, including their current status and timestamps.

## Purpose

This JPA entity is designed to manage the relationship between `Game` and `User` entities. It records when a user joins a game, their participation status, and optionally when they leave. The class provides factory and behavior methods to ensure consistent state management.

## Entity Details

- **Table**: `game_participants`
- **Package**: `com.upmatches.app.features.game.entities`
- **Annotations**: `@Entity`, `@Table`, `@Getter`, `@NoArgsConstructor(access = AccessLevel.PROTECTED)`

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Primary key, auto-generated using UUID strategy |
| `game` | `Game` | The game the user is participating in (Many-to-One relationship) |
| `user` | `User` | The user participating in the game (Many-to-One relationship) |
| `status` | `ParticipantStatus` | Current participation status (stored as string in DB) |
| `joinedAt` | `Instant` | Timestamp when the participant joined (set automatically on persist) |
| `leftAt` | `Instant` | Timestamp when the participant left (nullable) |

## Public Methods

### `create(Game game, User user)`
Creates a new `GameParticipant` instance with `ACTIVE` status.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to join |
| `user` | `User` | The user joining the game |

**Returns**: `GameParticipant` - A new participant instance with status set to `ACTIVE`

### `leave()`
Marks the participant as having left the game. Updates the status to `LEFT` and records the current timestamp in `leftAt`.

**Parameters**: None

**Returns**: `void`

## Lifecycle Callbacks

### `onCreate()`
A `@PrePersist` callback that automatically sets the `joinedAt` field to the current instant when the entity is first persisted.

## Usage Example

```java
// Creating a new participant
GameParticipant participant = GameParticipant.create(game, user);
entityManager.persist(participant);

// Participant leaves the game
participant.leave();
entityManager.merge(participant);
```

## Dependencies

- **Lombok**: Uses `@Getter` and `@NoArgsConstructor` for boilerplate reduction
- **Jakarta Persistence**: Standard JPA annotations for ORM mapping
- **ParticipantStatus**: Enum defining possible participant states (ACTIVE, LEFT, etc.)
- **Game**: The parent game entity
- **User**: The user entity representing the participant
