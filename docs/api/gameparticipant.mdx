## Overview

The `GameParticipant` class is an entity representing a participant in a game within the application. It is part of the `com.upmatches.app.features.game.entities` package and is mapped to the `game_participants` table in the database. This class manages the relationship between a user and a game, tracking the user's status and timestamps for when they join or leave the game.

## Public Methods

The `GameParticipant` class provides the following public methods:

### `create`

Creates a new instance of `GameParticipant` with the specified game and user, setting the initial status to `ACTIVE`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game`    | `Game` | The game the participant is joining. |
| `user`    | `User` | The user who is participating in the game. |

| Return Type | Description |
|-------------|-------------|
| `GameParticipant` | A new instance of `GameParticipant` with the specified game and user. |

### `leave`

Updates the participant's status to `LEFT` and records the current timestamp as the time they left the game.

| Parameter | Type | Description |
|-----------|------|-------------|
| *(none)*  |      |             |

| Return Type | Description |
|-------------|-------------|
| `void`      | This method does not return a value. |

## Annotations and Persistence

- **Entity and Table Mapping**: Annotated with `@Entity` and `@Table(name = "game_participants")` to map the class to a database table.
- **ID Generation**: The `id` field is annotated with `@Id` and `@GeneratedValue(strategy = GenerationType.UUID)` to automatically generate a unique identifier for each participant.
- **Relationships**: 
  - `@ManyToOne` relationships with `Game` and `User` entities, indicating that each participant is associated with one game and one user.
- **Enumerated Type**: The `status` field uses `@Enumerated(EnumType.STRING)` to store the participant's status as a string in the database.
- **Lifecycle Callback**: The `@PrePersist` annotation on the `onCreate` method sets the `joinedAt` timestamp when the entity is first persisted.
