## Purpose

The `GameParticipant` class represents an entity that links a user to a game, capturing the user's participation status and timestamps for when they joined and left the game. It is a part of the `com.upmatches.app.features.game.entities` package and is mapped to the `game_participants` table in the database.

## Public Methods

The `GameParticipant` class provides the following public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `create` | `Game game`, `User user` | `GameParticipant` | Static factory method to create a new `GameParticipant` instance with the given game and user, setting the status to `ACTIVE`. |
| `leave` | None | `void` | Updates the participant's status to `LEFT` and sets the `leftAt` timestamp to the current time. |

## Fields

The class contains several fields, most of which are private and accessed via Lombok-generated getters:

- `UUID id`: Unique identifier for the participant.
- `Game game`: The game associated with the participant.
- `User user`: The user participating in the game.
- `ParticipantStatus status`: The current status of the participant (e.g., ACTIVE, LEFT).
- `Instant joinedAt`: Timestamp indicating when the participant joined the game.
- `Instant leftAt`: Timestamp indicating when the participant left the game.
