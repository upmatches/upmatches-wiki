# SkillLevelRepository

The `SkillLevelRepository` interface provides database access operations for `SkillLevel` entities. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD functionality and defines a custom query method for retrieving skill levels ordered by their sort position within a specific activity.

## Interface Definition

```java
public interface SkillLevelRepository extends JpaRepository<SkillLevel, Long>
```

This repository manages `SkillLevel` entities with a primary key of type `Long`.

## Methods

### Inherited Methods from JpaRepository

The following standard CRUD methods are inherited from `JpaRepository<SkillLevel, Long>`:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all skill level entities |
| `findById(Long id)` | Finds a skill level by its primary key |
| `save(SkillLevel entity)` | Saves or updates a skill level |
| `deleteById(Long id)` | Deletes a skill level by its primary key |
| `count()` | Returns the total number of skill levels |

### Custom Query Methods

#### `findByActivityIdOrderBySortOrder`

```java
List<SkillLevel> findByActivityIdOrderBySortOrder(UUID activityId)
```

Retrieves all skill levels associated with a specific activity, ordered by their `sortOrder` field in ascending order.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityId` | `UUID` | The unique identifier of the activity whose skill levels should be retrieved |

**Returns:**

| Type | Description |
|------|-------------|
| `List<SkillLevel>` | An ordered list of skill levels belonging to the specified activity, sorted by their sort order |

**Example Usage:**

```java
@Autowired
private SkillLevelRepository skillLevelRepository;

// Retrieve skill levels for a specific activity
UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
List<SkillLevel> skillLevels = skillLevelRepository.findByActivityIdOrderBySortOrder(activityId);
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` base interface and automatic query implementation
- **Entity**: Works with the `SkillLevel` entity class from `com.upmatches.app.features.skilllevels.entities`

## Notes

- The `findByActivityIdOrderBySortOrder` method leverages Spring Data JPA's query derivation mechanism, which automatically generates the appropriate SQL query based on the method name
- The `sortOrder` field in the `SkillLevel` entity should be a numeric type (e.g., `int` or `Integer`) to ensure proper ordering
- Results are returned in ascending order by `sortOrder`; for descending order, use `findByActivityIdOrderBySortOrderDesc`
