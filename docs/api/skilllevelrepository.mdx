# SkillLevelRepository

The `SkillLevelRepository` interface provides database access operations for `SkillLevel` entities within the UpMatches application. It extends Spring Data JPA's `JpaRepository`, inheriting standard CRUD functionality while adding a custom query method to retrieve skill levels ordered by their sort position for a specific activity.

## Interface Definition

```java
public interface SkillLevelRepository extends JpaRepository<SkillLevel, Long>
```

The repository works with `SkillLevel` entities that have a primary key of type `Long`.

## Methods

### Inherited Methods

The following standard CRUD methods are inherited from `JpaRepository<SkillLevel, Long>`:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all `SkillLevel` entities |
| `findById(Long id)` | Finds a `SkillLevel` by its primary key |
| `save(SkillLevel entity)` | Persists a new or updates an existing `SkillLevel` |
| `delete(SkillLevel entity)` | Removes a `SkillLevel` from the database |
| `deleteById(Long id)` | Deletes a `SkillLevel` by its primary key |
| `count()` | Returns the total number of `SkillLevel` entities |
| `existsById(Long id)` | Checks if a `SkillLevel` exists with the given primary key |

### Custom Methods

#### `findByActivityIdOrderBySortOrder`

```java
List<SkillLevel> findByActivityIdOrderBySortOrder(UUID activityId)
```

Retrieves all skill levels associated with a specific activity, ordered by their `sortOrder` field in ascending order.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityId` | `UUID` | The unique identifier of the activity whose skill levels should be retrieved |

**Returns:**

| Type | Description |
|------|-------------|
| `List<SkillLevel>` | An ordered list of `SkillLevel` entities belonging to the specified activity |

**Example Usage:**

```java
@Autowired
private SkillLevelRepository skillLevelRepository;

public List<SkillLevel> getSkillLevelsForActivity(UUID activityId) {
    return skillLevelRepository.findByActivityIdOrderBySortOrder(activityId);
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` base interface and query derivation
- **SkillLevel entity**: The domain object this repository manages
- **UUID**: Used for activity identification in the custom query method
