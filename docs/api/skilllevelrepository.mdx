# SkillLevelRepository

The `SkillLevelRepository` interface provides database access operations for `SkillLevel` entities. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD functionality and defines a custom query method for retrieving skill levels ordered by their sort position within a specific activity.

## Interface Definition

```java
public interface SkillLevelRepository extends JpaRepository<SkillLevel, Long>
```

This repository manages `SkillLevel` entities with a primary key of type `Long`.

## Methods

### Inherited Methods from JpaRepository

The following standard CRUD methods are inherited from `JpaRepository<SkillLevel, Long>`:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all skill level entities |
| `findById(Long id)` | Finds a skill level by its primary key |
| `save(SkillLevel entity)` | Persists or updates a skill level |
| `deleteById(Long id)` | Deletes a skill level by its primary key |
| `delete(SkillLevel entity)` | Deletes a specific skill level |
| `count()` | Returns the total number of skill levels |
| `existsById(Long id)` | Checks if a skill level exists by its primary key |

### Custom Query Methods

#### `findByActivityIdOrderBySortOrder`

```java
List<SkillLevel> findByActivityIdOrderBySortOrder(UUID activityId)
```

Retrieves all skill levels associated with a specific activity, ordered by their `sortOrder` field in ascending order.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityId` | `UUID` | The unique identifier of the activity |

**Returns:**

| Type | Description |
|------|-------------|
| `List<SkillLevel>` | An ordered list of skill levels belonging to the specified activity |

**Example Usage:**

```java
@Autowired
private SkillLevelRepository skillLevelRepository;

public List<SkillLevel> getSkillLevelsForActivity(UUID activityId) {
    return skillLevelRepository.findByActivityIdOrderBySortOrder(activityId);
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` base interface and query derivation
- **SkillLevel entity**: The domain entity this repository manages
- **UUID**: Used for activity identification

## Notes

- The repository uses method name convention to automatically derive the query implementation
- Results are sorted by `sortOrder` to maintain the intended display sequence of skill levels
- The `activityId` parameter uses `UUID` type for distributed system compatibility
