# GameScheduler

The `GameScheduler` class is a Spring `@Component` that provides scheduled task execution for updating game statuses. It runs two distinct cron jobs every five minutes: one to mark games as STARTED and another to mark games as EXPIRED. This class acts as a lightweight orchestrator, delegating the actual business logic to injected service interfaces.

## Purpose

- **Automated Status Updates**: Periodically checks and updates game statuses without manual intervention.
- **Separation of Concerns**: The scheduler only handles timing and logging; the `IMarkStartedGamesService` and `IMarkExpiredGamesService` implementations contain the domain logic.
- **Observability**: Uses SLF4J logging to report how many games were updated in each execution.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IMarkStartedGamesService` | Service Interface | Handles logic for marking games as STARTED. |
| `IMarkExpiredGamesService` | Service Interface | Handles logic for marking games as EXPIRED. |
| `Logger` (SLF4J) | Logging | Logs the number of games updated per execution. |

## Constructor

### `GameScheduler(IMarkStartedGamesService, IMarkExpiredGamesService)`

Constructor-based dependency injection for the two required services.

| Parameter | Type | Description |
|-----------|------|-------------|
| `markStartedGamesService` | `IMarkStartedGamesService` | Service to mark games as started. |
| `markExpiredGamesService` | `IMarkExpiredGamesService` | Service to mark games as expired. |

## Public Methods

### `markStartedGames()`

Scheduled method that executes every 5 minutes (cron: `0 */5 * * * *`). Calls `markStartedGamesService.execute()` and logs the number of games updated.

| Aspect | Details |
|--------|---------|
| **Cron Expression** | `0 */5 * * * *` (every 5 minutes) |
| **Return Type** | `void` |
| **Log Output** | `Marked {count} games as STARTED.` |

### `markExpiredGames()`

Scheduled method that executes every 5 minutes (cron: `0 */5 * * * *`). Calls `markExpiredGamesService.execute()` and logs the number of games updated.

| Aspect | Details |
|--------|---------|
| **Cron Expression** | `0 */5 * * * *` (every 5 minutes) |
| **Return Type** | `void` |
| **Log Output** | `Marked {count} games as EXPIRED.` |

## Usage Example

```java
// The scheduler is automatically picked up by Spring component scanning.
// No manual instantiation is required.
// The cron jobs will run automatically every 5 minutes.
```

## Notes

- Both cron jobs run on the same schedule (every 5 minutes) but are independent of each other.
- The actual number of games updated depends on the implementation of the injected services.
- Logging uses parameterized messages for efficient string construction.
