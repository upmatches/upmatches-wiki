import com.upmatches.app.features.game.schedulers.GameScheduler;

## Purpose

The `GameScheduler` class is a Spring component responsible for scheduling tasks related to updating the status of games. It utilizes the Spring Scheduling framework to periodically mark games as either "started" or "expired" based on predefined conditions. This class ensures that the game statuses are updated every five minutes by invoking the appropriate services.

## Public Methods

The `GameScheduler` class exposes the following public methods:

| Method Name       | Description                                                                 | Parameters | Return Type |
|-------------------|-----------------------------------------------------------------------------|------------|-------------|
| `markStartedGames`| Marks games as "started" by invoking the `IMarkStartedGamesService`.        | None       | void        |
| `markExpiredGames`| Marks games as "expired" by invoking the `IMarkExpiredGamesService`.        | None       | void        |

### Method Details

#### `markStartedGames`

- **Description**: This method is scheduled to run every five minutes. It calls the `execute` method of the `IMarkStartedGamesService` to update the status of games to "started". The number of games updated is logged using SLF4J.
- **Parameters**: None
- **Return Type**: `void`

#### `markExpiredGames`

- **Description**: This method is scheduled to run every five minutes. It calls the `execute` method of the `IMarkExpiredGamesService` to update the status of games to "expired". The number of games updated is logged using SLF4J.
- **Parameters**: None
- **Return Type**: `void`

## Scheduling Details

Both `markStartedGames` and `markExpiredGames` methods are annotated with `@Scheduled(cron = "0 */5 * * * *")`, which means they are executed every five minutes. This scheduling is crucial for maintaining the timely update of game statuses within the application.
