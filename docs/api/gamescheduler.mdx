import com.upmatches.app.features.game.services.IMarkExpiredGamesService;
import com.upmatches.app.features.game.services.IMarkStartedGamesService;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

## Purpose

The `GameScheduler` class is a Spring component responsible for scheduling and executing tasks related to updating the status of games. It uses cron expressions to periodically mark games as either started or expired. This class leverages two services, `IMarkStartedGamesService` and `IMarkExpiredGamesService`, to perform the necessary updates and logs the results.

## Public Methods

| Method Name         | Description                                                                 | Parameters | Return Type |
|---------------------|-----------------------------------------------------------------------------|------------|-------------|
| `markStartedGames`  | Marks games as started by invoking the `IMarkStartedGamesService`.          | None       | void        |
| `markExpiredGames`  | Marks games as expired by invoking the `IMarkExpiredGamesService`.          | None       | void        |

### Method Details

#### `markStartedGames`

- **Description**: This method is scheduled to run every five minutes. It calls the `execute` method of the `IMarkStartedGamesService` to update the status of games to "started". The number of games updated is logged using SLF4J.
- **Parameters**: None
- **Return Type**: `void`

#### `markExpiredGames`

- **Description**: This method is also scheduled to run every five minutes. It calls the `execute` method of the `IMarkExpiredGamesService` to update the status of games to "expired". The number of games updated is logged using SLF4J.
- **Parameters**: None
- **Return Type**: `void`

## Scheduling Details

Both `markStartedGames` and `markExpiredGames` methods are annotated with `@Scheduled(cron = CRON_EVERY_FIVE_MINUTES)`, which means they are executed every five minutes based on the cron expression `"0 */5 * * * *"`. This ensures that the game statuses are regularly updated without manual intervention.
