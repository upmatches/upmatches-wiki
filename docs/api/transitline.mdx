# TransitLine

The `TransitLine` class is a JPA entity that represents a public transit line (e.g., a subway or bus route) within the venue features module. It maps to the `transit_lines` database table and provides a simple, immutable data model for storing transit line metadata such as its code, name, and display color.

## Purpose

This entity is used to persist and retrieve information about transit lines that serve a venue. Each transit line is uniquely identified by a short code (e.g., "B", "Red", "100") and includes a human-readable name and a hex color code for UI display purposes.

## Entity Mapping

| Database Column | Java Field | Type | Constraints |
|----------------|------------|------|-------------|
| `code` | `code` | `String` | Primary key, max length 10 |
| `name` | `name` | `String` | Not null, max length 100 |
| `color` | `color` | `String` | Not null, max length 7 (hex color, e.g., `#FF0000`) |

## Constructor

The class uses a **protected no-argument constructor** required by JPA. Direct instantiation is not intended; use the static factory method instead.

## Public Methods

### `create(String code, String name, String color)`

Creates a new `TransitLine` instance with the specified values.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | Unique identifier for the transit line (max 10 characters) |
| `name` | `String` | Human-readable name of the transit line (max 100 characters) |
| `color` | `String` | Hex color code for UI display (max 7 characters, e.g., `#FF5733`) |

**Returns:** `TransitLine` — a new entity instance with the provided values.

**Example usage:**
```java
TransitLine redLine = TransitLine.create("RED", "Red Line", "#FF0000");
```

## Getters

All fields are exposed via Lombok-generated getters:

- `getCode()` — returns the transit line code
- `getName()` — returns the transit line name
- `getColor()` — returns the hex color string

## Notes

- The class uses Lombok's `@Getter` annotation to automatically generate getter methods.
- The `color` field is expected to be a 7-character hex color string (e.g., `#RRGGBB`).
- This entity is designed to be immutable after creation; there are no setter methods exposed.
