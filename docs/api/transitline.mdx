# TransitLine

The `TransitLine` class is a JPA entity that represents a public transit line (e.g., a bus or train route) within the venue features module of the UpMatches application. It maps to the `transit_lines` database table and provides a simple, immutable data model for storing transit line metadata such as its unique code, human-readable name, and display color.

This entity uses Lombok's `@Getter` annotation to automatically generate getter methods for all fields, and it enforces immutability by providing no public setters. Instead, instances are created via the static factory method `create()`.

## Fields

| Field | Type | Database Column | Constraints | Description |
|-------|------|----------------|-------------|-------------|
| `code` | `String` | `code` | Primary key, max length 10 | Unique identifier for the transit line (e.g., "BART-YL") |
| `name` | `String` | `name` | Not null, max length 100 | Human-readable name of the transit line (e.g., "Yellow Line") |
| `color` | `String` | `color` | Not null, max length 7 | Hex color code for the transit line (e.g., "#FFD700") |

## Methods

### `create`

```java
public static TransitLine create(String code, String name, String color)
```

Static factory method to create a new `TransitLine` instance. This is the only way to instantiate the entity, ensuring that all required fields are provided at creation time.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | Unique identifier for the transit line (max 10 characters) |
| `name` | `String` | Human-readable name of the transit line (max 100 characters) |
| `color` | `String` | Hex color code for the transit line (max 7 characters, e.g., "#RRGGBB") |

**Returns:** A new `TransitLine` instance with the specified values.

**Example usage:**

```java
TransitLine yellowLine = TransitLine.create("BART-YL", "Yellow Line", "#FFD700");
```

## Notes

- The class uses a **protected no-argument constructor** required by JPA for entity instantiation. This constructor should not be called directly by application code.
- All fields are **immutable** after creation — there are no setter methods exposed.
- The `color` field is expected to be a valid 7-character hex color code (including the `#` prefix), though this is not validated at the entity level.
- The entity is mapped to the `transit_lines` table in the database, which should be created as part of the application's schema.
