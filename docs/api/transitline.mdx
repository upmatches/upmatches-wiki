# TransitLine

The `TransitLine` class is a JPA entity that represents a public transit line (e.g., a subway or bus line) within the venue features module. It maps to the `transit_lines` database table and stores basic identifying information such as a unique code, a human-readable name, and a display color.

## Purpose

This entity is used to model transit lines that serve a venue. Each line is uniquely identified by its `code` (e.g., "RED", "BLUE", "L1") and includes a descriptive name and a color value (typically a hex color code) for UI display purposes.

## Annotations

- `@Entity` – Marks this class as a JPA entity.
- `@Table(name = "transit_lines")` – Maps the entity to the `transit_lines` table.
- `@Getter` (Lombok) – Automatically generates getter methods for all fields.
- `@Id` – Designates the `code` field as the primary key.
- `@Column` – Specifies column details such as name, length, and nullability.

## Fields

| Field | Type | Database Column | Constraints | Description |
|-------|------|-----------------|-------------|-------------|
| `code` | `String` | `code` | Primary key, max length 10 | Unique identifier for the transit line (e.g., "RED", "BLUE"). |
| `name` | `String` | `name` | Not null, max length 100 | Human-readable name of the transit line (e.g., "Red Line"). |
| `color` | `String` | `color` | Not null, max length 7 | Hex color code for UI display (e.g., "#FF0000"). |

## Constructor

The class has a **protected no-argument constructor** required by JPA. External instantiation should be done via the static factory method.

## Methods

### `create(String code, String name, String color)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | Unique identifier for the transit line. |
| `name` | `String` | Human-readable name of the transit line. |
| `color` | `String` | Hex color code for UI display (e.g., "#FF0000"). |

**Returns:** `TransitLine` – A new instance with the specified values.

This static factory method creates a fully initialized `TransitLine` entity. It is the preferred way to instantiate new transit lines outside of JPA context.

## Usage Example

```java
TransitLine redLine = TransitLine.create("RED", "Red Line", "#FF0000");
```

## Database Schema

The corresponding `transit_lines` table has the following structure:

| Column | Type | Constraints |
|--------|------|-------------|
| `code` | `VARCHAR(10)` | PRIMARY KEY |
| `name` | `VARCHAR(100)` | NOT NULL |
| `color` | `VARCHAR(7)` | NOT NULL |
