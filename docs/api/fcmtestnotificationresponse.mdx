# FcmTestNotificationResponse

The `FcmTestNotificationResponse` record represents the response payload returned after sending a test notification via Firebase Cloud Messaging (FCM). It encapsulates the key details of the sent notification, including its unique identifier, the recipient email, notification type, and display content.

This record is typically used in test or debugging scenarios to confirm that a notification was successfully dispatched and to inspect its properties.

## Record Components

| Component   | Type             | Description                                                                 |
|-------------|------------------|-----------------------------------------------------------------------------|
| `messageId` | `String`         | The unique identifier assigned by FCM to the sent notification message.     |
| `emailId`   | `String`         | The email address of the recipient user who received the test notification. |
| `type`      | `NotificationType` | The category or type of the notification (e.g., `PUSH`, `IN_APP`).        |
| `title`     | `String`         | The title text displayed in the notification.                               |
| `body`      | `String`         | The body or content text displayed in the notification.                     |
| `badge`     | `Integer`        | The badge count to display on the app icon (nullable).                      |

**Returns:** A new `FcmTestNotificationResponse` instance.

**Example Usage:**

```java

    "fcm_msg_12345",

    "New Match!",
    "You have a new match with Jane.",
    1

```
