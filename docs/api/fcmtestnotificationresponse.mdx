# FcmTestNotificationResponse

## Purpose

The `FcmTestNotificationResponse` record is a data transfer object (DTO) used to represent the response from a Firebase Cloud Messaging (FCM) test notification operation. It encapsulates the key details of a sent test notification, including the FCM message identifier, the recipient's email address, the notification type, and the notification content (title, body, and optional badge count).

This record is typically returned by a service or controller method after successfully sending a test push notification via FCM, allowing callers to inspect the result of the operation.

## Record Definition

```java
public record FcmTestNotificationResponse(
    String messageId,
    String emailId,
    NotificationType type,
    String title,
    String body,
    Integer badge)
```

### Fields

| Field       | Type             | Description                                                                 |
|-------------|------------------|-----------------------------------------------------------------------------|
| `messageId` | `String`         | The unique identifier assigned by FCM for the sent notification message.    |
| `emailId`   | `String`         | The email address of the recipient user to whom the test notification was sent. |
| `type`      | `NotificationType` | The type of notification (e.g., `PROMOTIONAL`, `TRANSACTIONAL`, etc.), as defined by the `NotificationType` enum. |
| `title`     | `String`         | The title of the notification message.                                      |
| `body`      | `String`         | The body/content text of the notification message.                          |
| `badge`     | `Integer`        | An optional badge count to display on the app icon (nullable).              |

## Public Methods

### `of`

```java
public static FcmTestNotificationResponse of(
    String messageId,
    String emailId,
    NotificationType type,
    String title,
    String body,
    Integer badge)
```

Creates a new `FcmTestNotificationResponse` instance with the provided values.

**Parameters:**

| Parameter   | Type             | Description                                                                 |
|-------------|------------------|-----------------------------------------------------------------------------|
| `messageId` | `String`         | The FCM message identifier.                                                |
| `emailId`   | `String`         | The recipient's email address.                                             |
| `type`      | `NotificationType` | The notification type.                                                    |
| `title`     | `String`         | The notification title.                                                    |
| `body`      | `String`         | The notification body.                                                     |
| `badge`     | `Integer`        | The optional badge count (can be `null`).                                  |

**Returns:** `FcmTestNotificationResponse` — a new instance of this record with the specified field values.

## Usage Example

```java
FcmTestNotificationResponse response = FcmTestNotificationResponse.of(
    "fcm_msg_12345",
    "user@example.com",
    NotificationType.PROMOTIONAL,
    "Special Offer!",
    "Check out our latest deals.",
    1
);
```

## Notes

- This record is immutable and thread-safe by design.
- The `badge` field is nullable; a `null` value indicates no badge should be displayed.
- The `NotificationType` enum should be defined elsewhere in the `com.upmatches.app.features.notification.enums` package.
