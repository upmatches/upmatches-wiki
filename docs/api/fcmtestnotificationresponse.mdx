## Purpose

The `FcmTestNotificationResponse` class is a Java record that encapsulates the response details for a Firebase Cloud Messaging (FCM) test notification. It is designed to hold information such as the message ID, email ID, notification type, title, body, and badge count. This class is part of the `com.upmatches.app.features.notification.responses` package and is used to structure the data related to FCM notifications in a concise and immutable manner.

## Public Methods

### `of`

This static method is a factory method that creates a new instance of `FcmTestNotificationResponse`.

| Parameter   | Type                          | Description                                      |
|-------------|-------------------------------|--------------------------------------------------|
| `messageId` | `String`                      | The unique identifier for the message.           |
| `emailId`   | `String`                      | The email ID associated with the notification.   |
| `type`      | `NotificationType`            | The type of the notification.                    |
| `title`     | `String`                      | The title of the notification.                   |
| `body`      | `String`                      | The body content of the notification.            |
| `badge`     | `Integer`                     | The badge count associated with the notification.|

#### Return Type

- `FcmTestNotificationResponse`: Returns a new instance of `FcmTestNotificationResponse` initialized with the provided parameters.
