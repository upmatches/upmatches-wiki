## Purpose of the `GameLookupService` Class

The `GameLookupService` class is a service component in a Java application that provides methods to retrieve various entities such as `Game`, `Activity`, `Venue`, `User`, and `SkillLevel` from their respective repositories. It ensures that the entities are fetched correctly and throws specific exceptions if they are not found. This class is part of a larger application that likely involves managing games, activities, and user interactions.

## Public Methods

The following table documents the public methods available in the `GameLookupService` class, including their parameters and return types.

| Method Name                  | Parameters                                                                 | Return Type | Description                                                                                          |
|------------------------------|----------------------------------------------------------------------------|-------------|------------------------------------------------------------------------------------------------------|
| `findGameOrThrow`            | `UUID id`                                                                  | `Game`      | Finds a game by its ID, ignoring deleted games, and throws `GameNotFoundException` if not found.     |
| `findGameForUpdateOrThrow`   | `UUID id`                                                                  | `Game`      | Finds a game by its ID for update purposes and throws `GameNotFoundException` if not found.          |
| `findGameIgnoringDeletedOrThrow` | `UUID id`                                                             | `Game`      | Finds a game by its ID, including deleted games, and throws `GameNotFoundException` if not found.    |
| `findActivityOrThrow`        | `UUID id`                                                                  | `Activity`  | Finds an activity by its ID and throws `ResourceNotFoundException` if not found.                     |
| `findVenueOrThrow`           | `Long id`                                                                  | `Venue`     | Finds a venue by its ID and throws `ResourceNotFoundException` if not found.                         |
| `findUserOrThrow`            | `UUID id`                                                                  | `User`      | Finds a user by their ID and throws `ResourceNotFoundException` if not found.                        |
| `findUserForUpdateOrThrow`   | `UUID id`                                                                  | `User`      | Finds a user by their ID for update purposes and throws `ResourceNotFoundException` if not found.    |
| `findSkillLevelOrThrow`      | `Long id`                                                                  | `SkillLevel`| Finds a skill level by its ID and throws `ResourceNotFoundException` if not found.                   |

Each method in the `GameLookupService` class is designed to interact with a specific repository to retrieve an entity. If the entity is not found, a custom exception is thrown to indicate the absence of the requested resource. This ensures that the application can handle missing data gracefully and provide meaningful error messages to the user or calling service.
