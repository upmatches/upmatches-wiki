# GameLookupService

The `GameLookupService` class is a Spring service component that provides centralized lookup operations for various entities within the UpMatches application. It implements the `IGameLookupService` interface and serves as a single point of access for retrieving `Game`, `Activity`, `Venue`, `User`, and `SkillLevel` entities from their respective repositories.

This service encapsulates the logic for entity retrieval, including handling of soft-deleted records, pessimistic locking for updates, and consistent error messaging when entities are not found. By centralizing these operations, it promotes code reuse and ensures uniform error handling across the application.

## Constructor

### `GameLookupService(GameRepository, ActivityRepository, VenueRepository, UserRepository, SkillLevelRepository)`

Creates a new instance of `GameLookupService` with the required repository dependencies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameRepository` | `GameRepository` | Repository for Game entity operations |
| `activityRepository` | `ActivityRepository` | Repository for Activity entity operations |
| `venueRepository` | `VenueRepository` | Repository for Venue entity operations |
| `userRepository` | `UserRepository` | Repository for User entity operations |
| `skillLevelRepository` | `SkillLevelRepository` | Repository for SkillLevel entity operations |

## Methods

### `findGameOrThrow(UUID id)`

Retrieves a non-deleted Game by its ID. Throws `GameNotFoundException` if the game does not exist or has been soft-deleted.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game |

**Returns:** `Game` - The found game entity

**Throws:** `GameNotFoundException` - If no active game exists with the given ID

### `findGameForUpdateOrThrow(UUID id)`

Retrieves a Game with a pessimistic lock for update operations. Throws `GameNotFoundException` if the game does not exist.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game |

**Returns:** `Game` - The found game entity with a database lock

**Throws:** `GameNotFoundException` - If no game exists with the given ID

### `findGameIgnoringDeletedOrThrow(UUID id)`

Retrieves a Game by its ID regardless of its deletion status. Throws `GameNotFoundException` if the game does not exist.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game |

**Returns:** `Game` - The found game entity (may be soft-deleted)

**Throws:** `GameNotFoundException` - If no game exists with the given ID
