# GameLookupService

The `GameLookupService` class is a Spring `@Service` component that provides centralized lookup and validation methods for core domain entities within the UpMatches application. It implements the `IGameLookupService` interface and serves as a single point of access for retrieving `Game`, `Activity`, `Venue`, `User`, and `SkillLevel` entities by their identifiers.

This service encapsulates the logic for throwing appropriate exceptions when entities are not found, ensuring consistent error handling across the application. It leverages five different Spring Data JPA repositories to perform database lookups.

## Purpose

- **Centralized Entity Retrieval**: Provides a unified API for looking up domain entities by ID.
- **Consistent Error Handling**: Throws specific exceptions (`GameNotFoundException` or `ResourceNotFoundException`) when entities are not found, with descriptive error messages.
- **Pessimistic Locking Support**: Offers methods that acquire database-level pessimistic locks for concurrent update scenarios.
- **Soft Delete Awareness**: Includes methods that respect soft-delete logic (e.g., `findGameOrThrow` filters out deleted games).

## Public Methods

### Game Lookup Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `findGameOrThrow` | `UUID id` | `Game` | Finds a game by ID where `deletedAt` is null. Throws `GameNotFoundException` if not found. |
| `findGameForUpdateOrThrow` | `UUID id` | `Game` | Finds a game with a pessimistic write lock for update operations. Throws `GameNotFoundException` if not found. |
| `findGameIgnoringDeletedOrThrow` | `UUID id` | `Game` | Finds a game by ID regardless of its deletion status. Throws `GameNotFoundException` if not found. |

### Other Entity Lookup Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `findActivityOrThrow` | `UUID id` | `Activity` | Finds an activity by ID. Throws `ResourceNotFoundException` if not found. |
| `findVenueOrThrow` | `Long id` | `Venue` | Finds a venue by ID. Throws `ResourceNotFoundException` if not found. |
| `findUserOrThrow` | `UUID id` | `User` | Finds a user by ID. Throws `ResourceNotFoundException` if not found. |
| `findUserForUpdateOrThrow` | `UUID id` | `User` | Finds a user with a pessimistic write lock for update operations. Throws `ResourceNotFoundException` if not found. |
| `findSkillLevelOrThrow` | `Long id` | `SkillLevel` | Finds a skill level by ID. Throws `ResourceNotFoundException` if not found. |

## Exception Handling

The service defines two types of exceptions:

- **`GameNotFoundException`**: Thrown when a game entity cannot be found. This is a custom exception specific to game operations.
- **`ResourceNotFoundException`**: Thrown when any other entity (Activity, Venue, User, SkillLevel) cannot be found. This is a shared exception from the `com.upmatches.app.shared.exceptions.types` package.

All error messages follow a consistent pattern using the entity's ID, making debugging and logging straightforward.

## Dependencies

The service depends on the following Spring Data JPA repositories injected via constructor injection:

- `GameRepository`
- `ActivityRepository`
- `VenueRepository`
- `UserRepository`
- `SkillLevelRepository`

## Usage Example

```java
@Service
public class GameService {
    private final GameLookupService lookupService;

    public GameService(GameLookupService lookupService) {
        this.lookupService = lookupService;
    }

    public Game getGameDetails(UUID gameId) {
        // This will throw GameNotFoundException if the game doesn't exist or is soft-deleted
        return lookupService.findGameOrThrow(gameId);
    }

    public User getUserWithLock(UUID userId) {
        // This acquires a pessimistic lock on the user row
        return lookupService.findUserForUpdateOrThrow(userId);
    }
}
```
