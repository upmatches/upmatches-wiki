# GameLookupService

The `GameLookupService` is a Spring `@Service` component that provides centralized lookup and validation methods for core domain entities within the UpMatches application. It acts as a single point of access for retrieving `Game`, `Activity`, `Venue`, `User`, and `SkillLevel` entities, throwing appropriate exceptions when an entity is not found.

This service implements the `IGameLookupService` interface and is declared as `non-sealed`, allowing for future extension if needed.

## Purpose

- **Centralized Entity Lookup**: Provides a consistent pattern for retrieving entities by their identifiers.
- **Error Handling**: Throws specific exceptions (`GameNotFoundException` or `ResourceNotFoundException`) with descriptive messages when entities are not found.
- **Pessimistic Locking Support**: Offers methods that acquire database-level locks for update operations (`findGameForUpdateOrThrow`, `findUserForUpdateOrThrow`).
- **Soft Delete Awareness**: The `findGameOrThrow` method respects soft deletion by filtering out records where `deleted_at` is not null.

## Dependencies

The service depends on five Spring Data JPA repositories injected via constructor injection:

| Repository | Entity |
|------------|--------|
| `GameRepository` | `Game` |
| `ActivityRepository` | `Activity` |
| `VenueRepository` | `Venue` |
| `UserRepository` | `User` |
| `SkillLevelRepository` | `SkillLevel` |

## Public Methods

### Game Lookup Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findGameOrThrow` | `Game` | `UUID id` | Finds a non-deleted game by ID. Throws `GameNotFoundException` if not found or soft-deleted. |
| `findGameForUpdateOrThrow` | `Game` | `UUID id` | Finds a game with a pessimistic write lock. Throws `GameNotFoundException` if not found. |
| `findGameIgnoringDeletedOrThrow` | `Game` | `UUID id` | Finds a game regardless of its deletion status. Throws `GameNotFoundException` if not found. |

### Activity Lookup Method

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findActivityOrThrow` | `Activity` | `UUID id` | Finds an activity by ID. Throws `ResourceNotFoundException` if not found. |

### Venue Lookup Method

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findVenueOrThrow` | `Venue` | `Long id` | Finds a venue by ID. Throws `ResourceNotFoundException` if not found. |

### User Lookup Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findUserOrThrow` | `User` | `UUID id` | Finds a user by ID. Throws `ResourceNotFoundException` if not found. |
| `findUserForUpdateOrThrow` | `User` | `UUID id` | Finds a user with a pessimistic write lock. Throws `ResourceNotFoundException` if not found. |

### Skill Level Lookup Method

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findSkillLevelOrThrow` | `SkillLevel` | `Long id` | Finds a skill level by ID. Throws `ResourceNotFoundException` if not found. |

## Exception Handling

The service uses two custom exception types:

- **`GameNotFoundException`**: Thrown specifically for game-related lookups when the game is not found.
- **`ResourceNotFoundException`**: Thrown for all other entity types (Activity, Venue, User, SkillLevel) when not found.

Each exception message includes the entity type and the requested ID for easier debugging.

## Usage Example

```java
@Service
public class GameManagementService {
    
    private final GameLookupService lookupService;
    
    public GameManagementService(GameLookupService lookupService) {
        this.lookupService = lookupService;
    }
    
    public Game getGameDetails(UUID gameId) {
        // Automatically throws GameNotFoundException if game doesn't exist
        return lookupService.findGameOrThrow(gameId);
    }
    
    public Game updateGame(UUID gameId, GameUpdateRequest request) {
        // Acquires a pessimistic lock for safe concurrent updates
        Game game = lookupService.findGameForUpdateOrThrow(gameId);
        // ... update logic ...
        return game;
    }
}
```
