## Purpose

The `GameLookupService` class is a service component in a Java application that provides methods to retrieve various entities such as `Game`, `Activity`, `Venue`, `User`, and `SkillLevel` from their respective repositories. It ensures that if an entity is not found, a specific exception is thrown, providing a clear error message. This service is part of the application's backend logic, typically used to manage and access game-related data.

## Public Methods

### `findGameOrThrow`

Retrieves a `Game` entity by its ID, ensuring it is not marked as deleted.

| Parameter | Type   | Description          |
|-----------|--------|----------------------|
| `id`      | `UUID` | The ID of the game.  |

| Return Type |
|-------------|
| `Game`      |
