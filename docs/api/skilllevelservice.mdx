# SkillLevelService

The `SkillLevelService` class is a Spring service component that provides business logic for managing skill levels associated with activities. It implements the `ISkillLevelService` interface and handles the retrieval of skill levels for specific activities, ensuring proper validation and error handling.

## Purpose

This service acts as an intermediary between the API layer and the data repositories, encapsulating the logic for:
- Validating activity existence before querying skill levels
- Retrieving skill levels ordered by their sort order
- Converting database entities to response DTOs
- Handling resource not found scenarios

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Repository | Used to verify activity existence |
| `SkillLevelRepository` | Repository | Used to query skill level data |
| `ServiceOperationExecutor` | Utility | Provides standardized operation execution with error handling |

## Public Methods

### `getSkillLevelsByActivity`

Retrieves all skill levels associated with a specific activity, ordered by their sort order.

```java
@Transactional(readOnly = true)
public List<SkillLevelResponse> getSkillLevelsByActivity(UUID activityId)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityId` | `UUID` | The unique identifier of the activity |

**Returns:**

| Type | Description |
|------|-------------|
| `List<SkillLevelResponse>` | A list of skill level response DTOs ordered by sort order |

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown when no activity exists with the provided ID |

**Behavior:**

1. Validates that the activity exists in the database
2. If the activity does not exist, throws a `ResourceNotFoundException` with a descriptive message
3. If the activity exists, queries the `SkillLevelRepository` for all skill levels associated with the activity, ordered by their sort order
4. Maps each skill level entity to a `SkillLevelResponse` DTO
5. Returns the list of skill level responses

## Error Handling

The service uses `ServiceOperationExecutor.execute()` to provide standardized error handling and logging. The operation is wrapped with the `RETRIEVE` operation status, and any `ResourceNotFoundException` thrown during execution is properly propagated.
