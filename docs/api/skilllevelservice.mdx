## Purpose of the Class

The `SkillLevelService` class is a Spring Service component responsible for handling operations related to skill levels within activities. It interacts with the `ActivityRepository` and `SkillLevelRepository` to retrieve skill level data associated with a specific activity. The service ensures that the activity exists before attempting to fetch the skill levels, throwing a `ResourceNotFoundException` if the activity is not found.

## Public Methods

### `getSkillLevelsByActivity`

Retrieves a list of skill levels associated with a specific activity, ordered by their sort order.

| Parameter   | Type   | Description                                      |
|-------------|--------|--------------------------------------------------|
| `activityId`| `UUID` | The unique identifier of the activity.           |

| Return Type                      | Description                                      |
|----------------------------------|--------------------------------------------------|
| `List<SkillLevelResponse>`       | A list of skill level responses for the activity.|

### Exceptions

- **`ResourceNotFoundException`**: Thrown if the activity with the specified ID does not exist.
