# SkillLevelService

The `SkillLevelService` class is a Spring service component that provides business logic for managing skill levels associated with activities. It implements the `ISkillLevelService` interface and handles the retrieval of skill levels for a given activity, ensuring that the activity exists before fetching related skill levels.

## Purpose

This service acts as an intermediary between the API layer and the data repositories. Its primary responsibility is to:
- Validate that an activity exists before querying its skill levels
- Retrieve skill levels ordered by their sort order
- Transform database entities into response DTOs (`SkillLevelResponse`)
- Handle exceptions gracefully using a centralized operation executor

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Repository | Used to verify activity existence |
| `SkillLevelRepository` | Repository | Used to fetch skill levels by activity ID |
| `ServiceOperationExecutor` | Utility | Executes operations with standardized error handling and logging |

## Constructor

### `SkillLevelService(ActivityRepository, SkillLevelRepository)`

Initializes the service with the required repositories.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityRepository` | `ActivityRepository` | Repository for activity data access |
| `skillLevelRepository` | `SkillLevelRepository` | Repository for skill level data access |

## Public Methods

### `getSkillLevelsByActivity(UUID activityId)`

Retrieves all skill levels associated with a specific activity, ordered by their sort order.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityId` | `UUID` | The unique identifier of the activity |

**Returns:**

| Type | Description |
|------|-------------|
| `List<SkillLevelResponse>` | A list of skill level response DTOs ordered by sort order |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | If no activity exists with the provided `activityId` |

**Behavior:**

1. Validates that the activity exists in the database
2. If the activity does not exist, throws a `ResourceNotFoundException` with a descriptive message
3. If the activity exists, queries the `SkillLevelRepository` for all skill levels associated with the activity, ordered by their `sortOrder` field
4. Maps each skill level entity to a `SkillLevelResponse` DTO
5. Returns the list of skill level responses

**Example Usage:**

```java
@Service
public class SomeService {
    private final SkillLevelService skillLevelService;
    
    public SomeService(SkillLevelService skillLevelService) {
        this.skillLevelService = skillLevelService;
    }
    
    public void demonstrate() {
        UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
        List<SkillLevelResponse> skillLevels = skillLevelService.getSkillLevelsByActivity(activityId);
        // Process skill levels...
    }
}
```

## Error Handling

The service uses `ServiceOperationExecutor.execute()` to wrap the business logic. This provides:
- Consistent error handling across all service operations
- Standardized logging for the `RETRIEVE` operation status
- Automatic wrapping of `ResourceNotFoundException` instances

## Transaction Management

The `getSkillLevelsByActivity` method is annotated with `@Transactional(readOnly = true)`, which:
- Optimizes database connections for read-only operations
- Ensures data consistency during the read operation
- Prevents unintended data modifications
