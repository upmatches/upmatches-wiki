## Overview

The `SoftDeleteGameService` class is a Spring service responsible for handling the soft deletion of game entities. This service ensures that a game is marked as deleted without permanently removing it from the database. It also handles authorization checks, event publishing, and auditing of the soft delete operation.

## Public Methods

### `execute`

The `execute` method performs the soft deletion of a game. It verifies the user's authorization, marks the game as deleted, and publishes a notification event.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| `id`      | `UUID` | The unique identifier of the game to be soft deleted. |

| Return Type | Description |
|-------------|-------------|
| `void`      | This method does not return any value. |

## Detailed Description

- **Authorization**: The method checks if the current user is authorized to delete the game by asserting that the user is the organizer of the game.
- **Game Lookup**: It retrieves the game entity using the provided game ID. If the game is not found, a `ResourceNotFoundException` is thrown.
- **Soft Deletion**: The game is marked as canceled and deleted, but not removed from the database.
- **Event Publishing**: After marking the game as deleted, a `GameNotificationEvent` is published to notify other parts of the system about the deletion.
- **Auditing**: The operation is auditable, with the action "GAME_SOFT_DELETED" being recorded along with the game ID.

This service is crucial for maintaining data integrity and ensuring that game deletions are handled gracefully within the application.
