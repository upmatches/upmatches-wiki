# SoftDeleteGameService

The `SoftDeleteGameService` class is a Spring service responsible for performing a soft delete operation on a `Game` entity. Instead of permanently removing a game from the database, this service marks the game as deleted, allowing for potential recovery or audit trails. It ensures that only the authorized organizer of the game can perform this action and publishes a notification event upon successful deletion.

## Purpose

- **Soft Deletion**: Marks a game as deleted without physically removing it from the database.
- **Authorization**: Verifies that the authenticated user is the organizer of the game.
- **Auditing**: Logs the soft delete action using the `@Auditable` annotation.
- **Notification**: Publishes a `GameNotificationEvent` to notify other parts of the system about the deletion.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `GameRepository` | Repository for persisting game entities. |
| `IAuthenticatedUserResolver` | Resolves the currently authenticated user's ID. |
| `IGameLookupService` | Service for looking up games by ID. |
| `IGameAuthorizationService` | Service for checking if the user is the game organizer. |
| `ApplicationEventPublisher` | Publishes application events for notification. |

## Public Methods

### `execute(UUID id)`

Performs the soft delete operation on the game identified by the given ID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to be soft deleted. |

**Return Type:** `void`

**Behavior:**

1. Retrieves the authenticated user's ID.
2. Looks up the game by its ID; throws `ResourceNotFoundException` if not found.
3. Verifies that the authenticated user is the organizer of the game.
4. Calls `game.cancel()` and `game.markDeleted()` to update the game's state.
5. Persists the updated game entity using `ServiceOperationExecutor`.
6. Publishes a `GameNotificationEvent` with the game ID, user ID, notification type `GAME_REMOVED`, and the game's activity name (if available).

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown if the game is not found or if the save operation fails. |
| `AuthorizationException` | Thrown if the user is not the organizer of the game. |

## Usage Example

```java
@Autowired
private SoftDeleteGameService softDeleteGameService;

public void deleteGame(UUID gameId) {
    softDeleteGameService.execute(gameId);
}
```

## Notes

- The service is annotated with `@Service` and `@Transactional`, ensuring that the operation is executed within a database transaction.
- The `@Auditable` annotation logs the soft delete action with the resource type `GAME` and the resource ID extracted from the method argument.
- The `ServiceOperationExecutor` handles the save operation and wraps any exceptions into a `ResourceNotFoundException` if the operation fails.
