# IHardDeleteGameService Interface

## Purpose

The `IHardDeleteGameService` interface defines a contract for permanently deleting a game entity from the system. It follows a sealed interface pattern, restricting implementation to the `HardDeleteGameService` class only. This design ensures that the hard deletion logic is centralized and cannot be extended by unauthorized implementations.

## Interface Definition

```java
public sealed interface IHardDeleteGameService permits HardDeleteGameService
```

The interface is declared as `sealed`, meaning only the specified class (`HardDeleteGameService`) is allowed to implement it. This provides compile-time safety and enforces a controlled hierarchy for the deletion operation.

## Method Summary

| Method | Description |
|--------|-------------|
| `void execute(UUID id)` | Permanently deletes a game entity identified by the provided UUID. |

## Method Details

### `execute(UUID id)`

- **Purpose**: Initiates the hard deletion process for a game entity.
- **Parameter**: `id` - A `UUID` representing the unique identifier of the game to be permanently removed.
- **Return Type**: `void` - The method does not return a value.
- **Behavior**: Implementations should perform the actual deletion logic, which typically involves removing the game record from the database or storage system without the possibility of recovery.

## Usage Example

```java
IHardDeleteGameService hardDeleteService = new HardDeleteGameService();
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
hardDeleteService.execute(gameId);
```

## Implementation Notes

- The sealed interface pattern ensures that only `HardDeleteGameService` can implement this interface, preventing unauthorized or accidental implementations.
- The `execute` method should handle cases where the game ID does not exist, typically by throwing an appropriate exception (e.g., `GameNotFoundException`).
- Implementations should ensure transactional integrity to prevent partial deletions.
