# IHardDeleteGameService Interface

The `IHardDeleteGameService` interface defines a contract for permanently deleting a game entity from the system. Unlike soft deletion (which typically marks a record as inactive), this interface represents a hard delete operation that completely removes the game data.

This interface is part of the game management feature within the application's service layer and follows the command pattern by exposing a single `execute` method.

## Sealed Interface

This interface is declared as `sealed`, meaning only explicitly permitted classes can implement it. The only permitted implementation is `HardDeleteGameService`. This design ensures controlled extension and maintains a strict hierarchy for hard deletion logic.

## Method Summary

| Method | Description |
|--------|-------------|
| `void execute(UUID id)` | Permanently deletes a game identified by the provided UUID |

## Method Details

### `execute(UUID id)`

```java
void execute(UUID id)
```

Permanently removes the game entity with the specified unique identifier from the data store. This operation is irreversible and should be used with caution.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to be permanently deleted |

**Returns:** `void`

**Exceptions:** Implementations may throw runtime exceptions (e.g., `EntityNotFoundException` if the game does not exist, or `DataAccessException` for persistence errors).

## Usage Example

```java
@Autowired
private IHardDeleteGameService hardDeleteGameService;

public void removeGame(UUID gameId) {
    hardDeleteGameService.execute(gameId);
}
```

## Implementation Notes

- The `HardDeleteGameService` class is the sole permitted implementation
- Ensure proper authorization checks are performed before calling this service
- Consider cascading deletes for related entities (e.g., game sessions, player statistics)
- Implement transaction management to maintain data integrity
- Log deletion events for audit purposes
