# IHardDeleteGameService

The `IHardDeleteGameService` interface defines a contract for permanently deleting a game entity from the system. It is a **sealed interface**, meaning only the explicitly permitted class (`HardDeleteGameService`) can implement it. This design enforces a strict, single-implementation pattern for the hard-delete operation.

## Purpose

- Provides a clear, type-safe contract for hard-deleting a game by its unique identifier.
- Uses Java's sealed interface feature to restrict implementation to a single service class, ensuring consistency and preventing unintended extensions.
- Follows the command pattern, where the `execute` method encapsulates the entire deletion operation.

## Interface Definition

```java
public sealed interface IHardDeleteGameService permits HardDeleteGameService {
    void execute(UUID id);
}
```

## Method Summary

| Method | Description |
|--------|-------------|
| `void execute(UUID id)` | Permanently deletes the game identified by the given UUID. |

## Method Details

### `execute(UUID id)`

- **Purpose**: Initiates the hard-delete process for a specific game.
- **Parameter**: `id` – The unique identifier of the game to be permanently removed.
- **Return Type**: `void` – The method performs the deletion but does not return a value.
- **Behavior**: The implementing class (`HardDeleteGameService`) is responsible for the actual deletion logic, which may include database removal, cache invalidation, and cleanup of associated resources.

## Usage Example

```java
IHardDeleteGameService hardDeleteService = new HardDeleteGameService();
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
hardDeleteService.execute(gameId);
```

## Implementation Notes

- The interface is **sealed**, so only `HardDeleteGameService` can implement it. This prevents accidental or unauthorized implementations.
- The `execute` method is intentionally simple, focusing on the single responsibility of hard deletion.
- Consider adding exception handling in the implementing class to manage cases where the game ID does not exist or deletion fails.

## Related Components

- **HardDeleteGameService**: The sole permitted implementation that contains the actual deletion logic.
- **UUID**: Standard Java class used to uniquely identify games in the system.
