# AppleLoginService

The `AppleLoginService` class is a Spring service that handles Apple Sign-In authentication for the UpMatches application. It implements the `IAppleLoginService` interface and provides a complete authentication flow including token verification, user creation/lookup, and JWT token generation.

## Purpose

This service manages the entire Apple Sign-In authentication process:
- Verifies Apple identity tokens
- Matches token claims with user-provided identifiers
- Creates new users or retrieves existing ones based on Apple UUID
- Generates JWT access and refresh tokens
- Stores refresh tokens for session management

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IAppleAuthService` | Service | Handles Apple identity token verification |
| `UserRepository` | Repository | Data access for user entities |
| `IJwtTokenService` | Service | Generates JWT access tokens |
| `IRefreshTokenStore` | Store | Manages refresh token persistence |

## Public Methods

### `execute`

```java
@Transactional
public AppleLoginResponse execute(final AppleLoginRequest request)
```

Executes the complete Apple Sign-In authentication flow.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AppleLoginRequest` | Contains the identity token, user identifier, display name, and email |

**Returns:**

| Type | Description |
|------|-------------|
| `AppleLoginResponse` | Contains access token, refresh token, expiration timestamp, and new user flag |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `AuthenticationException` | Token verification fails or user identifier mismatch |

**Flow:**
1. Verifies the Apple identity token
2. Validates that the token's subject matches the provided user identifier
3. Finds or creates a user based on the Apple UUID
4. Generates an access token with the user's ID and Apple UUID
5. Generates and stores a refresh token
6. Returns the authentication response

## Private Methods

### `verifyToken`

```java
private AppleVerifiedClaims verifyToken(final String identityToken)
```

Verifies the Apple identity token and extracts claims.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `identityToken` | `String` | The Apple identity token to verify |

**Returns:**

| Type | Description |
|------|-------------|
| `AppleVerifiedClaims` | Contains verified claims including subject, email, and other token data |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `AuthenticationException` | Token verification fails or payload is invalid |

### `findOrCreateUser`

```java
private UpsertResult findOrCreateUser(final String appleUuid, final String displayName, final String email)
```

Finds an existing user by Apple UUID or creates a new one.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `appleUuid` | `String` | Apple's unique identifier for the user |
| `displayName` | `String` | User's display name from Apple |
| `email` | `String` | User's email from Apple |

**Returns:**

| Type | Description |
|------|-------------|
| `UpsertResult` | Contains the user entity and a boolean indicating if the user is new |

**Behavior:**
- If user exists: updates email, records login, returns existing user
- If user doesn't exist: creates new user, handles concurrent creation race conditions
- On `DataIntegrityViolationException`: attempts to find existing user (handles race condition)

| Field | Type | Description |

## Error Handling

The service handles several error scenarios:

| Scenario | Error Message | Log Level |
|----------|---------------|-----------|
| Invalid token payload | "The Apple identity token payload is invalid." | WARN |
| Token verification failure | "Apple authentication failed. Please try again." | WARN |
| User identifier mismatch | "Apple identity token subject does not match the supplied user identifier." | ERROR |
| Unable to create/find user | "Unable to create or find user." | ERROR |

## Thread Safety

The service uses `@Transactional` annotation to ensure atomicity during user creation and update operations. The `DataIntegrityViolationException` handling provides protection against concurrent user creation attempts.
