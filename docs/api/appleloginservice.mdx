## Overview

The `AppleLoginService` class is a part of the authentication feature in the application, specifically handling user authentication via Apple. It implements the `IAppleLoginService` interface and provides functionality to verify Apple identity tokens, manage user creation or retrieval, and generate authentication tokens.

## Public Methods

### `execute`

Executes the Apple login process by verifying the identity token, ensuring the user identifier matches, and handling user creation or retrieval. It generates access and refresh tokens for authenticated users.

| Parameter | Type                  | Description                          |
|-----------|-----------------------|--------------------------------------|
| request   | `AppleLoginRequest`   | Contains the identity token and user identifier. |

| Return Type            | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| `AppleLoginResponse`   | Contains the access token, refresh token, token expiration, and user status. |

## Method Details

### `execute`

- **Purpose**: This method is responsible for handling the login process using Apple's authentication system. It verifies the identity token, checks for user existence, and generates necessary tokens for session management.
- **Parameters**:
  - `request`: An instance of `AppleLoginRequest` which includes the identity token and user identifier.
- **Returns**: An instance of `AppleLoginResponse` containing the access token, refresh token, expiration time, and a flag indicating if the user is new.

### Private Methods

The class also contains private methods that are not part of the public API but are crucial for its internal operations:

- **`verifyToken`**: Verifies the Apple identity token and returns the verified claims.
- **`findOrCreateUser`**: Finds an existing user by Apple UUID or creates a new user if none exists. It handles potential concurrent user creation scenarios.

These methods ensure the integrity and security of the authentication process by interacting with the `IAppleAuthService`, `UserRepository`, `IJwtTokenService`, and `IRefreshTokenStore` components.
