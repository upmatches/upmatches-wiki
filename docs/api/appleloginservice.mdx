# AppleLoginService

The `AppleLoginService` class is a Spring service that handles Apple Sign-In authentication for the UpMatches application. It implements the `IAppleLoginService` interface and provides a complete authentication flow: verifying Apple identity tokens, creating or finding users, and generating JWT access and refresh tokens.

## Purpose

This service manages the entire Apple authentication lifecycle:
- Verifies the integrity and validity of Apple identity tokens
- Ensures the token's subject matches the provided user identifier
- Creates new user accounts or retrieves existing ones based on Apple UUID
- Generates JWT access tokens and refresh tokens for authenticated sessions
- Handles concurrent user creation scenarios gracefully

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IAppleAuthService` | Service | Handles Apple identity token verification |
| `UserRepository` | Repository | Data access for user entities |
| `IJwtTokenService` | Service | Generates JWT access tokens |
| `IRefreshTokenStore` | Store | Manages refresh token persistence |

## Public Methods

### `execute`

```java
@Transactional
public AppleLoginResponse execute(final AppleLoginRequest request)
```

The main entry point for Apple login authentication. This method orchestrates the entire login flow.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AppleLoginRequest` | Contains the identity token, user identifier, display name, and email |

**Returns:**

| Type | Description |
|------|-------------|
| `AppleLoginResponse` | Contains the access token, refresh token, expiration timestamp, and whether the user is new |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `AuthenticationException` | Token verification fails, user identifier mismatch, or user creation/find fails |

**Flow:**
1. Verifies the Apple identity token
2. Validates that the token's subject matches the provided user identifier
3. Finds or creates a user account
4. Generates an access token
5. Generates and stores a refresh token
6. Returns the authentication response

## Private Methods

### `verifyToken`

```java
private AppleVerifiedClaims verifyToken(final String identityToken)
```

Verifies the Apple identity token and extracts claims.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `identityToken` | `String` | The Apple identity token to verify |

**Returns:**

| Type | Description |
|------|-------------|
| `AppleVerifiedClaims` | Contains verified claims including subject (`sub`), email, and other Apple-provided data |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `AuthenticationException` | Token verification fails or payload is invalid |

### `findOrCreateUser`

```java
private UpsertResult findOrCreateUser(final String appleUuid, final String displayName, final String email)
```

Finds an existing user by Apple UUID or creates a new one.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `appleUuid` | `String` | Apple's unique identifier for the user |
| `displayName` | `String` | User's display name from Apple |
| `email` | `String` | User's email from Apple |

**Returns:**

| Type | Description |
|------|-------------|
| `UpsertResult` | Contains the user entity and a boolean indicating if the user is new |

**Behavior:**
- If user exists: updates email, records login, returns existing user
- If user doesn't exist: creates new user, handles concurrent creation via `DataIntegrityViolationException`

## Internal Records

### `UpsertResult`

```java
private record UpsertResult(User user, Boolean isNewUser)
```

A simple record to encapsulate the result of user creation or lookup.

| Field | Type | Description |
|-------|------|-------------|
| `user` | `User` | The user entity |
| `isNewUser` | `Boolean` | `true` if the user was just created, `false` if existing |

## Error Handling

The service handles several error scenarios:

| Scenario | Exception | Message |
|----------|-----------|---------|
| Invalid token payload | `AuthenticationException` | "The Apple identity token payload is invalid." |
| Token verification failure | `AuthenticationException` | "Apple authentication failed. Please try again." |
| User identifier mismatch | `AuthenticationException` | "Apple identity token subject does not match the supplied user identifier." |
| Unable to create/find user | `AuthenticationException` | "Unable to create or find user." |

## Logging

The service uses SLF4J logging with the following log levels:

| Log Level | Message | Purpose |
|-----------|---------|---------|
| WARN | "Apple identity token verification failed" | Token verification errors |
| INFO | "Created new user {id} from Apple" | New user registration |
| INFO | "Existing user {id} logged in via Apple" | Existing user login |
| INFO | "Concurrent Apple user creation detected, looking up existing user" | Race condition handling |
