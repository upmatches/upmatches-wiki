# GameVisibility Enum

The `GameVisibility` enum defines the visibility options available for a game within the application. It is used to control whether a game is accessible to all users or restricted to a specific group.

## Package

`com.upmatches.app.features.game.enums`

## Enum Values

| Value | Description |
|-------|-------------|
| `PUBLIC` | The game is visible and accessible to all users. |
| `PRIVATE` | The game is only visible and accessible to invited or authorized users. |

## Usage

This enum is typically used in game configuration settings, matchmaking logic, or user interface components to determine how a game should be displayed and who can join it.

### Example

```java
GameVisibility visibility = GameVisibility.PUBLIC;

if (visibility == GameVisibility.PRIVATE) {
    // Handle private game logic
}
```
