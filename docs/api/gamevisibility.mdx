## Purpose

The `GameVisibility` enum is part of the `com.upmatches.app.features.game.enums` package. It is used to define the visibility status of a game within the application. This enum provides two constants, `PUBLIC` and `PRIVATE`, which can be used to specify whether a game is accessible to everyone or restricted to certain users.

## Enum Constants

The `GameVisibility` enum contains the following constants:

| Constant | Description |
|----------|-------------|
| `PUBLIC` | Indicates that the game is visible to all users. |
| `PRIVATE` | Indicates that the game is restricted and only visible to certain users. |

## Usage

This enum can be used in the application to control and check the visibility status of games. By using these constants, developers can easily manage game accessibility and enforce visibility rules within the application logic.
