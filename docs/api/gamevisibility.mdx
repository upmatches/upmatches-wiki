# GameVisibility Enum

The `GameVisibility` enum defines the visibility options available for a game within the application. It is used to control whether a game is publicly accessible or restricted to a private audience.

## Package

`com.upmatches.app.features.game.enums`

## Enum Values

| Value | Description |
|-------|-------------|
| `PUBLIC` | The game is visible and accessible to all users. |
| `PRIVATE` | The game is hidden from public view and only accessible to invited or authorized users. |

## Usage

This enum is typically used as a field in game-related entities or data transfer objects (DTOs) to specify the visibility level of a game. For example:

```java
GameVisibility visibility = GameVisibility.PUBLIC;
```
