## Overview

The `GameVisibility` enum is part of the `com.upmatches.app.features.game.enums` package. It is used to define the visibility status of a game within the application. This enum provides a simple way to manage and understand the visibility settings by offering predefined constants.

## Enum Constants

The `GameVisibility` enum contains the following constants:

| Constant | Description                                                                 |
|----------|-----------------------------------------------------------------------------|
| PUBLIC   | Indicates that the game is visible to all users.                            |
| PRIVATE  | Indicates that the game is only visible to a restricted set of users.       |

## Usage

The `GameVisibility` enum can be used to set or check the visibility status of a game. By using these constants, developers can ensure consistency and clarity when dealing with game visibility settings throughout the application.
