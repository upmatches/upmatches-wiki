# GameVisibility Enum

The `GameVisibility` enum is part of the `com.upmatches.app.features.game.enums` package. It defines the visibility options for a game within the UpMatches application.

## Purpose

This enum is used to control whether a game is publicly visible to all users or restricted to a private group. It provides a simple, type-safe way to manage game visibility settings throughout the application.

## Enum Values

| Value | Description |
|-------|-------------|
| `PUBLIC` | The game is visible to all users of the application. |
| `PRIVATE` | The game is only visible to invited or authorized users. |

## Usage

The `GameVisibility` enum is typically used in game creation, editing, and display logic to determine how a game should be presented to users. For example:

- When creating a new game, the user can select between `PUBLIC` and `PRIVATE` visibility.
- When displaying a list of games, only `PUBLIC` games are shown to unauthenticated users.
- When a user views their own games, both `PUBLIC` and `PRIVATE` games are shown.

## Example

```java
GameVisibility visibility = GameVisibility.PUBLIC;

if (visibility == GameVisibility.PUBLIC) {
    // Show game to all users
} else {
    // Restrict access to authorized users only
}
```
