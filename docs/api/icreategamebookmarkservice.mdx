# ICreateGameBookmarkService

The `ICreateGameBookmarkService` is a **sealed interface** that defines the contract for creating a game bookmark within the UpMatches application. It serves as the abstraction layer for the bookmark creation use case, ensuring that only the permitted implementation (`CreateGameBookmarkService`) can fulfill this contract.

## Purpose

This interface encapsulates the operation of bookmarking a game by its unique identifier (`UUID`). By using a sealed interface, the design enforces a controlled hierarchy, allowing only specific implementations to handle the bookmark creation logic. This promotes type safety and maintainability in the codebase.

## Method Summary

| Method | Description |
|--------|-------------|
| `execute(UUID gameId)` | Creates a bookmark for the specified game and returns the corresponding response. |

## Method Details

### `execute`

```java
GameBookmarkResponse execute(UUID gameId)
```

Creates a game bookmark for the given game ID.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game to be bookmarked. Must not be null. |

**Returns:**

| Type | Description |
|------|-------------|
| `GameBookmarkResponse` | The response object containing the result of the bookmark creation operation. |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `IllegalArgumentException` | If `gameId` is null. |
| `GameNotFoundException` | If no game exists with the provided ID. |
| `DuplicateBookmarkException` | If the game is already bookmarked by the current user. |

## Usage Example

```java
// Assuming the service is injected via dependency injection
ICreateGameBookmarkService bookmarkService = new CreateGameBookmarkService(/* dependencies */);

UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
GameBookmarkResponse response = bookmarkService.execute(gameId);
```

## Implementation Notes

- The interface is sealed, meaning only `CreateGameBookmarkService` is allowed to implement it.
- The `execute` method is the single entry point for the bookmark creation operation.
- The returned `GameBookmarkResponse` typically contains information such as the bookmark ID, creation timestamp, and associated game details.
