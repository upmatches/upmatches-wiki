# ICreateGameBookmarkService

## Purpose

The `ICreateGameBookmarkService` interface defines the contract for creating a game bookmark within the application. It is a sealed interface, meaning only the explicitly permitted class (`CreateGameBookmarkService`) can implement it. This design enforces a controlled implementation hierarchy and ensures that the bookmark creation logic is centralized and consistent.

## Interface Definition

```java
public sealed interface ICreateGameBookmarkService permits CreateGameBookmarkService {
    GameBookmarkResponse execute(UUID gameId);
}
```

## Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `execute` | `GameBookmarkResponse` | `UUID gameId` | Creates a bookmark for the specified game and returns the response containing bookmark details. |

## Parameters

- **gameId** (`UUID`): The unique identifier of the game to be bookmarked. This is a required parameter and must not be null.

## Return Value

The method returns a `GameBookmarkResponse` object, which contains the details of the newly created bookmark. The exact structure of this response is defined in the `GameBookmarkResponse` class.

## Usage Example

```java
// Assuming you have an instance of CreateGameBookmarkService
ICreateGameBookmarkService bookmarkService = new CreateGameBookmarkService();

// Create a bookmark for a specific game
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
GameBookmarkResponse response = bookmarkService.execute(gameId);
```

## Implementation Notes

- The interface is sealed, so only `CreateGameBookmarkService` can implement it.
- The `execute` method is the single entry point for creating a game bookmark.
- The `gameId` parameter should correspond to an existing game in the system.
- The implementation should handle validation, persistence, and response generation.
