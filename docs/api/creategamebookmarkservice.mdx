# CreateGameBookmarkService

## Purpose

The `CreateGameBookmarkService` class is a Spring service responsible for creating a bookmark for a game by an authenticated user. It validates that the user has not already bookmarked the game, ensures the user is authorized to view the game, and persists the bookmark. Upon successful creation, it returns a response containing the bookmark details and the current count of active participants for the game.

## Class Details

| Aspect | Description |
|--------|-------------|
| **Package** | `com.upmatches.app.features.game.services` |
| **Type** | `non-sealed class` implementing `ICreateGameBookmarkService` |
| **Annotations** | `@Service`, `@Transactional` |
| **Dependencies** | `GameBookmarkRepository`, `GameParticipantRepository`, `IAuthenticatedUserResolver`, `IGameLookupService`, `IGameAuthorizationService` |

## Public Methods

### `execute(UUID gameId)`

Creates a bookmark for the specified game on behalf of the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game to bookmark |

| Returns | Type | Description |
|---------|------|-------------|
| **Success** | `GameBookmarkResponse` | Contains the created bookmark details and the current count of active participants |
| **Failure** | `AlreadyBookmarkedException` | Thrown if the user has already bookmarked the specified game |
| **Failure** | `ResourceNotFoundException` | Thrown if the game or user is not found |

#### Behavior

1. **Resolve User**: Retrieves the authenticated user's ID via `userResolver.requireUserId()`.
2. **Lookup Game**: Fetches the game entity using `lookupService.findGameOrThrow(gameId)`. Throws `ResourceNotFoundException` if the game does not exist.
3. **Authorization Check**: Verifies the user is authorized to view the game via `authorizationService.assertCanViewGame(game, userId)`.
4. **Duplicate Check**: Checks if the user has already bookmarked the game using `bookmarkRepository.existsByGameIdAndUserId(gameId, userId)`. If true, throws `AlreadyBookmarkedException`.
5. **Lookup User**: Retrieves the user entity via `lookupService.findUserOrThrow(userId)`.
6. **Create Bookmark**: Creates a new `GameBookmark` entity using `GameBookmark.create(game, user)`.
7. **Persist**: Saves the bookmark using `ServiceOperationExecutor.execute()` with the `SAVE` operation status.
8. **Count Participants**: Queries the count of active participants for the game using `participantRepository.countByGameIdAndStatus(gameId, ParticipantStatus.ACTIVE)`.
9. **Return Response**: Constructs and returns a `GameBookmarkResponse` from the saved bookmark and participant count.

## Exceptions

| Exception | Condition |
|-----------|-----------|
| `AlreadyBookmarkedException` | The user has already bookmarked the specified game |
| `ResourceNotFoundException` | The game or user cannot be found in the system |

## Usage Example

```java
// Inject the service
private final CreateGameBookmarkService createGameBookmarkService;

// Execute bookmark creation
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
GameBookmarkResponse response = createGameBookmarkService.execute(gameId);
// response contains bookmark details and participant count
```
