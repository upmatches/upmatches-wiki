# Auditing Configuration

The `AuditingConfiguration` class provides a Spring Boot configuration for JPA auditing. It defines how the system determines the current user (auditor) for automatic population of `createdBy` and `lastModifiedBy` fields in JPA entities.

## Purpose

This configuration enables automatic auditing of entity changes by resolving the current user from the security context. It handles three scenarios:

1. **Unauthenticated requests** – Falls back to a default system auditor
2. **OAuth2/JWT authenticated users** – Extracts the subject claim from the JWT token
3. **Standard authenticated users** – Uses the authentication name

## Configuration Details

The class uses Spring's `@EnableJpaAuditing` annotation with a reference to the `auditorAware` bean. This bean implements `AuditorAware<String>` and is automatically used by Spring Data JPA to populate auditing fields.

## Public Methods

### `auditorAware()`

| Property | Description |
|----------|-------------|
| **Return Type** | `AuditorAware<String>` |
| **Description** | Creates a bean that provides the current auditor (user) for JPA auditing. The implementation resolves the user from the security context with fallback logic. |

#### Resolution Logic

The method follows this priority order:

1. **No authentication or anonymous user** – Returns `"system"` as the default auditor
2. **JWT authenticated user** – Extracts the JWT subject claim; falls back to `"system"` if blank or null
3. **Standard authenticated user** – Uses the authentication name; falls back to `"system"` if blank or null

## Usage Example

To use this auditing configuration in your entities:

```java
@Entity
@EntityListeners(AuditingEntityListener.class)
public class YourEntity {
    
    @CreatedBy
    @Column(updatable = false)
    private String createdBy;
    
    @LastModifiedBy
    private String lastModifiedBy;
    
    // getters and setters
}
```

## Dependencies

- Spring Context (`@Configuration`, `@Bean`)
- Spring Data JPA (`@EnableJpaAuditing`, `AuditorAware`)
- Spring Security (`SecurityContextHolder`, `Authentication`)
- Spring Security OAuth2 JWT (`Jwt`)

## Notes

- The default auditor value is `"system"` for unauthenticated or anonymous requests
- The constant `ANONYMOUS_PRINCIPAL` (`"anonymousUser"`) is used to detect Spring Security's anonymous authentication
- The JWT subject claim is extracted using `jwt.getSubject()`
