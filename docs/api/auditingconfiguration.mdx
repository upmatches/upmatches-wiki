# Auditing Configuration

The `AuditingConfiguration` class provides Spring Data JPA auditing capabilities for the application. It configures an `AuditorAware` bean that automatically populates auditing fields (such as `createdBy`, `lastModifiedBy`) in JPA entities with the current user's identity.

## Purpose

This configuration ensures that every database entity with auditing annotations (like `@CreatedBy` and `@LastModifiedBy`) automatically captures who created or modified the record. The class handles multiple authentication scenarios:

- **Authenticated users**: Extracts the username from the security context
- **JWT-authenticated users**: Uses the JWT subject claim
- **Anonymous/unauthenticated requests**: Falls back to a system default auditor
- **Null or blank usernames**: Falls back to the system default auditor

## Configuration Details

| Property | Value |
|----------|-------|
| Package | `com.upmatches.app.shared.database.configurations` |
| Annotations | `@Configuration`, `@EnableJpaAuditing` |
| Auditor Reference | `auditorAware` |

## Public Methods

### `auditorAware()`

Returns an `AuditorAware<String>` bean that determines the current auditor for JPA auditing.

| Aspect | Details |
|--------|---------|
| **Return Type** | `AuditorAware<String>` |
| **Bean Name** | `auditorAware` |
| **Scope** | Singleton (default Spring bean scope) |

#### Behavior

The method implements the following logic to determine the current auditor:

| Condition | Result |
|-----------|--------|
| No authentication present | Returns `"system"` |
| Authentication is not authenticated | Returns `"system"` |
| Principal is `"anonymousUser"` | Returns `"system"` |
| Principal is a `Jwt` instance | Returns JWT subject if non-blank, otherwise `"system"` |
| Authentication name is non-null and non-blank | Returns the authentication name |
| Authentication name is null or blank | Returns `"system"` |

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `DEFAULT_AUDITOR` | `"system"` | Default auditor used when no authenticated user is available |
| `ANONYMOUS_PRINCIPAL` | `"anonymousUser"` | Principal identifier for unauthenticated requests |

## Usage Example

To use this auditing configuration in your JPA entities:

```java
@Entity
@EntityListeners(AuditingEntityListener.class)
public class UserProfile {
    
    @CreatedBy
    @Column(updatable = false)
    private String createdBy;
    
    @LastModifiedBy
    private String lastModifiedBy;
    
    // getters and setters
}
```

## Dependencies

- Spring Context (`@Configuration`, `@Bean`)
- Spring Data JPA (`@EnableJpaAuditing`, `AuditorAware`)
- Spring Security (`SecurityContextHolder`, `Authentication`)
- Spring Security OAuth2 JWT (`Jwt`)
