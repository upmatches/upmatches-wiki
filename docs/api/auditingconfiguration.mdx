# Auditing Configuration

The `AuditingConfiguration` class provides a Spring Boot configuration for JPA auditing. It defines a custom `AuditorAware` bean that automatically populates audit fields (such as `createdBy` and `lastModifiedBy`) in your JPA entities with the current authenticated user's identity.

## Purpose

This configuration enables automatic tracking of who creates or modifies entities in your application. It integrates with Spring Security to extract the authenticated user's identity from the security context and handles various authentication scenarios:

- **Authenticated users**: Extracts the username or JWT subject
- **Anonymous users**: Falls back to a default system auditor
- **JWT-based authentication**: Extracts the subject claim from the JWT token
- **Null or blank names**: Falls back to the default system auditor

## Configuration

The class uses Spring's `@Configuration` and `@EnableJpaAuditing` annotations to activate JPA auditing. The `auditorAwareRef` attribute points to the custom `AuditorAware` bean defined in this class.

## Public Methods

### `auditorAware()`

Creates a bean that provides the current auditor (user) for JPA auditing.

| Aspect | Details |
|--------|---------|
| **Return Type** | `AuditorAware<String>` |
| **Bean Name** | `auditorAware` |
| **Description** | Returns an `AuditorAware` implementation that resolves the current user from the security context |

#### Behavior

The method implements the following logic to determine the current auditor:

| Condition | Result |
|-----------|--------|
| No authentication present | Returns `"system"` |
| User is not authenticated | Returns `"system"` |
| Principal is `"anonymousUser"` | Returns `"system"` |
| Principal is a `Jwt` instance | Returns the JWT subject (or `"system"` if null/blank) |
| Authenticated user with a name | Returns the user's name |
| Authenticated user with null/blank name | Returns `"system"` |

## Usage Example

To use this auditing configuration in your JPA entities:

```java
@Entity
@EntityListeners(AuditingEntityListener.class)
public class YourEntity {
    
    @CreatedBy
    @Column(updatable = false)
    private String createdBy;
    
    @LastModifiedBy
    private String lastModifiedBy;
    
    // getters and setters
}
```

The `createdBy` and `lastModifiedBy` fields will be automatically populated with the current user's identity when entities are created or modified.

## Dependencies

This configuration requires the following dependencies in your project:

- Spring Boot with Spring Data JPA
- Spring Security (for authentication context)
- Spring Security OAuth2 Resource Server (for JWT support)
