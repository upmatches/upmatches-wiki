# JwtProperties

The `JwtProperties` class is a Spring Boot configuration properties record that manages JWT (JSON Web Token) settings for the UpMatches application. It provides a centralized and type-safe way to configure JWT-related parameters such as issuer, audience, token expiration times, and callback URLs.

## Purpose

This record serves as a configuration holder for JWT authentication settings. It is annotated with `@ConfigurationProperties(prefix = "app.jwt")`, allowing Spring Boot to automatically bind properties from application configuration files (e.g., `application.yml` or `application.properties`) that start with the `app.jwt` prefix.

## Features

- **Immutable Configuration**: As a Java record, all fields are final and immutable after construction.
- **Input Validation**: The compact constructor validates and sanitizes input values, providing sensible defaults where appropriate.
- **URI Validation**: The `frontendCallbackUrl` is validated to ensure it is a properly formatted URI.
- **Default Values**: Missing or invalid values for `issuer`, `audience`, and `mobileCallbackScheme` default to `"upmatches"`. Token expiry values default to 15 minutes for access tokens and 7 days for refresh tokens.

## Constructor Parameters

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| `issuer` | `String` | The JWT issuer claim | `"upmatches"` |
| `audience` | `String` | The JWT audience claim | `"upmatches"` |
| `accessTokenExpiryMinutes` | `Integer` | Access token expiration time in minutes | `15` |
| `refreshTokenExpiryDays` | `Integer` | Refresh token expiration time in days | `7` |
| `frontendCallbackUrl` | `String` | Frontend callback URL (must be valid URI) | Required |
| `mobileCallbackScheme` | `String` | Mobile callback scheme | `"upmatches"` |

## Public Methods

Since this is a Java record, the following accessor methods are automatically generated:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `issuer()` | `String` | Returns the JWT issuer |
| `audience()` | `String` | Returns the JWT audience |
| `accessTokenExpiryMinutes()` | `Integer` | Returns access token expiry in minutes |
| `refreshTokenExpiryDays()` | `Integer` | Returns refresh token expiry in days |
| `frontendCallbackUrl()` | `String` | Returns the frontend callback URL |
| `mobileCallbackScheme()` | `String` | Returns the mobile callback scheme |

## Usage Example

To use this configuration in your application, add the following properties to your `application.yml`:

```yaml
app:
  jwt:
    issuer: "my-app"
    audience: "my-app-users"
    access-token-expiry-minutes: 30
    refresh-token-expiry-days: 14
    frontend-callback-url: "https://myapp.com/callback"
    mobile-callback-scheme: "myapp://callback"
```

Then inject the properties into your service:

```java
@Service
public class JwtService {
    private final JwtProperties jwtProperties;

    public JwtService(JwtProperties jwtProperties) {
        this.jwtProperties = jwtProperties;
    }

    public void generateToken() {
        String issuer = jwtProperties.issuer();
        int expiryMinutes = jwtProperties.accessTokenExpiryMinutes();
        // Token generation logic...
    }
}
```

## Validation Rules

- **`frontendCallbackUrl`**: Must not be blank and must be a valid URI format. Throws `IllegalArgumentException` if invalid.
- **`issuer`, `audience`, `mobileCallbackScheme`**: If null or blank, defaults to `"upmatches"`.
- **`accessTokenExpiryMinutes`, `refreshTokenExpiryDays`**: If null or non-positive, defaults to 15 minutes and 7 days respectively.

## Dependencies

- Spring Boot `@ConfigurationProperties` annotation
- Java `java.net.URI` for URL validation
