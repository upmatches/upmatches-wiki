## Overview

The `JwtProperties` class is a configuration properties holder for JWT (JSON Web Token) settings within an application. It is designed to be used with Spring Boot's `@ConfigurationProperties` to map properties prefixed with `app.jwt` from configuration files. This class encapsulates various JWT-related settings such as issuer, audience, token expiry durations, and callback URLs.

## Public Methods

The `JwtProperties` class is a record, which means it primarily serves as a data carrier. It does not have traditional public methods but provides an implicit constructor and accessor methods for its fields. Below is a description of the fields and their purposes:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `JwtProperties` | `String issuer`, `String audience`, `Integer accessTokenExpiryMinutes`, `Integer refreshTokenExpiryDays`, `String frontendCallbackUrl`, `String mobileCallbackScheme` | `JwtProperties` | Constructs a new `JwtProperties` instance with the specified parameters. It applies default values and validation as necessary. |

## Fields

The following table describes the fields available in the `JwtProperties` record:

| Field Name | Type | Description |
|------------|------|-------------|
| `issuer` | `String` | The issuer of the JWT. Defaults to "upmatches" if not provided or blank. |
| `audience` | `String` | The audience for the JWT. Defaults to "upmatches" if not provided or blank. |
| `accessTokenExpiryMinutes` | `Integer` | The expiry time in minutes for the access token. Defaults to 15 minutes if not provided or non-positive. |
| `refreshTokenExpiryDays` | `Integer` | The expiry time in days for the refresh token. Defaults to 7 days if not provided or non-positive. |
| `frontendCallbackUrl` | `String` | The callback URL for the frontend application. Must be a valid URI and not blank. |
| `mobileCallbackScheme` | `String` | The callback scheme for mobile applications. Defaults to "upmatches" if not provided or blank. |

## Validation and Defaults

- **Default Values**: If certain fields are not provided or are invalid (e.g., blank or non-positive), default values are applied:
  - `issuer`, `audience`, and `mobileCallbackScheme` default to "upmatches".
  - `accessTokenExpiryMinutes` defaults to 15 minutes.
  - `refreshTokenExpiryDays` defaults to 7 days.

- **Validation**: The `frontendCallbackUrl` must be a valid URI and cannot be blank. If it is invalid, an `IllegalArgumentException` is thrown.
