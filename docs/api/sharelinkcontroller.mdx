# ShareLinkController

The `ShareLinkController` is a REST controller that manages share link operations in the UpMatches application. It provides endpoints for creating new share links and resolving existing ones using a unique alphanumeric code.

## Purpose

This controller handles two primary operations:
- **Creating** a new share link that can be shared with other users
- **Resolving** an existing share link by its unique 8-character alphanumeric code

## Endpoints

### Create Share Link

Creates a new share link based on the provided request data.

**HTTP Method:** `POST`

**Endpoint:** `/api/v1/share-links`

**Request Body:** `CreateShareLinkRequest` (validated)

**Response:** `ApiResponse<ShareLinkResponse>` with HTTP status `201 Created`

### Resolve Share Link

Resolves an existing share link using its unique code.

**HTTP Method:** `GET`

**Endpoint:** `/api/v1/share-links/{code}`

**Path Variable:** `code` - An 8-character alphanumeric string (validated with regex pattern `^[0-9A-Za-z]{8}$`)

**Response:** `ApiResponse<PublicShareLinkResponse>` with HTTP status `200 OK`

## Public Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `createShareLink` | `@Valid @RequestBody CreateShareLinkRequest body`, `HttpServletRequest request` | `ResponseEntity<ApiResponse<ShareLinkResponse>>` | Creates a new share link and returns the created link details |
| `resolveShareLink` | `@PathVariable @Pattern(regexp = "^[0-9A-Za-z]{8}$") String code`, `HttpServletRequest request` | `ResponseEntity<ApiResponse<PublicShareLinkResponse>>` | Resolves a share link by its 8-character alphanumeric code |

## Dependencies

The controller depends on two service interfaces:

| Service Interface | Purpose |
|-------------------|---------|
| `ICreateShareLinkService` | Handles the business logic for creating share links |
| `IResolveShareLinkService` | Handles the business logic for resolving share links |

## Validation

The controller uses Jakarta Bean Validation annotations to ensure data integrity:

- **Request Body:** Validated with `@Valid` annotation on `CreateShareLinkRequest`
- **Code Parameter:** Validated with `@Pattern` annotation requiring exactly 8 alphanumeric characters (`^[0-9A-Za-z]{8}$`)

## Response Format

Both endpoints return responses wrapped in an `ApiResponse` object with the following structure:

- **data:** The response payload (`ShareLinkResponse` or `PublicShareLinkResponse`)
- **message:** A success message describing the operation result
- **path:** The request URI for traceability

## Error Handling

The controller leverages Spring's validation framework to handle invalid inputs:

- Invalid request body will return a `400 Bad Request` with validation error details
- Invalid share link code (not matching the 8-character alphanumeric pattern) will return a `400 Bad Request` with the message "Share link code must be 8 alphanumeric characters."

## Usage Example

### Creating a Share Link

```http
POST /api/v1/share-links
Content-Type: application/json

{
  // CreateShareLinkRequest payload
}
```

### Resolving a Share Link

```http
GET /api/v1/share-links/ABC12345
```

## Notes

- The controller is mapped to the base path `/api/v1/share-links`
- All endpoints are validated at the class level with `@Validated`
- The controller uses constructor injection for its dependencies
- Success messages are defined as constants for consistency
