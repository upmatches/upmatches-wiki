# ShareLinkController

The `ShareLinkController` is a REST controller that handles HTTP requests related to share links in the UpMatches application. It provides endpoints for creating new share links and resolving existing ones using a unique alphanumeric code.

## Purpose

This controller serves as the entry point for share link operations, delegating business logic to dedicated service interfaces (`ICreateShareLinkService` and `IResolveShareLinkService`). It validates input parameters, constructs appropriate API responses, and returns standardized HTTP status codes.

## Endpoints

### Create Share Link

Creates a new share link based on the provided request body.

**HTTP Method:** `POST`  
**Path:** `/api/v1/share-links`  
**Request Body:** `CreateShareLinkRequest` (validated)  
**Response:** `ApiResponse<ShareLinkResponse>` with HTTP 201 (Created)

### Resolve Share Link

Resolves an existing share link using its unique 8-character alphanumeric code.

**HTTP Method:** `GET`  
**Path:** `/api/v1/share-links/{code}`  
**Path Variable:** `code` (must match pattern `^[0-9A-Za-z]{8}$`)  
**Response:** `ApiResponse<PublicShareLinkResponse>` with HTTP 200 (OK)

## Public Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `createShareLink` | `@Valid @RequestBody CreateShareLinkRequest body`, `HttpServletRequest request` | `ResponseEntity<ApiResponse<ShareLinkResponse>>` | Creates a new share link and returns it with a 201 status code |
| `resolveShareLink` | `@PathVariable @Pattern(regexp = "^[0-9A-Za-z]{8}$") String code`, `HttpServletRequest request` | `ResponseEntity<ApiResponse<PublicShareLinkResponse>>` | Resolves a share link by its 8-character alphanumeric code and returns it with a 200 status code |

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ICreateShareLinkService` | Service Interface | Handles the business logic for creating share links |
| `IResolveShareLinkService` | Service Interface | Handles the business logic for resolving share links |

## Validation

The controller uses Jakarta Bean Validation annotations to ensure input integrity:

- **`CreateShareLinkRequest`**: Validated with `@Valid` annotation
- **`code` path variable**: Validated with `@Pattern` annotation requiring exactly 8 alphanumeric characters (`^[0-9A-Za-z]{8}$`)

## Response Format

All responses are wrapped in an `ApiResponse` object containing:

- The response data (either `ShareLinkResponse` or `PublicShareLinkResponse`)
- A success message
- The request URI

## Error Handling

The controller relies on Spring's validation framework to handle invalid inputs. If validation fails, a `MethodArgumentNotValidException` or `ConstraintViolationException` is thrown, which can be handled by a global exception handler.
