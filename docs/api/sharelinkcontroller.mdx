# ShareLinkController

The `ShareLinkController` is a REST controller that handles the creation and resolution of share links within the UpMatches application. It exposes two endpoints under the `/api/v1/share-links` base path: one for generating new share links and another for resolving existing share links using a unique code.

## Purpose

This controller serves as the entry point for the share link feature, allowing users to:
- **Create** a new share link by providing the necessary data via a POST request.
- **Resolve** an existing share link by providing its 8-character alphanumeric code via a GET request.

The controller delegates the actual business logic to two service interfaces: `ICreateShareLinkService` and `IResolveShareLinkService`.

## Endpoints

### POST `/api/v1/share-links`

Creates a new share link.

| Parameter | Type | Description |
|-----------|------|-------------|
| `body` | `CreateShareLinkRequest` (Request Body) | The request payload containing the data needed to create a share link. Must be valid. |
| `request` | `HttpServletRequest` | The HTTP request object, used to capture the request URI for the response. |

**Response:** `201 Created` with an `ApiResponse<ShareLinkResponse>` containing the created share link details and a success message.

### GET `/api/v1/share-links/{code}`

Resolves an existing share link by its unique code.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` (Path Variable) | The 8-character alphanumeric code of the share link. Must match the pattern `^[0-9A-Za-z]{8}$`. |
| `request` | `HttpServletRequest` | The HTTP request object, used to capture the request URI for the response. |

**Response:** `200 OK` with an `ApiResponse<PublicShareLinkResponse>` containing the resolved share link data and a success message.

## Validation

The controller uses Jakarta Bean Validation annotations to ensure input data integrity:
- The `code` path variable is validated against the regex pattern `^[0-9A-Za-z]{8}$` to ensure it is exactly 8 alphanumeric characters.
- The `CreateShareLinkRequest` body is validated using the `@Valid` annotation.

## Dependencies

The controller depends on the following services:
- `ICreateShareLinkService`: Handles the creation of share links.
- `IResolveShareLinkService`: Handles the resolution of share links by code.

Both services are injected via constructor injection.

## Error Handling

Validation errors are automatically handled by Spring's validation framework, returning appropriate error responses when input constraints are violated. The controller itself does not implement custom error handling, relying on the global exception handling mechanisms of the application.
