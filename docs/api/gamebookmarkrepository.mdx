## Purpose

The `GameBookmarkRepository` interface is a part of the `com.upmatches.app.features.game.repositories` package and extends the `JpaRepository` interface provided by Spring Data JPA. It is designed to manage `GameBookmark` entities, which represent bookmarks of games by users. This repository provides methods to perform CRUD operations and custom queries on game bookmarks stored in a database.

## Public Methods

The `GameBookmarkRepository` interface includes the following public methods:

| Method Signature | Description |
|------------------|-------------|
| `boolean existsByGameIdAndUserId(UUID gameId, UUID userId)` | Checks if a `GameBookmark` exists for a given `gameId` and `userId`. |
| `Optional<GameBookmark> findByGameIdAndUserId(UUID gameId, UUID userId)` | Retrieves a `GameBookmark` for a specified `gameId` and `userId`, if it exists. |
| `List<GameBookmark> findByUserIdCursor(UUID userId, Instant afterBookmarkedAt, UUID afterId, int size)` | Retrieves a list of `GameBookmark` entities for a specified `userId`, using cursor-based pagination. The results are ordered by `bookmarked_at` in descending order and `id` in ascending order. |

### Method Details

#### `existsByGameIdAndUserId`

- **Parameters:**

  | Name     | Type   | Description                                      |
  |----------|--------|--------------------------------------------------|
  | `gameId` | `UUID` | The unique identifier of the game.               |
  | `userId` | `UUID` | The unique identifier of the user.               |

- **Return Type:** `boolean`  
  Returns `true` if a bookmark exists for the specified game and user, otherwise `false`.

#### `findByGameIdAndUserId`

- **Parameters:**

  | Name     | Type   | Description                                      |
  |----------|--------|--------------------------------------------------|
  | `gameId` | `UUID` | The unique identifier of the game.               |
  | `userId` | `UUID` | The unique identifier of the user.               |

- **Return Type:** `Optional<GameBookmark>`  
  Returns an `Optional` containing the `GameBookmark` if found, otherwise an empty `Optional`.

#### `findByUserIdCursor`

- **Parameters:**

  | Name                | Type     | Description                                                                 |
  |---------------------|----------|-----------------------------------------------------------------------------|
  | `userId`            | `UUID`   | The unique identifier of the user.                                          |
  | `afterBookmarkedAt` | `Instant`| The timestamp to start fetching bookmarks after. Can be `null`.             |
  | `afterId`           | `UUID`   | The ID to start fetching bookmarks after, used for tie-breaking.            |
  | `size`              | `int`    | The maximum number of bookmarks to retrieve.                                |

- **Return Type:** `List<GameBookmark>`  
  Returns a list of `GameBookmark` entities for the specified user, ordered by `bookmarked_at` and `id`.
