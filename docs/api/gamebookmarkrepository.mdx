# GameBookmarkRepository

The `GameBookmarkRepository` interface provides data access operations for the `GameBookmark` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD functionality and defines custom query methods for bookmark management, including existence checks, lookups, and cursor-based pagination.

## Interface Definition

```java
public interface GameBookmarkRepository extends JpaRepository<GameBookmark, UUID>
```

The repository works with `GameBookmark` entities and uses `UUID` as the primary key type.

## Methods

### Standard CRUD Methods

The following methods are inherited from `JpaRepository<GameBookmark, UUID>`:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all game bookmarks |
| `findById(UUID id)` | Finds a bookmark by its ID |
| `save(GameBookmark bookmark)` | Creates or updates a bookmark |
| `deleteById(UUID id)` | Deletes a bookmark by its ID |
| `delete(GameBookmark bookmark)` | Deletes a specific bookmark |
| `count()` | Returns the total number of bookmarks |

### Custom Query Methods

#### `existsByGameIdAndUserId`

```java
boolean existsByGameIdAndUserId(UUID gameId, UUID userId)
```

Checks whether a bookmark exists for a specific game and user combination.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |

**Returns:** `boolean` - `true` if a bookmark exists for the given game and user, `false` otherwise.

---

#### `findByGameIdAndUserId`

```java
Optional<GameBookmark> findByGameIdAndUserId(UUID gameId, UUID userId)
```

Retrieves a bookmark for a specific game and user combination.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game |
| `userId` | `UUID` | The unique identifier of the user |

**Returns:** `Optional<GameBookmark>` - An Optional containing the bookmark if found, or empty if no bookmark exists for the given game and user.

#### `findByUserIdCursor`

```java
@Query(value = """
    SELECT b.* FROM game_bookmarks b
    JOIN games g ON g.id = b.game_id
    WHERE b.user_id = :userId
      AND g.deleted_at IS NULL
      AND (CAST(:afterBookmarkedAt AS timestamptz) IS NULL
           OR b.bookmarked_at < :afterBookmarkedAt
           OR (b.bookmarked_at = :afterBookmarkedAt AND b.id > :afterId))
    ORDER BY b.bookmarked_at DESC, b.id ASC
    LIMIT :size
    """, nativeQuery = true)
List<GameBookmark> findByUserIdCursor(
    @Param("userId") UUID userId,
    @Param("afterBookmarkedAt") Instant afterBookmarkedAt,
    @Param("afterId") UUID afterId,
    @Param("size") int size)
```

Performs cursor-based pagination to retrieve bookmarks for a specific user. This method only returns bookmarks for games that have not been soft-deleted (`deleted_at IS NULL`).

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user whose bookmarks to retrieve |
| `afterBookmarkedAt` | `Instant` | The cursor timestamp for pagination. Pass `null` for the first page |
| `afterId` | `UUID` | The cursor ID for pagination, used to break ties when multiple bookmarks have the same timestamp |
| `size` | `int` | The maximum number of bookmarks to return |

**Returns:** `List<GameBookmark>` - A list of bookmarks sorted by `bookmarked_at` in descending order (most recent first), with ties broken by `id` in ascending order.

**Pagination Behavior:**

- For the first page, pass `null` for `afterBookmarkedAt` (any value for `afterId` is ignored in this case)
- For subsequent pages, pass the `bookmarked_at` and `id` values from the last bookmark of the previous page
- The query uses a composite cursor of `(bookmarked_at, id)` to ensure stable pagination even when multiple bookmarks share the same timestamp
