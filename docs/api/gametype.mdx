# GameType Enum

The `GameType` enum defines the possible game modes for a match in the UpMatches application. It is used to distinguish between singles and doubles matches, which affects player count, scoring rules, and match logic.

## Location

- **Package:** `com.upmatches.app.features.game.enums`
- **File:** `GameType.java`

## Values

| Constant | Description |
|----------|-------------|
| `SINGLE` | A match played between two individual players (1 vs 1). |
| `DOUBLE` | A match played between two teams of two players each (2 vs 2). |

## Usage

This enum is typically used in match creation, game logic, and UI components to determine the appropriate configuration for a match. For example:

- **Player count validation:** Ensure the correct number of players are assigned.
- **Scoring rules:** Apply different scoring logic for singles vs. doubles.
- **Display:** Show the correct match type label in the user interface.

## Example

```java
GameType type = GameType.SINGLE;

if (type == GameType.DOUBLE) {
    // Handle doubles match logic
}
```
