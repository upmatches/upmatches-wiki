# GameType Enum

The `GameType` enum defines the possible types of games within the application. It is used to distinguish between single-player and double-player game modes.

## Package Location

`com.upmatches.app.features.game.enums`

## Enum Values

| Value    | Description                                                                 |
| -------- | --------------------------------------------------------------------------- |
| `SINGLE` | Represents a single-player game mode where one participant plays alone.     |
| `DOUBLE` | Represents a double-player game mode where two participants play together.  |

## Usage

This enum is typically used to configure game logic, UI components, or data models that need to differentiate between the number of players in a game session. For example, it can be used in a game settings class or as a parameter in a game creation method.

## Example

```java
GameType currentGameType = GameType.SINGLE;

if (currentGameType == GameType.DOUBLE) {
    // Initialize two-player game logic
} else {
    // Initialize single-player game logic
}
```
