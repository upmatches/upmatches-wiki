## Overview

The `GameType` enum is part of the `com.upmatches.app.features.game.enums` package. It is used to represent the type of game being played in the application. Enums in Java are a special type of class that represents a group of constants (unchangeable variables, like final variables).

## Enum Constants

The `GameType` enum defines two constants:

- **SINGLE**: Represents a single-player game type.
- **DOUBLE**: Represents a double-player game type.
