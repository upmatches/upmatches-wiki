# GameType Enum

The `GameType` enum defines the possible types of games within the application. It is used to distinguish between single-player and double-player (or team-based) game modes.

## Package

`com.upmatches.app.features.game.enums`

## Enum Values

| Value    | Description                                                                 |
|----------|-----------------------------------------------------------------------------|
| `SINGLE` | Represents a single-player game mode, where one participant competes alone. |
| `DOUBLE` | Represents a double-player (or team) game mode, where two participants compete together. |

## Usage

This enum is typically used in game-related classes to specify the type of match or game session. For example, it can be used as a field in a `Game` entity or as a parameter in service methods to determine game logic or scoring rules.

### Example

```java
GameType type = GameType.SINGLE;

if (type == GameType.DOUBLE) {
    // Handle double player logic
}
```
