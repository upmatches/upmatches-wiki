## Purpose

The `GameType` enum is a part of the `com.upmatches.app.features.game.enums` package. It is used to define the types of games available in the application. Enums in Java are a special type of class that represents a group of constants (unchangeable variables, like final variables). In this case, `GameType` provides two constants: `SINGLE` and `DOUBLE`.

## Enum Constants

The `GameType` enum contains the following constants:

<Tabs>
<TabItem value="SINGLE" label="SINGLE" default>

- **Description**: Represents a single-player game type.
- **Usage**: This constant can be used when the game involves only one player.

</TabItem>
<TabItem value="DOUBLE" label="DOUBLE">

- **Description**: Represents a double-player game type.
- **Usage**: This constant can be used when the game involves two players.

</TabItem>
</Tabs>
