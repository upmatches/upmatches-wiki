## Purpose

The `Notification` class is an entity representing a notification within the application. It is designed to store and manage information about notifications sent to users. This class is mapped to a database table named `notifications` and includes various attributes such as the recipient, type, title, message, and read status of the notification.

## Public Methods

The `Notification` class provides the following public methods:

### `create`

Creates a new `Notification` instance with the specified parameters.

| Parameter     | Type               | Description                                      |
|---------------|--------------------|--------------------------------------------------|
| `recipient`   | `User`             | The user who will receive the notification.      |
| `type`        | `NotificationType` | The type of the notification.                    |
| `title`       | `String`           | The title of the notification.                   |
| `message`     | `String`           | The message content of the notification.         |
| `resourceType`| `String`           | The type of resource associated with the notification. |
| `resourceId`  | `UUID`             | The ID of the resource associated with the notification. |

**Returns:** `Notification` - A new instance of the `Notification` class.

### `markRead`

Marks the notification as read and sets the read timestamp.

| Parameter | Type | Description |
|-----------|------|-------------|
| *(none)*  |      |             |

**Returns:** `void` - This method does not return a value.

## Attributes

The `Notification` class includes the following attributes:

- `id`: `UUID` - The unique identifier for the notification.
- `recipient`: `User` - The user who receives the notification.
- `type`: `NotificationType` - The type of the notification.
- `title`: `String` - The title of the notification.
- `message`: `String` - The message content of the notification.
- `resourceType`: `String` - The type of resource associated with the notification.
- `resourceId`: `UUID` - The ID of the resource associated with the notification.
- `isRead`: `Boolean` - Indicates whether the notification has been read.
- `readAt`: `Instant` - The timestamp when the notification was marked as read.
- `createdAt`: `Instant` - The timestamp when the notification was created.
