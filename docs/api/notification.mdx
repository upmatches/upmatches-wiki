# Notification Entity

The `Notification` class is a JPA entity that represents a notification within the UpMatches application. It is mapped to the `notifications` database table and is responsible for storing and managing user notifications. Each notification is associated with a recipient user, contains a type, title, message, and optional resource references, and tracks its read status.

## Class Overview

- **Package:** `com.upmatches.app.features.notification.entities`
- **Annotations:** `@Entity`, `@Table(name = "notifications")`, `@Getter`, `@NoArgsConstructor(access = AccessLevel.PROTECTED)`
- **Implements:** None (plain JPA entity)

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Primary key, auto-generated using UUID strategy |
| `recipient` | `User` | The user who receives the notification (Many-to-One relationship) |
| `type` | `NotificationType` | Enum indicating the type of notification (stored as string) |
| `title` | `String` | Short title of the notification (max 255 characters) |
| `message` | `String` | Full message content of the notification (TEXT column) |
| `resourceType` | `String` | Optional type of the related resource (e.g., "match", "message") |
| `resourceId` | `UUID` | Optional UUID of the related resource |
| `isRead` | `Boolean` | Flag indicating whether the notification has been read |
| `readAt` | `Instant` | Timestamp when the notification was marked as read |
| `createdAt` | `Instant` | Timestamp when the notification was created (non-updatable) |

## Public Methods

### `create(User recipient, NotificationType type, String title, String message, String resourceType, UUID resourceId)`

Creates a new `Notification` instance with the specified parameters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipient` | `User` | The user who will receive the notification |
| `type` | `NotificationType` | The type of notification |
| `title` | `String` | The notification title |
| `message` | `String` | The notification message content |
| `resourceType` | `String` | Optional type of related resource (can be null) |
| `resourceId` | `UUID` | Optional UUID of related resource (can be null) |

**Returns:** `Notification` - A new notification instance with `isRead` set to `false`.

### `markRead()`

Marks the notification as read. If the notification is already marked as read, this method does nothing. Otherwise, it sets `isRead` to `true` and records the current timestamp in `readAt`.

**Parameters:** None  
**Returns:** `void`

## Lifecycle Callback

### `onCreate()`

A `@PrePersist` callback that automatically sets the `createdAt` timestamp to the current time and initializes `isRead` to `false` if it is null.

## Usage Example

```java
// Create a new notification
User recipient = userRepository.findById(userId).orElseThrow();
Notification notification = Notification.create(
    recipient,
    NotificationType.MATCH,
    "New Match!",
    "You have a new match with someone.",
    "match",
    matchId
);

// Save the notification
notificationRepository.save(notification);

// Later, mark it as read
notification.markRead();
notificationRepository.save(notification);
```

## Database Mapping

The entity maps to the `notifications` table with the following column details:

- `id` - UUID primary key
- `recipient_id` - Foreign key to users table (not null)
- `type` - VARCHAR(64) storing the enum name (not null)
- `title` - VARCHAR(255) (not null)
- `message` - TEXT (not null)
- `resource_type` - VARCHAR(64) (nullable)
- `resource_id` - UUID (nullable)
- `is_read` - BOOLEAN (not null)
- `read_at` - TIMESTAMP (nullable)
- `created_at` - TIMESTAMP (not null, non-updatable)
