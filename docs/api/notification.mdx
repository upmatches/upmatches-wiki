# Notification Entity

The `Notification` class is a JPA entity that represents a notification within the UpMatches application. It is mapped to the `notifications` database table and is responsible for storing and managing notification data for users.

## Purpose

This entity serves as the core data model for the notification system. It captures all relevant information about a notification, including:
- The recipient user
- The type of notification
- The notification content (title and message)
- Optional resource references (e.g., a specific match or message)
- Read status and timestamps

The class provides factory methods for creating new notifications and a method to mark notifications as read.

## Entity Details

| Property | Type | Description |
|----------|------|-------------|
| `id` | `UUID` | Primary key, auto-generated using UUID strategy |
| `recipient` | `User` | The user who receives the notification (Many-to-One relationship) |
| `type` | `NotificationType` | Enum indicating the notification type (stored as string) |
| `title` | `String` | Short title of the notification (max 255 characters) |
| `message` | `String` | Full notification message (TEXT column) |
| `resourceType` | `String` | Optional type of the related resource (max 64 characters) |
| `resourceId` | `UUID` | Optional ID of the related resource |
| `isRead` | `Boolean` | Flag indicating whether the notification has been read |
| `readAt` | `Instant` | Timestamp when the notification was read |
| `createdAt` | `Instant` | Timestamp when the notification was created (non-updatable) |

## Public Methods

### `create(User recipient, NotificationType type, String title, String message, String resourceType, UUID resourceId)`

Static factory method to create a new `Notification` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipient` | `User` | The user who will receive the notification |
| `type` | `NotificationType` | The type of notification |
| `title` | `String` | The notification title |
| `message` | `String` | The notification message body |
| `resourceType` | `String` | Optional type of the related resource (can be null) |
| `resourceId` | `UUID` | Optional ID of the related resource (can be null) |

**Returns:** `Notification` - A new notification instance with `isRead` set to `false`.

### `markRead()`

Marks the notification as read. If the notification is already marked as read, this method does nothing. When called, it sets `isRead` to `true` and records the current timestamp in `readAt`.

**Parameters:** None

**Returns:** `void`

## Lifecycle Callbacks

### `onCreate()`

A `@PrePersist` callback that automatically sets the `createdAt` timestamp to the current time and initializes `isRead` to `false` if it is null. This ensures that every notification has a creation timestamp and a default read status before being persisted to the database.

## Usage Example

```java
// Create a new notification
User recipient = userRepository.findById(userId).orElseThrow();
Notification notification = Notification.create(
    recipient,
    NotificationType.MATCH,
    "New Match!",
    "You have a new match with Sarah.",

    matchId

// Save the notification
notificationRepository.save(notification);

// Later, mark it as read
notification.markRead();
notificationRepository.save(notification);
```
