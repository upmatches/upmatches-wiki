# CreateShareLinkService

The `CreateShareLinkService` class is a Spring service responsible for creating shareable short links for resources within the UpMatches application. It handles the complete lifecycle of share link creation, including user authentication, duplicate link detection, unique short code generation with collision handling, and response building.

## Purpose

This service ensures that:
- Only authenticated users can create share links
- Existing share links for the same resource and user are reused rather than duplicated
- Short codes are generated with collision detection and retry logic (up to 3 attempts)
- All operations are audited via the `@Auditable` annotation
- Database integrity is maintained through transactional operations

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ShortLinkRepository` | Repository | Data access for `ShortLink` entities |
| `UserRepository` | Repository | Data access for `User` entities |
| `IShareLinkUrlBuilder` | Service | Builds share, web, and mobile URLs from short codes |

## Public Methods

### `execute(CreateShareLinkRequest request)`

Creates or retrieves an existing share link for the given resource.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateShareLinkRequest` | Contains `resourceType`, `resourceId`, and other link creation parameters |

**Returns:** `ShareLinkResponse` - Contains the short link details including URLs and click count.

**Exceptions:**
- `AuthenticationException` - If no valid JWT authentication is found or the user ID in the token is invalid
- `ResourceNotFoundException` - If the authenticated user is not found in the database
- `ShortCodeCollisionException` - If a unique short code cannot be generated after 3 attempts

**Behavior:**
1. Extracts the authenticated user ID from the JWT token
2. Checks if a share link already exists for the given resource type, resource ID, and user
3. If an existing link is found, returns it with the current click count
4. If no existing link is found, generates a new short link with a unique code and saves it

## Private Methods

### `saveWithUniqueCode(CreateShareLinkRequest request, User user)`

Generates and saves a short link with a unique code, retrying up to `MAX_CODE_ATTEMPTS` times on collision.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateShareLinkRequest` | The original link creation request |
| `user` | `User` | The authenticated user creating the link |

**Returns:** `ShortLink` - The successfully saved short link entity.

**Throws:** `ShortCodeCollisionException` - If all attempts to generate a unique code fail.

### `isUniqueCodeViolation(DataIntegrityViolationException ex)`

Determines if a `DataIntegrityViolationException` is caused by a unique constraint violation on the `code` column.

| Parameter | Type | Description |
|-----------|------|-------------|
| `ex` | `DataIntegrityViolationException` | The exception to analyze |

**Returns:** `boolean` - `true` if the exception is a code column violation, `false` otherwise.

### `getAuthenticatedUserId()`

Extracts the user ID from the current JWT authentication context.

**Returns:** `UUID` - The authenticated user's ID.

**Throws:** `AuthenticationException` - If no authentication is present or the token subject is not a valid UUID.

### `findUserOrThrow(UUID id)`

Finds a user by ID or throws a `ResourceNotFoundException`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The user ID to look up |

**Returns:** `User` - The found user entity.

**Throws:** `ResourceNotFoundException` - If no user exists with the given ID.

### `buildResponse(ShortLink link, Long clickCount)`

Constructs a `ShareLinkResponse` from a `ShortLink` entity and its click count.

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The short link entity |
| `clickCount` | `Long` | The number of clicks on the link |

**Returns:** `ShareLinkResponse` - A response object containing all share link URLs and metadata.

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `MAX_CODE_ATTEMPTS` | `3` | Maximum number of attempts to generate a unique short code |
| `CODE_COLUMN` | `"code"` | Database column name for the unique short code constraint |
| `MSG_NO_AUTHENTICATION` | `"No valid authentication found."` | Error message for missing authentication |
| `MSG_INVALID_SUBJECT` | `"Invalid user ID in token subject: %s"` | Error message template for invalid token subject |
| `MSG_CODE_COLLISION` | `"Failed to generate a unique short code after %d attempts."` | Error message template for code collision |
| `MSG_USER_NOT_FOUND` | `"User not found with ID: %s"` | Error message template for missing user |

## Annotations

| Annotation | Description |
|------------|-------------|
| `@Service` | Marks this class as a Spring service component |
| `@Transactional` | Ensures the `execute` method runs within a database transaction |
| `@Auditable(action = "SHARE_LINK_CREATED", resourceType = "SHARE_LINK", resourceIdExpression = "#result?.code")` | Records audit events for share link creation, using the generated code as the resource identifier |
