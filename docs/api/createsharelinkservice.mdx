# CreateShareLinkService

The `CreateShareLinkService` class is a Spring service responsible for creating shareable short links for resources within the application. It implements the `ICreateShareLinkService` interface and provides transactional, auditable functionality for generating unique short codes that map to specific resources.

## Purpose

This service handles the complete lifecycle of creating a share link:
- Authenticates the current user via JWT token
- Checks for existing share links for the same resource and user to avoid duplicates
- Generates unique short codes with collision detection and retry logic
- Persists new short links to the database
- Builds comprehensive response objects containing multiple URL formats (share, web, mobile)

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ShortLinkRepository` | Repository | Data access for `ShortLink` entities |
| `UserRepository` | Repository | Data access for `User` entities |
| `IShareLinkUrlBuilder` | Service | Builds share, web, and mobile URLs from short codes |

## Public Methods

### `execute(CreateShareLinkRequest request)`

Creates or retrieves an existing share link for the specified resource.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateShareLinkRequest` | Contains `resourceType`, `resourceId`, and other link creation parameters |

| Returns | Type | Description |
|---------|------|-------------|
| `ShareLinkResponse` | Object | Contains the short link details, click count, and generated URLs |

**Behavior:**
1. Authenticates the current user from the security context
2. Checks if a share link already exists for the given resource type, resource ID, and user
3. If an existing link is found, returns it with the current click count
4. If no existing link exists, generates a new unique short code and saves the link
5. Returns a comprehensive response with share, web, and mobile URLs

**Exceptions:**
- `AuthenticationException` - If no valid JWT authentication is found or the token subject is invalid
- `ResourceNotFoundException` - If the authenticated user is not found in the database
- `ShortCodeCollisionException` - If a unique short code cannot be generated after maximum attempts

## Private Methods

### `saveWithUniqueCode(CreateShareLinkRequest request, User user)`

Attempts to generate and save a short link with a unique code.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateShareLinkRequest` | The original link creation request |
| `user` | `User` | The authenticated user entity |

| Returns | Type | Description |
|---------|------|-------------|
| `ShortLink` | Entity | The successfully saved short link |

**Logic:**
- Attempts up to `MAX_CODE_ATTEMPTS` (3) times to generate a unique code
- Catches `DataIntegrityViolationException` specifically for code column violations
- Re-throws non-code-related database exceptions
- Throws `ShortCodeCollisionException` if all attempts fail

### `isUniqueCodeViolation(DataIntegrityViolationException ex)`

Determines if a database exception is caused by a unique code constraint violation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `ex` | `DataIntegrityViolationException` | The database exception to analyze |

| Returns | Type | Description |
|---------|------|-------------|
| `boolean` | Primitive | `true` if the exception message contains "code" (case-insensitive) |

### `getAuthenticatedUserId()`

Extracts the user ID from the current JWT authentication context.

| Returns | Type | Description |
|---------|------|-------------|
| `UUID` | Object | The authenticated user's UUID from the JWT subject claim |

**Exceptions:**
- `AuthenticationException` - If no authentication exists, principal is not a JWT, or subject is not a valid UUID

### `findUserOrThrow(UUID id)`

Retrieves a user entity by ID or throws an exception.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The user's unique identifier |

| Returns | Type | Description |
|---------|------|-------------|
| `User` | Entity | The found user entity |

**Exceptions:**
- `ResourceNotFoundException` - If no user exists with the given ID

### `buildResponse(ShortLink link, Long clickCount)`

Constructs a `ShareLinkResponse` from a short link entity and its click count.

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The short link entity |
| `clickCount` | `Long` | The number of clicks on the link |

| Returns | Type | Description |
|---------|------|-------------|
| `ShareLinkResponse` | Object | Response containing all URL formats and link metadata |

## Configuration Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `MAX_CODE_ATTEMPTS` | `3` | Maximum retry attempts for generating a unique short code |
| `CODE_COLUMN` | `"code"` | Database column name for the unique code constraint |
| `MSG_NO_AUTHENTICATION` | `"No valid authentication found."` | Error message for missing authentication |
| `MSG_INVALID_SUBJECT` | `"Invalid user ID in token subject: %s"` | Error message template for invalid JWT subject |
| `MSG_CODE_COLLISION` | `"Failed to generate a unique short code after %d attempts."` | Error message template for code generation failure |
| `MSG_USER_NOT_FOUND` | `"User not found with ID: %s"` | Error message template for missing user |

## Annotations

| Annotation | Details |
|------------|---------|
| `@Service` | Marks this class as a Spring service component |
| `@Transactional` | Ensures the `execute` method runs within a database transaction |
| `@Auditable` | Records audit events with action `SHARE_LINK_CREATED`, resource type `SHARE_LINK`, and resource ID from the result's code |
