# CreateShareLinkService

The `CreateShareLinkService` class is a Spring service responsible for creating shareable short links for resources within the application. It handles the complete lifecycle of share link creation, including user authentication, duplicate link detection, unique short code generation with collision handling, and response building.

## Purpose

This service provides a transactional operation that:
- Authenticates the current user from the security context
- Checks for existing share links for the same resource and user to avoid duplicates
- Generates unique short codes with retry logic to handle collisions
- Persists new share links to the database
- Builds comprehensive response objects with multiple URL formats (share, web, mobile)

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ShortLinkRepository` | Repository | Data access for `ShortLink` entities |
| `UserRepository` | Repository | Data access for `User` entities |
| `IShareLinkUrlBuilder` | Service | Builds share, web, and mobile URLs from link data |

## Public Methods

### `execute(CreateShareLinkRequest request)`

Creates or retrieves an existing share link for the given resource.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateShareLinkRequest` | Contains `resourceType`, `resourceId`, and other link creation parameters |

**Returns:** `ShareLinkResponse` - A response object containing the short link details, including:
- The generated short code
- Share URL
- Web URL
- Mobile URL
- Current click count

**Behavior:**
1. Authenticates the current user from the JWT token in the security context
2. Checks if a share link already exists for the same resource type, resource ID, and user
3. If an existing link is found, returns it with the current click count
4. If no existing link, generates a unique short code and persists a new `ShortLink` entity
5. Returns a comprehensive response with all URL formats

**Exceptions:**
- `AuthenticationException` - If no valid JWT authentication is found or the token subject is not a valid UUID
- `ResourceNotFoundException` - If the authenticated user is not found in the database
- `ShortCodeCollisionException` - If unable to generate a unique short code after maximum attempts

## Private Methods

### `saveWithUniqueCode(CreateShareLinkRequest request, User user)`

Attempts to create and save a new `ShortLink` with a unique code.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateShareLinkRequest` | The original creation request |
| `user` | `User` | The authenticated user entity |

**Returns:** `ShortLink` - The persisted short link entity

**Behavior:**
- Attempts up to `MAX_CODE_ATTEMPTS` (3) times to generate and save a unique short code
- On `DataIntegrityViolationException`, checks if the violation is due to a unique code constraint
- If not a code violation, re-throws the exception
- Throws `ShortCodeCollisionException` if all attempts fail

### `isUniqueCodeViolation(DataIntegrityViolationException ex)`

Determines if a data integrity violation is caused by a duplicate short code.

| Parameter | Type | Description |
|-----------|------|-------------|
| `ex` | `DataIntegrityViolationException` | The caught exception |

**Returns:** `boolean` - `true` if the violation message contains "code", `false` otherwise

### `getAuthenticatedUserId()`

Extracts the authenticated user's UUID from the JWT token in the security context.

**Returns:** `UUID` - The authenticated user's ID

**Exceptions:**
- `AuthenticationException` - If no authentication is found or the JWT subject is not a valid UUID

### `findUserOrThrow(UUID id)`

Retrieves a user by ID or throws an exception.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The user's unique identifier |

**Returns:** `User` - The found user entity

**Exceptions:**
- `ResourceNotFoundException` - If no user exists with the given ID

### `buildResponse(ShortLink link, Long clickCount)`

Constructs a `ShareLinkResponse` from a `ShortLink` entity and its click count.

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The persisted short link entity |
| `clickCount` | `Long` | The current number of clicks |

**Returns:** `ShareLinkResponse` - A formatted response with all URL variants

## Annotations

- `@Service` - Marks this class as a Spring service component
- `@Transactional` - Ensures the `execute` method runs within a database transaction
- `@Auditable(action = "SHARE_LINK_CREATED", ...)` - Custom annotation for audit logging, capturing the created link's code

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `MAX_CODE_ATTEMPTS` | `3` | Maximum retry attempts for unique code generation |
| `CODE_COLUMN` | `"code"` | Database column name for the short code |
| `MSG_NO_AUTHENTICATION` | `"No valid authentication found."` | Error message for missing authentication |
| `MSG_INVALID_SUBJECT` | `"Invalid user ID in token subject: %s"` | Error message template for invalid JWT subject |
| `MSG_CODE_COLLISION` | `"Failed to generate a unique short code after %d attempts."` | Error message template for code generation failure |
| `MSG_USER_NOT_FOUND` | `"User not found with ID: %s"` | Error message template for missing user |
