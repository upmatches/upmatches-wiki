# BaseEntity

The `BaseEntity` class is an abstract JPA `@MappedSuperclass` that provides a common set of fields and behavior for all entities in the UpMatches application. It centralizes standard auditing, identification, and soft-delete functionality, ensuring consistency across the data model.

## Purpose

- **Primary Key**: Automatically generates a database identity (`Long id`) and a unique, non-updatable UUID (`UUID uuid`) for external reference.
- **Auditing**: Leverages Spring Data JPA auditing to automatically populate `createdAt`, `updatedAt`, `createdBy`, and `updatedBy` fields.
- **Soft Delete**: Supports logical deletion via a `deletedAt` timestamp, with helper methods to check and mark deletion status.

## Fields

| Field       | Type     | Description                                                                 | Constraints                         |
|-------------|----------|-----------------------------------------------------------------------------|-------------------------------------|
| `id`        | `Long`   | Auto-generated primary key (database identity).                             | `@Id`, `@GeneratedValue`            |
| `uuid`      | `UUID`   | Universally unique identifier, generated on first persist.                  | `nullable=false`, `unique=true`, `updatable=false` |
| `createdAt` | `Instant`| Timestamp when the entity was created.                                      | `nullable=false`, `updatable=false` |
| `updatedAt` | `Instant`| Timestamp when the entity was last modified.                                | `nullable=false`                    |
| `createdBy` | `String` | Username or identifier of the user who created the entity.                  | `updatable=false`                   |
| `updatedBy` | `String` | Username or identifier of the user who last modified the entity.            |                                     |
| `deletedAt` | `Instant`| Timestamp indicating soft deletion; `null` means not deleted.               |                                     |

## Methods

### `onCreate()`

```java
@PrePersist
protected void onCreate()
```

- **Visibility**: `protected`
- **Description**: Lifecycle callback invoked before the first persist. If `uuid` is `null`, it generates a new random UUID.
- **Parameters**: None
- **Returns**: `void`

### `isDeleted()`

```java
public boolean isDeleted()
```

- **Visibility**: `public`
- **Description**: Checks whether the entity has been soft-deleted by inspecting the `deletedAt` field.
- **Parameters**: None
- **Returns**: `boolean` — `true` if `deletedAt` is not `null`, otherwise `false`.

### `markDeleted()`

```java
public void markDeleted()
```

- **Visibility**: `public`
- **Description**: Marks the entity as deleted by setting `deletedAt` to the current instant.
- **Parameters**: None
- **Returns**: `void`

## Usage Notes

- This class is abstract and must be extended by concrete entity classes.
- It relies on Spring Data JPA's `AuditingEntityListener` to automatically populate `createdAt`, `updatedAt`, `createdBy`, and `updatedBy`. Ensure that auditing is enabled in your Spring configuration (e.g., using `@EnableJpaAuditing`).
- The `uuid` field is intended for external references (e.g., API identifiers) and is not the primary key.
- Soft deletion is implemented via the `deletedAt` field. Queries should typically filter out deleted entities using `WHERE deleted_at IS NULL`.

## Example Subclass

```java
@Entity
@Table(name = "users")
public class User extends BaseEntity {
    private String username;
    private String email;
    // additional fields, getters, setters...
}
```
