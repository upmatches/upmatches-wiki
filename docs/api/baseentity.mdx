## Overview

The `BaseEntity` class is an abstract base class designed to be extended by other entity classes in a Java application. It provides common fields and functionality for entity classes, such as unique identifiers, audit information, and soft deletion capabilities. This class is annotated with JPA and Spring Data annotations to facilitate database operations and auditing.

## Class Details

### Purpose

The `BaseEntity` class serves as a foundational class for other entities, providing essential fields and methods that are commonly required across different entities. It includes fields for unique identification, creation and modification timestamps, and user information for auditing purposes. Additionally, it supports soft deletion by maintaining a `deletedAt` timestamp.

### Public Methods

| Method Name | Description | Parameters | Return Type |
|-------------|-------------|------------|-------------|
| `isDeleted` | Checks if the entity is marked as deleted. | None | `boolean` |
| `markDeleted` | Marks the entity as deleted by setting the `deletedAt` timestamp to the current time. | None | `void` |

### Fields

- **id**: A unique identifier for the entity, automatically generated.
- **uuid**: A universally unique identifier (UUID) for the entity, generated if not already set.
- **createdAt**: The timestamp when the entity was created, automatically set and immutable.
- **updatedAt**: The timestamp when the entity was last updated, automatically managed.
- **createdBy**: The user who created the entity, set during creation.
- **updatedBy**: The user who last modified the entity, updated automatically.
- **deletedAt**: The timestamp when the entity was marked as deleted, used for soft deletion.

### Annotations

- `@MappedSuperclass`: Indicates that this class is a base class for JPA entities.
- `@EntityListeners(AuditingEntityListener.class)`: Enables auditing of entity changes.
- `@Id`, `@GeneratedValue`: Specifies the primary key and its generation strategy.
- `@Column`: Configures the properties of the database column.
- `@CreatedDate`, `@LastModifiedDate`: Automatically manage date fields for auditing.
- `@CreatedBy`, `@LastModifiedBy`: Automatically manage user fields for auditing.
- `@PrePersist`: Lifecycle callback to initialize the UUID before persisting.

### Usage

The `BaseEntity` class is intended to be extended by other entity classes. By inheriting from `BaseEntity`, derived classes automatically gain the fields and methods defined in this base class, promoting code reuse and consistency across entity classes.
