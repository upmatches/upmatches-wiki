# RepositoryHelper

The `RepositoryHelper` class is a **utility class** that provides static helper methods for common repository operations in a Spring Data JPA-based application. It simplifies tasks such as finding entities by ID or UUID, paginated queries, and deletion (both hard and soft delete). The class is designed to reduce boilerplate code and enforce consistent error handling by throwing `ResourceNotFoundException` when entities are not found.

## Features

- **Find by ID or UUID** with automatic exception handling.
- **Paginated queries** with sorting and mapping.
- **Hard delete** by ID or UUID.
- **Soft delete** by ID or UUID with a custom marking function.

## Public Methods

### `findByIdOrThrow`

Finds an entity by its primary key (ID) or throws a `ResourceNotFoundException`.

| Parameter    | Type                | Description                                      |
|--------------|---------------------|--------------------------------------------------|
| `repository` | `JpaRepository<T, I>` | The Spring Data JPA repository.                |
| `id`         | `I`                 | The entity's primary key.                        |
| `entityClass`| `Class<T>`          | The entity class (used for error messages).      |
| **Returns**  | `T`                 | The found entity.                                |
| **Throws**   | `ResourceNotFoundException` | If the entity is not found.              |

### `findByUuidOrThrow`

Finds an entity by its UUID or throws a `ResourceNotFoundException`.

| Parameter    | Type                | Description                                      |
|--------------|---------------------|--------------------------------------------------|
| `repository` | `UuidRepository<T>` | A repository that supports UUID-based lookup.    |
| `uuid`       | `UUID`              | The entity's UUID.                               |
| `entityClass`| `Class<T>`          | The entity class (used for error messages).      |
| **Returns**  | `T`                 | The found entity.                                |
| **Throws**   | `ResourceNotFoundException` | If the entity is not found.              |

### `findAllPaged`

Retrieves a paginated, sorted, and mapped list of entities.

| Parameter       | Type                  | Description                                      |
|-----------------|-----------------------|--------------------------------------------------|
| `repository`    | `JpaRepository<T, ?>` | The Spring Data JPA repository.                |
| `page`          | `int`                 | The page number (0-indexed).                     |
| `size`          | `int`                 | The page size.                                   |
| `sortBy`        | `String`              | The field name to sort by.                       |
| `sortDirection` | `String`              | The sort direction (`"ASC"` or `"DESC"`).        |
| `mapper`        | `Function<T, R>`      | A function to map entities to the response DTO.  |
| **Returns**     | `PagedResponse<R>`    | A paginated response with mapped data.           |
| **Throws**      | `IllegalArgumentException` | If pagination parameters are invalid.       |

### `deleteByIdOrThrow`

Deletes an entity by its primary key. Throws `ResourceNotFoundException` if not found.

| Parameter    | Type                | Description                                      |
|--------------|---------------------|--------------------------------------------------|
| `repository` | `JpaRepository<T, I>` | The Spring Data JPA repository.                |
| `id`         | `I`                 | The entity's primary key.                        |
| `entityClass`| `Class<T>`          | The entity class (used for error messages).      |
| **Throws**   | `ResourceNotFoundException` | If the entity is not found.              |

### `deleteByUuidOrThrow`

Deletes an entity by its UUID. Throws `ResourceNotFoundException` if not found.

| Parameter    | Type                | Description                                      |
|--------------|---------------------|--------------------------------------------------|
| `repository` | `UuidRepository<T>` | A repository that supports UUID-based lookup.    |
| `uuid`       | `UUID`              | The entity's UUID.                               |
| `entityClass`| `Class<T>`          | The entity class (used for error messages).      |
| **Throws**   | `ResourceNotFoundException` | If the entity is not found.              |

### `softDeleteByIdOrThrow`

Performs a soft delete by ID using a custom marking function.

| Parameter     | Type                   | Description                                      |
|---------------|------------------------|--------------------------------------------------|
| `repository`  | `JpaRepository<T, Long>` | The Spring Data JPA repository (ID must be Long). |
| `id`          | `Long`                 | The entity's primary key.                        |
| `entityClass` | `Class<T>`             | The entity class (used for error messages).      |
| `markDeleted` | `Consumer<T>`          | A function that marks the entity as deleted.     |
| **Throws**    | `ResourceNotFoundException` | If the entity is not found.              |

### `softDeleteByUuidOrThrow`

Performs a soft delete by UUID using a custom marking function.

| Parameter     | Type                   | Description                                      |
|---------------|------------------------|--------------------------------------------------|
| `repository`  | `UuidRepository<T>`    | A repository that supports UUID-based lookup.    |
| `uuid`        | `UUID`                 | The entity's UUID.                               |
| `entityClass` | `Class<T>`             | The entity class (used for error messages).      |
| `markDeleted` | `Consumer<T>`          | A function that marks the entity as deleted.     |
| **Throws**    | `ResourceNotFoundException` | If the entity is not found.              |

## Usage Example

```java
// Find a user by ID
User user = RepositoryHelper.findByIdOrThrow(userRepository, 1L, User.class);

// Find a user by UUID
User user = RepositoryHelper.findByUuidOrThrow(userRepository, uuid, User.class);

// Paginated query with sorting and mapping
PagedResponse<UserDTO> response = RepositoryHelper.findAllPaged(
    userRepository, 0, 10, "createdAt", "DESC", user -> new UserDTO(user)
);

// Hard delete by ID
RepositoryHelper.deleteByIdOrThrow(userRepository, 1L, User.class);

// Soft delete by UUID
RepositoryHelper.softDeleteByUuidOrThrow(
    userRepository, uuid, User.class, user -> user.setDeleted(true)
);
```

## Notes

- This class is **final** and has a **private constructor** to prevent instantiation.
- All methods are **static** and designed for direct invocation.
- The `softDeleteByIdOrThrow` method requires the ID type to be `Long`.
