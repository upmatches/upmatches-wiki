# RepositoryHelper

The `RepositoryHelper` class is a **utility class** that provides static helper methods for common repository operations in a Spring Data JPA-based application. It simplifies CRUD operations by encapsulating repetitive patterns such as finding entities by ID or UUID, paginated queries, and soft/hard deletes, while ensuring consistent error handling via `ResourceNotFoundException`.

This class is part of the `com.upmatches.app.shared.helpers` package and is designed to be used across the application to reduce boilerplate code and enforce a uniform approach to data access.

## Features

- **Find by ID or UUID** with automatic exception throwing if not found.
- **Paginated queries** with validation and custom mapping.
- **Hard delete** by ID or UUID.
- **Soft delete** by ID or UUID using a custom `Consumer` to mark the entity as deleted.

## Public Methods

### `findByIdOrThrow`

Finds an entity by its primary key (ID) or throws a `ResourceNotFoundException`.

| Parameter    | Type                  | Description                                      |
|--------------|-----------------------|--------------------------------------------------|
| `repository` | `JpaRepository<T, I>` | The Spring Data JPA repository.                  |
| `id`         | `I`                   | The entity's ID.                                 |
| `entityClass`| `Class<T>`            | The entity class (used for error messages).      |
| **Returns**  | `T`                   | The found entity.                                |
| **Throws**   | `ResourceNotFoundException` | If no entity is found with the given ID.    |

### `findByUuidOrThrow`

Finds an entity by its UUID or throws a `ResourceNotFoundException`.

| Parameter    | Type                  | Description                                      |
|--------------|-----------------------|--------------------------------------------------|
| `repository` | `UuidRepository<T>`   | A repository that supports UUID-based lookup.    |
| `uuid`       | `UUID`                | The entity's UUID.                               |
| `entityClass`| `Class<T>`            | The entity class (used for error messages).      |
| **Returns**  | `T`                   | The found entity.                                |
| **Throws**   | `ResourceNotFoundException` | If no entity is found with the given UUID. |

### `findAllPaged`

Retrieves a paginated list of entities, maps them to a response DTO, and returns a `PagedResponse`.

| Parameter       | Type                  | Description                                      |
|-----------------|-----------------------|--------------------------------------------------|
| `repository`    | `JpaRepository<T, ?>` | The Spring Data JPA repository.                  |
| `page`          | `int`                 | The page number (0-based).                       |
| `size`          | `int`                 | The page size.                                   |
| `sortBy`        | `String`              | The field name to sort by.                       |
| `sortDirection` | `String`              | The sort direction (`"ASC"` or `"DESC"`).        |
| `mapper`        | `Function<T, R>`      | A function to map entity `T` to response `R`.    |
| **Returns**     | `PagedResponse<R>`    | A paginated response containing mapped results.  |
| **Throws**      | `IllegalArgumentException` | If pagination parameters are invalid.        |

### `deleteByIdOrThrow`

Deletes an entity by its ID after verifying it exists.

| Parameter    | Type                  | Description                                      |
|--------------|-----------------------|--------------------------------------------------|
| `repository` | `JpaRepository<T, I>` | The Spring Data JPA repository.                  |
| `id`         | `I`                   | The entity's ID.                                 |
| `entityClass`| `Class<T>`            | The entity class (used for error messages).      |
| **Throws**   | `ResourceNotFoundException` | If no entity is found with the given ID.    |

### `deleteByUuidOrThrow`

Deletes an entity by its UUID after verifying it exists.

| Parameter    | Type                  | Description                                      |
|--------------|-----------------------|--------------------------------------------------|
| `repository` | `UuidRepository<T>`   | A repository that supports UUID-based lookup.    |
| `uuid`       | `UUID`                | The entity's UUID.                               |
| `entityClass`| `Class<T>`            | The entity class (used for error messages).      |
| **Throws**   | `ResourceNotFoundException` | If no entity is found with the given UUID. |

### `softDeleteByIdOrThrow`

Performs a soft delete on an entity by its ID. The `markDeleted` consumer is used to set the entity's deletion flag before saving.

| Parameter    | Type                  | Description                                      |
|--------------|-----------------------|--------------------------------------------------|
| `repository` | `JpaRepository<T, Long>` | The Spring Data JPA repository (ID must be Long). |
| `id`         | `Long`                | The entity's ID.                                 |
| `entityClass`| `Class<T>`            | The entity class (used for error messages).      |
| `markDeleted`| `Consumer<T>`         | A consumer that marks the entity as deleted.     |
| **Throws**   | `ResourceNotFoundException` | If no entity is found with the given ID.    |

### `softDeleteByUuidOrThrow`

Performs a soft delete on an entity by its UUID. The `markDeleted` consumer is used to set the entity's deletion flag before saving.

| Parameter    | Type                  | Description                                      |
|--------------|-----------------------|--------------------------------------------------|
| `repository` | `UuidRepository<T>`   | A repository that supports UUID-based lookup.    |
| `uuid`       | `UUID`                | The entity's UUID.                               |
| `entityClass`| `Class<T>`            | The entity class (used for error messages).      |
| `markDeleted`| `Consumer<T>`         | A consumer that marks the entity as deleted.     |
| **Throws**   | `ResourceNotFoundException` | If no entity is found with the given UUID. |

## Usage Example

```java
// Find a user by ID
User user = RepositoryHelper.findByIdOrThrow(userRepository, 1L, User.class);

// Find a user by UUID
User user = RepositoryHelper.findByUuidOrThrow(userRepository, uuid, User.class);

// Paginated query with mapping to DTO
PagedResponse<UserDTO> response = RepositoryHelper.findAllPaged(
    userRepository, 0, 10, "createdAt", "DESC", UserDTO::fromEntity
);

// Hard delete
RepositoryHelper.deleteByIdOrThrow(userRepository, 1L, User.class);

// Soft delete
RepositoryHelper.softDeleteByIdOrThrow(
    userRepository, 1L, User.class, user -> user.setDeleted(true)
);
```

## Notes

- This class is **final** and has a **private constructor** to prevent instantiation.
- All methods are **static** and designed to be used as utility functions.
- The `softDelete` methods require a `Consumer<T>` that implements the logic to mark the entity as deleted (e.g., setting a `deleted` flag or timestamp).
