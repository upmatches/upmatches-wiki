## Purpose

The `RepositoryHelper` class is a utility class designed to simplify common operations on repositories in a Spring application. It provides methods for finding, deleting, and soft-deleting entities by their ID or UUID, as well as retrieving paginated responses. This class is final and cannot be instantiated, ensuring that its methods are used in a static context.

## Public Methods

### `findByIdOrThrow`

Finds an entity by its ID or throws a `ResourceNotFoundException` if not found.

| Parameter    | Type                      | Description                              |
|--------------|---------------------------|------------------------------------------|
| `repository` | `JpaRepository<T, I>`     | The repository to search in.             |
| `id`         | `I`                       | The ID of the entity to find.            |
| `entityClass`| `Class<T>`                | The class of the entity.                 |

**Returns:** `T` - The entity found.

### `findByUuidOrThrow`

Finds an entity by its UUID or throws a `ResourceNotFoundException` if not found.

| Parameter    | Type                      | Description                              |
|--------------|---------------------------|------------------------------------------|
| `repository` | `UuidRepository<T>`       | The repository to search in.             |
| `uuid`       | `UUID`                    | The UUID of the entity to find.          |
| `entityClass`| `Class<T>`                | The class of the entity.                 |

**Returns:** `T` - The entity found.

### `findAllPaged`

Retrieves a paginated response of entities, mapped to a different type.

| Parameter      | Type                          | Description                              |
|----------------|-------------------------------|------------------------------------------|
| `repository`   | `JpaRepository<T, ?>`         | The repository to search in.             |
| `page`         | `int`                         | The page number to retrieve.             |
| `size`         | `int`                         | The size of the page.                    |
| `sortBy`       | `String`                      | The property to sort by.                 |
| `sortDirection`| `String`                      | The direction to sort (`asc` or `desc`). |
| `mapper`       | `Function<T, R>`              | Function to map entities to another type.|

**Returns:** `PagedResponse<R>` - The paginated response.

### `deleteByIdOrThrow`

Deletes an entity by its ID or throws a `ResourceNotFoundException` if not found.

| Parameter    | Type                      | Description                              |
|--------------|---------------------------|------------------------------------------|
| `repository` | `JpaRepository<T, I>`     | The repository to delete from.           |
| `id`         | `I`                       | The ID of the entity to delete.          |
| `entityClass`| `Class<T>`                | The class of the entity.                 |

**Returns:** `void`

### `deleteByUuidOrThrow`

Deletes an entity by its UUID or throws a `ResourceNotFoundException` if not found.

| Parameter    | Type                      | Description                              |
|--------------|---------------------------|------------------------------------------|
| `repository` | `UuidRepository<T>`       | The repository to delete from.           |
| `uuid`       | `UUID`                    | The UUID of the entity to delete.        |
| `entityClass`| `Class<T>`                | The class of the entity.                 |

**Returns:** `void`

### `softDeleteByIdOrThrow`

Marks an entity as deleted by its ID without removing it from the database.

| Parameter    | Type                      | Description                              |
|--------------|---------------------------|------------------------------------------|
| `repository` | `JpaRepository<T, Long>`  | The repository to update.                |
| `id`         | `Long`                    | The ID of the entity to mark as deleted. |
| `entityClass`| `Class<T>`                | The class of the entity.                 |
| `markDeleted`| `Consumer<T>`             | Function to mark the entity as deleted.  |

**Returns:** `void`

### `softDeleteByUuidOrThrow`

Marks an entity as deleted by its UUID without removing it from the database.

| Parameter    | Type                      | Description                              |
|--------------|---------------------------|------------------------------------------|
| `repository` | `UuidRepository<T>`       | The repository to update.                |
| `uuid`       | `UUID`                    | The UUID of the entity to mark as deleted.|
| `entityClass`| `Class<T>`                | The class of the entity.                 |
| `markDeleted`| `Consumer<T>`             | Function to mark the entity as deleted.  |

**Returns:** `void`
