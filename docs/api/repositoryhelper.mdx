# RepositoryHelper

The `RepositoryHelper` class is a **final utility class** that provides static helper methods for common database operations in a Spring Data JPA application. It is designed to reduce boilerplate code when performing CRUD operations on entities, especially those that use both numeric IDs and UUIDs.

This class is part of the `com.upmatches.app.shared.helpers` package and relies on custom exceptions (`ResourceNotFoundException`) and custom repository interfaces (`UuidRepository`).

## Purpose

- **Simplify common repository operations** such as finding, deleting, and soft-deleting entities.
- **Provide consistent error handling** by throwing `ResourceNotFoundException` when an entity is not found.
- **Support paginated queries** with sorting and mapping to DTOs.
- **Enforce utility class pattern** by having a private constructor that throws `IllegalStateException`.

## Public Methods

### `findByIdOrThrow`

Finds an entity by its primary key (ID) or throws a `ResourceNotFoundException`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `repository` | `JpaRepository<T, I>` | The Spring Data JPA repository for the entity |
| `id` | `I` | The primary key of the entity |
| `entityClass` | `Class<T>` | The entity class (used for error messages) |
| **Returns** | `T` | The found entity |

**Throws:** `ResourceNotFoundException` if the entity is not found.

### `findByUuidOrThrow`

Finds an entity by its UUID or throws a `ResourceNotFoundException`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `repository` | `UuidRepository<T>` | A custom repository that supports UUID-based lookups |
| `uuid` | `UUID` | The UUID of the entity |
| `entityClass` | `Class<T>` | The entity class (used for error messages) |
| **Returns** | `T` | The found entity |

**Throws:** `ResourceNotFoundException` if the entity is not found.

### `findAllPaged`

Retrieves a paginated list of entities, maps them to a different type, and returns a `PagedResponse`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `repository` | `JpaRepository<T, ?>` | The Spring Data JPA repository for the entity |
| `page` | `int` | The page number (0-indexed) |
| `size` | `int` | The number of items per page |
| `sortBy` | `String` | The field name to sort by |
| `sortDirection` | `String` | The sort direction (`"ASC"` or `"DESC"`) |
| `mapper` | `Function<T, R>` | A function to map entity `T` to response type `R` |
| **Returns** | `PagedResponse<R>` | A paginated response containing mapped items |

**Throws:** `IllegalArgumentException` if pagination parameters are invalid (validated by `ValidationHelper`).

### `deleteByIdOrThrow`

Deletes an entity by its primary key. First finds the entity, then deletes it.

| Parameter | Type | Description |
|-----------|------|-------------|
| `repository` | `JpaRepository<T, I>` | The Spring Data JPA repository for the entity |
| `id` | `I` | The primary key of the entity to delete |
| `entityClass` | `Class<T>` | The entity class (used for error messages) |

**Throws:** `ResourceNotFoundException` if the entity is not found.

### `deleteByUuidOrThrow`

Deletes an entity by its UUID. First finds the entity, then deletes it.

| Parameter | Type | Description |
|-----------|------|-------------|
| `repository` | `UuidRepository<T>` | A custom repository that supports UUID-based lookups |
| `uuid` | `UUID` | The UUID of the entity to delete |
| `entityClass` | `Class<T>` | The entity class (used for error messages) |

**Throws:** `ResourceNotFoundException` if the entity is not found.

### `softDeleteByIdOrThrow`

Performs a soft delete on an entity identified by its numeric ID. The actual deletion logic is provided by a `Consumer` callback.

| Parameter | Type | Description |
|-----------|------|-------------|
| `repository` | `JpaRepository<T, Long>` | The Spring Data JPA repository for the entity |
| `id` | `Long` | The numeric ID of the entity |
| `entityClass` | `Class<T>` | The entity class (used for error messages) |
| `markDeleted` | `Consumer<T>` | A callback that marks the entity as deleted (e.g., sets a `deletedAt` field) |

**Throws:** `ResourceNotFoundException` if the entity is not found.

### `softDeleteByUuidOrThrow`

Performs a soft delete on an entity identified by its UUID. The actual deletion logic is provided by a `Consumer` callback.

| Parameter | Type | Description |
|-----------|------|-------------|
| `repository` | `UuidRepository<T>` | A custom repository that supports UUID-based lookups |
| `uuid` | `UUID` | The UUID of the entity |
| `entityClass` | `Class<T>` | The entity class (used for error messages) |
| `markDeleted` | `Consumer<T>` | A callback that marks the entity as deleted (e.g., sets a `deletedAt` field) |

**Throws:** `ResourceNotFoundException` if the entity is not found.

## Usage Example

```java
// Find a User by ID
User user = RepositoryHelper.findByIdOrThrow(userRepository, 1L, User.class);

// Find a Product by UUID
Product product = RepositoryHelper.findByUuidOrThrow(productRepository, uuid, Product.class);

// Get paginated DTOs
PagedResponse<UserDTO> users = RepositoryHelper.findAllPaged(
    userRepository, 0, 10, "createdAt", "DESC", UserDTO::fromEntity
);

// Soft delete a User
RepositoryHelper.softDeleteByIdOrThrow(
    userRepository, 1L, User.class, user -> user.setDeletedAt(LocalDateTime.now())
);
```
