# IUpdateActivityService Interface

The `IUpdateActivityService` interface defines the contract for updating an existing activity in the system. It follows a sealed interface pattern to restrict implementation to a single concrete class (`UpdateActivityService`), ensuring controlled and consistent update behavior across the application.

## Purpose

This interface serves as the abstraction layer for the activity update use case. By sealing the interface, the design enforces that only the designated `UpdateActivityService` class can implement the update logic, preventing unintended implementations and promoting a clear, single-responsibility architecture.

## Interface Definition

```java
public sealed interface IUpdateActivityService permits UpdateActivityService {
    ActivityResponse execute(UUID id, UpdateActivityRequest request);
}
```

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(UUID id, UpdateActivityRequest request)` | `ActivityResponse` | Updates an existing activity identified by the given UUID with the provided request data and returns the updated activity response. |

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to be updated. |
| `request` | `UpdateActivityRequest` | The request object containing the updated activity data. |

## Return Type

| Type | Description |
|------|-------------|
| `ActivityResponse` | The response object representing the updated activity after successful modification. |

## Usage Example

```java
// Assuming the implementation is injected via dependency injection
IUpdateActivityService updateActivityService = new UpdateActivityService(/* dependencies */);

UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UpdateActivityRequest request = new UpdateActivityRequest(/* updated fields */);

ActivityResponse updatedActivity = updateActivityService.execute(activityId, request);
```

## Related Components

- **`UpdateActivityRequest`**: The input data transfer object containing the fields to be updated.
- **`ActivityResponse`**: The output data transfer object representing the updated activity state.
- **`UpdateActivityService`**: The sole permitted implementation class that contains the actual update logic.
