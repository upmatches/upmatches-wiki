# IUpdateActivityService Interface

The `IUpdateActivityService` interface defines the contract for updating an existing activity in the system. It follows a sealed interface pattern to restrict implementation to a single concrete class (`UpdateActivityService`), ensuring controlled and consistent update behavior across the application.

## Purpose

This interface encapsulates the business logic for modifying activity details. By defining a single `execute` method, it provides a clear and focused API for updating activities, promoting separation of concerns and testability.

## Interface Definition

```java
public sealed interface IUpdateActivityService permits UpdateActivityService {
    ActivityResponse execute(UUID id, UpdateActivityRequest request);
}
```

- **Sealed Interface**: The `sealed` keyword restricts which classes can implement this interface. Only `UpdateActivityService` is permitted, ensuring that all update operations follow the same implementation pattern.
- **Single Method**: The interface contains one method, `execute`, which takes an activity ID and an update request, returning an `ActivityResponse`.

## Method Documentation

### `execute`

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to be updated. |
| `request` | `UpdateActivityRequest` | An object containing the updated activity data. |
| **Returns** | `ActivityResponse` | The response object containing the updated activity details. |

**Behavior**: This method processes the update request for the specified activity ID and returns the updated activity information. The concrete implementation (`UpdateActivityService`) handles validation, persistence, and response mapping.

## Usage Example

```java
// Assuming dependency injection provides an instance
IUpdateActivityService updateService = new UpdateActivityService(/* dependencies */);

UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UpdateActivityRequest request = new UpdateActivityRequest(/* updated fields */);

ActivityResponse response = updateService.execute(activityId, request);
```

## Related Components

- **`UpdateActivityRequest`**: The input DTO containing the fields to be updated.
- **`ActivityResponse`**: The output DTO representing the updated activity.
- **`UpdateActivityService`**: The sole permitted implementation of this interface.
