# IUpdateActivityService Interface

The `IUpdateActivityService` interface defines the contract for updating an existing activity within the application. It is a sealed interface, meaning only the explicitly permitted class (`UpdateActivityService`) can implement it. This design enforces a controlled extension point for the update activity use case.

## Purpose

This interface serves as the service layer abstraction for the "Update Activity" feature. It encapsulates the business logic required to modify an activity's details, such as its name, description, or schedule. By defining a single `execute` method, it follows the Command Pattern, promoting separation of concerns and testability.

## Interface Definition

```java
public sealed interface IUpdateActivityService permits UpdateActivityService {
    ActivityResponse execute(UUID id, UpdateActivityRequest request);
}
```

## Methods

### `execute`

Updates an existing activity identified by its unique ID with the provided request data.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to be updated. |
| `request` | `UpdateActivityRequest` | The request object containing the updated activity data. |

| Returns | Type | Description |
|---------|------|-------------|
| `ActivityResponse` | `ActivityResponse` | The response object containing the updated activity details. |

## Usage Example

```java
// Assuming an implementation is injected
IUpdateActivityService updateActivityService = new UpdateActivityService(/* dependencies */);

UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UpdateActivityRequest request = new UpdateActivityRequest("Updated Title", "Updated Description");

ActivityResponse response = updateActivityService.execute(activityId, request);
```

## Dependencies

- `UpdateActivityRequest` – The input data transfer object containing the fields to be updated.
- `ActivityResponse` – The output data transfer object representing the updated activity state.
- `UpdateActivityService` – The sole permitted implementation of this interface.

## Notes

- The interface is **sealed**, ensuring that only `UpdateActivityService` can implement it. This prevents unauthorized extensions and maintains a clear architecture.
- The `execute` method is synchronous and returns the updated activity data immediately after the update operation completes.
- The `UUID` parameter ensures that the correct activity is targeted for modification.
