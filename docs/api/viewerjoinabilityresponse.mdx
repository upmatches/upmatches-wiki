# ViewerJoinabilityResponse

The `ViewerJoinabilityResponse` record is a data carrier used to communicate whether a viewer is allowed to join a game session. It encapsulates three key pieces of information: a boolean flag indicating joinability, an optional reason for denial, and a list of warnings that may accompany either an allowed or blocked response.

This record is designed to be immutable and provides factory methods for creating common response states, ensuring that the `warnings` list is never null (it defaults to an empty list if null is passed).

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `canJoin` | `Boolean` | Indicates whether the viewer is allowed to join (`true`) or blocked (`false`). |
| `reason` | `JoinabilityReason` | The reason why the viewer is blocked. This is `null` when `canJoin` is `true`. |
| `warnings` | `List<JoinabilityWarning>` | A list of warnings associated with the joinability decision. Guaranteed to be non-null and unmodifiable. |

## Public Methods

### `allowed(List<JoinabilityWarning> warnings)`

Creates a response indicating that the viewer is allowed to join.

| Parameter | Type | Description |
|-----------|------|-------------|
| `warnings` | `List<JoinabilityWarning>` | A list of warnings to include. If `null`, an empty list is used. |

**Returns:** `ViewerJoinabilityResponse` with `canJoin` set to `true` and `reason` set to `null`.

### `blocked(JoinabilityReason reason, List<JoinabilityWarning> warnings)`

Creates a response indicating that the viewer is blocked from joining.

| Parameter | Type | Description |
|-----------|------|-------------|
| `reason` | `JoinabilityReason` | The reason why the viewer is blocked. Must not be `null`. |
| `warnings` | `List<JoinabilityWarning>` | A list of warnings to include. If `null`, an empty list is used. |

**Returns:** `ViewerJoinabilityResponse` with `canJoin` set to `false` and `reason` set to the provided value.

## Usage Example

```java
// Create an allowed response with warnings
List<JoinabilityWarning> warnings = List.of(JoinabilityWarning.LOW_BALANCE);
ViewerJoinabilityResponse allowedResponse = ViewerJoinabilityResponse.allowed(warnings);

// Create a blocked response with a reason and warnings
ViewerJoinabilityResponse blockedResponse = ViewerJoinabilityResponse.blocked(
    JoinabilityReason.ACCOUNT_SUSPENDED,
    List.of(JoinabilityWarning.VIOLATION_DETECTED)
);
```
