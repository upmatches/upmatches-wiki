## ViewerJoinabilityResponse Class

The `ViewerJoinabilityResponse` class is a Java record that encapsulates the response related to a viewer's ability to join a game. It provides information on whether a viewer can join, the reason if they cannot, and any warnings associated with the joinability status.

### Public Methods

The class provides two static factory methods to create instances of `ViewerJoinabilityResponse`. These methods are designed to clearly indicate whether joining is allowed or blocked, along with any relevant warnings.

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `allowed` | `List<JoinabilityWarning> warnings` | `ViewerJoinabilityResponse` | Creates a response indicating that joining is allowed. It accepts a list of warnings that might be relevant even when joining is permitted. |
| `blocked` | `JoinabilityReason reason`, `List<JoinabilityWarning> warnings` | `ViewerJoinabilityResponse` | Creates a response indicating that joining is blocked. It requires a reason for blocking and accepts a list of warnings. |

### Parameters

- **canJoin**: A `Boolean` indicating if the viewer can join the game.
- **reason**: A `JoinabilityReason` enum value providing the reason for blocking, if applicable.
- **warnings**: A `List` of `JoinabilityWarning` enum values that provide additional context or warnings related to the joinability status.

### Private Methods

The class includes a private utility method to handle warnings safely:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `safeWarnings` | `List<JoinabilityWarning> warnings` | `List<JoinabilityWarning>` | Ensures that the list of warnings is non-null by returning an empty list if the input is null, or a copy of the list if it is not. |

This design ensures that the `ViewerJoinabilityResponse` is robust and handles null warnings gracefully, providing a consistent API for determining a viewer's joinability status.
