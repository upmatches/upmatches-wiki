import com.upmatches.app.features.game.enums.JoinabilityReason;
import com.upmatches.app.features.game.enums.JoinabilityWarning;

## Purpose

The `ViewerJoinabilityResponse` class is a Java record that encapsulates the response for a viewer's ability to join a game. It provides information on whether joining is allowed, the reason for any restriction, and any warnings associated with the joinability status.

## Public Methods

The class provides the following public static methods:

### `allowed`

Creates a `ViewerJoinabilityResponse` indicating that joining is allowed.

| Parameter | Type                              | Description                              |
|-----------|-----------------------------------|------------------------------------------|
| warnings  | `List<JoinabilityWarning>`        | A list of warnings associated with the joinability status. |

| Return Type                      | Description                              |
|----------------------------------|------------------------------------------|
| `ViewerJoinabilityResponse`      | A response indicating joining is allowed. |

### `blocked`

Creates a `ViewerJoinabilityResponse` indicating that joining is blocked.

| Parameter | Type                              | Description                              |
|-----------|-----------------------------------|------------------------------------------|
| reason    | `JoinabilityReason`               | The reason why joining is blocked.       |
| warnings  | `List<JoinabilityWarning>`        | A list of warnings associated with the joinability status. |

| Return Type                      | Description                              |
|----------------------------------|------------------------------------------|
| `ViewerJoinabilityResponse`      | A response indicating joining is blocked. |

## Private Methods

### `safeWarnings`

A helper method that ensures the warnings list is safe to use by returning an empty list if the input is `null`, or a copy of the list otherwise.

| Parameter | Type                              | Description                              |
|-----------|-----------------------------------|------------------------------------------|
| warnings  | `List<JoinabilityWarning>`        | A list of warnings to be processed.      |

| Return Type                      | Description                              |
|----------------------------------|------------------------------------------|
| `List<JoinabilityWarning>`       | A safe list of warnings.                 |
