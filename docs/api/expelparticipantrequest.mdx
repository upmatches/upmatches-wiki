# ExpelParticipantRequest

The `ExpelParticipantRequest` class is a Java record used to encapsulate the data required when expelling a participant from a game. It provides a simple, immutable data structure that includes an optional reason for the expulsion.

## Purpose

This record is designed to be used as a request body in API endpoints that handle participant expulsion. It ensures that any provided reason does not exceed 280 characters, enforcing a business rule for user-generated content.

## Record Structure

| Field    | Type     | Constraints                                                                 | Description                                      |
|----------|----------|-----------------------------------------------------------------------------|--------------------------------------------------|
| `reason` | `String` | `@Size(max = 280)` – Must be at most 280 characters. | An optional explanation for why the participant is being expelled. |

## Constructor

The record has an implicit canonical constructor that accepts a single `String` parameter for the `reason` field. The `@Size` validation annotation is applied to this parameter.

## Validation

The `reason` field is validated using Jakarta Bean Validation (`jakarta.validation.constraints.Size`). If a value longer than 280 characters is provided, a validation error with the message "Reason must be at most 280 characters." will be triggered.

## Usage Example

```java
// Creating a valid request with a reason
ExpelParticipantRequest request = new ExpelParticipantRequest("Violation of community guidelines");

// Creating a request without a reason (null is allowed)
ExpelParticipantRequest emptyRequest = new ExpelParticipantRequest(null);
```

## Notes

- The `reason` field is optional and can be `null`.
- The record is immutable, meaning once created, its values cannot be changed.
- This class is part of the `com.upmatches.app.features.game.requests` package.
