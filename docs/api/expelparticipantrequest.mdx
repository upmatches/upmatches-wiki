# ExpelParticipantRequest

The `ExpelParticipantRequest` class is a Java record used to encapsulate the data required when expelling a participant from a game or match. It provides a simple, immutable data structure that includes an optional reason for the expulsion.

## Purpose

This record serves as a request DTO (Data Transfer Object) for the expulsion operation. It ensures that any reason provided adheres to a maximum length constraint, helping to maintain data integrity and prevent excessively long messages.

## Record Definition

```java
public record ExpelParticipantRequest(
    @Size(max = 280, message = "Reason must be at most 280 characters.")
    String reason
)
```

## Fields

| Field    | Type     | Description                                                                 | Constraints                                      |
|----------|----------|-----------------------------------------------------------------------------|--------------------------------------------------|
| `reason` | `String` | An optional explanation for why the participant is being expelled.          | Maximum length of 280 characters (Jakarta Bean Validation `@Size` annotation). |

## Constructor

The record has an implicit canonical constructor that accepts a single `String` parameter for the `reason` field.

## Methods

Since this is a Java record, the following methods are automatically generated:

| Method                    | Return Type | Description                                                      |
|---------------------------|-------------|------------------------------------------------------------------|
| `reason()`                | `String`    | Returns the reason for expulsion (may be `null`).                |
| `toString()`              | `String`    | Returns a string representation of the record.                   |
| `equals(Object o)`        | `boolean`   | Compares this record to another object for equality.             |
| `hashCode()`              | `int`       | Returns a hash code value for this record.                       |

## Usage Example

```java
// Creating a request with a reason
ExpelParticipantRequest request = new ExpelParticipantRequest("Violation of community guidelines");

// Creating a request without a reason
ExpelParticipantRequest emptyRequest = new ExpelParticipantRequest(null);

// Accessing the reason
String reason = request.reason(); // Returns "Violation of community guidelines"
```

## Validation

The `reason` field is validated using Jakarta Bean Validation. If a reason is provided that exceeds 280 characters, a `ConstraintViolationException` will be thrown with the message "Reason must be at most 280 characters."

## Notes

- The `reason` field is optional and can be `null`.
- This record is immutable and thread-safe.
- The validation constraint only applies when the field is not `null`; `null` values are allowed.
