# GetActivityService

The `GetActivityService` class is a Spring service component responsible for retrieving a single `Activity` entity by its unique identifier (UUID). It implements the `IGetActivityService` interface and provides a transactional, read-only operation that fetches an activity from the database and converts it into an `ActivityResponse` DTO.

## Purpose

This service encapsulates the business logic for fetching an activity by ID. It handles:
- Database lookup using the `ActivityRepository`
- Error handling when the activity is not found (throws `ResourceNotFoundException`)
- Conversion of the entity to a response DTO
- Execution within a read-only transaction for performance optimization

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Constructor Injection | Spring Data JPA repository for `Activity` entities |

## Public Methods

### `execute(UUID id)`

Retrieves an activity by its unique identifier and returns a response DTO.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to retrieve |

| Returns | Type | Description |
|---------|------|-------------|
| Success | `ActivityResponse` | The activity data wrapped in a response DTO |
| Failure | Throws `ResourceNotFoundException` | If no activity exists with the given ID |

**Example Usage:**

```java
@Autowired
private GetActivityService getActivityService;

public void someMethod() {
    UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
    ActivityResponse response = getActivityService.execute(activityId);
    // Use response...
}
```

## Error Handling

The service uses `ServiceOperationExecutor` to wrap the retrieval operation with standardized error handling. If the activity is not found, it throws a `ResourceNotFoundException` with a message formatted as:

```
Activity with ID '<uuid>' not found.
```

## Transactional Behavior

The `execute` method is annotated with `@Transactional(readOnly = true)`, which:
- Ensures the database operation runs within a transaction context
- Optimizes performance by allowing the database to use read-only optimizations
- Prevents any unintended write operations

## Implementation Details

The service follows a clean architecture pattern:
1. **Repository Layer**: `ActivityRepository` handles database access
2. **Service Layer**: `GetActivityService` contains business logic
3. **Response Layer**: `ActivityResponse` provides a DTO for API responses

The `non-sealed` modifier indicates this class can be extended by other classes in the same module, providing flexibility for future enhancements.
