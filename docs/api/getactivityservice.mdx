# GetActivityService

The `GetActivityService` class is a Spring service component responsible for retrieving a single `Activity` entity by its unique identifier (UUID). It implements the `IGetActivityService` interface and provides a transactional, read-only operation that fetches an activity from the database and returns it as an `ActivityResponse` DTO.

## Purpose

This service encapsulates the business logic for fetching an activity by ID. It handles the following concerns:
- Database retrieval via `ActivityRepository`
- Error handling when the activity is not found (throws `ResourceNotFoundException`)
- Conversion from the `Activity` entity to the `ActivityResponse` DTO
- Transaction management (read-only)
- Consistent operation execution and error wrapping via `ServiceOperationExecutor`

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Constructor injection | Repository for accessing `Activity` entities in the database |

## Public Methods

### `execute(UUID id)`

Retrieves an activity by its unique identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to retrieve |

| Returns | Type | Description |
|---------|------|-------------|
| `ActivityResponse` | DTO | The activity data wrapped in a response object |

**Throws:**
- `ResourceNotFoundException` – If no activity exists with the given ID

**Transactional Behavior:** Read-only transaction

**Example Usage:**
```java
@Autowired
private GetActivityService getActivityService;

public void someMethod() {
    UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
    ActivityResponse response = getActivityService.execute(activityId);
    // Use response data
}
```

## Error Handling

The service uses a custom error message template:
```
Activity with ID '%s' not found.
```

Where `%s` is replaced with the provided UUID. The `ResourceNotFoundException` is thrown when the activity is not found in the database.

## Implementation Details

- The class is declared as `non-sealed`, allowing it to be extended by other classes in the same package
- Uses `ServiceOperationExecutor.execute()` for consistent operation tracking and error handling
- The `RETRIEVE` operation status is passed to indicate this is a retrieval operation
- The `ResourceNotFoundException` constructor reference is passed as a fallback error handler
