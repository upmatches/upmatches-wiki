## Overview

The `InfisicalSecretProvider` class is a custom implementation of the `EnvironmentPostProcessor` interface in a Spring Boot application. It is designed to integrate with the Infisical SDK to fetch and manage secrets from the Infisical platform. This class is responsible for loading secrets into the application's environment, either from a `.env` file or directly from Infisical, and securely handling sensitive information.

## Public Methods

The class provides several public methods to interact with the environment and manage secrets. Below is a detailed documentation of these methods:

### `postProcessEnvironment`

This method is the entry point for the `EnvironmentPostProcessor` interface. It processes the application's environment to load secrets from Infisical or a `.env` file.

| Parameter     | Type                        | Description                                                                 |
|---------------|-----------------------------|-----------------------------------------------------------------------------|
| `environment` | `ConfigurableEnvironment`   | The environment to be processed.                                            |
| `application` | `SpringApplication`         | The Spring application instance.                                            |

### `setDotEnvPath`

Sets the path to the `.env` file that should be loaded into the environment.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| `path`    | `Path` | The path to the `.env` file.         |

### `InfisicalConfig` (Record)

The `InfisicalConfig` record is used to encapsulate configuration details required to connect to Infisical.

| Field          | Type     | Description                                      |
|----------------|----------|--------------------------------------------------|
| `clientId`     | `String` | The client ID for Infisical authentication.      |
| `clientSecret` | `String` | The client secret for Infisical authentication.  |
| `projectId`    | `String` | The project ID in Infisical.                     |
| `hostUri`      | `String` | The URI of the Infisical host.                   |
| `environment`  | `String` | The environment name (e.g., dev, prod).          |
| `secretPath`   | `String` | The path to the secrets in Infisical.            |

## Key Features

- **Environment Integration**: The class integrates with the Spring Boot environment to inject secrets.
- **Secure File Handling**: Secrets are written to secure temporary files with appropriate file permissions.
- **Infisical SDK Usage**: Utilizes the Infisical SDK to authenticate and fetch secrets.
- **Fallback to `.env`**: Supports loading secrets from a `.env` file if Infisical configuration is not provided.
- **Shutdown Hook**: Registers a shutdown hook to clean up temporary files created during the application's lifecycle.

## Usage

To use the `InfisicalSecretProvider`, ensure that it is included in the Spring Boot application's configuration. The class will automatically process the environment during application startup, fetching and injecting secrets as configured.
