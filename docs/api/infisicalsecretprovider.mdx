# InfisicalSecretProvider

## Purpose

The `InfisicalSecretProvider` class is a Spring Boot `EnvironmentPostProcessor` that integrates with [Infisical](https://infisical.com/) to securely fetch and inject secrets into the application's environment at startup. It provides a bridge between Infisical's secret management platform and Spring's configuration system, ensuring sensitive configuration values are never hardcoded or stored in plain text.

The class supports three modes of operation:
1. **Infisical Integration**: Fetches secrets from Infisical using client credentials authentication
2. **Environment Variable Fallback**: Maps environment variables to Spring configuration properties when Infisical is not configured
3. **.env File Support**: Loads configuration from a `.env` file as a fallback

## Key Features

- **Secure Key Storage**: Writes sensitive key material (e.g., Singpass keys) to temporary files with restricted POSIX permissions
- **Automatic Cleanup**: Registers a JVM shutdown hook to clean up temporary files
- **Configurable Mappings**: Maps Infisical secrets to specific Spring configuration properties
- **Multiple Resolution Strategies**: Supports property files, environment variables, and system properties

## Public Methods

### `postProcessEnvironment(ConfigurableEnvironment, SpringApplication)`

The main entry point called by Spring Boot during application startup. Orchestrates the secret resolution process.

| Parameter | Type | Description |
|-----------|------|-------------|
| `environment` | `ConfigurableEnvironment` | The Spring environment to modify |
| `application` | `SpringApplication` | The Spring application instance |

**Returns**: `void`

**Behavior**:
1. Attempts to load `.env` file if present
2. Resolves Infisical configuration from environment/properties
3. If Infisical is configured, fetches and processes secrets
4. If Infisical is not configured, falls back to environment variable mappings

### `setDotEnvPath(Path)`

Sets a custom path for the `.env` file. Primarily used for testing.

| Parameter | Type | Description |
|-----------|------|-------------|
| `path` | `Path` | Custom path to the `.env` file |

**Returns**: `void`

## Configuration Properties

### Infisical Connection

| Property | Environment Variable | Required | Default | Description |
|----------|---------------------|----------|---------|-------------|
| `app.infisical.client-id` | `INFISICAL_CLIENT_ID` | Yes | - | Infisical client ID for authentication |
| `app.infisical.client-secret` | `INFISICAL_CLIENT_SECRET` | Yes | - | Infisical client secret |
| `app.infisical.project-id` | `INFISICAL_PROJECT_ID` | Yes | - | Infisical project ID |
| `app.infisical.host-uri` | `INFISICAL_HOST_URI` | No | `https://app.infisical.com` | Infisical API host |
| `app.infisical.environment` | `INFISICAL_ENVIRONMENT` | No | `dev` | Target environment |
| `app.infisical.secret-path` | `INFISICAL_SECRET_PATH` | No | `/` | Secret path within project |

### Secret Mappings

The class defines two categories of secret mappings:

**Key Secrets** (written to temporary files):
| Infisical Secret | Spring Property |
|-----------------|-----------------|
| `SINGPASS_PRIVATE_SIGNING_KEY` | `app.singpass.private-signing-key-path` |
| `SINGPASS_PRIVATE_ENCRYPTION_KEY` | `app.singpass.private-encryption-key-path` |

**Configuration Secrets** (injected directly):
| Infisical Secret | Spring Property |
|-----------------|-----------------|
| `AUTH0_CLIENT_SECRET` | `app.auth0.client-secret` |
| `FIREBASE_ADMIN_SDK` | `app.firebase.service-account-json` |

## Internal Methods

### `resolveConfig(ConfigurableEnvironment)`

Resolves Infisical configuration from environment/properties. Returns `null` if `INFISICAL_CLIENT_ID` is not configured.

### `fetchSecrets(InfisicalConfig, ConfigurableEnvironment)`

Connects to Infisical, authenticates, and fetches secrets for the configured project/environment/path.

### `processSecrets(List<Secret>)`

Processes fetched secrets and maps them to Spring configuration properties. Key secrets are written to temporary files.

### `writeSecureTemporaryFile(String)`

Creates a temporary file with restricted permissions (owner read-only) and returns its absolute path.

### `loadDotEnvFile(ConfigurableEnvironment)`

Loads properties from a `.env` file and adds them to the environment.

### `mapEnvVarSecrets(ConfigurableEnvironment)`

Maps environment variables to Spring configuration properties when Infisical is not configured.

## Error Handling

- Throws `IllegalStateException` if required Infisical configuration is missing
- Throws `IllegalStateException` if no secrets are returned from Infisical
- Throws `IllegalStateException` if connection to Infisical fails
- Logs warnings for `.env` file loading failures and temporary file cleanup failures

## Security Considerations

- Temporary files are created with POSIX permissions `r--------` (owner read-only)
- Key files are stored in a dedicated directory under `java.io.tmpdir`
- A shutdown hook ensures cleanup of temporary files
- Secret values are never logged in plain text

## Usage Example

```java
// Configuration in application.yml
app:
  infisical:
    client-id: ${INFISICAL_CLIENT_ID}
    client-secret: ${INFISICAL_CLIENT_SECRET}
    project-id: ${INFISICAL_PROJECT_ID}
    environment: production
    secret-path: /api
```

The provider automatically processes these configurations during Spring Boot startup.
