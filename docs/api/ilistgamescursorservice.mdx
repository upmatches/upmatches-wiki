# IListGamesCursorService Interface

The `IListGamesCursorService` interface defines a contract for retrieving a paginated list of games using cursor-based pagination. This approach is commonly used in modern APIs to efficiently handle large datasets by providing a cursor (e.g., a unique identifier or timestamp) that points to a specific position in the result set, rather than using traditional offset-based pagination.

## Purpose

This interface is part of the game listing feature within the application. It provides a standardized way to fetch games with filtering capabilities and cursor-based pagination, enabling efficient and scalable data retrieval for game catalogs, search results, or user-specific game lists.

## Interface Definition

The interface is declared as `sealed`, meaning it restricts which classes or interfaces can implement it. In this case, only `ListGamesCursorService` is permitted to implement this interface.

```java
public sealed interface IListGamesCursorService permits ListGamesCursorService {
    // Method definition
}
```

## Method Details

### `execute`

```java
CursorPagedResponse<GameResponse> execute(ListGamesCursorFilterRequest filter, String cursor, int size)
```

Retrieves a paginated list of games using cursor-based pagination.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `filter` | `ListGamesCursorFilterRequest` | Filter criteria to apply when querying games (e.g., genre, platform, release date range) |
| `cursor` | `String` | The cursor indicating the position from which to start fetching results. Typically an encoded identifier or timestamp. Pass `null` or empty string for the first page |
| `size` | `int` | The maximum number of game records to return in a single page |

**Returns:**

| Return Type | Description |
|-------------|-------------|
| `CursorPagedResponse<GameResponse>` | A response object containing the paginated list of games, along with cursor information for navigating to the next page |

## Usage Example

```java
// Create an instance of the service (implementation)
IListGamesCursorService gameService = new ListGamesCursorService();

// Prepare filter criteria
ListGamesCursorFilterRequest filter = new ListGamesCursorFilterRequest();
filter.setGenre("Action");
filter.setPlatform("PC");

// Fetch the first page of results
CursorPagedResponse<GameResponse> firstPage = gameService.execute(filter, null, 20);

// Process results
for (GameResponse game : firstPage.getItems()) {
    System.out.println("Game: " + game.getTitle());
}

// Use the next cursor to fetch subsequent pages
String nextCursor = firstPage.getNextCursor();
if (nextCursor != null) {
    CursorPagedResponse<GameResponse> secondPage = gameService.execute(filter, nextCursor, 20);
    // Process second page...
}
```

## Notes

- The cursor-based pagination approach is particularly useful for real-time data feeds and infinite scroll implementations
- The sealed interface pattern ensures that only the designated implementation class can implement this interface, providing better control over the API contract
- The `CursorPagedResponse` typically contains both the list of items and metadata such as the next cursor for pagination
