## Overview

The `IListGamesCursorService` interface is part of the `com.upmatches.app.features.game.services` package. It defines a contract for services that provide paginated lists of games using a cursor-based pagination mechanism. This interface ensures that any implementing class will provide a method to retrieve a list of games based on specific filtering criteria, a cursor for pagination, and a specified page size.

## Public Methods

### `execute`

This method retrieves a paginated list of games based on the provided filter criteria, cursor, and page size. It returns a `CursorPagedResponse` containing `GameResponse` objects.

| Parameter | Type                                         | Description                                                                 |
|-----------|----------------------------------------------|-----------------------------------------------------------------------------|
| `filter`  | `ListGamesCursorFilterRequest`               | The filter criteria to apply when retrieving the list of games.             |
| `cursor`  | `String`                                     | The cursor indicating the starting point for the page of results to return. |
| `size`    | `int`                                        | The number of game records to return in the response.                       |

#### Returns

- `CursorPagedResponse<GameResponse>`: A paginated response containing the list of games that match the filter criteria.
