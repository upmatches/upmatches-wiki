# IListGamesCursorService Interface

The `IListGamesCursorService` interface defines a contract for retrieving a paginated list of games using cursor-based pagination. This sealed interface is designed to provide a standardized way to fetch game data with filtering capabilities, returning results in a cursor-based paginated format.

## Purpose

This interface serves as the abstraction layer for game listing operations that require:
- **Cursor-based pagination**: Efficiently navigate through large datasets without traditional page numbers
- **Filtering capabilities**: Apply filters to narrow down game results
- **Type-safe responses**: Return structured, typed responses for game data

## Interface Definition

```java
public sealed interface IListGamesCursorService permits ListGamesCursorService
```

The interface is declared as `sealed`, meaning only the specified class `ListGamesCursorService` is permitted to implement it. This ensures controlled inheritance and maintains a strict contract for the implementation.

## Method Summary

### `execute`

```java
CursorPagedResponse<GameResponse> execute(ListGamesCursorFilterRequest filter, String cursor, int size)
```

Executes a cursor-based paginated query to retrieve a list of games based on the provided filter criteria.

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `filter` | `ListGamesCursorFilterRequest` | Filter criteria to apply when querying games. Contains parameters for narrowing down the game results. |
| `cursor` | `String` | The cursor indicating the position from which to start fetching results. Use `null` or empty string for the first page. |
| `size` | `int` | The maximum number of game records to return in a single page. |

#### Returns

| Return Type | Description |
|-------------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing a list of `GameResponse` objects, along with cursor information for navigating to the next page. |

## Usage Example

```java
// Create an instance of the service (implementation)
IListGamesCursorService gameService = new ListGamesCursorService();

// Prepare filter request
ListGamesCursorFilterRequest filter = new ListGamesCursorFilterRequest();
// Configure filter parameters...

// Fetch first page of games
CursorPagedResponse<GameResponse> firstPage = gameService.execute(filter, null, 20);

// Use the cursor from the response to fetch the next page
String nextCursor = firstPage.getNextCursor();
if (nextCursor != null) {
    CursorPagedResponse<GameResponse> secondPage = gameService.execute(filter, nextCursor, 20);
}
```
