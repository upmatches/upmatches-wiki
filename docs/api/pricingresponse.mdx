# PricingResponse

The `PricingResponse` class is a Java record that serves as a Data Transfer Object (DTO) for exposing pricing information from the backend to API consumers. It encapsulates all pricing-related fields in a flat, immutable structure suitable for serialization (e.g., to JSON).

This record is typically used in REST API responses to provide clients with a clear, structured view of pricing details, including different prices for different genders, a flat price, a base price, and a per-shuttle price.

## Purpose

- **Data Transfer**: Transforms the internal `Pricing` value object into a format suitable for external API responses.
- **Immutability**: As a Java record, all fields are final and the class is thread-safe.
- **Null Safety**: The static factory method `fromPricing` handles `null` input gracefully by returning `null`.

## Constructor / Record Components

The record has the following components, which are automatically available as accessor methods:

| Component       | Type          | Description                                                                 |
|-----------------|---------------|-----------------------------------------------------------------------------|
| `mode`          | `PricingMode` | The pricing mode (e.g., flat, per-shuttle, etc.).                           |
| `currency`      | `String`      | The currency code (e.g., "USD", "EUR").                                     |
| `flatPrice`     | `BigDecimal`  | The flat price for the service.                                             |
| `malePrice`     | `BigDecimal`  | The price for male participants.                                            |
| `femalePrice`   | `BigDecimal`  | The price for female participants.                                          |
| `basePrice`     | `BigDecimal`  | The base price before any additional charges.                               |
| `pricePerShuttle` | `BigDecimal`| The price per shuttle (e.g., per transport unit).                           |

## Public Methods

### `fromPricing`

```java
public static PricingResponse fromPricing(Pricing pricing)
```

Creates a `PricingResponse` instance from a `Pricing` value object.

**Parameters:**

| Parameter | Type      | Description                               |
|-----------|-----------|-------------------------------------------|
| `pricing` | `Pricing` | The pricing value object to convert. Can be `null`. |

**Returns:**

| Type               | Description                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| `PricingResponse`  | A new `PricingResponse` with data extracted from the `Pricing` object, or `null` if the input is `null`. |

**Behavior:**

- If `pricing` is `null`, the method returns `null`.
- Otherwise, it extracts the following fields from the `Pricing` object:
  - `mode()` → mapped directly.
  - `currency().value()` → the currency string value.
  - `flatPrice()`, `malePrice()`, `femalePrice()`, `basePrice()`, `pricePerShuttle()` → mapped directly.

## Usage Example

```java
// Assume pricing is a Pricing object retrieved from a service
Pricing pricing = new Pricing(PricingMode.FLAT, new Currency("USD"), 
                               new BigDecimal("100.00"), null, null, 
                               new BigDecimal("80.00"), null);

PricingResponse response = PricingResponse.fromPricing(pricing);
// response.mode() == PricingMode.FLAT
// response.currency() == "USD"
// response.flatPrice() == 100.00
// response.basePrice() == 80.00
```

## Notes

- The `currency` field is a `String` in the response, while the original `Pricing` object likely uses a custom `Currency` value object. This conversion is handled in `fromPricing`.
- All monetary values are represented as `BigDecimal` to avoid floating-point precision issues.
- The record is immutable and can be safely used in concurrent environments.
