# PricingResponse

The `PricingResponse` record is a Data Transfer Object (DTO) used to expose pricing information from the backend to the client. It is designed to be a read-only representation of the domain `Pricing` object, ensuring that internal domain logic is not exposed directly to API consumers.

## Purpose

- **Decoupling**: Separates the internal domain model (`Pricing`) from the API response layer.
- **Immutability**: As a Java `record`, all fields are final and the object is immutable after creation.
- **Null Safety**: The static factory method `fromPricing` safely handles `null` input by returning `null`.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `mode` | `PricingMode` | The pricing mode (e.g., FLAT, PER_SHUTTLE, GENDER_BASED). |
| `currency` | `String` | The currency code (e.g., "USD", "EUR"). |
| `flatPrice` | `BigDecimal` | The flat price for the entire service. |
| `malePrice` | `BigDecimal` | The price for male participants (used in gender-based pricing). |
| `femalePrice` | `BigDecimal` | The price for female participants (used in gender-based pricing). |
| `basePrice` | `BigDecimal` | The base price before any adjustments. |
| `pricePerShuttle` | `BigDecimal` | The price per shuttle (used in per-shuttle pricing). |

## Methods

### `fromPricing(Pricing pricing)`

Converts a domain `Pricing` object into a `PricingResponse` DTO.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `pricing` | `Pricing` | The domain pricing object to convert. Can be `null`. |

**Returns:**

| Type | Description |
|------|-------------|
| `PricingResponse` | A new `PricingResponse` instance, or `null` if the input is `null`. |

**Example usage:**

```java
Pricing domainPricing = new Pricing(
    PricingMode.FLAT,
    new Currency("USD"),
    new BigDecimal("50.00"),
    null,
    null,
    new BigDecimal("50.00"),
    null
);

PricingResponse response = PricingResponse.fromPricing(domainPricing);
// response.mode() == PricingMode.FLAT
// response.currency() == "USD"
// response.flatPrice() == 50.00
```

## Notes

- The `currency` field is extracted from the domain's `Currency` value object using `.value()`.
- All monetary values are represented as `BigDecimal` to avoid floating-point precision issues.
- This record is typically used in REST API responses and serialized to JSON automatically by frameworks like Spring Boot.
