## Purpose

The `IAuthenticatedUserResolver` interface is part of the `com.upmatches.app.features.game.services` package. It defines a contract for resolving authenticated user identifiers within the application. This interface is designed to be implemented by classes that need to provide mechanisms for retrieving user IDs, either mandatorily or optionally.

## Public Methods

| Method Name       | Parameters | Return Type     | Description                                                                 |
|-------------------|------------|-----------------|-----------------------------------------------------------------------------|
| `requireUserId`   | None       | `UUID`          | Retrieves the user ID of the authenticated user. Throws an exception if the user ID is not available. |
| `optionalUserId`  | None       | `Optional<UUID>`| Retrieves the user ID of the authenticated user, if available, wrapped in an `Optional`. |

The `IAuthenticatedUserResolver` interface is a sealed interface, which means it restricts which classes can implement it. In this case, only the `AuthenticatedUserResolver` class is permitted to implement this interface. This design choice ensures controlled and predictable implementations of user ID resolution within the application.
