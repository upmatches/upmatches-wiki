# IAuthenticatedUserResolver Interface

The `IAuthenticatedUserResolver` interface defines a contract for resolving the currently authenticated user's unique identifier within the application. It provides two methods to obtain the user ID: one that throws an exception if the user is not authenticated, and another that returns an `Optional` to handle the absence of an authenticated user gracefully.

This interface is declared as a **sealed interface**, meaning it restricts which classes or interfaces can implement it. In this case, only `AuthenticatedUserResolver` is permitted to implement `IAuthenticatedUserResolver`. This design ensures controlled extension and a clear, single implementation path.

## Purpose

- **Centralized Authentication Resolution**: Provides a standard way to retrieve the authenticated user's ID across different parts of the application.
- **Flexible Error Handling**: Offers both a strict method (`requireUserId`) that fails fast when no user is authenticated, and a safe method (`optionalUserId`) that returns an empty `Optional` when the user is not present.
- **Sealed Contract**: By using a sealed interface, the codebase enforces that only the intended implementation (`AuthenticatedUserResolver`) can fulfill this contract, improving maintainability and security.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `requireUserId()` | `UUID` | Returns the unique identifier of the currently authenticated user. Throws an exception (e.g., `IllegalStateException` or a custom exception) if no user is authenticated. |
| `optionalUserId()` | `Optional<UUID>` | Returns an `Optional` containing the unique identifier of the currently authenticated user, or an empty `Optional` if no user is authenticated. |

## Usage Example

```java
// Using requireUserId() - throws if no authenticated user
UUID userId = resolver.requireUserId();

// Using optionalUserId() - handles absence gracefully
resolver.optionalUserId().ifPresentOrElse(
    id -> System.out.println("User ID: " + id),
    () -> System.out.println("No authenticated user")
);
```

## Notes

- The `UUID` type is used for user identifiers, providing a universally unique and secure identifier.
- The sealed nature of this interface (`permits AuthenticatedUserResolver`) ensures that only the designated implementation can be used, which is beneficial for dependency injection and testing.
