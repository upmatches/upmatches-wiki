# IAuthenticatedUserResolver Interface

The `IAuthenticatedUserResolver` interface defines a contract for resolving the currently authenticated user's unique identifier (UUID) within the application. It provides two methods to access the user ID: one that throws an exception if no user is authenticated, and another that returns an `Optional` to safely handle cases where the user is not authenticated.

This interface is a **sealed interface**, meaning it restricts which classes or interfaces can implement it. In this case, only `AuthenticatedUserResolver` is permitted to implement `IAuthenticatedUserResolver`. This design ensures controlled extensibility and enforces a single, well-defined implementation.

## Purpose

The primary purpose of this interface is to abstract the retrieval of the authenticated user's ID, decoupling the authentication mechanism from the rest of the application. By using this interface, services and components can obtain the current user's ID without needing to know the underlying authentication implementation details.

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `requireUserId()` | `UUID` | Returns the UUID of the currently authenticated user. Throws an exception (e.g., `IllegalStateException` or a custom exception) if no user is authenticated. |
| `optionalUserId()` | `Optional<UUID>` | Returns an `Optional<UUID>` containing the UUID of the authenticated user if present, or an empty `Optional` if no user is authenticated. |

## Usage Example

```java
// Assuming an implementation is injected
IAuthenticatedUserResolver userResolver = new AuthenticatedUserResolver();

// Get the user ID, throwing an exception if not authenticated
UUID userId = userResolver.requireUserId();

// Safely get the user ID, handling absence
Optional<UUID> optionalUserId = userResolver.optionalUserId();
optionalUserId.ifPresentOrElse(
    id -> System.out.println("User ID: " + id),
    () -> System.out.println("No authenticated user")
);
```

## Implementation Notes

- The interface is sealed, so only `AuthenticatedUserResolver` can implement it.
- The `requireUserId()` method is intended for use cases where the presence of an authenticated user is mandatory.
- The `optionalUserId()` method is suitable for scenarios where the user may or may not be authenticated, allowing for graceful handling.
