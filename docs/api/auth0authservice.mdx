## Overview

The `Auth0AuthService` class is a service component in a Java application that integrates with Auth0 for authentication purposes. It provides methods to generate an authorization URL and exchange an authorization code for verified claims. This class is designed to handle the OAuth2 authorization code flow with PKCE (Proof Key for Code Exchange) and verify ID tokens using JSON Web Keys (JWKs).

## Public Methods

### `getAuthorizationUrl`

Generates an authorization URL for Auth0's authorization endpoint.

| Parameter      | Type   | Description                                      |
|----------------|--------|--------------------------------------------------|
| `state`        | String | A unique string to maintain state between the request and callback. |
| `nonce`        | String | A unique string to associate a client session with an ID token. |
| `codeVerifier` | String | A cryptographically random string used to correlate the authorization request to the token request. |
| `connection`   | String | Optional. Specifies a specific connection to use for authentication. |

**Returns**: `String` - The constructed authorization URL.

### `exchangeAuthorizationCode`

Exchanges an authorization code for verified claims from Auth0.

| Parameter          | Type   | Description                                      |
|--------------------|--------|--------------------------------------------------|
| `authorizationCode`| String | The authorization code received from Auth0.      |
| `codeVerifier`     | String | The original code verifier used in the authorization request. |
| `nonce`            | String | The nonce value used in the authorization request. |

**Returns**: `Auth0VerifiedClaims` - An object containing verified claims such as subject, picture, and email.

## Private Methods

### `verifyIdToken`

Verifies the ID token received from Auth0.

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `idToken` | String | The ID token to be verified.                     |
| `nonce`   | String | The nonce value to verify against the token's nonce claim. |

**Returns**: `Auth0VerifiedClaims` - An object containing verified claims.

### `getAuth0Jwks`

Fetches and caches the JSON Web Key Set (JWKS) from Auth0.

**Returns**: `JWKSet` - The set of JSON Web Keys used to verify ID tokens.
