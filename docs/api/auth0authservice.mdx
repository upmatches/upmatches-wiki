## Purpose

The `Auth0AuthService` class is a Spring service designed to handle authentication operations with Auth0. It provides methods to generate authorization URLs and exchange authorization codes for verified claims. This class interacts with Auth0's OAuth2 endpoints and verifies ID tokens using JSON Web Keys (JWKS).

## Public Methods

### `getAuthorizationUrl`

Generates an authorization URL for Auth0's OAuth2 flow.

| Parameter     | Type   | Description                                      |
|---------------|--------|--------------------------------------------------|
| `state`       | String | A unique state value to maintain request state.  |
| `nonce`       | String | A nonce value to associate with the ID token.    |
| `codeVerifier`| String | A code verifier for PKCE.                        |
| `connection`  | String | Optional connection parameter for Auth0.         |

**Returns**: `String` - The constructed authorization URL.

### `exchangeAuthorizationCode`

Exchanges an authorization code for verified claims from Auth0.

| Parameter          | Type   | Description                                      |
|--------------------|--------|--------------------------------------------------|
| `authorizationCode`| String | The authorization code received from Auth0.      |
| `codeVerifier`     | String | The code verifier used in the authorization URL. |
| `nonce`            | String | The nonce value to verify against the ID token.  |

**Returns**: `Auth0VerifiedClaims` - An object containing verified claims such as subject, picture, and email.

## Additional Information

- The class uses a `RestClient` to interact with Auth0's endpoints.
- It caches the JWKS for a specified duration to optimize performance.
- The class handles various exceptions and logs relevant information for debugging purposes.
- The `verifyIdToken` method ensures the integrity and authenticity of the ID token by checking the issuer, audience, and nonce claims.
