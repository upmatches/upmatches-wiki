# Auth0AuthService

The `Auth0AuthService` class is a Spring service that provides authentication functionality using Auth0 as the identity provider. It implements the `IAuth0AuthService` interface and handles the OAuth 2.0 Authorization Code flow with PKCE (Proof Key for Code Exchange) for secure authentication.

## Purpose

This service manages the complete authentication lifecycle with Auth0, including:
- Generating authorization URLs for user redirection
- Exchanging authorization codes for ID tokens
- Verifying ID tokens using JWKS (JSON Web Key Set)
- Caching JWKS for performance optimization

## Public Methods

### `getAuthorizationUrl`

Generates the Auth0 authorization URL for redirecting users to the login page.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | Anti-CSRF state parameter |
| `nonce` | `String` | Replay attack prevention nonce |
| `codeVerifier` | `String` | PKCE code verifier for code challenge generation |
| `connection` | `String` | Optional Auth0 connection (e.g., "google-oauth2") |

**Returns:** `String` - The complete authorization URL

### `exchangeAuthorizationCode`

Exchanges an authorization code for verified claims from Auth0.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorizationCode` | `String` | The authorization code from Auth0 callback |
| `codeVerifier` | `String` | The PKCE code verifier used in the authorization request |
| `nonce` | `String` | The nonce used in the authorization request |

**Returns:** `Auth0VerifiedClaims` - Verified claims including subject, picture, and email

**Throws:** `IllegalStateException` if the token response is invalid or missing required fields

## Internal Methods

### `verifyIdToken`

Verifies the ID token signature and validates claims.

| Parameter | Type | Description |
|-----------|------|-------------|
| `idToken` | `String` | The JWT ID token from Auth0 |
| `nonce` | `String` | Expected nonce value for validation |

**Returns:** `Auth0VerifiedClaims` - Verified claims from the token

**Throws:** `Exception` if token verification fails

### `getAuth0Jwks`

Retrieves and caches the Auth0 JWKS (JSON Web Key Set) for token signature verification.

**Returns:** `JWKSet` - The parsed JWKS from Auth0

**Throws:** `IllegalStateException` if JWKS fetch fails or returns empty

## Configuration

The service uses `Auth0Properties` for configuration, which includes:
- `domain` - Auth0 tenant domain
- `clientId` - Auth0 application client ID
- `clientSecret` - Auth0 application client secret
- `redirectUri` - Callback URL after authentication
- `scopes` - Requested OAuth scopes

## Dependencies

- **RestClient** - HTTP client for Auth0 API calls
- **Auth0Properties** - Configuration properties
- **ObjectMapper** - JSON parsing
- **Nimbus JOSE + JWT** - JWT processing and verification

## Error Handling

The service throws `IllegalStateException` for various failure scenarios:
- Missing ID token in response
- Issuer mismatch
- Audience mismatch
- Nonce mismatch
- Missing subject claim
- Empty or failed JWKS fetch

## Caching

JWKS is cached for 900 seconds (15 minutes) to reduce network calls to Auth0's JWKS endpoint. The cache is thread-safe using double-checked locking with a volatile field.
