# IListGameBookmarksService Interface

## Purpose

The `IListGameBookmarksService` interface defines the contract for retrieving a paginated list of game bookmarks. It uses a cursor-based pagination strategy to efficiently fetch bookmarks in a scalable manner, avoiding the performance pitfalls of traditional offset-based pagination.

This sealed interface permits only the `ListGameBookmarksService` class to implement it, ensuring controlled extension and a clear, single implementation path.

## Interface Definition

```java
public sealed interface IListGameBookmarksService permits ListGameBookmarksService {
    CursorPagedResponse<GameBookmarkResponse> execute(String cursor, int size);
}
```

## Methods

### `execute`

Retrieves a cursor-paginated list of game bookmarks.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The cursor indicating the starting point for the next page of results. Pass `null` or an empty string to retrieve the first page. |
| `size` | `int` | The maximum number of bookmarks to return in a single page. Must be a positive integer. |

| Returns | Description |
|---------|-------------|
| `CursorPagedResponse<GameBookmarkResponse>` | A paginated response containing a list of `GameBookmarkResponse` objects and a cursor for the next page. |

## Usage Example

```java
// Get the first page of 20 bookmarks
IListGameBookmarksService service = new ListGameBookmarksService();
CursorPagedResponse<GameBookmarkResponse> firstPage = service.execute(null, 20);

// Use the cursor from the response to get the next page
String nextCursor = firstPage.getNextCursor();
if (nextCursor != null) {
    CursorPagedResponse<GameBookmarkResponse> secondPage = service.execute(nextCursor, 20);
}
```

## Related Types

- `CursorPagedResponse<T>` - Generic wrapper for cursor-based paginated responses
- `GameBookmarkResponse` - Data transfer object representing a single game bookmark
- `ListGameBookmarksService` - The sole permitted implementation of this interface
