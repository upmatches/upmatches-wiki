# IAuth0AuthService Interface

The `IAuth0AuthService` interface defines the contract for Auth0 authentication operations within the application. It provides methods for generating authorization URLs and exchanging authorization codes for verified user claims.

This is a **sealed interface** that permits only the `Auth0AuthService` class to implement it, ensuring controlled inheritance and a well-defined authentication service hierarchy.

## Purpose

- **Standardize Auth0 authentication flow** by defining a clear contract for authorization URL generation and token exchange
- **Ensure type safety** with sealed interface pattern, restricting implementation to a single concrete class
- **Encapsulate verified claims** through the inner record `Auth0VerifiedClaims`, providing a structured representation of authenticated user data

## Inner Record: Auth0VerifiedClaims

The `Auth0VerifiedClaims` record represents the verified claims extracted from an Auth0 ID token after successful authentication.

| Field | Type | Description |
|-------|------|-------------|
| `sub` | `String` | The Auth0 user identifier (subject claim) |
| `pictureUrl` | `String` | URL to the user's profile picture |
| `email` | `String` | User's email address |

## Methods

### getAuthorizationUrl

Generates the Auth0 authorization URL for initiating the OAuth 2.0 authentication flow.

```java
String getAuthorizationUrl(
    String state,
    String nonce,
    String codeVerifier,
    String connection)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | Anti-CSRF state parameter for protecting against cross-site request forgery |
| `nonce` | `String` | Cryptographic nonce for replay attack prevention |
| `codeVerifier` | `String` | PKCE code verifier for secure authorization code exchange |
| `connection` | `String` | Auth0 connection type (e.g., "google-oauth2", "facebook", "Username-Password-Authentication") |

**Returns:** `String` - The fully constructed authorization URL to redirect the user to Auth0.

### exchangeAuthorizationCode

Exchanges an authorization code for verified user claims after successful authentication.

```java
Auth0VerifiedClaims exchangeAuthorizationCode(
    String authorizationCode,
    String codeVerifier,
    String nonce)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorizationCode` | `String` | The authorization code received from Auth0 callback |
| `codeVerifier` | `String` | PKCE code verifier used in the initial authorization request |
| `nonce` | `String` | Cryptographic nonce used in the initial authorization request |

**Returns:** `Auth0VerifiedClaims` - A record containing the verified user claims (sub, pictureUrl, email).

## Usage Example

```java
// Generate authorization URL
String authUrl = authService.getAuthorizationUrl(
    state,
    nonce,
    codeVerifier,
    "google-oauth2"
);

// Exchange authorization code for claims
Auth0VerifiedClaims claims = authService.exchangeAuthorizationCode(
    authorizationCode,
    codeVerifier,
    nonce
);

String userId = claims.sub();
String email = claims.email();
String picture = claims.pictureUrl();
```

## Implementation Notes

- The interface is sealed, meaning only `Auth0AuthService` can implement it
- All methods are expected to throw appropriate exceptions (e.g., `IllegalArgumentException`, `AuthenticationException`) in case of invalid parameters or authentication failures
- The `Auth0VerifiedClaims` record is immutable and thread-safe by design
