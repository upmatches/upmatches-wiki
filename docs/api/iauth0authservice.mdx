# IAuth0AuthService

The `IAuth0AuthService` is a sealed interface that defines the contract for Auth0 authentication operations within the application. It provides methods for generating authorization URLs and exchanging authorization codes for verified claims. The interface is sealed to permit only `Auth0AuthService` as its implementation, ensuring controlled inheritance and type safety.

## Interface Definition

```java
public sealed interface IAuth0AuthService permits Auth0AuthService
```

## Methods

### `getAuthorizationUrl`

Generates the authorization URL for initiating the OAuth 2.0 authentication flow with Auth0.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | A random string used to maintain state between the request and callback, preventing CSRF attacks |
| `nonce` | `String` | A random string used to associate a client session with an ID token, preventing replay attacks |
| `codeVerifier` | `String` | A cryptographically random string used in PKCE (Proof Key for Code Exchange) flow |
| `connection` | `String` | The Auth0 connection type (e.g., "google-oauth2", "facebook", "Username-Password-Authentication") |

**Returns:** `String` - The fully constructed authorization URL to redirect the user to Auth0's authentication page.

### `exchangeAuthorizationCode`

Exchanges an authorization code for verified claims from Auth0 after successful user authentication.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorizationCode` | `String` | The authorization code received from Auth0 after user authentication |
| `codeVerifier` | `String` | The same code verifier used in the authorization request for PKCE verification |
| `nonce` | `String` | The same nonce used in the authorization request for ID token validation |

**Returns:** `Auth0VerifiedClaims` - A record containing the verified claims from Auth0.

## Inner Record: `Auth0VerifiedClaims`

A record that encapsulates the verified claims returned from Auth0 after successful authentication.

| Field | Type | Description |
|-------|------|-------------|
| `sub` | `String` | The subject identifier (unique user ID from Auth0) |
| `pictureUrl` | `String` | URL to the user's profile picture |
| `email` | `String` | The user's email address |

## Usage Example

```java
public class AuthServiceExample {
    private final IAuth0AuthService authService;
    
    public AuthServiceExample(IAuth0AuthService authService) {
        this.authService = authService;
    }
    
    public String initiateLogin() {
        String state = generateRandomState();
        String nonce = generateRandomNonce();
        String codeVerifier = generateCodeVerifier();
        String connection = "google-oauth2";
        
        return authService.getAuthorizationUrl(state, nonce, codeVerifier, connection);
    }
    
    public IAuth0AuthService.Auth0VerifiedClaims handleCallback(
            String authorizationCode, 
            String codeVerifier, 
            String nonce) {
        return authService.exchangeAuthorizationCode(authorizationCode, codeVerifier, nonce);
    }
}
```

## Implementation Notes

- The interface is sealed, meaning only `Auth0AuthService` can implement it
- The `Auth0VerifiedClaims` record is immutable and provides type-safe access to user claims
- PKCE (Proof Key for Code Exchange) is used for secure authorization code exchange
- The `nonce` parameter helps prevent replay attacks on ID tokens
- The `state` parameter helps prevent CSRF attacks during the OAuth flow
