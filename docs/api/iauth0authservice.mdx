# IAuth0AuthService

The `IAuth0AuthService` is a sealed interface that defines the contract for Auth0 authentication operations in the UpMatches application. It provides methods for generating authorization URLs and exchanging authorization codes for verified claims.

## Interface Overview

This interface is part of the `com.upmatches.app.features.auth.services` package and is designed to be implemented only by `Auth0AuthService`. It encapsulates the core authentication flow with Auth0, including OAuth 2.0 authorization code flow with PKCE (Proof Key for Code Exchange).

## Sealed Interface

The interface is declared as `sealed`, meaning only the specified class `Auth0AuthService` is permitted to implement it. This ensures controlled extension and maintains the integrity of the authentication service.

## Methods

### `getAuthorizationUrl`

Generates the authorization URL for redirecting users to Auth0's authentication page.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | A random string to prevent CSRF attacks |
| `nonce` | `String` | A random string to prevent replay attacks |
| `codeVerifier` | `String` | A cryptographically random string used for PKCE |
| `connection` | `String` | The Auth0 connection type (e.g., "google-oauth2", "facebook") |

**Returns:** `String` - The complete authorization URL to redirect the user to Auth0.

### `exchangeAuthorizationCode`

Exchanges an authorization code for verified claims from Auth0.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorizationCode` | `String` | The authorization code received from Auth0 callback |
| `codeVerifier` | `String` | The same code verifier used in the authorization request |
| `nonce` | `String` | The same nonce used in the authorization request |

**Returns:** `Auth0VerifiedClaims` - A record containing the verified user claims.

## Inner Record: `Auth0VerifiedClaims`

This record represents the verified claims returned by Auth0 after successful authentication.

| Field | Type | Description |
|-------|------|-------------|
| `sub` | `String` | The Auth0 user ID (subject) |
| `pictureUrl` | `String` | URL to the user's profile picture |
| `email` | `String` | The user's email address |

```java
// Implementation example

    @Override
    public String getAuthorizationUrl(String state, String nonce, 
                                      String codeVerifier, String connection) {
        // Implementation logic
    }
    
    @Override
    public Auth0VerifiedClaims exchangeAuthorizationCode(String authorizationCode, 
                                                         String codeVerifier, 
                                                         String nonce) {
        // Implementation logic
    }
}
```

## Security Considerations

- The `state` parameter helps prevent CSRF attacks
- The `nonce` parameter prevents replay attacks
- The `codeVerifier` ensures PKCE flow security
- All parameters should be cryptographically random and securely generated
