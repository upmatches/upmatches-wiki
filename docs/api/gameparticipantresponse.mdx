## Purpose of the Class

The `GameParticipantResponse` class is a Java record that encapsulates the response data for a participant in a game. It is part of the `com.upmatches.app.features.game.responses` package and is used to transfer participant-related data, including user information, participation status, skill level, and contact methods. This class is designed to be immutable and provides a structured way to represent participant data in a game context.

## Public Methods

The `GameParticipantResponse` class provides the following public static methods:

### fromGameParticipant

Converts a `GameParticipant` entity into a `GameParticipantResponse` object.

| Parameter              | Type                | Description                                                                 |
|------------------------|---------------------|-----------------------------------------------------------------------------|
| `participant`          | `GameParticipant`   | The game participant entity to convert.                                     |
| `gameActivityId`       | `UUID`              | The unique identifier for the game activity.                                |
| `includeContactMethods`| `boolean`           | Flag indicating whether to include contact methods in the response.         |

**Returns:** `GameParticipantResponse` - A new instance of `GameParticipantResponse` populated with data from the `GameParticipant` entity.

## Private Methods

The class also contains private static methods used internally to assist in constructing the `GameParticipantResponse`:

### resolveSkillLevel

Determines the skill level of a participant for a specific game activity.

| Parameter        | Type              | Description                                                                 |
|------------------|-------------------|-----------------------------------------------------------------------------|
| `participant`    | `GameParticipant` | The game participant whose skill level is to be resolved.                   |
| `gameActivityId` | `UUID`            | The unique identifier for the game activity.                                |

**Returns:** `SkillLevelResponse` - The resolved skill level response, or `null` if no matching skill level is found.

### contactMethodsFor

Generates a list of contact methods for a user.

| Parameter | Type  | Description                          |
|-----------|-------|--------------------------------------|
| `user`    | `User`| The user for whom contact methods are generated. |

**Returns:** `List<ContactMethod>` - A list of contact methods for the user, limited to a predefined capacity.
