# GameParticipantResponse

The `GameParticipantResponse` class is a Java record that serves as a Data Transfer Object (DTO) for representing a game participant's information in API responses. It encapsulates participant details such as their unique identifier, associated game and user information, participation status, skill level, timestamps, and optional contact methods.

This record is designed to provide a clean, immutable representation of a `GameParticipant` entity for external communication, ensuring that sensitive or unnecessary internal data is not exposed.

## Purpose

- **API Response DTO**: Transforms `GameParticipant` entities into a format suitable for REST API responses.
- **Data Aggregation**: Combines participant data with related user information and skill levels.
- **Contact Method Filtering**: Optionally includes user contact methods (WhatsApp, Telegram, Messenger) based on the request context.
- **Skill Level Resolution**: Dynamically resolves the participant's skill level for a specific game activity.

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique identifier for the participant record |
| `gameId` | `UUID` | Identifier of the associated game |
| `userId` | `UUID` | Identifier of the participating user |
| `userName` | `String` | Display name of the user |
| `status` | `ParticipantStatus` | Current participation status (e.g., JOINED, LEFT, PENDING) |
| `skillLevel` | `SkillLevelResponse` | User's skill level for the specific game activity (nullable) |
| `joinedAt` | `Instant` | Timestamp when the participant joined |
| `leftAt` | `Instant` | Timestamp when the participant left (nullable) |
| `contactMethods` | `List<ContactMethod>` | List of available contact methods (empty if not requested) |

## Public Methods

### `fromGameParticipant`

```java
public static GameParticipantResponse fromGameParticipant(
    GameParticipant participant,
    UUID gameActivityId,
    boolean includeContactMethods)
```

Creates a `GameParticipantResponse` from a `GameParticipant` entity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `participant` | `GameParticipant` | The source participant entity |
| `gameActivityId` | `UUID` | Identifier of the game activity for skill level resolution (can be null) |
| `includeContactMethods` | `boolean` | Whether to include user contact methods in the response |

**Returns:** `GameParticipantResponse` - A new response instance populated with data from the participant entity.

## Private Helper Methods

### `resolveSkillLevel`

```java
private static SkillLevelResponse resolveSkillLevel(
    GameParticipant participant,
    UUID gameActivityId)
```

Resolves the participant's skill level for a specific game activity.

**Logic:**
- Returns `null` if `gameActivityId` is null.
- Iterates through the user's skill levels to find a match for the given activity.
- Returns the corresponding `SkillLevelResponse` if found, otherwise `null`.

### `contactMethodsFor`

```java
private static List<ContactMethod> contactMethodsFor(User user)
```

Extracts available contact methods from a user entity.

**Logic:**
- Creates a list with initial capacity of 3.
- Checks for non-blank WhatsApp, Telegram, and Messenger values.
- Returns a list of `ContactMethod` objects with type and value.

## Usage Example

```java
// Create a response with contact methods for a specific activity
GameParticipantResponse response = GameParticipantResponse.fromGameParticipant(
    participant,
    activityId,
    true
);

// Create a response without contact methods
GameParticipantResponse responseWithoutContacts = GameParticipantResponse.fromGameParticipant(
    participant,
    activityId,
    false
);
```

## Dependencies

- `GameParticipant` - Source entity for participant data
- `SkillLevelResponse` - DTO for skill level representation
- `User` - Entity containing user profile and contact information
- `UserSkillLevel` - Entity linking users to skill levels for specific activities
- `ContactMethod` - Simple record/class representing a contact method type and value
- `ParticipantStatus` - Enum defining possible participant states
