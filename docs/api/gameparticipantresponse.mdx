# GameParticipantResponse

The `GameParticipantResponse` class is a Java record that serves as a Data Transfer Object (DTO) for representing a game participant's information in API responses. It encapsulates participant details such as their unique identifiers, status, skill level, and contact methods, providing a clean and immutable response structure for client applications.

## Purpose

This record is designed to:
- Provide a standardized response format for game participant data
- Transform internal entity objects (`GameParticipant`) into API-friendly representations
- Optionally include or exclude contact methods based on security/privacy requirements
- Resolve and include the participant's skill level for a specific game activity

## Record Structure

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique identifier for the participant record |
| `gameId` | `UUID` | Identifier of the associated game |
| `userId` | `UUID` | Identifier of the user participating in the game |
| `userName` | `String` | Display name of the participant |
| `status` | `ParticipantStatus` | Current status of the participant (e.g., joined, left, invited) |
| `skillLevel` | `SkillLevelResponse` | Skill level information for the specific game activity |
| `joinedAt` | `Instant` | Timestamp when the participant joined the game |
| `leftAt` | `Instant` | Timestamp when the participant left the game (nullable) |
| `contactMethods` | `List<ContactMethod>` | List of available contact methods for the participant |

## Public Methods

### `fromGameParticipant`

```java
public static GameParticipantResponse fromGameParticipant(
    GameParticipant participant,
    UUID gameActivityId,
    boolean includeContactMethods)
```

Creates a `GameParticipantResponse` from a `GameParticipant` entity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `participant` | `GameParticipant` | The source entity to convert |
| `gameActivityId` | `UUID` | Identifier of the game activity for skill level resolution (can be null) |
| `includeContactMethods` | `boolean` | Whether to include contact methods in the response |

**Returns:** `GameParticipantResponse` - A new response instance populated with data from the participant entity.

## Private Helper Methods

### `resolveSkillLevel`

```java
private static SkillLevelResponse resolveSkillLevel(
    GameParticipant participant,
    UUID gameActivityId)
```

Resolves the participant's skill level for a specific game activity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `participant` | `GameParticipant` | The participant whose skill levels to check |
| `gameActivityId` | `UUID` | The target game activity identifier |

**Returns:** `SkillLevelResponse` - The resolved skill level, or `null` if no matching skill level is found or if `gameActivityId` is null.

### `contactMethodsFor`

```java
private static List<ContactMethod> contactMethodsFor(User user)
```

Extracts available contact methods from a user entity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user entity containing contact information |

**Returns:** `List<ContactMethod>` - A list of up to 3 contact methods (WhatsApp, Telegram, Messenger) that are non-blank.

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `CONTACT_METHOD_CAPACITY` | `3` | Maximum number of contact methods to include |
| `CONTACT_METHOD_WHATSAPP` | `"whatsapp"` | Identifier for WhatsApp contact method |
| `CONTACT_METHOD_TELEGRAM` | `"telegram"` | Identifier for Telegram contact method |
| `CONTACT_METHOD_MESSENGER` | `"messenger"` | Identifier for Facebook Messenger contact method |

## Usage Example

```java
// Creating a response with contact methods included
GameParticipantResponse response = GameParticipantResponse.fromGameParticipant(
    participant,
    gameActivityId,
    true
);

// Creating a response without contact methods
GameParticipantResponse responseWithoutContacts = GameParticipantResponse.fromGameParticipant(
    participant,
    gameActivityId,
    false
);
```

## Dependencies

- `GameParticipant` - The source entity for participant data
- `SkillLevelResponse` - DTO for skill level information
- `User` - Entity containing user profile and contact information
- `ContactMethod` - Record representing a contact method (type and value)
- `ParticipantStatus` - Enumeration of possible participant statuses
