## Overview

The `AuthSessionStore` class is a service component in a Java application that manages authentication sessions using Redis as a storage mechanism. It implements the `IAuthSessionStore` interface and provides methods to store, retrieve, and manage authentication sessions. The class leverages the `StringRedisTemplate` for Redis operations and `ObjectMapper` for JSON serialization and deserialization.

## Public Methods

### store

Stores an authentication session in Redis with a specified state key and a predefined expiration time.

| Parameter | Type           | Description                          |
|-----------|----------------|--------------------------------------|
| state     | `String`       | The unique key for the session.      |
| session   | `AuthSession`  | The authentication session to store. |

- **Return Type:** `void`

### retrieveAndRemove

Retrieves an authentication session from Redis by its state key and removes it from the store.

| Parameter | Type     | Description                          |
|-----------|----------|--------------------------------------|
| state     | `String` | The unique key for the session.      |

- **Return Type:** `AuthSession` - Returns the `AuthSession` object if found, otherwise `null`.

### getPlatform

Retrieves the platform information from an authentication session stored in Redis by its state key.

| Parameter | Type     | Description                          |
|-----------|----------|--------------------------------------|
| state     | `String` | The unique key for the session.      |

- **Return Type:** `String` - Returns the platform information if the session is found, otherwise `null`.
