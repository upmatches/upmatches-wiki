# AuthSessionStore

The `AuthSessionStore` class is a Spring service responsible for managing authentication sessions in Redis. It provides methods to store, retrieve, and query authentication session data, with automatic expiration handling and JSON serialization/deserialization.

## Purpose

This service acts as a persistence layer for authentication sessions, using Redis as the backing store. It implements the `IAuthSessionStore` interface and handles the complete lifecycle of authentication sessions, including:

- Storing new sessions with automatic expiration
- Retrieving and removing sessions atomically
- Querying session platform information
- Error handling for serialization/deserialization failures

## Key Features

- **Redis-backed storage**: Uses `StringRedisTemplate` for efficient key-value operations
- **Automatic expiration**: Sessions expire after 5 minutes by default
- **JSON serialization**: Uses Jackson `ObjectMapper` for converting between `AuthSession` objects and JSON strings
- **Atomic operations**: Uses `getAndDelete` for safe retrieval and removal
- **Error resilience**: Gracefully handles serialization errors with logging

## Configuration

The class uses the following constants:

| Constant | Value | Description |
|----------|-------|-------------|
| `KEY_PREFIX` | `"auth:session:"` | Prefix for all Redis keys |
| `SESSION_EXPIRY_MINUTES` | `5` | Session expiration time in minutes |
| `EXPIRY` | `Duration.ofMinutes(5)` | Duration object for Redis TTL |

## Constructor

### `AuthSessionStore(StringRedisTemplate redisTemplate, ObjectMapper mapper)`

Creates a new instance with the required dependencies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `redisTemplate` | `StringRedisTemplate` | Redis template for string-based operations |
| `mapper` | `ObjectMapper` | Jackson mapper for JSON serialization/deserialization |

## Methods

### `store(String state, AuthSession session)`

Stores an authentication session in Redis with automatic expiration.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | The state identifier for the session |
| `session` | `AuthSession` | The authentication session to store |

**Returns**: `void`

**Throws**: `IllegalStateException` if serialization fails

**Example**:
```java
AuthSession session = new AuthSession("web", "user123");
authSessionStore.store("abc123", session);
```

### `retrieveAndRemove(String state)`

Retrieves and atomically removes an authentication session from Redis.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | The state identifier for the session |

**Returns**: `AuthSession` - The retrieved session, or `null` if not found or deserialization fails

**Example**:
```java
AuthSession session = authSessionStore.retrieveAndRemove("abc123");
if (session != null) {
    // Process the session
}
```

### `getPlatform(String state)`

Retrieves the platform information from a stored authentication session without removing it.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | The state identifier for the session |

**Returns**: `String` - The platform value from the session, or `null` if not found or deserialization fails

**Example**:
```java
String platform = authSessionStore.getPlatform("abc123");
if ("web".equals(platform)) {
    // Handle web platform
}
```

## Error Handling

The class handles two types of errors:

1. **Serialization errors**: When storing a session, if JSON serialization fails, an `IllegalStateException` is thrown with the message "Failed to serialize auth session".

2. **Deserialization errors**: When retrieving or querying sessions, if JSON deserialization fails, the error is logged as a warning and `null` is returned. This prevents the application from crashing due to corrupted data.

## Usage Example

```java
@Service
public class AuthService {
    private final AuthSessionStore sessionStore;
    
    public AuthService(AuthSessionStore sessionStore) {
        this.sessionStore = sessionStore;
    }
    
    public void createSession(String state, AuthSession session) {
        sessionStore.store(state, session);
    }
    
    public AuthSession consumeSession(String state) {
        return sessionStore.retrieveAndRemove(state);
    }
    
    public String getSessionPlatform(String state) {
        return sessionStore.getPlatform(state);
    }
}
```
