# AuthSessionStore

The `AuthSessionStore` class is a Spring service that provides Redis-backed storage for authentication sessions. It implements the `IAuthSessionStore` interface and handles serialization/deserialization of `AuthSession` objects using Jackson's `ObjectMapper`. Sessions are automatically expired after 5 minutes.

## Key Features

- **Redis-backed storage**: Uses `StringRedisTemplate` for efficient key-value operations
- **Automatic expiration**: Sessions expire after 5 minutes (configurable via `SESSION_EXPIRY_MINUTES`)
- **Thread-safe**: Leverages Redis atomic operations for safe concurrent access
- **Error handling**: Gracefully handles serialization/deserialization failures with logging

## Dependencies

- `StringRedisTemplate` - Spring Data Redis template for string-based operations
- `ObjectMapper` - Jackson library for JSON serialization/deserialization
- `AuthSession` - The session model object being stored

## Constructor

| Parameter | Type | Description |
|-----------|------|-------------|
| `redisTemplate` | `StringRedisTemplate` | Redis template for key-value operations |
| `mapper` | `ObjectMapper` | Jackson mapper for JSON serialization |

## Public Methods

### `store(String state, AuthSession session)`

Stores an authentication session in Redis with automatic expiration.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | Unique state identifier used as part of the Redis key |
| `session` | `AuthSession` | The authentication session to store |

**Returns**: `void`

**Throws**: `IllegalStateException` if serialization fails

**Example**:
```java
AuthSession session = new AuthSession("google", "token123");
authSessionStore.store("state_abc123", session);
```

### `retrieveAndRemove(String state)`

Retrieves and atomically removes an authentication session from Redis.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | The state identifier to look up |

**Returns**: `AuthSession` or `null` if not found or deserialization fails

**Example**:
```java
AuthSession session = authSessionStore.retrieveAndRemove("state_abc123");
if (session != null) {
    // Process the retrieved session
}
```

### `getPlatform(String state)`

Retrieves only the platform information from a stored session without removing it.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | The state identifier to look up |

**Returns**: `String` (platform name) or `null` if not found or deserialization fails

**Example**:
```java
String platform = authSessionStore.getPlatform("state_abc123");
if ("google".equals(platform)) {
    // Handle Google authentication
}
```

## Internal Details

### Key Format
Sessions are stored in Redis using the key pattern: `auth:session:{state}`

### Session Expiration
- Default expiration: 5 minutes
- Configurable via `SESSION_EXPIRY_MINUTES` constant
- Uses Redis TTL (Time-To-Live) for automatic cleanup

### Error Handling
- Serialization failures throw `IllegalStateException`
- Deserialization failures log a warning and return `null`
- Missing sessions (null JSON) return `null` without logging

## Usage Example

```java
@Service
public class AuthService {
    private final AuthSessionStore sessionStore;

    public AuthService(AuthSessionStore sessionStore) {
        this.sessionStore = sessionStore;
    }

    public void initiateAuth(String state, String platform) {
        AuthSession session = new AuthSession(platform, generateToken());
        sessionStore.store(state, session);
    }

    public AuthSession completeAuth(String state) {
        return sessionStore.retrieveAndRemove(state);
    }
}
```

## Notes

- The class is declared as `non-sealed`, allowing further extension if needed
- All operations use Redis atomic commands for consistency
- The `getPlatform` method is useful for routing authentication flows without consuming the session
