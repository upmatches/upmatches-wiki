## Overview

The `AuthSessionStore` class is a service component in a Java application that manages authentication sessions using Redis as a storage backend. It implements the `IAuthSessionStore` interface and provides methods to store, retrieve, and manage authentication sessions. The class utilizes JSON serialization and deserialization to handle session data, leveraging the Jackson library for these operations.

## Public Methods

### `store`

Stores an authentication session in Redis with a specified state as the key.

| Parameter | Type           | Description                           |
|-----------|----------------|---------------------------------------|
| `state`   | `String`       | The unique identifier for the session.|
| `session` | `AuthSession`  | The authentication session to store.  |

| Return Type |
|-------------|
| `void`      |

### `retrieveAndRemove`

Retrieves and removes an authentication session from Redis using the specified state.

| Parameter | Type     | Description                           |
|-----------|----------|---------------------------------------|
| `state`   | `String` | The unique identifier for the session.|

| Return Type    | Description                                      |
|----------------|--------------------------------------------------|
| `AuthSession`  | The retrieved authentication session, or `null` if not found or deserialization fails. |

### `getPlatform`

Retrieves the platform information from an authentication session stored in Redis.

| Parameter | Type     | Description                           |
|-----------|----------|---------------------------------------|
| `state`   | `String` | The unique identifier for the session.|

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| `String`    | The platform information, or `null` if not found or deserialization fails. |
