# CreateActivityService

The `CreateActivityService` class is a Spring service responsible for creating new `Activity` entities. It implements the `ICreateActivityService` interface and provides a transactional, auditable method to create an activity from a `CreateActivityRequest`. The service ensures that duplicate activities (by name) are not created and delegates the actual persistence and response mapping to helper methods.

## Purpose

- **Activity Creation**: Handles the business logic for creating a new activity.
- **Duplicate Prevention**: Checks if an activity with the given name already exists and throws an `ActivityAlreadyExistsException` if so.
- **Audit Support**: Uses the `@Auditable` annotation to log the creation event.
- **Transactional Execution**: Wraps the creation logic in a Spring `@Transactional` context to ensure data integrity.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Constructor Injection | Repository for persisting and querying `Activity` entities. |

## Public Methods

### `execute(CreateActivityRequest request)`

Creates a new activity based on the provided request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateActivityRequest` | The request object containing the activity name. |

| Returns | Type | Description |
|---------|------|-------------|
| `ActivityResponse` | `ActivityResponse` | The response object representing the newly created activity. |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `ActivityAlreadyExistsException` | If an activity with the same name already exists. |
| `ResourceNotFoundException` | If the activity creation fails (wrapped by `ServiceOperationExecutor`). |

**Behavior:**

1. Checks if an activity with the given name already exists using `activityRepository.existsByName(request.name())`.
2. If it exists, throws `ActivityAlreadyExistsException`.
3. Otherwise, creates a new `Activity` entity via `Activity.create(request.name())`.
4. Saves the entity using `activityRepository.save(activity)`.
5. Converts the saved entity to an `ActivityResponse` using `ActivityResponse.fromActivity(activity)`.
6. The entire operation is wrapped in `ServiceOperationExecutor.execute()` for consistent error handling and logging.

## Usage Example

```java
// Assuming CreateActivityService is injected
CreateActivityRequest request = new CreateActivityRequest("Hiking");
ActivityResponse response = createActivityService.execute(request);
// response contains the created activity details
```

## Notes

- The class is declared as `non-sealed`, meaning it can be extended by other classes in the same package or module.
- The `@Auditable` annotation automatically logs the creation event with the action `"ACTIVITY_CREATED"` and the resource type `"ACTIVITY"`.
- The `ServiceOperationExecutor` provides a consistent pattern for executing service operations with error handling and logging.
