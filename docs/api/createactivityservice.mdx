# CreateActivityService

The `CreateActivityService` class is a Spring service responsible for creating new `Activity` entities. It implements the `ICreateActivityService` interface and provides a transactional, auditable method to create an activity from a `CreateActivityRequest`. The service ensures that duplicate activity names are not allowed by throwing an `ActivityAlreadyExistsException` if an activity with the same name already exists.

## Purpose

- **Activity Creation**: Handles the business logic for creating a new activity.
- **Duplicate Prevention**: Checks for existing activities with the same name before creation.
- **Auditing**: Uses the `@Auditable` annotation to log creation events.
- **Transactional**: Ensures the creation process is atomic and consistent.

## Public Methods

### `execute(CreateActivityRequest request)`

Creates a new activity based on the provided request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateActivityRequest` | The request object containing the activity name. |

**Returns**: `ActivityResponse` - The response object representing the newly created activity.

**Throws**:
- `ActivityAlreadyExistsException` - If an activity with the given name already exists.
- `ResourceNotFoundException` - If the activity creation fails (wrapped from `ServiceOperationExecutor`).

**Example Usage**:
```java
CreateActivityRequest request = new CreateActivityRequest("Yoga Class");
ActivityResponse response = createActivityService.execute(request);
```

| Annotation | Description |
|------------|-------------|
| `@Service` | Marks this class as a Spring service component. |
| `@Transactional` | Ensures the method runs within a transaction. |
| `@Auditable` | Logs the creation action with metadata (action: `ACTIVITY_CREATED`, resourceType: `ACTIVITY`). |
