# CreateActivityService

The `CreateActivityService` class is a Spring service responsible for creating new `Activity` entities. It implements the `ICreateActivityService` interface and provides a transactional, auditable method to handle the creation workflow. The service ensures that duplicate activities are not created by checking for existing names before persisting.

## Purpose

- Encapsulates the business logic for creating an activity.
- Validates that the activity name does not already exist in the repository.
- Persists the new activity and returns a response DTO.
- Integrates with auditing and transaction management.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `ActivityRepository` | Spring Data repository for `Activity` entities. |

## Constructor

### `CreateActivityService(ActivityRepository activityRepository)`

Constructs the service with the required repository.

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityRepository` | `ActivityRepository` | The repository used for activity persistence. |

## Public Methods

### `execute(CreateActivityRequest request)`

Creates a new activity based on the provided request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateActivityRequest` | The request containing the activity name. |

**Returns:** `ActivityResponse` - A response DTO representing the newly created activity.

**Throws:**
- `ActivityAlreadyExistsException` - If an activity with the given name already exists.
- `ResourceNotFoundException` - If the save operation fails (wrapped by `ServiceOperationExecutor`).

**Behavior:**
1. Checks if an activity with the specified name already exists in the repository.
2. If it exists, throws `ActivityAlreadyExistsException`.
3. Otherwise, creates a new `Activity` entity using the factory method `Activity.create(request.name())`.
4. Saves the entity to the repository.
5. Returns an `ActivityResponse` built from the saved entity.

**Annotations:**
- `@Transactional` - Ensures the method runs within a database transaction.
- `@Auditable` - Records an audit event with action `ACTIVITY_CREATED`, resource type `ACTIVITY`, and the new activity's ID as the resource identifier.

## Usage Example

```java
// Assuming CreateActivityService is injected
CreateActivityRequest request = new CreateActivityRequest("Hiking");
ActivityResponse response = createActivityService.execute(request);
// response contains the created activity details
```

## Notes

- The class is declared as `non-sealed`, allowing it to be extended by other classes in the same package or module.
- The `ServiceOperationExecutor.execute` method handles the save operation and wraps any exceptions into a `ResourceNotFoundException` if the operation fails.
- The `existsByName` check is performed before the transaction begins to avoid unnecessary database operations.
