# ListActivitiesService

The `ListActivitiesService` class is a Spring service component responsible for retrieving a paginated list of activities from the database. It implements the `IListActivitiesService` interface and provides a transactional, read-only operation to fetch activities with pagination support.

## Purpose

This service encapsulates the business logic for listing activities, leveraging Spring Data's pagination capabilities to return results in a structured, page-based format. It uses the `ServiceOperationExecutor` utility to handle common cross-cutting concerns such as error handling and operation status tracking.

|-----------|------|-------------|
| `activityRepository` | `ActivityRepository` | The repository used to access activity data from the database |

## Public Methods

### `execute(Pageable pageable)`

Retrieves a paginated list of activities from the database.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | Spring Data pagination object containing page number, size, and sort parameters |

| Returns | Type | Description |
|---------|------|-------------|
| Success | `PagedResponse<ActivityResponse>` | A paginated response containing activity data |
| Error | Throws `ResourceNotFoundException` | If no activities are found or an error occurs during retrieval |

**Transactional Behavior:** This method is marked as `@Transactional(readOnly = true)`, ensuring it runs within a read-only database transaction for optimal performance.

**Example Usage:**

```java
// Create a pageable request for page 0 with 10 items per page
Pageable pageable = PageRequest.of(0, 10);

// Execute the service
PagedResponse<ActivityResponse> response = listActivitiesService.execute(pageable);

// Access paginated data
List<ActivityResponse> activities = response.getContent();
int totalPages = response.getTotalPages();
long totalElements = response.getTotalElements();
```

## Error Handling

The service uses `ServiceOperationExecutor.execute()` to handle errors consistently. If the repository returns no results or an error occurs during retrieval, a `ResourceNotFoundException` is thrown with the `RETRIEVE` operation status.
