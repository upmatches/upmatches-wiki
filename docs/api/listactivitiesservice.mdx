# ListActivitiesService

The `ListActivitiesService` class is a Spring service component responsible for retrieving a paginated list of activities from the database. It implements the `IListActivitiesService` interface and provides a single public method to fetch activities with pagination support.

This service is designed to be used in REST API endpoints where clients need to browse activities in a paginated manner. It leverages Spring Data's `Pageable` abstraction to handle pagination parameters and returns a standardized `PagedResponse` wrapper.

## Class Overview

- **Package:** `com.upmatches.app.features.activity.services`
- **Annotations:** `@Service`, `@Transactional(readOnly = true)`
- **Modifiers:** `public non-sealed`
- **Implements:** `IListActivitiesService`

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Constructor Injection | Spring Data JPA repository for activity entity persistence |

## Constructor

### `ListActivitiesService(ActivityRepository activityRepository)`

Creates a new instance of the service with the required repository dependency.

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityRepository` | `ActivityRepository` | The repository used to access activity data |

## Public Methods

### `execute(Pageable pageable)`

Retrieves a paginated list of activities from the database.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | Spring Data pagination object containing page number, size, and sort parameters |

**Returns:** `PagedResponse<ActivityResponse>` - A paginated response containing activity data wrapped in `ActivityResponse` objects.

**Exceptions:** Throws `ResourceNotFoundException` if the operation fails (wrapped by `ServiceOperationExecutor`).

**Transactional Behavior:** The method is marked as `@Transactional(readOnly = true)` to optimize database access for read-only operations.

## Usage Example

```java
// Create a Pageable instance
Pageable pageable = PageRequest.of(0, 10, Sort.by("createdAt").descending());

// Execute the service
PagedResponse<ActivityResponse> activities = listActivitiesService.execute(pageable);

// Access paginated data
List<ActivityResponse> items = activities.getContent();
int totalPages = activities.getTotalPages();
long totalElements = activities.getTotalElements();
```

## Implementation Details

The `execute` method uses `ServiceOperationExecutor.execute()` which provides:
- Consistent error handling across all service operations
- Automatic wrapping of results in appropriate response types
- Standardized exception handling with `ResourceNotFoundException`

The method converts domain entities to response DTOs using the `ActivityResponse::fromActivity` mapper method, ensuring that internal domain models are not exposed to API consumers.
