# ListActivitiesService

The `ListActivitiesService` class is a Spring service component responsible for retrieving a paginated list of activities from the database. It implements the `IListActivitiesService` interface and provides a single public method to fetch activities with pagination support.

This service uses the `ActivityRepository` to query the database and transforms the results into `ActivityResponse` objects using a functional mapping approach. The execution is wrapped in a `ServiceOperationExecutor` to handle common cross-cutting concerns such as error handling and logging.

## Public Methods

### `execute(Pageable pageable)`

Retrieves a paginated list of activities from the database and returns them as a `PagedResponse` of `ActivityResponse` objects.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | Spring Data pagination object containing page number, size, and sort parameters |

| Returns | Description |
|---------|-------------|
| `PagedResponse<ActivityResponse>` | A paginated response containing activity data and pagination metadata |

**Transactional Behavior:** This method is marked with `@Transactional(readOnly = true)` to optimize database access for read-only operations.

**Error Handling:** The method uses `ServiceOperationExecutor.execute()` which wraps the operation with:
- `RETRIEVE` operation status for logging/monitoring
- `ResourceNotFoundException` as the fallback exception type if the operation fails

**Example Usage:**

```java
// Create a pageable request for page 0 with 10 items per page
Pageable pageable = PageRequest.of(0, 10, Sort.by("createdAt").descending());

// Execute the service
PagedResponse<ActivityResponse> activities = listActivitiesService.execute(pageable);

// Access paginated results
List<ActivityResponse> items = activities.getContent();
int totalPages = activities.getTotalPages();
long totalElements = activities.getTotalElements();
```
