## Purpose

The `GetGameService` class is a Spring service component responsible for retrieving game details and determining the joinability status for viewers. It integrates with various services and repositories to perform its operations, ensuring that only authorized users can view game information.

## Public Methods

### `execute`

Retrieves game details and computes viewer joinability based on the user's authentication status and game participation.

| Parameter | Type   | Description                           |
|-----------|--------|---------------------------------------|
| `id`      | `UUID` | The unique identifier of the game.    |

| Return Type  | Description                                                                 |
|--------------|-----------------------------------------------------------------------------|
| `GameResponse` | A response object containing game details and viewer joinability information. |

## Method Details

- **`execute(UUID id)`**: This method performs the following operations:
  - Retrieves the optional user ID from the authenticated user resolver.
  - Finds the game using the `IGameLookupService`. If the game is not found, a `ResourceNotFoundException` is thrown.
  - Asserts that the user has permission to view the game using the `IGameAuthorizationService`.
  - Counts the number of active participants in the game using the `GameParticipantRepository`.
  - Depending on whether the user is authenticated, it returns a `GameResponse` for anonymous users or a detailed response for authenticated viewers, including joinability status computed by the `IGameJoinabilityService`.
