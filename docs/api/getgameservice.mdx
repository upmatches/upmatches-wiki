# GetGameService

The `GetGameService` class is a Spring service responsible for retrieving game details for a specific user or anonymous viewer. It orchestrates multiple sub-services to ensure proper authorization, participant counting, and joinability computation before returning a comprehensive `GameResponse`.

## Purpose

- Retrieves a game by its unique identifier (UUID)
- Determines the current authenticated user (if any)
- Validates that the requesting user has permission to view the game
- Counts active participants for the game
- Computes joinability information for authenticated users
- Returns a tailored `GameResponse` based on viewer context (anonymous vs. authenticated)

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameParticipantRepository` | Repository | Provides access to game participant data for counting active participants |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's ID, if available |
| `IGameLookupService` | Service | Handles game lookup and throws `ResourceNotFoundException` if not found |
| `IGameAuthorizationService` | Service | Validates whether the user is authorized to view the game |
| `IGameJoinabilityService` | Service | Computes whether the game is joinable for the current user |

## Public Methods

### `execute(UUID id)`

Retrieves game details for the specified game ID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to retrieve |

**Returns:** `GameResponse` - A response object containing game details, participant count, and optional joinability information.

**Throws:** `ResourceNotFoundException` if the game does not exist or the user is not authorized to view it.

**Behavior:**
1. Resolves the optional authenticated user ID
2. Looks up the game by ID (throws exception if not found)
3. Validates the user's authorization to view the game
4. Counts active participants for the game
5. Returns an anonymous `GameResponse` if no user is authenticated
6. Computes joinability and returns a viewer-specific `GameResponse` for authenticated users

## Usage Example

```java
@RestController
public class GameController {
    private final GetGameService getGameService;
    
    @GetMapping("/games/{id}")
    public ResponseEntity<GameResponse> getGame(@PathVariable UUID id) {
        GameResponse response = getGameService.execute(id);
        return ResponseEntity.ok(response);
    }
}
```

## Notes

- The service is annotated with `@Transactional(readOnly = true)` to optimize database access for read operations
- Uses `ServiceOperationExecutor` to wrap the participant count operation with standardized error handling
- The `non-sealed` modifier indicates this class is part of a sealed interface hierarchy (`IGetGameService`)
