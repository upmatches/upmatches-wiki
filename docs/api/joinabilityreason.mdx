## Overview

The `JoinabilityReason` enum is part of the `com.upmatches.app.features.game.enums` package. It defines a set of constants that represent the various reasons why a user might not be able to join a game. This enum can be used to provide meaningful feedback to users attempting to join a game session, helping them understand why their join request was unsuccessful.

## Enum Constants

The `JoinabilityReason` enum includes the following constants:

| Constant              | Description                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| `ALREADY_JOINED`      | Indicates that the user has already joined the game.                        |
| `NOT_JOINABLE`        | Indicates that the game is currently not joinable.                          |
| `PRIVATE_ACCESS_DENIED` | Indicates that the user does not have the necessary permissions to join a private game. |
| `GAME_FULL`           | Indicates that the game cannot be joined because it has reached its maximum capacity. |
| `OVERLAPPING`         | Indicates that joining the game would cause a scheduling conflict or overlap with another game. |

## Usage

This enum can be used in game management logic to determine and communicate the reason a join attempt fails. By using these predefined constants, developers can ensure consistency in how joinability issues are handled and reported across the application.
