# JoinabilityReason Enum

The `JoinabilityReason` enum defines the possible reasons why a user may be unable to join a game session. It is used throughout the game matching system to provide clear, programmatic feedback when a join attempt fails.

## Purpose

This enum serves as a standardized set of failure reasons for game join operations. Instead of using arbitrary strings or error codes, the application uses these typed constants to ensure consistency across the codebase. Each constant represents a distinct scenario that prevents a user from joining a game.

## Enum Constants

| Constant | Description |
|----------|-------------|
| `ALREADY_JOINED` | The user is already a participant in the game |
| `NOT_JOINABLE` | The game is not currently accepting new players |
| `PRIVATE_ACCESS_DENIED` | The game is private and the user does not have permission to join |
| `GAME_FULL` | The game has reached its maximum player capacity |
| `OVERLAPPING` | The user has a scheduling conflict with another game or event |

## Usage

This enum is typically returned from game join validation methods to indicate why a join operation failed. Example usage:

```java
public JoinabilityReason canJoinGame(User user, Game game) {
    if (game.isFull()) {
        return JoinabilityReason.GAME_FULL;
    }
    if (game.isPrivate() && !game.hasAccess(user)) {
        return JoinabilityReason.PRIVATE_ACCESS_DENIED;
    }
    // ... additional checks
    return null; // or a success indicator
}
```
