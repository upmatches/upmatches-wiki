# JoinabilityReason Enum

The `JoinabilityReason` enum defines the possible reasons why a user may be unable to join a game session. It provides a standardized set of failure reasons that can be returned by game join validation logic, enabling consistent error handling and user feedback across the application.

## Package Location

`com.upmatches.app.features.game.enums`

## Enum Values

| Enum Constant | Description |
|---|---|
| `ALREADY_JOINED` | The user is already a participant in the game and cannot join again. |
| `NOT_JOINABLE` | The game is not currently accepting new players (e.g., it has already started or is in a non-joinable state). |
| `PRIVATE_ACCESS_DENIED` | The game is private and the user does not have the required permissions or invitation to join. |
| `GAME_FULL` | The game has reached its maximum player capacity and cannot accommodate additional players. |
| `OVERLAPPING` | The user has a scheduling conflict or is already participating in another game that overlaps with this game's time slot. |

## Usage

This enum is typically used as a return type from game join validation methods or as a field in response objects to indicate why a join attempt failed.

### Example

```java
public JoinabilityReason canJoinGame(User user, Game game) {
    if (game.isFull()) {
        return JoinabilityReason.GAME_FULL;
    }
    if (game.isPrivate() && !game.hasAccess(user)) {
        return JoinabilityReason.PRIVATE_ACCESS_DENIED;
    }
    // Additional validation logic...
    return null; // or throw an exception if not joinable
}
```

## Related Components

- **GameService**: Service layer that uses this enum to determine join eligibility.
- **JoinGameResponse**: DTO that may include a `JoinabilityReason` field to communicate failure reasons to the client.
