# JoinabilityReason Enum

The `JoinabilityReason` enum defines the possible reasons why a user may be unable to join a game session. It is used throughout the game matching system to provide clear, descriptive feedback when a join attempt fails.

## Purpose

This enum serves as a standardized set of error codes for game join validation. Instead of using arbitrary strings or boolean flags, the system uses these typed constants to communicate specific failure reasons to both the UI layer and the API responses. This approach ensures consistency across the application and makes error handling more predictable.

## Enum Constants

| Constant | Description |
|----------|-------------|
| `ALREADY_JOINED` | The user is already a participant in this game session |
| `NOT_JOINABLE` | The game is not currently accepting new players (e.g., game has started or is cancelled) |
| `PRIVATE_ACCESS_DENIED` | The game is private and the user does not have permission to join |
| `GAME_FULL` | The game has reached its maximum player capacity |
| `OVERLAPPING` | The user has a scheduling conflict with another game or event |

## Usage Example

```java
public class GameJoinService {
    
    public JoinResult attemptJoin(User user, Game game) {
        if (game.isFull()) {
            return new JoinResult(false, JoinabilityReason.GAME_FULL);
        }
        if (game.isPrivate() && !game.hasAccess(user)) {
            return new JoinResult(false, JoinabilityReason.PRIVATE_ACCESS_DENIED);
        }
        // ... additional validation logic
        return new JoinResult(true, null);
    }
}
```
