# RegisterDeviceTokenService

## Purpose

The `RegisterDeviceTokenService` class is a Spring service responsible for registering or updating device tokens for push notifications. It ensures that each device token is uniquely associated with an authenticated user, handling both new registrations and updates to existing tokens (e.g., when the platform changes).

This service is part of the notification feature in the UpMatches application, enabling push notification delivery to user devices.

## Class Overview

- **Package:** `com.upmatches.app.features.notification.services`
- **Annotations:** `@Service`
- **Modifier:** `non-sealed` (implements `IRegisterDeviceTokenService`)
- **Dependencies:**
  - `DeviceTokenRepository` – persistence for device tokens
  - `UserRepository` – persistence for user entities
  - `IAuthenticatedUserResolver` – resolves the currently authenticated user

## Public Methods

### `execute(RegisterDeviceTokenRequest request)`

Registers or updates a device token for the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `RegisterDeviceTokenRequest` | Contains the device token string and platform identifier |

**Behavior:**
1. Resolves the authenticated user's ID via `userResolver.requireUserId()`.
2. Checks if a device token already exists for this user with the same token string.
3. **If the token exists:** Updates the existing token's platform and timestamp via `touch()`, then saves it.
4. **If the token does not exist:** Retrieves the user entity, creates a new `DeviceToken`, and persists it.

**Exceptions:**
- `ResourceNotFoundException` – thrown if the authenticated user cannot be found in the database.

**Transactional:** Yes (`@Transactional`)

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `DeviceTokenRepository` | Repository | Handles CRUD operations for `DeviceToken` entities |
| `UserRepository` | Repository | Handles CRUD operations for `User` entities |
| `IAuthenticatedUserResolver` | Service | Provides the current authenticated user's ID |
| `ServiceOperationExecutor` | Utility | Wraps repository operations with consistent error handling |

## Usage Example

```java
// Inject the service
private final RegisterDeviceTokenService registerDeviceTokenService;

// Register a device token
RegisterDeviceTokenRequest request = new RegisterDeviceTokenRequest(
    "fcm-token-abc123",
    Platform.IOS
);
registerDeviceTokenService.execute(request);
```

## Notes

- The service uses `ServiceOperationExecutor` to wrap save operations, ensuring consistent error handling and logging.
- The `touch()` method on `DeviceToken` updates the last-modified timestamp and potentially the platform, allowing the same token to be reused across platform changes.
- The `non-sealed` modifier indicates this class can be extended but is not intended for general inheritance (sealed class hierarchy).
