# RegisterDeviceTokenService

## Purpose

The `RegisterDeviceTokenService` class is a Spring service responsible for registering or updating device tokens for push notifications. It handles the logic of associating a device token with an authenticated user, either by updating an existing token record or creating a new one.

This service ensures that:
- Only authenticated users can register device tokens
- Existing tokens are updated with the latest platform information
- New tokens are created with proper user association
- All operations are executed within a transactional context

## Public Methods

### `execute(RegisterDeviceTokenRequest request)`

Registers or updates a device token for the currently authenticated user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `RegisterDeviceTokenRequest` | Contains the device token and platform information |

**Return Type:** `void`

**Behavior:**

1. Resolves the authenticated user's ID using `userResolver.requireUserId()`
2. Checks if a device token already exists for the user with the same token value
3. If the token exists:
   - Updates the existing token's platform and timestamp using `touch(request.platform())`
   - Saves the updated token
4. If the token does not exist:
   - Retrieves the user entity from the database
   - Creates a new `DeviceToken` entity using `DeviceToken.create(user, request.deviceToken(), request.platform())`
   - Saves the new token

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown when the authenticated user is not found in the database |

**Transactional Behavior:** The entire method executes within a single database transaction, ensuring atomicity of the operation.

## Error Handling

The service uses `ServiceOperationExecutor.execute()` to wrap save operations, providing consistent error handling and logging for database operations. If the user is not found during token creation, a `ResourceNotFoundException` is thrown with a descriptive message containing the user ID.
