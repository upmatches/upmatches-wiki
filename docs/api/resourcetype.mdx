## Overview

The `ResourceType` enum is part of the `com.upmatches.app.features.sharelink.enums` package. It is designed to represent different types of resources within the application, specifically focusing on resources related to games. This enum provides a structured way to handle resource types and their associated paths.

## Enum Constants

### GAME

- **Description**: Represents the resource type for games.
- **Associated Path**: `"games"`

## Public Methods

The `ResourceType` enum provides the following public method:

| Method Signature | Description |
|------------------|-------------|
| `String path()`  | Returns the path associated with the resource type. |

### Method Details

#### `path`

- **Description**: This method returns the path string associated with the specific resource type. It is useful for retrieving the path that corresponds to a particular resource type constant.
- **Parameters**: None
- **Returns**: `String` - The path associated with the resource type.

This enum is useful in scenarios where you need to manage and retrieve paths for different resource types in a consistent manner.
