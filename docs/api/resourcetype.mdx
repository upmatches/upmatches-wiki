# ResourceType Enum

The `ResourceType` enum is part of the `com.upmatches.app.features.sharelink.enums` package. It defines the types of resources that can be shared via links within the application.

## Purpose

This enum provides a centralized way to manage resource types and their associated URL paths. Currently, it supports game resources, but it can be extended to include other resource types as the application grows.

## Enum Constants

| Constant | Path Value | Description |
|----------|------------|-------------|
| `GAME`   | `games`    | Represents a game resource type |

## Methods

### `path()`

Returns the URL path segment associated with the resource type.

**Signature:**
```java
public String path()
```

**Returns:**
- `String` - The path segment for the resource type (e.g., `"games"` for the `GAME` constant)

**Example Usage:**
```java
ResourceType type = ResourceType.GAME;
String path = type.path(); // Returns "games"
```

## Usage Notes

- The enum is designed to be extensible - new resource types can be added by defining additional constants with their corresponding path values.
- The path values are typically used to construct URLs or API endpoints for accessing specific resource types.
- This enum is immutable and thread-safe by design.
