# ResourceType Enum

The `ResourceType` enum defines the types of resources that can be shared via the share link feature in the UpMatches application. It provides a mapping between resource types and their corresponding API path segments.

## Purpose

This enum is used to standardize resource type identification when constructing API endpoints for shared content. Currently, it supports game resources, with the ability to extend to additional resource types in the future.

## Enum Values

| Enum Constant | Path Value | Description |
|---------------|------------|-------------|
| `GAME` | `"games"` | Represents a game resource type |

## Methods

### `path()`

Returns the API path segment associated with the resource type.

**Signature:** `public String path()`

**Returns:** `String` - The path segment for the resource type (e.g., `"games"` for the `GAME` enum constant)

## Usage Example

```java
// Access the path for a game resource
String gamePath = ResourceType.GAME.path();
// gamePath = "games"

// Use the path in API endpoint construction
String endpoint = "/api/" + ResourceType.GAME.path() + "/123";
// endpoint = "/api/games/123"
```
