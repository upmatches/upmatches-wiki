# ResourceType Enum

The `ResourceType` enum defines the different types of resources that can be shared via the share link feature in the UpMatches application. It provides a mapping between resource types and their corresponding API path segments.

## Purpose

This enum is used to standardize resource type identification throughout the share link functionality. Each enum constant represents a specific type of resource that can be shared, and contains the URL path segment associated with that resource type. This design ensures consistency when constructing API endpoints and handling resource routing.

## Enum Constants

| Constant | Path Value | Description |
|----------|------------|-------------|
| `GAME`   | `games`    | Represents a game resource type |

## Methods

### `path()`

Returns the URL path segment associated with the resource type.

**Signature:**
```java
public String path()
```

**Returns:**
- `String` - The path segment for the resource type (e.g., `"games"` for the `GAME` constant)

**Example Usage:**
```java
ResourceType type = ResourceType.GAME;
String path = type.path(); // Returns "games"
```

## Usage Notes

- The enum is immutable and thread-safe by design
- New resource types can be added by defining additional enum constants with their corresponding path values
- The path values are used to construct API endpoints for resource sharing operations
