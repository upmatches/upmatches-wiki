## VenueImportResponse Class

The `VenueImportResponse` class is a simple data structure used to encapsulate the response of a venue import operation. It is implemented as a Java record, which is a special kind of class in Java that is ideal for immutable data carriers. This class is part of the `com.upmatches.app.features.venue.responses` package.

### Purpose

The primary purpose of the `VenueImportResponse` class is to hold the number of venues that were successfully imported during an import operation. It provides a clear and concise way to return this information from methods that perform venue import tasks.

### Public Methods

The `VenueImportResponse` class provides the following public methods, which are automatically generated by the Java compiler for record classes:

| Method Name | Parameters | Return Type | Description |
|-------------|------------|-------------|-------------|
| `imported`  | None       | `Integer`   | Returns the number of venues that were successfully imported. |

### Usage

This class is typically used in scenarios where a venue import operation is performed, and there is a need to communicate the result of that operation, specifically the count of successfully imported venues, back to the caller. The use of a record ensures that the data is immutable and thread-safe, making it a reliable choice for concurrent applications.
