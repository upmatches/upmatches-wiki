# VenueImportResponse

The `VenueImportResponse` class is a Java record that encapsulates the result of a venue import operation. It provides a simple, immutable data carrier indicating the number of venues successfully imported during a batch import process.

## Purpose

This record is used as a response object returned by venue import endpoints or services. It allows the caller to quickly determine how many venues were imported without needing to parse complex response structures. The record is designed to be lightweight and efficient, leveraging Java's built-in record features for automatic constructor, accessor, `equals()`, `hashCode()`, and `toString()` methods.

## Record Definition

```java
public record VenueImportResponse(Integer imported) {}
```

## Fields

| Field      | Type      | Description                                      |
|------------|-----------|--------------------------------------------------|
| `imported` | `Integer` | The number of venues that were successfully imported. |

## Usage Example

```java
// Creating a response indicating 25 venues were imported
VenueImportResponse response = new VenueImportResponse(25);

// Accessing the imported count
Integer count = response.imported();
System.out.println("Imported venues: " + count);
```

## Notes

- The `imported` field can be `null` if the import count is unknown or not applicable.
- This record is immutable and thread-safe by design.
- It is typically used in REST API responses or service layer return types.
