# VenueImportResponse

The `VenueImportResponse` class is a Java record that encapsulates the result of a venue import operation. It provides a simple, immutable data carrier that indicates how many venues were successfully imported during a batch import process.

## Purpose

This record is used as a response object returned by venue import endpoints or services. It allows the caller to quickly determine the number of venues that were imported in a single operation, enabling straightforward success/failure reporting and logging.

## Record Definition

```java
public record VenueImportResponse(Integer imported) {}
```

## Constructor and Components

| Component | Type      | Description                                      |
|-----------|-----------|--------------------------------------------------|
| `imported` | `Integer` | The number of venues successfully imported.      |

## Public Methods

Since `VenueImportResponse` is a Java record, the compiler automatically generates the following public methods:

| Method          | Return Type | Description                                      |
|-----------------|-------------|--------------------------------------------------|
| `imported()`    | `Integer`   | Returns the number of venues that were imported. |
| `toString()`    | `String`    | Returns a string representation of the record.   |
| `equals(Object)`| `boolean`   | Compares this record to another object for equality based on the `imported` value. |
| `hashCode()`    | `int`       | Returns a hash code value for this record.       |

## Usage Example

```java
// Creating a response indicating 25 venues were imported
VenueImportResponse response = new VenueImportResponse(25);

// Accessing the imported count
Integer count = response.imported(); // returns 25
```

## Notes

- The `imported` field can be `null` if the import count is unknown or not applicable.
- This record is immutable and thread-safe by design.
- It is typically used in REST API responses or service layer return values.
