# Auth0Uuid

The `Auth0Uuid` class is a Java record that represents a validated Auth0 user identifier. It serves as a value object within the application's domain layer, ensuring that any Auth0 UUID used throughout the system conforms to a specific format before it can be instantiated.

## Purpose

Auth0 user identifiers typically follow a pattern that combines a provider name with a unique user ID, separated by a pipe character (`|`). This class encapsulates that format and provides:

- **Validation**: Ensures the UUID matches the expected pattern on construction.
- **Immutability**: As a Java record, instances are immutable and thread-safe.
- **Type Safety**: Prevents primitive obsession by providing a dedicated type for Auth0 UUIDs.

## Format

The expected format is validated using the regular expression:

```
^[a-zA-Z0-9\-]+\|[a-zA-Z0-9@._\-]+$
```

This pattern requires:
- One or more alphanumeric characters, hyphens, or digits before the pipe
- A pipe character (`|`) as separator
- One or more alphanumeric characters, hyphens, digits, `@`, `.`, or underscores after the pipe

**Examples of valid formats:**
- `auth0|5a8f9b2c1d3e4f`
- `google-oauth2|1234567890`
- `facebook|user@example.com`

## Constructor

### `Auth0Uuid(String value)`

Creates a new `Auth0Uuid` instance after validating the input.

| Parameter | Type | Description |
|-----------|------|-------------|
| `value` | `String` | The raw Auth0 UUID string to validate and store |

**Throws:**
- `IllegalArgumentException` if the value is `null`, blank, or does not match the expected format.

## Methods

### `create(String uuid)`

Static factory method for creating an `Auth0Uuid` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `uuid` | `String` | The Auth0 UUID string to create an instance from |

**Returns:** `Auth0Uuid` - A new validated instance.

**Example:**
```java
Auth0Uuid userId = Auth0Uuid.create("auth0|abc123def456");
```

### `toString()`

Returns the string representation of the Auth0 UUID.

**Returns:** `String` - The original validated UUID value.

**Example:**
```java
Auth0Uuid userId = Auth0Uuid.create("google-oauth2|user@example.com");
System.out.println(userId.toString()); // Output: google-oauth2|user@example.com
```

## Usage Example

```java
// Valid creation
Auth0Uuid validUuid = Auth0Uuid.create("auth0|5a8f9b2c1d3e4f");

// This will throw IllegalArgumentException
try {
    Auth0Uuid invalidUuid = Auth0Uuid.create("invalid-format");
} catch (IllegalArgumentException e) {
    System.err.println("Invalid UUID format: " + e.getMessage());
}

// Access the value
String uuidValue = validUuid.value();
```

## Notes

- The class is defined as a Java `record`, which automatically provides `equals()`, `hashCode()`, and a compact constructor.
- The `value` accessor method is automatically generated by the record definition.
- Input is automatically trimmed before validation to handle whitespace.
