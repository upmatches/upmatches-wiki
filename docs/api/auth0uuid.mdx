## Overview

The `Auth0Uuid` class is a value object designed to encapsulate and validate UUIDs used within the Auth0 authentication system. It ensures that the UUIDs conform to a specific format and provides a convenient way to create and manage these identifiers.

## Class Definition

The `Auth0Uuid` class is defined as a Java record, which provides a compact syntax for declaring immutable data objects. This class includes a single field, `value`, which represents the UUID string.

## Validation

The `Auth0Uuid` class performs validation on the UUID string during instantiation. The string must not be null or blank, and it must match the expected format defined by the regular expression pattern `^[a-zA-Z0-9\\-]+\\|[a-zA-Z0-9@._\\-]+$`. If these conditions are not met, an `IllegalArgumentException` is thrown.
