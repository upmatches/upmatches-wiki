# Auth0Uuid

The `Auth0Uuid` class is a Java record that represents a validated Auth0 user identifier. It serves as a type-safe value object that encapsulates the format and validation logic for Auth0 UUIDs, which typically follow a pattern like `provider|user-id`.

## Purpose

This value object ensures that any Auth0 UUID used throughout the application conforms to the expected format. By wrapping the raw string in a dedicated type, the codebase gains:
- **Type safety**: Prevents accidental mixing of Auth0 UUIDs with other string identifiers
- **Validation**: Automatically validates format upon construction
- **Immutability**: As a Java record, instances are immutable and thread-safe

## Constructor

The compact constructor performs validation on the provided `value` parameter:

| Parameter | Type | Description |
|-----------|------|-------------|
| `value` | `String` | The Auth0 UUID string to validate and store |

**Validation rules:**
1. The value cannot be `null` or blank (whitespace-only)
2. The value is trimmed of leading/trailing whitespace
3. The value must match the pattern: `^[a-zA-Z0-9\\-]+\\|[a-zA-Z0-9@._\\-]+$`

**Throws:**
- `IllegalArgumentException` if validation fails

## Methods

### `create(String uuid)`

Factory method to create an `Auth0Uuid` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `uuid` | `String` | The Auth0 UUID string |

| Returns | Description |
|---------|-------------|
| `Auth0Uuid` | A new validated Auth0Uuid instance |

**Example:**
```java
Auth0Uuid uuid = Auth0Uuid.create("auth0|abc123def456");
```

### `toString()`

Returns the string representation of the Auth0 UUID.

| Returns | Description |
|---------|-------------|
| `String` | The original UUID value |

## Format Pattern

The expected format for an Auth0 UUID is:

```
provider|user-identifier
```

Where:
- **Provider**: One or more alphanumeric characters, hyphens, or dashes
- **Separator**: A pipe character (`|`)
- **User identifier**: One or more alphanumeric characters, hyphens, dashes, `@`, `.`, or underscores

**Valid examples:**
- `auth0|abc123`
- `google-oauth2|user@example.com`
- `facebook|1234567890`
- `windowslive|user_name@outlook.com`

**Invalid examples:**
- `abc123` (missing provider and pipe)
- `|user123` (missing provider)
- `auth0|` (missing user identifier)
- `auth0|user name` (contains space)

## Usage Example

```java
// Creating a valid Auth0 UUID
Auth0Uuid uuid = Auth0Uuid.create("auth0|5a8b9c0d1e2f3g4h5i6j7k8l");
System.out.println(uuid); // Output: auth0|5a8b9c0d1e2f3g4h5i6j7k8l

// This will throw IllegalArgumentException
Auth0Uuid invalid = Auth0Uuid.create("invalid-format");
```
