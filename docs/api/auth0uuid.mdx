import { Auth0Uuid } from 'com.upmatches.app.features.auth.valueobjects';

## Purpose

The `Auth0Uuid` class is a value object designed to encapsulate and validate a UUID string specific to Auth0. It ensures that the UUID adheres to a specific format and is neither null nor blank. This class is immutable and provides a simple API for creating and representing an Auth0 UUID.

## Public Methods

### `create`

Creates a new instance of `Auth0Uuid`.

| Parameter | Type   | Description                  |
|-----------|--------|------------------------------|
| `uuid`    | String | The UUID string to encapsulate. |

| Return Type | Description                        |
|-------------|------------------------------------|
| `Auth0Uuid` | A new instance of the `Auth0Uuid`. |

### `toString`

Returns the string representation of the `Auth0Uuid`.

| Return Type | Description                        |
|-------------|------------------------------------|
| `String`    | The UUID string encapsulated by this object. |

## Usage

To create an instance of `Auth0Uuid`, use the static `create` method:

```java
Auth0Uuid auth0Uuid = Auth0Uuid.create("valid-uuid|example@domain.com");
System.out.println(auth0Uuid.toString());
```

This will output the UUID string if it is valid according to the specified format. If the UUID is invalid, an `IllegalArgumentException` will be thrown.
