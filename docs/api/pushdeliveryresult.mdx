# Push Delivery Result

The `PushDeliveryResult` enum defines the possible outcomes of a push notification delivery attempt. It is used throughout the notification system to standardize the reporting of delivery statuses, enabling consistent error handling and logging.

## Enum Values

| Value | Description |
|-------|-------------|
| `SENT` | The push notification was successfully delivered to the device. |
| `NO_TOKENS` | The target user has no registered device tokens, so the notification could not be sent. |
| `UNAVAILABLE` | The push notification service is temporarily unavailable (e.g., network issue, service outage). |
| `FAILED` | The delivery attempt failed for an unspecified reason (e.g., invalid token, authentication error). |

## Usage

This enum is typically returned by push notification service methods to indicate the result of a delivery attempt. Example:

```java
PushDeliveryResult result = pushService.sendNotification(user, message);
switch (result) {
    case SENT:
        // handle success
        break;
    case NO_TOKENS:
        // log warning
        break;
    case UNAVAILABLE:
        // retry later
        break;
    case FAILED:
        // log error
        break;
}
```
