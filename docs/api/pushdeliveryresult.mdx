## Purpose

The `PushDeliveryResult` enum is part of the `com.upmatches.app.features.notification.models` package. It represents the possible outcomes of a push notification delivery attempt. This enum is useful for categorizing the result of sending a push notification, allowing developers to handle each case appropriately in their application logic.

## Enum Constants

The `PushDeliveryResult` enum defines the following constants:

| Constant    | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `SENT`      | Indicates that the push notification was successfully sent.                  |
| `NO_TOKENS` | Indicates that there were no tokens available to send the push notification. |
| `UNAVAILABLE` | Indicates that the service required to send the notification is unavailable. |
| `FAILED`    | Indicates that the push notification failed to be sent due to an error.      |

## Usage

This enum can be used in switch statements or conditional logic to handle different outcomes of a push notification delivery attempt. By using this enum, developers can ensure that their application responds appropriately to each possible result of a push notification operation.
