# PushDeliveryResult

The `PushDeliveryResult` enum defines the possible outcomes of a push notification delivery attempt. It is used within the notification system to standardize the reporting of delivery statuses across different push notification services.

## Purpose

This enum provides a clear, type-safe way to represent the result of sending a push notification to a device. Instead of using ambiguous strings or integer codes, the application can use these well-defined constants to make the code more readable and maintainable. The enum is part of the `com.upmatches.app.features.notification.models` package.

## Enum Constants

| Constant | Description |
|----------|-------------|
| `SENT` | The push notification was successfully sent to the push notification service (e.g., FCM, APNs). |
| `NO_TOKENS` | The target user or device has no registered push notification tokens, so the notification could not be delivered. |
| `UNAVAILABLE` | The push notification service is temporarily unavailable or unreachable. The notification may be retried later. |
| `FAILED` | The push notification delivery failed due to an error (e.g., invalid token, authentication failure, or network issue). |
