# PushDeliveryResult

The `PushDeliveryResult` enum defines the possible outcomes of a push notification delivery attempt. It is used within the notification system to report the status of each push notification sent to a user's device.

## Purpose

This enum provides a standardized set of return values for push notification delivery operations. By using an enum, the system ensures type safety and clear communication of delivery results across different components (e.g., notification services, logging, analytics).

## Enum Values

| Value | Description |
|-------|-------------|
| `SENT` | The push notification was successfully delivered to the push service provider (e.g., FCM, APNs). |
| `NO_TOKENS` | The target user has no registered device tokens, so no notification could be sent. |
| `UNAVAILABLE` | The push notification service is temporarily unavailable or unreachable. |
| `FAILED` | The push notification delivery failed for an unspecified reason (e.g., invalid token, service error). |

## Usage

This enum is typically returned by methods that handle push notification delivery. For example:

```java
PushDeliveryResult result = notificationService.sendPush(user, message);
switch (result) {
    case SENT:
        // Log success
        break;
    case NO_TOKENS:
        // Handle missing tokens
        break;
    case UNAVAILABLE:
        // Retry later
        break;
    case FAILED:
        // Log error
        break;
}
```
