## Purpose

The `UserRepository` interface is a part of the `com.upmatches.app.features.user.repositories` package and extends the `JpaRepository` interface provided by Spring Data JPA. It is designed to manage `User` entities, which are identified by a `UUID`. This repository interface provides several methods for querying `User` entities based on different unique identifiers such as Singpass UUID, Auth0 UUID, Apple UUID, and email. Additionally, it supports a method for obtaining a user entity with a pessimistic write lock.

## Public Methods

| Method Signature | Description |
|------------------|-------------|
| `Optional<User> findBySingpassUuid(String singpassUuid)` | Retrieves a `User` entity based on the provided Singpass UUID. |
| `Optional<User> findByAuth0Uuid(String auth0UserId)` | Retrieves a `User` entity based on the provided Auth0 UUID. |
| `Optional<User> findByAppleUuid(String appleUuid)` | Retrieves a `User` entity based on the provided Apple UUID. |
| `Optional<User> findFirstByEmail(String email)` | Retrieves the first `User` entity that matches the provided email. |
| `Optional<User> findForUpdateById(@Param("id") UUID id)` | Retrieves a `User` entity by its ID with a pessimistic write lock, ensuring that the entity is locked for updates. |

## Parameters and Return Types

| Method | Parameters | Return Type |
|--------|------------|-------------|
| `findBySingpassUuid` | `singpassUuid` (String): The Singpass UUID of the user. | `Optional<User>` |
| `findByAuth0Uuid` | `auth0UserId` (String): The Auth0 UUID of the user. | `Optional<User>` |
| `findByAppleUuid` | `appleUuid` (String): The Apple UUID of the user. | `Optional<User>` |
| `findFirstByEmail` | `email` (String): The email of the user. | `Optional<User>` |
| `findForUpdateById` | `id` (UUID): The unique identifier of the user. | `Optional<User>` |

The `UserRepository` interface leverages Spring Data JPA's capabilities to simplify data access layers, providing a clean and efficient way to perform CRUD operations and custom queries on `User` entities.
