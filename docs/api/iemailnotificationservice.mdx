# IEmailNotificationService

The `IEmailNotificationService` is a **sealed interface** that defines the contract for sending email notifications within the UpMatches application. It serves as the abstraction layer for email delivery, ensuring that only the designated implementation (`EmailNotificationService`) can extend this interface.

## Purpose

This interface establishes a standardized method for dispatching email notifications. By using a sealed interface, the design enforces a controlled hierarchy, preventing unauthorized implementations and promoting a clear, maintainable architecture for the notification system.

## Interface Definition

```java
public sealed interface IEmailNotificationService permits EmailNotificationService {
    void send(Notification notification, EmailContext context);
}
```

### Key Characteristics

- **Sealed Interface**: Only the `EmailNotificationService` class is permitted to implement this interface, ensuring a single, controlled implementation.
- **Single Method Contract**: Defines one core operation for sending email notifications.

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `send(Notification notification, EmailContext context)` | Sends an email notification using the provided notification data and email context. | `Notification notification` - The notification entity containing the message and recipient details.<br/>`EmailContext context` - The email context containing additional configuration (e.g., template, sender, subject). | `void` |

## Usage Example

```java
// Assuming you have an instance of IEmailNotificationService
IEmailNotificationService emailService = new EmailNotificationService();

// Create a notification and email context
Notification notification = new Notification();
EmailContext context = new EmailContext();

// Send the email notification
emailService.send(notification, context);
```

## Dependencies

- `com.upmatches.app.features.notification.entities.Notification` - The notification entity class.
- `com.upmatches.app.features.notification.models.EmailContext` - The email context model class.

## Related Components

- **EmailNotificationService** - The sole permitted implementation of this interface.
- **Notification Entity** - Represents the notification data structure.
- **EmailContext** - Encapsulates email-specific configuration and metadata.
