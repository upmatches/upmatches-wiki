## Purpose

The `IEmailNotificationService` interface is part of the `com.upmatches.app.features.notification.services` package. It defines the contract for sending email notifications within the application. This interface is designed to be implemented by classes that handle the specifics of email notification delivery, ensuring a consistent method signature for sending notifications.

## Public Methods

### `send`

The `send` method is responsible for dispatching an email notification based on the provided `Notification` and `EmailContext` objects.

| Method Signature | Description |
|------------------|-------------|
| `void send(Notification notification, EmailContext context)` | Sends an email notification using the specified `Notification` and `EmailContext`. |

#### Parameters

| Parameter   | Type                          | Description |
|-------------|-------------------------------|-------------|
| `notification` | `Notification`              | The notification entity containing the details of the message to be sent. |
| `context`      | `EmailContext`              | The context for the email, including any additional information required for sending the email. |

#### Return Type

This method does not return any value (`void`).
