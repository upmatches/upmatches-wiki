# IEmailNotificationService

The `IEmailNotificationService` is a **sealed interface** that defines the contract for sending email notifications within the UpMatches application. It establishes a clear API for email notification delivery, ensuring that only the permitted implementation (`EmailNotificationService`) can fulfill this contract.

## Purpose

This interface serves as the abstraction layer for email notification functionality. By using a sealed interface, the design enforces a controlled hierarchy where only the explicitly permitted class can implement the email sending behavior. This approach enhances security, maintainability, and clarity in the notification system.

## Interface Definition

```java
public sealed interface IEmailNotificationService permits EmailNotificationService {
    void send(Notification notification, EmailContext context);
}
```

## Methods

### `send`

Sends an email notification using the provided notification data and email context.

| Parameter      | Type             | Description                                                                 |
|----------------|------------------|-----------------------------------------------------------------------------|
| `notification` | `Notification`   | The notification entity containing the message content and metadata.        |
| `context`      | `EmailContext`   | The email context containing additional configuration (e.g., recipient, subject, template data). |

**Return Type:** `void`

**Behavior:** This method processes the notification and context to deliver an email. The exact implementation details (e.g., SMTP configuration, template rendering) are handled by the implementing class `EmailNotificationService`.

## Usage Example

```java
// Assuming you have an instance of IEmailNotificationService
IEmailNotificationService emailService = new EmailNotificationService();

Notification notification = new Notification("Welcome to UpMatches!");
EmailContext context = new EmailContext("user@example.com", "Welcome", Map.of("name", "John"));

emailService.send(notification, context);
```

## Implementation Notes

- The interface is **sealed**, meaning only `EmailNotificationService` is allowed to implement it.
- The `send` method is intentionally simple, focusing on the contract rather than implementation details.
- Both `Notification` and `EmailContext` are expected to be properly constructed before calling this method.
