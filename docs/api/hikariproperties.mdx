# HikariProperties

The `HikariProperties` record is a Java data carrier class that encapsulates configuration parameters for a HikariCP connection pool. HikariCP is a high-performance JDBC connection pool library commonly used in Spring Boot applications. This record provides a type-safe and immutable way to define pool settings such as pool size limits, timeout durations, and connection lifecycle thresholds.

## Purpose

This record serves as a configuration model for HikariCP connection pool settings. It allows developers to centralize and manage pool tuning parameters in a structured manner, ensuring consistency across different environments (development, staging, production). The record's immutability guarantees that once configured, the pool settings cannot be accidentally modified at runtime.

## Record Components

The following table describes each component (field) of the `HikariProperties` record:

| Component | Type | Description |
|-----------|------|-------------|
| `maximumPoolSize` | `Integer` | The maximum number of connections that can be created in the pool. A higher value allows more concurrent database operations but consumes more resources. |
| `minimumIdle` | `Integer` | The minimum number of idle connections that HikariCP tries to maintain in the pool. Helps reduce connection creation latency during low traffic periods. |
| `idleTimeout` | `Long` | The maximum time (in milliseconds) that a connection is allowed to sit idle in the pool. Connections exceeding this timeout are closed and removed. |
| `maxLifetime` | `Long` | The maximum lifetime (in milliseconds) of a connection in the pool. After this time, the connection is closed and replaced, even if it is still active. |
| `connectionTimeout` | `Long` | The maximum time (in milliseconds) that the pool will wait for a connection to become available before throwing an exception. |
| `leakDetectionThreshold` | `Long` | The time (in milliseconds) after which a connection is considered "leaked" if it has not been returned to the pool. Useful for detecting connection leaks in application code. |
| `initializationFailTimeout` | `Long` | The time (in milliseconds) that the pool will wait for the initial connection to be established before failing. A value of `-1` means fail immediately if the connection cannot be established. |

## Usage Example

```java
// Create a HikariProperties instance with custom pool settings
HikariProperties poolConfig = new HikariProperties(
    20,    // maximumPoolSize
    5,     // minimumIdle
    300000L, // idleTimeout (5 minutes)
    1800000L, // maxLifetime (30 minutes)
    30000L,   // connectionTimeout (30 seconds)
    0L,       // leakDetectionThreshold (disabled)
    -1L       // initializationFailTimeout (fail immediately)
);
```

## Notes

- All fields are nullable (`Integer` and `Long` wrapper types), allowing partial configuration where some values may be left as `null` to use HikariCP's default settings.
- Timeout values are specified in milliseconds.
- The record is immutable and thread-safe by design, making it suitable for use in concurrent environments.
