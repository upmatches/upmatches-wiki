## Overview

The `HikariProperties` class is a Java record that encapsulates configuration properties for a HikariCP connection pool. HikariCP is a fast, simple, and reliable JDBC connection pool. This class provides a structured way to define and manage the settings required to optimize database connection pooling.

## Public Methods

The `HikariProperties` class automatically provides the following public methods due to its nature as a Java record. Each method corresponds to a component of the record and allows access to the respective property.

| Method Name                  | Parameters | Return Type | Description                                                                 |
|------------------------------|------------|-------------|-----------------------------------------------------------------------------|
| `maximumPoolSize()`          | None       | `Integer`   | Returns the maximum number of connections in the pool.                      |
| `minimumIdle()`              | None       | `Integer`   | Returns the minimum number of idle connections that the pool maintains.     |
| `idleTimeout()`              | None       | `Long`      | Returns the maximum amount of time that a connection is allowed to sit idle in the pool. |
| `maxLifetime()`              | None       | `Long`      | Returns the maximum lifetime of a connection in the pool.                   |
| `connectionTimeout()`        | None       | `Long`      | Returns the maximum number of milliseconds that a client will wait for a connection from the pool. |
| `leakDetectionThreshold()`   | None       | `Long`      | Returns the amount of time that a connection can be out of the pool before a message is logged indicating a possible connection leak. |
| `initializationFailTimeout()`| None       | `Long`      | Returns the time in milliseconds that the pool will wait for a connection to be successfully established before failing. |

## Usage

The `HikariProperties` record is typically used to configure a HikariCP connection pool by providing the necessary parameters to optimize performance and resource management. Each property can be accessed via its corresponding method to retrieve the configuration value.
