## Overview

The `AuthDevProperties` class is a configuration properties holder used in a Spring Boot application. It is designed to manage development-specific authentication settings. The class is annotated with `@ConfigurationProperties`, which binds the properties defined in the application's configuration files (e.g., `application.yml` or `application.properties`) to this class. The properties are prefixed with `app.auth.dev`.

## Purpose

The primary purpose of the `AuthDevProperties` class is to encapsulate configuration settings related to authentication in a development environment. This includes enabling or disabling certain authentication features and specifying allowed hosts for token pages.

## Public Methods

The `AuthDevProperties` class is a Java Record, which means it primarily serves as a data carrier. It does not have traditional methods with logic but provides implicit accessor methods for its fields. Below is a table documenting these accessors.

| Method Name                | Parameters | Return Type | Description                                                                 |
|----------------------------|------------|-------------|-----------------------------------------------------------------------------|
| `tokenPageEnabled()`       | None       | `Boolean`   | Returns whether the token page is enabled.                                  |
| `mintEndpointEnabled()`    | None       | `Boolean`   | Returns whether the mint endpoint is enabled.                               |
| `tokenPageAllowedHosts()`  | None       | `List<String>` | Returns a list of allowed hosts for the token page.                          |

## Constructor

The constructor of the `AuthDevProperties` class ensures that:

- `tokenPageEnabled` is set to `false` if it is `null`.
- `mintEndpointEnabled` is set to `false` if it is `null`.
- `tokenPageAllowedHosts` is initialized as an empty list if it is `null`, otherwise, it is a copy of the provided list to ensure immutability.

This design helps maintain default values and prevents `NullPointerException` during runtime.
