# AuthDevProperties

The `AuthDevProperties` class is a Spring Boot configuration properties record that maps to the `app.auth.dev` prefix in your application's configuration files (e.g., `application.yml` or `application.properties`). It centralizes development-specific authentication settings, providing a type-safe way to configure features like token page visibility and mint endpoint availability.

## Purpose

This record is designed to manage development-only authentication flags and host allowlists. It ensures that certain features (like a token page or mint endpoint) are only enabled when explicitly set to `true`, and that host lists are never null (defaulting to an empty list). This helps prevent accidental exposure of development features in production environments.

## Configuration Prefix

- **Prefix:** `app.auth.dev`
- **Example YAML:**
  ```yaml
  app:
    auth:
      dev:
        token-page-enabled: true
        mint-endpoint-enabled: false
        token-page-allowed-hosts:
          - localhost
          - 127.0.0.1
  ```

## Constructor Behavior

The compact constructor performs two key validations:

1. **Boolean coercion:** Both `tokenPageEnabled` and `mintEndpointEnabled` are normalized using `Boolean.TRUE.equals()`, ensuring that only an explicit `true` value results in `true`; any other value (including `null`) becomes `false`.
2. **Null-safe list:** If `tokenPageAllowedHosts` is `null`, it defaults to an empty, immutable list. Otherwise, it creates an immutable copy via `List.copyOf()`.

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `tokenPageEnabled` | `Boolean` | `false` | Enables or disables the token page in development mode. Only `true` enables it. |
| `mintEndpointEnabled` | `Boolean` | `false` | Enables or disables the mint endpoint in development mode. Only `true` enables it. |
| `tokenPageAllowedHosts` | `List<String>` | `[]` | A list of allowed hosts for the token page. Never `null`; defaults to an empty list. |

## Usage Example

```java
// Inject the properties into a service
@Service
public class AuthDevService {
    private final AuthDevProperties authDevProperties;

    public AuthDevService(AuthDevProperties authDevProperties) {
        this.authDevProperties = authDevProperties;
    }

    public boolean isTokenPageAccessible(String host) {
        return authDevProperties.tokenPageEnabled() &&
               authDevProperties.tokenPageAllowedHosts().contains(host);
    }
}
```

## Dependencies

- **Spring Boot:** Requires `spring-boot-starter` for `@ConfigurationProperties` support.
- **Java:** Requires Java 16+ for record support.

## Notes

- This class is immutable after construction due to the use of a Java record and `List.copyOf()`.
- The `@ConfigurationProperties` annotation requires Spring Boot's configuration processor for IDE support (add `spring-boot-configuration-processor` as a dependency).
