# AuthDevProperties

The `AuthDevProperties` class is a Spring Boot configuration properties record that maps to the `app.auth.dev` prefix in your application's configuration files (e.g., `application.yml` or `application.properties`). It centralizes development-specific authentication settings, such as enabling certain endpoints and restricting access to specific hosts.

## Purpose

This record is designed to manage development-only flags and host allowlists for authentication features. It ensures that development endpoints (like a token page or a mint endpoint) are only enabled when explicitly configured, and that access to the token page is restricted to a predefined set of allowed hosts. The compact constructor normalizes the boolean fields and ensures the host list is never null.

## Configuration Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `app.auth.dev.token-page-enabled` | `Boolean` | `false` | Enables the token page endpoint in development mode. |
| `app.auth.dev.mint-endpoint-enabled` | `Boolean` | `false` | Enables the mint endpoint in development mode. |
| `app.auth.dev.token-page-allowed-hosts` | `List<String>` | `[]` (empty list) | List of hosts allowed to access the token page. |

## Constructor Behavior

The compact constructor performs the following normalization:

- **`tokenPageEnabled`**: Converts `null` to `false` using `Boolean.TRUE.equals()`.
- **`mintEndpointEnabled`**: Converts `null` to `false` using `Boolean.TRUE.equals()`.
- **`tokenPageAllowedHosts`**: If the provided list is `null`, it defaults to an empty, immutable list. Otherwise, it creates an immutable copy via `List.copyOf()`.

## Usage Example

In your `application.yml`:

```yaml
app:
  auth:
    dev:
      token-page-enabled: true
      mint-endpoint-enabled: false
      token-page-allowed-hosts:
        - localhost
        - 127.0.0.1
```

## Public Methods

Since `AuthDevProperties` is a Java record, the following accessor methods are automatically generated:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `tokenPageEnabled()` | `Boolean` | Returns whether the token page endpoint is enabled. |
| `mintEndpointEnabled()` | `Boolean` | Returns whether the mint endpoint is enabled. |
| `tokenPageAllowedHosts()` | `List<String>` | Returns an immutable list of allowed hosts for the token page. |

## Dependencies

- **Spring Boot**: `@ConfigurationProperties` annotation from `org.springframework.boot.context.properties`.
- **Java 16+**: Record feature (or Java 14+ with preview enabled).
