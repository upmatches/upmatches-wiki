# UnreadCountResponse

The `UnreadCountResponse` class is a Java record that serves as a simple data transfer object (DTO) for representing the number of unread notifications for a user. It is used in the notification feature of the application to encapsulate the unread count value in a type-safe and immutable manner.

## Purpose

This record provides a standardized way to communicate the count of unread notifications between different layers of the application, such as from a service to a controller or from a controller back to the client. By using a record, the class automatically inherits `equals()`, `hashCode()`, `toString()`, and a canonical constructor, reducing boilerplate code.

## Record Components

| Component | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `count`   | `Long` | The number of unread notifications for the user. |

## Public Methods

| Method                                                      | Return Type             | Description                                                                 |
|-------------------------------------------------------------|-------------------------|-----------------------------------------------------------------------------|
| `of(Long count)`                                            | `UnreadCountResponse`   | Static factory method that creates a new `UnreadCountResponse` instance with the given count. |

### Method Details

#### `of(Long count)`

Creates a new `UnreadCountResponse` instance.

**Parameters:**

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `count`   | `Long` | The number of unread notifications.              |

**Returns:**

| Type                   | Description                                      |
|------------------------|--------------------------------------------------|
| `UnreadCountResponse`  | A new `UnreadCountResponse` instance with the specified count. |

**Example Usage:**

```java
UnreadCountResponse response = UnreadCountResponse.of(5L);
// response.count() returns 5
```

## Usage Notes

- The `count` field is immutable and cannot be changed after the record is created.
- The `of()` static factory method provides a convenient way to instantiate the record without using the `new` keyword.
- This record is typically used in REST API responses to return the unread notification count to the client.
