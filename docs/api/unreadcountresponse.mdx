# UnreadCountResponse

The `UnreadCountResponse` class is a Java record that serves as a simple data transfer object (DTO) for representing the number of unread notifications for a user. It is used in the notification feature of the application to encapsulate the unread count value in a type-safe and immutable manner.

## Purpose

This record provides a standardized way to communicate the unread notification count between the server and client. By using a Java record, it automatically generates constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods, reducing boilerplate code. The static factory method `of()` offers a convenient way to create instances.

## Public API

### Record Components

| Component | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `count`   | `Long` | The number of unread notifications for the user. |

### Static Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `of(Long count)` | `UnreadCountResponse` | `count` - the unread notification count | Creates a new `UnreadCountResponse` instance with the specified count. |

## Usage Example

```java
// Create an UnreadCountResponse with 5 unread notifications
UnreadCountResponse response = UnreadCountResponse.of(5L);

// Access the count value
Long unreadCount = response.count(); // returns 5L
```
