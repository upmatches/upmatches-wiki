# UnreadCountResponse

The `UnreadCountResponse` class is a Java record that serves as a simple data transfer object (DTO) for representing the number of unread notifications for a user. It is used in the notification feature of the application to encapsulate the unread count value in a type-safe and immutable manner.

## Purpose

This record provides a lightweight, immutable container for a single `Long` value representing the count of unread notifications. By using a record, the class automatically generates constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods, reducing boilerplate code. The static factory method `of()` offers a convenient way to create instances.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `of(Long count)` | `UnreadCountResponse` | Static factory method that creates a new `UnreadCountResponse` instance with the specified unread count. |
| `count()` | `Long` | Auto-generated accessor method that returns the unread count value. |

## Parameters

### `of(Long count)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `count` | `Long` | The number of unread notifications. Must not be null. |

## Usage Example

```java
// Create an UnreadCountResponse with 5 unread notifications
UnreadCountResponse response = UnreadCountResponse.of(5L);

// Access the count value
Long unreadCount = response.count(); // returns 5L
```

## Notes

- This record is immutable by design, ensuring thread safety and predictability.
- The `count` field is declared as `Long` (object type) rather than `long` (primitive) to allow for null values if needed, though in practice it should always be provided.
- The static factory method `of()` provides a clean, expressive way to instantiate the record without using the `new` keyword directly.
