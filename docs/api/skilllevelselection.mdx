# Skill Level Selection Record

The `SkillLevelSelection` record is a Java data carrier used within the user request flow of the UpMatches application. It encapsulates the selection of a specific skill level for a given activity. This record is typically used as a request body when a user indicates their proficiency level for a particular activity.

## Purpose

The primary purpose of this record is to provide a type-safe, immutable, and concise way to transfer the following information between application layers:

- **Activity Identification**: Which activity the skill level applies to.
- **Skill Level Identification**: The specific skill level the user has selected.

By using a Java record, the class automatically generates constructors, accessor methods, `equals()`, `hashCode()`, and `toString()` methods, reducing boilerplate code.

## Record Definition

```java
public record SkillLevelSelection(
    @NotNull UUID activityId,
    @NotNull Long skillLevelId
) {}
```

## Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `activityId` | `UUID` | `@NotNull` | The unique identifier of the activity for which the skill level is being selected. |
| `skillLevelId` | `Long` | `@NotNull` | The unique identifier of the selected skill level. |

## Validation

Both fields are annotated with `@NotNull` from the `jakarta.validation.constraints` package. This ensures that when the record is used in a request body (e.g., in a Spring Boot controller), the framework will automatically validate that neither field is `null` before the request is processed.

## Usage Example

The following example demonstrates how `SkillLevelSelection` might be used in a REST controller:

```java
@PostMapping("/users/skill-levels")
public ResponseEntity<Void> selectSkillLevel(
    @Valid @RequestBody SkillLevelSelection selection
) {
    // Process the skill level selection
    UUID activityId = selection.activityId();
    Long skillLevelId = selection.skillLevelId();
    
    // Business logic...
    return ResponseEntity.ok().build();
}
```
