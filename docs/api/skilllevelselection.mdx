## Purpose

The `SkillLevelSelection` class is a Java record used to encapsulate the selection of a skill level for a specific activity. It is part of the `com.upmatches.app.features.user.requests` package. This class ensures that both the `activityId` and `skillLevelId` are provided and valid, as indicated by the `@NotNull` annotations.

## Public Methods

Since `SkillLevelSelection` is a Java record, it automatically provides the following public methods:

### Constructor

| Method Signature | Description |
|------------------|-------------|
| `SkillLevelSelection(UUID activityId, Long skillLevelId)` | Constructs a new `SkillLevelSelection` instance with the specified `activityId` and `skillLevelId`. Both parameters are required and must not be null. |

### Accessor Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `activityId()` | `UUID` | Returns the `activityId` associated with this skill level selection. |
| `skillLevelId()` | `Long` | Returns the `skillLevelId` associated with this skill level selection. |

## Parameters

The `SkillLevelSelection` record has the following parameters:

| Parameter Name | Type | Description |
|----------------|------|-------------|
| `activityId`   | `UUID` | The unique identifier for the activity. Must not be null. |
| `skillLevelId` | `Long` | The unique identifier for the skill level. Must not be null. |

## Return Types

The accessor methods return the following types:

- `UUID` for the `activityId()`
- `Long` for the `skillLevelId()`
