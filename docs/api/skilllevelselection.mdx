# SkillLevelSelection Record

The `SkillLevelSelection` record is a Java data transfer object (DTO) used within the user requests module of the UpMatches application. It encapsulates the selection of a specific skill level for a given activity. This record is typically used when a user indicates their proficiency level for a particular activity during onboarding or profile setup.

## Purpose

- **Data Transfer**: Carries the necessary identifiers (`activityId` and `skillLevelId`) between different layers of the application (e.g., from a controller to a service).
- **Validation**: Uses Jakarta Bean Validation annotations (`@NotNull`) to ensure that both fields are always provided, preventing null values from being processed.
- **Immutability**: As a Java record, it provides a concise, immutable data carrier with automatically generated constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods.

## Record Definition

```java
public record SkillLevelSelection(
    @NotNull UUID activityId,
    @NotNull Long skillLevelId
) {}
```

## Fields

| Field          | Type   | Validation | Description                                                                 |
|----------------|--------|------------|-----------------------------------------------------------------------------|
| `activityId`   | `UUID` | `@NotNull` | The unique identifier of the activity for which the skill level is selected. |
| `skillLevelId` | `Long` | `@NotNull` | The unique identifier of the chosen skill level (e.g., Beginner, Intermediate, Expert). |

## Usage Example

The following example demonstrates how to create an instance of `SkillLevelSelection`:

```java
import java.util.UUID;

UUID activityId = UUID.fromString("a1b2c3d4-e5f6-7890-abcd-ef1234567890");
Long skillLevelId = 3L;

SkillLevelSelection selection = new SkillLevelSelection(activityId, skillLevelId);
```

## Validation

Both fields are annotated with `@NotNull`, meaning that any attempt to create a `SkillLevelSelection` with a `null` value for either field will result in a validation error when processed by a Jakarta Bean Validation framework (e.g., in a Spring Boot controller with `@Valid`). This ensures data integrity before the record is used in business logic.

## Related Components

- **User Requests Package**: This record is part of the `com.upmatches.app.features.user.requests` package, which contains DTOs and request objects for user-related operations.
- **Activity and Skill Level Entities**: The `activityId` and `skillLevelId` fields reference existing entities in the system, typically stored in a database.
