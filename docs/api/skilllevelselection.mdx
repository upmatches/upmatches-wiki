# SkillLevelSelection

The `SkillLevelSelection` record is a Java data carrier used to represent a user's selection of a skill level for a specific activity. It is typically employed in request bodies for API endpoints that allow users to set or update their proficiency level in a given activity.

## Purpose

This record encapsulates two mandatory pieces of information:
- The unique identifier of the activity (e.g., "Running", "Swimming").
- The unique identifier of the chosen skill level (e.g., "Beginner", "Intermediate", "Advanced").

By using a Java record, the class automatically provides a constructor, getters, `equals()`, `hashCode()`, and `toString()` methods with minimal boilerplate.

## Validation

Both fields are annotated with `@NotNull` (from `jakarta.validation.constraints`), ensuring that neither the `activityId` nor the `skillLevelId` can be `null` when the record is used in a validated context (e.g., a Spring REST controller with `@Valid`).

## Fields

| Field          | Type       | Description                                      | Constraints |
|----------------|------------|--------------------------------------------------|-------------|
| `activityId`   | `UUID`     | The unique identifier of the activity.           | Not null    |
| `skillLevelId` | `Long`     | The unique identifier of the skill level.        | Not null    |

## Usage Example

```java
// Creating a new SkillLevelSelection instance
SkillLevelSelection selection = new SkillLevelSelection(
    UUID.fromString("a1b2c3d4-e5f6-7890-abcd-ef1234567890"),
    42L
);

// Accessing fields
UUID activityId = selection.activityId();
Long skillLevelId = selection.skillLevelId();
```
