# UserProfileResponse

The `UserProfileResponse` record is a Data Transfer Object (DTO) used to represent a user's profile information in API responses. It encapsulates all relevant user data, including authentication provider details, contact methods, skill levels, and game statistics, providing a comprehensive view of a user's profile.

## Purpose

This record serves as the response model for user profile endpoints. It transforms a `User` entity and associated data into a structured, immutable response format suitable for serialization. The record includes a factory method `fromUser()` that handles the conversion logic, including:
- Mapping contact methods (WhatsApp, Telegram, Messenger)
- Determining the authentication provider (Singpass, Apple, Auth0)
- Converting skill level entities to response objects
- Including computed statistics (games joined/hosted)

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `userId` | `UUID` | Unique identifier for the user |
| `authProvider` | `String` | Authentication provider (singpass, apple, auth0) |
| `providerUuid` | `String` | UUID from the authentication provider |
| `name` | `String` | User's display name |
| `contactMethods` | `List<ContactMethod>` | List of available contact methods |
| `skillLevels` | `List<SkillLevelResponse>` | User's skill levels |
| `hasCompletedOnboarding` | `Boolean` | Whether onboarding is complete |
| `totalGamesJoined` | `Long` | Total number of games joined |
| `totalGamesHosted` | `Long` | Total number of games hosted |
| `penaltyPoints` | `Integer` | User's penalty points |
| `avatarUrl` | `String` | URL to user's avatar image |
| `canCreateGame` | `Boolean` | Whether user can create new games |

## Public Methods

### `fromUser(User user, long totalGamesJoined, long totalGamesHosted)`

Creates a `UserProfileResponse` from a `User` entity and game statistics.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user entity to convert |
| `totalGamesJoined` | `long` | Total number of games the user has joined |
| `totalGamesHosted` | `long` | Total number of games the user has hosted |

**Returns:** `UserProfileResponse` - A new response instance populated with user data.

**Behavior:**
- Builds a list of `ContactMethod` objects from non-null contact fields (WhatsApp, Telegram, Messenger)
- Determines the authentication provider priority: Singpass > Apple > Auth0
- Maps `UserSkillLevel` entities to `SkillLevelResponse` objects
- Populates all record fields from the user entity and provided statistics

## Usage Example

```java
// Assuming 'user' is a User entity retrieved from database
UserProfileResponse response = UserProfileResponse.fromUser(
    user,
    user.getTotalGamesJoined(),
    user.getTotalGamesHosted()
);

// The response can now be serialized and returned from an API endpoint
return ResponseEntity.ok(response);
```
