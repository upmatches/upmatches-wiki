## Overview

The `UserProfileResponse` class is a Java record that encapsulates the response structure for a user's profile in the application. It aggregates various user-related data, including authentication details, contact methods, skill levels, and game participation statistics. This class is designed to be immutable and provides a static method to create an instance from a `User` entity.

## Public Methods

### `fromUser`

The `fromUser` method is a static factory method that constructs a `UserProfileResponse` object from a `User` entity. It gathers necessary information such as contact methods, authentication provider details, and skill levels to populate the response object.

| Parameter         | Type      | Description                                                                 |
|-------------------|-----------|-----------------------------------------------------------------------------|
| `user`            | `User`    | The user entity from which to create the profile response.                  |
| `totalGamesJoined`| `long`    | The total number of games the user has joined.                              |
| `totalGamesHosted`| `long`    | The total number of games the user has hosted.                              |

| Return Type             | Description                                                                 |
|-------------------------|-----------------------------------------------------------------------------|
| `UserProfileResponse`   | A new instance of `UserProfileResponse` populated with data from the `User`. |

## Fields

The `UserProfileResponse` record contains the following fields:

- `UUID userId`: The unique identifier for the user.
- `String authProvider`: The authentication provider used by the user (e.g., "singpass", "apple", "auth0").
- `String providerUuid`: The unique identifier provided by the authentication provider.
- `String name`: The name of the user.
- `List<ContactMethod> contactMethods`: A list of contact methods associated with the user.
- `List<SkillLevelResponse> skillLevels`: A list of skill levels associated with the user.
- `Boolean hasCompletedOnboarding`: Indicates whether the user has completed the onboarding process.
- `Long totalGamesJoined`: The total number of games the user has joined.
- `Long totalGamesHosted`: The total number of games the user has hosted.
- `Integer penaltyPoints`: The penalty points accumulated by the user.
- `String avatarUrl`: The URL of the user's avatar image.
- `Boolean canCreateGame`: Indicates whether the user has the permission to create a game.
