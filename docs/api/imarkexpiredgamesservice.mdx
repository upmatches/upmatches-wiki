# IMarkExpiredGamesService Interface

## Purpose

The `IMarkExpiredGamesService` interface defines a contract for marking expired games within the system. It is a **sealed interface**, meaning only the explicitly permitted implementing class (`MarkExpiredGamesService`) can implement it. This design enforces a controlled hierarchy and ensures that the logic for marking games as expired is centralized and not extended arbitrarily.

The primary responsibility of this interface is to expose a single operation that, when executed, identifies and updates the status of games that have passed their expiration point. This is typically used in batch processing or scheduled tasks to maintain data integrity and reflect the current state of games.

## Interface Definition

```java
package com.upmatches.app.feature.game.services;

public sealed interface IMarkExpiredGamesService permits MarkExpiredGamesService {

    int execute();

}
```

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute()` | `int` | Executes the process of marking expired games. Returns the number of games that were marked as expired during the operation. |

### Method Details

#### `execute()`

- **Description**: Triggers the business logic to identify all games that have expired and update their status accordingly. The exact criteria for expiration (e.g., based on end date, time, or other conditions) is defined in the implementing class.
- **Return Value**: An integer representing the count of games that were successfully marked as expired. A return value of `0` indicates no games were expired during this execution.
- **Usage**: This method is designed to be called by a scheduler or a batch job to perform periodic cleanup or status updates.

## Sealed Interface Permits

This interface uses the `sealed` keyword to restrict implementation. The only permitted subclass is:

- `MarkExpiredGamesService`

This ensures that all expiration logic is contained within a single, well-defined implementation, preventing unauthorized or accidental extensions.

## Example Usage

```java
// Assuming dependency injection provides the implementation
IMarkExpiredGamesService service = new MarkExpiredGamesService();
int expiredCount = service.execute();
System.out.println("Marked " + expiredCount + " games as expired.");
```

## Notes

- The interface is part of the `com.upmatches.app.feature.game.services` package, indicating it belongs to the game feature module.
- The sealed interface pattern is a Java 17+ feature that enhances encapsulation and maintainability.
- For production use, the implementation should be injected via a dependency injection framework (e.g., Spring, Micronaut) rather than instantiated directly.
