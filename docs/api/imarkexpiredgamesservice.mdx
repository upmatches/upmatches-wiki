# IMarkExpiredGamesService

The `IMarkExpiredGamesService` is a **sealed interface** that defines the contract for marking expired games within the application. It is part of the `com.upmatches.app.features.game.services` package and is designed to be implemented exclusively by the `MarkExpiredGamesService` class.

## Purpose

This interface provides a single, focused method for executing the logic that identifies and marks games as expired. By sealing the interface, the design ensures that only the permitted implementation (`MarkExpiredGamesService`) can fulfill this contract, promoting a controlled and secure extension of the service layer.

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute()` | `int` | Executes the process of marking expired games and returns the number of games that were marked as expired. |

## Method Details

### `execute()`

```java
int execute()
```

Executes the business logic to identify and mark all games that have passed their expiration threshold. The method returns an integer representing the count of games that were successfully marked as expired during the execution.

**Returns:**
- `int` — The number of games that were marked as expired.

**Implementation Note:**
This method is intended to be implemented by `MarkExpiredGamesService`, which will contain the actual logic for querying the data store, determining expiration status, and updating the relevant records.

## Sealed Interface Permits

The interface is declared as `sealed` and permits only one implementation:

- `MarkExpiredGamesService`

This restriction ensures that the contract for marking expired games is not extended by unauthorized classes, maintaining a clear and secure service boundary.

## Usage Example

```java
// Assuming dependency injection provides the implementation
IMarkExpiredGamesService markExpiredService = new MarkExpiredGamesService();

int expiredCount = markExpiredService.execute();
System.out.println("Marked " + expiredCount + " games as expired.");
```
