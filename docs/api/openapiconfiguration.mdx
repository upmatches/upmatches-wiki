## Purpose of the OpenApiConfiguration Class

The `OpenApiConfiguration` class is a Spring configuration class designed to set up and provide an OpenAPI specification for the Upmatches API. This configuration class uses the Swagger OpenAPI library to define API metadata, such as title, version, description, contact information, and server details. The class is annotated with `@Configuration`, indicating that it contains bean definitions for the application context.

## Public Methods

The class contains the following public method:

| Method Signature | Description |
| ---------------- | ----------- |
| `public OpenAPI openApi()` | Configures and returns an `OpenAPI` object with specified API information and server details. |

### Method Details

#### `openApi`

- **Purpose**: This method configures the OpenAPI specification for the Upmatches API.
- **Parameters**: None
- **Returns**: An `OpenAPI` object configured with API metadata and server information.

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| None      | -    | -           |

| Return Type | Description |
| ----------- | ----------- |
| `OpenAPI`   | An instance of the `OpenAPI` class containing API metadata and server configuration. |

### Configuration Details

- **API Title**: "Upmatches API"
- **API Version**: "0.0.1"
- **API Description**: "Upmatches API"
- **Contact Name**: "Upmatches"
- **License Name**: "All Rights Reserved"
- **Server URL**: Constructed using the prefix "http://localhost:" and the server port.
- **Server Description**: "Local"

The server port is injected using the `@Value` annotation, defaulting to `8080` if not specified in the application properties.
