# OpenApiConfiguration

## Purpose

The `OpenApiConfiguration` class is a Spring Boot configuration class that sets up and customizes the OpenAPI documentation for the Upmatches API. It defines the API metadata (title, version, description, contact, and license) and configures the server URL dynamically based on the application's runtime port. This class is annotated with `@Configuration` and produces a single `OpenAPI` bean that is used by Swagger/OpenAPI tools to generate interactive API documentation.

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `openApi()` | `OpenAPI` | None | Creates and returns an `OpenAPI` instance configured with API information (title, version, description, contact, license) and a list of servers (one local server with the port from `server.port` property, defaulting to `8080`). |

## Configuration Details

- **API Title**: `Upmatches API`
- **API Version**: `0.0.1`
- **API Description**: `Upmatches API`
- **Contact Name**: `Upmatches`
- **License**: `All Rights Reserved`
- **Server URL**: `http://localhost:{server.port}` (default port `8080`)
- **Server Description**: `Local`

The server port is injected via the `@Value("${server.port:8080}")` annotation, allowing it to be overridden in application properties or environment variables.

## Usage

This configuration is automatically picked up by Spring Boot's auto-configuration when the `springdoc-openapi` or similar dependency is present on the classpath. No additional setup is required beyond including this class in your project.
