# OpenApiConfiguration

The `OpenApiConfiguration` class is a Spring `@Configuration` class that provides a bean for customizing the OpenAPI documentation for the Upmatches API. It defines metadata such as the API title, version, description, contact information, license, and server details. This configuration is used by SpringDoc OpenAPI (or similar libraries) to generate the API documentation (e.g., Swagger UI).

## Purpose

- **Centralized API Metadata**: Defines reusable constants for API title, version, description, contact, and license.
- **Dynamic Server URL**: Reads the server port from the application properties (defaulting to `8080`) and constructs the server URL dynamically.
- **Bean Definition**: Exposes an `OpenAPI` bean that SpringDoc uses to generate the OpenAPI specification.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `openApi()` | `OpenAPI` | Creates and returns an `OpenAPI` instance configured with API info (title, version, description, contact, license) and a list of servers (local server with dynamic port). |

## Parameters

The `openApi()` method has no parameters. It relies on the injected `serverPort` field.

## Field Details

| Field | Type | Description |
|-------|------|-------------|
| `serverPort` | `int` | Injected from the `server.port` property (default `8080`). Used to construct the local server URL. |

## Usage Example

This configuration is automatically picked up by Spring Boot when the application starts. No additional code is required to use it. The generated OpenAPI documentation will include:

- **Title**: "Upmatches API"
- **Version**: "0.0.1"
- **Description**: "Upmatches API"
- **Contact**: "Upmatches"
- **License**: "All Rights Reserved"
- **Server**: `http://localhost:{port}` (e.g., `http://localhost:8080`)

## Notes

- The class is annotated with `@Configuration`, making it a Spring-managed configuration class.
- The `@Value` annotation reads the `server.port` property from the application's configuration (e.g., `application.properties` or `application.yml`).
- The `OpenAPI` bean is typically used by SpringDoc OpenAPI (or Springfox) to generate the API documentation endpoint (e.g., `/v3/api-docs` or `/swagger-ui.html`).
