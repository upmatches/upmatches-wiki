## Purpose

The `IMarkStartedGamesService` interface is part of the `com.upmatches.app.features.game.services` package. It defines a contract for marking games as started. This interface is designed to be implemented by classes that provide the actual logic for marking games as started. The interface is sealed, meaning it restricts which classes can implement it, specifically permitting only the `MarkStartedGamesService` class.

## Public Methods

| Method Signature | Description | Parameters | Return Type |
|------------------|-------------|------------|-------------|
| `int execute()`  | Executes the logic to mark games as started. | None | `int` - Returns an integer indicating the result of the execution, typically the number of games marked as started. |

This interface is crucial for ensuring that any implementation adheres to a specific method signature for marking games as started, providing consistency across different implementations.
