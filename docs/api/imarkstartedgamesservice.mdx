## Overview

The `IMarkStartedGamesService` is a **sealed interface** in the `com.upmatches.app.features.game.services` package. It defines a contract for marking games as started within the application. The interface is sealed, meaning only the explicitly permitted class `MarkStartedGamesService` can implement it. This design enforces a controlled hierarchy and ensures that the service logic is centralized and not extended arbitrarily.

The primary purpose of this interface is to provide a single method, `execute()`, which returns an integer representing the outcome of the operation (e.g., number of games marked as started, or a status code).

## Public Method

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute()` | `int` | Executes the operation to mark games as started. The return value typically indicates the result, such as the count of affected games or a success/error code. |

## Permitted Implementations

The only class allowed to implement this interface is:

- `MarkStartedGamesService`

This restriction is enforced by the `sealed` keyword and the `permits` clause in the interface declaration.

## Usage Notes

- The `execute()` method should be called when the application needs to transition games from a pending or unstarted state to a started state.
- The exact semantics of the returned integer depend on the implementation in `MarkStartedGamesService`. Refer to that class for details on possible return values and their meanings.
- Since the interface is sealed, you can safely rely on the fact that no other implementations exist in the codebase, simplifying reasoning about the service behavior.
