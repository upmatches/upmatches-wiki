## Purpose

The `IMarkStartedGamesService` interface defines a contract for marking games that have started. It is a sealed interface, meaning only the permitted implementation (`MarkStartedGamesService`) can implement it. This design ensures controlled extensibility and enforces a single point of execution for the "mark started games" operation.

## Interface Definition

```java
package com.upmatches.app.features.game.services;

public sealed interface IMarkStartedGamesService permits MarkStartedGamesService {

    int execute();

}
```

## Public Methods

| Method   | Return Type | Description                                                                 |
|----------|-------------|-----------------------------------------------------------------------------|
| `execute` | `int`       | Executes the operation to mark games as started. Returns an integer representing the number of games affected or a status code. |

## Parameters

The `execute()` method takes no parameters.

## Usage Notes

- The interface is **sealed**, so only `MarkStartedGamesService` is allowed to implement it.
- The return value of `execute()` is an `int`, which typically indicates the number of games successfully marked as started, or a status/error code.
- This interface follows a command pattern, encapsulating the logic for marking started games into a single callable method.

## Example Implementation

```java
public final class MarkStartedGamesService implements IMarkStartedGamesService {
    @Override
    public int execute() {
        // Implementation logic to mark games as started
        // Return the count of affected games
        return 0;
    }
}
```
