# VenueResponse

The `VenueResponse` class is a Java record that serves as a Data Transfer Object (DTO) for representing venue information in API responses. It encapsulates all relevant venue data including location details, associated activity, and nearby stations. The record provides a static factory method to convert a `Venue` entity into this response format.

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `Long` | Unique identifier for the venue |
| `sourceId` | `String` | External source identifier |
| `activity` | `ActivityResponse` | Associated activity information |
| `name` | `String` | Venue name |
| `address` | `String` | Street address |
| `postalCode` | `String` | Postal/ZIP code |
| `latitude` | `BigDecimal` | Geographic latitude coordinate |
| `longitude` | `BigDecimal` | Geographic longitude coordinate |
| `stations` | `List<StationResponse>` | List of nearby stations |
| `createdAt` | `Instant` | Timestamp when the venue was created |
| `updatedAt` | `Instant` | Timestamp when the venue was last updated |

## Methods

### `fromVenue(Venue venue)`

Converts a `Venue` entity into a `VenueResponse` DTO.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `venue` | `Venue` | The venue entity to convert |

**Returns:** `VenueResponse` - A new response object populated with data from the provided venue entity.

**Behavior:**
- Maps all fields from the `Venue` entity to the corresponding record components
- Converts the venue's station list to `StationResponse` objects using `StationResponse.fromStation()`
- Converts the venue's activity to an `ActivityResponse` using `ActivityResponse.fromActivity()`

## Usage Example

```java
// Assuming you have a Venue entity
Venue venue = venueRepository.findById(1L);
VenueResponse response = VenueResponse.fromVenue(venue);

// Access response fields
String venueName = response.name();
BigDecimal lat = response.latitude();
List<StationResponse> stations = response.stations();
```
