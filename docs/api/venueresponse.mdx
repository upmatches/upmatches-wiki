## Purpose of the VenueResponse Class

The `VenueResponse` class is a Java record that represents a response object for venue-related data in the application. It encapsulates various details about a venue, such as its identifier, location, associated activity, and related stations. This class is designed to facilitate the transfer of venue data between different layers of the application, particularly from the backend to the frontend.

## Public Methods

The `VenueResponse` class provides the following public method:

### `fromVenue`

Converts a `Venue` entity into a `VenueResponse` object.

| Method Signature | Description |
|------------------|-------------|
| `public static VenueResponse fromVenue(Venue venue)` | Creates a `VenueResponse` instance from a given `Venue` object. |

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `venue`   | `Venue` | The `Venue` entity to be converted into a `VenueResponse`. |

#### Return Type

| Type | Description |
|------|-------------|
| `VenueResponse` | A new instance of `VenueResponse` containing data from the provided `Venue` entity. |

This method extracts data from a `Venue` object, including its ID, source ID, associated activity, name, address, postal code, geographical coordinates, list of stations, and timestamps for creation and last update. It then constructs a `VenueResponse` object with this data, ensuring a structured and consistent format for venue information.
