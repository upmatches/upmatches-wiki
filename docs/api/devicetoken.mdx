## Purpose

The `DeviceToken` class is an entity representing a device token associated with a user for notification purposes. It is part of the notification feature in the application and is used to store information about the device tokens that are linked to users, including the platform type and timestamps for creation and updates.

## Public Methods

The `DeviceToken` class provides the following public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `create` | `User user`, `String deviceToken`, `DevicePlatform platform` | `DeviceToken` | Static method to create a new instance of `DeviceToken` with the specified user, device token, and platform. |
| `touch` | `DevicePlatform platform` | `void` | Updates the platform of the device token. |

## Fields

The class contains the following fields:

- `UUID id`: Unique identifier for the device token.
- `User user`: The user associated with the device token.
- `String deviceToken`: The device token string.
- `DevicePlatform platform`: Enum representing the platform of the device (e.g., iOS, Android).
- `Instant createdAt`: Timestamp indicating when the device token was created.
- `Instant updatedAt`: Timestamp indicating when the device token was last updated.
