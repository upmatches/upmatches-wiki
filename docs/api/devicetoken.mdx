## Overview

The `DeviceToken` class is an entity representing a device token associated with a user for notification purposes. It is part of the notification feature in the application and is mapped to the `notification_device_tokens` table in the database. This class uses JPA annotations for ORM (Object-Relational Mapping) and Lombok annotations to reduce boilerplate code.

## Public Methods

The `DeviceToken` class provides the following public methods:

### `create`

Creates a new instance of `DeviceToken`.

| Parameter    | Type            | Description                       |
|--------------|-----------------|-----------------------------------|
| `user`       | `User`          | The user associated with the device token. |
| `deviceToken`| `String`        | The device token string.          |
| `platform`   | `DevicePlatform`| The platform of the device.       |

| Return Type  | Description                       |
|--------------|-----------------------------------|
| `DeviceToken`| A new instance of `DeviceToken`.  |

### `touch`

Updates the platform of the device token.

| Parameter    | Type            | Description                       |
|--------------|-----------------|-----------------------------------|
| `platform`   | `DevicePlatform`| The new platform of the device.   |

| Return Type  | Description                       |
|--------------|-----------------------------------|
| `void`       | This method does not return a value. |
