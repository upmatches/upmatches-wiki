# DeviceToken

The `DeviceToken` entity represents a push notification token registered for a user's device. It is used to send targeted push notifications to specific devices associated with a user account.

## Purpose

This entity stores the unique device token provided by the platform-specific push notification service (e.g., Apple Push Notification Service (APNS) for iOS, Firebase Cloud Messaging (FCM) for Android). Each token is linked to a specific user and platform, enabling the application to send notifications to the correct device.

## Entity Details

- **Table Name:** `notification_device_tokens`
- **Unique Constraint:** A combination of `user_id` and `device_token` must be unique, preventing duplicate token registrations for the same user.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Primary key, automatically generated using UUID strategy. |
| `user` | `User` | The user who owns this device token. Many-to-one relationship with the `User` entity. |
| `deviceToken` | `String` | The actual device token string, up to 512 characters. |
| `platform` | `DevicePlatform` | The platform of the device (e.g., `IOS`, `ANDROID`). Stored as a string in the database. |
| `createdAt` | `Instant` | Timestamp when the token was first created. Automatically set on persist. |
| `updatedAt` | `Instant` | Timestamp when the token was last updated. Automatically set on update. |

## Public Methods

### `create(User user, String deviceToken, DevicePlatform platform)`

Creates a new `DeviceToken` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user to associate with this device token. |
| `deviceToken` | `String` | The device token string from the push notification service. |
| `platform` | `DevicePlatform` | The platform of the device. |

**Returns:** `DeviceToken` - A new, unsaved `DeviceToken` instance.

### `touch(DevicePlatform platform)`

Updates the platform associated with this device token. This is useful when a device's platform changes (e.g., after an OS update) or when the token is refreshed.

| Parameter | Type | Description |
|-----------|------|-------------|
| `platform` | `DevicePlatform` | The new platform for the device. |

**Returns:** `void`

## Lifecycle Callbacks

- **`onCreate()`**: Automatically sets the `createdAt` field to the current instant before persisting the entity.
- **`onUpdate()`**: Automatically sets the `updatedAt` field to the current instant before updating the entity.

## Usage Example

```java
// Create a new device token for a user
DeviceToken token = DeviceToken.create(user, "abc123deviceToken", DevicePlatform.IOS);

// Save the token using a repository
deviceTokenRepository.save(token);

// Later, update the platform if needed
token.touch(DevicePlatform.ANDROID);
deviceTokenRepository.save(token);
```
