# MintDevTokenService

The `MintDevTokenService` class provides a development-only endpoint for minting authentication tokens. It is designed to be used exclusively in non-production environments (profiles other than `prod`) and is conditionally enabled via the `app.auth.dev.mint-endpoint-enabled` configuration property.

This service allows developers to generate valid JWT access tokens and refresh tokens for any user by providing their user ID, bypassing the normal authentication flow. This is useful for testing and development purposes.

## Class Overview

- **Package:** `com.upmatches.app.features.auth.services`
- **Implements:** `IMintDevTokenService`
- **Annotations:** `@Service`, `@Profile("!prod")`, `@ConditionalOnProperty`
- **Modifier:** `non-sealed`

## Dependencies

| Dependency | Description |
|------------|-------------|
| `UserRepository` | Repository for accessing user data |
| `IJwtTokenService` | Service for generating JWT access and refresh tokens |
| `IRefreshTokenStore` | Store for persisting refresh tokens |

## Public Methods

### `execute`

```java
@Transactional
public TokenResponse execute(final UUID userId)
```

Generates a complete token set (access token + refresh token) for the specified user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user for whom to generate tokens |

**Returns:**

| Type | Description |
|------|-------------|
| `TokenResponse` | A response object containing the access token, refresh token, and access token expiration timestamp |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `AuthenticationException` | If no user exists with the provided `userId` |

**Behavior:**

1. Retrieves the user from the database using the provided `userId`
2. Generates an access token containing the user's ID and various UUIDs (Singpass, Auth0, Apple)
3. Generates a new refresh token
4. Stores the refresh token in the refresh token store
5. Returns a `TokenResponse` containing all generated tokens and expiration information

## Configuration

This service is only active when:

- The Spring profile is **not** `prod` (`@Profile("!prod")`)
- The property `app.auth.dev.mint-endpoint-enabled` is set to `true` (`@ConditionalOnProperty`)

## Error Handling

If the provided `userId` does not correspond to an existing user in the database, the service throws an `AuthenticationException` with a message indicating that a dev token was requested for an unknown user.
