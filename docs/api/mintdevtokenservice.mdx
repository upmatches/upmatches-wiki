## Overview

The `MintDevTokenService` class is a part of the authentication feature in the application. It is designed to generate development tokens for users in non-production environments. This service is conditionally enabled based on the application's configuration properties and is not available in production profiles. It implements the `IMintDevTokenService` interface and provides functionality to mint JWT access tokens and refresh tokens for a specified user.

## Public Methods

### `execute`

Generates a JWT access token and a refresh token for a given user.

| Parameter | Type   | Description                       |
|-----------|--------|-----------------------------------|
| `userId`  | `UUID` | The unique identifier of the user |

| Return Type     | Description                                                                 |
|-----------------|-----------------------------------------------------------------------------|
| `TokenResponse` | Contains the generated access token, refresh token, and the token expiry time |

#### Method Details

- **Transactional**: This method is annotated with `@Transactional`, ensuring that the operations within are executed within a transaction context.
- **Exception Handling**: If the user is not found in the repository, an `AuthenticationException` is thrown with a message indicating the user ID that was not found.
- **Token Generation**: 
  - The method uses `jwtTokenService` to generate an access token for the user based on their unique identifiers.
  - A refresh token is generated and stored using `refreshTokenStore`.
- **Return**: A `TokenResponse` object is returned, encapsulating the access token, refresh token, and the expiration time of the access token.
