# MintDevTokenService

The `MintDevTokenService` class is a development-only service that provides a mechanism to mint (generate) authentication tokens for testing purposes. It implements the `IMintDevTokenService` interface and is designed to be used exclusively in non-production environments.

## Purpose

This service allows developers to generate valid JWT access tokens and refresh tokens for any user in the system by providing their user ID. This is particularly useful for:
- Local development and testing
- Integration testing
- API testing without going through the full authentication flow
- Debugging authentication-related issues

## Key Characteristics

- **Profile-restricted**: Only active when the Spring profile is NOT `prod`
- **Feature-flagged**: Requires the property `app.auth.dev.mint-endpoint-enabled=true` to be set
- **Transactional**: Token generation and storage are performed within a single database transaction
- **Non-sealed**: The class is declared as `non-sealed`, allowing for future extension if needed

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `UserRepository` | Repository | Used to look up users by their UUID |
| `IJwtTokenService` | Service | Handles JWT access token and refresh token generation |
| `IRefreshTokenStore` | Store | Manages persistence of refresh tokens |

## Public Methods

### `execute(UUID userId)`

Generates a complete token response (access token + refresh token) for the specified user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user to generate tokens for |

**Returns**: `TokenResponse` containing:
- Access token (JWT)
- Refresh token
- Access token expiration timestamp (UTC)

**Throws**: `AuthenticationException` if no user exists with the provided `userId`

**Behavior**:
1. Looks up the user by their UUID in the database
2. Generates an access token containing the user's ID and their various platform UUIDs (Singpass, Auth0, Apple)
3. Generates a new refresh token
4. Stores the refresh token in the token store
5. Returns a `TokenResponse` with all generated tokens

## Error Handling

The service throws an `AuthenticationException` with a descriptive message when the requested user ID does not exist in the system. The error message format is:
```
Dev token requested for unknown user '<userId>'
```

## Configuration

To enable this service, the following conditions must be met:

1. The active Spring profile must NOT be `prod`
2. The property `app.auth.dev.mint-endpoint-enabled` must be set to `true`

Example `application-dev.yml` configuration:
```yaml
app:
  auth:
    dev:
      mint-endpoint-enabled: true
```
