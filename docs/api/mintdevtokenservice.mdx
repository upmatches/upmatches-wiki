## Purpose

The `MintDevTokenService` class is a part of the authentication feature in the application. It is responsible for generating development tokens for users in non-production environments. This service is conditionally enabled based on application properties and is designed to facilitate testing and development by providing JWT access tokens and refresh tokens for a specified user.

## Public Methods

### `execute`

Generates a JWT access token and a refresh token for a specified user.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| `userId`  | `UUID` | The unique identifier of the user.   |

| Return Type   | Description                                                                 |
|---------------|-----------------------------------------------------------------------------|
| `TokenResponse` | Returns a `TokenResponse` object containing the access token, refresh token, and the expiration time of the access token. |

## Detailed Description

- **Class Annotations**:
  - `@Service`: Indicates that this class is a service component in the Spring framework.
  - `@Profile("!prod")`: Specifies that this service should only be active in non-production profiles.
  - `@ConditionalOnProperty`: Ensures that the service is only enabled when the `app.auth.dev.mint-endpoint-enabled` property is set to `true`.

- **Dependencies**:
  - `UserRepository`: Used to retrieve user information from the database.
  - `IJwtTokenService`: Provides methods to generate JWT access and refresh tokens.
  - `IRefreshTokenStore`: Handles the storage of refresh tokens.

- **Exception Handling**:
  - Throws `AuthenticationException` if the user is not found in the repository.

This class is crucial for development environments where generating tokens for testing purposes is necessary without affecting the production environment.
