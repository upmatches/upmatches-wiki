# MintDevTokenService

The `MintDevTokenService` class provides a development-only endpoint for minting authentication tokens. It is designed to be used exclusively in non-production environments (profiles other than `prod`) and is conditionally enabled via the `app.auth.dev.mint-endpoint-enabled` configuration property.

This service allows developers to generate valid JWT access tokens and refresh tokens for any user by providing their user ID, bypassing the normal authentication flow. This is useful for testing and development purposes.

## Class Overview

- **Package:** `com.upmatches.app.features.auth.services`
- **Implements:** `IMintDevTokenService`
- **Annotations:** `@Service`, `@Profile("!prod")`, `@ConditionalOnProperty`
- **Modifier:** `non-sealed`

### Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `UserRepository` | Repository | Used to look up users by their UUID |
| `IJwtTokenService` | Service | Generates JWT access and refresh tokens |
| `IRefreshTokenStore` | Store | Persists refresh tokens for later validation |

## Public Methods

### `execute`

```java
@Transactional
public TokenResponse execute(final UUID userId)
```

Generates a complete token set (access token + refresh token) for the specified user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user for whom to generate tokens |

**Returns:**

| Type | Description |
|------|-------------|
| `TokenResponse` | Contains the generated access token, refresh token, and access token expiration timestamp |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `AuthenticationException` | If no user exists with the provided `userId` |

**Behavior:**

1. Looks up the user by their UUID in the database.
2. If the user is not found, throws an `AuthenticationException` with a descriptive message.
3. Generates an access token using the user's ID, Singpass UUID, Auth0 UUID, and Apple UUID.
4. Generates a new refresh token.
5. Stores the refresh token in the refresh token store, associated with the user's ID.
6. Returns a `TokenResponse` containing the access token, refresh token, and expiration time.

## Configuration

This service is only active when:

- The Spring profile is **not** `prod` (i.e., development or test profiles)
- The property `app.auth.dev.mint-endpoint-enabled` is set to `true`

## Usage Example

```java
// Inject the service
private final IMintDevTokenService mintDevTokenService;

// Generate tokens for a user
UUID userId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
TokenResponse tokens = mintDevTokenService.execute(userId);

// Use the tokens
String accessToken = tokens.accessToken();
String refreshToken = tokens.refreshToken();
Instant expiresAt = tokens.expiresAtUtc();
```
