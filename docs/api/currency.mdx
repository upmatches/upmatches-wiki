## Purpose of the `Currency` Class

The `Currency` class is a value object that represents a currency using a 3-letter ISO-4217 code. It ensures that the currency code is valid by enforcing constraints during instantiation. This class is immutable and uses Java's `record` feature to define its structure concisely.

## Public Methods

The `Currency` class provides the following public method:

| Method Signature            | Description                                                                 |
|-----------------------------|-----------------------------------------------------------------------------|
| `public static Currency create(String value)` | Creates a new `Currency` instance with the specified 3-letter ISO-4217 code. |

### Method Details

#### `create`

- **Description**: This static method is used to create a new instance of the `Currency` class. It validates the input to ensure it is a non-null, 3-letter ISO-4217 currency code.
- **Parameters**:

  | Name  | Type   | Description                               |
  |-------|--------|-------------------------------------------|
  | value | String | The 3-letter ISO-4217 currency code.      |

- **Returns**: A new instance of the `Currency` class.

## Validation

The `Currency` class performs the following validations:

1. **Null Check**: Ensures that the currency value is not null. If null, it throws an `IllegalArgumentException` with the message "Currency value must not be null."
2. **Pattern Check**: Ensures that the currency value matches the ISO-4217 format, which is a 3-letter uppercase code. If the value does not match, it throws an `IllegalArgumentException` with a message indicating the expected format and the invalid value provided.
