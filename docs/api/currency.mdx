# Currency

The `Currency` class is a Java record that represents a currency code compliant with the ISO 4217 standard. It provides a type-safe way to handle currency values in the application, ensuring that only valid 3-letter uppercase currency codes (e.g., 'SGD', 'USD', 'EUR') are accepted.

## Purpose

This value object is designed to:
- Enforce ISO 4217 currency code validation at construction time
- Provide an immutable representation of a currency
- Offer a factory method for convenient creation
- Prevent null or malformed currency values from propagating through the system

## Constructor

The record's canonical constructor performs validation on the provided `value` parameter.

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `value`   | String | The ISO 4217 currency code to validate and store |

**Validation Rules:**
- The value must not be `null` (throws `IllegalArgumentException` with message "Currency value must not be null.")
- The value must match the pattern `^[A-Z]{3}$` (throws `IllegalArgumentException` with message "Currency must be a 3-letter ISO-4217 code (e.g. 'SGD'). Got: '%s'")

## Public Methods

### `create(String value)`

Factory method for creating a `Currency` instance.

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `value`   | String | The ISO 4217 currency code to validate and store |

| Returns   | Type       | Description                                      |
|-----------|------------|--------------------------------------------------|
| `Currency`| `Currency` | A new `Currency` instance with the validated code|

**Example Usage:**
```java
Currency sgd = Currency.create("SGD");
Currency usd = Currency.create("USD");
```

## Record Components

As a Java record, `Currency` automatically provides:
- `String value()` - accessor method to retrieve the currency code
- `equals()` - value-based equality comparison
- `hashCode()` - consistent hash code based on the value
- `toString()` - string representation of the record
