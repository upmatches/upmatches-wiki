# Currency

The `Currency` class is a Java record that represents a currency code compliant with the ISO 4217 standard. It ensures that any currency value is a valid three-letter uppercase alphabetic code (e.g., "SGD", "USD", "EUR").

This class is immutable and provides a factory method for convenient instantiation.

## Purpose

- **Validation**: Guarantees that the currency code is non-null and matches the ISO 4217 pattern (`^[A-Z]{3}$`).
- **Immutability**: As a Java record, it automatically provides `equals()`, `hashCode()`, `toString()`, and a canonical constructor.
- **Type Safety**: Prevents invalid or malformed currency strings from being used throughout the application.

## Public API

### Constructor

| Constructor | Description |
|-------------|-------------|
| `Currency(String value)` | Creates a new `Currency` instance. Throws `IllegalArgumentException` if the value is null or does not match the ISO 4217 pattern. |

### Factory Method

| Method | Return Type | Description |
|--------|-------------|-------------|
| `static Currency create(String value)` | `Currency` | Convenience factory method that delegates to the constructor. Returns a new `Currency` instance. |

### Record Accessor

| Method | Return Type | Description |
|--------|-------------|-------------|
| `String value()` | `String` | Returns the ISO 4217 currency code string. |

## Usage Example

```java
// Valid currency codes
Currency usd = Currency.create("USD");
Currency sgd = new Currency("SGD");

// Access the value
String code = usd.value(); // "USD"

// Invalid codes will throw IllegalArgumentException
// Currency invalid = Currency.create("usd");   // lowercase
// Currency invalid = Currency.create("USDD");  // too long
// Currency invalid = Currency.create(null);    // null
```

## Error Handling

The class throws `IllegalArgumentException` in two cases:

1. **Null value**: If the provided `value` is `null`, the error message is: `"Currency value must not be null."`
2. **Invalid format**: If the value does not match the ISO 4217 pattern, the error message includes the invalid input: `"Currency must be a 3-letter ISO-4217 code (e.g. 'SGD'). Got: '<invalid_value>'"`

## Dependencies

- `java.util.regex.Pattern` – Used for ISO 4217 validation.

## Notes

- The class is defined as a `record`, which automatically generates the constructor, accessor, `equals()`, `hashCode()`, and `toString()` methods.
- The validation is performed in the canonical constructor, ensuring that no invalid `Currency` instance can be created.
- The `create()` static method is provided for convenience and readability, but it is functionally identical to calling the constructor directly.
