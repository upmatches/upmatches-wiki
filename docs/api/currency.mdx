# Currency

The `Currency` class is a Java record that represents a currency code compliant with the ISO-4217 standard. It provides a type-safe way to handle currency values in the application, ensuring that only valid three-letter uppercase currency codes (e.g., "SGD", "USD", "EUR") are accepted.

## Purpose

- **Type Safety**: Encapsulates currency codes as a dedicated type rather than using raw strings.
- **Validation**: Automatically validates that the provided value is a non-null, three-letter uppercase alphabetic string matching the ISO-4217 pattern.
- **Immutability**: As a Java record, `Currency` is immutable by design, making it safe for use in concurrent contexts.

## Constructor

The record's canonical constructor performs validation:

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `value`   | String | The ISO-4217 currency code (e.g., "SGD", "USD") |

**Throws:**
- `IllegalArgumentException` if `value` is `null`.
- `IllegalArgumentException` if `value` does not match the pattern `^[A-Z]{3}$`.

## Public Methods

### `create(String value)`

Factory method to create a `Currency` instance.

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `value`   | String | The ISO-4217 currency code (e.g., "SGD", "USD") |

**Returns:** `Currency` — a new validated `Currency` instance.

**Throws:**
- `IllegalArgumentException` if `value` is `null` or invalid.

### `value()`

Auto-generated accessor method from the record definition.

**Returns:** `String` — the three-letter ISO-4217 currency code.

## Example Usage

```java
// Create a valid currency
Currency currency = Currency.create("SGD");
System.out.println(currency.value()); // Output: SGD

// Invalid currency throws exception
try {
    Currency invalid = Currency.create("sgd"); // lowercase
} catch (IllegalArgumentException e) {
    System.out.println(e.getMessage()); // Currency must be a 3-letter ISO-4217 code...
}
```

## Notes

- The class uses a compiled `Pattern` for efficient regex validation.
- Error messages are defined as constants for maintainability.
