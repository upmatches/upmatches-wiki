# DevTokenPageRenderer

The `DevTokenPageRenderer` class is a Spring `@Service` that generates an HTML page for development purposes. It renders authentication tokens (access and refresh tokens) in a user-friendly web interface, allowing developers to easily copy tokens during local development and testing.

This class implements the `IDevTokenPageRenderer` interface and is designed to work with the `AuthDevProperties` configuration to control when and how the token page is displayed.

## Purpose

- Provides a visual representation of authentication tokens during development
- Enables easy copying of access and refresh tokens for testing
- Displays token expiration information
- Shows mobile deep links for testing mobile authentication flows
- Restricts access to trusted hosts (localhost, 127.0.0.1, etc.)

## Configuration

The class uses `AuthDevProperties` to configure:
- Whether the token page is enabled (`tokenPageEnabled`)
- Additional allowed hosts beyond the defaults (`tokenPageAllowedHosts`)

## Default Allowed Hosts

| Host | Description |
|------|-------------|
| `localhost` | Standard localhost |
| `127.0.0.1` | IPv4 loopback |
| `[::1]` | IPv6 loopback |
| `0:0:0:0:0:0:0:1` | IPv6 full notation |

## Methods

### `isEnabledFor(HttpServletRequest request)`

Checks if the token page should be rendered for the given request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The incoming HTTP request |

**Returns:** `boolean` - `true` if the token page is enabled and the request comes from an allowed host

### `render(String accessToken, String refreshToken, Long expiresAtUtc, Boolean isNewUser, String mobileRedirectUrl)`

Generates the HTML page containing the authentication tokens.

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The access token to display |
| `refreshToken` | `String` | The refresh token to display |
| `expiresAtUtc` | `Long` | Token expiration time in UTC epoch seconds |
| `isNewUser` | `Boolean` | Whether this is a new user (shows "new user" badge) |
| `mobileRedirectUrl` | `String` | The mobile deep link URL |

**Returns:** `ResponseEntity<String>` - HTML response with `Content-Type: text/html`

## HTML Page Features

The generated page includes:

- **Title section** with optional "new user" badge
- **Development mode notice** indicating `MOCKPASS_DEV_MODE=true`
- **Access Token field** with copy button
- **Refresh Token field** with copy button
- **Expiration time** display in UTC epoch seconds
- **Mobile Deep Link** with clickable URL
- **Copy functionality** with visual feedback (button changes to "Copied" with green styling)

## Usage Example

```java
@Autowired
private DevTokenPageRenderer renderer;

public ResponseEntity<String> handleCallback(HttpServletRequest request) {
    if (renderer.isEnabledFor(request)) {
        return renderer.render(
            "eyJhbGciOiJIUzI1NiIs...",
            "dGhpcyBpcyBhIHJlZnJl...",
            1700000000L,
            true,
            "myapp://callback?token=abc123"
        );
    }
    // Handle normal flow
}
```

## Security Considerations

- The page is only rendered for requests from allowed hosts (localhost by default)
- All token values are HTML-escaped to prevent XSS attacks
- The class uses `HtmlUtils.htmlEscape()` for safe rendering
- Additional hosts can be configured via `AuthDevProperties`
