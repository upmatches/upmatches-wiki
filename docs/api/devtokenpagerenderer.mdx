## Purpose of the Class

The `DevTokenPageRenderer` class is a service component in a Spring application that generates an HTML page for displaying development tokens. It is primarily used in development environments to facilitate the testing of authentication flows by rendering access and refresh tokens along with additional metadata. The class ensures that the token page is only accessible from a predefined set of allowed hosts and provides a user-friendly interface for copying tokens and viewing mobile deep links.

## Public Methods

### `isEnabledFor`

Determines if the token page rendering is enabled for a given HTTP request based on the host.

| Parameter | Type                      | Description                                  |
|-----------|---------------------------|----------------------------------------------|
| request   | `HttpServletRequest`      | The HTTP request to check against allowed hosts. |

| Return Type | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `boolean`   | Returns `true` if the token page is enabled for the request's host; otherwise, `false`. |

### `render`

Generates an HTML page containing the access token, refresh token, expiration time, and a mobile deep link.

| Parameter         | Type       | Description                                                  |
|-------------------|------------|--------------------------------------------------------------|
| accessToken       | `String`   | The access token to display.                                 |
| refreshToken      | `String`   | The refresh token to display.                                |
| expiresAtUtc      | `Long`     | The expiration time in UTC epoch seconds.                    |
| isNewUser         | `Boolean`  | Indicates if the user is new, affecting the display of a badge. |
| mobileRedirectUrl | `String`   | The URL to which mobile clients would be redirected.         |

| Return Type                | Description                                                                 |
|----------------------------|-----------------------------------------------------------------------------|
| `ResponseEntity<String>`   | Returns a `ResponseEntity` containing the HTML content of the token page.   |
