## Overview

The `InfisicalProperties` class is a configuration properties holder for the Infisical application. It is designed to be used with Spring Boot's `@ConfigurationProperties` annotation, allowing the application to bind external configuration properties to this class. The properties are prefixed with `app.infisical` in the configuration files.

This class is implemented as a Java record, which provides a concise way to model immutable data. It includes several properties related to Infisical's client configuration, such as `clientId`, `clientSecret`, `projectId`, `hostUri`, `environment`, and `secretPath`. Default values are provided for `hostUri`, `environment`, and `secretPath` if they are not specified or are blank.

## Public Methods

The `InfisicalProperties` class does not explicitly define public methods beyond those automatically provided by the Java record, such as accessors for each field. Below is a table documenting these accessors:

| Method Name       | Parameters | Return Type | Description                                                  |
|-------------------|------------|-------------|--------------------------------------------------------------|
| `clientId()`      | None       | `String`    | Returns the client ID for Infisical.                         |
| `clientSecret()`  | None       | `String`    | Returns the client secret for Infisical.                     |
| `projectId()`     | None       | `String`    | Returns the project ID associated with Infisical.            |
| `hostUri()`       | None       | `String`    | Returns the host URI for Infisical. Defaults to `https://app.infisical.com` if not set. |
| `environment()`   | None       | `String`    | Returns the environment setting for Infisical. Defaults to `dev` if not set. |
| `secretPath()`    | None       | `String`    | Returns the secret path for Infisical. Defaults to `/` if not set. |

## Default Values

The class provides default values for certain properties to ensure that the application can function with minimal configuration:

- **`hostUri`**: Defaults to `https://app.infisical.com` if not provided or blank.
- **`environment`**: Defaults to `dev` if not provided or blank.
- **`secretPath`**: Defaults to `/` if not provided or blank.

These defaults are set within the compact constructor of the record, ensuring that any instance of `InfisicalProperties` will have valid values for these fields.
