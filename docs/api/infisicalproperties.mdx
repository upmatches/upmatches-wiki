# InfisicalProperties

The `InfisicalProperties` class is a Spring Boot configuration properties record that maps to the `app.infisical.*` prefix in your application's configuration files (e.g., `application.yml` or `application.properties`). It encapsulates all necessary connection parameters for integrating with the Infisical secrets management platform.

## Purpose

This record provides a type-safe way to externalize Infisical configuration settings. By using Spring Boot's `@ConfigurationProperties` annotation, it automatically binds properties from your configuration sources to the record's components. The compact constructor ensures sensible defaults are applied when optional values are not explicitly provided.

## Configuration Properties

The following table describes each configurable property:

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `clientId` | `String` | (required) | The client ID used for authentication with Infisical |
| `clientSecret` | `String` | (required) | The client secret used for authentication with Infisical |
| `projectId` | `String` | (required) | The unique identifier of the Infisical project |
| `hostUri` | `String` | `https://app.infisical.com` | The base URI of the Infisical API server |
| `environment` | `String` | `dev` | The target environment (e.g., dev, staging, prod) |
| `secretPath` | `String` | `/` | The path within the project where secrets are stored |

## Default Values

The record applies the following defaults when properties are not explicitly configured:

- **hostUri**: Defaults to `https://app.infisical.com` if not provided or blank
- **environment**: Defaults to `dev` if not provided or blank
- **secretPath**: Defaults to `/` if not provided or blank

## Usage Example

To use this configuration in your Spring Boot application, add the following to your `application.yml`:

```yaml
app:
  infisical:
    client-id: your-client-id
    client-secret: your-client-secret
    project-id: your-project-id
    host-uri: https://app.infisical.com
    environment: dev
    secret-path: /
```

Then inject the properties into your service:

```java
@Service
public class InfisicalService {
    private final InfisicalProperties properties;

    public InfisicalService(InfisicalProperties properties) {
        this.properties = properties;
    }

    public void connect() {
        // Use properties.clientId(), properties.clientSecret(), etc.
    }
}
```

## Notes

- The `@ConfigurationProperties` annotation requires Spring Boot's configuration processor to be enabled for IDE support and metadata generation.
- All properties are immutable after construction due to the record's design.
- The compact constructor validates and applies defaults, ensuring the record always contains valid values.
