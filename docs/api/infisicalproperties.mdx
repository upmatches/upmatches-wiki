# InfisicalProperties

## Purpose

The `InfisicalProperties` class is a Spring Boot configuration properties record that maps to the `app.infisical` prefix in application configuration files (e.g., `application.yml` or `application.properties`). It encapsulates all necessary connection parameters for integrating with the Infisical secrets management platform.

This record provides sensible defaults for optional fields, ensuring that the application can function with minimal configuration while still allowing full customization when needed.

## Configuration Prefix

All properties are prefixed with `app.infisical` in your application configuration.

## Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `clientId` | `String` | Yes | None | The client ID used for authentication with Infisical |
| `clientSecret` | `String` | Yes | None | The client secret used for authentication with Infisical |
| `projectId` | `String` | Yes | None | The unique identifier of the Infisical project |
| `hostUri` | `String` | No | `https://app.infisical.com` | The base URI of the Infisical server |
| `environment` | `String` | No | `dev` | The environment to target (e.g., dev, staging, prod) |
| `secretPath` | `String` | No | `/` | The path within the project where secrets are stored |

## Default Values

The record constructor applies the following defaults when properties are not explicitly configured:

- **hostUri**: Defaults to `https://app.infisical.com` if not provided or blank
- **environment**: Defaults to `dev` if not provided or blank
- **secretPath**: Defaults to `/` if not provided or blank

## Usage Example

### application.yml

```yaml
app:
  infisical:
    client-id: your-client-id
    client-secret: your-client-secret
    project-id: your-project-id
    host-uri: https://app.infisical.com
    environment: dev
    secret-path: /
```

### application.properties

```properties
app.infisical.client-id=your-client-id
app.infisical.client-secret=your-client-secret
app.infisical.project-id=your-project-id
app.infisical.host-uri=https://app.infisical.com
app.infisical.environment=dev
app.infisical.secret-path=/
```

## Dependency Injection

To use this configuration in your Spring beans, inject it via constructor injection:

```java
@Service
public class InfisicalService {
    private final InfisicalProperties properties;
    
    public InfisicalService(InfisicalProperties properties) {
        this.properties = properties;
    }
    
    public void connect() {
        // Use properties.clientId(), properties.clientSecret(), etc.
    }
}
```

## Notes

- This class is implemented as a Java `record`, providing immutable data carriers with automatically generated constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods.
- The custom compact constructor ensures that optional fields are properly defaulted during object creation.
- To enable `@ConfigurationProperties` scanning, ensure your Spring Boot application has `@ConfigurationPropertiesScan` or `@EnableConfigurationProperties(InfisicalProperties.class)` configured.
