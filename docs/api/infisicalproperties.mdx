## Overview

The `InfisicalProperties` class is a configuration properties holder for the Infisical application within the `com.upmatches.app.features.auth.properties` package. It is designed to manage and provide access to various configuration parameters needed for authentication and integration with the Infisical service. This class utilizes Spring Boot's `@ConfigurationProperties` to map properties from external configuration files to its fields, allowing for easy configuration management.

## Class Details

The `InfisicalProperties` class is defined as a Java record, which is a special kind of class in Java that is immutable and primarily used to store data. It includes the following fields:

- `clientId`: The client ID for authentication.
- `clientSecret`: The client secret for authentication.
- `projectId`: The project ID associated with the Infisical service.
- `hostUri`: The URI of the Infisical host. Defaults to `https://app.infisical.com` if not provided.
- `environment`: The environment in which the application is running. Defaults to `dev` if not provided.
- `secretPath`: The path to the secret. Defaults to `/` if not provided.
