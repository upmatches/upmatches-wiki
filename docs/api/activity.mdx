## Purpose

The `Activity` class represents an entity in the application that is mapped to the `activities` table in the database. It is designed to handle activities with unique identifiers and names, and it automatically manages timestamps for creation and updates. This class leverages JPA annotations for ORM (Object-Relational Mapping) and uses Lombok for boilerplate code reduction.

## Public Methods

The `Activity` class provides the following public methods:

| Method Name   | Parameters          | Return Type | Description                                                                 |
|---------------|---------------------|-------------|-----------------------------------------------------------------------------|
| `create`      | `String name`       | `Activity`  | Static factory method to create a new `Activity` instance with the given name. |
| `updateName`  | `String name`       | `void`      | Updates the name of the `Activity` instance.                                |

## Annotations and Lifecycle Methods

- **JPA Annotations**: The class uses JPA annotations such as `@Entity`, `@Table`, `@Id`, `@GeneratedValue`, and `@Column` to define the mapping between the class and the database table.
- **Lifecycle Callbacks**: 
  - `@PrePersist`: The `onCreate` method is annotated with `@PrePersist` to set the `createdAt` and `updatedAt` timestamps before the entity is persisted.
  - `@PreUpdate`: The `onUpdate` method is annotated with `@PreUpdate` to update the `updatedAt` timestamp before the entity is updated.

## Fields

- **id**: A unique identifier for each `Activity`, generated automatically using UUID strategy.
- **referenceId**: An integer reference ID that is unique and non-updatable.
- **name**: A unique name for the `Activity`, with a maximum length of 100 characters.
- **createdAt**: The timestamp when the `Activity` was created, set automatically and non-updatable.
- **updatedAt**: The timestamp when the `Activity` was last updated, managed automatically.
