# Activity Entity

The `Activity` class is a JPA entity that represents an activity within the UpMatches application. It maps to the `activities` database table and provides a structured way to manage activity data, including unique identification, naming, and automatic timestamp management.

## Purpose

This entity serves as the data model for activities, which are core domain objects in the application. It handles:
- Unique identification via UUID and an auto-incrementing reference ID
- Name management with uniqueness constraints
- Automatic timestamp tracking for creation and updates
- Immutable creation timestamps to maintain data integrity

## Class Overview

The `Activity` class uses Lombok's `@Getter` annotation to automatically generate getter methods for all fields. It implements JPA lifecycle callbacks to automatically manage timestamps.

### Fields

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | `UUID` | Primary Key, Auto-generated | Unique identifier for the activity |
| `referenceId` | `Integer` | Not Null, Unique, Non-insertable, Non-updatable | Auto-incrementing reference number |
| `name` | `String` | Not Null, Unique, Max 100 characters | Name of the activity |
| `createdAt` | `Instant` | Not Null, Non-updatable | Timestamp when the activity was created |
| `updatedAt` | `Instant` | Nullable | Timestamp when the activity was last updated |

## Public Methods

### `create(String name)`
Creates a new `Activity` instance with the specified name.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The name for the new activity |

**Returns:** `Activity` - A new Activity instance with the provided name

### `updateName(String name)`
Updates the name of the activity.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The new name for the activity |

**Returns:** `void`

## Lifecycle Callbacks

### `onCreate()`
Automatically called before the entity is persisted. Sets both `createdAt` and `updatedAt` to the current timestamp.

### `onUpdate()`
Automatically called before the entity is updated. Updates the `updatedAt` timestamp to the current time.

## Usage Example

```java
// Create a new activity
Activity hiking = Activity.create("Hiking");

// Update the activity name
hiking.updateName("Mountain Hiking");

// The entity will automatically manage timestamps
// when persisted via JPA
```

## Database Mapping

The entity maps to the `activities` table with the following column mappings:
- `id` → UUID primary key
- `reference_id` → Auto-incrementing integer (managed by database)
- `name` → Unique activity name (max 100 characters)
- `created_at` → Creation timestamp (set once)
- `updated_at` → Last update timestamp
