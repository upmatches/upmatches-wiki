# Activity Entity

The `Activity` class is a JPA entity that represents an activity within the UpMatches application. It maps to the `activities` database table and encapsulates the core data fields and lifecycle management for an activity record.

## Purpose

This entity is designed to store and manage activity information, including a unique identifier, a reference ID, a name, and timestamps for creation and updates. It provides a factory method for creating new instances and ensures automatic timestamp management through JPA lifecycle callbacks.

## Entity Mapping

The class is annotated with `@Entity` and `@Table(name = "activities")`, mapping it to the `activities` table in the database.

## Fields

| Field | Type | Database Column | Constraints | Description |
|-------|------|-----------------|-------------|-------------|
| `id` | `UUID` | `id` | Primary Key, Generated | Unique identifier for the activity |
| `referenceId` | `Integer` | `reference_id` | Not Null, Unique, Non-insertable, Non-updatable | External reference identifier |
| `name` | `String` | `name` | Not Null, Unique, Max Length 100 | Name of the activity |
| `createdAt` | `Instant` | `created_at` | Not Null, Non-updatable | Timestamp when the activity was created |
| `updatedAt` | `Instant` | `updated_at` | Nullable | Timestamp when the activity was last updated |

## Public Methods

### `create(String name)`

Creates a new `Activity` instance with the specified name.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The name for the new activity |

**Returns:** `Activity` - A new Activity instance with the provided name

### `updateName(String name)`

Updates the name of the activity.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The new name for the activity |

**Returns:** `void`

## Lifecycle Callbacks

The entity uses JPA lifecycle callbacks to automatically manage timestamps:

- **`@PrePersist` (`onCreate()`)**: Sets both `createdAt` and `updatedAt` to the current instant before persisting a new entity.
- **`@PreUpdate` (`onUpdate()`)**: Updates the `updatedAt` field to the current instant before updating an existing entity.

## Usage Example

```java
// Create a new activity
Activity activity = Activity.create("Hiking");
// Update the activity name
activity.updateName("Mountain Hiking");
```

## Notes

- The `referenceId` field is marked as `insertable = false` and `updatable = false`, meaning it is managed externally (likely by the database or another system component).
- The class uses Lombok's `@Getter` annotation to generate getters for all fields.
- The protected no-argument constructor is required by JPA for entity instantiation.
