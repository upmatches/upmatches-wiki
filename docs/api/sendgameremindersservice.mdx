## Purpose

The `SendGameRemindersService` class is responsible for sending notifications to users about upcoming games. It handles both individual game reminders and aggregated reminders for games occurring in the next three days. The service interacts with various repositories and services to fetch game data, create notifications, and deliver them via push notifications or email.

## Public Methods

### `execute`

Executes the process of sending game reminders based on the specified notification type and time range.

| Parameter     | Type            | Description                                                                 |
|---------------|-----------------|-----------------------------------------------------------------------------|
| `type`        | `NotificationType` | The type of notification to send (e.g., GAME_REMINDER_3_DAYS).              |
| `minHoursAhead` | `long`          | The minimum number of hours ahead to consider for sending reminders.       |
| `maxHoursAhead` | `long`          | The maximum number of hours ahead to consider for sending reminders.       |

**Returns:** `int` - The number of notifications sent.

## Detailed Description

### Class Dependencies

- **Repositories:**
  - `GameRepository`: Used to fetch scheduled games within a specified time range.
  - `GameParticipantRepository`: Used to find active participants of a game.
  - `NotificationRepository`: Used to check for existing notifications and store new ones.

- **Services:**
  - `ICreateNotificationService`: Used to create new notification entities.
  - `IPushNotificationService`: Used to send push notifications.
  - `IEmailNotificationService`: Used to send email notifications.

- **Properties:**
  - `ShareLinkProperties`: Provides configuration for generating game URLs.

### Notification Process

1. **Fetch Games:** The service retrieves games scheduled to start within a specified time window.
2. **Determine Notification Type:** Depending on the `NotificationType`, it either sends individual game reminders or aggregated reminders for games occurring in the next three days.
3. **Create and Send Notifications:** For each game or group of games, the service creates a notification and attempts to deliver it via push notification. If push delivery fails, it falls back to email delivery.

### Helper Methods

- **`sendPerGameReminders`:** Sends individual reminders for each game.
- **`sendAggregatedThreeDayReminders`:** Sends aggregated reminders for games occurring in the next three days.
- **`deliverExternally`:** Handles the external delivery of notifications via push or email.
- **`recipientIdsFor`:** Retrieves the set of recipient IDs for a given game.
- **`localDateFor`:** Converts a game's start time to a local date in the Singapore timezone.
- **`dateResourceId`:** Generates a UUID for a notification resource based on its type and date.
- **`courtLabel`:** Returns the appropriate label ("court" or "courts") based on the count.
- **`formatDate`:** Formats a date using a predefined pattern.
