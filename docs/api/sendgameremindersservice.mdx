# SendGameRemindersService

## Purpose

The `SendGameRemindersService` is a Spring service responsible for sending game reminders to users. It handles two types of reminders:

1. **3-day aggregated reminders**: Groups upcoming games by date and sends a single notification summarizing all games on that date.
2. **1-day per-game reminders**: Sends individual notifications for each game happening the next day.

The service ensures that duplicate notifications are not sent by checking existing records in the database. It also handles external delivery via push notifications, falling back to email if push fails.

## Public Methods

### `execute`

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of reminder to send (e.g., `GAME_REMINDER_3_DAYS` or `GAME_REMINDER_1_DAY`) |
| `minHoursAhead` | `long` | Minimum hours ahead of the game start time to consider |
| `maxHoursAhead` | `long` | Maximum hours ahead of the game start time to consider |

**Returns:** `int` - The number of notifications sent.

**Description:**  
This is the main entry point for sending game reminders. It queries for games scheduled to start within the specified time window and sends appropriate reminders based on the notification type.

- For `GAME_REMINDER_3_DAYS`, it aggregates games by date and sends a single reminder per recipient per date.
- For other types (typically `GAME_REMINDER_1_DAY`), it sends individual reminders for each game.

## Private Methods

### `sendPerGameReminders`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to send reminders for |
| `type` | `NotificationType` | The type of reminder |

**Returns:** `int` - Number of notifications sent.

**Description:**  
Sends individual reminders for each game. For each game, it:
1. Retrieves all recipient IDs (organizer + active participants)
2. Checks if a notification already exists for the recipient, type, and game
3. Creates a new notification if one doesn't exist
4. Delivers the notification externally (push or email)

### `sendAggregatedThreeDayReminders`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to aggregate reminders for |

**Returns:** `int` - Number of notifications sent.

**Description:**  
Groups games by recipient and date, then sends a single aggregated reminder per recipient per date. The message includes the count of games and the date (e.g., "You have 2 courts on 15-Jan.").

### `deliverExternally`

| Parameter | Type | Description |
|-----------|------|-------------|
| `notification` | `Notification` | The notification to deliver |
| `emailContext` | `EmailContext` | Context data for email delivery |

**Returns:** `void`

**Description:**  
Attempts to send a push notification first. If push delivery fails (returns anything other than `SENT`), it falls back to sending an email if the recipient has an email address.

### `recipientIdsFor`

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to get recipients for |

**Returns:** `Set<UUID>` - Set of recipient user IDs.

**Description:**  
Collects the IDs of the game organizer and all active participants.

### `localDateFor`

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to get the local date for |

**Returns:** `LocalDate` - The game's start date in Singapore time (SGT).

### `dateResourceId`

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The notification type |
| `date` | `LocalDate` | The date to generate a resource ID for |

**Returns:** `UUID` - A deterministic UUID based on the notification type and date.

**Description:**  
Generates a unique resource ID for aggregated reminders to prevent duplicate notifications for the same date and type.

### `courtLabel`

| Parameter | Type | Description |
|-----------|------|-------------|
| `count` | `int` | Number of courts |

**Returns:** `String` - "court" for singular, "courts" for plural.

### `formatDate`

| Parameter | Type | Description |
|-----------|------|-------------|
| `date` | `LocalDate` | The date to format |

**Returns:** `String` - Formatted date string (e.g., "15-Jan").
