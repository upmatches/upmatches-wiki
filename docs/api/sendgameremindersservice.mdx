# SendGameRemindersService

## Purpose

The `SendGameRemindersService` is a Spring service responsible for sending game reminders to users. It handles two types of reminders:

1. **3-day aggregated reminders**: Groups upcoming games by date and sends a single notification summarizing the number of courts booked on each date.
2. **1-day per-game reminders**: Sends individual notifications for each game scheduled for the next day.

The service ensures that duplicate notifications are not sent by checking existing records in the `NotificationRepository`. It also attempts to deliver notifications via push first, falling back to email if push delivery fails or is unavailable.

## Public Methods

### `execute(NotificationType type, long minHoursAhead, long maxHoursAhead)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of reminder to send (`GAME_REMINDER_3_DAYS` or `GAME_REMINDER_1_DAY`). |
| `minHoursAhead` | `long` | Minimum hours ahead of the game start time to consider. |
| `maxHoursAhead` | `long` | Maximum hours ahead of the game start time to consider. |

**Returns:** `int` - The number of notifications successfully sent.

**Description:**  
This is the main entry point for sending reminders. It queries games scheduled within the specified time window and dispatches the appropriate reminder logic based on the notification type.

## Private Methods

### `sendPerGameReminders(List<Game> games, NotificationType type)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to send reminders for. |
| `type` | `NotificationType` | The type of reminder (typically 1-day reminder). |

**Returns:** `int` - Number of notifications sent.

**Description:**  
Iterates over each game and sends a reminder to all active participants and the organizer. Skips recipients who already have a notification for the same game and type.

### `sendAggregatedThreeDayReminders(List<Game> games)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to aggregate reminders for. |

**Returns:** `int` - Number of notifications sent.

**Description:**  
Groups games by recipient and date, then sends a single aggregated notification per recipient per date summarizing the number of courts booked. Uses a deterministic UUID based on the notification type and date to prevent duplicate notifications.

### `deliverExternally(Notification notification, EmailContext emailContext)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `notification` | `Notification` | The notification to deliver. |
| `emailContext` | `EmailContext` | Context data for email delivery. |

**Description:**  
Attempts to send a push notification first. If push delivery fails (returns anything other than `SENT`), falls back to sending an email if the recipient has a valid email address.

### `recipientIdsFor(Game game)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to find recipients for. |

**Returns:** `Set<UUID>` - Set of recipient user IDs.

**Description:**  
Collects the IDs of the game organizer and all active participants.

### `localDateFor(Game game)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to extract the date from. |

**Returns:** `LocalDate` - The game's start date in Singapore Time (SGT).

### `dateResourceId(NotificationType type, LocalDate date)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The notification type. |
| `date` | `LocalDate` | The date to generate the resource ID for. |

**Returns:** `UUID` - A deterministic UUID based on the type and date.

### `courtLabel(int count)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `count` | `int` | Number of courts. |

**Returns:** `String` - "court" if count is 1, otherwise "courts".

### `formatDate(LocalDate date)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `date` | `LocalDate` | The date to format. |

**Returns:** `String` - Formatted date string (e.g., "15-Mar").
