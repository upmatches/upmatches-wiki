# SendGameRemindersService

## Purpose

The `SendGameRemindersService` is a Spring service responsible for sending game reminders to users. It handles two types of reminders:

- **3-day reminders**: Aggregated notifications sent 3 days before a game, grouping multiple games on the same date into a single notification.
- **1-day reminders**: Per-game notifications sent 1 day before a game.

The service checks for existing notifications to avoid duplicates, and delivers reminders via push notification or email as a fallback.

## Public Methods

### `execute(NotificationType type, long minHoursAhead, long maxHoursAhead)`

Sends game reminders for games scheduled within a specified time window.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of reminder to send (`GAME_REMINDER_3_DAYS` or `GAME_REMINDER_1_DAY`) |
| `minHoursAhead` | `long` | Minimum hours ahead of the current time to look for games |
| `maxHoursAhead` | `long` | Maximum hours ahead of the current time to look for games |

**Returns:** `int` - The number of notifications sent.

**Behavior:**
- Queries for games starting between `now + minHoursAhead` and `now + maxHoursAhead`.
- If `type` is `GAME_REMINDER_3_DAYS`, sends aggregated reminders grouped by date.
- Otherwise, sends per-game reminders.

## Private Methods

### `sendPerGameReminders(List<Game> games, NotificationType type)`

Sends individual reminders for each game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to send reminders for |
| `type` | `NotificationType` | The type of reminder |

**Returns:** `int` - Number of notifications sent.

### `sendAggregatedThreeDayReminders(List<Game> games)`

Sends aggregated reminders grouped by recipient and date.

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to send reminders for |

**Returns:** `int` - Number of notifications sent.

### `deliverExternally(Notification notification, EmailContext emailContext)`

Delivers a notification externally via push notification or email.

| Parameter | Type | Description |
|-----------|------|-------------|
| `notification` | `Notification` | The notification to deliver |
| `emailContext` | `EmailContext` | Context for email delivery |

**Behavior:**
- Attempts push notification first.
- Falls back to email if push fails and recipient has an email address.

### `recipientIdsFor(Game game)`

Gets the set of recipient IDs for a game (organizer + active participants).

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to get recipients for |

**Returns:** `Set<UUID>` - Set of recipient user IDs.

### `localDateFor(Game game)`

Converts a game's start time to a local date in Singapore timezone.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to get the date for |

**Returns:** `LocalDate` - The local date of the game.

### `dateResourceId(NotificationType type, LocalDate date)`

Generates a deterministic UUID for a date-based resource ID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The notification type |
| `date` | `LocalDate` | The date to generate the ID for |

**Returns:** `UUID` - A deterministic UUID based on the type and date.

### `courtLabel(int count)`

Returns the appropriate label for court count (singular/plural).

| Parameter | Type | Description |
|-----------|------|-------------|
| `count` | `int` | Number of courts |

**Returns:** `String` - "court" if count is 1, "courts" otherwise.

### `formatDate(LocalDate date)`

Formats a date for display (e.g., "15-Mar").

| Parameter | Type | Description |
|-----------|------|-------------|
| `date` | `LocalDate` | The date to format |

**Returns:** `String` - Formatted date string.

## Usage Example

```java
// Send 3-day reminders for games starting between 71 and 73 hours from now
int sent = sendGameRemindersService.execute(
    NotificationType.GAME_REMINDER_3_DAYS,
    71,
    73
);

// Send 1-day reminders for games starting between 23 and 25 hours from now
int sent = sendGameRemindersService.execute(
    NotificationType.GAME_REMINDER_1_DAY,
    23,
    25
);
```
