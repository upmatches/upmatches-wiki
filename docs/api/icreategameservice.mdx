# ICreateGameService Interface

The `ICreateGameService` interface defines the contract for creating a new game within the UpMatches application. It follows a command pattern, encapsulating the creation logic behind a single `execute` method. This interface is sealed, meaning only the explicitly permitted implementation (`CreateGameService`) can implement it, ensuring controlled extensibility and a clear, bounded domain.

## Interface Definition

```java
public sealed interface ICreateGameService permits CreateGameService {

    GameResponse execute(CreateGameRequest request);

}
```

## Methods

| Method | Description | Parameters | Returns |
| :----- | :---------- | :--------- | :------ |
| `execute` | Executes the game creation process based on the provided request data. | `CreateGameRequest request` – The request object containing all necessary information to create a new game. | `GameResponse` – The response object containing the result of the game creation operation (e.g., the created game details or confirmation). |

## Usage Example

```java
// Assuming you have an instance of ICreateGameService (e.g., CreateGameService)
ICreateGameService gameService = new CreateGameService();

// Create a request with the required game data
CreateGameRequest request = new CreateGameRequest(/* ... */);

// Execute the game creation
GameResponse response = gameService.execute(request);

// Use the response (e.g., display success message, navigate to new game)
```

## Related Components

- **`CreateGameRequest`**: The input data transfer object (DTO) that carries the game creation parameters.
- **`GameResponse`**: The output DTO that encapsulates the result of the game creation.
- **`CreateGameService`**: The sole permitted implementation of this sealed interface, containing the actual business logic for creating a game.
