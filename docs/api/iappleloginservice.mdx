# IAppleLoginService Interface

The `IAppleLoginService` interface defines the contract for Apple Sign-In authentication within the UpMatches application. It serves as the abstraction layer for processing Apple login requests, ensuring a standardized implementation across the authentication module.

This sealed interface permits only the `AppleLoginService` class to implement it, enforcing a controlled and secure extension model for Apple authentication logic.

## Interface Definition

```java
public sealed interface IAppleLoginService permits AppleLoginService {
    AppleLoginResponse execute(AppleLoginRequest request);
}
```

## Methods

### `execute`

Processes an Apple login request and returns the corresponding authentication response.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AppleLoginRequest` | The request object containing Apple Sign-In credentials and metadata |

| Returns | Description |
|---------|-------------|
| `AppleLoginResponse` | The response object containing authentication result and user data |

## Usage Example

```java
// Inject the service
private final IAppleLoginService appleLoginService;

// Execute Apple login
AppleLoginRequest request = new AppleLoginRequest(/* parameters */);
AppleLoginResponse response = appleLoginService.execute(request);
```

## Related Components

- **`AppleLoginRequest`**: Input data transfer object containing Apple authorization code, identity token, and user information
- **`AppleLoginResponse`**: Output data transfer object containing authentication tokens, user profile data, and session information
- **`AppleLoginService`**: The concrete implementation class that handles the actual Apple Sign-In business logic

## Security Considerations

- The sealed interface pattern ensures that only the designated `AppleLoginService` can implement this contract
- All implementations must handle Apple's authentication tokens securely
- The interface enforces a consistent method signature for processing Apple login requests across the application
