# IAppleLoginService Interface

## Purpose

The `IAppleLoginService` interface defines the contract for handling Apple Sign-In authentication within the UpMatches application. It serves as the abstraction layer for Apple login functionality, allowing for a clean separation between the interface definition and its implementation (`AppleLoginService`). This sealed interface ensures that only the designated implementation class can extend it, providing controlled extensibility and enhanced security.

## Interface Definition

```java
public sealed interface IAppleLoginService permits AppleLoginService {
    AppleLoginResponse execute(AppleLoginRequest request);
}
```

## Methods

### `execute`

| Property | Description |
|----------|-------------|
| **Signature** | `AppleLoginResponse execute(AppleLoginRequest request)` |
| **Purpose** | Processes an Apple Sign-In authentication request and returns the corresponding response |
| **Parameters** | `request` - An `AppleLoginRequest` object containing the necessary authentication data from Apple Sign-In |
| **Returns** | `AppleLoginResponse` - The response object containing the authentication result and user information |
| **Throws** | Implementation-specific exceptions may be thrown (e.g., authentication failures, network errors) |

## Usage Example

```java
// Inject the service (typically via dependency injection)
private final IAppleLoginService appleLoginService;

// Create a login request
AppleLoginRequest request = new AppleLoginRequest(/* authorization code, identity token, etc. */);

// Execute the login
AppleLoginResponse response = appleLoginService.execute(request);
```

## Implementation Details

The interface is declared as `sealed`, meaning only the class `AppleLoginService` is permitted to implement it. This design pattern provides:

- **Controlled inheritance**: Only the specified implementation can extend this interface
- **Enhanced security**: Prevents unauthorized implementations
- **Clear contract**: Defines a single, well-defined authentication method
- **Testability**: Allows for easy mocking in unit tests

## Related Components

- **`AppleLoginRequest`**: The input data transfer object containing Apple Sign-In credentials
- **`AppleLoginResponse`**: The output data transfer object containing authentication results
- **`AppleLoginService`**: The concrete implementation of this interface
