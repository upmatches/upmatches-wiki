## Purpose

The `IAppleLoginService` interface is part of the authentication services within the `com.upmatches.app.features.auth.services` package. It defines a contract for implementing Apple login functionality. This interface is sealed, meaning it restricts which classes can implement it, specifically permitting the `AppleLoginService` class.

## Public Methods

The `IAppleLoginService` interface declares the following public method:

| Method Signature | Description |
|------------------|-------------|
| `AppleLoginResponse execute(AppleLoginRequest request)` | Executes the Apple login process using the provided `AppleLoginRequest` and returns an `AppleLoginResponse`. |

### Method Details

#### `execute`

- **Parameters:**

  | Name    | Type                                | Description                              |
  |---------|-------------------------------------|------------------------------------------|
  | request | `AppleLoginRequest`                 | The request object containing necessary data for Apple login. |

- **Returns:**

  | Type                  | Description                              |
  |-----------------------|------------------------------------------|
  | `AppleLoginResponse`  | The response object containing the result of the Apple login process. |
