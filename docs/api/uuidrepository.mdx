# UuidRepository

The `UuidRepository` interface is a custom Spring Data JPA repository base interface that provides UUID-based lookup functionality for entities. It extends `JpaRepository` and adds a method to find entities by their UUID field, while being annotated with `@NoRepositoryBean` to prevent Spring from creating a bean for this interface directly.

## Purpose

This interface serves as a reusable base repository for entities that have a UUID field. By extending `UuidRepository` instead of `JpaRepository`, you automatically gain the ability to look up entities by their UUID without having to declare the method in each entity-specific repository.

## Key Features

- **UUID-based lookup**: Provides a `findByUuid` method for querying entities by their UUID
- **Standard CRUD operations**: Inherits all standard JPA repository methods from `JpaRepository`
- **Type safety**: Uses generics to work with any entity type
- **No direct instantiation**: Marked with `@NoRepositoryBean` to prevent Spring from creating a repository bean for this interface

## Interface Definition

```java
@NoRepositoryBean
public interface UuidRepository<T> extends JpaRepository<T, Long> {
    Optional<T> findByUuid(UUID uuid);
}
```

## Methods

### Inherited from JpaRepository

The interface inherits all standard CRUD and pagination methods from `JpaRepository<T, Long>`, including:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all entities |
| `findById(Long id)` | Finds an entity by its primary key |
| `save(T entity)` | Saves a given entity |
| `delete(T entity)` | Deletes a given entity |
| `deleteById(Long id)` | Deletes an entity by its ID |
| `count()` | Returns the number of entities |

### Custom Method

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findByUuid(UUID uuid)` | `Optional<T>` | `uuid` - The UUID to search for | Finds an entity by its UUID field. Returns an `Optional` that contains the entity if found, or empty if not found. |

## Usage Example

To use this repository, create a specific repository interface for your entity:

```java
public interface UserRepository extends UuidRepository<User> {
    // Additional custom methods can be added here
}
```

Then inject and use it in your service:

```java
@Service
public class UserService {
    private final UserRepository userRepository;
    
    public UserService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }
    
    public Optional<User> findByUuid(UUID uuid) {
        return userRepository.findByUuid(uuid);
    }
}
```

## Requirements

- Your entity class must have a `UUID` field named `uuid` (or you can customize the query method name if using Spring Data JPA's query derivation)
- The entity's primary key must be of type `Long` (as specified in `JpaRepository<T, Long>`)

## Notes

- The `@NoRepositoryBean` annotation is essential to prevent Spring Data JPA from creating a bean for this interface at runtime
- This interface is designed to be extended by entity-specific repository interfaces
- The `findByUuid` method leverages Spring Data JPA's query derivation mechanism
