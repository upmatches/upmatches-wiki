# UuidRepository

The `UuidRepository` interface is a custom base repository interface designed to provide UUID-based lookup functionality for JPA entities. It extends `JpaRepository<T, Long>` and introduces a method to find entities by their UUID field, while preventing Spring Data JPA from creating a bean instance for this interface itself (using `@NoRepositoryBean`).

## Purpose

This interface serves as a reusable foundation for entity repositories that need to support both standard primary key (Long) lookups and UUID-based lookups. By extending `JpaRepository`, it inherits all standard CRUD operations, pagination, and sorting capabilities. The addition of `findByUuid` allows developers to query entities using a universally unique identifier, which is useful for distributed systems, public-facing APIs, or scenarios where exposing sequential numeric IDs is undesirable.

## Interface Definition

```java
@NoRepositoryBean
public interface UuidRepository<T> extends JpaRepository<T, Long> {
    Optional<T> findByUuid(UUID uuid);
}
```

### Key Characteristics

- **Generic Type**: `T` represents the entity type managed by the repository.
- **Primary Key Type**: `Long` is used as the primary key type (inherited from `JpaRepository`).
- **No Repository Bean**: The `@NoRepositoryBean` annotation prevents Spring Data JPA from creating a bean for this interface. Concrete repository interfaces should extend this interface instead.
- **UUID Lookup**: The `findByUuid` method enables querying entities by their UUID field.

## Methods

### Inherited Methods from `JpaRepository<T, Long>`

The interface inherits all standard methods from `JpaRepository`, including but not limited to:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all entities |
| `findById(Long id)` | Finds an entity by its primary key |
| `save(T entity)` | Saves a given entity |
| `deleteById(Long id)` | Deletes an entity by its primary key |
| `count()` | Returns the number of entities |

### Custom Method

| Method | Return Type | Description |
|--------|-------------|-------------|
| `findByUuid(UUID uuid)` | `Optional<T>` | Finds an entity by its UUID field. Returns an `Optional` that contains the entity if found, or empty if no entity matches the given UUID. |

## Usage Example

To use this repository, create a concrete repository interface that extends `UuidRepository`:

```java
public interface UserRepository extends UuidRepository<User> {
    // Additional custom query methods can be added here
}
```

The entity class should have a UUID field:

```java
@Entity
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(unique = true, nullable = false)
    private UUID uuid;
    
    // Other fields, constructors, getters, and setters
}
```

## Notes

- The entity class must have a field named `uuid` of type `UUID` for the `findByUuid` method to work correctly with Spring Data JPA's query derivation.
- Consider adding a unique constraint on the UUID column in the database to ensure data integrity.
- This pattern is particularly useful when you need to expose entity identifiers in URLs or APIs without revealing sequential database IDs.
