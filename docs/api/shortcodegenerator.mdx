# ShortCodeGenerator

The `ShortCodeGenerator` class provides a utility for generating cryptographically secure, random alphanumeric short codes. It is designed for use cases such as creating unique shareable links, referral codes, or short identifiers.

## Overview

This class uses `SecureRandom` to produce unpredictable codes, making it suitable for security-sensitive applications. The generated codes are 8 characters long and consist of uppercase letters, lowercase letters, and digits (62 possible characters per position).

## Features

- **Cryptographically Secure**: Uses `java.security.SecureRandom` for random number generation.
- **Configurable Length**: The code length is set to 8 characters (modifiable via the `CODE_LENGTH` constant).
- **Thread-Safe**: The `SecureRandom` instance is thread-safe, and the `generate()` method can be called concurrently.
- **Utility Class**: The constructor is private, preventing instantiation. All functionality is accessed via the static `generate()` method.

## Public API

### `generate()`

Generates a new random short code.

| Return Type | Description |
|-------------|-------------|
| `String`    | An 8-character alphanumeric code (e.g., `"a3X9kL2p"`) |

**Example Usage:**

```java
String code = ShortCodeGenerator.generate();
System.out.println(code); // Example output: "7Bf2Qw9z"
```

## Implementation Details

- **Character Set**: The alphabet includes digits (0-9), uppercase letters (A-Z), and lowercase letters (a-z), providing 62 possible characters per position.
- **Code Length**: The constant `CODE_LENGTH` is set to 8, resulting in 62^8 ≈ 218 trillion possible combinations.
- **Randomness**: `SecureRandom` is used instead of `java.util.Random` to ensure cryptographic strength and unpredictability.

## Security Considerations

- The generated codes are suitable for use in URLs, referral systems, and temporary access tokens.
- For production use, consider adding collision detection or database uniqueness constraints if codes must be globally unique.
- The 8-character length provides a good balance between uniqueness and usability, but you may adjust `CODE_LENGTH` for different security requirements.

## Dependencies

- `java.security.SecureRandom` (standard Java library)
