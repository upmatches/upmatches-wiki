# GameResponse

The `GameResponse` record is a Data Transfer Object (DTO) used to represent a game's full details in API responses. It encapsulates all relevant information about a game, including its activity, organizer, venue, skill levels, pricing, and viewer-specific context.

## Purpose

This record serves as the primary response object for game-related API endpoints. It provides multiple factory methods to construct instances with varying levels of detail, supporting different use cases such as:

- **Standard game listing** with full details
- **Viewer-specific responses** that include whether the current user is the organizer
- **Anonymous responses** that omit organizer and pricing information for privacy

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique identifier for the game |
| `activity` | `ActivitySummary` | Summary of the associated activity |
| `organizer` | `OrganizerSummary` | Summary of the game organizer |
| `venue` | `VenueSummary` | Summary of the game venue |
| `skillLevel` | `SkillLevelRange` | Range of skill levels for the game |
| `currency` | `String` | Currency code for pricing |
| `price` | `BigDecimal` | Price of the game |
| `pricing` | `PricingResponse` | Detailed pricing information |
| `slots` | `Integer` | Total number of slots available |
| `numberOfPlayerJoined` | `Long` | Number of players who have joined |
| `startTime` | `Instant` | Game start time |
| `endTime` | `Instant` | Game end time |
| `visibility` | `GameVisibility` | Visibility setting of the game |
| `gameType` | `GameType` | Type of game |
| `status` | `GameStatus` | Current status of the game |
| `remark` | `String` | Additional remarks or notes |
| `shareLink` | `ShareLinkResponse` | Share link information |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer's joinability status |
| `viewerIsOrganizer` | `Boolean` | Whether the viewer is the organizer |
| `createdAt` | `Instant` | Timestamp when the game was created |
| `updatedAt` | `Instant` | Timestamp when the game was last updated |

## Factory Methods

### `fromGame(Game game, long participantCount, ShareLinkResponse shareLink, ViewerJoinabilityResponse viewerJoinability, Boolean viewerIsOrganizer)`

Creates a full `GameResponse` with all available information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer's joinability status |
| `viewerIsOrganizer` | `Boolean` | Whether the viewer is the organizer |

**Returns:** `GameResponse` - A fully populated response object.

### `fromGame(Game game, long participantCount, ShareLinkResponse shareLink, ViewerJoinabilityResponse viewerJoinability)`

Creates a `GameResponse` without specifying whether the viewer is the organizer.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer's joinability status |

**Returns:** `GameResponse` - A response object with `viewerIsOrganizer` set to `null`.

### `fromGame(Game game, long participantCount, ShareLinkResponse shareLink)`

Creates a `GameResponse` with share link but without viewer-specific information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |

**Returns:** `GameResponse` - A response object with `viewerJoinability` and `viewerIsOrganizer` set to `null`.

### `fromGame(Game game, long participantCount, ViewerJoinabilityResponse viewerJoinability)`

Creates a `GameResponse` with viewer joinability but without share link.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer's joinability status |

**Returns:** `GameResponse` - A response object with `shareLink` and `viewerIsOrganizer` set to `null`.

### `fromGame(Game game, long participantCount)`

Creates a basic `GameResponse` without any viewer-specific or share link information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |

**Returns:** `GameResponse` - A response object with `shareLink`, `viewerJoinability`, and `viewerIsOrganizer` set to `null`.

### `fromGameForViewer(Game game, long participantCount, ViewerJoinabilityResponse viewerJoinability, UUID viewerUserId)`

Creates a `GameResponse` tailored for a specific viewer, including joinability and organizer status.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer's joinability status |
| `viewerUserId` | `UUID` | ID of the viewer user |

**Returns:** `GameResponse` - A response object with viewer-specific information.

### `fromGameForViewer(Game game, long participantCount, ShareLinkResponse shareLink, UUID viewerUserId)`

Creates a `GameResponse` for a viewer with share link information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |
| `viewerUserId` | `UUID` | ID of the viewer user |

**Returns:** `GameResponse` - A response object with share link and viewer organizer status.

### `fromGameForViewer(Game game, long participantCount, UUID viewerUserId)`

Creates a basic viewer-specific `GameResponse` without share link or joinability information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `viewerUserId` | `UUID` | ID of the viewer user |

**Returns:** `GameResponse` - A response object with only viewer organizer status.

### `fromGameAnonymous(Game game, long participantCount)`

Creates an anonymous `GameResponse` that omits organizer and pricing information for privacy.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |

**Returns:** `GameResponse` - A response object with `organizer`, `currency`, `price`, `pricing`, `shareLink`, `viewerJoinability`, and `viewerIsOrganizer` set to `null`.

## Private Helper Methods

### `isViewerOrganizer(Game game, UUID viewerUserId)`

Determines if the viewer is the organizer of the game.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity |
| `viewerUserId` | `UUID` | ID of the viewer user |

**Returns:** `Boolean` - `true` if the viewer is the organizer, `false` otherwise, or `null` if `viewerUserId` is `null`.

### `contactMethodsFor(User user)`

Extracts available contact methods from a user entity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user entity |

**Returns:** `List<ContactMethod>` - A list of available contact methods (WhatsApp, Telegram, Messenger).

### `safeOrganizerName(Game game)`

Returns the organizer's name, falling back to "Anonymous" if the name is missing or blank.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity |

**Returns:** `String` - The organizer's name or "Anonymous".
