# GameResponse

The `GameResponse` class is a Java record that serves as the API response model for game-related endpoints in the UpMatches application. It encapsulates all relevant information about a game, including activity details, organizer information, venue data, skill levels, pricing, and viewer-specific context.

## Purpose

This record provides a standardized, immutable data structure for returning game information from the backend API. It includes multiple factory methods (`fromGame` and `fromGameForViewer`) to construct responses with varying levels of detail depending on the context (e.g., anonymous users, authenticated viewers, or general listing).

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique identifier for the game |
| `activity` | `ActivitySummary` | Summary of the activity associated with the game |
| `organizer` | `OrganizerSummary` | Summary of the game organizer (can be `null` for anonymous responses) |
| `venue` | `VenueSummary` | Summary of the venue where the game takes place |
| `skillLevel` | `SkillLevelRange` | Range of skill levels (from/to) for the game |
| `currency` | `String` | Currency code for pricing (can be `null`) |
| `price` | `BigDecimal` | Price of the game (can be `null`) |
| `pricing` | `PricingResponse` | Detailed pricing information (can be `null`) |
| `slots` | `Integer` | Total number of slots available |
| `numberOfPlayerJoined` | `Long` | Number of players who have joined |
| `startTime` | `Instant` | Start time of the game |
| `endTime` | `Instant` | End time of the game |
| `visibility` | `GameVisibility` | Visibility setting of the game |
| `gameType` | `GameType` | Type of game |
| `status` | `GameStatus` | Current status of the game |
| `remark` | `String` | Additional remarks or notes |
| `shareLink` | `ShareLinkResponse` | Share link information (can be `null`) |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Joinability information for the viewer (can be `null`) |
| `viewerIsOrganizer` | `Boolean` | Whether the viewer is the organizer (can be `null`) |
| `createdAt` | `Instant` | Timestamp when the game was created |
| `updatedAt` | `Instant` | Timestamp when the game was last updated |

### `fromGameForViewer` Factory Methods

These methods create a `GameResponse` specifically for a viewer, automatically determining if the viewer is the organizer.

#### `fromGameForViewer(Game game, long participantCount, ViewerJoinabilityResponse viewerJoinability, UUID viewerUserId)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |

| `viewerUserId` | `UUID` | The viewer's user ID |

## Private Helper Methods

### `isViewerOrganizer(Game game, UUID viewerUserId)`

Determines if the given viewer is the organizer of the game.

**Parameters:**
- `game` - The game entity
- `viewerUserId` - The viewer's user ID (can be `null`)

**Returns:** `Boolean` - `true` if the viewer is the organizer, `false` if not, `null` if `viewerUserId` is `null`.

### `contactMethodsFor(User user)`

Extracts available contact methods from a user entity.

**Parameters:**
- `user` - The user entity

**Returns:** `List<ContactMethod>` - A list of contact methods (WhatsApp, Telegram, Messenger) that are not null or blank.

### `safeOrganizerName(Game game)`

Safely retrieves the organizer's name, falling back to "Anonymous" if the name is missing or blank.

**Parameters:**
- `game` - The game entity

**Returns:** `String` - The organizer's name or "Anonymous".

## Usage Example

```java
// Creating a response for a general listing
GameResponse response = GameResponse.fromGame(game, participantCount);

// Creating a response for a specific viewer
GameResponse viewerResponse = GameResponse.fromGameForViewer(
    game, 
    participantCount, 
    viewerJoinability, 
    viewerUserId
);

// Creating an anonymous response
GameResponse anonymousResponse = GameResponse.fromGameAnonymous(game, participantCount);
```
