## Overview

The `GameResponse` class is a Java record that encapsulates the response details of a game entity. It is part of the `com.upmatches.app.features.game.responses` package and serves as a data transfer object (DTO) for representing game information in a structured format. This class is designed to facilitate the conversion of game-related data into a format suitable for client-side consumption, particularly in scenarios involving user interfaces or API responses.

## Public Methods

The `GameResponse` class provides several static factory methods to create instances of `GameResponse` from a `Game` object. These methods offer flexibility in terms of the data included in the response, such as participant count, share links, and viewer-specific details.

| Method Signature | Description |
|------------------|-------------|
| `fromGame(Game game, long participantCount, ShareLinkResponse shareLink, ViewerJoinabilityResponse viewerJoinability, Boolean viewerIsOrganizer)` | Creates a `GameResponse` from a `Game` object with detailed parameters including share link and viewer joinability. |
| `fromGame(Game game, long participantCount, ShareLinkResponse shareLink, ViewerJoinabilityResponse viewerJoinability)` | Creates a `GameResponse` from a `Game` object without specifying if the viewer is the organizer. |
| `fromGame(Game game, long participantCount, ShareLinkResponse shareLink)` | Creates a `GameResponse` from a `Game` object with a share link but without viewer joinability. |
| `fromGame(Game game, long participantCount, ViewerJoinabilityResponse viewerJoinability)` | Creates a `GameResponse` from a `Game` object with viewer joinability but without a share link. |
| `fromGame(Game game, long participantCount)` | Creates a basic `GameResponse` from a `Game` object with only participant count. |
| `fromGameForViewer(Game game, long participantCount, ViewerJoinabilityResponse viewerJoinability, UUID viewerUserId)` | Creates a `GameResponse` for a viewer, determining if the viewer is the organizer. |
| `fromGameForViewer(Game game, long participantCount, ShareLinkResponse shareLink, UUID viewerUserId)` | Creates a `GameResponse` for a viewer with a share link, determining if the viewer is the organizer. |
| `fromGameForViewer(Game game, long participantCount, UUID viewerUserId)` | Creates a `GameResponse` for a viewer, determining if the viewer is the organizer without additional details. |
| `fromGameAnonymous(Game game, long participantCount)` | Creates an anonymous `GameResponse` without organizer details. |
