# GameResponse

The `GameResponse` record is a Data Transfer Object (DTO) used to represent a game's full details in API responses. It encapsulates all relevant information about a game, including activity, organizer, venue, skill levels, pricing, and viewer-specific context.

## Purpose

This record serves as the primary response object for game-related endpoints. It provides multiple factory methods to create instances with varying levels of detail, supporting different use cases such as:

- Full game details for authenticated users
- Anonymous game details (without organizer or pricing information)
- Viewer-specific responses that indicate whether the current user is the organizer

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique identifier for the game |
| `activity` | `ActivitySummary` | Summary of the associated activity |
| `organizer` | `OrganizerSummary` | Summary of the game organizer (can be `null` for anonymous responses) |
| `venue` | `VenueSummary` | Summary of the venue location |
| `skillLevel` | `SkillLevelRange` | Range of skill levels for the game |
| `currency` | `String` | Currency code for pricing (can be `null`) |
| `price` | `BigDecimal` | Price of the game (can be `null`) |
| `pricing` | `PricingResponse` | Detailed pricing information (can be `null`) |
| `slots` | `Integer` | Total number of available slots |
| `numberOfPlayerJoined` | `Long` | Number of players who have joined |
| `startTime` | `Instant` | Start time of the game |
| `endTime` | `Instant` | End time of the game |
| `visibility` | `GameVisibility` | Visibility setting of the game |
| `gameType` | `GameType` | Type of game |
| `status` | `GameStatus` | Current status of the game |
| `remark` | `String` | Additional remarks or notes |
| `shareLink` | `ShareLinkResponse` | Share link information (can be `null`) |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Joinability information for the viewer (can be `null`) |
| `viewerIsOrganizer` | `Boolean` | Whether the viewer is the organizer (can be `null`) |
| `createdAt` | `Instant` | Timestamp when the game was created |
| `updatedAt` | `Instant` | Timestamp when the game was last updated |

## Factory Methods

### `fromGame(Game game, long participantCount, ShareLinkResponse shareLink, ViewerJoinabilityResponse viewerJoinability, Boolean viewerIsOrganizer)`

Creates a full `GameResponse` from a `Game` entity with all optional parameters.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer joinability information |
| `viewerIsOrganizer` | `Boolean` | Whether the viewer is the organizer |

**Returns:** `GameResponse` - A complete game response with all fields populated.

### `fromGame(Game game, long participantCount, ShareLinkResponse shareLink, ViewerJoinabilityResponse viewerJoinability)`

Creates a `GameResponse` without specifying `viewerIsOrganizer` (defaults to `null`).

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer joinability information |

**Returns:** `GameResponse` - A game response with `viewerIsOrganizer` set to `null`.

### `fromGame(Game game, long participantCount, ShareLinkResponse shareLink)`

Creates a `GameResponse` with only share link information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |

**Returns:** `GameResponse` - A game response with share link but without viewer-specific information.

### `fromGame(Game game, long participantCount, ViewerJoinabilityResponse viewerJoinability)`

Creates a `GameResponse` with only viewer joinability information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer joinability information |

**Returns:** `GameResponse` - A game response with viewer joinability but without share link.

### `fromGame(Game game, long participantCount)`

Creates a basic `GameResponse` without any viewer-specific or share link information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |

**Returns:** `GameResponse` - A basic game response without optional fields.

### `fromGameForViewer(Game game, long participantCount, ViewerJoinabilityResponse viewerJoinability, UUID viewerUserId)`

Creates a `GameResponse` tailored for a specific viewer, including joinability information and whether the viewer is the organizer.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `viewerJoinability` | `ViewerJoinabilityResponse` | Viewer joinability information |
| `viewerUserId` | `UUID` | The viewer's user ID |

**Returns:** `GameResponse` - A viewer-specific game response.

### `fromGameForViewer(Game game, long participantCount, ShareLinkResponse shareLink, UUID viewerUserId)`

Creates a `GameResponse` for a viewer with share link information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `shareLink` | `ShareLinkResponse` | Share link information |
| `viewerUserId` | `UUID` | The viewer's user ID |

**Returns:** `GameResponse` - A viewer-specific game response with share link.

### `fromGameForViewer(Game game, long participantCount, UUID viewerUserId)`

Creates a basic viewer-specific `GameResponse`.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |
| `viewerUserId` | `UUID` | The viewer's user ID |

**Returns:** `GameResponse` - A basic viewer-specific game response.

### `fromGameAnonymous(Game game, long participantCount)`

Creates an anonymous `GameResponse` that excludes organizer, pricing, and viewer-specific information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert |
| `participantCount` | `long` | Number of participants |

**Returns:** `GameResponse` - An anonymous game response with limited information.

## Private Helper Methods

### `isViewerOrganizer(Game game, UUID viewerUserId)`

Determines if the viewer is the organizer of the game.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity |
| `viewerUserId` | `UUID` | The viewer's user ID |

**Returns:** `Boolean` - `true` if the viewer is the organizer, `false` otherwise, or `null` if `viewerUserId` is `null`.

### `contactMethodsFor(User user)`

Extracts available contact methods from a user entity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user entity |

**Returns:** `List<ContactMethod>` - A list of available contact methods (WhatsApp, Telegram, Messenger).

### `safeOrganizerName(Game game)`

Returns the organizer's name, defaulting to "Anonymous" if the name is missing or blank.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity |

**Returns:** `String` - The organizer's name or "Anonymous".
