## Purpose

The `Auth0Properties` class is a configuration properties holder for Auth0 authentication settings in a Spring Boot application. It is designed to map properties prefixed with `app.auth0` from the application's configuration files (e.g., `application.yml` or `application.properties`) to a structured Java object. This class is implemented as a Java record, providing an immutable data structure with built-in methods for accessing its fields.

## Public Methods

The `Auth0Properties` class does not explicitly define public methods beyond those automatically provided by the Java record. However, it includes a custom constructor logic to ensure default values for certain fields. Below is a summary of the fields and their initialization logic:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `Auth0Properties` | `String domain`, `String clientId`, `String clientSecret`, `String redirectUri`, `String scopes` | `Auth0Properties` | Constructs an instance of `Auth0Properties`. If the `scopes` parameter is `null` or blank, it defaults to `"openid profile email"`. |

## Fields

The `Auth0Properties` record includes the following fields:

- **domain**: The domain of the Auth0 tenant.
- **clientId**: The client ID for the Auth0 application.
- **clientSecret**: The client secret for the Auth0 application.
- **redirectUri**: The URI to which Auth0 will redirect after authentication.
- **scopes**: The scopes requested during authentication. Defaults to `"openid profile email"` if not provided.
