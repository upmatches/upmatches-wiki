# Auth0Properties

The `Auth0Properties` class is a Spring Boot configuration properties record that maps to the `app.auth0` prefix in your application's configuration files (e.g., `application.yml` or `application.properties`). It encapsulates all the necessary Auth0 authentication settings, including domain, client credentials, redirect URI, and OAuth scopes.

## Purpose

This class serves as a centralized, type-safe configuration holder for Auth0 integration. By using Spring Boot's `@ConfigurationProperties` annotation, it automatically binds properties from your configuration files to this record, making it easy to inject Auth0 settings into other components of your application.

## Configuration Properties

The following table describes the configuration properties that can be set under the `app.auth0` prefix:

| Property | Type | Description | Default Value |
|----------|------|-------------|---------------|
| `app.auth0.domain` | `String` | The Auth0 tenant domain (e.g., `your-tenant.auth0.com`) | Required |
| `app.auth0.client-id` | `String` | The Auth0 application client ID | Required |
| `app.auth0.client-secret` | `String` | The Auth0 application client secret | Required |
| `app.auth0.redirect-uri` | `String` | The callback URL after authentication | Required |
| `app.auth0.scopes` | `String` | Space-separated list of OAuth scopes | `"openid profile email"` |

## Constructor Behavior

The compact constructor of this record provides default value handling for the `scopes` field:

- If `scopes` is `null` or blank (empty or whitespace-only), it defaults to `"openid profile email"`
- This ensures that even if the configuration doesn't specify scopes, the application will have reasonable defaults for basic authentication

## Usage Example

To use this configuration class in your Spring Boot application:

1. **Enable configuration properties** in your main application class or a configuration class:

```java
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Configuration;

@Configuration
@EnableConfigurationProperties(Auth0Properties.class)
public class Auth0Config {
}
```

2. **Configure properties** in `application.yml`:

```yaml
app:
  auth0:
    domain: your-tenant.auth0.com
    client-id: your-client-id
    client-secret: your-client-secret
    redirect-uri: http://localhost:8080/callback
    scopes: openid profile email
```

3. **Inject and use** the properties in your services:

```java
import org.springframework.stereotype.Service;

@Service
public class Auth0Service {
    private final Auth0Properties auth0Properties;

    public Auth0Service(Auth0Properties auth0Properties) {
        this.auth0Properties = auth0Properties;
    }

    public String getAuthorizationUrl() {
        return String.format(
            "https://%s/authorize?response_type=code&client_id=%s&redirect_uri=%s&scope=%s",
            auth0Properties.domain(),
            auth0Properties.clientId(),
            auth0Properties.redirectUri(),
            auth0Properties.scopes()
        );
    }
}
```

## Notes

- The `scopes` property defaults to `"openid profile email"` if not explicitly configured, which is sufficient for basic user authentication and profile retrieval
- All other properties (`domain`, `clientId`, `clientSecret`, `redirectUri`) are required and must be provided in your configuration
- The class uses Java records (introduced in Java 14+), providing immutable, concise data carriers with automatically generated accessor methods
