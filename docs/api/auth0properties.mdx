# Auth0Properties

The `Auth0Properties` class is a Spring Boot configuration properties record that maps Auth0 OAuth2 configuration values from the application's property files (e.g., `application.yml` or `application.properties`). It uses the prefix `app.auth0` to bind external configuration to the record's components.

This record encapsulates all necessary Auth0 settings required for authentication flows, including the domain, client credentials, redirect URI, and requested scopes. It provides a default value for the `scopes` field if none is explicitly configured.

## Configuration Prefix

All properties are prefixed with `app.auth0`. For example, in `application.yml`:

```yaml
app:
  auth0:
    domain: your-domain.auth0.com
    client-id: your-client-id
    client-secret: your-client-secret
    redirect-uri: http://localhost:8080/callback
    scopes: openid profile email
```

## Constructor Behavior

The compact constructor validates and normalizes the `scopes` parameter. If `scopes` is `null` or blank, it defaults to `"openid profile email"`. This ensures that the application always has a valid set of scopes for authentication requests.

## Public API

### Record Components

| Component      | Type     | Description                                                                 |
|----------------|----------|-----------------------------------------------------------------------------|
| `domain`       | `String` | The Auth0 tenant domain (e.g., `your-tenant.auth0.com`).                    |
| `clientId`     | `String` | The Auth0 application client ID.                                            |
| `clientSecret` | `String` | The Auth0 application client secret.                                        |
| `redirectUri`  | `String` | The URI to redirect users to after authentication (e.g., `/callback`).      |
| `scopes`       | `String` | Space-separated list of OAuth2 scopes. Defaults to `"openid profile email"`.|

### Methods

Since this is a Java record, the following methods are automatically generated by the compiler:

| Method             | Return Type | Description                                      |
|--------------------|-------------|--------------------------------------------------|
| `domain()`         | `String`    | Returns the Auth0 domain.                        |
| `clientId()`       | `String`    | Returns the Auth0 client ID.                     |
| `clientSecret()`   | `String`    | Returns the Auth0 client secret.                 |
| `redirectUri()`    | `String`    | Returns the redirect URI.                        |
| `scopes()`         | `String`    | Returns the OAuth2 scopes (never null or blank). |
| `toString()`       | `String`    | Returns a string representation of the record.   |
| `equals(Object)`   | `boolean`   | Compares this record to another object.          |
| `hashCode()`       | `int`       | Returns a hash code for this record.             |

## Usage Example

```java
@Configuration
@EnableConfigurationProperties(Auth0Properties.class)
public class Auth0Config {

    private final Auth0Properties auth0Properties;

    public Auth0Config(Auth0Properties auth0Properties) {
        this.auth0Properties = auth0Properties;
    }

    public void printConfig() {
        System.out.println("Domain: " + auth0Properties.domain());
        System.out.println("Client ID: " + auth0Properties.clientId());
        System.out.println("Scopes: " + auth0Properties.scopes());
    }
}
```

## Notes

- The `@ConfigurationProperties` annotation with `prefix = "app.auth0"` enables automatic binding of properties from the application's configuration sources.
- The record is immutable by design, ensuring thread safety and consistency.
- The default scopes (`openid profile email`) are commonly required for basic OpenID Connect authentication flows.
