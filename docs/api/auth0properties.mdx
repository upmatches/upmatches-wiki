# Auth0Properties

The `Auth0Properties` class is a Spring Boot configuration properties record that maps Auth0 OAuth2 configuration values from the application's property files (e.g., `application.yml` or `application.properties`). It centralizes all Auth0-related settings under the `app.auth0` prefix, providing a type-safe and immutable way to access these values throughout the application.

## Purpose

This class serves as a configuration holder for Auth0 authentication parameters. By using Spring Boot's `@ConfigurationProperties` annotation, it automatically binds properties from the application configuration to the record's components. The record's compact constructor ensures that if no custom scopes are provided, a default set of scopes (`openid profile email`) is used.

## Configuration Properties

The following table describes the configuration properties that can be set in your application's property files under the `app.auth0` prefix.

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `app.auth0.domain` | `String` | Yes | The Auth0 tenant domain (e.g., `your-tenant.auth0.com`) |
| `app.auth0.client-id` | `String` | Yes | The Auth0 application client ID |
| `app.auth0.client-secret` | `String` | Yes | The Auth0 application client secret |
| `app.auth0.redirect-uri` | `String` | Yes | The callback URL after authentication |
| `app.auth0.scopes` | `String` | No | Space-separated list of OAuth2 scopes. Defaults to `openid profile email` if not provided |

## Constructor Behavior

The compact constructor validates and normalizes the `scopes` parameter:

- If `scopes` is `null` or blank (empty or whitespace-only), it defaults to `"openid profile email"`
- This ensures that the application always has a valid set of scopes for authentication requests

## Usage Example

To use this configuration class, add the following properties to your `application.yml`:

```yaml
app:
  auth0:
    domain: your-tenant.auth0.com
    client-id: your-client-id
    client-secret: your-client-secret
    redirect-uri: http://localhost:8080/callback
    scopes: openid profile email offline_access
```

Then inject the `Auth0Properties` bean into your services:

```java
@Service
public class AuthService {
    private final Auth0Properties auth0Properties;
    
    public AuthService(Auth0Properties auth0Properties) {
        this.auth0Properties = auth0Properties;
    }
    
    public String getAuthorizationUrl() {
        // Use auth0Properties.domain(), auth0Properties.clientId(), etc.
        return String.format("https://%s/authorize?client_id=%s&redirect_uri=%s&scope=%s",
            auth0Properties.domain(),
            auth0Properties.clientId(),
            auth0Properties.redirectUri(),
            auth0Properties.scopes());
    }
}
```

## Important Notes

- The class is a Java `record`, making it immutable and providing automatic `equals()`, `hashCode()`, and `toString()` methods
- Spring Boot's `@ConfigurationProperties` requires the `spring-boot-configuration-processor` dependency for IDE support and metadata generation
- The `@ConfigurationProperties` annotation must be enabled in your Spring Boot application using `@EnableConfigurationProperties(Auth0Properties.class)` or by adding `@ConfigurationPropertiesScan` to your main application class
