import com.upmatches.app.features.game.entities.GameShareAccess;
import org.springframework.data.jpa.repository.JpaRepository;

import java.util.UUID;

## Overview

The `GameShareAccessRepository` interface is a part of the repository layer in a Spring application. It extends the `JpaRepository` interface, providing CRUD operations for the `GameShareAccess` entity. This repository is responsible for handling data access related to game share access records, which are identified by a unique `UUID`.

## Public Methods

The `GameShareAccessRepository` interface includes the following public method:

| Method Signature | Description |
|------------------|-------------|
| `boolean existsByGameIdAndUserId(UUID gameId, UUID userId)` | Checks if a `GameShareAccess` record exists for a given `gameId` and `userId`. |

### Method Details

#### `existsByGameIdAndUserId`

- **Parameters:**

  | Name    | Type   | Description                              |
  |---------|--------|------------------------------------------|
  | gameId  | UUID   | The unique identifier of the game.       |
  | userId  | UUID   | The unique identifier of the user.       |

- **Return Type:** `boolean`

  Returns `true` if a `GameShareAccess` record exists for the specified `gameId` and `userId`, otherwise returns `false`.
