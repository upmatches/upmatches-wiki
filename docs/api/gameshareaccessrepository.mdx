## Purpose of the Class

The `GameShareAccessRepository` interface is a part of the data access layer in a Spring application. It extends the `JpaRepository` interface, which provides CRUD (Create, Read, Update, Delete) operations for the `GameShareAccess` entity. This repository is specifically designed to handle operations related to game sharing access, allowing the application to interact with the underlying database in a seamless manner.

## Public Methods

The `GameShareAccessRepository` interface includes the following public method:

| Method Signature | Description |
|------------------|-------------|
| `boolean existsByGameIdAndUserId(UUID gameId, UUID userId)` | Checks if a `GameShareAccess` entity exists for a given `gameId` and `userId`. |

### Method Details

#### `existsByGameIdAndUserId`

- **Parameters:**

  | Name   | Type   | Description                          |
  |--------|--------|--------------------------------------|
  | gameId | UUID   | The unique identifier of the game.   |
  | userId | UUID   | The unique identifier of the user.   |

- **Return Type:** `boolean`

  Returns `true` if a `GameShareAccess` entity exists for the specified `gameId` and `userId`, otherwise returns `false`. This method is useful for verifying whether a user has access to share a particular game.
