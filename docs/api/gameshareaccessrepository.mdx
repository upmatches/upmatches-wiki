# GameShareAccessRepository

The `GameShareAccessRepository` interface provides database access operations for the `GameShareAccess` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD (Create, Read, Update, Delete) functionality, and includes a custom query method for checking access permissions.

## Purpose

This repository serves as the data access layer for managing game share access records. It enables the application to:
- Perform standard database operations on `GameShareAccess` entities (save, find, delete, etc.)
- Check whether a specific user has access to a particular game

## Inheritance

The interface extends `JpaRepository<GameShareAccess, UUID>`, which provides:
- **Entity type**: `GameShareAccess`
- **Primary key type**: `UUID`

## Custom Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `existsByGameIdAndUserId` | `boolean` | `UUID gameId`, `UUID userId` | Checks if a record exists where a specific user has access to a specific game. Returns `true` if an access record exists, `false` otherwise. |

## Usage Example

```java
@Service
public class GameShareService {
    
    private final GameShareAccessRepository repository;
    
    public GameShareService(GameShareAccessRepository repository) {
        this.repository = repository;
    }
    
    public boolean hasUserAccessToGame(UUID gameId, UUID userId) {
        return repository.existsByGameIdAndUserId(gameId, userId);
    }
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` base interface and query derivation
- **GameShareAccess entity**: The JPA entity this repository manages
- **UUID**: Used as the primary key type for the entity

## Notes

- The custom method `existsByGameIdAndUserId` is automatically implemented by Spring Data JPA through method name convention
- This method is optimized for existence checks and returns a boolean result without loading the full entity
- The repository is typically injected into service classes using constructor injection
