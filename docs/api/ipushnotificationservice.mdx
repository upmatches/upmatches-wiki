# IPushNotificationService

The `IPushNotificationService` is a **sealed interface** that defines the contract for sending push notifications within the UpMatches application. It establishes a single, clear abstraction for push notification delivery, ensuring that only authorized implementations (specifically `PushNotificationService`) can fulfill this contract.

## Purpose

This interface serves as the core abstraction for push notification sending. By using a sealed interface, the design enforces a controlled hierarchy, preventing unauthorized classes from implementing the service and ensuring all push notification logic flows through a single, well-defined channel.

## Interface Definition

```java
public sealed interface IPushNotificationService permits PushNotificationService {
    PushDeliveryResult send(Notification notification);
}
```

## Methods

### `send`

Sends a push notification and returns the result of the delivery attempt.

| Parameter      | Type           | Description                                      |
|----------------|----------------|--------------------------------------------------|
| `notification` | `Notification` | The notification object containing the message details and target recipient(s). |

| Returns              | Description                                      |
|----------------------|--------------------------------------------------|
| `PushDeliveryResult` | An object representing the outcome of the push delivery (e.g., success, failure, or partial delivery). |

## Permitted Implementations

The only class permitted to implement this interface is:

- **`PushNotificationService`** – The concrete implementation responsible for handling the actual push notification delivery logic.

## Usage Example

```java
// Assuming PushNotificationService is injected
IPushNotificationService pushService = new PushNotificationService();

Notification notification = new Notification(/* ... */);
PushDeliveryResult result = pushService.send(notification);

if (result.isSuccess()) {
    // Handle successful delivery
} else {
    // Handle delivery failure
}
```

## Related Components

- **`Notification`** – The entity representing a push notification message.
- **`PushDeliveryResult`** – The model class encapsulating the delivery outcome.
- **`PushNotificationService`** – The sole implementation of this interface.
