# IPushNotificationService Interface

The `IPushNotificationService` interface defines the contract for sending push notifications within the UpMatches application. It serves as the abstraction layer for push notification delivery, allowing different implementations to be swapped without affecting the calling code.

This interface is declared as a **sealed interface**, meaning it restricts which classes or interfaces can implement it. Currently, only `PushNotificationService` is permitted to implement this interface, ensuring controlled extension and maintaining a clear hierarchy.

## Interface Definition

```java
public sealed interface IPushNotificationService permits PushNotificationService {
    PushDeliveryResult send(Notification notification);
}
```

## Methods

| Method | Description | Parameters | Return Type |
|--------|-------------|------------|-------------|
| `send` | Sends a push notification to the intended recipient(s) | `Notification notification` - The notification object containing the message, target device(s), and any additional metadata required for delivery | `PushDeliveryResult` - An object representing the outcome of the delivery attempt, including success/failure status and any relevant error information |

## Usage

The `IPushNotificationService` interface is designed to be injected into components that need to send push notifications. By programming to this interface, the application achieves loose coupling and can easily switch between different push notification providers or delivery strategies.

### Example Implementation

```java
public final class PushNotificationService implements IPushNotificationService {
    @Override
    public PushDeliveryResult send(Notification notification) {
        // Implementation logic for sending push notifications
        // e.g., using Firebase Cloud Messaging, APNs, etc.
    }
}
```

## Related Components

- **Notification** - The entity class representing a push notification with its content and target information
- **PushDeliveryResult** - The model class that encapsulates the result of a push notification delivery attempt
- **PushNotificationService** - The concrete implementation of this interface
