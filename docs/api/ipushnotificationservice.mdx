## Overview

The `IPushNotificationService` interface is part of the `com.upmatches.app.features.notification.services` package. It defines the contract for sending push notifications within the application. This interface is designed to be implemented by classes that handle the delivery of push notifications to users.

## Public Methods

The `IPushNotificationService` interface declares the following public method:

| Method Signature | Description |
|------------------|-------------|
| `PushDeliveryResult send(Notification notification)` | Sends a push notification and returns the result of the delivery attempt. |

### Method Details

#### `send`

- **Description**: Sends a push notification to the intended recipient and returns the result of the delivery.
- **Parameters**:
  | Name | Type | Description |
  |------|------|-------------|
  | `notification` | `Notification` | The notification object containing the details of the message to be sent. |
- **Returns**: 
  | Type | Description |
  |------|-------------|
  | `PushDeliveryResult` | An object representing the outcome of the push notification delivery, including success or failure status. |

This interface is sealed, meaning it restricts which classes can implement it. Currently, it permits the `PushNotificationService` class to implement its methods, ensuring a controlled and predictable implementation hierarchy.
