# IPushNotificationService Interface

The `IPushNotificationService` interface defines the contract for sending push notifications within the UpMatches application. It is a **sealed interface**, meaning only explicitly permitted classes (in this case, `PushNotificationService`) can implement it. This design enforces a controlled hierarchy and ensures that all push notification delivery logic adheres to a single, well-defined API.

## Purpose

- **Abstraction**: Decouples the notification sending logic from its implementation, allowing for easier testing and future changes.
- **Sealed Contract**: Restricts implementation to a single class (`PushNotificationService`), preventing unauthorized or unintended implementations.
- **Type Safety**: Returns a `PushDeliveryResult` object, providing structured feedback about the delivery outcome.

## Public Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `send(Notification notification)` | Sends a push notification to the intended recipient(s). | `Notification notification` – The notification entity containing message details, target user, and delivery configuration. | `PushDeliveryResult` – An object encapsulating the result of the delivery attempt (e.g., success, failure, or partial delivery). |

## Usage Example

```java
// Assuming notification is already constructed
IPushNotificationService pushService = new PushNotificationService();
PushDeliveryResult result = pushService.send(notification);

if (result.isSuccess()) {
    System.out.println("Notification sent successfully.");
} else {
    System.err.println("Delivery failed: " + result.getErrorMessage());
}
```

## Implementation Notes

- The `PushNotificationService` class (the only permitted implementation) must handle all the underlying logic, such as connecting to push notification providers (e.g., Firebase Cloud Messaging, Apple Push Notification service), managing retries, and logging.
- The `PushDeliveryResult` class should provide meaningful status information to allow callers to react appropriately.

## Related Components

- **`Notification`** – The entity representing the notification to be sent.
- **`PushDeliveryResult`** – The result object returned after a delivery attempt.
- **`PushNotificationService`** – The sole implementation of this interface.
