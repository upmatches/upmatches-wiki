## Overview

The `UpdateGameRequest` class is a Java record used to encapsulate the data required to update a game in the application. It includes various fields such as venue ID, skill levels, currency, price, slots, start and end times, visibility, game type, and remarks. This class leverages Java's record feature to provide a concise and immutable data structure.

## Usage

The `UpdateGameRequest` record is typically used in scenarios where a game needs to be updated with new details. It ensures that the data provided adheres to specified constraints, such as valid currency codes and appropriate slot numbers, enhancing data integrity and consistency within the application.
