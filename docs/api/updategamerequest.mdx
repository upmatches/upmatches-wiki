# UpdateGameRequest

The `UpdateGameRequest` record is a Java DTO (Data Transfer Object) used to encapsulate the data required for updating an existing game entity in the UpMatches application. It leverages Jakarta Bean Validation annotations to enforce data integrity and business rules before the request reaches the service layer.

## Purpose

This record serves as the input contract for the game update endpoint. It allows partial updates by making all fields optional (nullable). Each field that is provided is validated according to the constraints defined in the record declaration.

## Record Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `venueId` | `Long` | None | Identifier of the venue where the game takes place. |
| `skillLevelFromId` | `Long` | None | Minimum skill level identifier for participants. |
| `skillLevelToId` | `Long` | None | Maximum skill level identifier for participants. |
| `currency` | `String` | `@Pattern(regexp = "^[A-Z]{3}$")` | ISO-4217 three-letter currency code (e.g., USD, EUR). |
| `price` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price of the game, must be non-negative with up to 8 integer digits and 2 decimal places. |
| `pricing` | `PricingRequest` | `@Valid` | Nested pricing details object, validated recursively. |
| `slots` | `Integer` | `@Min(1)`, `@Max(100)` | Number of available slots for the game (1–100). |
| `startTime` | `Instant` | None | Start time of the game in UTC. |
| `endTime` | `Instant` | None | End time of the game in UTC. |
| `visibility` | `GameVisibility` | None | Visibility setting for the game (e.g., PUBLIC, PRIVATE). |
| `gameType` | `GameType` | None | Type of game (e.g., SOCCER, BASKETBALL). |
| `remark` | `String` | `@Size(max = 500)` | Optional remark or note about the game, max 500 characters. |

## Usage Example

```java
UpdateGameRequest request = new UpdateGameRequest(
    1L,                    // venueId
    2L,                    // skillLevelFromId
    5L,                    // skillLevelToId
    "USD",                 // currency
    new BigDecimal("25.00"), // price
    new PricingRequest(...), // pricing
    10,                    // slots
    Instant.now(),         // startTime
    Instant.now().plus(2, ChronoUnit.HOURS), // endTime
    GameVisibility.PUBLIC, // visibility
    GameType.SOCCER,       // gameType
    "Bring your own water bottle" // remark
);
```

## Validation Behavior

- All fields are optional (nullable) to support partial updates.
- When a field is provided, it must pass its associated validation constraints.
- The `pricing` field is validated recursively via `@Valid`.
- Validation errors are thrown as `ConstraintViolationException` by the Jakarta Bean Validation framework.

## Related Components

- **PricingRequest**: A nested record containing pricing details, validated when provided.
- **GameVisibility**: Enum defining visibility options (PUBLIC, PRIVATE, etc.).
- **GameType**: Enum defining game types (SOCCER, BASKETBALL, etc.).
