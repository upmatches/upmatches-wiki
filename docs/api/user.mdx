# User Entity

The `User` entity represents a user within the UpMatches application. It is a JPA entity mapped to the `users` database table and serves as the central model for user authentication, profile management, and skill level tracking.

## Purpose

This class handles:
- User creation from various identity providers (Singpass, Auth0, Apple)
- Profile management (name, contact methods, avatar)
- Skill level associations
- Login tracking
- Onboarding completion status
- Penalty point tracking

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Primary key, auto-generated |
| `singpassUuid` | `String` | Unique identifier from Singpass |
| `auth0Uuid` | `String` | Unique identifier from Auth0 |
| `appleUuid` | `String` | Unique identifier from Apple |
| `lastLoginAt` | `Instant` | Timestamp of last login |
| `name` | `String` | User's display name |
| `whatsapp` | `String` | WhatsApp contact |
| `telegram` | `String` | Telegram handle |
| `messenger` | `String` | Messenger contact |
| `avatarUrl` | `String` | URL to user's avatar image |
| `email` | `String` | User's email address |
| `skillLevels` | `Set<UserSkillLevel>` | Associated skill levels |
| `hasCompletedOnboarding` | `boolean` | Onboarding completion status |
| `penaltyPoints` | `int` | Accumulated penalty points |
| `createdAt` | `Instant` | Record creation timestamp |
| `updatedAt` | `Instant` | Record update timestamp |

## Public Methods

### Static Factory Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `createFromSingpass` | `String singpassUuid` | `User` | Creates a new user authenticated via Singpass |
| `createFromAuth0` | `String auth0Uuid, String avatarUrl, String email` | `User` | Creates a new user authenticated via Auth0 |
| `createFromApple` | `String appleUuid, String displayName, String email` | `User` | Creates a new user authenticated via Apple |

### Instance Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `canCreateGame` | None | `boolean` | Checks if user can create games (requires Singpass) |
| `updateAvatarUrl` | `String url` | `void` | Updates the user's avatar URL |
| `applyIdpEmail` | `String email` | `void` | Applies email from identity provider if not null/blank |
| `recordLogin` | None | `void` | Records the current timestamp as last login |
| `updateProfile` | `ProfileData data` | `void` | Updates full profile and marks onboarding as complete |
| `patchProfile` | `PatchData data` | `void` | Partially updates profile fields |

## Inner Records

### ProfileData

Used for full profile updates during onboarding.

| Field | Type | Description |
|-------|------|-------------|
| `name` | `String` | User's display name |
| `whatsapp` | `String` | WhatsApp contact |
| `telegram` | `String` | Telegram handle |
| `messenger` | `String` | Messenger contact |
| `skillLevels` | `List<SkillLevel>` | List of skill levels |

### PatchData

Used for partial profile updates.

| Field | Type | Description |
|-------|------|-------------|
| `name` | `String` | User's display name (nullable) |
| `whatsapp` | `String` | WhatsApp contact (nullable) |
| `telegram` | `String` | Telegram handle (nullable) |
| `messenger` | `String` | Messenger contact (nullable) |
| `skillLevels` | `List<SkillLevel>` | List of skill levels (nullable) |

## Key Behaviors

- **Automatic Timestamps**: `createdAt` and `updatedAt` are automatically managed via `@PrePersist` and `@PreUpdate` lifecycle callbacks
- **Skill Level Management**: Skill levels are replaced entirely during profile updates, not merged
- **Null Handling**: Blank or null values for contact fields and email are normalized to `null`
- **Onboarding**: Completing a full profile update automatically marks onboarding as finished
