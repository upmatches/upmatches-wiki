# User Entity

The `User` entity represents a registered user within the UpMatches application. It serves as the core domain model for user management, supporting multiple authentication providers (Singpass, Auth0, Apple), profile management, skill level tracking, and onboarding completion status.

This JPA entity is mapped to the `users` database table and uses Lombok's `@Getter` and `@NoArgsConstructor` annotations to reduce boilerplate code. The entity is designed to be immutable where appropriate, with controlled mutation through dedicated methods.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Primary key, auto-generated using UUID strategy |
| `singpassUuid` | `String` | Unique identifier from Singpass authentication |
| `auth0Uuid` | `String` | Unique identifier from Auth0 authentication |
| `appleUuid` | `String` | Unique identifier from Apple authentication |
| `lastLoginAt` | `Instant` | Timestamp of the user's last login |
| `name` | `String` | User's display name |
| `whatsapp` | `String` | WhatsApp contact identifier |
| `telegram` | `String` | Telegram contact identifier |
| `messenger` | `String` | Messenger contact identifier |
| `avatarUrl` | `String` | URL to the user's avatar image |
| `email` | `String` | User's email address |
| `skillLevels` | `Set<UserSkillLevel>` | Collection of user skill levels |
| `hasCompletedOnboarding` | `boolean` | Flag indicating if onboarding is complete |
| `penaltyPoints` | `int` | Accumulated penalty points |
| `createdAt` | `Instant` | Timestamp of user creation (non-updatable) |
| `updatedAt` | `Instant` | Timestamp of last update |

## Public Methods

### Factory Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `createFromSingpass` | `String singpassUuid` | `User` | Creates a new user authenticated via Singpass |
| `createFromAuth0` | `String auth0Uuid, String avatarUrl, String email` | `User` | Creates a new user authenticated via Auth0 |
| `createFromApple` | `String appleUuid, String displayName, String email` | `User` | Creates a new user authenticated via Apple |

### Business Logic Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `canCreateGame` | None | `boolean` | Returns `true` if the user has a Singpass UUID, indicating they can create games |
| `updateAvatarUrl` | `String url` | `void` | Updates the user's avatar URL |
| `applyIdpEmail` | `String email` | `void` | Applies an email from an identity provider if the value is not blank |
| `recordLogin` | None | `void` | Records the current timestamp as the last login time |
| `updateProfile` | `ProfileData data` | `void` | Fully updates the user's profile and marks onboarding as complete |
| `patchProfile` | `PatchData data` | `void` | Partially updates the user's profile, only modifying non-null fields |

### Inner Records

#### `ProfileData`

| Field | Type | Description |
|-------|------|-------------|

| `telegram` | `String` | Telegram contact identifier |

| `skillLevels` | `List<SkillLevel>` | List of skill levels to assign |

#### `PatchData`

| Field | Type | Description |
|-------|------|-------------|
| `name` | `String` | User's display name (nullable) |
| `whatsapp` | `String` | WhatsApp contact identifier (nullable) |
| `telegram` | `String` | Telegram contact identifier (nullable) |
| `messenger` | `String` | Messenger contact identifier (nullable) |
| `skillLevels` | `List<SkillLevel>` | List of skill levels to assign (nullable) |

## Usage Examples

### Creating a User via Singpass

```java
User user = User.createFromSingpass("singpass-uuid-123");
```

### Updating User Profile

```java
User.ProfileData profileData = new User.ProfileData(
    "John Doe",
    "+1234567890",
    "@johndoe",
    "john.messenger",
    skillLevels
);
user.updateProfile(profileData);
```

### Patching User Profile

```java
User.PatchData patchData = new User.PatchData(
    "Jane Doe",  // Update name
    null,        // Keep existing WhatsApp
    null,        // Keep existing Telegram
    null,        // Keep existing Messenger
    null         // Keep existing skill levels
);
user.patchProfile(patchData);
```

## Notes

- The `blankToNull` utility method ensures that blank strings are stored as `null` in the database
- The `@PrePersist` and `@PreUpdate` callbacks automatically manage `createdAt` and `updatedAt` timestamps
- Skill levels are managed through a `UserSkillLevel` join entity with cascade operations
- The `penaltyPoints` field is initialized to `0` by default
