## Overview

The `User` class represents a user entity in the application. It is an entity class mapped to the `users` table in the database using JPA annotations. This class encapsulates user-related data and provides methods for creating and managing user profiles, handling authentication identifiers, and updating user information.

## Public Methods

The following table documents the public methods available in the `User` class:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `createFromSingpass` | `String singpassUuid` | `User` | Creates a new `User` instance using a Singpass UUID and records the login time. |
| `createFromAuth0` | `String auth0Uuid, String avatarUrl, String email` | `User` | Creates a new `User` instance using Auth0 credentials, sets the avatar URL and email, and records the login time. |
| `createFromApple` | `String appleUuid, String displayName, String email` | `User` | Creates a new `User` instance using Apple credentials, sets the display name and email, and records the login time. |
| `canCreateGame` | None | `boolean` | Checks if the user can create a game, based on the presence of a Singpass UUID. |
| `updateAvatarUrl` | `String url` | `void` | Updates the user's avatar URL. |
| `applyIdpEmail` | `String email` | `void` | Applies an email from an identity provider, normalizing it to `null` if blank. |
| `recordLogin` | None | `void` | Updates the last login timestamp to the current time. |
| `updateProfile` | `ProfileData data` | `void` | Updates the user's profile with the provided data and marks onboarding as completed. |
| `patchProfile` | `PatchData data` | `void` | Partially updates the user's profile with the provided data. |

## Additional Information

- The `User` class uses JPA annotations to define the mapping between the class fields and the database columns.
- The class includes lifecycle callback methods (`onCreate` and `onUpdate`) to automatically set timestamps for creation and updates.
- The `ProfileData` and `PatchData` records are used to encapsulate profile information for updates and patches, respectively.
- The `replaceSkillLevels` method is a private helper used to update the user's skill levels, ensuring that existing levels are cleared before adding new ones.
