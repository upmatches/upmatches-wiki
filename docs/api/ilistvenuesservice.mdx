# IListVenuesService Interface

The `IListVenuesService` interface defines the contract for retrieving a paginated list of venues in the UpMatches application. It is a sealed interface, meaning only the explicitly permitted implementing class (`ListVenuesService`) can implement it. This design enforces a controlled extension point for the venue listing functionality.

## Purpose

This interface provides a single method to fetch venues with pagination support. By using a sealed interface, the codebase ensures that all venue listing operations go through a single, well-defined implementation, promoting consistency and maintainability.

## Method Summary

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `execute` | `PagedResponse<VenueResponse>` | `Pageable pageable` | Retrieves a paginated list of venues based on the provided pagination parameters. |

## Method Details

### `execute(Pageable pageable)`

This method accepts a Spring Data `Pageable` object that specifies pagination parameters such as page number, page size, and sorting criteria. It returns a `PagedResponse` containing a list of `VenueResponse` objects along with pagination metadata.

**Parameters:**
- `pageable` (Pageable): The pagination information including page number, page size, and sort options.

**Returns:**
- `PagedResponse<VenueResponse>`: A response object containing:
  - The list of `VenueResponse` objects for the requested page
  - Pagination metadata (total pages, total elements, current page, etc.)

## Usage Example

```java
// Inject the service
@Autowired
private IListVenuesService listVenuesService;

// Create a pageable request (page 0, size 10, sorted by name ascending)
Pageable pageable = PageRequest.of(0, 10, Sort.by("name").ascending());

// Execute the query
PagedResponse<VenueResponse> response = listVenuesService.execute(pageable);

// Access the results
List<VenueResponse> venues = response.getContent();
int totalPages = response.getTotalPages();
long totalElements = response.getTotalElements();
```

## Implementation Notes

- The interface is sealed with `permits ListVenuesService`, restricting implementation to a single class
- Uses Spring Data's `Pageable` for flexible pagination and sorting
- Returns a custom `PagedResponse` wrapper instead of Spring's `Page` to decouple the API from Spring Data internals
- The `VenueResponse` class contains the venue data returned to clients

## Related Components

- `ListVenuesService`: The sole implementing class of this interface
- `VenueResponse`: The DTO representing venue data in API responses
- `PagedResponse`: Generic wrapper for paginated responses
