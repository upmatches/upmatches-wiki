# IListVenuesService Interface

The `IListVenuesService` interface defines the contract for retrieving a paginated list of venues in the UpMatches application. It serves as the abstraction layer between the controller and the concrete implementation, following the interface segregation principle.

This sealed interface permits only the `ListVenuesService` class to implement it, ensuring controlled extension and preventing unauthorized implementations.

## Interface Definition

```java
public sealed interface IListVenuesService permits ListVenuesService {
    PagedResponse<VenueResponse> execute(Pageable pageable);
}
```

## Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `execute` | `PagedResponse<VenueResponse>` | `Pageable pageable` | Retrieves a paginated list of venues based on the provided pagination parameters |

### Method Details

#### `execute(Pageable pageable)`

This method accepts a Spring Data `Pageable` object that contains pagination information such as page number, page size, and sorting criteria. It returns a `PagedResponse` containing a list of `VenueResponse` objects along with pagination metadata.

**Parameters:**
- `pageable` - A Spring Data `Pageable` instance specifying pagination and sorting parameters

**Returns:**
- `PagedResponse<VenueResponse>` - A paginated response containing venue data and pagination information

## Usage Example

```java
@Service
public class VenueController {
    private final IListVenuesService listVenuesService;
    
    public VenueController(IListVenuesService listVenuesService) {
        this.listVenuesService = listVenuesService;
    }
    
    @GetMapping("/venues")
    public ResponseEntity<PagedResponse<VenueResponse>> getVenues(
            @PageableDefault(size = 20, sort = "name") Pageable pageable) {
        PagedResponse<VenueResponse> response = listVenuesService.execute(pageable);
        return ResponseEntity.ok(response);
    }
}
```

## Related Types

- `VenueResponse` - The response DTO containing venue information
- `PagedResponse` - Generic wrapper for paginated API responses
- `ListVenuesService` - The permitted implementation class
- `Pageable` - Spring Data interface for pagination abstraction
