# IListVenuesService Interface

The `IListVenuesService` interface defines the contract for retrieving a paginated list of venues in the UpMatches application. It is a sealed interface, meaning only the specified implementing class (`ListVenuesService`) is allowed to implement it. This design pattern enforces a controlled hierarchy and ensures that the venue listing logic is centralized and maintainable.

## Purpose

The primary purpose of this interface is to provide a standardized method for fetching venues with pagination support. By using a sealed interface, the application guarantees that only one implementation exists, which simplifies dependency injection and testing while preventing unauthorized extensions.

## Method Summary

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `execute` | `PagedResponse<VenueResponse>` | `Pageable pageable` | Retrieves a paginated list of venues based on the provided pagination information. |

## Method Details

### `execute(Pageable pageable)`

This method accepts a Spring Data `Pageable` object containing pagination parameters (page number, page size, sorting criteria) and returns a `PagedResponse` containing a list of `VenueResponse` objects.

**Parameters:**
- `pageable` (Pageable): The pagination information including page number, page size, and sort options.

**Returns:**
- `PagedResponse<VenueResponse>`: A paginated response wrapper containing the list of venue data and pagination metadata (total pages, total elements, current page, etc.).

**Throws:**
- This method does not declare any checked exceptions. However, implementations may throw runtime exceptions such as `DataAccessException` if database access fails.

## Usage Example

```java
@Autowired
private IListVenuesService listVenuesService;

public void displayVenues() {
    Pageable pageable = PageRequest.of(0, 10, Sort.by("name").ascending());
    PagedResponse<VenueResponse> response = listVenuesService.execute(pageable);
    
    System.out.println("Total venues: " + response.getTotalElements());
    System.out.println("Current page: " + response.getPageNumber());
    response.getContent().forEach(venue -> System.out.println(venue.getName()));
}
```

## Related Components

- **`ListVenuesService`**: The sole permitted implementation of this interface.
- **`VenueResponse`**: The DTO representing venue data returned in the response.
- **`PagedResponse`**: A generic wrapper for paginated API responses.
- **`Pageable`**: Spring Data interface for pagination abstraction.
