# IImportVenuesService Interface

The `IImportVenuesService` interface defines the contract for importing venue data into the system. It is a sealed interface, meaning only the permitted implementation (`ImportVenuesService`) can extend it. This design enforces a single, controlled implementation for the venue import functionality.

## Purpose

This interface serves as the abstraction layer for importing venues from an external file (e.g., CSV, Excel, or JSON). By defining a single method `execute`, it standardizes the import process and allows for future enhancements or alternative implementations while maintaining backward compatibility.

## Sealed Interface

The interface is declared as `sealed`, which restricts which classes or interfaces can implement it. In this case, only `ImportVenuesService` is permitted. This ensures that the import logic remains centralized and prevents unauthorized or unintended implementations.

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(MultipartFile file)` | `VenueImportResponse` | Processes the uploaded file and imports venue data into the system. |

## Method Details

### `execute(MultipartFile file)`

This is the sole method of the interface. It accepts a `MultipartFile` representing the uploaded file containing venue data and returns a `VenueImportResponse` object that encapsulates the result of the import operation.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `file` | `MultipartFile` | The uploaded file containing venue data to be imported. Must not be null. |

**Returns:**

| Type | Description |
|------|-------------|
| `VenueImportResponse` | An object containing the results of the import operation, including success/failure status, number of venues imported, and any error messages. |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `IllegalArgumentException` | If the provided file is null or empty. |
| `IOException` | If there is an error reading the file contents. |
| `DataIntegrityViolationException` | If the import violates database constraints (e.g., duplicate venue names). |

## Usage Example

```java
@Autowired
private IImportVenuesService importVenuesService;

public void handleFileUpload(MultipartFile file) {
    VenueImportResponse response = importVenuesService.execute(file);
    if (response.isSuccess()) {
        System.out.println("Successfully imported " + response.getImportedCount() + " venues.");
    } else {
        System.err.println("Import failed: " + response.getErrorMessage());
    }
}
```

## Dependencies

- **Spring Web**: `MultipartFile` is provided by the Spring Framework for handling file uploads.
- **VenueImportResponse**: A custom response object defined in the `com.upmatches.app.features.venue.responses` package.

## Related Components

- `ImportVenuesService` - The sole permitted implementation of this interface.
- `VenueImportResponse` - The response object returned by the import operation.
