# CreateShareLinkRequest

The `CreateShareLinkRequest` class is a Java record that serves as a Data Transfer Object (DTO) for creating share links within the UpMatches application. It encapsulates the necessary input parameters required to generate a new shareable link for a specific resource.

## Purpose

This record defines the contract for incoming API requests to create share links. It ensures that all required fields are provided and validated before processing. The class leverages Jakarta Bean Validation annotations to enforce data integrity at the application boundary.

## Record Structure

The record contains two fields that must be provided when creating a share link:

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `resourceType` | `ResourceType` | `@NotNull` | The type of resource being shared (e.g., profile, post, event) |
| `resourceId` | `String` | `@NotBlank`, `@Pattern` | The unique identifier of the resource, must be a valid UUID |

## Validation Constants

The class defines several static constants used for validation messages and patterns:

| Constant | Value | Purpose |
|----------|-------|---------|
| `MSG_RESOURCE_TYPE_REQUIRED` | "Resource type is required." | Error message when resource type is null |
| `MSG_RESOURCE_ID_REQUIRED` | "Resource ID is required." | Error message when resource ID is blank |
| `MSG_INVALID_UUID` | "Resource ID must be a valid UUID." | Error message when resource ID doesn't match UUID format |
| `UUID_PATTERN` | `^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$` | Regular expression for UUID validation |

## Constructor Parameters

### `resourceType`
- **Type**: `ResourceType` (enum)
- **Validation**: `@NotNull`
- **Description**: Specifies the category of resource for which the share link is being created. This enum value determines how the link will be processed and what type of content it will point to.

### `resourceId`
- **Type**: `String`
- **Validation**: `@NotBlank` and `@Pattern(regexp = UUID_PATTERN)`
- **Description**: The unique identifier of the specific resource. Must be a valid UUID in the standard 8-4-4-4-12 format (e.g., `123e4567-e89b-12d3-a456-426614174000`).

## Usage Example

```java
// Creating a valid request
CreateShareLinkRequest request = new CreateShareLinkRequest(
    ResourceType.PROFILE,
    "123e4567-e89b-12d3-a456-426614174000"
);

// This would fail validation
CreateShareLinkRequest invalidRequest = new CreateShareLinkRequest(
    null,  // resourceType is null - validation error
    "invalid-id"  // not a valid UUID - validation error
);
```

## Validation Behavior

When this record is used in a Spring Boot controller with `@Valid` annotation, the following validations are automatically applied:

1. **Resource Type Validation**: If `resourceType` is `null`, the system returns a validation error with the message "Resource type is required."
2. **Resource ID Validation**: 
   - If `resourceId` is blank (null, empty, or whitespace), the system returns "Resource ID is required."
   - If `resourceId` doesn't match the UUID pattern, the system returns "Resource ID must be a valid UUID."

## Dependencies

- `jakarta.validation.constraints.NotBlank` - For non-blank string validation
- `jakarta.validation.constraints.NotNull` - For non-null object validation
- `jakarta.validation.constraints.Pattern` - For regex pattern matching
- `com.upmatches.app.features.sharelink.enums.ResourceType` - Enum defining available resource types
