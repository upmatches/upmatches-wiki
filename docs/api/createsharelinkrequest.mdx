## Overview

The `CreateShareLinkRequest` class is a Java record used to encapsulate the data required to create a shareable link for a resource within the application. It ensures that the necessary information is provided and validated before processing the request to generate a share link.

## Class Details

The `CreateShareLinkRequest` record consists of two fields: `resourceType` and `resourceId`. These fields are validated using annotations to ensure that they meet the required constraints.

### Fields

- **resourceType**: Represents the type of resource for which the share link is being created. It is of type `ResourceType` and must not be null.
- **resourceId**: A string representing the unique identifier of the resource. It must be a non-blank valid UUID.

### Validation Constraints

- `resourceType` must not be null. If it is null, an error message "Resource type is required." is triggered.
- `resourceId` must not be blank and must match the UUID pattern. If it does not meet these criteria, appropriate error messages are triggered:
  - "Resource ID is required." if the field is blank.
  - "Resource ID must be a valid UUID." if the field does not match the UUID pattern.
