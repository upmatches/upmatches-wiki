# JwksController

The `JwksController` is a Spring REST controller that exposes a JSON Web Key Set (JWKS) endpoint. This endpoint provides public keys used for verifying JSON Web Tokens (JWTs) issued by the Singpass authentication system. By serving the JWKS at the standard `/.well-known/jwks.json` path, the controller enables clients (such as API gateways or other services) to retrieve the public keys necessary for token validation.

## Purpose

- **Public Key Distribution**: Serves the public keys required to verify JWTs signed by the Singpass identity provider.
- **Standard Endpoint**: Adheres to the well-known URI convention (`/.well-known/jwks.json`) for JWKS discovery.
- **Caching Support**: Implements HTTP caching headers to reduce load and improve performance, with a configurable cache duration.

## Dependencies

- `ISingpassKeyProvider`: Interface that provides the JWKS JSON string containing public keys.
- Spring Web: `@RestController`, `@GetMapping`, `ResponseEntity`, `CacheControl`, `MediaType`.

## Public Methods

### `getJwks()`

Returns the JSON Web Key Set (JWKS) as a JSON string.

| Parameter | Type | Description |
|-----------|------|-------------|
| *(none)*  |      |             |

| Return Type | Description |
|-------------|-------------|
| `ResponseEntity<String>` | HTTP response containing the JWKS JSON with appropriate caching and content-type headers. |

**Response Headers:**
- `Cache-Control`: `public, max-age=3600` (1 hour cache)
- `Content-Type`: `application/json`

**Example Response:**
```json
{
  "keys": [
    {
      "kty": "RSA",
      "use": "sig",
      "kid": "key-id-1",
      "n": "base64url-encoded-modulus",
      "e": "AQAB"
    }
  ]
}
```

## Configuration

The controller uses the following constants:

| Constant | Value | Description |
|----------|-------|-------------|
| `JWKS_ENDPOINT` | `/.well-known/jwks.json` | The URI path for the JWKS endpoint |
| `CACHE_MAX_AGE_HOURS` | `1` | Cache duration in hours for the JWKS response |

## Usage

The endpoint is automatically registered by Spring Boot when the application starts. Clients can retrieve the JWKS by making a GET request to:

```
GET /.well-known/jwks.json
```

The response will be cached by intermediaries (CDNs, browsers) for 1 hour, after which they should re-fetch the keys.

## Notes

- The actual JWKS content is delegated to the `ISingpassKeyProvider` implementation, which should handle key generation, rotation, and serialization.
- The cache duration of 1 hour is a reasonable default for most use cases; adjust `CACHE_MAX_AGE_HOURS` based on your key rotation policy.
- This endpoint should be publicly accessible without authentication, as it is required for token verification.
