# JwksController

The `JwksController` is a Spring REST controller that exposes a JSON Web Key Set (JWKS) endpoint for Singpass authentication. It provides public keys in JWKS format, which clients can use to verify the signature of JWTs issued by the application.

## Purpose

This controller serves the public keys required for JWT signature verification in a Singpass integration. By exposing the JWKS endpoint at `/.well-known/jwks.json`, it follows the standard OAuth 2.0 and OpenID Connect discovery pattern, allowing clients to dynamically retrieve the public keys needed to validate token signatures.

## Endpoint

| HTTP Method | Path                    | Description                                      |
|-------------|-------------------------|--------------------------------------------------|
| GET         | `/.well-known/jwks.json` | Returns the public JWKS JSON for key verification |

## Dependencies

- **`ISingpassKeyProvider`**: Interface that provides the public JWKS JSON string. Injected via constructor.

## Configuration

- **Cache Control**: Responses are cached for 1 hour with public cache directive to improve performance and reduce load.
- **Content Type**: Returns `application/json` media type.

## Methods

### `getJwks()`

Returns the public JSON Web Key Set (JWKS) as a JSON string.

**Response:**

| Status | Description                                      |
|--------|--------------------------------------------------|
| 200 OK | Returns the JWKS JSON with appropriate caching headers |

**Response Headers:**

| Header          | Value                                          |
|-----------------|------------------------------------------------|
| Cache-Control   | `max-age=3600, public`                         |
| Content-Type    | `application/json`                             |

**Example Response Body:**

```json
{
  "keys": [
    {
      "kty": "RSA",
      "use": "sig",
      "kid": "key-id-1",
      "n": "base64url-encoded-modulus",
      "e": "AQAB"
    }
  ]
}
```

## Usage

The controller is automatically registered as a Spring bean due to the `@RestController` annotation. Clients can access the JWKS endpoint at:

```
GET https://your-domain.com/.well-known/jwks.json
```

## Security Considerations

- The endpoint is public by design, as JWKS are meant to be publicly accessible for signature verification.
- Caching is implemented to reduce server load and improve response times.
- The actual key material is managed by the `ISingpassKeyProvider` implementation, which should handle key rotation and secure storage.
