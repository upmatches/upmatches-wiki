# GameJoinabilityService

The `GameJoinabilityService` class is a Spring service that determines whether a user can join a specific game. It evaluates multiple conditions such as skill level compatibility, game visibility, participant capacity, time overlaps, and the user's current participation status. The service provides both single-game and batch computation methods, returning a `ViewerJoinabilityResponse` that indicates whether joining is allowed or blocked, along with any relevant warnings.

## Class Overview

- **Package:** `com.upmatches.app.features.game.services`
- **Annotations:** `@Service`, `@Transactional(readOnly = true)`
- **Implements:** `IGameJoinabilityService`
- **Key Dependencies:**
  - `GameParticipantRepository` – for checking user participation and overlaps
  - `GameShareAccessRepository` – for verifying private game access
  - `IGameLookupService` – for retrieving user information

## Public Methods

### `hasSkillMismatch(Game game, User user)`

Checks if the user's skill levels are incompatible with the game's required skill range.

| Parameter | Type   | Description |
|-----------|--------|-------------|
| `game`    | `Game` | The game entity to check |
| `user`    | `User` | The user entity to evaluate |

**Returns:** `boolean` – `true` if the user has skill levels that are out of the game's range and no matching skill levels; `false` otherwise.

### `compute(Game game, long participantCount, UUID userId)`

Computes the joinability response for a single game and user.

| Parameter          | Type    | Description |
|--------------------|---------|-------------|
| `game`             | `Game`  | The game entity |
| `participantCount` | `long`  | Current number of participants in the game |
| `userId`           | `UUID`  | The user's unique identifier |

**Returns:** `ViewerJoinabilityResponse` – A response object indicating whether the user can join, or `null` if `userId` is `null`.

### `computeBatch(List<Game> games, Map<UUID, Long> participantCountsByGameId, UUID userId)`

Computes joinability responses for multiple games in a batch, optimizing database queries.

| Parameter                    | Type                | Description |
|------------------------------|---------------------|-------------|
| `games`                      | `List<Game>`        | List of games to evaluate |
| `participantCountsByGameId`  | `Map<UUID, Long>`   | Map of game IDs to their participant counts |
| `userId`                     | `UUID`              | The user's unique identifier |

**Returns:** `Map<UUID, ViewerJoinabilityResponse>` – A map of game IDs to their corresponding joinability responses. Returns an empty map if `games` is null/empty or `userId` is null.

## Internal Logic

The service evaluates joinability based on the following criteria, in order:

1. **Already Joined** – If the user is already an active participant, joining is blocked.
2. **Past or Inactive Game** – Games that have ended or are inactive cannot be joined.
3. **Private Access Denied** – Private games require explicit access via `GameShareAccessRepository`.
4. **Game Full** – If the participant count meets or exceeds the game's capacity.
5. **Time Overlap** – If the user has another active game that overlaps in time.

Additionally, the service generates warnings for:
- **IS_ORGANIZER** – The user is the game organizer (cannot join their own game).
- **SKILL_MISMATCH** – The user's skill levels do not match the game's requirements.

## Private Records

### `SkillLevelTally`

A simple record to hold the result of skill level evaluation.

| Field          | Type      | Description |
|----------------|-----------|-------------|
| `hasMatching`  | `boolean` | Whether the user has at least one matching skill level |
| `hasOutOfRange`| `boolean` | Whether the user has at least one skill level outside the game's range |

### `TimeRange`

Represents a time interval for overlap detection.

| Field    | Type       | Description |
|----------|------------|-------------|
| `gameId` | `UUID`     | The game's unique identifier |
| `start`  | `Instant`  | Start time of the game |
| `end`    | `Instant`  | End time of the game |
