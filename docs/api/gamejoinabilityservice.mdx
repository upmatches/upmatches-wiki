## Purpose

The `GameJoinabilityService` class is a service component in a Java application that determines the joinability of a user to a game. It evaluates various conditions such as skill level compatibility, game visibility, and schedule overlaps to decide if a user can join a game or not.

## Public Methods

### `hasSkillMismatch`

Determines if there is a skill mismatch between the user and the game.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| `game`    | `Game` | The game to check against.           |
| `user`    | `User` | The user whose skills are evaluated. |

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| `boolean`   | `true` if there is a skill mismatch, `false` otherwise. |

### `compute`

Computes the joinability of a user for a specific game.

| Parameter          | Type     | Description                                      |
|--------------------|----------|--------------------------------------------------|
| `game`             | `Game`   | The game to evaluate.                            |
| `participantCount` | `long`   | The current number of participants in the game.  |
| `userId`           | `UUID`   | The ID of the user to evaluate.                  |

| Return Type                  | Description                                      |
|------------------------------|--------------------------------------------------|
| `ViewerJoinabilityResponse`  | The response indicating if the user can join the game. |

### `computeBatch`

Computes the joinability of a user for a batch of games.

| Parameter                  | Type                          | Description                                      |
|----------------------------|-------------------------------|--------------------------------------------------|
| `games`                    | `List<Game>`                  | The list of games to evaluate.                   |
| `participantCountsByGameId`| `Map<UUID, Long>`             | A map of game IDs to their participant counts.   |
| `userId`                   | `UUID`                        | The ID of the user to evaluate.                  |

| Return Type                          | Description                                      |
|--------------------------------------|--------------------------------------------------|
| `Map<UUID, ViewerJoinabilityResponse>` | A map of game IDs to their joinability responses. |

## Additional Details

- The service uses repositories such as `GameParticipantRepository` and `GameShareAccessRepository` to fetch necessary data.
- It checks for conditions like skill mismatch, private access denial, and schedule overlap to determine joinability.
- The `build` method constructs the `ViewerJoinabilityResponse` based on the evaluated conditions.
- The `resolveReason` method determines the specific reason why a user cannot join a game, if applicable.
