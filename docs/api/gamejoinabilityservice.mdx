# GameJoinabilityService

The `GameJoinabilityService` is a Spring service class responsible for determining whether a user can join a specific game. It evaluates various conditions such as skill level mismatches, game visibility, participant capacity, time overlaps, and the user's current participation status. The service provides both single-game and batch computation methods for joinability checks.

## Purpose

This service acts as the core business logic layer for joinability validation in a game management system. It ensures that users can only join games when all prerequisites are met, preventing conflicts and enforcing game rules. The service is designed to be efficient for both individual game checks and bulk operations.

## Public Methods

### `hasSkillMismatch(Game game, User user)`

Checks if the user's skill levels are outside the acceptable range for the game's activity.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to check skill requirements for |
| `user` | `User` | The user whose skills are being evaluated |

**Returns:** `boolean` - `true` if the user has skill levels that are out of range for the game's activity, `false` otherwise.

### `compute(Game game, long participantCount, UUID userId)`

Computes the joinability response for a single game and user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to evaluate |
| `participantCount` | `long` | Current number of participants in the game |
| `userId` | `UUID` | The ID of the user to check joinability for |

**Returns:** `ViewerJoinabilityResponse` - A response object indicating whether the user can join and any associated warnings or reasons for blocking. Returns `null` if `userId` is `null`.

### `computeBatch(List<Game> games, Map<UUID, Long> participantCountsByGameId, UUID userId)`

Computes joinability responses for multiple games simultaneously.

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to evaluate |
| `participantCountsByGameId` | `Map<UUID, Long>` | Map of game IDs to their current participant counts |
| `userId` | `UUID` | The ID of the user to check joinability for |

**Returns:** `Map<UUID, ViewerJoinabilityResponse>` - A map of game IDs to their corresponding joinability responses. Returns an empty map if `games` is null/empty or `userId` is null.

## Internal Logic

### Joinability Decision Flow

The service evaluates joinability in the following order:

1. **Already Joined**: If the user is already an active participant, the response is blocked with `ALREADY_JOINED` reason.
2. **Past or Inactive Game**: If the game is past its start time or inactive, the response is blocked with `NOT_JOINABLE` reason.
3. **Private Access Denied**: If the game is private and the user doesn't have explicit access, the response is blocked with `PRIVATE_ACCESS_DENIED` reason.
4. **Game Full**: If the game has reached its maximum capacity, the response is blocked with `GAME_FULL` reason.
5. **Time Overlap**: If the user has another active game that overlaps in time, the response is blocked with `OVERLAPPING` reason.
6. **Allowed**: If none of the above conditions are met, the response is allowed.

### Warnings

The service may also add warnings to the response:

- `IS_ORGANIZER`: The user is the organizer of the game
- `SKILL_MISMATCH`: The user's skill levels don't match the game's requirements

## Private Records

### `SkillLevelTally`

A record used internally to track whether a user has matching or out-of-range skill levels.

| Field | Type | Description |
|-------|------|-------------|
| `hasMatching` | `boolean` | Whether the user has at least one skill level within the game's range |
| `hasOutOfRange` | `boolean` | Whether the user has at least one skill level outside the game's range |

### `TimeRange`

A record used internally to represent a time range for overlap detection.

| Field | Type | Description |
|-------|------|-------------|
| `gameId` | `UUID` | The ID of the game associated with this time range |
| `start` | `Instant` | The start time of the range |
| `end` | `Instant` | The end time of the range |

## Dependencies

- `GameParticipantRepository`: For checking user participation status
- `GameShareAccessRepository`: For checking private game access
- `IGameLookupService`: For looking up user information

## Usage Example

```java
// Single game check
ViewerJoinabilityResponse response = joinabilityService.compute(
    game,
    game.getParticipantCount(),
    currentUser.getId()
);

if (response.isAllowed()) {
    // Allow user to join
} else {
    // Show reason and warnings
    JoinabilityReason reason = response.getReason();
    List<JoinabilityWarning> warnings = response.getWarnings();
}

// Batch check for multiple games
Map<UUID, ViewerJoinabilityResponse> responses = joinabilityService.computeBatch(
    games,
    participantCounts,
    currentUser.getId()
);
```
