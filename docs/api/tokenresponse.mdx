## Purpose of the TokenResponse Class

The `TokenResponse` class is a part of the `com.upmatches.app.features.auth.responses` package. It is designed to encapsulate the response data related to authentication tokens. This class uses Java's `record` feature to define a simple data carrier for holding an access token, a refresh token, and an expiration timestamp.

## Public Methods

The `TokenResponse` class provides the following public method:

| Method Signature | Description |
|------------------|-------------|
| `static TokenResponse of(String accessToken, String refreshToken, Long expiresAt)` | A static factory method that creates a new instance of `TokenResponse` with the specified access token, refresh token, and expiration time. |

### Method Details

#### `of`

- **Parameters:**

  | Name          | Type   | Description                      |
  |---------------|--------|----------------------------------|
  | accessToken   | String | The access token string.         |
  | refreshToken  | String | The refresh token string.        |
  | expiresAt     | Long   | The expiration timestamp in milliseconds. |

- **Returns:** 

  | Type          | Description                                      |
  |---------------|--------------------------------------------------|
  | TokenResponse | A new instance of `TokenResponse` containing the specified tokens and expiration time. |

This method provides a convenient way to create a `TokenResponse` object without directly invoking the constructor, enhancing code readability and maintainability.
