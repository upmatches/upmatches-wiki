# TokenResponse

The `TokenResponse` class is a Java record that represents the response payload returned by the authentication server after a successful login or token refresh operation. It encapsulates the essential tokens and expiration information required for maintaining a user's authenticated session.

## Purpose

This record serves as a data transfer object (DTO) for authentication responses. It contains:
- An **access token** used for authorizing API requests
- A **refresh token** used to obtain new access tokens without requiring the user to re-authenticate
- The **expiration timestamp** indicating when the access token will expire

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The JWT or bearer token used to authenticate API requests |
| `refreshToken` | `String` | A long-lived token used to obtain new access tokens |
| `expiresAt` | `Long` | Unix timestamp (in seconds or milliseconds) indicating when the access token expires |

## Methods

### `of`

```java
public static TokenResponse of(String accessToken, String refreshToken, Long expiresAt)
```

Factory method to create a new `TokenResponse` instance.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The access token string |
| `refreshToken` | `String` | The refresh token string |
| `expiresAt` | `Long` | The expiration timestamp |

**Returns:**

| Type | Description |
|------|-------------|
| `TokenResponse` | A new `TokenResponse` instance with the provided values |

## Usage Example

```java
// Creating a TokenResponse from authentication server response
TokenResponse response = TokenResponse.of(
    "eyJhbGciOiJIUzI1NiIs...",  // access token
    "dGhpcyBpcyBhIHJlZnJl...",  // refresh token
    1700000000L                   // expires at timestamp
);

// Accessing record components
String accessToken = response.accessToken();
String refreshToken = response.refreshToken();
Long expiresAt = response.expiresAt();
```

## Notes

- As a Java record, `TokenResponse` automatically provides `equals()`, `hashCode()`, `toString()`, and component accessor methods.
- The record is immutable, ensuring thread-safety when passing token data between components.
- The `of` static factory method provides a convenient way to construct instances while maintaining the immutability guarantees of the record.
