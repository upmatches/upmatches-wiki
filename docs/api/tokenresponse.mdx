# TokenResponse

The `TokenResponse` class is a Java record that encapsulates the response data returned after a successful authentication or token refresh operation. It provides a structured way to transport authentication tokens and their expiration details between the backend and client application.

## Purpose

This record serves as a Data Transfer Object (DTO) for authentication responses. It bundles three critical pieces of information:
- An **access token** used for authorizing API requests
- A **refresh token** used to obtain new access tokens without re-authentication
- The **expiration timestamp** indicating when the access token becomes invalid

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The JWT or bearer token used to authenticate API requests |
| `refreshToken` | `String` | A long-lived token used to obtain new access tokens |
| `expiresAt` | `Long` | Unix timestamp (in seconds or milliseconds) indicating when the access token expires |

## Methods

### `of(String accessToken, String refreshToken, Long expiresAt)`

A static factory method that creates a new `TokenResponse` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The access token string |
| `refreshToken` | `String` | The refresh token string |
| `expiresAt` | `Long` | The expiration timestamp |

**Returns:** `TokenResponse` - A new instance of the record with the provided values.

**Example usage:**
```java
TokenResponse response = TokenResponse.of(
    "eyJhbGciOiJIUzI1NiIs...",
    "dGhpcyBpcyBhIHJlZnJl...",
    1700000000L
);
```

## Notes

- As a Java record, `TokenResponse` automatically provides `equals()`, `hashCode()`, `toString()`, and accessor methods (e.g., `accessToken()`, `refreshToken()`, `expiresAt()`).
- The record is immutable by design, ensuring thread safety and data integrity.
- This class is part of the `com.upmatches.app.features.auth.responses` package, indicating its role in the authentication feature module.
