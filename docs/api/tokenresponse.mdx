## Overview

The `TokenResponse` class is a Java record that encapsulates the response details for authentication tokens. It is part of the `com.upmatches.app.features.auth.responses` package. This class is designed to hold information about an access token, a refresh token, and the expiration time of the access token. It provides a static factory method to create instances of `TokenResponse`.

### `of`

The `of` method is a static factory method that creates a new instance of the `TokenResponse` record.

| Parameter    | Type   | Description                           |
|--------------|--------|---------------------------------------|
| accessToken  | String | The access token for authentication.  |
| refreshToken | String | The refresh token for obtaining a new access token. |
| expiresAt    | Long   | The expiration time of the access token in milliseconds since epoch. |

| Return Type  | Description                                      |
|--------------|--------------------------------------------------|
| TokenResponse| A new instance of the `TokenResponse` record.    |
