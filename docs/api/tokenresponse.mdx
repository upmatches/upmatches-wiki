# TokenResponse

The `TokenResponse` class is a Java record that encapsulates the response data returned after a successful authentication or token refresh operation. It provides a structured way to transport the access token, refresh token, and expiration timestamp between the authentication service and the client.

## Purpose

This record serves as a Data Transfer Object (DTO) for authentication responses. It bundles three critical pieces of information:
- **Access Token**: The short-lived token used for API authorization
- **Refresh Token**: A longer-lived token used to obtain new access tokens
- **Expires At**: The Unix timestamp (in seconds or milliseconds) when the access token expires

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The JWT or bearer token for API authentication |
| `refreshToken` | `String` | The token used to request new access tokens |
| `expiresAt` | `Long` | Unix timestamp indicating when the access token expires |

## Public Methods

### `of(String accessToken, String refreshToken, Long expiresAt)`

Creates a new `TokenResponse` instance with the specified values.

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The access token string |
| `refreshToken` | `String` | The refresh token string |
| `expiresAt` | `Long` | The expiration timestamp |

**Returns:** `TokenResponse` - A new instance with the provided values.

**Example usage:**
```java
TokenResponse response = TokenResponse.of(
    "eyJhbGciOiJIUzI1NiIs...",
    "dGhpcyBpcyBhIHJlZnJl...",
    1700000000L
);
```

## Notes

- As a Java record, `TokenResponse` automatically provides:
  - Constructor with all components
  - `accessToken()`, `refreshToken()`, and `expiresAt()` accessor methods
  - `equals()`, `hashCode()`, and `toString()` implementations
- The static factory method `of()` provides a convenient way to create instances without using the `new` keyword
- This class is immutable by design, making it safe for use in concurrent environments
