# ICreateNotificationService Interface

The `ICreateNotificationService` interface defines the contract for creating notifications within the UpMatches application. It serves as the abstraction layer for notification creation, ensuring that all implementing services adhere to a consistent method signature for generating notifications.

This interface is declared as a **sealed interface**, meaning it restricts which classes or interfaces can implement it. In this case, only `CreateNotificationService` is permitted to implement this interface, providing controlled extensibility and ensuring that notification creation logic remains centralized.

## Interface Definition

```java
public sealed interface ICreateNotificationService permits CreateNotificationService {
    Notification execute(
        UUID recipientId,
        NotificationType type,
        String title,
        String message,
        String resourceType,
        UUID resourceId);
}
```

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute` | `Notification` | Creates and returns a new notification based on the provided parameters |

## Parameters

The `execute` method accepts the following parameters:

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipientId` | `UUID` | The unique identifier of the user who will receive the notification |
| `type` | `NotificationType` | The category or type of notification (e.g., MATCH, MESSAGE, LIKE) |
| `title` | `String` | The title or subject line of the notification |
| `message` | `String` | The body content of the notification |
| `resourceType` | `String` | The type of resource associated with the notification (e.g., "user", "match", "message") |
| `resourceId` | `UUID` | The unique identifier of the resource related to the notification |

## Return Value

The method returns a `Notification` object representing the newly created notification entity.

## Usage Example

```java
// Assuming you have an instance of CreateNotificationService
ICreateNotificationService notificationService = new CreateNotificationService();

Notification notification = notificationService.execute(
    recipientId,
    NotificationType.MATCH,
    "New Match!",
    "You have a new match with Sarah",
    "user",
    UUID.randomUUID()
);
```

## Implementation Requirements

Any class implementing this interface must:

1. Be named `CreateNotificationService` (as specified by the `permits` clause)
2. Implement the `execute` method with the exact signature shown above
3. Return a valid `Notification` object
4. Handle any necessary validation, persistence, or business logic associated with notification creation

## Related Components

- **Notification**: The entity class representing a notification
- **NotificationType**: Enum defining the various types of notifications
- **CreateNotificationService**: The sole permitted implementation of this interface
