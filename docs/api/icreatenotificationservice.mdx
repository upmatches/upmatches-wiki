## Overview

The `ICreateNotificationService` interface is part of the `com.upmatches.app.features.notification.services` package. It defines a contract for creating notifications within the application. This interface is designed to be implemented by classes that handle the creation of notifications, ensuring a consistent method signature for executing the notification creation process.

## Public Methods

### `execute`

The `execute` method is responsible for creating a notification based on the provided parameters. It returns a `Notification` object that represents the newly created notification.

| Parameter     | Type                          | Description                                      |
|---------------|-------------------------------|--------------------------------------------------|
| `recipientId` | `UUID`                        | The unique identifier of the notification recipient. |
| `type`        | `NotificationType`            | The type of notification to be created.          |
| `title`       | `String`                      | The title of the notification.                   |
| `message`     | `String`                      | The message content of the notification.         |
| `resourceType`| `String`                      | The type of resource associated with the notification. |
| `resourceId`  | `UUID`                        | The unique identifier of the resource associated with the notification. |

#### Return Type

- **`Notification`**: The method returns a `Notification` object representing the created notification.
