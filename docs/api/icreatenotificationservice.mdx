# ICreateNotificationService Interface

The `ICreateNotificationService` is a sealed interface that defines the contract for creating notifications within the UpMatches application. It serves as the abstraction layer for notification creation, ensuring that only the designated implementation (`CreateNotificationService`) can extend this interface.

## Purpose

This interface establishes a standardized method for creating notifications by defining the required parameters that must be provided when a new notification is generated. By using a sealed interface, the application enforces a controlled inheritance hierarchy, preventing unauthorized implementations and maintaining consistency across the notification system.

## Interface Definition

```java
public sealed interface ICreateNotificationService permits CreateNotificationService
```

The interface is sealed to allow only `CreateNotificationService` as its permitted implementation, ensuring that all notification creation logic flows through a single, controlled path.

## Method Summary

### `execute`

Creates and returns a new `Notification` entity based on the provided parameters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipientId` | `UUID` | The unique identifier of the user who will receive the notification |
| `type` | `NotificationType` | The category or type of notification (e.g., MATCH, MESSAGE, SYSTEM) |
| `title` | `String` | The title or subject line of the notification |
| `message` | `String` | The body content of the notification |
| `resourceType` | `String` | The type of resource associated with the notification (e.g., "profile", "message", "event") |
| `resourceId` | `UUID` | The unique identifier of the specific resource triggering the notification |

**Returns:** `Notification` - A fully constructed notification entity ready for persistence

## Usage Example

```java
// Inject the service
private final ICreateNotificationService createNotificationService;

// Create a new notification
Notification notification = createNotificationService.execute(
    recipientId,
    NotificationType.MATCH,
    "New Match!",
    "You have a new match with someone special.",
    "profile",
    profileId
);
```

## Implementation Requirements

Any class implementing this interface must:

1. Accept all six parameters as defined in the method signature
2. Return a valid `Notification` entity
3. Handle any necessary validation or business logic for notification creation
4. Ensure proper association between the notification and its related resource

## Related Components

- **`Notification`** - The entity class representing a notification record
- **`NotificationType`** - Enumeration defining the available notification categories
- **`CreateNotificationService`** - The sole permitted implementation of this interface
