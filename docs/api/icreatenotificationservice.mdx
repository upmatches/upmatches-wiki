# ICreateNotificationService Interface

The `ICreateNotificationService` interface defines the contract for creating notifications within the UpMatches application. It serves as the abstraction layer for notification creation, ensuring that all implementations adhere to a standardized method signature for generating notifications.

This interface is declared as a **sealed interface**, meaning it restricts which classes or interfaces can implement it. In this case, only `CreateNotificationService` is permitted to provide the concrete implementation.

## Interface Declaration

```java
public sealed interface ICreateNotificationService permits CreateNotificationService
```

- **Sealed Interface**: The `sealed` keyword restricts implementation to only the specified class (`CreateNotificationService`). This provides controlled extensibility and ensures that all notification creation logic flows through a single, known implementation.

## Method Summary

| Method | Description |
|--------|-------------|
| `execute` | Creates and returns a new `Notification` object based on the provided parameters. |

## Method Details

### `execute`

```java
Notification execute(
    UUID recipientId,
    NotificationType type,
    String title,
    String message,
    String resourceType,
    UUID resourceId)
```

Creates a new notification with the specified attributes.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipientId` | `UUID` | The unique identifier of the user who will receive the notification. |
| `type` | `NotificationType` | The type of notification (e.g., MATCH, MESSAGE, LIKE). Defined in the `NotificationType` enum. |
| `title` | `String` | A short, descriptive title for the notification. |
| `message` | `String` | The main content or body of the notification. |
| `resourceType` | `String` | The type of resource associated with the notification (e.g., "profile", "message", "event"). |
| `resourceId` | `UUID` | The unique identifier of the resource that triggered the notification. |

**Returns:**

| Return Type | Description |
|-------------|-------------|
| `Notification` | A fully constructed `Notification` entity object ready for persistence or delivery. |

## Implementation Notes

- The sealed interface pattern ensures that only `CreateNotificationService` can implement this contract, providing a single point of control for notification creation logic.
- All parameters are required; no overloaded methods are provided.
- The returned `Notification` object is a fully initialized entity, ready for further processing (e.g., saving to database, sending via push notification).
