# ISingpassKeyProvider Interface

The `ISingpassKeyProvider` interface defines the contract for providing cryptographic keys specifically for Singpass authentication integration. It extends the `SigningKeyProvider` interface and is part of the authentication services layer in the application.

## Purpose

This sealed interface serves as a specialized key provider for Singpass, Singapore's national digital identity platform. It ensures that only authorized implementations (specifically `SingpassKeyProvider`) can provide the required encryption keys and public key material in JWKS (JSON Web Key Set) format.

## Interface Hierarchy

```
SigningKeyProvider (parent interface)
    └── ISingpassKeyProvider (sealed interface)
            └── SingpassKeyProvider (permitted implementation)
```

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getEncryptionKey()` | `ECKey` | Returns the Elliptic Curve (EC) encryption key used for encrypting data in Singpass communications |
| `getPublicJwksJson()` | `String` | Returns the public key material in JSON Web Key Set (JWKS) format as a JSON string |

## Method Details

### `getEncryptionKey()`

- **Return Type**: `com.nimbusds.jose.jwk.ECKey`
- **Description**: Provides the EC encryption key required for cryptographic operations with Singpass. The key is used for encrypting sensitive data during authentication flows.

### `getPublicJwksJson()`

- **Return Type**: `String`
- **Description**: Returns the public keys in JWKS format, which is a standard JSON structure for representing cryptographic keys. This is typically exposed to Singpass for verification purposes.

## Implementation Notes

- The interface is declared as `sealed`, meaning only the explicitly permitted class `SingpassKeyProvider` can implement it
- Extends `SigningKeyProvider`, inheriting any signing-related key methods from the parent interface
- Uses the Nimbus JOSE+JWT library (`com.nimbusds.jose.jwk.ECKey`) for EC key representation
- Part of the `com.upmatches.app.features.auth.services` package
