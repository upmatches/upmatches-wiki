# ISingpassKeyProvider Interface

## Purpose

The `ISingpassKeyProvider` interface defines a contract for providing cryptographic keys specifically for Singpass authentication. It extends the `SigningKeyProvider` interface and is a **sealed interface**, meaning it can only be implemented by the permitted subclass `SingpassKeyProvider`. This interface ensures that any implementation provides both encryption keys and public JWKS (JSON Web Key Set) data for Singpass integration.

## Interface Hierarchy

```
SigningKeyProvider (parent interface)
    └── ISingpassKeyProvider (sealed interface)
            └── SingpassKeyProvider (permitted implementation)
```

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getEncryptionKey()` | `ECKey` | Retrieves the Elliptic Curve (EC) encryption key used for encrypting data in Singpass communications |
| `getPublicJwksJson()` | `String` | Returns the public JSON Web Key Set (JWKS) as a JSON string, which is used for verifying signatures and encrypting data |

## Method Details

### `getEncryptionKey()`

```java
ECKey getEncryptionKey();
```

Returns an `ECKey` object representing the Elliptic Curve encryption key. This key is used for encrypting sensitive data during Singpass authentication flows.

**Returns:**
- `ECKey` - The Elliptic Curve encryption key

### `getPublicJwksJson()`

```java
String getPublicJwksJson();
```

Returns the public JSON Web Key Set (JWKS) as a JSON string. This is used by external systems to verify signatures and encrypt data intended for the Singpass integration.

**Returns:**
- `String` - The public JWKS in JSON format

## Important Notes

- This is a **sealed interface**, which restricts implementation to only the `SingpassKeyProvider` class
- The interface extends `SigningKeyProvider`, inheriting any signing-related methods
- The `ECKey` type comes from the Nimbus JOSE+JWT library (`com.nimbusds.jose.jwk.ECKey`)
- This interface is part of the `com.upmatches.app.features.auth.services` package
