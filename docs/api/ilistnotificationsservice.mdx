# IListNotificationsService

The `IListNotificationsService` interface defines the contract for retrieving a paginated list of notifications within the UpMatches application. It follows a sealed interface pattern to restrict implementation to a single concrete service class, ensuring controlled extensibility and a clear service boundary.

## Purpose

This interface abstracts the operation of fetching notifications with pagination support. By using a sealed interface, the design enforces that only `ListNotificationsService` can implement this contract, which improves maintainability and prevents unintended implementations across the codebase.

## Interface Definition

```java
public sealed interface IListNotificationsService permits ListNotificationsService {

    PagedResponse<NotificationResponse> execute(Pageable pageable);

}
```

## Method Summary

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `execute` | `PagedResponse<NotificationResponse>` | `Pageable pageable` | Retrieves a paginated list of notifications based on the provided pagination information. |

## Parameters

### `execute(Pageable pageable)`

- **pageable** (`org.springframework.data.domain.Pageable`): A Spring Data object that encapsulates pagination and sorting parameters (e.g., page number, page size, sort direction).

## Return Type

- **`PagedResponse<NotificationResponse>`**: A generic wrapper that contains:
  - The list of `NotificationResponse` objects for the current page.
  - Pagination metadata such as total elements, total pages, current page number, and page size.

## Sealed Interface Constraint

The `permits` clause restricts implementation to `ListNotificationsService` only. This ensures:
- Single responsibility: Only one service handles notification listing.
- Compile-time safety: The compiler enforces the implementation restriction.
- Clear architecture: Developers immediately know where to find the implementation.

## Usage Example

```java
@Autowired
private IListNotificationsService listNotificationsService;

public void displayNotifications(int page, int size) {
    Pageable pageable = PageRequest.of(page, size, Sort.by("createdAt").descending());
    PagedResponse<NotificationResponse> response = listNotificationsService.execute(pageable);
    // Process the paginated response
}
```

## Dependencies

## Related Components

- **ListNotificationsService**: The sole permitted implementation of this interface.
- **NotificationResponse**: The DTO representing a single notification.
- **PagedResponse**: Generic pagination wrapper used across the application.
