## Purpose

The `IListNotificationsService` interface is part of the `com.upmatches.app.features.notification.services` package. It defines a contract for services that handle the retrieval of notifications in a paginated format. This interface is sealed, meaning it restricts which classes can implement it, specifically permitting the `ListNotificationsService` class.

## Public Methods

### `execute`

This method is responsible for fetching a paginated list of notifications.

| Method Signature | Description |
|------------------|-------------|
| `PagedResponse<NotificationResponse> execute(Pageable pageable)` | Retrieves a paginated list of notifications based on the provided pagination information. |

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | An object that provides pagination information such as page number and size. |

#### Return Type

| Type | Description |
|------|-------------|
| `PagedResponse<NotificationResponse>` | Returns a paginated response containing a list of `NotificationResponse` objects. |
