## Purpose

The `NotificationController` class is a REST controller in a Spring Boot application that manages notification-related operations. It provides endpoints to list notifications, get the count of unread notifications, mark notifications as read, mark all notifications as read, and delete notifications. This controller interacts with various services to perform these operations and returns appropriate HTTP responses.

## Public Methods

### listNotifications

Retrieves a paginated list of notifications.

| Parameter | Type    | Description                              |
|-----------|---------|------------------------------------------|
| page      | Integer | The page number to retrieve (default 0). |
| size      | Integer | The number of items per page (default 20).|
| request   | HttpServletRequest | The HTTP request object.       |

**Returns:** `ResponseEntity<ApiResponse<PagedResponse<NotificationResponse>>>` - A paginated response containing notifications.

### getUnreadCount

Fetches the count of unread notifications.

| Parameter | Type               | Description            |
|-----------|--------------------|------------------------|
| request   | HttpServletRequest | The HTTP request object.|

**Returns:** `ResponseEntity<ApiResponse<UnreadCountResponse>>` - The count of unread notifications.

### markRead

Marks a specific notification as read.

| Parameter | Type    | Description                  |
|-----------|---------|------------------------------|
| id        | UUID    | The ID of the notification.  |
| request   | HttpServletRequest | The HTTP request object.|

**Returns:** `ResponseEntity<ApiResponse<NotificationResponse>>` - The updated notification marked as read.

### markAllRead

Marks all notifications as read.

| Parameter | Type               | Description            |
|-----------|--------------------|------------------------|
| request   | HttpServletRequest | The HTTP request object.|

**Returns:** `ResponseEntity<ApiResponse<Integer>>` - The number of notifications marked as read.

### deleteNotification

Deletes a specific notification.

| Parameter | Type    | Description                  |
|-----------|---------|------------------------------|
| id        | UUID    | The ID of the notification.  |

**Returns:** `ResponseEntity<Void>` - An empty response indicating successful deletion.
