# Notification Controller

The `NotificationController` class is a REST controller that handles HTTP requests related to user notifications in the UpMatches application. It provides endpoints for listing notifications, retrieving unread counts, marking notifications as read, and deleting notifications.

## Purpose

This controller serves as the API gateway for all notification-related operations. It delegates business logic to dedicated service interfaces, ensuring a clean separation of concerns between the web layer and the application logic.

## Endpoints

### List Notifications

Retrieves a paginated list of notifications for the authenticated user.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/notifications` | Returns a paginated list of notifications |

**Query Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | Integer | 0 | The page number to retrieve (zero-indexed) |
| `size` | Integer | 20 | The number of items per page |

**Response:** `200 OK` with `ApiResponse<PagedResponse<NotificationResponse>>`

### Get Unread Count

Retrieves the count of unread notifications for the authenticated user.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/notifications/unread-count` | Returns the number of unread notifications |

**Response:** `200 OK` with `ApiResponse<UnreadCountResponse>`

### Mark Notification as Read

Marks a specific notification as read.

| Method | Path | Description |
|--------|------|-------------|
| PUT | `/api/v1/notifications/{id}/read` | Marks the specified notification as read |

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | The unique identifier of the notification |

**Response:** `200 OK` with `ApiResponse<NotificationResponse>`

### Mark All Notifications as Read

Marks all notifications for the authenticated user as read.

| Method | Path | Description |
|--------|------|-------------|
| PUT | `/api/v1/notifications/read-all` | Marks all notifications as read |

**Response:** `200 OK` with `ApiResponse<Integer>` (returns the number of updated notifications)

### Delete Notification

Deletes a specific notification.

| Method | Path | Description |
|--------|------|-------------|
| DELETE | `/api/v1/notifications/{id}` | Deletes the specified notification |

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | The unique identifier of the notification |

**Response:** `204 No Content`

## Dependencies

The controller depends on the following service interfaces:

- `IListNotificationsService` - Handles paginated notification retrieval
- `IGetUnreadCountService` - Handles unread count calculation
- `IMarkNotificationReadService` - Handles marking individual notifications as read
- `IMarkAllReadService` - Handles marking all notifications as read
- `IDeleteNotificationService` - Handles notification deletion

## Validation

The controller uses `ValidationHelper.validatePaginationParameters()` to validate pagination parameters before processing list requests.

## Sorting

Notifications are sorted by `createdAt` in descending order by default, ensuring the most recent notifications appear first.
