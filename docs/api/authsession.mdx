## Overview

The `AuthSession` class is a Java record that is part of the `com.upmatches.app.features.auth.models` package. This class is designed to encapsulate authentication session data, which includes a state, nonce, code verifier, and platform. Java records are a special kind of class in Java that are immutable and provide a concise way to model data.

## Public Methods

The `AuthSession` record automatically provides the following public methods for accessing its fields:

| Method          | Parameters | Return Type | Description                                      |
|-----------------|------------|-------------|--------------------------------------------------|
| `state()`       | None       | `String`    | Returns the state associated with the auth session. |
| `nonce()`       | None       | `String`    | Returns the nonce value used in the auth session.  |
| `codeVerifier()`| None       | `String`    | Returns the code verifier for the auth session.    |
| `platform()`    | None       | `String`    | Returns the platform information for the auth session. |

## Purpose

The `AuthSession` class is used to store and manage authentication session details in a structured and immutable way. By using a record, the class benefits from automatic generation of constructor, accessors, `equals()`, `hashCode()`, and `toString()` methods, making it a convenient choice for modeling simple data carriers.
