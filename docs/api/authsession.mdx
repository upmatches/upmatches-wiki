# AuthSession

The `AuthSession` class is a Java record that encapsulates the essential parameters required for an OAuth 2.0 authorization flow. It stores the state, nonce, code verifier, and platform identifier used during the authentication process. This record is immutable and provides a concise way to group these related fields together.

## Purpose

- **State**: A random string used to prevent Cross-Site Request Forgery (CSRF) attacks. The authorization server returns this value, and the client verifies it matches the original request.
- **Nonce**: A random value used to associate a client session with an ID token and to mitigate replay attacks.
- **Code Verifier**: A cryptographically random string used in the PKCE (Proof Key for Code Exchange) flow to securely exchange the authorization code for tokens.
- **Platform**: A string identifying the platform (e.g., "web", "android", "ios") from which the authentication request originated.

## Record Definition

```java

```
