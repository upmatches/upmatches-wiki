## Overview

The `AuthSession` class is a simple data structure used to encapsulate authentication session details within the application. It is implemented as a Java Record, which provides a concise way to model immutable data. This class is part of the `com.upmatches.app.features.auth.models` package.

## Purpose

The purpose of the `AuthSession` class is to store and manage authentication-related information such as the state, nonce, code verifier, and platform. These fields are typically used in authentication flows to ensure security and integrity.

## Public Methods

The `AuthSession` class automatically provides the following public methods due to its nature as a Java Record:

| Method Name   | Parameters | Return Type | Description                                                                 |
|---------------|------------|-------------|-----------------------------------------------------------------------------|
| `state`       | None       | `String`    | Returns the state associated with the authentication session.               |
| `nonce`       | None       | `String`    | Returns the nonce value used in the authentication process.                 |
| `codeVerifier`| None       | `String`    | Returns the code verifier used for PKCE (Proof Key for Code Exchange).      |
| `platform`    | None       | `String`    | Returns the platform information related to the authentication session.     |

Each of these methods corresponds to the fields defined in the `AuthSession` record, providing a straightforward way to access the encapsulated data.
