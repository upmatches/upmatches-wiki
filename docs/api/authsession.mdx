# AuthSession

The `AuthSession` class is a Java record that encapsulates the essential parameters required for managing an OAuth 2.0 authentication flow within the application. It stores the state, nonce, code verifier, and platform identifier used during the authorization process to ensure secure and stateful communication with the authentication provider.

## Purpose

This record serves as a lightweight, immutable data carrier for the transient data needed during the OAuth handshake. By bundling these parameters together, it simplifies passing authentication context between different components of the system (e.g., from the authorization request to the token exchange step). The `state` and `nonce` help prevent CSRF and replay attacks, while the `codeVerifier` is used in the PKCE (Proof Key for Code Exchange) flow. The `platform` field identifies the client platform (e.g., "web", "mobile") for routing or logging purposes.

## Record Components

| Component       | Type     | Description                                                                 |
|-----------------|----------|-----------------------------------------------------------------------------|
| `state`         | `String` | A random string used to maintain state between the request and callback to prevent CSRF attacks. |
| `nonce`         | `String` | A unique value used to associate a client session with an ID token and mitigate replay attacks. |
| `codeVerifier`  | `String` | A cryptographically random string used in the PKCE flow to verify the authorization code exchange. |
| `platform`      | `String` | Identifies the client platform (e.g., "ios", "android", "web") for context-aware processing. |

## Usage Example

```java
// Creating an AuthSession instance
AuthSession session = new AuthSession(
    "xyz123state",
    "abc456nonce",
    "generatedCodeVerifierValue",
    "web"
);

// Accessing fields
String state = session.state();
String nonce = session.nonce();
String codeVerifier = session.codeVerifier();
String platform = session.platform();
```

## Notes

- This record is immutable and thread-safe by design.
- All fields are non-nullable by convention; ensure values are provided during construction.
- The record automatically provides `equals()`, `hashCode()`, and `toString()` methods based on its components.
