# AuthSession

The `AuthSession` class is a Java record that encapsulates the parameters required for an OAuth 2.0 authorization flow. It stores the state, nonce, code verifier, and platform information needed to initiate and validate an authentication request.

## Purpose

This record serves as a lightweight data carrier for session-specific authentication data. It is typically used during the initial phase of an OAuth 2.0 authorization code flow with PKCE (Proof Key for Code Exchange) to maintain state across redirects and prevent CSRF attacks.

## Record Components

| Component      | Type     | Description                                                                 |
|----------------|----------|-----------------------------------------------------------------------------|
| `state`        | `String` | A random value used to maintain state between the request and callback.     |
| `nonce`        | `String` | A random value used to associate a client session with an ID token.         |
| `codeVerifier` | `String` | A cryptographically random string used for PKCE verification.               |
| `platform`     | `String` | The platform identifier (e.g., "web", "android", "ios").                    |

## Constructor

The record provides a canonical constructor that initializes all four fields. Since this is a Java record, the constructor is implicitly defined and cannot be overridden.

```java
public AuthSession(String state, String nonce, String codeVerifier, String platform)
```

## Methods

| Method            | Return Type | Description                                      |
|-------------------|-------------|--------------------------------------------------|
| `state()`         | `String`    | Returns the state value.                         |
| `nonce()`         | `String`    | Returns the nonce value.                         |
| `codeVerifier()`  | `String`    | Returns the code verifier value.                 |
| `platform()`      | `String`    | Returns the platform identifier.                 |
| `toString()`      | `String`    | Returns a string representation of the record.   |
| `equals(Object)`  | `boolean`   | Compares this record to another object.          |
| `hashCode()`      | `int`       | Returns a hash code for this record.             |

## Usage Example

```java
// Create a new AuthSession for a web-based authentication flow
AuthSession session = new AuthSession(
    "xyz123state",
    "abc456nonce",
    "def789codeVerifier",
    "web"
);

// Access individual components
String state = session.state();
String nonce = session.nonce();
String codeVerifier = session.codeVerifier();
String platform = session.platform();
```

## Notes

- This record is immutable by design, making it safe for use in concurrent environments.
- The `platform` field allows the application to differentiate between authentication flows originating from different client types.
- The `state` and `nonce` values should be generated using a cryptographically secure random number generator.
