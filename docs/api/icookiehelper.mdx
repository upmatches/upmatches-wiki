# ICookieHelper Interface

The `ICookieHelper` interface defines a contract for managing authentication cookies in the application. It provides methods for setting, clearing, and retrieving authentication tokens from HTTP cookies, ensuring a standardized approach to cookie-based authentication across the application.

## Interface Declaration

```java
public sealed interface ICookieHelper permits CookieHelper
```

The interface is declared as `sealed`, meaning only the `CookieHelper` class is permitted to implement it. This design pattern ensures controlled inheritance and maintains a single implementation point for cookie management logic.

## TokenData Dependency

The interface relies on the `CookieHelper.TokenData` class, which encapsulates authentication token information. This nested class contains the necessary data for creating authentication cookies.

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `setAuthCookies` | Sets authentication cookies in the HTTP response based on the provided token data and request context | `HttpServletResponse response` - The HTTP response to add cookies to<br/>`HttpServletRequest request` - The current HTTP request for context<br/>`TokenData tokenData` - The authentication token data to store in cookies | `void` |
| `clearAuthCookies` | Removes authentication cookies from the HTTP response, effectively logging out the user | `HttpServletResponse response` - The HTTP response to clear cookies from<br/>`HttpServletRequest request` - The current HTTP request for context | `void` |
| `getRefreshTokenFromCookie` | Extracts the refresh token from the cookies in the HTTP request | `HttpServletRequest request` - The HTTP request containing cookies | `String` - The refresh token value, or `null` if not found |

## Usage Example

```java
// Inject the CookieHelper implementation
private final ICookieHelper cookieHelper;

// Setting authentication cookies
public void login(HttpServletRequest request, HttpServletResponse response, TokenData tokenData) {
    cookieHelper.setAuthCookies(response, request, tokenData);
}

// Clearing authentication cookies (logout)
public void logout(HttpServletRequest request, HttpServletResponse response) {
    cookieHelper.clearAuthCookies(response, request);
}

// Retrieving refresh token
public String getRefreshToken(HttpServletRequest request) {
    return cookieHelper.getRefreshTokenFromCookie(request);
}
```

## Implementation Notes

- The interface uses Jakarta Servlet API classes (`HttpServletRequest` and `HttpServletResponse`), making it suitable for modern Jakarta EE / Spring Boot applications
- The sealed interface pattern ensures that only `CookieHelper` can implement this contract, promoting consistency and maintainability
- Cookie management typically involves setting secure, HttpOnly flags and appropriate expiration times for security
