# ICookieHelper Interface

The `ICookieHelper` interface defines a contract for managing authentication cookies in the UpMatches application. It provides methods for setting, clearing, and retrieving authentication tokens from HTTP cookies, ensuring a standardized approach to cookie-based authentication across the application.

## Interface Declaration

```java
public sealed interface ICookieHelper permits CookieHelper
```

This is a **sealed interface**, meaning only the `CookieHelper` class is permitted to implement it. This design pattern ensures controlled inheritance and maintains a single implementation for cookie management.

## TokenData Dependency

The interface relies on the `TokenData` record from `CookieHelper.TokenData`, which encapsulates authentication token information.

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `setAuthCookies` | Sets authentication cookies in the HTTP response | `HttpServletResponse response` - The HTTP response object<br/>`HttpServletRequest request` - The HTTP request object<br/>`TokenData tokenData` - The authentication token data | `void` |
| `clearAuthCookies` | Removes authentication cookies from the HTTP response | `HttpServletResponse response` - The HTTP response object<br/>`HttpServletRequest request` - The HTTP request object | `void` |
| `getRefreshTokenFromCookie` | Retrieves the refresh token from the request cookies | `HttpServletRequest request` - The HTTP request object | `String` - The refresh token value, or `null` if not found |

## Usage Example

```java
// Inject the cookie helper
private final ICookieHelper cookieHelper;

// Setting authentication cookies
cookieHelper.setAuthCookies(response, request, tokenData);

// Clearing authentication cookies (e.g., on logout)
cookieHelper.clearAuthCookies(response, request);

// Retrieving refresh token from incoming request
String refreshToken = cookieHelper.getRefreshTokenFromCookie(request);
```

## Implementation Notes

- The interface is sealed to restrict implementation to `CookieHelper` only
- All methods work with standard Jakarta Servlet API objects
- The `getRefreshTokenFromCookie` method returns `null` if no refresh token cookie is present
- Cookie operations are performed on the `HttpServletResponse` object, which must be properly configured for the application context

## Related Components

- **CookieHelper** - The sole implementation of this interface
- **TokenData** - The data structure containing authentication token information
- **HttpServletRequest/HttpServletResponse** - Jakarta Servlet API objects for HTTP request/response handling
