## Overview

The `IGameAuthorizationService` is a sealed interface in the `com.upmatches.app.features.game.services` package. It defines a set of methods for handling authorization logic related to game operations. This interface ensures that only authorized users can perform specific actions on game entities, such as viewing, organizing, joining, and modifying games. The interface is implemented by the `GameAuthorizationService` class.

## Public Methods

The following table documents the public methods available in the `IGameAuthorizationService` interface:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `assertCanViewGame` | `Game game`, `UUID userId` | `void` | Ensures that the user with the specified `userId` has permission to view the given `game`. |
| `assertIsOrganizer` | `Game game`, `UUID userId` | `void` | Verifies that the user with the specified `userId` is the organizer of the given `game`. |
| `assertGameJoinable` | `UUID id`, `Game game` | `void` | Checks if the game identified by `id` is joinable. |
| `assertPrivateAccess` | `UUID id`, `UUID userId`, `Game game` | `void` | Ensures that the user with the specified `userId` has private access to the game identified by `id`. |
| `assertNotAlreadyJoined` | `UUID id`, `UUID userId` | `void` | Confirms that the user with the specified `userId` has not already joined the game identified by `id`. |
| `assertVisibilityUnchanged` | `UUID id`, `Game game`, `UpdateGameRequest request` | `void` | Ensures that the visibility of the game identified by `id` remains unchanged according to the `request`. |
| `assertSlotsAboveActive` | `UUID id`, `Integer newSlots`, `long activeCount` | `void` | Validates that the number of new slots for the game identified by `id` is above the current active count. |
| `assertImmutableFields` | `UUID id`, `Game game`, `UpdateGameRequest request`, `long activeCount` | `void` | Ensures that certain immutable fields of the game identified by `id` are not altered according to the `request`. |

This interface is crucial for maintaining the integrity and security of game-related operations by enforcing authorization checks.
