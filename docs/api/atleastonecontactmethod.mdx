## Purpose

The `AtLeastOneContactMethod` annotation is a custom validation annotation used in Java applications to ensure that at least one contact method is provided. This annotation can be applied to fields within a class to enforce that the field meets the specified validation criteria. It is part of the `com.upmatches.app.features.user.validators` package and relies on the `AtLeastOneContactMethodValidator` class to perform the actual validation logic.

## Public Methods

The `AtLeastOneContactMethod` annotation provides the following public methods:

| Method Signature | Description |
|------------------|-------------|
| `String message() default AtLeastOneContactMethodValidator.DEFAULT_VALIDATION_MESSAGE;` | Returns the default validation message that will be used if the validation fails. |
| `Class<?>[] groups() default { };` | Allows the specification of validation groups, which can be used to restrict the set of constraints applied during validation. |
| `Class<? extends Payload>[] payload() default { };` | Can be used by clients of the Bean Validation API to assign custom payload objects to a constraint. |

## Usage

To use the `AtLeastOneContactMethod` annotation, apply it to a field within a class where you want to ensure that at least one contact method is provided. The annotation will trigger the associated validator to check the field's value and enforce the validation rule.
