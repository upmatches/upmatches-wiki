# AtLeastOneContactMethod

The `AtLeastOneContactMethod` annotation is a custom Jakarta Bean Validation constraint used to ensure that at least one contact method (e.g., email, phone number) is provided for a user entity. This annotation is applied at the field level and leverages the `AtLeastOneContactMethodValidator` class to perform the actual validation logic.

## Purpose

In user registration or profile update scenarios, it is often required that a user provides at least one way to be contacted. This annotation enforces that business rule by validating that the annotated field (typically a collection or composite object) contains at least one non-null, non-empty contact method.

## Usage

Apply this annotation to a field that represents a user's contact methods. The field should be of a type that can hold multiple contact options, such as a `List`, `Set`, or a custom object with multiple contact fields.

```java
@AtLeastOneContactMethod
private List<ContactMethod> contactMethods;
```

## Annotation Attributes

| Attribute | Type | Default | Description |
|-----------|------|---------|-------------|
| `message` | `String` | `AtLeastOneContactMethodValidator.DEFAULT_VALIDATION_MESSAGE` | The error message to be returned when validation fails. |
| `groups` | `Class<?>[]` | `{}` | Allows specifying validation groups for selective validation. |
| `payload` | `Class<? extends Payload>[]` | `{}` | Used by clients to assign custom payload objects to a constraint. |

## Validation Logic

The actual validation is performed by the `AtLeastOneContactMethodValidator` class. This validator checks whether the annotated field contains at least one valid contact method. The default validation message is defined in the validator class.

## Example

```java
import com.upmatches.app.features.user.validators.AtLeastOneContactMethod;

public class UserProfile {
    @AtLeastOneContactMethod
    private List<ContactMethod> contactMethods;

    // getters and setters
}
```

## Dependencies

- Jakarta Bean Validation API (`jakarta.validation`)
- Custom validator class: `AtLeastOneContactMethodValidator`

## Notes

- This annotation is retained at runtime (`RetentionPolicy.RUNTIME`) for reflection-based validation.
- It targets fields only (`ElementType.FIELD`).
- The annotation is documented (`@Documented`) to appear in generated JavaDoc.
