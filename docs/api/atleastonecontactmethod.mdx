# AtLeastOneContactMethod

The `AtLeastOneContactMethod` annotation is a custom Jakarta Bean Validation constraint that ensures at least one contact method is provided for a user. It is designed to be applied to fields that represent a collection or set of contact methods, validating that the collection is not empty.

## Purpose

This annotation addresses the common requirement in user registration and profile management systems where a user must provide at least one way to be contacted (e.g., email, phone number, or messaging handle). By enforcing this rule at the validation layer, it prevents incomplete user profiles from being persisted to the database.

## Usage

Apply this annotation to any field that holds a collection of contact methods:

```java
@AtLeastOneContactMethod
private Set<ContactMethod> contactMethods;
```

## Annotation Elements

| Element | Type | Default | Description |
|---------|------|---------|-------------|
| `message` | `String` | `AtLeastOneContactMethodValidator.DEFAULT_VALIDATION_MESSAGE` | The error message to display when validation fails. The default message is defined in the validator class. |
| `groups` | `Class<?>[]` | `{}` | Allows specifying validation groups for partial validation scenarios. |
| `payload` | `Class<? extends Payload>[]` | `{}` | Used by Bean Validation clients to associate metadata with a constraint declaration. |

## Validation Behavior

The annotation delegates validation to the `AtLeastOneContactMethodValidator` class. The validator checks that the annotated field:

1. Is not `null`
2. Contains at least one element

If either condition is not met, the validation fails and the specified error message is returned.

## Example

```java
public class UserRegistrationRequest {
    
    @NotBlank(message = "Name is required")
    private String name;
    
    @AtLeastOneContactMethod
    private List<@Valid ContactMethod> contactMethods;
    
    // getters and setters
}
```

## Dependencies

This annotation requires:
- Jakarta Bean Validation API (e.g., `jakarta.validation-api`)
- A Bean Validation implementation (e.g., Hibernate Validator)
