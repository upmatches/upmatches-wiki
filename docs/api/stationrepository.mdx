import com.upmatches.app.features.venue.entities.Station;
import org.springframework.data.jpa.repository.JpaRepository;

## Purpose

The `StationRepository` interface is a part of the repository layer in the application, responsible for data access related to `Station` entities. It extends the `JpaRepository` interface provided by Spring Data JPA, which offers CRUD operations and additional JPA-related methods for the `Station` entity. This interface allows for interaction with the database to perform operations such as finding, saving, and deleting `Station` records.

## Public Methods

The `StationRepository` interface includes the following public method:

| Method Signature                        | Description                                                                 |
|-----------------------------------------|-----------------------------------------------------------------------------|
| `Optional<Station> findByName(String name)` | Retrieves an `Optional` containing a `Station` entity that matches the given name. If no station is found, an empty `Optional` is returned. |

### Method Details

#### `findByName`

- **Parameters:**

  | Name  | Type   | Description                  |
  |-------|--------|------------------------------|
  | name  | String | The name of the station to find. |

- **Returns:**  
  An `Optional<Station>` which contains the `Station` entity if found, otherwise an empty `Optional`.
