# StationRepository

The `StationRepository` interface provides data access operations for the `Station` entity. It extends Spring Data JPA's `JpaRepository`, inheriting standard CRUD (Create, Read, Update, Delete) functionality while adding a custom query method for retrieving stations by name.

## Purpose

This repository serves as the persistence layer for `Station` entities within the venue management feature of the application. By extending `JpaRepository<Station, Long>`, it automatically provides methods for saving, finding, updating, and deleting `Station` records in the database, where the primary key is of type `Long`.

## Methods

### Inherited Methods from JpaRepository

The following standard CRUD methods are inherited from `JpaRepository<Station, Long>`:

| Method | Description |
|--------|-------------|
| `List<Station> findAll()` | Retrieves all station records |
| `Optional<Station> findById(Long id)` | Finds a station by its primary key |
| `Station save(Station entity)` | Saves or updates a station record |
| `void deleteById(Long id)` | Deletes a station by its primary key |
| `void delete(Station entity)` | Deletes a specific station record |
| `long count()` | Returns the total number of station records |
| `boolean existsById(Long id)` | Checks if a station exists with the given primary key |

### Custom Methods

#### `findByName(String name)`

Finds a station by its exact name.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The name of the station to search for |

**Returns:** `Optional<Station>` - An Optional containing the found station, or an empty Optional if no station with the given name exists.

**Example usage:**
```java
Optional<Station> station = stationRepository.findByName("Central Station");
if (station.isPresent()) {
    // Process the found station
} else {
    // Handle case where station was not found
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` interface and automatic query implementation
- **Station entity**: The domain object this repository manages
- **Java Optional**: Used for null-safe return values
