# StationRepository

The `StationRepository` interface provides database access operations for the `Station` entity. It extends Spring Data JPA's `JpaRepository`, inheriting standard CRUD functionality while adding a custom query method for looking up stations by name.

## Purpose

This repository serves as the data access layer for station entities in the venue management feature. By extending `JpaRepository<Station, Long>`, it automatically provides methods for:
- Saving, updating, and deleting station records
- Finding stations by their primary key (Long ID)
- Pagination and sorting support

## Custom Query Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `findByName(String name)` | `Optional<Station>` | Retrieves a station by its exact name. Returns an empty `Optional` if no station with the given name exists. |

## Inherited Methods

As a subinterface of `JpaRepository`, this repository inherits all standard CRUD operations:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all station records |
| `findById(Long id)` | Finds a station by its primary key |
| `save(Station entity)` | Persists a new station or updates an existing one |
| `delete(Station entity)` | Removes a station record |
| `deleteById(Long id)` | Deletes a station by its ID |
| `count()` | Returns the total number of station records |

## Usage Example

```java
@Service
public class StationService {
    private final StationRepository stationRepository;
    
    public StationService(StationRepository stationRepository) {
        this.stationRepository = stationRepository;
    }
    
    public Optional<Station> findStationByName(String name) {
        return stationRepository.findByName(name);
    }
}
```

## Dependencies

- Spring Data JPA
- Station entity class (from `com.upmatches.app.features.venue.entities`)
