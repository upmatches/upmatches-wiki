# SecurityConfiguration

The `SecurityConfiguration` class is a Spring Security configuration component that defines the security rules, JWT authentication, CORS policies, and bearer token resolution for the application. It is annotated with `@Configuration` and `@EnableWebSecurity` to integrate with Spring Security's auto-configuration.

## Purpose

This class configures the following security aspects:

- **HTTP Security**: Defines which endpoints are public (permit all) and which require authentication.
- **JWT Decoding**: Configures a `JwtDecoder` using ES256 algorithm and a provided signing key.
- **Bearer Token Resolution**: Implements a fallback mechanism that first checks the `Authorization` header, then falls back to a cookie named `accessToken`.
- **CORS Configuration**: Allows cross-origin requests from configurable origins, with support for credentials.

## Public Methods

### `securityFilterChain(HttpSecurity http)`

Configures the HTTP security filter chain.

| Parameter | Type | Description |
|-----------|------|-------------|
| `http` | `HttpSecurity` | The Spring Security HTTP security object to configure. |

**Returns**: `SecurityFilterChain` - The built security filter chain.

**Behavior**:
- Disables CSRF protection.
- Enables CORS with default settings.
- Sets session management to stateless.
- Defines a comprehensive set of public endpoints (see table below).
- All other requests require authentication.
- Configures OAuth2 resource server with JWT and custom bearer token resolver.

**Public Endpoints**:

| Pattern | HTTP Method | Description |
|---------|-------------|-------------|
| `/actuator/**` | All | Actuator endpoints |
| `/v3/api-docs/**` | All | OpenAPI documentation |

| `/api/v1/auth/refresh` | All | Token refresh |
| `/api/v1/auth/logout` | All | Logout |
| `/api/v1/auth/dev/**` | All | Development auth endpoints |
| `/internal/dev/**` | All | Internal development endpoints |

### `jwtDecoder(ISingpassKeyProvider keyProvider)`

Creates a JWT decoder using the Singpass key provider.

| Parameter | Type | Description |
|-----------|------|-------------|
| `keyProvider` | `ISingpassKeyProvider` | Provider for the signing key used to verify JWTs. |

**Returns**: `JwtDecoder` - A Nimbus-based JWT decoder configured with ES256 algorithm.

**Behavior**:
- Retrieves the public key from the `keyProvider`.
- Creates a `JWKSet` from the public key.
- Configures a `DefaultJWTProcessor` with a `JWSVerificationKeySelector` using ES256 algorithm.
- Returns a `NimbusJwtDecoder` wrapping the processor.

### `cookieFallbackBearerTokenResolver()`

Creates a bearer token resolver that checks the `Authorization` header first, then falls back to a cookie.

**Returns**: `BearerTokenResolver` - A custom resolver that extracts the token from either the header or cookie.

**Behavior**:
- Checks the `Authorization` header for a `Bearer` token.
- If not found, checks cookies for an `accessToken` cookie.
- Returns `null` if neither source contains a token.

### `corsConfigurationSource(String allowedOrigins)`

Configures CORS settings from application properties.

| Parameter | Type | Description |
|-----------|------|-------------|
| `allowedOrigins` | `String` | Semicolon-separated list of allowed origins (default: `http://localhost:3002`). |

**Returns**: `CorsConfigurationSource` - A URL-based CORS configuration source.

**Behavior**:
- Splits the `allowedOrigins` string by semicolons to support multiple origins.
- Allows all HTTP methods and headers.
- Enables credentials (cookies, authorization headers).
- Applies the configuration to all paths (`/**`).

## Constants

The class defines several private constants used for URL patterns and configuration values:

| Constant | Value | Description |
|----------|-------|-------------|
| `BEARER_PREFIX_LENGTH` | `7` | Length of "Bearer " prefix |
| `BEARER_PREFIX` | `"Bearer "` | Bearer token prefix |
| `ACCESS_TOKEN_COOKIE` | `"accessToken"` | Cookie name for access token |
| `ORIGINS_DELIMITER` | `";"` | Delimiter for allowed origins |
| `WILDCARD` | `"*"` | Wildcard character |
| `ALL_PATHS_PATTERN` | `"/**"` | Pattern for all paths |

## Dependencies

- **Spring Security**: For security filter chain, CORS, and OAuth2 resource server.
- **Nimbus JOSE + JWT**: For JWT processing and verification.
- **Singpass Key Provider**: Custom interface `ISingpassKeyProvider` for obtaining the signing key.
