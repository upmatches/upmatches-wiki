# Security Configuration

The `SecurityConfiguration` class is a Spring Security configuration that sets up authentication, authorization, CORS, and JWT decoding for the application. It defines which endpoints are publicly accessible, configures stateless session management, and implements a custom bearer token resolver that can extract JWT tokens from either the `Authorization` header or a cookie named `accessToken`.

## Beans

### `securityFilterChain`

Configures the main security filter chain for the application.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `http` | `HttpSecurity` | The HTTP security configuration object |

**Returns:** `SecurityFilterChain`

**Configuration:**
- Disables CSRF protection
- Enables CORS with default configuration
- Sets session management to stateless
- Configures authorization rules (see Public Endpoints table)
- Enables OAuth2 resource server with JWT support
- Uses custom bearer token resolver with cookie fallback

### `jwtDecoder`

Creates a JWT decoder that verifies tokens using the Singpass signing key.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `keyProvider` | `ISingpassKeyProvider` | Provider for the Singpass signing key |

**Returns:** `JwtDecoder`

**Implementation:**
- Creates a `JWKSet` from the public key obtained from the `ISingpassKeyProvider`
- Configures a `JWSVerificationKeySelector` using the ES256 algorithm
- Creates a `DefaultJWTProcessor` with the key selector
- Returns a `NimbusJwtDecoder` wrapping the processor

### `cookieFallbackBearerTokenResolver`

Creates a custom bearer token resolver that first checks the `Authorization` header for a Bearer token, and if not found, falls back to checking cookies for an `accessToken` cookie.

**Returns:** `BearerTokenResolver`

**Behavior:**
1. Checks the `Authorization` header for a token starting with `Bearer `
2. If found, extracts and returns the token (removing the `Bearer ` prefix)
3. If not found, checks cookies for one named `accessToken`
4. Returns the cookie value if found, otherwise returns `null`

### `corsConfigurationSource`

Configures CORS settings for the application.

**Parameters:**

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| `allowedOrigins` | `String` | Semicolon-separated list of allowed origins | `http://localhost:3002` |

**Returns:** `CorsConfigurationSource`

**Configuration:**
- Parses the `allowedOrigins` string by splitting on semicolons
- Allows all HTTP methods (`*`)
- Allows all headers (`*`)
- Enables credentials (cookies, authorization headers)
- Applies configuration to all paths (`/**`)
