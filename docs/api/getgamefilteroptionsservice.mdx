# GetGameFilterOptionsService

## Purpose

The `GetGameFilterOptionsService` class is a Spring service that retrieves and aggregates distinct filter options (venues, skill levels, start times, and game types) from a set of games matching the provided filter criteria. It is designed to populate filter dropdowns or selection UI components in a game discovery application.

The service performs a read-only transactional query against the `GameRepository`, applying optional filters such as date range, time range, location (with bounding box computation), venue IDs, skill level IDs, and game type. It then extracts distinct values from the resulting game list and returns them as structured response objects.

## Public Methods

### `execute(GameFilterOptionsRequest filter)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `filter` | `GameFilterOptionsRequest` | The filter criteria including date range, time range, location, venues, skill levels, and game type |

| Returns | Type | Description |
|---------|------|-------------|
| `GameFilterOptionsResponse` | Object | Contains distinct lists of venues, skill levels, start times, and game types derived from matching games |

**Description:**  
Executes the filter options retrieval process. Validates cross-field constraints, runs the database query, and aggregates distinct values from the result set. Throws `ResourceNotFoundException` if no games match the criteria.

**Validation Rules:**
- If any location field is provided, all three (latitude, longitude, radiusKm) must be present
- `toDate` must be on or after `fromDate`
- Date range must not exceed 90 days
- `skillLevelIds` must contain at most 20 entries

## Internal Methods

### `runQuery(UUID userId, GameFilterOptionsRequest f)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | Optional authenticated user ID for visibility filtering |
| `f` | `GameFilterOptionsRequest` | The validated filter request |

| Returns | Type | Description |
|---------|------|-------------|
| `List<Game>` | List | Up to 500 games matching the filter criteria |

**Description:**  
Converts the filter request parameters into database query parameters and calls `gameRepository.findVisibleForFilterOptions()`. Computes a bounding box if location filtering is enabled.

### `distinctVenues(List<Game> games)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to extract venues from |

| Returns | Type | Description |
|---------|------|-------------|
| `List<VenueResponse>` | List | Distinct venues in insertion order |

**Description:**  
Extracts unique venues from the game list, preserving the order of first appearance.

### `distinctSkillLevels(List<Game> games)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to extract skill levels from |

| Returns | Type | Description |
|---------|------|-------------|
| `List<SkillLevelResponse>` | List | Distinct skill levels sorted by sort order |

**Description:**  
Collects both `skillLevelFrom` and `skillLevelTo` from each game, deduplicates them, and sorts by their defined sort order.

### `distinctStartTimes(List<Game> games)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to extract start times from |

| Returns | Type | Description |
|---------|------|-------------|
| `List<String>` | List | Distinct start times formatted as "HH:mm" and sorted alphabetically |

**Description:**  
Converts game start times to Singapore timezone (SGT), formats them as "HH:mm", and returns distinct sorted values.

### `distinctGameTypes(List<Game> games)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to extract game types from |

| Returns | Type | Description |
|---------|------|-------------|
| `List<GameType>` | List | Distinct game types sorted naturally |

**Description:**  
Extracts unique game type enum values from the game list.

### `toMinutes(LocalTime time)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `time` | `LocalTime` | Time to convert (nullable) |

| Returns | Type | Description |
|---------|------|-------------|
| `Integer` | Integer | Total minutes since midnight, or `null` if input is null |

**Description:**  
Converts a `LocalTime` to total minutes for database query compatibility.

### `validateCrossFields(GameFilterOptionsRequest f)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `f` | `GameFilterOptionsRequest` | The filter request to validate |

| Throws | Condition |
|--------|-----------|
| `IllegalArgumentException` | If cross-field validation fails |

**Description:**  
Validates interdependent field constraints as described in the `execute()` method documentation.

### `computeBoundingBox(GameFilterOptionsRequest f)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `f` | `GameFilterOptionsRequest` | The filter request containing location data |

| Returns | Type | Description |
|---------|------|-------------|
| `BoundingBox` | Record | Latitude and longitude min/max values |

**Description:**  
Computes a geographic bounding box from a center point (latitude/longitude) and radius in kilometers. Uses the Haversine approximation with latitude-dependent longitude scaling.

## Usage Example

```java
@Autowired
private GetGameFilterOptionsService filterOptionsService;

public void demonstrate() {
    GameFilterOptionsRequest request = GameFilterOptionsRequest.builder()
        .fromDate(LocalDate.now())
        .toDate(LocalDate.now().plusDays(7))
        .build();
    
    GameFilterOptionsResponse response = filterOptionsService.execute(request);
    
    List<VenueResponse> venues = response.venues();
    List<SkillLevelResponse> skillLevels = response.skillLevels();
    List<String> startTimes = response.startTimes();
    List<GameType> gameTypes = response.gameTypes();
}
```
