# GetGameFilterOptionsService

## Purpose

The `GetGameFilterOptionsService` class is a Spring service that retrieves and returns available filter options for games based on a given set of criteria. It is designed to support a game discovery or search feature, allowing users to narrow down games by venue, skill level, start time, and game type.

The service performs a database query using the provided filters (date range, time range, location, skill levels, venues, game type) and returns a `GameFilterOptionsResponse` containing distinct lists of venues, skill levels, start times, and game types that match the filtered game set.

## Key Features

- **Location-based filtering**: Computes a bounding box from latitude, longitude, and radius to filter games within a geographic area.
- **Date and time range filtering**: Supports filtering games within a specified date range (up to 90 days) and time range.
- **Skill level and venue filtering**: Allows filtering by specific skill levels and venues.
- **Game type filtering**: Supports filtering by game type.
- **Validation**: Enforces cross-field validation rules (e.g., location fields must be provided together, date range limits, skill level count limits).
- **Performance**: Limits the number of games sampled to 500 for performance reasons.

## Public Methods

### `execute`

```java
@Transactional(readOnly = true)
public GameFilterOptionsResponse execute(GameFilterOptionsRequest filter)
```

Executes the filter options retrieval process.

| Parameter | Type | Description |
|-----------|------|-------------|
| `filter` | `GameFilterOptionsRequest` | The filter criteria including date range, time range, location, skill levels, venues, and game type. |

| Returns | Description |
|---------|-------------|
| `GameFilterOptionsResponse` | Contains distinct lists of venues, skill levels, start times, and game types that match the filtered game set. |

**Throws:**
- `IllegalArgumentException` if validation fails (e.g., missing location fields, invalid date range, too many skill levels).
- `ResourceNotFoundException` if no games match the filter criteria.

## Internal Record

### `BoundingBox`

```java

```

Represents a geographic bounding box.

| Field | Type | Description |
|-------|------|-------------|
| `latMin` | `BigDecimal` | Minimum latitude (may be null for empty box). |
| `latMax` | `BigDecimal` | Maximum latitude (may be null for empty box). |
| `lngMin` | `BigDecimal` | Minimum longitude (may be null for empty box). |
| `lngMax` | `BigDecimal` | Maximum longitude (may be null for empty box). |

**Static Methods:**
- `empty()`: Returns an empty bounding box (all fields null).
