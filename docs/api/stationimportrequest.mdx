# StationImportRequest

The `StationImportRequest` class is a Java record used to represent the data required for importing a station into the system. It serves as a Data Transfer Object (DTO) for receiving station import requests via REST APIs, ensuring that the incoming data is validated before processing.

## Purpose

This record encapsulates the essential fields needed to create or update a station entry, including its unique code, display name, color, and geographic coordinates. It leverages Jakarta Bean Validation annotations to enforce data integrity at the API boundary.

## Record Definition

```java
public record StationImportRequest(
    @NotBlank @Size(max = 50) String code,
    @NotBlank @Size(max = 150) String name,
    @NotBlank @Size(max = 7) String color,
    @NotNull BigDecimal latitude,
    @NotNull BigDecimal longitude
) {}
```

## Fields

| Field       | Type        | Validation Constraints                | Description                                                                 |
|-------------|-------------|---------------------------------------|-----------------------------------------------------------------------------|
| `code`      | `String`    | `@NotBlank`, `@Size(max = 50)`        | A unique identifier for the station (e.g., "STN-001"). Must not be blank.   |
| `name`      | `String`    | `@NotBlank`, `@Size(max = 150)`       | The human-readable name of the station (e.g., "Central Station").           |
| `color`     | `String`    | `@NotBlank`, `@Size(max = 7)`         | A color code for the station (e.g., "#FF5733"). Typically a hex color.      |
| `latitude`  | `BigDecimal`| `@NotNull`                            | The latitude coordinate of the station (e.g., 40.7128).                     |
| `longitude` | `BigDecimal`| `@NotNull`                            | The longitude coordinate of the station (e.g., -74.0060).                   |

## Usage Example

```java
// Creating a new station import request
StationImportRequest request = new StationImportRequest(
    "STN-001",
    "Central Station",
    "#FF5733",
    new BigDecimal("40.7128"),
    new BigDecimal("-74.0060")
);
```

## Validation Behavior

- **`@NotBlank`**: Ensures the string field is not `null` and contains at least one non-whitespace character.
- **`@Size(max = ...)`**: Restricts the maximum length of the string field.
- **`@NotNull`**: Ensures the `BigDecimal` field is not `null`.

If validation fails, a `ConstraintViolationException` is thrown, typically resulting in a `400 Bad Request` HTTP response when used in a Spring Boot controller.
