## Purpose

The `StationImportRequest` class is a Java record used to represent the data required for importing a station into the system. It serves as a Data Transfer Object (DTO) for incoming station import requests, ensuring that the provided data meets basic validation constraints before being processed.

## Record Definition

This record is defined with five components, each representing a field of the station import request. The record automatically generates a constructor, getter methods, `equals()`, `hashCode()`, and `toString()` methods.

## Fields

| Field | Type | Validation Constraints | Description |
|-------|------|------------------------|-------------|
| `code` | `String` | `@NotBlank`, `@Size(max = 50)` | A unique identifier code for the station, up to 50 characters. |
| `name` | `String` | `@NotBlank`, `@Size(max = 150)` | The name of the station, up to 150 characters. |
| `color` | `String` | `@NotBlank`, `@Size(max = 7)` | A color code associated with the station (e.g., hex color), up to 7 characters. |
| `latitude` | `BigDecimal` | `@NotNull` | The latitude coordinate of the station. |
| `longitude` | `BigDecimal` | `@NotNull` | The longitude coordinate of the station. |

## Validation

The record uses Jakarta Bean Validation annotations to enforce data integrity:

- **`@NotBlank`**: Ensures that `String` fields are not null and contain at least one non-whitespace character.
- **`@NotNull`**: Ensures that `BigDecimal` fields are not null.
- **`@Size(max = ...)`**: Restricts the maximum length of `String` fields.

## Usage

This record is typically used in REST API endpoints to receive station import data from clients. For example:

```java
@PostMapping("/import")
public ResponseEntity<Void> importStation(@Valid @RequestBody StationImportRequest request) {
    // Process the import request
}
```

The record is located in the package `com.upmatches.app.features.venue.requests`.
