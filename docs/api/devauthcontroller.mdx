# DevAuthController

The `DevAuthController` is a development-only REST controller that provides an endpoint for minting authentication tokens during local development and testing. It is designed to be **disabled in production** environments and only accessible from localhost connections.

## Purpose

This controller serves as a convenience utility for developers to quickly generate authentication tokens without going through the full authentication flow. It is particularly useful for:

- Local development and debugging
- Integration testing
- API testing with tools like Postman or cURL
- Frontend development that requires authenticated API access

## Security Constraints

The controller enforces strict security measures:

- **Profile Restriction**: Only active when the Spring profile is NOT `prod`
- **Conditional Property**: Requires the property `app.auth.dev.mint-endpoint-enabled=true` to be set
- **Host Restriction**: Only accepts requests from localhost (IPv4 and IPv6)

## Endpoints

### POST `/api/v1/auth/dev/tokens`

Mints a new development authentication token for the specified user.

#### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `userId` | String | Yes | The unique identifier of the user to mint a token for |

#### Response

| Status Code | Description |
|-------------|-------------|
| 200 OK | Token minted successfully |
| 400 Bad Request | Invalid request body (validation error) |
| 403 Forbidden | Request from non-localhost host |
| 500 Internal Server Error | Token minting service failure |

#### Example Request

```json
{
  "userId": "user-12345"
}
```

#### Example Response

```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expiresAt": "2024-12-31T23:59:59Z"
  },
  "message": "Dev token minted successfully.",
  "path": "/api/v1/auth/dev/tokens"
}
```

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IMintDevTokenService` | Service | Interface for token minting logic |
| `MintDevTokenRequest` | DTO | Request validation object |
| `TokenResponse` | DTO | Token response data |
| `ApiResponse` | Utility | Standard API response wrapper |

## Configuration

To enable this controller, add the following to your application properties:

```properties
# Enable dev token minting endpoint
app.auth.dev.mint-endpoint-enabled=true
```

## Error Handling

The controller throws an `AuthenticationException` when a request originates from a non-localhost host. This exception should be handled by a global exception handler to return an appropriate HTTP 403 response.

## Usage Example

```bash
# Mint a token for user "dev-user-1"
curl -X POST http://localhost:8080/api/v1/auth/dev/tokens \
  -H "Content-Type: application/json" \
  -d '{"userId": "dev-user-1"}'
```

## Notes

- This endpoint should **never** be exposed in production environments
- The host restriction check is case-insensitive
- The controller uses constructor injection for its service dependency
- All validation is handled by Jakarta Bean Validation annotations on the request body
