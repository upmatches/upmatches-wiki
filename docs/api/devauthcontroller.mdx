# DevAuthController

The `DevAuthController` is a development-only REST controller that provides an endpoint for minting authentication tokens for testing and development purposes. It is designed to be **disabled in production** environments and only accessible from localhost.

## Purpose

This controller allows developers to generate authentication tokens without going through the standard authentication flow. It is particularly useful for:

- Local development and testing
- Integration testing with automated test suites
- API development and debugging

## Security Constraints

The controller enforces strict security measures:

- **Profile Restriction**: Only active when the Spring profile is NOT `prod`
- **Property Gate**: Requires `app.auth.dev.mint-endpoint-enabled=true` in application properties
- **Host Restriction**: Only accepts requests from localhost (127.0.0.1, [::1], or hostname "localhost")

## Endpoints

### POST `/api/v1/auth/dev/tokens`

Mints a new development authentication token for a specified user.

#### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `userId` | String | Yes | The unique identifier of the user to generate a token for |

#### Response

| Status Code | Description |
|-------------|-------------|
| 200 OK | Token minted successfully |
| 400 Bad Request | Invalid request body (validation error) |
| 403 Forbidden | Request not from localhost |
| 500 Internal Server Error | Token minting service failure |

#### Response Body

```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expiresAt": "2024-01-01T00:00:00Z"
  },
  "message": "Dev token minted successfully.",
  "path": "/api/v1/auth/dev/tokens"
}
```

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IMintDevTokenService` | Service | Interface for token minting logic |
| `MintDevTokenRequest` | DTO | Request validation object |
| `TokenResponse` | DTO | Token response data |
| `ApiResponse` | Utility | Standard API response wrapper |

## Usage Example

```java
// Example request
POST /api/v1/auth/dev/tokens
Content-Type: application/json

{
  "userId": "user-123-abc"
}

// Example response
HTTP/1.1 200 OK
Content-Type: application/json

{
  "success": true,
  "data": {
    "token": "dev-token-xyz-789",
    "expiresAt": "2024-12-31T23:59:59Z"
  },
  "message": "Dev token minted successfully.",
  "path": "/api/v1/auth/dev/tokens"
}
```

## Configuration

To enable this controller, add the following to your `application-dev.yml` or `application-local.yml`:

```yaml
app:
  auth:
    dev:
      mint-endpoint-enabled: true
```

## Error Handling

| Error Scenario | HTTP Status | Error Message |
|----------------|-------------|---------------|
| Non-localhost request | 403 Forbidden | "Dev token endpoint is not reachable from host '192.168.1.1'" |
| Invalid request body | 400 Bad Request | Validation error details |
| Service failure | 500 Internal Server Error | Internal error details |

## Notes

- This controller should **never** be enabled in production environments
- The `@Profile("!prod")` annotation ensures it's automatically disabled when the `prod` profile is active
- The `@ConditionalOnProperty` annotation provides an additional safety layer
- Tokens generated through this endpoint may have different properties than production tokens (e.g., longer expiration, elevated permissions)
