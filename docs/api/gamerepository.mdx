## Purpose

The `GameRepository` interface is a part of the data access layer in a Spring application, responsible for managing `Game` entities. It extends the `JpaRepository` interface, providing CRUD operations and custom queries to interact with the `Game` database table. This repository supports operations such as finding games by various criteria, updating game statuses, and counting games based on user participation.

## Public Methods

Below is a detailed description of the public methods available in the `GameRepository` interface:

### Methods

| Method Name                          | Parameters                                                                                                                                                                                                                                           | Return Type          | Description                                                                                           |
|--------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------|-------------------------------------------------------------------------------------------------------|
| `findByIdAndDeletedAtIsNull`         | `UUID id`                                                                                                                                                                                                                                            | `Optional<Game>`     | Finds a game by its ID, ensuring it is not marked as deleted.                                         |
| `findForUpdateById`                  | `UUID id`                                                                                                                                                                                                                                            | `Optional<Game>`     | Finds a game by its ID with a pessimistic write lock, ensuring it is not marked as deleted.           |
| `findVisibleToUser`                  | `UUID userId`, `Pageable pageable`                                                                                                                                                                                                                   | `Page<Game>`         | Finds games visible to a user, considering their participation and access rights.                     |
| `findVisibleToUserFiltered`          | `UUID userId`, `Instant afterStartTime`, `UUID afterId`, `Long[] venueIds`, `Long[] skillLevelIds`, `Instant fromInstant`, `Instant toInstant`, `Integer fromMinutes`, `Integer toMinutes`, `BigDecimal latitude`, `BigDecimal longitude`, `Integer radiusKm`, `BigDecimal latMin`, `BigDecimal latMax`, `BigDecimal lngMin`, `BigDecimal lngMax`, `int size` | `List<Game>`         | Finds games visible to a user with various filters applied, such as time, location, and skill level.  |
| `findVisibleForFilterOptions`        | `UUID userId`, `Instant fromInstant`, `Instant toInstant`, `Long[] venueIds`, `Long[] skillLevelIds`, `Integer fromMinutes`, `Integer toMinutes`, `String gameType`, `BigDecimal latitude`, `BigDecimal longitude`, `Integer radiusKm`, `BigDecimal latMin`, `BigDecimal latMax`, `BigDecimal lngMin`, `BigDecimal lngMax`, `int maxGames` | `List<Game>`         | Finds games visible to a user with additional filter options, including game type.                    |
| `findJoinedByUser`                   | `UUID userId`, `Instant afterStartTime`, `UUID afterId`, `int size`                                                                                                                                                                                  | `List<Game>`         | Finds games that a user has joined, with optional pagination.                                          |
| `findHostedByUser`                   | `UUID userId`, `Instant afterStartTime`, `UUID afterId`, `int size`                                                                                                                                                                                  | `List<Game>`         | Finds games hosted by a user, with optional pagination.                                                |
| `countJoinedByUser`                  | `UUID userId`                                                                                                                                                                                                                                        | `long`               | Counts the number of expired games a user has joined.                                                  |
| `countHostedByUser`                  | `UUID userId`                                                                                                                                                                                                                                        | `long`               | Counts the number of expired games hosted by a user.                                                   |
| `markStartedBefore`                  | `Instant cutoff`, `Instant now`                                                                                                                                                                                                                      | `int`                | Marks games as started if they were scheduled to start before a given cutoff time.                     |
| `markExpiredBefore`                  | `Collection<GameStatus> statuses`, `Instant cutoff`, `Instant now`                                                                                                                                                                                   | `int`                | Marks games as expired if they ended before a given cutoff time and match specified statuses.          |
| `findScheduledStartingBetween`       | `Instant from`, `Instant to`                                                                                                                                                                                                                         | `List<Game>`         | Finds games scheduled to start between two given instants.                                             |
| `findDistinctStartTimesBetween`      | `Instant from`, `Instant to`                                                                                                                                                                                                                         | `List<Instant>`      | Finds distinct start times of games between two given instants.                                        |

This interface is crucial for managing game-related data and operations, providing both standard and complex query capabilities to support the application's business logic.
