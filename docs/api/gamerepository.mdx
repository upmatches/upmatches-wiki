# GameRepository

The `GameRepository` interface provides data access operations for the `Game` entity in the UpMatches application. It extends Spring Data JPA's `JpaRepository` and includes custom query methods for retrieving, filtering, and updating game records with support for visibility rules, pagination, and concurrency control.

## Purpose

This repository handles all database interactions related to games, including:
- Finding games by ID with soft-delete awareness
- Retrieving games visible to a specific user based on visibility settings and participation
- Filtering games by various criteria (venue, skill level, time, location, etc.)
- Managing game lifecycle transitions (starting and expiring games)
- Counting games joined or hosted by a user

## Methods

### Basic CRUD Operations

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findByIdAndDeletedAtIsNull` | `Optional<Game>` | `UUID id` | Finds a game by ID that hasn't been soft-deleted |
| `findForUpdateById` | `Optional<Game>` | `UUID id` | Finds a game with pessimistic write lock for concurrent updates |

### Visibility and Filtering

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findVisibleToUser` | `Page<Game>` | `UUID userId`, `Pageable pageable` | Returns paginated games visible to a user (public, organized, participated, or shared) |
| `findVisibleToUserFiltered` | `List<Game>` | Multiple filter parameters | Returns games visible to user with advanced filtering (cursor-based pagination, venue, skill level, time range, location) |
| `findVisibleForFilterOptions` | `List<Game>` | Multiple filter parameters | Returns games visible to user for filter options with time range and game type filtering |

### User-Specific Queries

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findJoinedByUser` | `List<Game>` | `UUID userId`, `Instant afterStartTime`, `UUID afterId`, `int size` | Returns games the user has joined with cursor-based pagination |
| `findHostedByUser` | `List<Game>` | `UUID userId`, `Instant afterStartTime`, `UUID afterId`, `int size` | Returns games the user is hosting with cursor-based pagination |
| `countJoinedByUser` | `long` | `UUID userId` | Counts expired games the user has joined |
| `countHostedByUser` | `long` | `UUID userId` | Counts expired games the user has hosted |

### Lifecycle Management

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `markStartedBefore` | `int` | `Instant cutoff`, `Instant now` | Updates scheduled games to STARTED status if start time is before cutoff |
| `markExpiredBefore` | `int` | `Collection<GameStatus> statuses`, `Instant cutoff`, `Instant now` | Updates games to EXPIRED status if end time is before cutoff |

### Time-Based Queries

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findScheduledStartingBetween` | `List<Game>` | `Instant from`, `Instant to` | Finds scheduled games starting within a time range |
| `findDistinctStartTimesBetween` | `List<Instant>` | `Instant from`, `Instant to` | Returns distinct start times for games within a time range |

## Filter Parameters

The advanced filtering methods (`findVisibleToUserFiltered` and `findVisibleForFilterOptions`) accept the following parameters:

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The user requesting the games |
| `afterStartTime` | `Instant` | Cursor for pagination (start time) |
| `afterId` | `UUID` | Cursor for pagination (game ID) |
| `venueIds` | `Long[]` | Filter by venue IDs |
| `skillLevelIds` | `Long[]` | Filter by skill level IDs |
| `fromInstant` | `Instant` | Start of time range filter |
| `toInstant` | `Instant` | End of time range filter |
| `fromMinutes` | `Integer` | Start of time-of-day filter (minutes from midnight) |
| `toMinutes` | `Integer` | End of time-of-day filter (minutes from midnight) |
| `latitude` | `BigDecimal` | Center latitude for location-based filtering |
| `longitude` | `BigDecimal` | Center longitude for location-based filtering |
| `radiusKm` | `Integer` | Search radius in kilometers |
| `latMin`/`latMax` | `BigDecimal` | Latitude bounding box |
| `lngMin`/`lngMax` | `BigDecimal` | Longitude bounding box |
| `size`/`maxGames` | `int` | Maximum number of results to return |
| `gameType` | `String` | Filter by game type (only in `findVisibleForFilterOptions`) |

## Usage Notes

- All queries respect soft-delete by checking `deletedAt IS NULL`
- Visibility rules ensure users only see games they have access to (public, organized, participated, or shared)
- Location filtering uses the Haversine formula for distance calculation
- Time-of-day filtering handles wrap-around cases (e.g., 10 PM to 2 AM)
- The `findForUpdateById` method uses `PESSIMISTIC_WRITE` lock for safe concurrent updates
- Lifecycle methods (`markStartedBefore`, `markExpiredBefore`) are annotated with `@Modifying` for bulk updates
