## Overview

The `GameRepository` interface is a part of the `com.upmatches.app.features.game.repositories` package and extends the `JpaRepository` interface provided by Spring Data JPA. It is responsible for providing CRUD operations and custom queries for the `Game` entity. The repository facilitates interaction with the database to manage game-related data, including finding games by various criteria, updating game statuses, and counting games based on user participation.

## Public Methods

The following table documents the public methods available in the `GameRepository` interface:

| Method Name | Parameters | Return Type | Description |
|-------------|------------|-------------|-------------|
| `findByIdAndDeletedAtIsNull` | `UUID id` | `Optional<Game>` | Finds a game by its ID where the game is not marked as deleted. |
| `findForUpdateById` | `UUID id` | `Optional<Game>` | Finds a game by its ID for update with a pessimistic write lock, ensuring the game is not marked as deleted. |
| `findVisibleToUser` | `UUID userId`, `Pageable pageable` | `Page<Game>` | Retrieves a page of games visible to a specific user, considering game visibility and user participation. |
| `findVisibleToUserFiltered` | Multiple parameters including `UUID userId`, `Instant afterStartTime`, `UUID afterId`, etc. | `List<Game>` | Finds games visible to a user with additional filtering options such as time, venue, skill level, and location. |
| `findVisibleForFilterOptions` | Multiple parameters including `UUID userId`, `Instant fromInstant`, `Instant toInstant`, etc. | `List<Game>` | Retrieves games visible to a user with filtering options, including game type and location constraints. |
| `findJoinedByUser` | `UUID userId`, `Instant afterStartTime`, `UUID afterId`, `int size` | `List<Game>` | Finds games that a user has joined, ordered by start time. |
| `findHostedByUser` | `UUID userId`, `Instant afterStartTime`, `UUID afterId`, `int size` | `List<Game>` | Finds games hosted by a user, ordered by start time. |
| `countJoinedByUser` | `UUID userId` | `long` | Counts the number of expired games a user has joined. |
| `countHostedByUser` | `UUID userId` | `long` | Counts the number of expired games hosted by a user. |
| `markStartedBefore` | `Instant cutoff`, `Instant now` | `int` | Updates the status of games to 'STARTED' if they were scheduled to start before a given cutoff time. |
| `markExpiredBefore` | `Collection<GameStatus> statuses`, `Instant cutoff`, `Instant now` | `int` | Updates the status of games to 'EXPIRED' if they ended before a given cutoff time. |
| `findScheduledStartingBetween` | `Instant from`, `Instant to` | `List<Game>` | Finds games that are scheduled to start between two given instants. |
| `findDistinctStartTimesBetween` | `Instant from`, `Instant to` | `List<Instant>` | Retrieves distinct start times of games between two given instants. |

This interface is designed to handle complex queries and updates efficiently, leveraging both JPQL and native SQL queries to meet specific application requirements.
