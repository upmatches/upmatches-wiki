# MarkNotificationReadService

The `MarkNotificationReadService` is a Spring service class responsible for marking a specific notification as read for the currently authenticated user. It ensures that only the intended recipient can mark a notification as read, providing both security and data integrity.

## Purpose

This service encapsulates the business logic of updating a notification's read status. It performs the following operations:
1. Resolves the authenticated user's ID.
2. Retrieves the notification by its ID and verifies it belongs to the authenticated user.
3. Marks the notification as read using the domain entity's `markRead()` method.
4. Persists the updated notification to the database.
5. Returns a `NotificationResponse` DTO representing the updated notification.

## Public Methods

### `execute(UUID id)`

Marks a notification as read for the authenticated user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the notification to mark as read |

**Returns:** `NotificationResponse` - A DTO representing the updated notification with its read status changed.

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `NotificationNotFoundException` | When the notification with the given ID does not exist or does not belong to the authenticated user |
| `ResourceNotFoundException` | When the database update operation fails |

**Transactional Behavior:** This method is annotated with `@Transactional`, ensuring that the entire operation (find, update, save) is executed within a single database transaction.

## Error Handling

The service uses a consistent error handling approach:

1. **Notification Not Found**: If the notification cannot be found for the given ID and user combination, a `NotificationNotFoundException` is thrown with a descriptive message including the notification ID and user ID.

2. **Update Failure**: If the database save operation fails, the `ServiceOperationExecutor.execute()` method wraps the exception in a `ResourceNotFoundException`.

## Usage Example

```java
// In a controller or other service
@Autowired
private MarkNotificationReadService markNotificationReadService;

public ResponseEntity<NotificationResponse> markAsRead(@PathVariable UUID notificationId) {
    NotificationResponse response = markNotificationReadService.execute(notificationId);
    return ResponseEntity.ok(response);
}
```
