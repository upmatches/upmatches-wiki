# MarkNotificationReadService

The `MarkNotificationReadService` is a Spring service class responsible for marking a specific notification as read for the currently authenticated user. It ensures that only the intended recipient can mark a notification as read, providing a secure and transactional operation.

## Purpose

- Marks a notification as read by its unique identifier (`UUID`).
- Validates that the notification belongs to the authenticated user.
- Updates the notification status in the database within a transactional context.
- Returns a `NotificationResponse` DTO representing the updated notification.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `NotificationRepository` | Repository | Data access layer for `Notification` entities. |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's ID. |

## Public Methods

### `execute(UUID id)`

Marks a notification as read for the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the notification to mark as read. |

| Returns | Type | Description |
|---------|------|-------------|
| `NotificationResponse` | DTO | The updated notification data after marking it as read. |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `NotificationNotFoundException` | If the notification with the given ID does not exist or does not belong to the authenticated user. |
| `ResourceNotFoundException` | If the database update operation fails unexpectedly. |

**Behavior:**

1. Resolves the authenticated user's ID via `userResolver.requireUserId()`.
2. Queries the database for a notification matching both the provided `id` and the user's ID.
3. If not found, throws `NotificationNotFoundException` with a descriptive message.
4. Calls `notification.markRead()` to update the entity's internal state.
5. Persists the updated notification using `ServiceOperationExecutor.execute()` with the `UPDATE` operation status.
6. Converts the saved entity to a `NotificationResponse` and returns it.

## Example Usage

```java
// Assuming this service is injected into a controller or another service
@Autowired
private MarkNotificationReadService markNotificationReadService;

public void markAsRead(UUID notificationId) {
    NotificationResponse response = markNotificationReadService.execute(notificationId);
    // response now contains the updated notification data
}
```

## Notes

- The class is declared as `non-sealed`, indicating it is part of a sealed interface hierarchy (`IMarkNotificationReadService`).
- The operation is wrapped in `@Transactional` to ensure atomicity.
- Error messages are formatted using `String.format` with the notification ID and user ID for clarity.
