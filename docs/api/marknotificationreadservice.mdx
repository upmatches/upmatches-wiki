# MarkNotificationReadService

The `MarkNotificationReadService` is a Spring service class responsible for marking a specific notification as read for the currently authenticated user. It ensures that only the intended recipient can mark a notification as read, providing both security and data integrity.

## Purpose

This service encapsulates the business logic for updating a notification's read status. It performs the following operations:
- Resolves the authenticated user's ID
- Retrieves the notification by its ID and ensures it belongs to the authenticated user
- Marks the notification as read
- Persists the updated notification to the database
- Returns a `NotificationResponse` DTO

## Class Details

| Aspect | Description |
|--------|-------------|
| **Package** | `com.upmatches.app.features.notification.services` |
| **Annotations** | `@Service` |
| **Modifiers** | `public non-sealed` |
| **Implements** | `IMarkNotificationReadService` |
| **Dependencies** | `NotificationRepository`, `IAuthenticatedUserResolver` |

## Constructor

### `MarkNotificationReadService(NotificationRepository, IAuthenticatedUserResolver)`

Initializes the service with required dependencies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `notificationRepository` | `NotificationRepository` | Repository for notification persistence operations |
| `userResolver` | `IAuthenticatedUserResolver` | Service to resolve the currently authenticated user |

## Public Methods

### `execute(UUID id)`

Marks a notification as read for the authenticated user.

| Aspect | Details |
|--------|---------|
| **Return Type** | `NotificationResponse` |
| **Parameters** | `id` (`UUID`) - The unique identifier of the notification to mark as read |
| **Exceptions** | `NotificationNotFoundException` - If the notification is not found or does not belong to the authenticated user |
| **Transactional** | Yes - The operation is wrapped in a database transaction |

**Behavior:**
1. Resolves the authenticated user's ID using `userResolver.requireUserId()`
2. Attempts to find the notification by its ID and the user's ID
3. If not found, throws a `NotificationNotFoundException` with a descriptive message
4. Calls `notification.markRead()` to update the notification's read status
5. Persists the updated notification using `ServiceOperationExecutor.execute()`
6. Returns a `NotificationResponse` built from the saved notification

## Error Handling

The service handles the following error scenarios:

| Error | Condition | Exception |
|-------|-----------|-----------|
| Notification not found | No notification exists with the given ID for the authenticated user | `NotificationNotFoundException` |
| Persistence failure | Database operation fails during save | `ResourceNotFoundException` (wrapped) |

## Usage Example

```java
// Inject the service
private final MarkNotificationReadService markNotificationReadService;

// Mark a notification as read
UUID notificationId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
NotificationResponse response = markNotificationReadService.execute(notificationId);
```

## Dependencies

- **Spring Framework**: `@Service`, `@Transactional`
- **NotificationRepository**: For database operations
- **IAuthenticatedUserResolver**: For user authentication context
- **ServiceOperationExecutor**: For standardized service operation execution with error handling
