# CompleteProfileRequest

The `CompleteProfileRequest` class is a Java record used to encapsulate the data required for completing a user's profile in the UpMatches application. It serves as a Data Transfer Object (DTO) for the profile completion endpoint, ensuring that all necessary fields are provided and validated before processing.

## Purpose

This record defines the structure for a profile completion request, including the user's name, email, contact methods, and skill level selections. It leverages Jakarta Bean Validation annotations to enforce data integrity and business rules, such as requiring at least one contact method and limiting field sizes.

## Record Definition

```java
public record CompleteProfileRequest(
    @NotBlank
    @Size(max = CompleteProfileRequest.MAX_NAME_LENGTH)
    String name,

    @NotBlank
    @Email
    @Size(max = CompleteProfileRequest.MAX_EMAIL_LENGTH)
    String email,

    @AtLeastOneContactMethod
    @Size(max = CompleteProfileRequest.MAX_CONTACT_METHODS)
    List<ContactMethod> contactMethods,

    @NotNull
    @Valid
    @Size(max = CompleteProfileRequest.MAX_SKILL_LEVELS)
    List<SkillLevelSelection> skillLevels
) { ... }
```

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `MAX_NAME_LENGTH` | 200 | Maximum length for the user's name |
| `MAX_EMAIL_LENGTH` | 320 | Maximum length for the email address |
| `MAX_CONTACT_METHODS` | 10 | Maximum number of contact methods allowed |
| `MAX_SKILL_LEVELS` | 50 | Maximum number of skill level selections allowed |

## Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `name` | `String` | `@NotBlank`, `@Size(max=200)` | The user's full name |
| `email` | `String` | `@NotBlank`, `@Email`, `@Size(max=320)` | The user's email address |
| `contactMethods` | `List<ContactMethod>` | `@AtLeastOneContactMethod`, `@Size(max=10)` | List of contact methods (at least one required) |
| `skillLevels` | `List<SkillLevelSelection>` | `@NotNull`, `@Valid`, `@Size(max=50)` | List of skill level selections |

## Validation Rules

- **name**: Must not be blank and cannot exceed 200 characters.
- **email**: Must not be blank, must be a valid email format, and cannot exceed 320 characters.
- **contactMethods**: Must contain at least one contact method (enforced by `@AtLeastOneContactMethod` custom annotation) and cannot exceed 10 items.
- **skillLevels**: Must not be null, must contain valid items (enforced by `@Valid`), and cannot exceed 50 items.

## Usage Example

```java
CompleteProfileRequest request = new CompleteProfileRequest(
    "John Doe",
    "john.doe@example.com",
    List.of(new ContactMethod(...)),
    List.of(new SkillLevelSelection(...))
);
```

## Dependencies

- `jakarta.validation.constraints.*` - Jakarta Bean Validation annotations
- `com.upmatches.app.features.user.validators.AtLeastOneContactMethod` - Custom validation annotation
- `ContactMethod` - Represents a single contact method
- `SkillLevelSelection` - Represents a skill level selection

## Notes

- This record is immutable by design, as all Java records are.
- The `@Valid` annotation on `skillLevels` ensures that each `SkillLevelSelection` object within the list is also validated according to its own validation constraints.
- The `@AtLeastOneContactMethod` annotation is a custom validator that enforces the business rule requiring at least one contact method to be provided.
