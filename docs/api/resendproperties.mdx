## Overview

The `ResendProperties` class is a configuration properties holder used in a Spring Boot application. It is designed to manage properties related to resending notifications, specifically handling API keys and sender information. This class utilizes the `@ConfigurationProperties` annotation to map properties prefixed with `app.resend` from the application's configuration files.

## Public Methods

The `ResendProperties` class provides the following public methods:

| Method Name | Description | Parameters | Return Type |
|-------------|-------------|------------|-------------|
| `hasApiKey` | Checks if the API key is present and not null. | None | `boolean` |

## Constructor

The `ResendProperties` record constructor automatically initializes the fields `apiKey`, `fromAddress`, and `fromName`. It uses a private static method `blankToNull` to convert blank strings to `null`, ensuring that only meaningful values are stored.

### Parameters

| Parameter Name | Description | Type |
|----------------|-------------|------|
| `apiKey` | The API key used for authentication. | `String` |
| `fromAddress` | The email address from which notifications are sent. | `String` |
| `fromName` | The name associated with the sender's email address. | `String` |

## Usage

The `ResendProperties` class is typically used in a Spring Boot application to encapsulate and validate configuration properties related to notification resending. By using the `@ConfigurationProperties` annotation, it allows for easy configuration and management of these properties through external configuration files such as `application.yml` or `application.properties`.
