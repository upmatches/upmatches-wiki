# ResendProperties

The `ResendProperties` class is a Spring Boot configuration properties record that maps application properties prefixed with `app.resend` to a structured Java object. It encapsulates the configuration required to connect to the Resend email service, including the API key, sender address, and sender name.

This record is designed to be used with Spring Boot's `@ConfigurationProperties` annotation, allowing externalized configuration from `application.yml` or `application.properties` files. The record automatically sanitizes blank or null values by converting them to `null`, and provides a convenient method to check if the API key is configured.

## Constructor

The compact constructor automatically sanitizes all three fields (`apiKey`, `fromAddress`, `fromName`) by converting blank or null strings to `null` using the private helper method `blankToNull`.

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `hasApiKey()` | `boolean` | Returns `true` if the `apiKey` field is not null (i.e., a valid API key has been configured), otherwise returns `false`. |

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `apiKey` | `String` | The API key for authenticating with the Resend email service. Will be `null` if not provided or blank. |
| `fromAddress` | `String` | The email address used as the sender for outgoing emails. Will be `null` if not provided or blank. |
| `fromName` | `String` | The display name associated with the sender email address. Will be `null` if not provided or blank. |

## Usage Example

To configure this properties record, add the following to your `application.yml`:

```yaml
app:
  resend:
    apiKey: "your-resend-api-key"
    fromAddress: "noreply@example.com"
    fromName: "Your App Name"
```

Then inject the properties into a Spring component:

```java
@Component
public class EmailService {
    private final ResendProperties resendProperties;

    public EmailService(ResendProperties resendProperties) {
        this.resendProperties = resendProperties;
    }

    public void sendEmail() {
        if (resendProperties.hasApiKey()) {
            // Use resendProperties.apiKey(), resendProperties.fromAddress(), etc.
        }
    }
}
```
