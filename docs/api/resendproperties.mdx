# ResendProperties

The `ResendProperties` class is a Spring Boot configuration properties record that maps application properties prefixed with `app.resend` to a structured Java object. It encapsulates the configuration required to connect to the Resend email service, including the API key, sender address, and sender name.

This record automatically normalizes blank or null values to `null` during construction, ensuring that downstream consumers can safely check for the presence of required configuration values.

## Configuration Properties

The following table describes the properties that can be set in your `application.yml` or `application.properties` file under the `app.resend` prefix.

| Property | Type | Description |
|----------|------|-------------|
| `app.resend.api-key` | `String` | The API key used to authenticate with the Resend service. |
| `app.resend.from-address` | `String` | The email address used as the sender for outgoing emails. |
| `app.resend.from-name` | `String` | The display name associated with the sender email address. |

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `apiKey()` | `String` | Returns the API key, or `null` if the property was blank or not set. |
| `fromAddress()` | `String` | Returns the sender email address, or `null` if the property was blank or not set. |
| `fromName()` | `String` | Returns the sender display name, or `null` if the property was blank or not set. |
| `hasApiKey()` | `boolean` | Returns `true` if the API key is present (non-null), `false` otherwise. |

## Usage Example

```java
@Configuration
@EnableConfigurationProperties(ResendProperties.class)
public class ResendConfig {

    private final ResendProperties properties;

    public ResendConfig(ResendProperties properties) {
        this.properties = properties;
    }

    public void configureResendClient() {
        if (properties.hasApiKey()) {
            // Initialize Resend client with properties.apiKey()
            // Use properties.fromAddress() and properties.fromName() for sender info
        } else {
            throw new IllegalStateException("Resend API key is not configured");
        }
    }
}
```

## Application Configuration

In your `application.yml`:

```yaml
app:
  resend:
    api-key: "re_xxxxxxxxxxxxx"
    from-address: "noreply@example.com"
    from-name: "My Application"
```

Or in `application.properties`:

```properties
app.resend.api-key=re_xxxxxxxxxxxxx
app.resend.from-address=noreply@example.com
app.resend.from-name=My Application
```

## Notes

- All string properties are automatically normalized: blank or null values become `null`.
- Use `hasApiKey()` to safely check if the API key is configured before attempting to use it.
- This record is immutable after construction, making it thread-safe for concurrent access.
