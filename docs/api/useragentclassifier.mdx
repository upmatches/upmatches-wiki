## Purpose

The `UserAgentClassifier` class is a utility component designed to classify user agents into different client platforms. It helps in determining whether a user is accessing the application from an Android device, an iOS device, or a web browser. This classification can be useful for tailoring user experiences based on the platform.

## Public Methods

### classify

The `classify` method analyzes the provided user agent string and determines the client platform.

| Parameter  | Type   | Description                                      |
|------------|--------|--------------------------------------------------|
| userAgent  | String | The user agent string to be classified.          |

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| `ClientPlatform`     | An enum indicating the platform: `IOS`, `ANDROID`, or `WEB`. |

## Usage

To use the `UserAgentClassifier`, you need to instantiate it and call the `classify` method with a user agent string. The method will return the corresponding `ClientPlatform` enum value based on the content of the user agent string.

```java
UserAgentClassifier classifier = new UserAgentClassifier();
UserAgentClassifier.ClientPlatform platform = classifier.classify("Mozilla/5.0 (iPhone; CPU iPhone OS 14_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/14.0 Mobile/15E148 Safari/604.1");
System.out.println(platform); // Output: IOS
```

## ClientPlatform Enum

The `ClientPlatform` enum defines the possible platforms that can be identified:

- `IOS`: Represents iOS devices such as iPhone, iPad, and iPod.
- `ANDROID`: Represents Android devices.
- `WEB`: Represents web browsers or any other platform not explicitly identified as iOS or Android.
