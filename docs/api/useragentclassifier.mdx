# UserAgentClassifier

The `UserAgentClassifier` is a Spring `@Component` that provides a simple utility for classifying HTTP `User-Agent` strings into one of three client platforms: **iOS**, **Android**, or **Web**. This is commonly used in share‑link or deep‑linking features to determine the appropriate redirect or fallback behavior based on the user's device.

## Enum: `ClientPlatform`

| Enum Constant | Description |
|---------------|-------------|
| `IOS`         | Represents Apple mobile devices (iPhone, iPad, iPod). |
| `ANDROID`     | Represents Android devices. |
| `WEB`         | Represents all other clients (desktop browsers, unknown, or missing User‑Agent). |

## Public Methods

### `classify(String userAgent)`

Classifies the given `User-Agent` string into a `ClientPlatform`.

| Parameter   | Type     | Description |
|-------------|----------|-------------|
| `userAgent` | `String` | The raw `User-Agent` header value from an HTTP request. May be `null` or blank. |

| Returns          | Description |
|------------------|-------------|
| `ClientPlatform` | The detected platform: `ANDROID` if the string contains "Android"; `IOS` if it contains "iPhone", "iPad", or "iPod"; otherwise `WEB`. |

**Behavior details:**
- If `userAgent` is `null` or blank, the method returns `ClientPlatform.WEB`.
- The check for Android is performed before the iOS check.
- The method uses simple substring matching (case‑sensitive) against the predefined tokens.

## Usage Example

```java
@Autowired
private UserAgentClassifier classifier;

public void handleRequest(String userAgent) {
    UserAgentClassifier.ClientPlatform platform = classifier.classify(userAgent);
    switch (platform) {
        case IOS:
            // redirect to App Store or open deep link
            break;
        case ANDROID:
            // redirect to Google Play or open deep link
            break;
        case WEB:
            // show web fallback page
            break;
    }
}
```

## Notes

- The classification is intentionally simple and does not handle all edge cases (e.g., Android tablets, Windows Phone, or custom browsers). For production use with more complex requirements, consider a dedicated User‑Agent parsing library.
- The component is stateless and thread‑safe.
