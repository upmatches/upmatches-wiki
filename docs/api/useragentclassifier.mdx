# UserAgentClassifier

The `UserAgentClassifier` is a Spring `@Component` that provides a simple utility for classifying HTTP `User-Agent` strings into one of three client platforms: **iOS**, **Android**, or **Web**. This is commonly used in share‑link or deep‑linking flows to determine the appropriate redirect or fallback behavior based on the user's device.

## Enum: `ClientPlatform`

The classifier returns one of the following platform identifiers:

| Platform | Description |
|----------|-------------|
| `IOS`    | Apple mobile devices (iPhone, iPad, iPod) |
| `ANDROID`| Android devices |
| `WEB`    | All other clients (desktop browsers, unknown agents, or missing/blank input) |

## Public Methods

### `classify(String userAgent)`

Classifies the given `User-Agent` header value into a `ClientPlatform`.

| Parameter   | Type     | Description |
|-------------|----------|-------------|
| `userAgent` | `String` | The raw `User-Agent` string from an HTTP request. May be `null` or blank. |

**Returns:** `ClientPlatform` – one of `IOS`, `ANDROID`, or `WEB`.

**Behavior:**
- If `userAgent` is `null` or blank, returns `WEB`.
- If the string contains `"Android"` (case‑sensitive), returns `ANDROID`.
- If the string contains `"iPhone"`, `"iPad"`, or `"iPod"` (case‑sensitive), returns `IOS`.
- Otherwise, returns `WEB`.

**Example usage:**

```java
UserAgentClassifier classifier = new UserAgentClassifier();

ClientPlatform platform = classifier.classify(
    "Mozilla/5.0 (iPhone; CPU iPhone OS 15_0 like Mac OS X) ..."
);
// platform == ClientPlatform.IOS

platform = classifier.classify(
    "Mozilla/5.0 (Linux; Android 12; Pixel 6) ..."
);
// platform == ClientPlatform.ANDROID

platform = classifier.classify(
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ..."
);
// platform == ClientPlatform.WEB
```

## Notes

- The detection is based on simple substring matching and is **case‑sensitive**. Real‑world `User-Agent` strings from major browsers and mobile apps almost always use the exact casing shown in the constants.
- The component is stateless and thread‑safe, suitable for injection into any Spring bean.
- For more robust parsing (e.g., distinguishing tablets from phones, or detecting specific browser versions), consider using a dedicated library like `eu.bitwalker:UserAgentUtils`.
