# UserAgentClassifier

The `UserAgentClassifier` class is a Spring `@Component` that provides a simple utility for classifying HTTP `User-Agent` strings into one of three client platforms: **iOS**, **Android**, or **Web**. This is commonly used in share-link or deep-linking workflows to determine the appropriate redirect or fallback behavior based on the user's device.

## Enum: `ClientPlatform`

The class defines an inner enum `ClientPlatform` with three constants:

| Constant | Description |
|----------|-------------|
| `IOS`    | Represents Apple mobile devices (iPhone, iPad, iPod) |
| `ANDROID`| Represents Android devices |
| `WEB`    | Represents all other clients (desktop browsers, unknown, or missing User-Agent) |

## Public Methods

### `classify(String userAgent)`

Classifies the given `User-Agent` string into a `ClientPlatform`.

| Parameter  | Type     | Description |
|------------|----------|-------------|
| `userAgent`| `String` | The HTTP `User-Agent` header value to classify. Can be `null` or blank. |

**Returns:** `ClientPlatform` – one of `IOS`, `ANDROID`, or `WEB`.

**Behavior:**
- If `userAgent` is `null` or blank, returns `WEB`.
- If the string contains `"Android"` (case-sensitive), returns `ANDROID`.
- If the string contains `"iPhone"`, `"iPad"`, or `"iPod"` (case-sensitive), returns `IOS`.
- Otherwise, returns `WEB`.

**Example usage:**

```java
UserAgentClassifier classifier = new UserAgentClassifier();

ClientPlatform platform1 = classifier.classify("Mozilla/5.0 (Linux; Android 13) AppleWebKit/537.36");
// platform1 == ClientPlatform.ANDROID

ClientPlatform platform2 = classifier.classify("Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X)");
// platform2 == ClientPlatform.IOS

ClientPlatform platform3 = classifier.classify("Mozilla/5.0 (Windows NT 10.0; Win64; x64)");
// platform3 == ClientPlatform.WEB

ClientPlatform platform4 = classifier.classify(null);
// platform4 == ClientPlatform.WEB
```

## Notes

- The detection is based on simple substring matching and is **case-sensitive**. For example, `"android"` (lowercase) would not match `"Android"`.
- The class is stateless and thread-safe.
- It is annotated with `@Component`, making it eligible for automatic detection and dependency injection in a Spring Boot application.
