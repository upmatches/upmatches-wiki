# AtLeastOneContactMethodValidator

## Purpose

The `AtLeastOneContactMethodValidator` is a custom Jakarta Bean Validation constraint validator that ensures a list of contact methods contains at least one valid, non-empty entry from the allowed set: `whatsapp`, `telegram`, or `messenger`. It is designed to be used with the `@AtLeastOneContactMethod` annotation on fields of type `List<ContactMethod>`.

This validator enforces business rules for user registration or profile update flows where at least one contact method must be provided and must have a non-blank value.

## Class Overview

- **Package:** `com.upmatches.app.features.user.validators`
- **Implements:** `jakarta.validation.ConstraintValidator<AtLeastOneContactMethod, List<ContactMethod>>`
- **Type Parameters:** Validates `List<ContactMethod>` objects annotated with `@AtLeastOneContactMethod`

## Constants

| Constant | Type | Description |
|----------|------|-------------|
| `DEFAULT_VALIDATION_MESSAGE` | `String` | Default error message: "At least one contact method (whatsapp, telegram, or messenger) must be provided and non-empty." |
| `VALID_NAMES` | `Set<String>` | Immutable set containing the allowed contact method names: `"whatsapp"`, `"telegram"`, `"messenger"` |

## Public Methods

### `isValid(List<ContactMethod> contactMethods, ConstraintValidatorContext context)`

Validates that the provided list of contact methods contains at least one valid entry.

| Parameter | Type | Description |
|-----------|------|-------------|
| `contactMethods` | `List<ContactMethod>` | The list of contact methods to validate. Can be `null` or empty. |
| `context` | `ConstraintValidatorContext` | The validation context provided by the Jakarta Bean Validation framework. |

**Returns:** `boolean` — `true` if the list contains at least one contact method with:
- A non-null object
- A non-null name that matches one of the valid names (case-insensitive)
- A non-null value that is not blank

Returns `false` if:
- The list is `null` or empty
- No contact method in the list satisfies all validation criteria

## Validation Logic

1. **Null/Empty Check:** If the `contactMethods` list is `null` or empty, validation fails immediately.
2. **Stream Processing:** The validator streams through the list, filtering out `null` entries and entries with `null` names.
3. **Matching Criteria:** For each remaining entry, it checks:
   - The name (lowercased) is one of `"whatsapp"`, `"telegram"`, or `"messenger"`
   - The value is not `null` and not blank (after trimming whitespace)
4. **Result:** Returns `true` if any entry matches all criteria; otherwise `false`.

## Usage Example

```java
@AtLeastOneContactMethod
private List<ContactMethod> contactMethods;
```

## Dependencies

- `jakarta.validation:jakarta.validation-api` (for `ConstraintValidator` and `ConstraintValidatorContext`)
- `com.upmatches.app.features.user.requests.ContactMethod` (the record/class representing a single contact method with `name()` and `value()` accessors)
