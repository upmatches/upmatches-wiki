# AtLeastOneContactMethodValidator

## Purpose

The `AtLeastOneContactMethodValidator` class is a custom Jakarta Bean Validation constraint validator. It ensures that a list of `ContactMethod` objects contains at least one valid, non-empty contact method from a predefined set of allowed types: `whatsapp`, `telegram`, or `messenger`.

This validator is designed to enforce business rules where a user must provide at least one contact method for communication, preventing submissions with empty or invalid contact information.

## Class Overview

- **Package:** `com.upmatches.app.features.user.validators`
- **Implements:** `ConstraintValidator<AtLeastOneContactMethod, List<ContactMethod>>`
- **Key Constants:**
  - `DEFAULT_VALIDATION_MESSAGE`: Default error message when validation fails.
  - `VALID_NAMES`: A static set containing the three allowed contact method names (`whatsapp`, `telegram`, `messenger`).

## Validation Logic

The `isValid` method performs the following checks:

1. Returns `false` if the input list is `null` or empty.
2. Filters out any `null` entries or entries with a `null` name.
3. Checks if any remaining entry satisfies all conditions:
   - The name (case-insensitive) is one of the valid types (`whatsapp`, `telegram`, `messenger`).
   - The value is not `null` and is not blank (i.e., contains non-whitespace characters).

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `isValid(List<ContactMethod> contactMethods, ConstraintValidatorContext context)` | `boolean` | `contactMethods` - the list of contact methods to validate; `context` - the validation context | Validates that at least one contact method in the list is valid and non-empty. Returns `true` if validation passes, `false` otherwise. |

## Usage Example

```java
// The validator is typically used via the @AtLeastOneContactMethod annotation
// on a field or parameter of type List<ContactMethod>

@AtLeastOneContactMethod
private List<ContactMethod> contactMethods;
```

## Error Message

When validation fails, the default error message is:

> "At least one contact method (whatsapp, telegram, or messenger) must be provided and non-empty."

This message can be overridden by specifying a custom message in the `@AtLeastOneContactMethod` annotation.
