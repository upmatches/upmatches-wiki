# Pricing

The `Pricing` record is a value object that encapsulates the pricing configuration for a game feature. It supports three distinct pricing modes: flat, gendered, and shuttlecock. Each mode enforces specific constraints on which price fields must be provided and which must be absent, ensuring data integrity at construction time.

## Purpose

- **Encapsulation**: Bundles all pricing-related data (mode, currency, and various price amounts) into a single immutable object.
- **Validation**: Enforces business rules at construction, preventing invalid pricing configurations (e.g., providing both flat and gendered prices).
- **Backward Compatibility**: Provides a `representativeAmount()` method to derive a single price value for legacy systems.
- **Scale-Tolerant Equality**: Offers `semanticEquals()` to compare `BigDecimal` values by their numeric value rather than scale, which is essential when comparing values from different sources (e.g., API vs. database).

## Constructor

The canonical constructor performs the following validations:

1. **Mode and Currency**: Both must be non-null.
2. **Non-Negative Amounts**: All provided `BigDecimal` values must be >= 0.
3. **Mode-Specific Rules**: Based on the `PricingMode`, it validates that the correct combination of price fields is provided and that no extraneous fields are present.

## Public Methods

### Static Factory Methods

| Method | Parameters | Returns | Description |
|--------|------------|---------|-------------|
| `flat` | `BigDecimal amount`, `Currency currency` | `Pricing` | Creates a flat pricing with a single price for all participants. |
| `gendered` | `BigDecimal male`, `BigDecimal female`, `Currency currency` | `Pricing` | Creates a gendered pricing with separate prices for male and female participants. |
| `shuttlecock` | `BigDecimal base`, `BigDecimal perShuttle`, `Currency currency` | `Pricing` | Creates a shuttlecock pricing with a base price and a per-shuttle price. |

### Instance Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `representativeAmount()` | `BigDecimal` | Returns a single representative price for backward compatibility. For `FLAT` mode, returns the flat price. For `GENDERED` mode, returns the lower of male and female prices. For `SHUTTLECOCK` mode, returns the base price. |
| `semanticEquals(Pricing other)` | `boolean` | Compares two `Pricing` objects for semantic equality, ignoring `BigDecimal` scale differences. Returns `true` if all fields are numerically equal (using `compareTo`), `false` otherwise. |

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `mode` | `PricingMode` | The pricing mode (FLAT, GENDERED, or SHUTTLECOCK). |
| `currency` | `Currency` | The currency for all price amounts. |
| `flatPrice` | `BigDecimal` | The flat price (used only in FLAT mode). |
| `malePrice` | `BigDecimal` | The male price (used only in GENDERED mode). |
| `femalePrice` | `BigDecimal` | The female price (used only in GENDERED mode). |
| `basePrice` | `BigDecimal` | The base price (used only in SHUTTLECOCK mode). |
| `pricePerShuttle` | `BigDecimal` | The price per shuttle (used only in SHUTTLECOCK mode). |

## Usage Examples

```java
// Flat pricing
Pricing flatPricing = Pricing.flat(new BigDecimal("10.00"), Currency.getInstance("USD"));

// Gendered pricing
Pricing genderedPricing = Pricing.gendered(
    new BigDecimal("12.00"),
    new BigDecimal("10.00"),
    Currency.getInstance("USD")
);

// Shuttlecock pricing
Pricing shuttlecockPricing = Pricing.shuttlecock(
    new BigDecimal("5.00"),
    new BigDecimal("2.50"),
    Currency.getInstance("USD")
);

// Get representative amount
BigDecimal repAmount = flatPricing.representativeAmount(); // 10.00

// Semantic equality
Pricing pricing1 = Pricing.flat(new BigDecimal("10.00"), Currency.getInstance("USD"));
Pricing pricing2 = Pricing.flat(new BigDecimal("10.0"), Currency.getInstance("USD"));
boolean equal = pricing1.semanticEquals(pricing2); // true (ignores scale)
```

## Validation Rules

| Mode | Required Fields | Prohibited Fields |
|------|----------------|-------------------|
| FLAT | `flatPrice` | `malePrice`, `femalePrice`, `basePrice`, `pricePerShuttle` |
| GENDERED | `malePrice`, `femalePrice` | `flatPrice`, `basePrice`, `pricePerShuttle` |
| SHUTTLECOCK | `basePrice`, `pricePerShuttle` | `flatPrice`, `malePrice`, `femalePrice` |

## Error Handling

The constructor throws `IllegalArgumentException` with descriptive messages for the following scenarios:

- `mode` is null
- `currency` is null
- Any price amount is negative
- Required fields are missing for the given mode
- Prohibited fields are present for the given mode
