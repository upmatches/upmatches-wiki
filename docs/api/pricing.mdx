# Pricing Record

The `Pricing` record is a value object that encapsulates different pricing models for a service or product. It supports three distinct pricing modes: **Flat**, **Gendered**, and **Shuttlecock**. Each mode enforces specific validation rules to ensure that only the relevant price fields are populated.

## Purpose

- **Immutable Data Carrier**: As a Java `record`, it provides a concise way to define an immutable data structure with automatically generated constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods.
- **Domain-Driven Design**: It models a core business concept (pricing) with clear constraints and validation, ensuring data integrity at the point of creation.
- **Backward Compatibility**: The `representativeAmount()` method provides a single price value for legacy systems that expect a single price column.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `mode` | `PricingMode` | The pricing model (FLAT, GENDERED, SHUTTLECOCK). |
| `currency` | `Currency` | The currency for all price amounts. |
| `flatPrice` | `BigDecimal` | The flat price (used only in FLAT mode). |
| `malePrice` | `BigDecimal` | The price for male participants (used only in GENDERED mode). |
| `femalePrice` | `BigDecimal` | The price for female participants (used only in GENDERED mode). |
| `basePrice` | `BigDecimal` | The base price (used only in SHUTTLECOCK mode). |
| `pricePerShuttle` | `BigDecimal` | The price per shuttle (used only in SHUTTLECOCK mode). |

## Validation Rules

The compact constructor performs the following validations:

1. **Mode and Currency**: Both `mode` and `currency` must be non-null.
2. **Non-Negative Amounts**: All price fields, if not null, must be >= 0.
3. **Mode-Specific Validation**:
   - **FLAT**: `flatPrice` must be non-null; all other price fields must be null.
   - **GENDERED**: Both `malePrice` and `femalePrice` must be non-null; `flatPrice`, `basePrice`, and `pricePerShuttle` must be null.
   - **SHUTTLECOCK**: Both `basePrice` and `pricePerShuttle` must be non-null; `flatPrice`, `malePrice`, and `femalePrice` must be null.

## Public Methods

### Static Factory Methods

| Method | Parameters | Returns | Description |
|--------|------------|---------|-------------|
| `flat(BigDecimal amount, Currency currency)` | `amount` - the flat price; `currency` - the currency | `Pricing` | Creates a FLAT pricing instance. |
| `gendered(BigDecimal male, BigDecimal female, Currency currency)` | `male` - male price; `female` - female price; `currency` - the currency | `Pricing` | Creates a GENDERED pricing instance. |
| `shuttlecock(BigDecimal base, BigDecimal perShuttle, Currency currency)` | `base` - base price; `perShuttle` - price per shuttle; `currency` - the currency | `Pricing` | Creates a SHUTTLECOCK pricing instance. |

### Instance Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `representativeAmount()` | `BigDecimal` | Returns a single representative price for backward compatibility: flat price for FLAT, the lower of male/female for GENDERED, and base price for SHUTTLECOCK. |
| `semanticEquals(Pricing other)` | `boolean` | Compares two `Pricing` instances using `BigDecimal.compareTo()` instead of `BigDecimal.equals()`, making it tolerant of scale differences (e.g., `10` vs `10.00`). |

## Usage Examples

### Creating a Flat Pricing

```java
Pricing flatPricing = Pricing.flat(new BigDecimal("25.00"), Currency.getInstance("USD"));
```

### Creating a Gendered Pricing

```java
Pricing genderedPricing = Pricing.gendered(
    new BigDecimal("20.00"),
    new BigDecimal("15.00"),
    Currency.getInstance("EUR")
);
```

### Creating a Shuttlecock Pricing

```java
Pricing shuttlecockPricing = Pricing.shuttlecock(
    new BigDecimal("10.00"),
    new BigDecimal("2.50"),
    Currency.getInstance("GBP")
);
```

### Using representativeAmount()

```java
BigDecimal repAmount = flatPricing.representativeAmount(); // Returns 25.00
```

### Using semanticEquals()

```java
Pricing p1 = Pricing.flat(new BigDecimal("10"), Currency.getInstance("USD"));
Pricing p2 = Pricing.flat(new BigDecimal("10.00"), Currency.getInstance("USD"));

boolean equal = p1.semanticEquals(p2); // true, despite scale difference
boolean notEqual = p1.equals(p2); // false, due to scale difference
```

## Error Handling

The constructor throws `IllegalArgumentException` with descriptive messages for the following scenarios:

- `mode` or `currency` is null
- Any price field is negative
- Invalid combination of price fields for the given mode
