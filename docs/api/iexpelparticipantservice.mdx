# IExpelParticipantService Interface

## Purpose

The `IExpelParticipantService` interface defines the contract for expelling a participant from a game within the UpMatches application. It is a **sealed interface**, meaning only explicitly permitted classes (in this case, `ExpelParticipantService`) can implement it. This design enforces a controlled and secure implementation hierarchy, ensuring that the expulsion logic is handled by a single, designated service class.

The interface provides a single method, `execute`, which takes the game ID, participant ID, and an `ExpelParticipantRequest` object containing any additional details required for the expulsion operation.

## Public Methods

| Method | Return Type | Parameters | Description |
| :--- | :--- | :--- | :--- |
| `execute` | `void` | `UUID gameId` - The unique identifier of the game from which the participant is being expelled.<br/><br/>`UUID participantId` - The unique identifier of the participant to be expelled.<br/><br/>`ExpelParticipantRequest request` - An object containing the details of the expulsion request (e.g., reason, admin notes). | Executes the expulsion of a participant from a game. The method does not return a value but is expected to perform the necessary business logic and side effects (e.g., updating database records, sending notifications). |
