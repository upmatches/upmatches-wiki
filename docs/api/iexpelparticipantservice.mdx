# IExpelParticipantService Interface

## Purpose

The `IExpelParticipantService` interface defines the contract for expelling a participant from a game within the UpMatches application. It serves as a sealed interface, restricting its implementation to only the `ExpelParticipantService` class. This design pattern enforces a controlled hierarchy, ensuring that only the designated service class can provide the expulsion logic.

The interface encapsulates the operation of removing a participant from a game session, requiring the game ID, participant ID, and an `ExpelParticipantRequest` object that likely contains additional details about the expulsion (e.g., reason, timestamp).

## Interface Definition

```java
public sealed interface IExpelParticipantService permits ExpelParticipantService {
    void execute(UUID gameId, UUID participantId, ExpelParticipantRequest request);
}
```

## Methods

### `execute`

| Parameter       | Type                     | Description                                      |
|-----------------|--------------------------|--------------------------------------------------|
| `gameId`        | `UUID`                   | The unique identifier of the game from which the participant will be expelled. |
| `participantId` | `UUID`                   | The unique identifier of the participant to be expelled. |
| `request`       | `ExpelParticipantRequest`| The request object containing details about the expulsion operation. |

**Return Type:** `void`

**Description:** Executes the expulsion of a participant from a specified game. The method takes the game's UUID, the participant's UUID, and an `ExpelParticipantRequest` object that provides the necessary context for the operation. The implementation in `ExpelParticipantService` handles the actual business logic, such as validating the request, updating the game state, and persisting changes.

## Usage Example

```java
// Assuming service is injected or instantiated
IExpelParticipantService expelService = new ExpelParticipantService();

UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UUID participantId = UUID.fromString("987fcdeb-51a2-43d7-9abc-123456789012");
ExpelParticipantRequest request = new ExpelParticipantRequest("Violation of game rules");

expelService.execute(gameId, participantId, request);
```

## Related Components

- **`ExpelParticipantService`**: The sole permitted implementation of this interface, containing the concrete expulsion logic.
- **`ExpelParticipantRequest`**: The request data class that carries expulsion-specific information.
