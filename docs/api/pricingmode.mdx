# PricingMode Enum

The `PricingMode` enum defines the different pricing strategies available for game sessions within the UpMatches application. It is used to determine how the cost of a game is calculated and distributed among participants.

## Location

- **Package:** `com.upmatches.app.features.game.enums`
- **File:** `PricingMode.java`

## Purpose

This enum provides a clear, type-safe way to represent the three distinct pricing models supported by the platform. By using an enum, the application ensures that only valid pricing modes are used throughout the codebase, reducing the risk of errors from using raw strings or integers.

## Enum Constants

| Constant       | Description                                                                 |
|----------------|-----------------------------------------------------------------------------|
| `FLAT`         | A single, fixed price for all participants regardless of any other factors. |
| `GENDERED`     | Pricing varies based on the gender of the participant (e.g., different rates for men and women). |
| `SHUTTLECOCK`  | Pricing is calculated per shuttlecock used during the game session.         |

## Usage

The `PricingMode` enum is typically used in conjunction with game configuration objects or pricing calculators. For example:

```java
// Example usage in a game configuration
GameConfig config = new GameConfig();
config.setPricingMode(PricingMode.FLAT);

// Switch on pricing mode to calculate cost
switch (pricingMode) {
    case FLAT:
        // Calculate flat rate
        break;
    case GENDERED:
        // Calculate gendered pricing
        break;
    case SHUTTLECOCK:
        // Calculate per-shuttlecock pricing
        break;
}
```

## Related Components

- **Game Configuration:** The enum is used to set the pricing strategy for a specific game session.
- **Pricing Calculator:** A service or utility class that reads the `PricingMode` and applies the corresponding pricing logic.

## Notes

- This enum is immutable and thread-safe by design.
- New pricing modes can be added in the future by simply adding new constants to this enum.
