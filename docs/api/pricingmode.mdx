# PricingMode Enum

The `PricingMode` enum defines the available pricing strategies for matches within the UpMatches application. It is used to determine how the cost of a match is calculated and distributed among participants.

## Location

`com.upmatches.app.features.game.enums.PricingMode`

## Purpose

This enum provides a clear and type-safe way to specify the pricing model for a game or match. By using an enum instead of raw strings or integers, the application ensures that only valid pricing modes are used throughout the codebase, reducing errors and improving maintainability.

## Enum Constants

| Constant       | Description                                                                 |
|----------------|-----------------------------------------------------------------------------|
| `FLAT`         | A single, fixed price for all participants regardless of gender.            |
| `GENDERED`     | Pricing varies based on the gender of the participant (e.g., different rates for men and women). |
| `SHUTTLECOCK`  | Pricing is calculated per shuttlecock used during the match (common in badminton). |

## Usage Example

```java
PricingMode mode = PricingMode.FLAT;

switch (mode) {
    case FLAT:
        // Apply flat pricing logic
        break;
    case GENDERED:
        // Apply gendered pricing logic
        break;
    case SHUTTLECOCK:
        // Apply per-shuttlecock pricing logic
        break;
}
```

## Related Components

This enum is typically used in conjunction with match creation and pricing calculation services within the `game` feature package. It may be stored as a field in match-related entities or DTOs to persist the selected pricing strategy.
