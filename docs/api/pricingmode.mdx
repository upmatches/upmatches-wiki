# PricingMode Enum

The `PricingMode` enum is part of the `com.upmatches.app.features.game.enums` package. It is used to define different modes of pricing within the application. Enums in Java are a special type of class that represents a group of constants (unchangeable variables, like final variables).

## Enum Constants

The `PricingMode` enum contains the following constants:

| Constant    | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `FLAT`      | Represents a flat pricing mode where the price is consistent across all conditions. |
| `GENDERED`  | Represents a gendered pricing mode where pricing may vary based on gender.  |
| `SHUTTLECOCK` | Represents a pricing mode specific to shuttlecock-related activities or items. |

## Purpose

The purpose of the `PricingMode` enum is to provide a clear and type-safe way to handle different pricing strategies within the application. By using an enum, the code becomes more readable and less error-prone, as it restricts the possible values to the predefined constants.

## Usage

Enums are typically used in switch statements or as a part of conditional logic to execute different code paths based on the selected pricing mode. This enum can be used throughout the application wherever pricing logic needs to be applied or evaluated.
