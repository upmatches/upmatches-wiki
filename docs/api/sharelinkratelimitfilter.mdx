## Purpose

The `ShareLinkRateLimitFilter` class is a Spring component designed to enforce rate limiting on specific API endpoints related to share links. It extends the `OncePerRequestFilter` class, ensuring that the filter logic is applied only once per request. The filter uses Redis to track request counts and applies limits to prevent abuse of the share link creation and resolution endpoints.

## Public Methods

### Constructor

| Method Signature | Description |
|------------------|-------------|
| `ShareLinkRateLimitFilter(StringRedisTemplate redisTemplate)` | Constructs a new `ShareLinkRateLimitFilter` with the specified `StringRedisTemplate` for interacting with Redis. |

### Overridden Methods

#### `shouldNotFilter`

| Method Signature | Description |
|------------------|-------------|
| `protected boolean shouldNotFilter(HttpServletRequest request)` | Determines whether the filter should be applied to the given request. Returns `true` if the request URI does not start with the share link path prefix, indicating that the filter should not be applied. |

#### `doFilterInternal`

| Method Signature | Description |
|------------------|-------------|
| `protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) throws ServletException, IOException` | Applies rate limiting logic to incoming requests. If the request exceeds the rate limit, a "Too Many Requests" response is returned. Otherwise, the request is passed down the filter chain. |

### Private Methods

#### `isRateLimited`

| Method Signature | Description |
|------------------|-------------|
| `private boolean isRateLimited(String key, int limit)` | Checks if the request associated with the given key exceeds the specified limit. Returns `true` if the limit is exceeded, otherwise `false`. |

#### `resolveClientIp`

| Method Signature | Description |
|------------------|-------------|
| `private String resolveClientIp(HttpServletRequest request)` | Resolves the client's IP address from the request, considering the `X-Forwarded-For` header if present. |

#### `resolveSubjectOrIp`

| Method Signature | Description |
|------------------|-------------|
| `private String resolveSubjectOrIp(HttpServletRequest request)` | Resolves the subject from the JWT token if available, otherwise falls back to the client's IP address. |

#### `writeRateLimitResponse`

| Method Signature | Description |
|------------------|-------------|
| `private void writeRateLimitResponse(HttpServletResponse response, String bucket, String instance) throws IOException` | Writes a rate limit exceeded response to the client, including a problem detail JSON object with information about the rate limit violation. |
