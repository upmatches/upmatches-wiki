# IJwtTokenService Interface

The `IJwtTokenService` interface defines the contract for JWT (JSON Web Token) token generation services within the authentication module. It establishes a sealed interface hierarchy that restricts implementation to the `JwtTokenService` class, ensuring type safety and controlled extensibility.

## Purpose

This interface serves as the abstraction layer for generating authentication tokens in the application. By defining a sealed interface, the design enforces that only the designated `JwtTokenService` class can implement the token generation logic, preventing unauthorized implementations and maintaining a consistent token generation strategy across the application.

## Interface Definition

```java
public sealed interface IJwtTokenService permits JwtTokenService
```

The `sealed` keyword restricts implementation to the `JwtTokenService` class only, providing compile-time safety and clear architectural boundaries.

## Methods

### generateAccessToken

Generates an access token for authenticated users. This method accepts multiple user identifiers to support different authentication providers and user identification strategies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user in the system |
| `singpassUuid` | `String` | The user's UUID from Singpass authentication provider |
| `auth0Uuid` | `String` | The user's UUID from Auth0 authentication provider |
| `appleUuid` | `String` | The user's UUID from Apple authentication provider |

**Returns:** `AccessTokenResult` - An object containing the generated access token and its associated metadata (e.g., expiration time, token type).

### generateRefreshToken

Generates a refresh token that can be used to obtain new access tokens without requiring the user to re-authenticate.

**Parameters:** None

**Returns:** `String` - A unique refresh token string that can be stored and validated for token refresh operations.

## Related Components

- **JwtTokenService**: The sole implementation class for this interface
- **AccessTokenResult**: A nested record/class within `JwtTokenService` that encapsulates the access token generation result
- **Authentication Flow**: This interface is typically used in authentication controllers and services to generate tokens upon successful user authentication
