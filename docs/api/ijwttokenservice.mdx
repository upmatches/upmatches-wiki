## Overview

The `IJwtTokenService` interface is part of the `com.upmatches.app.features.auth.services` package. It defines the contract for generating JWT tokens, specifically access and refresh tokens, which are essential for authentication and authorization processes in applications. This interface is implemented by the `JwtTokenService` class.

## Public Methods

### `generateAccessToken`

Generates an access token for a user based on various unique identifiers.

| Parameter     | Type   | Description                                |
|---------------|--------|--------------------------------------------|
| `userId`      | `UUID` | The unique identifier for the user.        |
| `singpassUuid`| `String` | The Singpass unique identifier.           |
| `auth0Uuid`   | `String` | The Auth0 unique identifier.              |
| `appleUuid`   | `String` | The Apple unique identifier.              |

**Returns**: `AccessTokenResult` - An object containing the result of the access token generation.

### `generateRefreshToken`

Generates a refresh token which can be used to obtain a new access token without re-authenticating the user.

**Returns**: `String` - A newly generated refresh token.
