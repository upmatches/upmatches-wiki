# IJwtTokenService Interface

## Purpose

The `IJwtTokenService` interface defines the contract for JWT (JSON Web Token) token generation services within the authentication module. It provides a sealed interface pattern that restricts implementation to the `JwtTokenService` class, ensuring controlled token generation behavior across the application.

This interface is part of the `com.upmatches.app.features.auth.services` package and serves as the abstraction layer for generating access tokens and refresh tokens used in user authentication flows.

## Interface Definition

```java
public sealed interface IJwtTokenService permits JwtTokenService
```

The interface is declared as `sealed`, meaning only the specified class `JwtTokenService` is allowed to implement it. This design pattern provides:
- **Controlled extensibility**: Only authorized implementations can exist
- **Enhanced security**: Prevents unauthorized token generation implementations
- **Clear contract**: Defines exactly what token operations are available

## Methods

### `generateAccessToken`

Generates an access token for authenticated users with multiple identity provider identifiers.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The unique identifier of the user in the system |
| `singpassUuid` | `String` | The user's UUID from Singpass identity provider |
| `auth0Uuid` | `String` | The user's UUID from Auth0 identity provider |
| `appleUuid` | `String` | The user's UUID from Apple identity provider |

**Returns**: `AccessTokenResult` - An object containing the generated access token and its metadata (defined in `JwtTokenService`)

### `generateRefreshToken`

Generates a refresh token for extending user sessions without requiring re-authentication.

| Parameter | Type | Description |
|-----------|------|-------------|
| None | - | - |

**Returns**: `String` - A generated refresh token string

## Usage Example

```java
// Implementation in JwtTokenService
public final class JwtTokenService implements IJwtTokenService {
    
    @Override
    public AccessTokenResult generateAccessToken(
        UUID userId,
        String singpassUuid,
        String auth0Uuid,
        String appleUuid) {
        // Token generation logic
    }
    
    @Override
    public String generateRefreshToken() {
        // Refresh token generation logic
    }
    
    // Nested record for access token result
    public record AccessTokenResult(
        String accessToken,
        Instant expiresAt,
        String tokenType
    ) {}
}
```

## Dependencies

- `java.util.UUID` - For user identification
- `JwtTokenService` - The permitted implementation class containing `AccessTokenResult` definition

## Related Components

- `JwtTokenService` - The sole implementation of this interface
- Authentication controllers that consume these tokens
- Security filters that validate generated tokens
