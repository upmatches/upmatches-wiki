# @Auditable

The `@Auditable` annotation is a custom Java annotation used to mark methods that should be audited. When applied to a method, it captures metadata about the operation being performed, enabling automatic audit logging of user actions within the application.

## Purpose

This annotation serves as a declarative mechanism to define audit requirements for specific methods. It allows developers to specify what action is being performed, the category of the audit event, the resource being affected, and whether the operation involves sensitive data. The annotation is retained at runtime, making it accessible for reflection-based audit processing.

## Annotation Elements

| Element | Type | Default | Description |
|---------|------|---------|-------------|
| `action` | `String` | (required) | A descriptive name for the action being audited (e.g., "CREATE_USER", "UPDATE_PROFILE"). |
| `category` | `AuditCategory` | `AuditCategory.WRITE` | The category of the audit event, typically indicating the type of operation (e.g., READ, WRITE, DELETE). |
| `resourceType` | `String` | `""` | The type of resource being acted upon (e.g., "User", "Order", "Document"). |
| `resourceIdExpression` | `String` | `""` | A SpEL (Spring Expression Language) expression that resolves to the identifier of the resource being audited. |
| `sensitive` | `boolean` | `false` | Indicates whether the audited operation involves sensitive data that may require special handling or masking. |

## Usage Example

```java
import com.upmatches.app.features.audit.annotations.Auditable;
import com.upmatches.app.features.audit.enums.AuditCategory;

public class UserService {

    @Auditable(
        action = "CREATE_USER",
        category = AuditCategory.WRITE,
        resourceType = "User",
        resourceIdExpression = "#user.id",
        sensitive = true
    )
    public User createUser(User user) {
        // Method implementation
    }
}
```

## Target and Retention

- **Target**: `ElementType.METHOD` – This annotation can only be applied to methods.
- **Retention**: `RetentionPolicy.RUNTIME` – The annotation is available at runtime for reflection-based processing.

## Related Components

- **`AuditCategory`**: An enum that defines the categories of audit events (e.g., READ, WRITE, DELETE).
- **Audit Interceptor/Aspect**: A component that processes methods annotated with `@Auditable` to generate and store audit logs.
