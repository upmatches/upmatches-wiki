# ListGameParticipantsService

The `ListGameParticipantsService` class is a Spring service responsible for retrieving the list of active participants for a specific game. It ensures that only authorized users can view participant data and optionally includes contact information if the requesting user is the game organizer.

## Purpose

This service provides a secure and transactional method to fetch all active participants of a game. It performs the following operations:
- Resolves the authenticated user.
- Validates that the game exists.
- Checks authorization to view the game.
- Retrieves all active participants ordered by join date.
- Maps participants to response objects, optionally including contact details for the organizer.

## Public Methods

### `execute(UUID id)`

Retrieves the list of active participants for the game identified by the given UUID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game. |

**Returns:** `List<GameParticipantResponse>` — A list of participant response objects.

**Throws:**
- `ResourceNotFoundException` — If the game does not exist or an error occurs during retrieval.

**Behavior:**
1. Resolves the authenticated user's ID.
2. Looks up the game by its ID; throws `ResourceNotFoundException` if not found.
3. Checks if the authenticated user has permission to view the game.
4. Determines whether to include contact methods based on whether the user is the game organizer.
5. Queries the repository for all active participants, ordered by join date.
6. Maps each participant to a `GameParticipantResponse` object, including the activity ID and contact methods flag.
7. Returns the list of responses.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameParticipantRepository` | Repository | Data access layer for game participants. |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user. |
| `IGameLookupService` | Service | Provides game lookup functionality. |
| `IGameAuthorizationService` | Service | Handles authorization checks for game operations. |
| `ServiceOperationExecutor` | Utility | Executes service operations with standardized error handling. |

## Annotations

- `@Service` — Marks this class as a Spring service component.
- `@Transactional(readOnly = true)` — Ensures the method runs within a read-only transaction for performance optimization.

## Class Modifiers

- `non-sealed` — This class is part of a sealed hierarchy, allowing it to be extended by other classes.

## Usage Example

```java
@Autowired
private ListGameParticipantsService listGameParticipantsService;

public void displayParticipants(UUID gameId) {
    List<GameParticipantResponse> participants = listGameParticipantsService.execute(gameId);
    participants.forEach(p -> System.out.println(p.getUser().getDisplayName()));
}
```
