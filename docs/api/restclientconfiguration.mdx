## Overview

The `RestClientConfiguration` class is a Spring configuration class that defines and configures several `RestClient` beans for different services. It provides a centralized way to manage HTTP client configurations, such as timeouts and headers, for external service integrations like Singpass, Auth0, and Apple.

## Public Methods

The class provides the following public methods:

| Method Name          | Parameters                                                                 | Return Type | Description                                                                                           |
|----------------------|----------------------------------------------------------------------------|-------------|-------------------------------------------------------------------------------------------------------|
| `singpassRestClient` | None                                                                       | `RestClient`| Creates a `RestClient` bean configured with default headers for Singpass integration.                  |
| `auth0RestClient`    | `Auth0Properties auth0Properties`                                          | `RestClient`| Creates a `RestClient` bean for Auth0 integration, requiring a valid domain from `Auth0Properties`.   |
| `appleRestClient`    | `AppleProperties appleProperties`                                          | `RestClient`| Creates a `RestClient` bean for Apple integration, requiring a valid JWKS URI from `AppleProperties`. |

### Method Details

#### `singpassRestClient`

- **Parameters:** None
- **Return Type:** `RestClient`
- **Description:** This method creates and returns a `RestClient` bean specifically configured for Singpass integration. It sets a default header for content type as `application/x-www-form-urlencoded`.

#### `auth0RestClient`

- **Parameters:** 
  - `Auth0Properties auth0Properties`: Contains configuration properties for Auth0, including the domain.
- **Return Type:** `RestClient`
- **Description:** This method creates and returns a `RestClient` bean for Auth0 integration. It requires the domain to be set in `Auth0Properties`. If the domain is not configured, it throws an `IllegalStateException`.

#### `appleRestClient`

- **Parameters:** 
  - `AppleProperties appleProperties`: Contains configuration properties for Apple, including the JWKS URI.
- **Return Type:** `RestClient`
- **Description:** This method creates and returns a `RestClient` bean for Apple integration. It requires the JWKS URI to be set in `AppleProperties`. If the JWKS URI is not configured, it throws an `IllegalStateException`.

## Configuration Details

- **Timeouts:** The `SimpleClientHttpRequestFactory` is used to set connection and read timeouts to 30,000 milliseconds (30 seconds) for all `RestClient` instances.
- **Headers:** The `singpassRestClient` method sets a default content type header to `application/x-www-form-urlencoded`.
- **Base URLs:** The `auth0RestClient` method constructs the base URL using the domain from `Auth0Properties`, prefixed with `https://`.
