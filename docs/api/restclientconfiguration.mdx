# RestClientConfiguration

The `RestClientConfiguration` class is a Spring `@Configuration` class that provides pre-configured `RestClient` beans for interacting with external authentication services. It centralizes HTTP client configuration, including timeouts and default headers, ensuring consistent behavior across all REST calls to Singpass, Auth0, and Apple services.

## Purpose

This configuration class creates three distinct `RestClient` beans, each tailored for a specific authentication provider:

- **Singpass**: Configured with form URL-encoded content type for token exchange.
- **Auth0**: Configured with a base URL derived from the Auth0 domain property.
- **Apple**: Configured with a default timeout but no base URL (typically used for JWKS key fetching).

All beans use a 30-second connect and read timeout to prevent hanging requests.

## Configuration Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `TIMEOUT_MS` | `30000` | Connection and read timeout in milliseconds |
| `CONTENT_TYPE` | `"Content-Type"` | HTTP header name for content type |
| `HTTPS_PREFIX` | `"https://"` | Prefix added to Auth0 domain |

## Beans

### `singpassRestClient`

Creates a `RestClient` bean named `"singpassRestClient"` configured for Singpass authentication.

**Configuration:**
- Default `Content-Type` header set to `application/x-www-form-urlencoded`
- 30-second connect and read timeout

**Returns:** `RestClient` - A pre-configured client for Singpass API calls.

### `auth0RestClient`

Creates a `RestClient` bean named `"auth0RestClient"` configured for Auth0 authentication.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `auth0Properties` | `Auth0Properties` | Configuration properties containing the Auth0 domain |

**Configuration:**
- Base URL set to `https://{domain}` where `domain` is from `auth0Properties.domain()`
- 30-second connect and read timeout

**Throws:**
- `IllegalStateException` if `auth0Properties.domain()` is null or blank

**Returns:** `RestClient` - A pre-configured client for Auth0 API calls.

### `appleRestClient`

Creates a `RestClient` bean named `"appleRestClient"` configured for Apple authentication.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `appleProperties` | `AppleProperties` | Configuration properties containing the Apple JWKS URI |

**Configuration:**
- 30-second connect and read timeout
- No base URL set (the JWKS URI is typically passed at call time)

**Throws:**
- `IllegalStateException` if `appleProperties.jwksUri()` is null or blank

**Returns:** `RestClient` - A pre-configured client for Apple API calls.

## Private Methods

### `createRequestFactory()`

Creates a `SimpleClientHttpRequestFactory` with a 30-second connect and read timeout.

**Returns:** `SimpleClientHttpRequestFactory` - A configured request factory for all RestClient beans.

## Usage Example

```java
@Autowired
@Qualifier("auth0RestClient")
private RestClient auth0RestClient;

public void callAuth0() {
    String response = auth0RestClient.get()
        .uri("/userinfo")
        .retrieve()
        .body(String.class);
}
```

## Dependencies

This configuration requires the following Spring Boot properties to be defined in your `application.yml` or `application.properties`:

```yaml
app:
  auth0:
    domain: your-tenant.auth0.com
  apple:
    jwks-uri: https://appleid.apple.com/auth/keys
```
