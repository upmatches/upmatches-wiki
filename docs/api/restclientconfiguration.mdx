# RestClientConfiguration

The `RestClientConfiguration` class is a Spring `@Configuration` class that provides pre-configured `RestClient` beans for interacting with external authentication providers. It centralizes HTTP client configuration, including connection and read timeouts, and ensures that required properties are present before creating the beans.

## Purpose

This configuration class creates three distinct `RestClient` beans, each tailored for a specific authentication service:

- **Singpass**: A generic client for form-encoded requests.
- **Auth0**: A client pre-configured with the Auth0 domain as the base URL.
- **Apple**: A client for fetching Apple's JWKS (JSON Web Key Set) URI.

All beans use a 30-second timeout for both connection and read operations.

## Configuration Details

| Property | Value |
|----------|-------|
| `TIMEOUT_MS` | 30000 (30 seconds) |
| `CONTENT_TYPE` | `Content-Type` |
| `HTTPS_PREFIX` | `https://` |

## Beans

### `singpassRestClient`

Creates a `RestClient` bean named `"singpassRestClient"` with a default `Content-Type` header of `application/x-www-form-urlencoded`.

| Parameter | Type | Description |
|-----------|------|-------------|
| None | - | No dependencies |

**Returns**: `RestClient` - A configured client for Singpass authentication.

### `auth0RestClient`

Creates a `RestClient` bean named `"auth0RestClient"` with the Auth0 domain as the base URL. The domain is read from `Auth0Properties`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `auth0Properties` | `Auth0Properties` | Configuration properties containing the Auth0 domain |

**Returns**: `RestClient` - A configured client for Auth0 authentication.

**Throws**: `IllegalStateException` if the Auth0 domain is not configured.

### `appleRestClient`

Creates a `RestClient` bean named `"appleRestClient"` for fetching Apple's JWKS URI. The JWKS URI is read from `AppleProperties`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `appleProperties` | `AppleProperties` | Configuration properties containing the Apple JWKS URI |

**Returns**: `RestClient` - A configured client for Apple authentication.

**Throws**: `IllegalStateException` if the Apple JWKS URI is not configured.

## Private Methods

### `createRequestFactory()`

Creates a `SimpleClientHttpRequestFactory` with a 30-second timeout for both connection and read operations.

| Parameter | Type | Description |
|-----------|------|-------------|
| None | - | No parameters |

**Returns**: `SimpleClientHttpRequestFactory` - A configured request factory with timeouts.

## Usage Example

```java
@Autowired
@Qualifier("auth0RestClient")
private RestClient auth0RestClient;

public void authenticateWithAuth0() {
    String response = auth0RestClient.get()
        .uri("/oauth/token")
        .retrieve()
        .body(String.class);
}
```
