# IListMyJoinedGamesCursorService

The `IListMyJoinedGamesCursorService` is a **sealed interface** that defines the contract for retrieving a cursor-paginated list of games the current user has joined. It is part of the game features package and is designed to be implemented only by the `ListMyJoinedGamesCursorService` class.

## Purpose

This interface provides a standardized way to fetch joined games with cursor-based pagination. By using a sealed interface, the design enforces a controlled implementation hierarchy, ensuring that only the permitted class (`ListMyJoinedGamesCursorService`) can fulfill this contract. This pattern is useful for maintaining a clear and secure service layer in the application.

## Method Summary

| Method | Description |
|--------|-------------|
| `execute(String cursor, int size)` | Retrieves a cursor-paginated response containing games the user has joined. |

## Method Details

### `execute`

```java
CursorPagedResponse<GameResponse> execute(String cursor, int size)
```

Executes the query to fetch a page of joined games based on the provided cursor and page size.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The cursor indicating the starting point for the page. Can be `null` or empty to fetch the first page. |
| `size` | `int` | The maximum number of items to return in the response. |

**Returns:**

| Type | Description |
|------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing a list of `GameResponse` objects and the next cursor for subsequent requests. |

## Implementation Notes

- The interface is **sealed**, meaning only the `ListMyJoinedGamesCursorService` class is allowed to implement it.
- The `CursorPagedResponse` and `GameResponse` types are defined elsewhere in the `com.upmatches.app.features.game.responses` package.
- The `cursor` parameter follows standard cursor-based pagination semantics: an empty or `null` cursor typically indicates the first page, while subsequent pages use the cursor returned in the previous response.

## Example Usage

```java
IListMyJoinedGamesCursorService service = new ListMyJoinedGamesCursorService();

// Fetch the first page of 20 joined games
CursorPagedResponse<GameResponse> firstPage = service.execute(null, 20);

// Fetch the next page using the cursor from the previous response
CursorPagedResponse<GameResponse> nextPage = service.execute(firstPage.getNextCursor(), 20);
```
