# IListMyJoinedGamesCursorService

## Purpose

The `IListMyJoinedGamesCursorService` interface defines the contract for retrieving a paginated list of games that the current user has joined, using cursor-based pagination. This sealed interface permits only the `ListMyJoinedGamesCursorService` class to implement it, ensuring controlled extension and a single implementation within the application.

## Interface Definition

```java
public sealed interface IListMyJoinedGamesCursorService permits ListMyJoinedGamesCursorService {
    CursorPagedResponse<GameResponse> execute(String cursor, int size);
}
```

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(String cursor, int size)` | `CursorPagedResponse<GameResponse>` | Retrieves a cursor-paginated list of games joined by the current user. |

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The pagination cursor indicating the starting point for the next page of results. Pass `null` or an empty string to retrieve the first page. |
| `size` | `int` | The maximum number of game records to return in a single page. Must be a positive integer. |

## Return Type

The method returns a `CursorPagedResponse<GameResponse>` object containing:

- A list of `GameResponse` objects representing the games joined by the user
- A cursor string for retrieving the next page of results (if more results exist)
- Metadata about the paginated response (e.g., total count, has more pages)

## Usage Example

```java
// First page request
CursorPagedResponse<GameResponse> firstPage = service.execute(null, 20);

// Subsequent page request using cursor from previous response
CursorPagedResponse<GameResponse> nextPage = service.execute(firstPage.getNextCursor(), 20);
```

## Implementation Notes

- This is a **sealed interface**, meaning only the `ListMyJoinedGamesCursorService` class can implement it
- The interface enforces cursor-based pagination, which is more efficient for large datasets compared to offset-based pagination
- The `GameResponse` object contains the details of each joined game
- The `CursorPagedResponse` wrapper provides a standardized way to handle paginated results across the application
