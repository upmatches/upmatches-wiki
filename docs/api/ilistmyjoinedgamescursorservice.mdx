## Purpose

The `IListMyJoinedGamesCursorService` interface is part of the `com.upmatches.app.features.game.services` package. It defines a contract for services that provide a paginated list of games that a user has joined. This interface is designed to be implemented by classes that handle the logic for retrieving game data in a cursor-based pagination format.

## Public Methods

The interface declares the following public method:

### `execute`

This method retrieves a paginated list of games that the user has joined, using a cursor-based pagination approach.

| Parameter | Type   | Description                                           |
|-----------|--------|-------------------------------------------------------|
| `cursor`  | String | The cursor indicating the starting point for fetching the next set of results. |
| `size`    | int    | The number of game records to retrieve in the response. |

#### Return Type

- **`CursorPagedResponse<GameResponse>`**: This method returns a `CursorPagedResponse` containing `GameResponse` objects, which represent the paginated list of games joined by the user. The response includes the data and the next cursor for subsequent requests.
