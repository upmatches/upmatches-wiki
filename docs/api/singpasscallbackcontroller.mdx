## Overview

The `SingpassCallbackController` class is a Spring REST controller responsible for handling the callback from Singpass authentication. It processes the authentication response, exchanges authorization codes for tokens, and manages user sessions and cookies. This controller is a crucial part of the authentication flow, ensuring that users are correctly authenticated and redirected to the appropriate platform (web or mobile) with the necessary tokens.

## Public Methods

### `callbackSingpass`

Handles the Singpass callback request, processes the authentication response, and returns the appropriate HTTP response.

| Parameter | Type                  | Description                                                                 |
|-----------|-----------------------|-----------------------------------------------------------------------------|
| `code`    | `String`              | The authorization code returned by Singpass.                                |
| `state`   | `String`              | The state parameter to validate the request.                                |
| `request` | `HttpServletRequest`  | The HTTP request object.                                                    |
| `response`| `HttpServletResponse` | The HTTP response object.                                                   |

**Returns**: `ResponseEntity<Object>` - The HTTP response entity containing the redirect or error information.

## Detailed Description

### Purpose

The `SingpassCallbackController` is designed to handle the callback from Singpass, a popular authentication service in Singapore. It ensures that the authentication process is completed securely and that users are redirected appropriately based on their platform (web or mobile).

### Key Responsibilities

- **Error Handling**: The controller checks for any errors returned by Singpass and throws an `AuthenticationException` if any are found.
- **Code Exchange**: It exchanges the authorization code for a token using the `ISingpassAuthService`.
- **User Management**: The controller finds or creates a user based on the Singpass UUID and logs the user in.
- **Token Management**: It generates access and refresh tokens using `IJwtTokenService` and stores the refresh token.
- **Response Building**: Depending on the platform, it builds a redirect response for web or mobile users, setting the necessary cookies or redirect URLs.

### Private Methods

- **`rejectIfProviderError`**: Checks for errors in the request and logs them.
- **`exchangeCode`**: Exchanges the authorization code for a token.
- **`parseSingpassUuid`**: Parses the Singpass UUID from the token.
- **`findOrCreateUser`**: Finds an existing user or creates a new one based on the Singpass UUID.
- **`buildResponse`**: Constructs the HTTP response for web users.
- **`buildMobileRedirect`**: Constructs the HTTP response for mobile users.

### Dependencies

The controller relies on several services and repositories, including:

- `ISingpassAuthService`: For exchanging authorization codes.
- `IAuthSessionStore`: For managing authentication sessions.
- `UserRepository`: For accessing user data.
- `IJwtTokenService`: For generating JWT tokens.
- `IRefreshTokenStore`: For storing refresh tokens.
- `ICookieHelper`: For managing cookies.
- `IDevTokenPageRenderer`: For rendering development token pages.
- `JwtProperties`: For accessing JWT configuration properties.
