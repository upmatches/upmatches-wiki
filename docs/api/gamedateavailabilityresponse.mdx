# GameDateAvailabilityResponse

The `GameDateAvailabilityResponse` is a Java record that represents the availability status of a game on a specific date. It is used to communicate whether a particular date has an associated game scheduled, typically in response to queries about game schedules or date availability.

## Purpose

This record serves as a lightweight data transfer object (DTO) for conveying two key pieces of information:
- The date being queried.
- Whether a game exists on that date.

It is commonly used in REST API responses or internal service layers to provide a clear, immutable representation of date-based game availability.

## Record Definition

```java
public record GameDateAvailabilityResponse(
    LocalDate date,
    Boolean hasGame
) {}
```

## Fields

| Field    | Type        | Description                                                                 |
|----------|-------------|-----------------------------------------------------------------------------|
| `date`   | `LocalDate` | The specific date being evaluated for game availability.                    |
| `hasGame`| `Boolean`   | Indicates whether a game is scheduled on the given date (`true` or `false`).|

## Usage Example

```java
// Creating a response indicating a game exists on 2024-12-25
GameDateAvailabilityResponse response = new GameDateAvailabilityResponse(
    LocalDate.of(2024, 12, 25),
    true
);

// Accessing fields
LocalDate date = response.date();       // 2024-12-25
Boolean hasGame = response.hasGame();   // true
```

## Notes

- As a Java record, this class is immutable and provides automatic implementations of `equals()`, `hashCode()`, and `toString()`.
- The `hasGame` field uses the wrapper type `Boolean` rather than the primitive `boolean`, allowing for `null` values if the availability status is unknown or not applicable.
- This record is part of the `com.upmatches.app.features.game.responses` package and is intended for use within the game scheduling feature of the application.
