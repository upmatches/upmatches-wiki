## Overview

The `GameDateAvailabilityResponse` class is a Java record that represents the availability of a game on a specific date. This class is part of the `com.upmatches.app.features.game.responses` package and is used to encapsulate the response data related to game scheduling.

## Purpose

The primary purpose of the `GameDateAvailabilityResponse` class is to provide a structured response indicating whether a game is scheduled on a particular date. It contains two fields: a `LocalDate` representing the date in question and a `Boolean` indicating the presence of a game on that date.

## Public Methods

Since `GameDateAvailabilityResponse` is a record, it automatically provides the following public methods:

| Method Signature | Description |
|------------------|-------------|
| `LocalDate date()` | Returns the date associated with this response. |
| `Boolean hasGame()` | Returns `true` if there is a game on the specified date, otherwise `false`. |

## Fields

The `GameDateAvailabilityResponse` record contains the following fields:

| Field Name | Type | Description |
|------------|------|-------------|
| `date`     | `LocalDate` | The date for which the game availability is being checked. |
| `hasGame`  | `Boolean`  | Indicates whether a game is scheduled on the specified date. |

This structure allows for easy integration with systems that need to check game schedules and respond with clear, concise data regarding game availability.
