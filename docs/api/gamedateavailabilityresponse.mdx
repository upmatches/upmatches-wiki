# GameDateAvailabilityResponse

The `GameDateAvailabilityResponse` is a Java record that represents the availability status of a game for a specific date. It is used as a response object in the game-related features of the application, typically to indicate whether a game exists or is scheduled on a given date.

## Purpose

This record provides a simple, immutable data carrier for communicating date-based game availability from the backend to the client. It is commonly used in API responses where the client needs to know, for a particular date, whether a game is present (e.g., for calendar views, scheduling, or availability checks).

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `date` | `LocalDate` | The date for which game availability is being reported. |
| `hasGame` | `Boolean` | Indicates whether a game exists on the specified date. `true` if a game is present, `false` otherwise. |

## Usage

This record is typically returned by service or controller methods that query game schedules or availability. For example:

```java
GameDateAvailabilityResponse response = new GameDateAvailabilityResponse(
    LocalDate.of(2025, 4, 15),
    true
);
```

The response can then be serialized to JSON (e.g., using Jackson) for API consumption:

```json
{
  "date": "2025-04-15",
  "hasGame": true
}
```

## Notes

- The record is immutable and thread-safe by design.
- The `hasGame` field is of type `Boolean` (object) rather than `boolean` (primitive), allowing for `null` values if the availability status is unknown or not applicable.
- The `date` field uses `java.time.LocalDate`, ensuring proper date handling without time or timezone components.
