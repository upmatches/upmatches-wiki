# GameDateAvailabilityResponse

The `GameDateAvailabilityResponse` is a Java record used to represent the availability status of a game on a specific date. It is typically returned from API endpoints that check whether a game exists or is scheduled for a given date.

This record is part of the `com.upmatches.app.features.game.responses` package and is designed to be immutable, concise, and easy to serialize/deserialize (e.g., to/from JSON).

## Purpose

- To provide a simple data transfer object (DTO) that pairs a `LocalDate` with a boolean flag indicating game availability.
- To be used in response payloads for queries like "Is there a game on this date?".
- To leverage Java's `record` feature for automatic generation of constructors, accessors, `equals()`, `hashCode()`, and `toString()`.

## Record Components

| Component | Type        | Description                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| `date`    | `LocalDate` | The date for which game availability is being reported.                     |
| `hasGame` | `Boolean`   | A boolean flag indicating whether a game exists on the specified date.      |

## Usage Example

```java
import com.upmatches.app.features.game.responses.GameDateAvailabilityResponse;
import java.time.LocalDate;

public class ExampleUsage {
    public static void main(String[] args) {
        GameDateAvailabilityResponse response = new GameDateAvailabilityResponse(
            LocalDate.of(2025, 4, 15),
            true
        );

        System.out.println(response.date());    // 2025-04-15
        System.out.println(response.hasGame()); // true
        System.out.println(response);           // GameDateAvailabilityResponse[date=2025-04-15, hasGame=true]
    }
}
```

## Notes

- The `hasGame` field is of type `Boolean` (object) rather than `boolean` (primitive). This allows for `null` values, which may be useful when the availability status is unknown or not applicable.
- This record is immutable by design, making it thread-safe and suitable for use in reactive or concurrent environments.
- When serialized to JSON (e.g., using Jackson), the field names will match the component names: `date` and `hasGame`.
