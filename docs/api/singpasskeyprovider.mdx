# SingpassKeyProvider

The `SingpassKeyProvider` class is a Spring service that manages and provides access to Singpass cryptographic keys. It implements the `ISingpassKeyProvider` interface and handles the loading, caching, and exposure of both signing and encryption keys used for Singpass authentication.

## Purpose

This service is responsible for:
- Loading and caching Singpass private keys (signing and encryption) from file paths configured in `SingpassProperties`
- Providing access to the public keys in JWKS (JSON Web Key Set) format
- Ensuring thread-safe lazy initialization of keys
- Validating key files exist and contain private components

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getSigningKey()` | `ECKey` | Returns the cached signing key, loading it from the configured path if not yet loaded |
| `getSigningKeyId()` | `String` | Returns the key ID (kid) of the signing key |
| `getEncryptionKey()` | `ECKey` | Returns the cached encryption key, loading it from the configured path if not yet loaded |
| `getPublicJwksJson()` | `String` | Returns the public keys in JWKS JSON format, building it from the signing and encryption public keys |

## Constructor

### `SingpassKeyProvider(SingpassProperties properties)`

Creates a new instance with the provided configuration properties.

**Parameters:**
- `properties` - Configuration properties containing paths to the private key files

## Key Features

### Thread-Safe Lazy Loading
All key access methods use double-checked locking with `volatile` fields to ensure thread-safe lazy initialization while maintaining good performance.

### Key Validation
The `loadKey` method performs several validations:
- Checks that the file path is configured (not null or blank)
- Verifies the key file exists on the filesystem
- Ensures the parsed key contains a private component

### Error Handling
The service throws `IllegalStateException` with descriptive messages for various failure scenarios:
- Missing key file path configuration
- Key file not found at specified path
- Missing private component in key file
- IO errors reading key file
- Parse errors parsing JWK format

## Private Methods

### `loadKey(String filePath, String use)`
Loads and parses an EC private key from a JSON file.

**Parameters:**
- `filePath` - Path to the JWK JSON file
- `use` - Key usage description ("sig" or "enc") for error messages

**Returns:** `ECKey` - The parsed private key

**Throws:** `IllegalStateException` if validation fails or parsing errors occur

### `buildPublicJwksJson()`
Builds a JWKS JSON string containing the public components of both the signing and encryption keys.

**Returns:** `String` - JWKS JSON representation of public keys

## Dependencies

- `com.nimbusds.jose.jwk.ECKey` - Nimbus JOSE+JWT library for EC key handling
- `com.nimbusds.jose.jwk.JWKSet` - Nimbus library for JWK set management
- `com.upmatches.app.features.auth.properties.SingpassProperties` - Application configuration properties
- `org.slf4j.Logger` - Logging framework

## Usage Example

```java
@Autowired
private SingpassKeyProvider keyProvider;

public void authenticateWithSingpass() {
    ECKey signingKey = keyProvider.getSigningKey();
    String signingKeyId = keyProvider.getSigningKeyId();
    ECKey encryptionKey = keyProvider.getEncryptionKey();
    String publicJwks = keyProvider.getPublicJwksJson();
    
    // Use keys for Singpass authentication
}
```

## Configuration

The service expects the following properties to be configured in `SingpassProperties`:
- `privateSigningKeyPath()` - Path to the signing private key JWK file
- `privateEncryptionKeyPath()` - Path to the encryption private key JWK file
