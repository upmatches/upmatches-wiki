## Overview

The `SingpassKeyProvider` class is a service component in a Java application responsible for managing cryptographic keys used for signing and encryption in the Singpass authentication feature. It ensures the secure loading and provision of these keys, which are essential for maintaining the integrity and confidentiality of authentication processes.

## Public Methods

The following table documents the public methods available in the `SingpassKeyProvider` class:

| Method Name       | Parameters | Return Type | Description |
|-------------------|------------|-------------|-------------|
| `getSigningKey`   | None       | `ECKey`     | Retrieves the signing key, loading it from the configured file path if not already loaded. |
| `getSigningKeyId` | None       | `String`    | Returns the key ID of the signing key. |
| `getEncryptionKey`| None       | `ECKey`     | Retrieves the encryption key, loading it from the configured file path if not already loaded. |
| `getPublicJwksJson` | None     | `String`    | Provides the public JSON Web Key Set (JWKS) representation of the signing and encryption keys. |

## Detailed Method Descriptions

### `getSigningKey`

- **Description**: This method returns the signing key used for cryptographic signing operations. If the key is not already loaded, it reads the key from the file specified in the application properties.
- **Return Type**: `ECKey`

### `getSigningKeyId`

- **Description**: This method returns the key ID (`kid`) of the signing key, which is a unique identifier for the key.
- **Return Type**: `String`

### `getEncryptionKey`

- **Description**: This method returns the encryption key used for cryptographic encryption operations. If the key is not already loaded, it reads the key from the file specified in the application properties.
- **Return Type**: `ECKey`

### `getPublicJwksJson`

- **Description**: This method returns a JSON representation of the public keys for both signing and encryption, formatted as a JSON Web Key Set (JWKS). This is typically used for public key distribution.
- **Return Type**: `String`

## Usage

The `SingpassKeyProvider` class is typically used within the authentication service of an application to manage and provide cryptographic keys necessary for secure operations. It ensures that keys are loaded securely and are available for use in signing and encryption tasks.
