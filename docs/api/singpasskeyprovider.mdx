# SingpassKeyProvider

The `SingpassKeyProvider` class is a Spring service that manages and provides access to Singpass cryptographic keys used for signing and encryption operations. It implements the `ISingpassKeyProvider` interface and follows a lazy initialization pattern with double-checked locking for thread safety.

## Purpose

This service is responsible for:
- Loading and caching Singpass private EC keys (signing and encryption) from file paths configured in `SingpassProperties`
- Providing access to the loaded keys and their identifiers
- Generating and caching a public JWKS (JSON Web Key Set) JSON string containing the public components of both keys

## Key Features

- **Lazy Loading**: Keys are loaded on first access, not at service initialization
- **Thread Safety**: Uses double-checked locking with `volatile` fields for safe concurrent access
- **Error Handling**: Provides clear error messages for missing configurations, missing files, and invalid key formats
- **Public JWKS Generation**: Automatically builds a JWKS containing public keys for both signing and encryption

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `getSigningKey()` | `ECKey` | Returns the cached signing key, loading it from the configured path if not already loaded |
| `getSigningKeyId()` | `String` | Returns the key ID (kid) of the signing key |
| `getEncryptionKey()` | `ECKey` | Returns the cached encryption key, loading it from the configured path if not already loaded |
| `getPublicJwksJson()` | `String` | Returns the cached public JWKS JSON string, building it from both keys if not already cached |

## Private Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `loadKey(String filePath, String use)` | `ECKey` | Loads and parses an EC key from a JSON file, validating it has a private component |
| `buildPublicJwksJson()` | `String` | Constructs a JWKS JSON string containing public keys for both signing and encryption |

## Error Handling

The `loadKey` method throws `IllegalStateException` with descriptive messages for the following scenarios:

| Condition | Error Message Pattern |
|-----------|----------------------|
| File path not configured | "Singpass {use} key file path is not configured." |
| Key file not found | "Singpass {use} key file not found at '{path}'." |
| Missing private component | "Singpass {use} key at '{path}' is missing the private component (d)." |
| Failed to read file | "Failed to read Singpass {use} key file" |
| Failed to parse JSON | "Failed to parse Singpass {use} key file as JWK" |

## Dependencies

- **Spring Framework**: `@Service` annotation for dependency injection
- **Nimbus JOSE+JWT**: `ECKey` and `JWKSet` classes for key handling
- **SLF4J**: Logging framework for key loading events
- **SingpassProperties**: Configuration properties providing key file paths

## Usage Example

```java
@Autowired
private SingpassKeyProvider keyProvider;

public void demonstrateUsage() {
    // Get the signing key
    ECKey signingKey = keyProvider.getSigningKey();
    String signingKeyId = keyProvider.getSigningKeyId();
    
    // Get the encryption key
    ECKey encryptionKey = keyProvider.getEncryptionKey();
    
    // Get the public JWKS for distribution
    String publicJwks = keyProvider.getPublicJwksJson();
}
```
