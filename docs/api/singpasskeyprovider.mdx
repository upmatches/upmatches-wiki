## Purpose

The `SingpassKeyProvider` class is a service component in a Java application that manages cryptographic keys used for signing and encryption in the context of Singpass authentication. It ensures that the keys are loaded from specified file paths, and provides methods to access the signing and encryption keys as well as their public JSON Web Key Set (JWKS) representation.

## Public Methods

| Method Name       | Parameters | Return Type | Description |
|-------------------|------------|-------------|-------------|
| `getSigningKey`   | None       | `ECKey`     | Retrieves the signing key, loading it from the configured file path if necessary. |
| `getSigningKeyId` | None       | `String`    | Returns the key ID of the signing key. |
| `getEncryptionKey`| None       | `ECKey`     | Retrieves the encryption key, loading it from the configured file path if necessary. |
| `getPublicJwksJson` | None     | `String`    | Provides the public JSON Web Key Set (JWKS) as a JSON string, containing both the signing and encryption keys. |

## Detailed Description

- **getSigningKey**: This method checks if the signing key is already loaded. If not, it synchronizes and loads the key from the file path specified in the `SingpassProperties`. The key is expected to be in JSON format and must include a private component.

- **getSigningKeyId**: This method returns the key ID of the signing key, which is useful for identifying the key in cryptographic operations.

- **getEncryptionKey**: Similar to `getSigningKey`, this method ensures the encryption key is loaded from the specified file path if it hasn't been loaded already. It also requires the key to have a private component.

- **getPublicJwksJson**: This method constructs a JSON Web Key Set (JWKS) containing the public parts of both the signing and encryption keys. This is useful for sharing the public keys with external systems that need to verify signatures or encrypt data for the application.

The class uses the `ECKey` and `JWKSet` classes from the Nimbus JOSE+JWT library to handle JSON Web Keys, and relies on the `SingpassProperties` to obtain file paths for the keys. It logs key loading events and handles exceptions related to file I/O and JSON parsing.
