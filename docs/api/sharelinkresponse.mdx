# ShareLinkResponse

The `ShareLinkResponse` class is a Java record that serves as a Data Transfer Object (DTO) for representing a shareable link's response data. It encapsulates all relevant information about a shortened link that has been generated for sharing content, including the generated URLs, resource details, and usage statistics.

This record is typically used in API responses to provide clients with complete information about a created or retrieved share link. It includes both the original shortened URL and platform-specific URLs (web and mobile), making it suitable for multi-platform sharing scenarios.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | Unique identifier for the share link |
| `code` | `String` | Short code used in the shortened URL |
| `resourceType` | `ResourceType` | Type of resource being shared (e.g., post, profile) |
| `resourceId` | `String` | Identifier of the shared resource |
| `shareUrl` | `String` | The shortened share URL |
| `webUrl` | `String` | Web-specific URL for the shared content |
| `mobileUrl` | `String` | Mobile-specific URL for the shared content |
| `clickCount` | `Long` | Number of times the share link has been clicked |
| `createdAt` | `Instant` | Timestamp when the share link was created |

## Methods

### `fromShortLink`

```java
public static ShareLinkResponse fromShortLink(
    ShortLink link,
    String shareUrl,
    String webUrl,
    String mobileUrl,
    Long clickCount)
```

Creates a `ShareLinkResponse` instance from a `ShortLink` entity and additional URL information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The source `ShortLink` entity containing core link data |
| `shareUrl` | `String` | The generated shortened share URL |
| `webUrl` | `String` | Web-specific URL for the shared content |
| `mobileUrl` | `String` | Mobile-specific URL for the shared content |
| `clickCount` | `Long` | Current click count for the share link |

**Returns:** `ShareLinkResponse` - A new response object populated with data from the provided `ShortLink` entity and URL parameters.

**Example usage:**

```java
ShortLink shortLink = shortLinkRepository.findById(linkId);
ShareLinkResponse response = ShareLinkResponse.fromShortLink(
    shortLink,
    "https://short.url/abc123",
    "https://example.com/web/content",
    "https://example.com/mobile/content",
    42L
);
```
