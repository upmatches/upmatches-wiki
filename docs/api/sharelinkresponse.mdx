# ShareLinkResponse

The `ShareLinkResponse` class is a Java record that serves as a Data Transfer Object (DTO) for representing a shareable link response in the UpMatches application. It encapsulates all relevant information about a shortened link, including its unique identifier, generated code, resource type, and various URL representations for different platforms.

This record is designed to provide a clean, immutable response structure when clients request information about a shortened link. It includes both the original link metadata and the computed URLs for sharing across different contexts (web, mobile, and general share).

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique identifier for the share link |
| `code` | `String` | Shortened code or alias for the link |
| `resourceType` | `ResourceType` | Type of resource being shared (enum) |
| `resourceId` | `String` | Identifier of the shared resource |
| `shareUrl` | `String` | General shareable URL |
| `webUrl` | `String` | Web-specific URL for the resource |
| `mobileUrl` | `String` | Mobile-specific URL for the resource |
| `clickCount` | `Long` | Number of times the link has been clicked |
| `createdAt` | `Instant` | Timestamp when the link was created |

## Methods

### `fromShortLink`

```java
public static ShareLinkResponse fromShortLink(
    ShortLink link,
    String shareUrl,
    String webUrl,
    String mobileUrl,
    Long clickCount)
```

Factory method that creates a `ShareLinkResponse` instance from a `ShortLink` entity and additional URL information.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The source `ShortLink` entity containing link metadata |
| `shareUrl` | `String` | The general shareable URL for the link |
| `webUrl` | `String` | The web-specific URL for the resource |
| `mobileUrl` | `String` | The mobile-specific URL for the resource |
| `clickCount` | `Long` | The current click count for the link |

**Returns:**

| Type | Description |
|------|-------------|
| `ShareLinkResponse` | A new `ShareLinkResponse` instance populated with data from the provided `ShortLink` and URL parameters |

**Example Usage:**

```java
ShortLink shortLink = shortLinkRepository.findById(linkId);
ShareLinkResponse response = ShareLinkResponse.fromShortLink(
    shortLink,
    "https://upmatches.com/s/abc123",
    "https://upmatches.com/resource/123",
    "upmatches://resource/123",
    42L
);
```

## Implementation Notes

- The record is immutable by design, ensuring thread safety and data consistency.
- The `fromShortLink` factory method provides a convenient way to transform a `ShortLink` entity into a response DTO, separating the internal domain model from the API response format.
- The `ResourceType` enum allows for flexible categorization of shared resources (e.g., user profiles, posts, events).
- All timestamps are stored as `Instant` for precise time handling across different time zones.
