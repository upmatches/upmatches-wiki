## Overview

The `ShareLinkResponse` class is a Java record that encapsulates the response details for a shared link within the application. It is part of the `com.upmatches.app.features.sharelink.responses` package. This class is designed to provide a structured response containing essential information about a shared link, such as its unique identifier, associated URLs, and metadata like click count and creation timestamp.

## Public Methods

### fromShortLink

The `fromShortLink` method is a static factory method that creates an instance of `ShareLinkResponse` from a `ShortLink` object and additional URL and click count information.

| Parameter   | Type         | Description                                                   |
|-------------|--------------|---------------------------------------------------------------|
| `link`      | `ShortLink`  | The `ShortLink` entity containing basic link information.     |
| `shareUrl`  | `String`     | The URL used for sharing the link.                            |
| `webUrl`    | `String`     | The web URL associated with the link.                         |
| `mobileUrl` | `String`     | The mobile URL associated with the link.                      |
| `clickCount`| `Long`       | The number of times the link has been clicked.                |

#### Return Type

- **`ShareLinkResponse`**: Returns a new instance of `ShareLinkResponse` populated with data from the `ShortLink` entity and additional parameters.

## Fields

The `ShareLinkResponse` record contains the following fields:

| Field Name   | Type          | Description                                                  |
|--------------|---------------|--------------------------------------------------------------|
| `id`         | `UUID`        | Unique identifier for the shared link.                       |
| `code`       | `String`      | Code representing the shared link.                           |
| `resourceType` | `ResourceType` | Enum indicating the type of resource being shared.          |
| `resourceId` | `String`      | Identifier for the resource associated with the link.        |
| `shareUrl`   | `String`      | URL used for sharing the link.                               |
| `webUrl`     | `String`      | Web URL associated with the link.                            |
| `mobileUrl`  | `String`      | Mobile URL associated with the link.                         |
| `clickCount` | `Long`        | Number of times the link has been clicked.                   |
| `createdAt`  | `Instant`     | Timestamp indicating when the link was created.              |

This structured approach allows for easy integration and use of shared link data across different parts of the application.
