# PricingRequest

The `PricingRequest` class is a Java record that serves as a Data Transfer Object (DTO) for receiving pricing configuration data from API clients. It encapsulates all the necessary fields to define a pricing structure for a game feature, including pricing mode, currency, and various price components.

This record is designed with Jakarta Bean Validation annotations to ensure that incoming data meets business requirements before being processed. It provides a convenient `toPricing()` method to convert the request data into a domain `Pricing` value object.

## Record Definition

```java
public record PricingRequest(
    PricingMode mode,
    String currency,
    BigDecimal flatPrice,
    BigDecimal malePrice,
    BigDecimal femalePrice,
    BigDecimal basePrice,
    BigDecimal pricePerShuttle
)
```

## Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `mode` | `PricingMode` | `@NotNull` | The pricing mode (enum) that determines how pricing is calculated |
| `currency` | `String` | `@NotNull`, `@Pattern(regexp = "^[A-Z]{3}$")` | ISO-4217 3-letter currency code (e.g., USD, EUR) |
| `flatPrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Flat price amount, must be >= 0, max 8 digits with 2 decimal places |
| `malePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price for male participants, must be >= 0, max 8 digits with 2 decimal places |
| `femalePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price for female participants, must be >= 0, max 8 digits with 2 decimal places |
| `basePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Base price amount, must be >= 0, max 8 digits with 2 decimal places |
| `pricePerShuttle` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price per shuttle/unit, must be >= 0, max 8 digits with 2 decimal places |

## Methods

### `toPricing()`

```java
public Pricing toPricing()
```

Converts this request object into a domain `Pricing` value object.

**Returns:** `Pricing` - A new `Pricing` instance constructed from the request's field values, with the currency string converted to a `Currency` value object.

## Usage Example

```java
// Example: Creating a PricingRequest for a flat-rate pricing model
PricingRequest request = new PricingRequest(
    PricingMode.FLAT,
    "USD",
    new BigDecimal("25.00"),  // flatPrice
    null,                      // malePrice (not used in FLAT mode)
    null,                      // femalePrice (not used in FLAT mode)
    null,                      // basePrice (not used in FLAT mode)
    null                       // pricePerShuttle (not used in FLAT mode)
);

// Convert to domain object
Pricing pricing = request.toPricing();
```

## Validation Notes

- All `BigDecimal` fields are validated to ensure they have at most 8 integer digits and 2 decimal places.
- All monetary values must be greater than or equal to 0.00.
- The `currency` field must be a valid 3-letter uppercase ISO-4217 code.
- The `mode` field is required and must be a valid `PricingMode` enum value.
