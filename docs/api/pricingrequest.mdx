# PricingRequest

The `PricingRequest` class is a Java record that serves as a Data Transfer Object (DTO) for creating or updating pricing configurations within the game feature module. It encapsulates all necessary pricing parameters, including the pricing mode, currency, and various price components (flat, male, female, base, and per-shuttle prices). The record uses Jakarta Bean Validation annotations to enforce data integrity and business rules before processing.

## Purpose

- **Data Transfer**: Provides a structured way to receive pricing data from API requests.
- **Validation**: Ensures that all required fields are present and conform to expected formats and constraints.
- **Conversion**: Offers a convenient `toPricing()` method to transform the request into a domain `Pricing` object for further business logic.

## Record Components

| Component | Type | Validation Constraints | Description |
|-----------|------|------------------------|-------------|
| `mode` | `PricingMode` | `@NotNull` | The pricing mode (e.g., FLAT, GENDER_BASED). |
| `currency` | `String` | `@NotNull`, `@Pattern(regexp = "^[A-Z]{3}$")` | ISO-4217 3-letter currency code. |
| `flatPrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Flat price for all participants. |
| `malePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price for male participants. |
| `femalePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price for female participants. |
| `basePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Base price before any adjustments. |
| `pricePerShuttle` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price per shuttle (e.g., in badminton). |

## Public Methods

### `toPricing()`

Converts this request object into a domain `Pricing` object.

**Returns**: `Pricing` - A new `Pricing` instance constructed from the record's components.

**Example**:
```java
PricingRequest request = new PricingRequest(
    PricingMode.FLAT,
    "USD",
    new BigDecimal("50.00"),
    null,
    null,
    null,
    null
);
Pricing pricing = request.toPricing();
```

## Usage Notes

- All price fields (`flatPrice`, `malePrice`, `femalePrice`, `basePrice`, `pricePerShuttle`) are optional in the sense that they can be `null`, but if provided, they must meet the validation constraints.
- The `currency` field must be a valid 3-letter uppercase ISO-4217 code (e.g., "USD", "EUR").
- The `mode` field is mandatory and must be a valid `PricingMode` enum value.
- The `toPricing()` method creates a `Currency` value object from the currency string using `Currency.create()`.
