# PricingRequest

The `PricingRequest` class is a Java record that serves as a Data Transfer Object (DTO) for creating or updating pricing configurations in the game feature module. It encapsulates all the necessary pricing parameters and provides validation constraints to ensure data integrity before processing.

This record is part of the `com.upmatches.app.features.game.requests` package and is designed to be used in API endpoints where clients submit pricing information for game-related services.

## Purpose

- **Data Transfer**: Transports pricing data from API requests to the service layer.
- **Validation**: Enforces business rules through Jakarta Bean Validation annotations.
- **Conversion**: Provides a `toPricing()` method to convert the request into a domain `Pricing` object.

## Record Components

The record contains the following components, each with specific validation constraints:

| Component | Type | Validation | Description |
|-----------|------|------------|-------------|
| `mode` | `PricingMode` | `@NotNull` | The pricing mode (e.g., FLAT, GENDER_BASED, etc.) |
| `currency` | `String` | `@NotNull`, `@Pattern(regexp = "^[A-Z]{3}$")` | ISO-4217 3-letter currency code |
| `flatPrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Flat price for all users |
| `malePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price for male users |
| `femalePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price for female users |
| `basePrice` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Base price for calculations |
| `pricePerShuttle` | `BigDecimal` | `@DecimalMin("0.00")`, `@Digits(integer=8, fraction=2)` | Price per shuttle unit |

## Public Methods

### `toPricing()`

Converts the `PricingRequest` record into a domain `Pricing` object.

**Signature:**
```java
public Pricing toPricing()
```

**Returns:**
- `Pricing` - A new `Pricing` instance constructed from the request's components.

**Behavior:**
- Creates a `Currency` value object from the `currency` string using `Currency.create()`.
- Passes all pricing fields to the `Pricing` constructor.

## Usage Example

```java
// Creating a pricing request for a flat-rate pricing model
PricingRequest request = new PricingRequest(
    PricingMode.FLAT,
    "USD",
    new BigDecimal("29.99"),  // flatPrice
    null,                     // malePrice (not used in FLAT mode)
    null,                     // femalePrice (not used in FLAT mode)
    new BigDecimal("25.00"),  // basePrice
    new BigDecimal("5.00")    // pricePerShuttle
);

// Convert to domain object
Pricing pricing = request.toPricing();
```

## Validation Notes

- All `BigDecimal` fields must have a minimum value of `0.00`.
- Numeric fields are limited to 8 integer digits and 2 decimal places.
- The `currency` field must be a valid 3-letter uppercase ISO-4217 code.
- The `mode` field is required and cannot be null.

## Dependencies

- **Jakarta Validation**: For bean validation annotations (`@NotNull`, `@DecimalMin`, `@Digits`, `@Pattern`).
- **PricingMode**: Enum defining available pricing modes.
- **Currency**: Value object for currency representation.
- **Pricing**: Domain object representing a complete pricing configuration.
