# UpdateActivityService

The `UpdateActivityService` class is a Spring service responsible for updating existing `Activity` entities in the system. It implements the `IUpdateActivityService` interface and provides transactional, auditable update operations with proper validation and error handling.

## Purpose

This service handles the business logic for updating an activity's details, specifically its name. It ensures that:
- The activity exists before attempting an update
- No duplicate activity names are created
- The operation is executed within a transactional context
- All updates are audited for tracking purposes

## Class Details

| Property | Value |
|----------|-------|
| **Package** | `com.upmatches.app.features.activity.services` |
| **Type** | `non-sealed class` |
| **Implements** | `IUpdateActivityService` |
| **Annotations** | `@Service` |
| **Dependencies** | `ActivityRepository` |

## Constructor

### `UpdateActivityService(ActivityRepository activityRepository)`

Creates a new instance of the service with the required repository dependency.

| Parameter | Type | Description |
|-----------|------|-------------|
| `activityRepository` | `ActivityRepository` | Repository for accessing activity data |

## Public Methods

### `execute(UUID id, UpdateActivityRequest request)`

Updates an existing activity with the provided request data.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to update |
| `request` | `UpdateActivityRequest` | The request containing the updated activity data |

**Returns:** `ActivityResponse` - The response containing the updated activity details

**Throws:**
- `ResourceNotFoundException` - If no activity exists with the given ID
- `ActivityAlreadyExistsException` - If another activity already has the requested name

**Annotations:**
- `@Transactional` - Ensures the operation is executed within a database transaction
- `@Auditable(action = "ACTIVITY_UPDATED", resourceType = "ACTIVITY", resourceIdExpression = "#args[0]")` - Records the update operation for auditing purposes

## Error Handling

The service uses a constant error message template for consistency:

```java
private static final String MSG_ACTIVITY_NOT_FOUND = "Activity with ID '%s' not found.";
```

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Repository | Data access layer for Activity entities |
| `ServiceOperationExecutor` | Utility | Executes service operations with standardized error handling |
| `ResourceNotFoundException` | Exception | Thrown when an activity is not found |
| `ActivityAlreadyExistsException` | Exception | Thrown when a duplicate activity name is detected |

## Usage Example

```java
@Autowired
private UpdateActivityService updateActivityService;

// Update an activity
UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UpdateActivityRequest request = new UpdateActivityRequest("Updated Activity Name");
ActivityResponse response = updateActivityService.execute(activityId, request);
```
