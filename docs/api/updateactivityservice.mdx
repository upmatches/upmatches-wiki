# UpdateActivityService

The `UpdateActivityService` class is a Spring service component responsible for updating existing `Activity` entities in the system. It implements the `IUpdateActivityService` interface and provides transactional, auditable update operations with comprehensive validation and error handling.

## Purpose

This service handles the business logic for updating activity records. It ensures that:
- The activity to be updated exists in the database
- The new name doesn't conflict with existing activities (unless it's the same activity)
- The update operation is executed within a transaction
- The operation is audited for tracking purposes
- Proper error handling and resource management are maintained

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Constructor Injection | Repository for accessing and persisting activity data |

## Public Methods

### `execute(UUID id, UpdateActivityRequest request)`

Updates an existing activity with the provided data.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to update |
| `request` | `UpdateActivityRequest` | The request object containing the updated activity data |

**Returns:** `ActivityResponse` - The response object containing the updated activity data

**Throws:**
- `ResourceNotFoundException` - If no activity exists with the provided ID
- `ActivityAlreadyExistsException` - If another activity already has the requested name

**Behavior:**
1. Retrieves the existing activity by ID
2. Validates that the activity exists; throws `ResourceNotFoundException` if not found
3. Checks for name uniqueness; throws `ActivityAlreadyExistsException` if another activity has the same name
4. Updates the activity name
5. Persists the changes
6. Returns the updated activity as a response object

## Annotations

| Annotation | Description |
|------------|-------------|
| `@Service` | Marks this class as a Spring service component |
| `@Transactional` | Ensures the update operation is executed within a database transaction |
| `@Auditable` | Enables auditing for the update operation with action "ACTIVITY_UPDATED" and resource type "ACTIVITY" |

## Error Handling

The service uses a consistent error handling approach:
- **ResourceNotFoundException**: Thrown when the activity ID doesn't match any existing record
- **ActivityAlreadyExistsException**: Thrown when attempting to rename an activity to a name already used by another activity
- **ServiceOperationExecutor**: Wraps the update logic to provide consistent error handling and operation status tracking

## Usage Example

```java
@Autowired
private UpdateActivityService updateActivityService;

public void updateActivityExample() {
    UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
    UpdateActivityRequest request = new UpdateActivityRequest("Updated Activity Name");
    
    try {
        ActivityResponse response = updateActivityService.execute(activityId, request);
        // Handle successful update
    } catch (ResourceNotFoundException e) {
        // Handle activity not found
    } catch (ActivityAlreadyExistsException e) {
        // Handle duplicate name
    }
}
```
