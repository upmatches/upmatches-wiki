## Overview

The `UpdateActivityService` class is a Spring service responsible for handling the update operations for `Activity` entities. It ensures that an activity can be updated if it exists and that the new name does not conflict with existing activities. This service is part of the application's activity management feature and uses transactional operations to maintain data integrity.

## Public Methods

### `execute`

The `execute` method updates an existing activity based on the provided ID and request data. It checks for the existence of the activity and ensures that the new name is unique before proceeding with the update.

| Parameter | Type                      | Description                                                                 |
|-----------|---------------------------|-----------------------------------------------------------------------------|
| `id`      | `UUID`                    | The unique identifier of the activity to be updated.                        |
| `request` | `UpdateActivityRequest`   | Contains the new data for the activity, including the potential new name.   |

| Return Type         | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| `ActivityResponse`  | Returns a response object containing the updated activity details.          |

## Exceptions

- `ResourceNotFoundException`: Thrown if the activity with the specified ID does not exist.
- `ActivityAlreadyExistsException`: Thrown if an activity with the new name already exists and is different from the current activity's name.
