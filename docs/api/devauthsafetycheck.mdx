# DevAuthSafetyCheck

The `DevAuthSafetyCheck` class is a Spring Boot configuration component that acts as a safety guard to prevent accidental exposure of development-only authentication endpoints in a production environment. It performs a runtime validation during application startup to ensure that the development token minting endpoint is not enabled when the `prod` profile is active.

## Purpose

This class addresses a critical security concern: preventing the accidental deployment of a development endpoint that can mint authentication tokens for any user. Such an endpoint, if exposed in production, would represent a severe security vulnerability. The check runs automatically after bean initialization using the `@PostConstruct` annotation.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `AuthDevProperties` | Configuration properties class containing the `mint-endpoint-enabled` flag |
| `Environment` | Spring's environment abstraction to access active profiles |

## Constructor

### `DevAuthSafetyCheck(AuthDevProperties authDevProperties, Environment environment)`

Creates a new instance of the safety check with the required dependencies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authDevProperties` | `AuthDevProperties` | Configuration properties for development authentication features |
| `environment` | `Environment` | Spring environment to check active profiles |

## Methods

### `verify()`

Performs the safety validation during application startup. This method is annotated with `@PostConstruct`, ensuring it executes after the bean is fully initialized.

**Behavior:**
1. Checks if the development mint endpoint is enabled via `authDevProperties.mintEndpointEnabled()`
2. Checks if the `prod` profile is among the active profiles
3. If both conditions are true, throws an `IllegalStateException` with a descriptive error message

**Throws:**
- `IllegalStateException` - When the development endpoint is enabled in a production environment

## Error Message

When the safety check fails, the following error message is thrown:

```
FATAL: app.auth.dev.mint-endpoint-enabled=true is not allowed when the 'prod' profile is active. 
This would expose an endpoint that mints access tokens for any user.
```

## Usage Example

```java
// In application-dev.yml
app:
  auth:
    dev:
      mint-endpoint-enabled: true

// In application-prod.yml
app:
  auth:
    dev:
      mint-endpoint-enabled: false  # Must be false when prod profile is active
```

## Security Considerations

- This check is mandatory for any application that has development-only authentication endpoints
- The check runs at startup, preventing the application from running in an insecure state
- The error message clearly indicates the configuration property and profile that caused the failure
- The check is non-bypassable as it throws an exception that prevents application startup
