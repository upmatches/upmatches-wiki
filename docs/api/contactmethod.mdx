## Overview

The `ContactMethod` class is a simple, immutable data structure used to represent a method of contact for a user. It is implemented as a Java record, which provides a concise way to model data with automatic generation of boilerplate code such as constructors, `equals()`, `hashCode()`, and `toString()` methods.

## Public Methods

The `ContactMethod` record automatically provides the following public methods:

| Method Signature       | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| `String name()`        | Returns the name of the contact method. This could be an identifier like "email" or "phone". |
| `String value()`       | Returns the value associated with the contact method. This could be an actual email address or phone number. |

## Parameters

The `ContactMethod` record has two parameters:

| Parameter | Type   | Description                                                                 |
|-----------|--------|-----------------------------------------------------------------------------|
| `name`    | String | The name of the contact method, such as "email" or "phone".                 |
| `value`   | String | The value associated with the contact method, such as the actual email address or phone number. |

## Return Types

The methods in the `ContactMethod` record return the following types:

| Method    | Return Type | Description                                                                 |
|-----------|-------------|-----------------------------------------------------------------------------|
| `name()`  | String      | Returns the name of the contact method.                                     |
| `value()` | String      | Returns the value associated with the contact method.                       |

This class is part of the `com.upmatches.app.features.user.requests` package and is designed to be used wherever a simple representation of a contact method is needed.
