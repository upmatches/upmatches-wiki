## Overview

The `ContactMethod` record is a simple data carrier used within the user requests feature of the UpMatches application. It encapsulates a single contact method entry, pairing a **name** (e.g., "Email", "Phone", "Telegram") with its corresponding **value** (e.g., "user@example.com", "+1234567890").

This record is immutable, thread-safe, and automatically provides `equals()`, `hashCode()`, `toString()`, and a canonical constructor, making it ideal for representing structured data in request objects.

## Package

`com.upmatches.app.features.user.requests`

## Record Definition

```java
public record ContactMethod(String name, String value) {}
```

## Components

| Component | Type     | Description                                      |
|-----------|----------|--------------------------------------------------|
| `name`    | `String` | The label or type of the contact method (e.g., "Email", "Phone"). |
| `value`   | `String` | The actual contact information (e.g., email address, phone number). |

## Public Methods

Since `ContactMethod` is a Java `record`, the following methods are automatically generated by the compiler:

| Method                    | Return Type | Description                                                                 |
|---------------------------|-------------|-----------------------------------------------------------------------------|
| `name()`                  | `String`    | Returns the contact method name (e.g., "Email").                           |
| `value()`                 | `String`    | Returns the contact method value (e.g., "user@example.com").               |
| `equals(Object o)`        | `boolean`   | Compares this record to another object for equality based on all components. |
| `hashCode()`              | `int`       | Returns a hash code value for this record.                                 |
| `toString()`              | `String`    | Returns a string representation of the record (e.g., `ContactMethod[name=Email, value=user@example.com]`). |

## Usage Example

```java
ContactMethod email = new ContactMethod("Email", "john.doe@example.com");
ContactMethod phone = new ContactMethod("Phone", "+1234567890");

System.out.println(email.name());   // Output: Email
System.out.println(email.value());  // Output: john.doe@example.com
System.out.println(email);          // Output: ContactMethod[name=Email, value=john.doe@example.com]
```

## Notes

- This record is intended to be used as part of larger request objects within the user feature module.
- No validation is performed on the `name` or `value` fields at construction time. Callers should ensure data integrity before creating instances.
- The record is immutable; once created, its fields cannot be changed.
