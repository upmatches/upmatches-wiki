## Overview

The `ContactMethod` record is a simple data carrier used within the user requests feature of the UpMatches application. It encapsulates a single contact method entry, pairing a **name** (e.g., "Email", "Phone", "WhatsApp") with its corresponding **value** (e.g., "user@example.com", "+1234567890").

This record is immutable, thread-safe, and provides automatic implementations of `equals()`, `hashCode()`, and `toString()`.

## Package

`com.upmatches.app.features.user.requests`

## Record Definition

```java
public record ContactMethod(String name, String value) {}
```

## Constructor & Components

The record automatically generates a canonical constructor and accessor methods for both components.

| Component | Type     | Description                                      |
|-----------|----------|--------------------------------------------------|
| `name`    | `String` | The label or type of the contact method (e.g., "Email", "Phone"). |
| `value`   | `String` | The actual contact information (e.g., email address, phone number). |

## Usage Example

```java
ContactMethod email = new ContactMethod("Email", "jane.doe@example.com");
ContactMethod phone = new ContactMethod("Phone", "+1-555-123-4567");

System.out.println(email.name());   // Output: Email
System.out.println(email.value());  // Output: jane.doe@example.com
```

## Notes

- This record is intended to be used as part of a larger request object or collection within the user profile update flow.
- Validation of the `name` and `value` fields (e.g., ensuring non-null, proper format) should be handled by the calling code or a dedicated validator.
