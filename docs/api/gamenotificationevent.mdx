# GameNotificationEvent

The `GameNotificationEvent` class is a Java record that represents a notification event related to a game within the UpMatches application. It encapsulates the essential data required to trigger and process game-related notifications, such as when a user performs an action on a game (e.g., liking, commenting, or sharing).

This record is immutable and thread-safe by design, leveraging Java's `record` feature to automatically generate constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods.

## Package

`com.upmatches.app.features.notification.events`

## Record Definition

```java
public record GameNotificationEvent(
    UUID gameId,
    UUID actorId,
    NotificationType type,
    String gameTitle
) {}
```

## Components

| Component    | Type             | Description                                                                 |
|--------------|------------------|-----------------------------------------------------------------------------|
| `gameId`     | `UUID`           | The unique identifier of the game associated with the notification.         |
| `actorId`    | `UUID`           | The unique identifier of the user who performed the action triggering the notification. |
| `type`       | `NotificationType` | An enum value indicating the type of notification (e.g., LIKE, COMMENT, SHARE). |
| `gameTitle`  | `String`         | The title of the game, used for display purposes in the notification message. |

## Usage

This record is typically used in event-driven architectures where a notification service listens for `GameNotificationEvent` instances and processes them accordingly. Example usage:

```java
GameNotificationEvent event = new GameNotificationEvent(
    UUID.randomUUID(),
    UUID.randomUUID(),
    NotificationType.LIKE,
    "Super Adventure"
);

// Access components
UUID gameId = event.gameId();
UUID actorId = event.actorId();
NotificationType type = event.type();
String gameTitle = event.gameTitle();
```

## Related Types

- `NotificationType` – An enum located in `com.upmatches.app.features.notification.enums` that defines the possible notification categories.

## Notes

- The record is immutable; once created, its components cannot be changed.
- All components are non-nullable by convention; ensure that valid UUIDs and non-null strings are provided.
- This class is part of the notification feature module and is intended for internal use within the UpMatches application.
