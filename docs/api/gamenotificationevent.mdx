# GameNotificationEvent

The `GameNotificationEvent` is a Java record class that represents a notification event related to a game within the application. It is part of the notification system and is used to encapsulate the essential data required to process and dispatch notifications when specific game-related actions occur.

## Purpose

This record serves as a data carrier for game notification events. It is designed to be immutable and lightweight, leveraging Java's record feature to automatically generate constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods. The primary use case is to pass notification data between different components of the system, such as from a service layer to a notification handler or event bus.

## Record Components

The `GameNotificationEvent` record contains the following components:

| Component   | Type             | Description                                                                 |
|-------------|------------------|-----------------------------------------------------------------------------|
| `gameId`    | `UUID`           | The unique identifier of the game associated with the notification event.   |
| `actorId`   | `UUID`           | The unique identifier of the user or entity that triggered the notification.|
| `type`      | `NotificationType` | The type of notification being sent (e.g., GAME_INVITE, GAME_UPDATE).       |
| `gameTitle` | `String`         | The title or name of the game for display purposes in the notification.     |

## Usage Example

```java
import com.upmatches.app.features.notification.enums.NotificationType;
import java.util.UUID;

// Create a new game notification event
GameNotificationEvent event = new GameNotificationEvent(
    UUID.randomUUID(),
    UUID.randomUUID(),
    NotificationType.GAME_INVITE,
    "Chess Masters"
);

// Access record components
UUID gameId = event.gameId();
UUID actorId = event.actorId();
NotificationType type = event.type();
String gameTitle = event.gameTitle();
```

## Key Features

- **Immutability**: As a Java record, all fields are final and cannot be modified after creation.
- **Automatic Methods**: The compiler generates `equals()`, `hashCode()`, `toString()`, and accessor methods automatically.
- **Type Safety**: Uses `UUID` for identifiers and `NotificationType` enum for type safety.
- **Lightweight**: Minimal boilerplate code required for data transfer objects.

## Dependencies

- `java.util.UUID` - For unique identifier generation and representation.
- `com.upmatches.app.features.notification.enums.NotificationType` - Enum defining the types of notifications available in the system.
