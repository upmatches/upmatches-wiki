# GameNotificationEvent

The `GameNotificationEvent` is a Java record class that represents a notification event related to a game within the application. It is part of the notification system and is used to encapsulate the essential data required to process and dispatch game-related notifications to users.

## Purpose

This record serves as a data carrier for game notification events. When a game-related action occurs (e.g., a player joins, a game starts, or a game ends), an instance of `GameNotificationEvent` is created and passed through the notification pipeline. The record ensures that all necessary information—such as the game identifier, the acting user, the notification type, and the game title—is available in a structured and immutable format.

## Record Components

The `GameNotificationEvent` record defines the following components:

| Component   | Type             | Description                                                                 |
|-------------|------------------|-----------------------------------------------------------------------------|
| `gameId`    | `UUID`           | The unique identifier of the game associated with the notification event.   |
| `actorId`   | `UUID`           | The unique identifier of the user who triggered the notification event.     |
| `type`      | `NotificationType` | The type of notification (e.g., GAME_START, GAME_END, PLAYER_JOIN).       |
| `gameTitle` | `String`         | The title or name of the game for display purposes.                         |

## Usage

Since `GameNotificationEvent` is a Java record, it automatically provides:
- A canonical constructor
- Accessor methods (`gameId()`, `actorId()`, `type()`, `gameTitle()`)
- `equals()`, `hashCode()`, and `toString()` implementations

This makes it ideal for use in event-driven architectures, message queues, or notification services where immutability and data integrity are important.

### Example

```java
GameNotificationEvent event = new GameNotificationEvent(
    UUID.randomUUID(),
    UUID.randomUUID(),
    NotificationType.GAME_START,
    "Chess Match #42"
);

// Accessing components
UUID gameId = event.gameId();
String title = event.gameTitle();
```

## Dependencies

- `com.upmatches.app.features.notification.enums.NotificationType` – An enum that defines the various types of game notifications.
- `java.util.UUID` – Used for generating and representing universally unique identifiers.
