## Purpose of the GameNotificationEvent Class

The `GameNotificationEvent` class is a record in Java that represents an event related to game notifications. It encapsulates the details of a notification event, including the game ID, the actor ID, the type of notification, and the game title. This class is part of the `com.upmatches.app.features.notification.events` package and is used to manage and process game-related notifications within the application.
