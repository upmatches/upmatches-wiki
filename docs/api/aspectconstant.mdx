## Purpose

The `AspectConstant` class is a utility class that defines a set of constants used for logging and monitoring method execution within an application. These constants are primarily used for managing logging contexts, defining metric names, and constructing log messages related to method execution performance and status.

This class is designed to be non-instantiable and provides a centralized location for constants that are used across different components of the application, such as controllers and services.

## Public Constants

The `AspectConstant` class contains several public static final constants. Below is a table documenting each constant, its type, and its purpose:

| Constant Name                  | Type   | Description                                                                 |
|--------------------------------|--------|-----------------------------------------------------------------------------|
| `SLOW_EXECUTION_THRESHOLD_MS`  | `long` | Threshold in milliseconds to determine if a method execution is considered slow. |
| `MDC_REQUEST_ID`               | `String` | Key for storing the request ID in the MDC (Mapped Diagnostic Context).      |
| `MDC_METHOD`                   | `String` | Key for storing the method name in the MDC.                                 |
| `MDC_HTTP_METHOD`              | `String` | Key for storing the HTTP method in the MDC.                                 |
| `MDC_ENDPOINT`                 | `String` | Key for storing the endpoint in the MDC.                                    |
| `STATUS_TAG`                   | `String` | Tag used to represent the status of an operation.                           |
| `COMPONENT_CONTROLLER`         | `String` | Tag used to represent the controller component in metrics.                  |
| `COMPONENT_SERVICE`            | `String` | Tag used to represent the service component in metrics.                     |
| `METRIC_NAME`                  | `String` | Name of the metric for method execution.                                    |
| `METRIC_TAG_COMPONENT`         | `String` | Tag used to represent the component in metrics.                             |
| `STATUS_FAILURE`               | `String` | Status value indicating a failure.                                          |
| `STATUS_SUCCESS`               | `String` | Status value indicating success.                                            |
| `REQUEST_ID_SEPARATOR`         | `String` | Separator used in request IDs.                                              |
| `LOG_METHOD_SLOW`              | `String` | Log message template for slow method execution.                             |
| `LOG_METHOD_SUCCESS`           | `String` | Log message template for successful method execution.                       |
| `LOG_METHOD_FAILURE`           | `String` | Log message template for failed method execution.                           |

## Constructor

The `AspectConstant` class has a private constructor to prevent instantiation:

- **Constructor:** `private AspectConstant()`
  - **Description:** Throws an `AssertionError` to prevent instantiation of the class, as it is intended to be used only for its constants.
