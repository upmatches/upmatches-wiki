# AspectConstant

The `AspectConstant` class is a utility class that provides a centralized repository of constants used across the application's logging and monitoring aspects. It is designed to be used with Spring AOP (Aspect-Oriented Programming) to standardize logging, metrics, and performance monitoring across different components such as controllers and services.

## Purpose

This class serves as a single source of truth for:
- **Performance thresholds**: Defines the threshold for slow method execution detection
- **MDC (Mapped Diagnostic Context) keys**: Standardizes keys used for logging context
- **Metric definitions**: Provides consistent naming and tagging for application metrics
- **Status indicators**: Defines success and failure status constants
- **Log message templates**: Predefined log message formats for consistent logging

## Constants

### Performance Threshold

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `SLOW_EXECUTION_THRESHOLD_MS` | `long` | `1000` | Threshold in milliseconds for considering a method execution as slow |

### MDC Keys

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `MDC_REQUEST_ID` | `String` | `"requestId"` | Key for storing request identifier in MDC |
| `MDC_METHOD` | `String` | `"method"` | Key for storing method name in MDC |
| `MDC_HTTP_METHOD` | `String` | `"httpMethod"` | Key for storing HTTP method in MDC |
| `MDC_ENDPOINT` | `String` | `"endpoint"` | Key for storing endpoint path in MDC |

### Component Types

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `COMPONENT_CONTROLLER` | `String` | `"controller"` | Identifier for controller components |
| `COMPONENT_SERVICE` | `String` | `"service"` | Identifier for service components |

### Metric Definitions

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `METRIC_NAME` | `String` | `"app.method.execution"` | Base name for method execution metrics |
| `METRIC_TAG_COMPONENT` | `String` | `"component"` | Tag name for component type in metrics |

### Status Indicators

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `STATUS_TAG` | `String` | `"status"` | Tag name for execution status |
| `STATUS_FAILURE` | `String` | `"failure"` | Value indicating failed execution |
| `STATUS_SUCCESS` | `String` | `"success"` | Value indicating successful execution |

### Utility Constants

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `REQUEST_ID_SEPARATOR` | `String` | `"-"` | Separator used in request ID generation |

### Log Message Templates

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `LOG_METHOD_SLOW` | `String` | `"Method {} executed slowly in {} ms"` | Template for slow method execution logs |
| `LOG_METHOD_SUCCESS` | `String` | `"Method {} executed successfully in {} ms"` | Template for successful method execution logs |
| `LOG_METHOD_FAILURE` | `String` | `"Method {} failed in {} ms with {}: {}"` | Template for failed method execution logs |

## Constructor

The class has a private constructor that throws an `AssertionError` to prevent instantiation, as this is a utility class designed to be used statically.

```java
private AspectConstant() {
    throw new AssertionError();
}
```

## Usage Example

These constants are typically used in AOP aspects for logging and monitoring:

```java
@Around("@annotation(LogExecutionTime)")
public Object logExecutionTime(ProceedingJoinPoint joinPoint) throws Throwable {
    long start = System.currentTimeMillis();
    String methodName = joinPoint.getSignature().getName();
    
    try {
        Object result = joinPoint.proceed();
        long executionTime = System.currentTimeMillis() - start;
        
        if (executionTime > AspectConstant.SLOW_EXECUTION_THRESHOLD_MS) {
            logger.warn(AspectConstant.LOG_METHOD_SLOW, methodName, executionTime);
        } else {
            logger.info(AspectConstant.LOG_METHOD_SUCCESS, methodName, executionTime);
        }
        
        return result;
    } catch (Exception e) {
        long executionTime = System.currentTimeMillis() - start;
        logger.error(AspectConstant.LOG_METHOD_FAILURE, methodName, executionTime, 
                     e.getClass().getSimpleName(), e.getMessage());
        throw e;
    }
}
```
