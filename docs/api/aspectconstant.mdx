# AspectConstant

The `AspectConstant` class is a utility class that centralizes all constants used by AOP (Aspect-Oriented Programming) aspects within the `com.upmatches.app.shared.logging.constants` package. It provides a single source of truth for logging-related constants, including thresholds, MDC (Mapped Diagnostic Context) keys, metric names, and log message templates.

This class is declared as `final` and has a private constructor to prevent instantiation, following the standard utility class pattern.

## Constants

### Execution Threshold

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `SLOW_EXECUTION_THRESHOLD_MS` | `long` | `1000` | Threshold in milliseconds for considering a method execution as slow |

### MDC Keys

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `MDC_REQUEST_ID` | `String` | `"requestId"` | MDC key for storing the request identifier |
| `MDC_METHOD` | `String` | `"method"` | MDC key for storing the method name |
| `MDC_HTTP_METHOD` | `String` | `"httpMethod"` | MDC key for storing the HTTP method |
| `MDC_ENDPOINT` | `String` | `"endpoint"` | MDC key for storing the endpoint path |

### Status Tags

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `STATUS_TAG` | `String` | `"status"` | Tag name for status in metrics |
| `STATUS_FAILURE` | `String` | `"failure"` | Value indicating a failure status |
| `STATUS_SUCCESS` | `String` | `"success"` | Value indicating a success status |

### Component Types

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `COMPONENT_CONTROLLER` | `String` | `"controller"` | Identifier for controller components |
| `COMPONENT_SERVICE` | `String` | `"service"` | Identifier for service components |

### Metrics

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `METRIC_NAME` | `String` | `"app.method.execution"` | Name of the metric for method execution |
| `METRIC_TAG_COMPONENT` | `String` | `"component"` | Tag name for component type in metrics |

### Log Message Templates

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `LOG_METHOD_SLOW` | `String` | `"Method {} executed slowly in {} ms"` | Log template for slow method execution |
| `LOG_METHOD_SUCCESS` | `String` | `"Method {} executed successfully in {} ms"` | Log template for successful method execution |
| `LOG_METHOD_FAILURE` | `String` | `"Method {} failed in {} ms with {}: {}"` | Log template for failed method execution |

### Miscellaneous

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `REQUEST_ID_SEPARATOR` | `String` | `"-"` | Separator used in request ID construction |

## Constructor

The class has a private constructor that throws an `AssertionError` to prevent instantiation:

```java
private AspectConstant() {
    throw new AssertionError();
}
```

## Usage

This class is typically used in AOP aspects to maintain consistency across logging and monitoring implementations. For example:

```java
// Using constants in an aspect
if (executionTime > AspectConstant.SLOW_EXECUTION_THRESHOLD_MS) {
    logger.warn(AspectConstant.LOG_METHOD_SLOW, methodName, executionTime);
}
```

## Notes

- All constants are `public static final`, making them accessible throughout the application
- The class cannot be instantiated or extended due to the `final` modifier and private constructor
- Constants are organized by their functional purpose (thresholds, MDC keys, metrics, etc.)
