# AppleAuthService

The `AppleAuthService` class is a Spring service component that handles verification of Apple Identity Tokens. It implements the `IAppleAuthService` interface and provides functionality to validate and extract claims from Apple's JWT tokens using Apple's public keys (JWKS).

## Purpose

This service is responsible for:
- Fetching and caching Apple's JSON Web Key Set (JWKS) for token signature verification
- Verifying the authenticity of Apple Identity Tokens using RS256 algorithm
- Extracting verified claims (subject identifier and email) from valid tokens
- Ensuring token issuer and audience match configured Apple properties

## Dependencies

| Dependency | Description |
|------------|-------------|
| `RestClient` | HTTP client for fetching Apple's JWKS endpoint |
| `AppleProperties` | Configuration properties containing Apple's issuer, audience, and JWKS URI |
| `Nimbus JOSE + JWT` | Library for JWT processing and verification |

## Public Methods

### `verifyIdentityToken`

```java
AppleVerifiedClaims verifyIdentityToken(String identityToken)
```

Verifies an Apple Identity Token and extracts the verified claims.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `identityToken` | `String` | The Apple Identity Token to verify |

**Returns:**

| Type | Description |
|------|-------------|
| `AppleVerifiedClaims` | Object containing verified claims (subject and email) |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `IllegalStateException` | If token verification fails due to issuer mismatch, audience mismatch, missing subject claim, or any other verification error |

## Internal Implementation Details

### Token Verification Process

1. **Fetch JWKS**: Retrieves Apple's public keys from the configured JWKS URI with caching
2. **Configure JWT Processor**: Sets up a `DefaultJWTProcessor` with RS256 verification using Apple's public keys
3. **Process Token**: Verifies the JWT signature and extracts claims
4. **Validate Claims**:
   - Checks that the token issuer matches the configured Apple issuer
   - Verifies the audience contains the configured client ID
   - Ensures the subject claim (`sub`) is present and non-blank
5. **Extract Claims**: Retrieves the subject identifier and email claim from the verified token

### JWKS Caching

The service implements a thread-safe caching mechanism for Apple's JWKS:

- **Cache Duration**: 900 seconds (15 minutes)
- **Thread Safety**: Uses double-checked locking with `synchronized` block
- **Cache Invalidation**: Automatically refreshes when cache expires

### Error Handling

The service provides specific error messages for common failure scenarios:

| Error Message | Description |
|---------------|-------------|
| `Apple ID token issuer mismatch` | Token issuer doesn't match configured Apple issuer |
| `Apple ID token audience mismatch` | Token audience doesn't contain configured client ID |
| `Apple ID token missing 'sub' claim` | Token doesn't contain a subject identifier |
| `Failed to verify Apple ID token` | General verification failure |
| `Empty JWKS response from Apple` | Apple returned empty JWKS data |
| `Failed to fetch Apple JWKS` | Unable to retrieve JWKS from Apple's endpoint |

## Usage Example

```java
@Service
public class AuthController {
    private final AppleAuthService appleAuthService;
    
    public AuthController(AppleAuthService appleAuthService) {
        this.appleAuthService = appleAuthService;
    }
    
    public void handleAppleLogin(String identityToken) {
        try {
            AppleVerifiedClaims claims = appleAuthService.verifyIdentityToken(identityToken);
            String userId = claims.sub();
            String email = claims.email();
            // Process authenticated user
        } catch (IllegalStateException e) {
            // Handle verification failure
        }
    }
}
```

## Configuration Requirements

The service requires the following properties to be configured in `AppleProperties`:

| Property | Description |
|----------|-------------|
| `issuer` | Apple's token issuer URL (typically `https://appleid.apple.com`) |
| `audience` | Your application's client ID registered with Apple |
| `jwksUri` | Apple's JWKS endpoint URL |
