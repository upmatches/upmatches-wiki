# AppleAuthService

The `AppleAuthService` class is a Spring service that implements the `IAppleAuthService` interface. It provides functionality to verify Apple Identity Tokens (JWT tokens) issued by Apple's authentication system. This service is essential for applications that support "Sign in with Apple" functionality.

## Purpose

The primary purpose of this service is to:
- Verify the authenticity of Apple ID tokens
- Validate token claims (issuer, audience, subject)
- Extract verified user claims (sub and email)
- Cache Apple's JSON Web Key Set (JWKS) for performance optimization

## Class Details

- **Package**: `com.upmatches.app.features.auth.services`
- **Type**: `non-sealed class` implementing `IAppleAuthService`
- **Annotations**: `@Service`
- **Dependencies**: `RestClient` (qualified as "appleRestClient"), `AppleProperties`

## Public Methods

### `verifyIdentityToken(String identityToken)`

Verifies an Apple Identity Token and returns the verified claims.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `identityToken` | `String` | The Apple ID token to verify |

**Returns:**
| Type | Description |
|------|-------------|
| `AppleVerifiedClaims` | Object containing verified user claims (sub and email) |

**Throws:**
| Exception | Condition |
|-----------|-----------|
| `IllegalStateException` | If token verification fails for any reason (issuer mismatch, audience mismatch, missing subject, or general verification failure) |

## Internal Methods

### `verify(String identityToken)`

Private method that performs the actual token verification process.

**Process:**
1. Fetches Apple's JWKS (from cache or remote)
2. Creates a JWT processor with RSA256 verification
3. Processes the identity token to extract claims
4. Validates the issuer matches the expected Apple issuer
5. Validates the audience contains the expected client ID
6. Extracts and validates the subject claim
7. Extracts the email claim (optional)
8. Returns `AppleVerifiedClaims` with sub and email

### `getAppleJwks()`

Private method that manages JWKS caching and retrieval.

**Caching Strategy:**
- Uses double-checked locking pattern for thread safety
- Cache duration: 900 seconds (15 minutes)
- Fetches JWKS from Apple's JWKS endpoint using the configured `RestClient`
- Parses the JSON response into a `JWKSet` object

## Usage Example

```java
@Service
public class AuthenticationService {
    private final AppleAuthService appleAuthService;
    
    public AuthenticationService(AppleAuthService appleAuthService) {
        this.appleAuthService = appleAuthService;
    }
    
    public void authenticateWithApple(String identityToken) {
        try {
            AppleVerifiedClaims claims = appleAuthService.verifyIdentityToken(identityToken);
            String userId = claims.sub();
            String email = claims.email();
            // Process authenticated user
        } catch (IllegalStateException e) {
            // Handle authentication failure
            log.error("Apple authentication failed: {}", e.getMessage());
        }
    }
}
```

## Dependencies

The service requires the following dependencies to be configured in the Spring context:

1. **RestClient** (qualified as "appleRestClient"): Configured to communicate with Apple's authentication endpoints
2. **AppleProperties**: Configuration properties containing:
   - `issuer`: Apple's expected issuer URL
   - `audience`: The application's client ID
   - `jwksUri`: Apple's JWKS endpoint URL

## Thread Safety

The service is thread-safe due to:
- Use of `volatile` keyword for cached JWKS and expiry time
- Double-checked locking pattern in `getAppleJwks()` method
- Immutable JWKSet creation for each verification
