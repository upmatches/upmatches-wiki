# IListActivitiesService Interface

The `IListActivitiesService` interface defines the contract for retrieving a paginated list of activities within the UpMatches application. It follows a sealed interface pattern to restrict implementation to a single concrete class (`ListActivitiesService`), ensuring controlled extensibility and a clear service layer boundary.

## Purpose

This interface abstracts the operation of fetching activities with pagination support. By using a sealed interface, the design enforces that only the designated implementation (`ListActivitiesService`) can fulfill this contract, which improves maintainability and prevents unintended subclassing.

## Interface Definition

```java
public sealed interface IListActivitiesService permits ListActivitiesService {
    PagedResponse<ActivityResponse> execute(Pageable pageable);
}
```

## Method Summary

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `execute` | `PagedResponse<ActivityResponse>` | `Pageable pageable` | Retrieves a paginated list of activities based on the provided pagination information. |

## Parameters

### `execute(Pageable pageable)`

- **`pageable`** (`org.springframework.data.domain.Pageable`): Encapsulates pagination parameters such as page number, page size, and sorting criteria. This object is typically constructed from request parameters in a controller layer.

## Return Type

### `PagedResponse<ActivityResponse>`

A generic wrapper that contains:
- The list of `ActivityResponse` objects for the current page
- Pagination metadata (total pages, total elements, current page number, etc.)

The `ActivityResponse` class represents the data transfer object for an activity, containing relevant fields exposed to the client.

## Usage Example

```java
@Service
public class ListActivitiesService implements IListActivitiesService {
    
    @Override
    public PagedResponse<ActivityResponse> execute(Pageable pageable) {
        // Implementation logic to fetch and return paginated activities
    }
}
```

## Dependencies

- `com.upmatches.app.features.activity.responses.ActivityResponse`
- `com.upmatches.app.shared.responses.PagedResponse`
- `org.springframework.data.domain.Pageable`

## Related Components

- **`ListActivitiesService`**: The sole permitted implementation of this interface.
- **`ActivityResponse`**: The DTO used to represent activity data in API responses.
- **`PagedResponse`**: A generic pagination wrapper used across the application for consistent paginated responses.
