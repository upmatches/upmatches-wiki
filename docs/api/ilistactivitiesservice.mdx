# IListActivitiesService Interface

## Purpose

The `IListActivitiesService` interface defines the contract for retrieving a paginated list of activities within the UpMatches application. It serves as the abstraction layer for the activity listing functionality, allowing for a clean separation between the service interface and its implementation.

This interface is declared as a **sealed interface**, meaning it restricts which classes or interfaces can implement it. In this case, only `ListActivitiesService` is permitted to provide the concrete implementation.

## Interface Definition

```java
public sealed interface IListActivitiesService permits ListActivitiesService {
    PagedResponse<ActivityResponse> execute(Pageable pageable);
}
```

## Methods

### `execute`

Retrieves a paginated list of activities based on the provided pagination parameters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | Spring Data pagination object containing page number, size, and sorting information |

| Returns | Type | Description |
|---------|------|-------------|
| `PagedResponse<ActivityResponse>` | `PagedResponse<ActivityResponse>` | A paginated response containing a list of `ActivityResponse` objects with pagination metadata |

## Usage Example

```java
// Inject the service
private final IListActivitiesService listActivitiesService;

// Use the service to retrieve paginated activities
Pageable pageable = PageRequest.of(0, 10, Sort.by("createdAt").descending());
PagedResponse<ActivityResponse> activities = listActivitiesService.execute(pageable);
```

## Related Components

- **`ListActivitiesService`**: The sole permitted implementation of this interface
- **`ActivityResponse`**: The response DTO representing an activity
- **`PagedResponse`**: A generic wrapper for paginated responses containing list data and pagination metadata
- **`Pageable`**: Spring Data interface for pagination information

## Notes

- This interface uses Java's sealed class feature (introduced in Java 17) to restrict implementation to `ListActivitiesService` only
- The pagination mechanism leverages Spring Data's `Pageable` for flexible querying
- The response is wrapped in a `PagedResponse` to provide both the data and pagination metadata to the client
