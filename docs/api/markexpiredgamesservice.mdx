# MarkExpiredGamesService

## Purpose

The `MarkExpiredGamesService` is a Spring service class responsible for marking games as expired when their scheduled time has passed. It identifies games that are still in `SCHEDULED` or `STARTED` status but whose start time is before the current moment, and updates their status to reflect expiration.

This service is part of the game management feature in the UpMatches application and ensures that games are automatically transitioned to an expired state, maintaining data consistency and enabling downstream processes to handle expired games appropriately.

## Class Details

- **Package:** `com.upmatches.app.features.game.services`
- **Type:** `non-sealed` class implementing `IMarkExpiredGamesService`
- **Annotations:** `@Service`
- **Dependencies:** `GameRepository`

## Public Methods

### `execute()`

| Property | Details |
|----------|---------|
| **Signature** | `@Transactional public int execute()` |
| **Description** | Executes the expiration logic by finding all games with `SCHEDULED` or `STARTED` status whose start time is before the current moment, and marks them as expired. |
| **Returns** | `int` - The number of games that were successfully marked as expired. |
| **Exceptions** | Throws `ResourceNotFoundException` if the operation fails (wrapped by `ServiceOperationExecutor`). |
| **Transactional** | Yes - the entire operation is wrapped in a database transaction. |

#### Method Flow

1. Captures the current timestamp using `Instant.now()`
2. Calls `gameRepository.markExpiredBefore()` with:
   - A list of statuses to check: `SCHEDULED` and `STARTED`
   - The current timestamp as both the expiration time and the comparison time
3. Wraps the operation in `ServiceOperationExecutor.execute()` with:
   - Operation type: `UPDATE`
   - Error handling: Creates a `ResourceNotFoundException` if the operation fails

## Usage Example

```java
@Autowired
private MarkExpiredGamesService markExpiredGamesService;

// In a scheduled task or batch job
public void processExpiredGames() {
    int expiredCount = markExpiredGamesService.execute();
    logger.info("Marked {} games as expired", expiredCount);
}
```
