# Auth0CallbackController

The `Auth0CallbackController` is a Spring REST controller that handles the OAuth 2.0 callback from Auth0 after a user authenticates. It processes the authorization code, exchanges it for tokens, creates or retrieves the user, and generates the appropriate response (either a redirect for web clients or a token response for mobile clients).

## Purpose

This controller serves as the entry point for Auth0's authentication callback flow. It:

- Validates the incoming callback request parameters
- Exchanges the authorization code for verified claims from Auth0
- Creates a new user or retrieves an existing user based on the Auth0 user ID
- Generates JWT access and refresh tokens
- Records audit events for authentication success or failure
- Returns appropriate responses for web (cookie-based) or mobile (token-based) clients

## Endpoints

### `GET /callback/auth0`

Handles the Auth0 authentication callback.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `code` | String | No | Authorization code from Auth0 |
| `state` | String | No | State parameter for CSRF protection |

**Returns:** `ResponseEntity<Object>` - Redirect response for web clients or token response for mobile clients

**Throws:**
- `InvalidAuthRequestException` - If code or state parameters are missing
- `AuthenticationException` - If authentication fails for any reason

## Public Methods

### `callbackAuth0`

```java
public ResponseEntity<Object> callbackAuth0(
    @RequestParam(required = false) final String code,
    @RequestParam(required = false) final String state,
    final HttpServletRequest request,
    final HttpServletResponse response)
```

Main callback handler that orchestrates the entire authentication flow.

**Flow:**
1. Checks for provider errors from Auth0
2. Validates the presence of `code` and `state` parameters
3. Retrieves the authentication session using the state parameter
4. Exchanges the authorization code for verified claims
5. Parses the Auth0 user ID from the `sub` claim
6. Finds or creates the user in the database
7. Records an audit event for successful authentication
8. Builds and returns the appropriate response

## Private Methods

### `recordAuthSuccess`

```java
private void recordAuthSuccess(final UUID userId, final HttpServletRequest request)
```

Records a successful authentication audit event.

### `recordAuthFailure`

```java
private void recordAuthFailure(final RuntimeException ex, final HttpServletRequest request)
```

Records a failed authentication audit event with error details.

### `rejectIfProviderError`

```java
private void rejectIfProviderError(final HttpServletRequest request)
```

Checks if Auth0 returned an error in the callback and throws an `AuthenticationException` if so.

### `exchangeCode`

```java
private Auth0VerifiedClaims exchangeCode(final String code, final AuthSession session, final String state)
```

Exchanges the authorization code for verified claims from Auth0 using the stored code verifier and nonce.

### `parseAuth0Uuid`

```java
private Auth0Uuid parseAuth0Uuid(final String sub)
```

Parses the Auth0 `sub` claim into an `Auth0Uuid` value object.

### `findOrCreateUser`

```java
private CallbackResult findOrCreateUser(final Auth0Uuid auth0UserId, final String pictureUrl, final String email)
```

Finds an existing user by Auth0 UUID or creates a new one. Handles concurrent creation scenarios with `DataIntegrityViolationException`.

### `refreshAvatar`

```java
private void refreshAvatar(final User user, final String pictureUrl)
```

Updates the user's avatar URL if a new picture URL is provided.

### `buildResponse`

```java
private ResponseEntity<Object> buildResponse(
    final CallbackResult result,
    final String platform,
    final HttpServletRequest request,
    final HttpServletResponse response)
```

Builds the appropriate response based on the client platform:
- **Web clients**: Sets authentication cookies and redirects to the frontend
- **Mobile clients**: Returns a redirect with tokens in the URL or renders a developer token page

### `buildMobileRedirect`

```java
private ResponseEntity<Object> buildMobileRedirect(
    final JwtTokenService.AccessTokenResult accessToken,
    final String refreshToken,
    final boolean isNewUser,
    final HttpServletRequest request)
```

Builds a mobile-specific redirect response with tokens in the URL. If the developer token page is enabled, it renders an HTML page instead.

## Internal Records

### `CallbackResult`

```java
private record CallbackResult(User user, Boolean isNewUser)
```

Internal record that holds the result of user lookup/creation, including the user entity and whether they are new.

## Error Handling

The controller handles several error scenarios:

| Error | Exception | Description |
|-------|-----------|-------------|
| Missing code or state | `InvalidAuthRequestException` | Required parameters are missing |
| State mismatch | `AuthenticationException` | Session not found for the given state |
| Auth0 provider error | `AuthenticationException` | Auth0 returned an error |
| Token exchange failure | `AuthenticationException` | Failed to exchange authorization code |
| Invalid sub claim | `AuthenticationException` | Auth0 user ID format is invalid |
| User creation failure | `AuthenticationException` | Unable to create or find user |
