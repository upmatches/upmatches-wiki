# Auth0CallbackController

The `Auth0CallbackController` is a Spring REST controller that handles the OAuth 2.0 callback from Auth0 after a user has authenticated. It processes the authorization code, exchanges it for tokens, creates or retrieves the user, and generates the appropriate response (either a redirect for web clients or a token-based response for mobile clients).

## Purpose

This controller serves as the entry point for Auth0's authentication callback flow. It:

- Validates the incoming callback request parameters (`code` and `state`)
- Exchanges the authorization code for verified claims from Auth0
- Creates a new user or retrieves an existing user based on the Auth0 user ID
- Generates JWT access and refresh tokens
- Returns the appropriate response based on the client platform (web or mobile)

## Endpoints

| HTTP Method | Path | Description |
|-------------|------|-------------|
| GET | `/callback/auth0` | Handles the Auth0 authentication callback |

## Public Methods

### `callbackAuth0`

```java
@GetMapping("/callback/auth0")
public ResponseEntity<Object> callbackAuth0(
    @RequestParam(required = false) final String code,
    @RequestParam(required = false) final String state,
    final HttpServletRequest request,
    final HttpServletResponse response)
```

The main callback handler that processes the Auth0 authentication response.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `code` | `String` | No | The authorization code from Auth0 |
| `state` | `String` | No | The state parameter for CSRF protection |
| `request` | `HttpServletRequest` | Yes | The HTTP request object |
| `response` | `HttpServletResponse` | Yes | The HTTP response object |

**Returns:** `ResponseEntity<Object>` - A redirect response for web clients or a token response for mobile clients

**Throws:**
- `InvalidAuthRequestException` - If `code` or `state` parameters are missing
- `AuthenticationException` - If authentication fails for any reason
