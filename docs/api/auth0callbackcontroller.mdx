## Purpose

The `Auth0CallbackController` class is a Spring Boot REST controller designed to handle the callback from Auth0 authentication. It processes the authentication response, exchanges authorization codes for tokens, manages user sessions, and handles user creation or retrieval in the system. The controller also records audit events for successful and failed authentication attempts.

## Public Methods

### `callbackAuth0`

Handles the Auth0 callback request, processes the authentication response, and returns an appropriate HTTP response.

| Parameter | Type                  | Description                                                                 |
|-----------|-----------------------|-----------------------------------------------------------------------------|
| `code`    | `String`              | The authorization code returned by Auth0.                                   |
| `state`   | `String`              | The state parameter to validate the request.                                |
| `request` | `HttpServletRequest`  | The HTTP request object.                                                    |
| `response`| `HttpServletResponse` | The HTTP response object.                                                   |

| Return Type              | Description                                                                 |
|--------------------------|-----------------------------------------------------------------------------|
| `ResponseEntity<Object>` | A response entity indicating the result of the authentication process.      |

### Key Functionalities

- **Error Handling**: The method checks for provider errors and missing parameters, throwing exceptions if necessary.
- **Session Management**: Retrieves and removes the authentication session using the state parameter.
- **Token Exchange**: Exchanges the authorization code for verified claims using the `IAuth0AuthService`.
- **User Management**: Finds or creates a user based on the Auth0 UUID and updates user information.
- **Audit Logging**: Records audit events for both successful and failed authentication attempts.
- **Response Building**: Constructs the appropriate HTTP response based on the platform (web or mobile) and user status (new or existing).

### Private Methods

- `recordAuthSuccess`: Records a successful authentication event.
- `recordAuthFailure`: Records a failed authentication event.
- `rejectIfProviderError`: Checks for and handles provider errors.
- `exchangeCode`: Exchanges the authorization code for verified claims.
- `parseAuth0Uuid`: Parses the Auth0 UUID from the subject claim.
- `findOrCreateUser`: Finds an existing user or creates a new one based on Auth0 information.
- `refreshAvatar`: Updates the user's avatar URL if a new picture URL is provided.
- `buildResponse`: Builds the HTTP response for web platforms.
- `buildMobileRedirect`: Builds the HTTP response for mobile platforms.
