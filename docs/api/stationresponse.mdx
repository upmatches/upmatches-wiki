## Purpose

The `StationResponse` class is a Java record designed to encapsulate the response data for a station entity within the application. It provides a structured way to represent station information, including its geographical coordinates and associated transit lines. This class is primarily used to transform and transfer station data from the backend to the frontend in a consistent format.

## Public Methods

The `StationResponse` class includes the following public method:

### `fromStation`

Converts a `Station` entity into a `StationResponse` object.

| Parameter | Type    | Description                          |
|-----------|---------|--------------------------------------|
| station   | Station | The station entity to be transformed.|

| Return Type    | Description                                      |
|----------------|--------------------------------------------------|
| StationResponse | A new instance of `StationResponse` containing the data from the provided `Station` entity.|

This method extracts the necessary information from a `Station` object, including its ID, name, latitude, longitude, and associated transit lines, and maps them into a `StationResponse` object. The transit lines are transformed into `TransitLineResponse` objects using the `fromStationLine` method of the `TransitLineResponse` class.
