# StationResponse

The `StationResponse` record is a Data Transfer Object (DTO) used to represent a transit station in API responses. It encapsulates the essential station information along with its associated transit lines, providing a clean, immutable view of the station data for clients.

## Purpose

This record serves as the response model for station-related endpoints. It transforms the internal `Station` entity into a lightweight, serializable format that includes:
- Basic station identification and location data
- A list of associated transit lines (each represented as a `TransitLineResponse`)

The static factory method `fromStation()` handles the conversion from the domain entity to this response DTO, including the mapping of nested `StationLine` entities to their corresponding response objects.

## Constructor Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `Long` | Unique identifier for the station |
| `name` | `String` | Human-readable name of the station |
| `latitude` | `BigDecimal` | Geographic latitude coordinate |
| `longitude` | `BigDecimal` | Geographic longitude coordinate |
| `transitLines` | `List<TransitLineResponse>` | Collection of transit lines serving this station |

## Public Methods

### `fromStation(Station station)`

| Aspect | Details |
|--------|---------|
| **Return Type** | `StationResponse` |
| **Description** | Factory method that converts a `Station` entity into a `StationResponse` DTO. It maps the station's basic fields directly and transforms each `StationLine` entity into a `TransitLineResponse` using the `TransitLineResponse.fromStationLine()` method. |

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The domain entity to convert |

**Example Usage:**

```java
Station station = stationRepository.findById(1L).orElseThrow();
StationResponse response = StationResponse.fromStation(station);
// response now contains the station data with all transit lines mapped
```
