# StationResponse

The `StationResponse` record is a Data Transfer Object (DTO) used to represent a transit station in API responses. It encapsulates the essential station information along with its associated transit lines, providing a clean, immutable view of the station data for clients.

## Purpose

This record serves as the response model for station-related endpoints. By converting the internal `Station` entity into a `StationResponse`, the API layer ensures that only relevant fields are exposed to consumers, and that the internal domain model remains decoupled from the API contract.

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `id` | `Long` | Unique identifier for the station |
| `name` | `String` | Human-readable name of the station |
| `latitude` | `BigDecimal` | Geographic latitude coordinate |
| `longitude` | `BigDecimal` | Geographic longitude coordinate |
| `transitLines` | `List<TransitLineResponse>` | Collection of transit lines serving this station |

## Factory Method

### `fromStation(Station station)`

Creates a `StationResponse` instance from a `Station` entity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The source station entity to convert |

**Returns:** `StationResponse` — A new response object populated with data from the provided station.

**Behavior:**
- Iterates over the station's associated `StationLine` entities
- Converts each `StationLine` to a `TransitLineResponse` using its own factory method
- Constructs and returns a new `StationResponse` with the station's ID, name, coordinates, and the list of transit line responses

## Usage Example

```java
// Given a Station entity
Station station = stationService.findById(42L);

// Convert to response DTO
StationResponse response = StationResponse.fromStation(station);

// The response can now be serialized and returned to the client
return ResponseEntity.ok(response);
```
