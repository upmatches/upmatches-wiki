# GameShareAccess

The `GameShareAccess` entity represents a record of a user being granted access to a shared game. It is used to track which users have been given permission to view or interact with a specific game resource.

## Purpose

This entity serves as a join table between `Game` and `User` entities, enforcing a unique constraint that ensures each user can only have one access record per game. The `resolvedAt` timestamp captures the exact moment when the access was granted, providing an audit trail for game sharing activities.

## Entity Details

- **Table Name:** `game_share_accesses`
- **Unique Constraint:** `(game_id, user_id)` – prevents duplicate access records for the same game and user combination.
- **Primary Key:** UUID (auto-generated)
- **Package:** `com.upmatches.app.features.game.entities`

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Primary key, auto-generated using UUID strategy |
| `game` | `Game` | The game that access is granted to (many-to-one relationship) |
| `user` | `User` | The user who is granted access (many-to-one relationship) |
| `resolvedAt` | `Instant` | Timestamp when the access was created (non-nullable, non-updatable) |

## Public Methods

### `create(Game game, User user)`

Creates a new `GameShareAccess` instance with the specified game and user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game to grant access to |
| `user` | `User` | The user to grant access to |

**Returns:** `GameShareAccess` – a new instance with the provided game and user, and the `resolvedAt` timestamp set to the current time upon persistence.

## Lifecycle Callbacks

### `onCreate()`

A `@PrePersist` callback that automatically sets the `resolvedAt` field to the current instant (`Instant.now()`) before the entity is persisted to the database. This ensures the timestamp is always recorded at the moment of creation.

## Usage Example

```java
// Create a new game share access record
GameShareAccess access = GameShareAccess.create(game, user);
gameShareAccessRepository.save(access);
```
