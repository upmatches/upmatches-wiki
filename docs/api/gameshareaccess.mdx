## Overview

The `GameShareAccess` class is an entity representing the access permissions for a user to a specific game. It is part of the `com.upmatches.app.features.game.entities` package and is used to manage the relationship between games and users, ensuring that each user has the appropriate access to a game. This class is mapped to the `game_share_accesses` table in the database with unique constraints on the combination of `game_id` and `user_id`.

## Public Methods

The `GameShareAccess` class provides the following public methods:

### `create`

Creates a new instance of `GameShareAccess` with the specified game and user.

| Method Signature | Description |
| ---------------- | ----------- |
| `public static GameShareAccess create(Game game, User user)` | Static method to create a new `GameShareAccess` instance. |

#### Parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `game`    | `Game` | The game for which access is being granted. |
| `user`    | `User` | The user who is being granted access to the game. |

#### Return Type

| Type | Description |
| ---- | ----------- |
| `GameShareAccess` | Returns a new instance of `GameShareAccess` with the specified game and user. |

## Entity Details

- **Table Name**: `game_share_accesses`
- **Unique Constraints**: Combination of `game_id` and `user_id`.

## Fields

- **id**: A unique identifier for each `GameShareAccess` instance, generated using UUID strategy.
- **game**: A reference to the `Game` entity, representing the game to which access is being granted.
- **user**: A reference to the `User` entity, representing the user who is being granted access.
- **resolvedAt**: A timestamp indicating when the access was resolved, automatically set to the current time when the entity is persisted.

## Lifecycle Callback

- **onCreate**: A `@PrePersist` method that sets the `resolvedAt` field to the current timestamp when a new `GameShareAccess` entity is created.
