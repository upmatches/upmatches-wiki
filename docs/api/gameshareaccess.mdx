# GameShareAccess

The `GameShareAccess` entity represents a record of when a specific user was granted access to a shared game. It is used to track and audit game-sharing events within the application.

## Purpose

This JPA entity is designed to persist the relationship between a `Game` and a `User` when access is shared. Each record captures the exact moment the access was resolved (granted). The table enforces a unique constraint on the combination of `game_id` and `user_id`, ensuring that a user can only have one access record per game.

## Entity Details

| Field        | Type    | Description                                                                 |
|--------------|---------|-----------------------------------------------------------------------------|
| `id`         | UUID    | Primary key, auto-generated using UUID strategy.                            |
| `game`       | Game    | Many-to-one relationship to the `Game` entity. Cannot be null.              |
| `user`       | User    | Many-to-one relationship to the `User` entity. Cannot be null.              |
| `resolvedAt` | Instant | Timestamp of when the access was created. Set automatically on persist.     |

## Public Methods

### `create(Game game, User user)`

Creates a new `GameShareAccess` instance with the specified game and user. The `resolvedAt` timestamp is automatically set when the entity is persisted.

| Parameter | Type | Description                          |
|-----------|------|--------------------------------------|
| `game`    | Game | The game to which access is granted. |
| `user`    | User | The user who is granted access.      |

**Returns:** `GameShareAccess` — a new instance ready for persistence.

## Database Constraints

- **Unique Constraint:** The combination of `game_id` and `user_id` must be unique across the `game_share_accesses` table. This prevents duplicate access records for the same user and game.

## Lifecycle Callbacks

- **`@PrePersist`**: The `onCreate()` method sets the `resolvedAt` field to the current UTC timestamp (`Instant.now()`) just before the entity is persisted. This field is immutable after creation (`updatable = false`).

## Usage Example

```java
Game game = gameRepository.findById(gameId).orElseThrow();
User user = userRepository.findById(userId).orElseThrow();

GameShareAccess access = GameShareAccess.create(game, user);
gameShareAccessRepository.save(access);
```
