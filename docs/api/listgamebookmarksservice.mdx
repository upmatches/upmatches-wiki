# ListGameBookmarksService

## Purpose

The `ListGameBookmarksService` is a Spring service class responsible for retrieving a paginated list of game bookmarks for the currently authenticated user. It implements cursor-based pagination to efficiently fetch bookmarks along with the count of active participants for each bookmarked game.

This service is part of the game features module and provides read-only access to bookmark data, ensuring that only the authenticated user's bookmarks are returned.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameBookmarkRepository` | Repository | Data access for bookmark entities |
| `GameParticipantRepository` | Repository | Data access for participant counts |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user |
| `GameCursor` | Helper | Encodes/decodes cursor values for pagination |
| `ServiceOperationExecutor` | Utility | Executes service operations with standardized error handling |

## Public Methods

### `execute(String cursor, int size)`

Retrieves a cursor-paginated list of game bookmarks for the authenticated user, including the count of active participants for each bookmarked game.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The pagination cursor from a previous response, or `null` for the first page |
| `size` | `int` | The maximum number of bookmarks to return per page |

**Returns:**

| Type | Description |
|------|-------------|
| `CursorPagedResponse<GameBookmarkResponse>` | A paginated response containing the list of bookmark responses and the next cursor value |

**Behavior:**

1. Resolves the authenticated user's UUID
2. Decodes the provided cursor string (if present) to extract the start time and ID for pagination
3. Fetches bookmarks from the repository using cursor-based pagination
4. Collects all game IDs from the retrieved bookmarks
5. Queries the participant repository for active participant counts per game ID
6. Maps each bookmark to a `GameBookmarkResponse` enriched with the participant count
7. Generates the next cursor if there are more results (i.e., the number of bookmarks equals the requested page size)
8. Returns the paginated response wrapped in a standardized service operation executor

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown if the authenticated user cannot be resolved or if the operation fails |

## Example Usage

```java
// First page request
CursorPagedResponse<GameBookmarkResponse> firstPage = 
    listGameBookmarksService.execute(null, 20);

// Subsequent page request using cursor from previous response
CursorPagedResponse<GameBookmarkResponse> nextPage = 
    listGameBookmarksService.execute(firstPage.getNextCursor(), 20);
```

## Notes

- This service is annotated with `@Transactional(readOnly = true)`, ensuring database read optimization
- The service implements the `IListGameBookmarksService` interface as a non-sealed class
- Cursor-based pagination uses the bookmark's creation timestamp and ID for stable ordering
- Participant counts are fetched in a single batch query for efficiency
- The `ServiceOperationExecutor` wraps the operation with standardized logging and error handling
