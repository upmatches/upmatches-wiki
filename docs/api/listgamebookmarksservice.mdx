# ListGameBookmarksService

The `ListGameBookmarksService` class is a Spring service that provides cursor-based pagination for retrieving a user's game bookmarks. It implements the `IListGameBookmarksService` interface and is marked as a `non-sealed` class, allowing further extension.

This service handles the complete lifecycle of fetching bookmarked games for an authenticated user, including:
- Decoding the cursor for pagination
- Retrieving bookmarks with cursor-based pagination
- Enriching bookmark data with active participant counts
- Encoding the next cursor for subsequent requests

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameBookmarkRepository` | Repository | Data access for game bookmarks |
| `GameParticipantRepository` | Repository | Data access for game participants |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user |
| `GameCursor` | Helper | Encodes/decodes cursor values for pagination |

## Constructor

### `ListGameBookmarksService(GameBookmarkRepository, GameParticipantRepository, IAuthenticatedUserResolver, GameCursor)`

Initializes the service with all required dependencies via constructor injection.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `bookmarkRepository` | `GameBookmarkRepository` | Repository for bookmark data access |
| `participantRepository` | `GameParticipantRepository` | Repository for participant data access |
| `userResolver` | `IAuthenticatedUserResolver` | Resolves the authenticated user's identity |
| `gameCursor` | `GameCursor` | Helper for cursor encoding/decoding |

## Public Methods

### `execute(String cursor, int size)`

Retrieves a paginated list of game bookmarks for the authenticated user, enriched with active participant counts.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | Encoded cursor string for pagination. Pass `null` or empty for the first page. |
| `size` | `int` | Maximum number of bookmarks to return per page |

**Returns:** `CursorPagedResponse<GameBookmarkResponse>` - A paginated response containing:
- `content`: List of `GameBookmarkResponse` objects with bookmark details and participant counts
- `nextCursor`: Encoded cursor string for the next page, or `null` if there are no more results

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown if the authenticated user cannot be resolved or if an error occurs during retrieval |

**Behavior:**

1. **Authentication**: Resolves the authenticated user's UUID via `userResolver.requireUserId()`
2. **Cursor Decoding**: Decodes the provided cursor string to extract the start time and ID for pagination
3. **Bookmark Retrieval**: Fetches bookmarks using cursor-based pagination from `bookmarkRepository.findByUserIdCursor()`
4. **Participant Counts**: For all retrieved game IDs, queries active participant counts in a single batch operation
5. **Response Mapping**: Maps each bookmark to a `GameBookmarkResponse`, including the participant count
6. **Next Cursor**: If the result set is full (equals the requested size), encodes the last bookmark's timestamp and ID as the next cursor

**Transactional Behavior:** The method is marked with `@Transactional(readOnly = true)` to optimize database access and ensure consistency during reads.

**Example Usage:**

```java
// First page: 20 bookmarks
CursorPagedResponse<GameBookmarkResponse> firstPage = service.execute(null, 20);

// Subsequent page using cursor from previous response
CursorPagedResponse<GameBookmarkResponse> nextPage = service.execute(firstPage.getNextCursor(), 20);
```
