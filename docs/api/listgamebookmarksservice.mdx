## Overview

The `ListGameBookmarksService` class is a part of the game feature services in the application. It is responsible for retrieving a paginated list of game bookmarks for a user, using a cursor-based pagination mechanism. This service ensures that the bookmarks are fetched efficiently and includes participant counts for each game.

## Public Methods

### `execute`

Retrieves a paginated list of game bookmarks for the authenticated user.

| Parameter | Type   | Description                                                                 |
|-----------|--------|-----------------------------------------------------------------------------|
| `cursor`  | String | The cursor indicating the starting point for the pagination.                |
| `size`    | int    | The number of bookmarks to retrieve.                                        |

| Return Type                                | Description                                                                                     |
|--------------------------------------------|-------------------------------------------------------------------------------------------------|
| `CursorPagedResponse<GameBookmarkResponse>` | A response containing a list of `GameBookmarkResponse` objects and a cursor for the next page.  |

## Detailed Description

The `execute` method performs the following operations:

1. **User Identification**: It retrieves the user ID of the authenticated user using the `userResolver`.

2. **Cursor Decoding**: It decodes the provided cursor to determine the starting point for fetching bookmarks.

3. **Bookmark Retrieval**: It fetches a list of `GameBookmark` entities from the `bookmarkRepository` based on the user ID and the decoded cursor values.

4. **Participant Count Calculation**: It calculates the number of active participants for each game associated with the bookmarks using the `participantRepository`.

5. **Response Construction**: It maps the bookmarks to `GameBookmarkResponse` objects, including the participant counts, and constructs a `CursorPagedResponse` with the results and the next cursor.

6. **Error Handling**: It uses `ServiceOperationExecutor` to handle the operation execution and manage exceptions, specifically throwing a `ResourceNotFoundException` if necessary.

This service is marked with the `@Service` annotation, indicating that it is a Spring-managed service component, and it uses the `@Transactional(readOnly = true)` annotation to ensure that the database operations are executed in a read-only transaction.
