## Overview

The `ISingpassAuthService` interface is part of the `com.upmatches.app.features.auth.services` package. It defines the contract for authentication services that interact with the Singpass system. This interface is designed to be implemented by classes that handle the authentication process, specifically focusing on sending authorization requests and exchanging authorization codes.

## Public Methods

The `ISingpassAuthService` interface declares the following public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `sendPushedAuthorizationRequest` | `String state`, `String nonce`, `String codeVerifier` | `String` | Sends a pushed authorization request to the Singpass system. The method requires a `state`, `nonce`, and `codeVerifier` as parameters and returns a `String` response. |
| `exchangeAuthorizationCode` | `String authorizationCode`, `String codeVerifier`, `String nonce` | `String` | Exchanges an authorization code for an access token. This method takes an `authorizationCode`, `codeVerifier`, and `nonce` as parameters and returns a `String` response. |

The interface is sealed, permitting only the `SingpassAuthService` class to implement it, ensuring controlled extension and implementation within the application.
