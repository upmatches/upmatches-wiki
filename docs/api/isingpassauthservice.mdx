## Overview

The `ISingpassAuthService` interface is part of the `com.upmatches.app.features.auth.services` package. It defines the contract for implementing Singpass authentication services. This interface is designed to be implemented by classes that handle the authentication process using Singpass, a digital identity platform. The interface ensures that any implementing class provides methods for sending a pushed authorization request and exchanging an authorization code.

## Public Methods

### `sendPushedAuthorizationRequest`

Sends a pushed authorization request to the Singpass service.

<Tabs>
<TabItem value="signature" label="Signature" default>

```java
String sendPushedAuthorizationRequest(String state, String nonce, String codeVerifier);
```

</TabItem>
<TabItem value="parameters" label="Parameters">

| Parameter     | Type   | Description                                           |
|---------------|--------|-------------------------------------------------------|
| `state`       | String | A unique state value to maintain the request context. |
| `nonce`       | String | A unique nonce value to ensure request integrity.     |
| `codeVerifier`| String | A code verifier for PKCE (Proof Key for Code Exchange).|

</TabItem>
<TabItem value="returns" label="Returns">

Returns a `String` representing the response from the Singpass service.

</TabItem>
</Tabs>

### `exchangeAuthorizationCode`

Exchanges an authorization code for an access token with the Singpass service.

<Tabs>
<TabItem value="signature" label="Signature" default>

```java
String exchangeAuthorizationCode(String authorizationCode, String codeVerifier, String nonce);
```

</TabItem>
<TabItem value="parameters" label="Parameters">

| Parameter          | Type   | Description                                           |
|--------------------|--------|-------------------------------------------------------|
| `authorizationCode`| String | The authorization code received from Singpass.        |
| `codeVerifier`     | String | A code verifier for PKCE (Proof Key for Code Exchange).|
| `nonce`            | String | A unique nonce value to ensure request integrity.     |

</TabItem>
<TabItem value="returns" label="Returns">

Returns a `String` representing the access token or response from the Singpass service.

</TabItem>
</Tabs>
