# RegisterDeviceTokenRequest

The `RegisterDeviceTokenRequest` is a Java record class used to encapsulate the data required for registering a device token for push notifications. It serves as a Data Transfer Object (DTO) for incoming API requests, ensuring that the provided device token and platform information are valid before processing.

## Purpose

This record is designed to:
- Receive and validate device token registration requests from mobile clients.
- Enforce constraints on the device token length and ensure the platform is specified.
- Provide a type-safe and immutable representation of the request data using Java records.

## Record Definition

```java
public record RegisterDeviceTokenRequest(
    @NotBlank
    @Size(max = 512)
    String deviceToken,
    @NotNull
    DevicePlatform platform
) {}
```

## Fields

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `deviceToken` | `String` | `@NotBlank`, `@Size(max = 512)` | The unique token provided by the device's push notification service (e.g., APNs for iOS, FCM for Android). Must not be blank and cannot exceed 512 characters. |
| `platform` | `DevicePlatform` | `@NotNull` | The platform of the device (e.g., iOS, Android). Must not be null. |

## Validation

The record uses Jakarta Bean Validation annotations to ensure data integrity:

- **`@NotBlank`** on `deviceToken`: Ensures the token is not null and contains at least one non-whitespace character.
- **`@Size(max = 512)`** on `deviceToken`: Limits the token length to a maximum of 512 characters to prevent excessively large payloads.
- **`@NotNull`** on `platform`: Guarantees that the platform is always provided.

## Usage Example

```java
// Creating a request for an iOS device
RegisterDeviceTokenRequest request = new RegisterDeviceTokenRequest(
    "abc123def456...", 
    DevicePlatform.IOS
);

// Creating a request for an Android device
RegisterDeviceTokenRequest androidRequest = new RegisterDeviceTokenRequest(
    "xyz789...", 
    DevicePlatform.ANDROID
);
```

## Related Components

- **`DevicePlatform`**: An enum that defines supported device platforms (e.g., `IOS`, `ANDROID`).
- **Notification Service**: The service that processes this request and stores the device token for future push notifications.
