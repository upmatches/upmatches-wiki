import com.upmatches.app.features.notification.requests.RegisterDeviceTokenRequest;

## Purpose

The `RegisterDeviceTokenRequest` class is a Java record used to encapsulate the data required for registering a device token in the notification system. This record is part of the `com.upmatches.app.features.notification.requests` package and is designed to ensure that the necessary information about a device token and its platform is captured and validated before processing.

## Public Methods

The `RegisterDeviceTokenRequest` record provides an immutable data structure with the following components:

### Constructor

The constructor for `RegisterDeviceTokenRequest` is automatically provided by the Java record and is used to create instances of the record with the specified fields.

### Parameters

| Parameter    | Type                        | Description                                                                 |
|--------------|-----------------------------|-----------------------------------------------------------------------------|
| deviceToken  | `String`                    | The token representing the device, used for sending notifications. Must not be blank and can have a maximum length of 512 characters. |
| platform     | `DevicePlatform`            | The platform of the device (e.g., iOS, Android). Must not be null.          |

### Return Types

The `RegisterDeviceTokenRequest` record does not have explicit methods with return types beyond the default accessors provided by the record structure. Each field in the record has an implicit getter method:

- `String deviceToken()`: Returns the device token.
- `DevicePlatform platform()`: Returns the platform of the device.

## Usage

The `RegisterDeviceTokenRequest` is typically used in scenarios where a device needs to be registered for receiving notifications. The validation annotations ensure that the data provided is both complete and within expected constraints, facilitating robust notification handling in the application.
