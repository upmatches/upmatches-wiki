# Register Device Token Request

The `RegisterDeviceTokenRequest` is a Java record class used to encapsulate the data required for registering a device token in the UpMatches application. It serves as a Data Transfer Object (DTO) for the notification system, ensuring that incoming requests contain valid and properly formatted device registration information.

## Purpose

This record is designed to:
- Capture device token registration data from client applications
- Enforce validation constraints on input data
- Provide a type-safe representation of device platform information
- Facilitate seamless integration with Jakarta Bean Validation

## Record Definition

```java
public record RegisterDeviceTokenRequest(
    @NotBlank
    @Size(max = 512)
    String deviceToken,
    @NotNull
    DevicePlatform platform
)
```

## Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `deviceToken` | `String` | `@NotBlank`, `@Size(max = 512)` | The unique token identifying the device for push notifications. Must not be blank and cannot exceed 512 characters. |
| `platform` | `DevicePlatform` | `@NotNull` | The operating system platform of the device (e.g., iOS, Android). Must not be null. |

## Validation Constraints

The record applies the following Jakarta Bean Validation constraints:

- **`@NotBlank` on `deviceToken`**: Ensures the token is not null and contains at least one non-whitespace character
- **`@Size(max = 512)` on `deviceToken`**: Limits the token length to a maximum of 512 characters to prevent excessively large payloads
- **`@NotNull` on `platform`**: Guarantees that a valid platform enum value is always provided

## Usage Example

```java
// Creating a new registration request
RegisterDeviceTokenRequest request = new RegisterDeviceTokenRequest(
    "fcm-token-abc123xyz789",
    DevicePlatform.ANDROID
);

// Accessing fields
String token = request.deviceToken();
DevicePlatform platform = request.platform();
```

## Related Components

- **`DevicePlatform`**: An enum located in `com.upmatches.app.features.notification.enums` that defines supported device platforms
- **Package**: `com.upmatches.app.features.notification.requests`

## Notes

- This record is immutable by design, ensuring thread-safety and data integrity
- The validation annotations are processed automatically when used with Jakarta Bean Validation (e.g., in Spring Boot controllers with `@Valid`)
- The maximum token length of 512 characters accommodates various push notification service token formats (FCM, APNs, etc.)
