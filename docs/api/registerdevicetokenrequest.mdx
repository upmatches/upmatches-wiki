# RegisterDeviceTokenRequest

The `RegisterDeviceTokenRequest` class is a Java record that serves as a Data Transfer Object (DTO) for registering a device token for push notifications. It encapsulates the necessary information required to associate a device with a user's notification preferences.

## Purpose

This record is used to receive and validate incoming requests to register a device token. It ensures that the provided data meets the required constraints before being processed by the application's notification service.

## Record Structure

The record defines two fields:

| Field | Type | Validation Constraints | Description |
|-------|------|------------------------|-------------|
| `deviceToken` | `String` | `@NotBlank`, `@Size(max = 512)` | The unique token identifying the device for push notifications. Must not be blank and cannot exceed 512 characters. |
| `platform` | `DevicePlatform` | `@NotNull` | The platform of the device (e.g., iOS, Android). Must not be null. |

## Usage

This record is typically used as a request body in a REST API endpoint for registering device tokens. For example:

```java
@PostMapping("/register-device-token")
public ResponseEntity<?> registerDeviceToken(@Valid @RequestBody RegisterDeviceTokenRequest request) {
    // Process the registration
}
```

## Validation

The record leverages Jakarta Bean Validation annotations to enforce data integrity:

- **`@NotBlank`** on `deviceToken`: Ensures the token is not null and contains at least one non-whitespace character.
- **`@Size(max = 512)`** on `deviceToken`: Limits the token length to 512 characters to prevent excessively large payloads.
- **`@NotNull`** on `platform`: Guarantees that a platform is always specified.

## Related Components

- **`DevicePlatform`**: An enum that defines the supported device platforms (e.g., `IOS`, `ANDROID`).
- **Notification Service**: The service that processes the registration request and stores the device token.
