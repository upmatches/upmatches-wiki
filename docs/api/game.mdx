## Purpose of the Game Class

The `Game` class represents a game entity within the application. It is designed to manage various aspects of a game, including its activity, organizer, venue, skill levels, pricing, and status. The class provides methods to create, update, and manage the lifecycle of a game, ensuring that all necessary validations are performed to maintain data integrity.

## Public Methods

The following table documents the public methods available in the `Game` class:

| Method Name   | Parameters                                                                                                                                                                                                                                         | Return Type | Description                                                                                           |
|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------|-------------------------------------------------------------------------------------------------------|
| `create`      | `Activity activity`, `User organizer`, `Venue venue`, `SkillLevel skillLevelFrom`, `SkillLevel skillLevelTo`, `Pricing pricing`, `Integer slots`, `Instant startTime`, `Instant endTime`, `GameVisibility visibility`, `GameType gameType`, `String remark` | `Game`      | Creates a new `Game` instance with the specified parameters, performing necessary validations.         |
| `update`      | `Venue venue`, `SkillLevel skillLevelFrom`, `SkillLevel skillLevelTo`, `Pricing pricing`, `Integer slots`, `Instant startTime`, `Instant endTime`, `GameType gameType`, `String remark`                                                             | `void`      | Updates the existing `Game` instance with new values, ensuring all validations are met.                |
| `updateSlots` | `Integer slots`                                                                                                                                                                                                                                     | `void`      | Updates the number of slots available for the game.                                                   |
| `markStarted` | None                                                                                                                                                                                                                                                | `void`      | Marks the game status as `STARTED`.                                                                   |
| `markExpired` | None                                                                                                                                                                                                                                                | `void`      | Marks the game status as `EXPIRED`.                                                                   |

## Additional Information

The `Game` class includes several private methods for internal validation and pricing application, ensuring that the game data remains consistent and valid throughout its lifecycle. These methods are not exposed publicly but are crucial for maintaining the integrity of the game entity.
