# Game Entity

The `Game` class is a JPA entity that represents a scheduled sporting event or match within the UpMatches application. It encapsulates all the core attributes of a game, including its activity type, organizer, venue, skill level requirements, pricing structure, scheduling details, and lifecycle status.

This entity serves as the central domain object for managing game creation, updates, and state transitions. It enforces business rules through validation methods and provides a structured approach to pricing through the `Pricing` value object.

## Entity Overview

The `Game` entity is mapped to the `games` database table and uses UUID-based primary key generation. It maintains relationships with several other entities:

- **Activity**: The type of sport or activity being played
- **User (organizer)**: The user who created and manages the game
- **Venue**: The location where the game takes place
- **SkillLevel**: Both a minimum (`skillLevelFrom`) and maximum (`skillLevelTo`) skill level range

## Public Methods

### Static Factory Method

#### `create()`

Creates a new `Game` instance with comprehensive validation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `activity` | `Activity` | The sport/activity type |
| `organizer` | `User` | The game organizer |
| `venue` | `Venue` | The game venue |
| `skillLevelFrom` | `SkillLevel` | Minimum skill level |
| `skillLevelTo` | `SkillLevel` | Maximum skill level |
| `pricing` | `Pricing` | Pricing configuration |
| `slots` | `Integer` | Maximum participants |
| `startTime` | `Instant` | Game start time |
| `endTime` | `Instant` | Game end time |
| `visibility` | `GameVisibility` | Visibility setting |
| `gameType` | `GameType` | Type of game |
| `remark` | `String` | Optional remarks |

**Returns**: `Game` - A new game instance with status set to `SCHEDULED`

**Throws**: `IllegalArgumentException` if validation fails

### Instance Methods

#### `update()`

Updates the game's mutable properties with validation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `venue` | `Venue` | New venue |
| `skillLevelFrom` | `SkillLevel` | New minimum skill level |
| `skillLevelTo` | `SkillLevel` | New maximum skill level |
| `pricing` | `Pricing` | New pricing configuration |
| `slots` | `Integer` | New participant limit |
| `startTime` | `Instant` | New start time |
| `endTime` | `Instant` | New end time |
| `gameType` | `GameType` | New game type |
| `remark` | `String` | New remarks |

**Throws**: `IllegalArgumentException` if validation fails

#### `updateSlots()`

Updates only the participant slot count.

| Parameter | Type | Description |
|-----------|------|-------------|
| `slots` | `Integer` | New participant limit |

#### `markStarted()`

Transitions the game status to `STARTED`.

#### `markExpired()`

Transitions the game status to `EXPIRED`.

#### `cancel()`

Transitions the game status to `CANCELLED`.

#### `markDeleted()`

Sets the `deletedAt` timestamp to the current time.

#### `isDeleted()`

**Returns**: `boolean` - `true` if the game has been soft-deleted (`deletedAt` is not null)

#### `isFull()`

Checks if the game has reached its participant capacity.

| Parameter | Type | Description |
|-----------|------|-------------|
| `participantCount` | `long` | Current number of participants |

**Returns**: `boolean` - `true` if participant count meets or exceeds slots

#### `isPastOrInactive()`

Checks if the game is no longer active or scheduled.

**Returns**: `boolean` - `true` if status is not `SCHEDULED` or end time has passed

#### `getPricing()`

Reconstructs the structured `Pricing` object from persisted fields. For legacy rows where `pricingMode` is null, it falls back to creating a flat pricing using the stored `price` and `currency` fields.

**Returns**: `Pricing` - The reconstructed pricing configuration

## Validation Rules

The entity enforces several business rules through private validation methods:

1. **Time Validation**: End time must be after start time
2. **Skill Level Validation**: 
   - Both skill levels must belong to the same activity as the game
   - The "to" skill level's sort order must be greater than or equal to the "from" skill level's sort order
3. **Pricing Validation**: Pricing object must not be null

## Lifecycle Callbacks

- **`@PrePersist` (`onCreate()`)**: Sets `createdAt` and `updatedAt` to the current time before persisting
- **`@PreUpdate` (`onUpdate()`)**: Updates `updatedAt` to the current time before updating

## Usage Example

```java
// Create a new game
Game game = Game.create(
    badmintonActivity,
    organizerUser,
    sportsVenue,
    beginnerLevel,
    intermediateLevel,
    Pricing.flat(new BigDecimal("15.00"), Currency.create("USD")),
    20,
    Instant.parse("2024-01-15T10:00:00Z"),
    Instant.parse("2024-01-15T12:00:00Z"),
    GameVisibility.PUBLIC,
    GameType.SINGLES,
    "Bring your own racket"
);

// Update game details
game.update(
    newVenue,
    beginnerLevel,
    advancedLevel,
    Pricing.perPerson(new BigDecimal("10.00"), Currency.create("USD")),
```
