# Game Entity

The `Game` class is a JPA entity that represents a scheduled sports game or match within the UpMatches application. It encapsulates all game-related data including scheduling, venue, skill levels, pricing, and status management. This entity serves as the core domain object for organizing and managing competitive matches between participants.

## Class Overview

- **Package**: `com.upmatches.app.features.game.entities`
- **Database Table**: `games`
- **Key Dependencies**: Activity, User (organizer), Venue, SkillLevel, Pricing

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique identifier (auto-generated) |
| `activity` | `Activity` | The sport/activity type |
| `organizer` | `User` | The user who created the game |
| `venue` | `Venue` | Location where the game takes place |
| `skillLevelFrom` | `SkillLevel` | Minimum skill level required |
| `skillLevelTo` | `SkillLevel` | Maximum skill level allowed |
| `currency` | `String` | ISO 4217 currency code (3 characters) |
| `price` | `BigDecimal` | Representative price amount |
| `pricingMode` | `PricingMode` | Pricing strategy (FLAT, GENDER_BASED, etc.) |
| `flatPrice` | `BigDecimal` | Flat price for all participants |
| `malePrice` | `BigDecimal` | Price for male participants |
| `femalePrice` | `BigDecimal` | Price for female participants |
| `basePrice` | `BigDecimal` | Base price before adjustments |
| `pricePerShuttle` | `BigDecimal` | Price per shuttle (for badminton) |
| `slots` | `Integer` | Maximum number of participants |
| `startTime` | `Instant` | Game start time |
| `endTime` | `Instant` | Game end time |
| `visibility` | `GameVisibility` | Who can see the game |
| `gameType` | `GameType` | Type of game (SINGLES, DOUBLES, etc.) |
| `remark` | `String` | Additional notes (max 500 characters) |
| `status` | `GameStatus` | Current game status |
| `createdAt` | `Instant` | Creation timestamp |
| `updatedAt` | `Instant` | Last update timestamp |
| `deletedAt` | `Instant` | Deletion timestamp (soft delete) |

## Public Methods

### Static Factory Method

#### `create()`
Creates a new Game instance with comprehensive validation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `activity` | `Activity` | The sport/activity type |
| `organizer` | `User` | The game organizer |
| `venue` | `Venue` | Game location |
| `skillLevelFrom` | `SkillLevel` | Minimum skill level |
| `skillLevelTo` | `SkillLevel` | Maximum skill level |
| `pricing` | `Pricing` | Pricing configuration |
| `slots` | `Integer` | Maximum participants |
| `startTime` | `Instant` | Start time |
| `endTime` | `Instant` | End time |
| `visibility` | `GameVisibility` | Visibility setting |
| `gameType` | `GameType` | Game type |
| `remark` | `String` | Optional notes |

**Returns**: `Game` - A new Game instance with status set to `SCHEDULED`

**Throws**: `IllegalArgumentException` if validation fails

### Instance Methods

#### `update()`
Updates game details with validation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `venue` | `Venue` | New venue |
| `skillLevelFrom` | `SkillLevel` | New minimum skill level |
| `skillLevelTo` | `SkillLevel` | New maximum skill level |
| `pricing` | `Pricing` | New pricing configuration |
| `slots` | `Integer` | New slot count |
| `startTime` | `Instant` | New start time |
| `endTime` | `Instant` | New end time |
| `gameType` | `GameType` | New game type |
| `remark` | `String` | New remarks |

**Throws**: `IllegalArgumentException` if validation fails

#### `updateSlots()`
Updates the number of available slots.

| Parameter | Type | Description |
|-----------|------|-------------|
| `slots` | `Integer` | New slot count |

#### `markStarted()`
Changes game status to `STARTED`.

#### `markExpired()`
Changes game status to `EXPIRED`.

#### `cancel()`
Changes game status to `CANCELLED`.

#### `markDeleted()`
Sets the `deletedAt` timestamp to the current time (soft delete).

### Transient/Computed Methods

#### `isDeleted()`
Checks if the game has been soft-deleted.

**Returns**: `boolean` - `true` if `deletedAt` is not null

#### `isFull()`
Checks if the game has reached maximum capacity.

| Parameter | Type | Description |
|-----------|------|-------------|
| `participantCount` | `long` | Current number of participants |

**Returns**: `boolean` - `true` if participant count >= slots

#### `isPastOrInactive()`
Checks if the game is no longer active or has passed.

**Returns**: `boolean` - `true` if status is not `SCHEDULED` or end time has passed

#### `getPricing()`
Reconstructs the structured Pricing object from persisted fields.

**Returns**: `Pricing` - A Pricing object with appropriate mode and amounts

## Validation Rules

1. **Time Validation**: End time must be after start time
2. **Skill Level Validation**: 
   - Both skill levels must belong to the same activity as the game
   - The "to" skill level must have a sort order >= the "from" skill level
3. **Pricing Validation**: Pricing object must not be null

## Lifecycle Callbacks

- **`@PrePersist`**: Automatically sets `createdAt` and `updatedAt` timestamps before first persistence
- **`@PreUpdate`**: Automatically updates `updatedAt` timestamp before any update operation

## Usage Example

```java
// Creating a new game
Game game = Game.create(
    badmintonActivity,
    organizerUser,
    sportsVenue,
    beginnerSkillLevel,
    intermediateSkillLevel,
    Pricing.flat(new BigDecimal("15.00"), Currency.create("USD")),
    20,
    Instant.now().plus(7, ChronoUnit.DAYS),
    Instant.now().plus(7, ChronoUnit.DAYS).plus(2, ChronoUnit.HOURS),
    GameVisibility.PUBLIC,
    GameType.DOUBLES,
    "Bring your own racket"
);

// Updating game details
game.update(
    newVenue,
    newSkillLevelFrom,
    newSkillLevelTo,
    newPricing,
    25,
    newStartTime,
    newEndTime,
    GameType.SINGLES,
    "Updated remarks"
);

// Managing game lifecycle
game.markStarted();
game.markExpired();
game.cancel();
game.markDeleted();
```
