# Game Entity

The `Game` class is a JPA entity that represents a scheduled sports game or match within the UpMatches application. It encapsulates all game-related data including scheduling, venue, skill level requirements, pricing, and status management. This entity serves as the core domain object for organizing and managing matches between players.

## Class Overview

- **Package**: `com.upmatches.app.features.game.entities`
- **Table**: `games`
- **Key Relationships**: Activity, User (organizer), Venue, SkillLevel (from/to)
- **Status Lifecycle**: SCHEDULED → STARTED → EXPIRED/CANCELLED

## Fields

| `id` | `UUID` | Primary key, auto-generated |

| `skillLevelTo` | `SkillLevel` | Maximum skill level allowed (Many-to-One) |

| `price` | `BigDecimal` | Representative price amount |
| `pricingMode` | `PricingMode` | Pricing strategy (FLAT, GENDER_BASED, PER_SHUTTLE, etc.) |

| `femalePrice` | `BigDecimal` | Price for female participants |

| `visibility` | `GameVisibility` | Who can see/join the game |

| `status` | `GameStatus` | Current game status |

| `updatedAt` | `Instant` | Last update timestamp |
| `deletedAt` | `Instant` | Deletion timestamp (soft delete) |

## Public Methods

### Static Factory Method

#### `create()`
Creates a new Game instance with comprehensive validation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `activity` | `Activity` | The sport/activity for the game |
| `organizer` | `User` | The user organizing the game |
| `venue` | `Venue` | The venue where the game will be held |
| `skillLevelFrom` | `SkillLevel` | Minimum skill level requirement |
| `skillLevelTo` | `SkillLevel` | Maximum skill level requirement |
| `pricing` | `Pricing` | Pricing configuration |
| `slots` | `Integer` | Maximum participant slots |
| `startTime` | `Instant` | Game start time |
| `endTime` | `Instant` | Game end time |
| `visibility` | `GameVisibility` | Game visibility setting |
| `gameType` | `GameType` | Type of game |
| `remark` | `String` | Optional remarks |

**Returns**: `Game` - A new Game instance with status set to SCHEDULED

**Throws**: `IllegalArgumentException` if validation fails for:
- End time not after start time
- Skill level activity mismatch
- Skill level sort order violation
- Missing pricing

### Instance Methods

#### `update()`
Updates the game's mutable properties with validation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `venue` | `Venue` | New venue |
| `skillLevelFrom` | `SkillLevel` | New minimum skill level |
| `skillLevelTo` | `SkillLevel` | New maximum skill level |
| `pricing` | `Pricing` | New pricing configuration |
| `slots` | `Integer` | New slot count |
| `startTime` | `Instant` | New start time |
| `endTime` | `Instant` | New end time |
| `gameType` | `GameType` | New game type |
| `remark` | `String` | New remarks |

**Throws**: `IllegalArgumentException` if validation fails

#### `updateSlots()`
Updates only the participant slots.

| Parameter | Type | Description |
|-----------|------|-------------|
| `slots` | `Integer` | New slot count |

#### `markStarted()`
Changes game status to STARTED.

#### `markExpired()`
Changes game status to EXPIRED.

#### `cancel()`
Changes game status to CANCELLED.

#### `markDeleted()`
Sets the deletedAt timestamp to the current time (soft delete).

### Transient/Computed Methods

#### `isDeleted()`
**Returns**: `boolean` - `true` if the game has been soft-deleted

#### `isFull(long participantCount)`
| Parameter | Type | Description |
|-----------|------|-------------|
| `participantCount` | `long` | Current number of participants |

**Returns**: `boolean` - `true` if participant count meets or exceeds slots

#### `isPastOrInactive()`
**Returns**: `boolean` - `true` if the game is not SCHEDULED or end time has passed

#### `getPricing()`
Reconstructs the structured Pricing object from persisted fields. For legacy rows without a pricing mode, falls back to flat pricing using the stored price and currency.

**Returns**: `Pricing` - The reconstructed pricing configuration

## Validation Rules

1. **Time Validation**: End time must be strictly after start time
2. **Skill Level Validation**:
   - Both skill levels must belong to the same activity as the game
   - The "to" skill level's sort order must be >= the "from" skill level's sort order
3. **Pricing Validation**: Pricing object must not be null

## Lifecycle Callbacks

- **@PrePersist** (`onCreate()`): Sets `createdAt` and `updatedAt` to current time
- **@PreUpdate** (`onUpdate()`): Updates `updatedAt` to current time

## Usage Example

```java
// Creating a new game
Game game = Game.create(
    badmintonActivity,
    organizerUser,
    sportsVenue,
    beginnerSkillLevel,
    intermediateSkillLevel,
    Pricing.flat(new BigDecimal("15.00"), Currency.USD),
    8,
    Instant.now().plus(7, ChronoUnit.DAYS),
    Instant.now().plus(7, ChronoUnit.DAYS).plus(2, ChronoUnit.HOURS),
    GameVisibility.PUBLIC,
    GameType.DOUBLES,
    "Bring your own racket"
);

// Updating game details
game.update(
    newVenue,
    intermediateSkillLevel,
    advancedSkillLevel,
    Pricing.genderBased(new BigDecimal("10.00"), new BigDecimal("12.00"), Currency.USD),
    12,
    newStartTime,
    newEndTime,
    GameType.SINGLES,
    "Updated remarks"
);

// Status management
game.markStarted();
game.cancel();
game.markDeleted();

// Checking game state
boolean isFull = game.isFull(currentParticipantCount);
boolean isInactive = game.isPastOrInactive();
```
