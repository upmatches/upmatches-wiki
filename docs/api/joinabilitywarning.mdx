## Overview

The `JoinabilityWarning` enum is part of the `com.upmatches.app.features.game.enums` package. It is used to represent different types of warnings that may occur when a user attempts to join a game. This enum helps in identifying specific conditions that might prevent or caution a user from joining a game session.

## Enum Constants

The `JoinabilityWarning` enum defines the following constants:

| Constant       | Description                                                                 |
|----------------|-----------------------------------------------------------------------------|
| IS_ORGANIZER   | Indicates that the user attempting to join is the organizer of the game.    |
| SKILL_MISMATCH | Indicates that there is a skill mismatch between the user and the game.     |

## Usage

This enum can be used in game-related logic to check for conditions that might affect a user's ability to join a game. By using these constants, developers can implement logic to handle these specific warnings appropriately, such as notifying the user or preventing them from joining under certain conditions.
