# JoinabilityWarning

The `JoinabilityWarning` enum defines a set of warnings that can be returned when a user attempts to join a game session. These warnings indicate potential issues that may prevent or discourage a user from joining a particular game, without necessarily blocking the action entirely.

## Purpose

This enum is used to communicate specific reasons why a join attempt might be problematic. It provides a lightweight, type-safe way to represent these conditions throughout the application, particularly in the game matching and session management features.

## Enum Values

| Value | Description |
|-------|-------------|
| `IS_ORGANIZER` | Indicates that the user attempting to join is already the organizer of the game session. This warning suggests the user may not need to join their own game. |
| `SKILL_MISMATCH` | Indicates that the user's skill level does not match the expected skill range for the game session. This warning alerts the user to a potential imbalance in gameplay experience. |

## Usage

The `JoinabilityWarning` enum is typically used in conjunction with a joinability check result, where multiple warnings can be returned to inform the user of all potential issues with their join request. For example:

```java
// Example usage in a joinability check
List<JoinabilityWarning> warnings = new ArrayList<>();
if (userIsOrganizer) {
    warnings.add(JoinabilityWarning.IS_ORGANIZER);
}
if (skillMismatch) {
    warnings.add(JoinabilityWarning.SKILL_MISMATCH);
}
return warnings;
```
