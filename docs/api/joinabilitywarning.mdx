# JoinabilityWarning

The `JoinabilityWarning` enum defines a set of warnings that can be raised when a player attempts to join a game session. These warnings indicate potential issues that may prevent the player from joining or that the player should be aware of before joining.

## Purpose

This enum is used to communicate specific reasons why a player's join request might be problematic. It helps the application provide clear feedback to users about why they cannot join a particular game or what they should consider before joining.

## Enum Values

| Value | Description |
|-------|-------------|
| `IS_ORGANIZER` | Indicates that the player attempting to join is the organizer of the game session. This warning typically means the organizer cannot join their own game as a participant. |
| `SKILL_MISMATCH` | Indicates that the player's skill level does not match the expected skill level for the game session. This warning helps maintain balanced gameplay and fair competition. |

## Usage

This enum is typically used in conjunction with join validation logic. When a player attempts to join a game, the system checks for potential issues and returns the appropriate warning if any are found.

### Example

```java
// Example usage in a join validation method
public JoinabilityWarning validateJoinRequest(Player player, GameSession session) {
    if (session.getOrganizer().equals(player)) {
        return JoinabilityWarning.IS_ORGANIZER;
    }
    
    if (player.getSkillLevel() != session.getRequiredSkillLevel()) {
        return JoinabilityWarning.SKILL_MISMATCH;
    }
    
    return null; // No warnings, player can join
}
```
