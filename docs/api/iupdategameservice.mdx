# IUpdateGameService Interface

The `IUpdateGameService` interface defines the contract for updating an existing game entity within the application. It follows a sealed interface pattern, restricting implementation to the `UpdateGameService` class only. This design ensures that all game update operations are performed through a single, controlled implementation, promoting consistency and maintainability.

## Purpose

This interface serves as the service layer abstraction for modifying game data. By defining a single `execute` method, it encapsulates the business logic required to update a game identified by its unique ID (`UUID`) with the data provided in an `UpdateGameRequest`. The result is returned as a `GameResponse` object.

## Method Summary

| Method | Description |
|--------|-------------|
| `execute(UUID id, UpdateGameRequest request)` | Updates a game entity identified by the given UUID with the provided request data and returns the updated game information. |

## Method Details

### `execute`

```java
GameResponse execute(UUID id, UpdateGameRequest request)
```

Updates an existing game with the specified identifier.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to be updated. |
| `request` | `UpdateGameRequest` | The request object containing the updated game data. |

**Returns:**

| Type | Description |
|------|-------------|
| `GameResponse` | The response object containing the updated game information. |

**Implementation Constraints:**

- This interface is `sealed`, meaning only the `UpdateGameService` class is permitted to implement it.
- Any attempt to implement this interface from an unauthorized class will result in a compilation error.

## Usage Example

```java
// Assuming UpdateGameService is properly instantiated
IUpdateGameService updateGameService = new UpdateGameService();

UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UpdateGameRequest request = new UpdateGameRequest("Updated Game Title", "New description");

GameResponse response = updateGameService.execute(gameId, request);
```

## Related Components

- `UpdateGameRequest` - The input data transfer object containing the fields to be updated.
- `GameResponse` - The output data transfer object representing the updated game state.
- `UpdateGameService` - The sole implementation class of this interface.
