# IUpdateGameService Interface

The `IUpdateGameService` interface defines the contract for updating an existing game entity within the UpMatches application. It follows a sealed interface pattern to restrict implementation to a single concrete service class (`UpdateGameService`), ensuring controlled and consistent update behavior across the system.

## Purpose

This interface serves as the abstraction layer for game update operations. By defining a single `execute` method, it enforces a standardized approach to modifying game data while allowing the underlying implementation to handle business logic, validation, and persistence concerns.

## Interface Definition

```java
public sealed interface IUpdateGameService permits UpdateGameService {
    GameResponse execute(UUID id, UpdateGameRequest request);
}
```

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(UUID id, UpdateGameRequest request)` | `GameResponse` | Updates an existing game identified by the provided UUID with the data from the update request |

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to be updated |
| `request` | `UpdateGameRequest` | The request object containing the updated game data |

## Return Value

The method returns a `GameResponse` object representing the updated game state after successful modification.

## Sealed Interface Constraint

The `sealed` keyword restricts implementation to only the `UpdateGameService` class. This design choice provides:

- **Controlled extensibility**: Only the permitted class can implement this interface
- **Compile-time safety**: The compiler enforces the implementation restriction
- **Clear intent**: Developers understand that game update logic is centralized

## Usage Example

```java
// Inject the service
private final IUpdateGameService updateGameService;

// Update a game
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
UpdateGameRequest request = new UpdateGameRequest(/* ... */);
GameResponse updatedGame = updateGameService.execute(gameId, request);
```

## Related Components

- **`UpdateGameRequest`**: The input DTO containing fields to be updated
- **`GameResponse`**: The output DTO representing the updated game
- **`UpdateGameService`**: The concrete implementation of this interface
