# IUpdateGameService Interface

The `IUpdateGameService` interface defines the contract for updating an existing game entity within the application. It follows a sealed interface pattern, restricting implementation to the `UpdateGameService` class only. This design ensures that all game update operations adhere to a single, controlled implementation path.

## Purpose

This interface serves as the abstraction layer for the "Update Game" use case. By defining a single `execute` method, it encapsulates the logic required to modify a game's attributes based on the provided request data. The sealed keyword enforces compile-time safety by preventing unauthorized implementations.

## Method Summary

| Method | Description |
|--------|-------------|
| `execute(UUID id, UpdateGameRequest request)` | Updates a game identified by the given UUID with the data provided in the request. Returns the updated game details. |

## Method Details

### `execute`

```java
GameResponse execute(UUID id, UpdateGameRequest request)
```

Updates an existing game entity with the specified identifier.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to be updated. |
| `request` | `UpdateGameRequest` | The request object containing the updated game data. |

**Returns:**

| Type | Description |
|------|-------------|
| `GameResponse` | The response object containing the updated game details. |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `GameNotFoundException` | If no game exists with the provided UUID. |
| `InvalidUpdateException` | If the update request contains invalid or inconsistent data. |

## Usage Example

```java
@Autowired
private IUpdateGameService updateGameService;

public void updateGameExample() {
    UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
    UpdateGameRequest request = new UpdateGameRequest("Updated Title", "New Description");
    
    GameResponse response = updateGameService.execute(gameId, request);
    // Process the updated game response
}
```

## Implementation Notes

- The interface is **sealed**, meaning only the `UpdateGameService` class can implement it.
- The `execute` method is the single entry point for game update operations.
- The `UpdateGameRequest` and `GameResponse` classes are expected to be defined elsewhere in the application.
- UUID is used for game identification to ensure globally unique identifiers.
