import java.util.UUID;

## Overview

The `IUpdateGameService` interface is a part of the `com.upmatches.app.features.game.services` package. It defines the contract for updating game information within the application. This interface is designed to be implemented by classes that provide the actual update logic for game data. By using a sealed interface, it restricts which classes can implement it, ensuring a controlled extension of its functionality.

## Public Methods

The `IUpdateGameService` interface declares the following public method:

| Method Signature | Description |
|------------------|-------------|
| `GameResponse execute(UUID id, UpdateGameRequest request)` | Executes the update operation for a game identified by the given UUID. |

### Method Details

#### `execute`

- **Description**: This method is responsible for updating the game information based on the provided `UpdateGameRequest`. It returns a `GameResponse` which contains the updated game details.
- **Parameters**:
  | Name    | Type                       | Description                           |
  |---------|----------------------------|---------------------------------------|
  | `id`    | `UUID`                     | The unique identifier of the game to be updated. |
  | `request` | `UpdateGameRequest`      | The request object containing the new game data. |
- **Returns**: `GameResponse` - An object containing the updated game information.
