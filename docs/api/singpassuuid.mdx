## Purpose of the SingpassUuid Class

The `SingpassUuid` class is a value object designed to encapsulate and validate a UUID string specific to the Singpass system. It ensures that the UUID conforms to a predefined format, which includes optional prefixes and a standard UUID structure. This class is immutable and provides a robust way to handle UUIDs within the application, ensuring that any UUID used is valid and correctly formatted.

## Public Methods

The `SingpassUuid` class provides the following public methods:

### `create`

Creates a new instance of `SingpassUuid`.

| Parameter | Type   | Description                  |
|-----------|--------|------------------------------|
| `uuid`    | String | The UUID string to validate and encapsulate. |

| Return Type   | Description                           |
|---------------|---------------------------------------|
| `SingpassUuid`| A new instance of `SingpassUuid` if the input is valid. |

### `toString`

Returns the string representation of the `SingpassUuid`.

| Return Type | Description                           |
|-------------|---------------------------------------|
| `String`    | The UUID string encapsulated by this instance. |

## Validation

The `SingpassUuid` class performs validation on the UUID string during instantiation. The validation checks include:

- The UUID string must not be null or blank.
- The UUID string must match the expected format, which includes optional prefixes (`s=` and `u=`) and a standard UUID pattern (`xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`).

If the validation fails, an `IllegalArgumentException` is thrown with an appropriate error message.
