## Purpose of the Class

The `SingpassUuid` class is a value object that encapsulates a UUID string specifically formatted for Singpass authentication. It ensures that the UUID adheres to a specific pattern and provides a convenient way to create and manage these UUIDs within the application. The class is implemented as a Java record, which is a special kind of class in Java that is immutable and primarily used to store data.

## Validation

The `SingpassUuid` class performs validation on the UUID string to ensure it is not null, not blank, and matches the expected format. If any of these conditions are not met, an `IllegalArgumentException` is thrown. This ensures that only valid UUIDs are encapsulated by instances of this class.
