# IGetGameService Interface

The `IGetGameService` interface defines the contract for retrieving a single game entity by its unique identifier. It is a sealed interface, meaning only the explicitly permitted class `GetGameService` can implement it. This design enforces a controlled hierarchy and ensures that the retrieval logic is centralized and consistent across the application.

## Purpose

- Provides a single method to fetch a game based on its UUID.
- Encapsulates the retrieval logic behind a clean, testable interface.
- Uses Java's sealed interface feature to restrict implementation to a specific service class.

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(UUID id)` | `GameResponse` | Retrieves a game by its unique identifier and returns the corresponding response object. |

## Method Details

### `execute(UUID id)`

```java
GameResponse execute(UUID id);
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to retrieve. Must not be null. |

**Returns:**

| Type | Description |
|------|-------------|
| `GameResponse` | The response object containing the game data. |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `IllegalArgumentException` | If the provided `id` is null. |
| `NoSuchElementException` | If no game exists with the given `id`. |

## Usage Example

```java
// Assuming GetGameService is properly instantiated
IGetGameService gameService = new GetGameService();

UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
GameResponse response = gameService.execute(gameId);
```

## Implementation Notes

- The interface is sealed, so only `GetGameService` can implement it.
- The `execute` method is the single entry point for game retrieval.
- The returned `GameResponse` object should contain all necessary game information for the client.

## Related Components

- `GetGameService` - The only permitted implementation of this interface.
- `GameResponse` - The data transfer object returned by the `execute` method.
