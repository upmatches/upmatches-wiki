# DatabaseConstant

The `DatabaseConstant` class is a utility class that centralizes all database-related constants used across the Upmatches application. It provides a single source of truth for JDBC URL prefixes, HikariCP connection pool defaults, logging message templates, and database-specific configuration parameters for PostgreSQL and H2 databases.

This class is declared as `final` and has a private constructor to prevent instantiation, following the standard utility class pattern.

## Constants
