## Overview

The `DatabaseConstant` class is a utility class that provides a collection of constants used for database configuration and logging within the application. It is designed to be immutable and cannot be instantiated. This class includes constants for JDBC URLs, default pool configurations, logging messages, and various database-specific settings.

## Constructor

The `DatabaseConstant` class has a private constructor to prevent instantiation:

```java
private DatabaseConstant() {
    throw new AssertionError();
}
```

This constructor throws an `AssertionError` if an attempt is made to instantiate the class, ensuring that it remains a utility class with only static members.
