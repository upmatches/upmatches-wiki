# DatabaseConstant

The `DatabaseConstant` class is a utility class that centralizes all database-related constants used across the Upmatches application. It provides a single source of truth for JDBC URL prefixes, HikariCP connection pool defaults, PostgreSQL and H2 database-specific configuration parameters, logging message templates, and URL masking patterns.

This class is declared as `final` and has a private constructor to prevent instantiation, following the standard utility class pattern.

## Constants

### JDBC URL Prefixes

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `JDBC_H2` | `String` | `"jdbc:h2:"` | JDBC URL prefix for H2 database |
| `JDBC_POSTGRESQL` | `String` | `"jdbc:postgresql:"` | JDBC URL prefix for PostgreSQL |
| `JDBC_MYSQL` | `String` | `"jdbc:mysql:"` | JDBC URL prefix for MySQL |
