## Overview

The `DatabaseConstant` class is a utility class that provides a collection of constants used for database configuration and logging within the application. These constants include JDBC URL prefixes, default pool settings, logging messages, and various configuration parameters for H2 and PostgreSQL databases. This class is designed to be non-instantiable and is marked as `final` to prevent inheritance.

## Constructor

The `DatabaseConstant` class has a private constructor to prevent instantiation:

```java
private DatabaseConstant() {
    throw new AssertionError();
}
```

This constructor throws an `AssertionError` if called, ensuring that the class cannot be instantiated or extended.
