# ISendFcmTestNotificationService Interface

## Purpose

The `ISendFcmTestNotificationService` interface defines the contract for sending test Firebase Cloud Messaging (FCM) notifications. It is a **sealed interface**, meaning only the explicitly permitted class (`SendFcmTestNotificationService`) can implement it. This design enforces a single, controlled implementation for sending test notifications, ensuring consistency and security within the notification system.

## Interface Definition

```java
public sealed interface ISendFcmTestNotificationService permits SendFcmTestNotificationService {
    FcmTestNotificationResponse execute(SendFcmTestNotificationRequest request);
}
```

## Methods

### `execute`

Executes the logic to send a test FCM notification based on the provided request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `SendFcmTestNotificationRequest` | The request object containing the necessary data to send the test notification (e.g., device token, message payload). |

| Returns | Type | Description |
|---------|------|-------------|
| `FcmTestNotificationResponse` | `FcmTestNotificationResponse` | The response object containing the result of the test notification operation (e.g., success status, message ID, error details). |

## Permitted Implementations

| Implementation Class | Description |
|----------------------|-------------|
| `SendFcmTestNotificationService` | The sole permitted implementation that handles the actual FCM test notification sending logic. |

## Usage Example

```java
// Assuming you have an instance of the permitted implementation
ISendFcmTestNotificationService testNotificationService = new SendFcmTestNotificationService();

// Create the request
SendFcmTestNotificationRequest request = new SendFcmTestNotificationRequest();
// ... populate request fields ...

// Execute the test notification
FcmTestNotificationResponse response = testNotificationService.execute(request);

// Process the response
if (response.isSuccess()) {
    System.out.println("Test notification sent successfully. Message ID: " + response.getMessageId());
} else {
    System.err.println("Failed to send test notification: " + response.getError());
}
```

## Related Components

- **`SendFcmTestNotificationRequest`**: The input data transfer object containing test notification parameters.
- **`FcmTestNotificationResponse`**: The output data transfer object containing the result of the test notification operation.
- **`SendFcmTestNotificationService`**: The concrete implementation class that fulfills this interface contract.
