## Overview

The `ISendFcmTestNotificationService` is a sealed interface designed to handle the sending of test notifications via Firebase Cloud Messaging (FCM). This interface is part of the notification services in the application and ensures that any implementing class provides the necessary functionality to execute a test notification request.

## Public Methods

### `execute`

Executes the process of sending a test notification using the provided request data.

| Parameter | Type                                           | Description                                      |
|-----------|------------------------------------------------|--------------------------------------------------|
| request   | `SendFcmTestNotificationRequest`               | The request object containing notification data. |

| Return Type                      | Description                                      |
|----------------------------------|--------------------------------------------------|
| `FcmTestNotificationResponse`    | The response object containing the result of the notification attempt. |

This method is essential for testing the notification system by sending a test message to ensure that the FCM integration is functioning correctly.
