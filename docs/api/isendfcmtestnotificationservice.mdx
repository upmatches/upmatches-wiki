# ISendFcmTestNotificationService Interface

## Purpose

The `ISendFcmTestNotificationService` interface defines the contract for sending Firebase Cloud Messaging (FCM) test notifications within the UpMatches application. It follows a sealed interface pattern to restrict implementation to a single concrete class (`SendFcmTestNotificationService`), ensuring controlled extensibility and type safety.

This interface is part of the notification feature module and is responsible for executing the business logic required to send a test push notification via FCM. By abstracting the execution logic behind an interface, the application promotes loose coupling and testability.

## Interface Declaration

```java
public sealed interface ISendFcmTestNotificationService permits SendFcmTestNotificationService
```

- **Sealed Interface**: The `sealed` keyword restricts which classes or interfaces can implement this interface. Only `SendFcmTestNotificationService` is permitted to implement it.
- **Package**: `com.upmatches.app.features.notification.services`

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(SendFcmTestNotificationRequest request)` | `FcmTestNotificationResponse` | Executes the logic to send a test FCM notification based on the provided request data and returns the response. |

## Parameters

### `execute` Method

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `SendFcmTestNotificationRequest` | The request object containing the necessary data to send a test FCM notification (e.g., device token, message payload). |

## Return Type

| Type | Description |
|------|-------------|
| `FcmTestNotificationResponse` | The response object containing the result of the FCM test notification operation (e.g., success status, message ID, or error details). |

## Usage Example

```java
// Assuming the implementation is injected via dependency injection
ISendFcmTestNotificationService service = new SendFcmTestNotificationService();

SendFcmTestNotificationRequest request = new SendFcmTestNotificationRequest();
// Populate request fields...

FcmTestNotificationResponse response = service.execute(request);
```
