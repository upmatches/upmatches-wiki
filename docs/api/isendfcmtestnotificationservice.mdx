# ISendFcmTestNotificationService Interface

## Purpose

The `ISendFcmTestNotificationService` interface defines the contract for sending test Firebase Cloud Messaging (FCM) notifications within the UpMatches application. It follows a sealed interface pattern to restrict implementation to a single concrete class (`SendFcmTestNotificationService`), ensuring controlled and secure usage of the notification testing functionality.

This interface is part of the notification feature module and is designed to support testing workflows where developers or administrators need to send test push notifications to verify FCM integration and device token validity.

## Interface Definition

```java
public sealed interface ISendFcmTestNotificationService permits SendFcmTestNotificationService {
    FcmTestNotificationResponse execute(SendFcmTestNotificationRequest request);
}
```

### Sealed Interface

The interface is declared as `sealed`, meaning only the explicitly permitted class (`SendFcmTestNotificationService`) can implement it. This design choice provides:
- **Controlled extensibility**: Only one implementation exists, preventing unauthorized implementations.
- **Pattern matching support**: Enables exhaustive pattern matching in switch expressions.
- **Security**: Ensures test notification logic follows a single, approved implementation path.

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(SendFcmTestNotificationRequest request)` | `FcmTestNotificationResponse` | Executes the test notification sending process based on the provided request parameters. |

## Parameters

### `execute` Method

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `SendFcmTestNotificationRequest` | Contains the necessary data for sending a test FCM notification, such as device token, notification title, body, and optional data payload. |

## Return Type

| Type | Description |
|------|-------------|
| `FcmTestNotificationResponse` | Encapsulates the result of the test notification operation, including success status, message ID, and any error details if the operation fails. |

## Usage Example

```java
// Assuming you have an instance of the service
ISendFcmTestNotificationService testService = new SendFcmTestNotificationService();

// Create a test notification request
SendFcmTestNotificationRequest request = new SendFcmTestNotificationRequest(
    "device-token-12345",
    "Test Notification",
    "This is a test message from UpMatches"
);

// Execute the test notification
FcmTestNotificationResponse response = testService.execute(request);

// Check the result
if (response.isSuccess()) {
    System.out.println("Test notification sent successfully. Message ID: " + response.getMessageId());
} else {
    System.err.println("Failed to send test notification: " + response.getError());
}
```
