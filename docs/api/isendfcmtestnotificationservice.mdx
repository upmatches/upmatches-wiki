## Overview

The `ISendFcmTestNotificationService` is a sealed interface in the `com.upmatches.app.features.notification.services` package. It defines a contract for sending Firebase Cloud Messaging (FCM) test notifications. This interface is designed to be implemented by classes that handle the logic for sending test notifications via FCM, ensuring a consistent API for this functionality.

## Public Methods

The interface declares the following public method:

| Method Signature | Description |
|------------------|-------------|
| `FcmTestNotificationResponse execute(SendFcmTestNotificationRequest request)` | Executes the process of sending a test notification using the provided request data. |

### Method Details

#### `execute`

- **Description**: This method is responsible for executing the process of sending a test notification via FCM. It takes a request object containing the necessary data to perform the notification sending operation and returns a response object indicating the result of the operation.
- **Parameters**:

  | Parameter | Type | Description |
  |-----------|------|-------------|
  | `request` | `SendFcmTestNotificationRequest` | An object containing the data required to send a test notification. |

- **Returns**: `FcmTestNotificationResponse` - An object representing the response from the FCM service, indicating the success or failure of the notification sending process.
