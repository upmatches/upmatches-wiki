# CreateActivityRequest

The `CreateActivityRequest` class is a Java record used as a Data Transfer Object (DTO) for creating a new activity. It encapsulates the input data required when a user submits a request to create an activity, ensuring that the provided name is valid according to the defined constraints.

## Purpose

This record serves as the request payload for activity creation endpoints. By using Jakarta Bean Validation annotations, it enforces input validation at the API boundary, preventing invalid or malicious data from reaching the service layer.

## Record Definition

```java
public record CreateActivityRequest(
    @NotBlank
    @Size(max = 100)
    String name
) {}
```

## Fields

| Field | Type   | Validation Constraints | Description |
|-------|--------|------------------------|-------------|
| `name`| String | `@NotBlank`<br/>`@Size(max = 100)` | The name of the activity. Must not be blank and cannot exceed 100 characters. |

## Validation Details

- **`@NotBlank`**: Ensures the `name` field is not null and contains at least one non-whitespace character.
- **`@Size(max = 100)`**: Limits the `name` field to a maximum of 100 characters.

## Usage Example

```java
// Valid request
CreateActivityRequest validRequest = new CreateActivityRequest("Morning Yoga");

// Invalid request (blank name)
CreateActivityRequest invalidRequest = new CreateActivityRequest("   ");
```
