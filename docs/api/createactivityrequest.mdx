# CreateActivityRequest

The `CreateActivityRequest` class is a Java record used as a Data Transfer Object (DTO) for creating a new activity. It encapsulates the input data required when a user submits a request to create an activity, ensuring that the provided name meets validation constraints before being processed by the application.

## Purpose

This record serves as the request payload for activity creation endpoints. By using Jakarta Bean Validation annotations, it enforces business rules at the API boundary, preventing invalid or malformed data from reaching the service layer.

## Record Definition

```java
public record CreateActivityRequest(
    @NotBlank
    @Size(max = 100)
    String name
) {}
```

## Fields

| Field | Type   | Validation Constraints | Description |
|-------|--------|------------------------|-------------|
| `name`| String | `@NotBlank`<br/>`@Size(max = 100)` | The name of the activity. Must not be blank and cannot exceed 100 characters. |

## Validation Details

- **`@NotBlank`**: Ensures the `name` field is not `null` and contains at least one non-whitespace character.
- **`@Size(max = 100)`**: Restricts the `name` length to a maximum of 100 characters, preventing excessively long activity names.

## Usage Example

The record is typically used in a Spring Boot controller as a request body parameter:

```java
@PostMapping("/activities")
public ResponseEntity<ActivityResponse> createActivity(
    @Valid @RequestBody CreateActivityRequest request) {
    // Process the validated request
    Activity activity = activityService.create(request.name());
    return ResponseEntity.ok(new ActivityResponse(activity));
}
```

## Notes

- As a Java record, `CreateActivityRequest` automatically provides a canonical constructor, `equals()`, `hashCode()`, `toString()`, and an accessor method `name()`.
- The `@Valid` annotation on the controller parameter triggers validation of the request body against the record's constraints.
- This DTO pattern separates the API contract from the internal domain model, allowing the activity entity to evolve independently.
