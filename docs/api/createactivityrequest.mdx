## Purpose

The `CreateActivityRequest` class is a Java record used to encapsulate the data required to create a new activity within the application. It ensures that the activity name adheres to specified validation constraints, making it a crucial part of the application's request handling mechanism.

## Public Methods

The `CreateActivityRequest` class is a record, which means it automatically provides a constructor, accessors, and other utility methods. Below is a documentation of its components:

### Constructor

The constructor is implicitly provided by the record and is used to create an instance of `CreateActivityRequest`.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| name      | String | The name of the activity. Must not be blank and can have a maximum length of 100 characters. |

### Accessor Methods

Since `CreateActivityRequest` is a record, it provides an accessor method for each component.

| Method | Return Type | Description                          |
|--------|-------------|--------------------------------------|
| name() | String      | Returns the name of the activity.    |

## Validation Constraints

The `CreateActivityRequest` class uses Jakarta Bean Validation annotations to enforce constraints on its fields:

- `@NotBlank`: Ensures that the `name` field is not null or empty.
- `@Size(max = 100)`: Ensures that the `name` field does not exceed 100 characters in length.
