## Overview

The `ListMyJoinedGamesCursorService` class is a Spring service responsible for retrieving a paginated list of games that a user has joined. It utilizes cursor-based pagination to efficiently navigate through large datasets. This service interacts with repositories to fetch game data and participant counts, ensuring that only active participants are considered.

## Public Methods

### `execute`

Retrieves a paginated list of games joined by the authenticated user, starting from a specified cursor position.

| Parameter | Type   | Description                                         |
|-----------|--------|-----------------------------------------------------|
| `cursor`  | String | The cursor indicating the starting point of the page. |
| `size`    | int    | The number of games to retrieve.                    |

| Return Type                          | Description                                           |
|--------------------------------------|-------------------------------------------------------|
| `CursorPagedResponse<GameResponse>`  | A response containing the list of games and the next cursor. |

## Method Details

### `execute(String cursor, int size)`

- **Purpose**: This method retrieves a list of games that the authenticated user has joined, using cursor-based pagination. It decodes the cursor to determine the starting point and fetches the specified number of games. It also calculates the number of active participants for each game and encodes the next cursor for subsequent requests.
- **Transactional**: This method is marked as `@Transactional(readOnly = true)`, indicating that it performs read-only operations within a transaction context.

### Private Methods

#### `countParticipants(List<Game> games)`

- **Purpose**: Counts the number of active participants for each game in the provided list.
- **Return Type**: `Map<UUID, Long>` - A map where the key is the game ID and the value is the count of active participants.

This service is crucial for applications where users need to efficiently browse through their joined games, providing a seamless and performant user experience.
