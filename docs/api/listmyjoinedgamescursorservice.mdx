# ListMyJoinedGamesCursorService

## Purpose

The `ListMyJoinedGamesCursorService` is a Spring service class responsible for retrieving a paginated list of games that the currently authenticated user has joined. It implements cursor-based pagination to efficiently fetch and return game data, including participant counts, in a scalable manner.

This service is designed to handle large datasets by using a cursor (based on game start time and ID) rather than traditional offset-based pagination, ensuring consistent performance even as the dataset grows.

## Class Overview

- **Package:** `com.upmatches.app.feature.game.services`
- **Type:** `non-sealed class` implementing `IListMyJoinedGamesCursorService`
- **Annotations:** `@Service`, `@Transactional(readOnly = true)`
- **Dependencies:**
  - `GameRepository` – Data access for game entities
  - `GameParticipantRepository` – Data access for participant counts
  - `IAuthenticatedUserResolver` – Resolves the currently authenticated user
  - `GameCursor` – Encodes/decodes cursor values for pagination

## Public Method

### `execute(String cursor, int size)`

Retrieves a cursor-paginated list of games joined by the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The cursor string for pagination. Pass `null` or empty to fetch the first page. |
| `size` | `int` | The maximum number of items to return per page. |

| Returns | Type | Description |
|---------|------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing the list of games and a cursor for the next page. |

**Behavior:**
1. Resolves the authenticated user's ID via `userResolver.requireUserId()`.
2. Decodes the cursor string to extract the `startTime` and `id` of the last item from the previous page.
3. Queries the database for games joined by the user, ordered by start time and ID, limited to the specified page size.
4. For each retrieved game, counts the number of active participants.
5. Maps each game to a `GameResponse` object using `GameResponse.fromGameForViewer()`.
6. Generates a new cursor for the next page if there are more results; otherwise, sets it to `null`.
7. Returns a `CursorPagedResponse` containing the game list and the next cursor.

**Edge Cases:**
- If the cursor is `null` or cannot be decoded, the query starts from the beginning.
- If no games are found, an empty list is returned with a `null` next cursor.
- If the result set is smaller than the requested page size, the next cursor is `null`, indicating the end of the data.

## Private Method

### `countParticipants(List<Game> games)`

Counts active participants for a list of games.

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | The list of games for which to count participants. |

| Returns | Type | Description |
|---------|------|-------------|
| `Map<UUID, Long>` | A map where keys are game IDs and values are the count of active participants. |

**Behavior:**
- Extracts game IDs from the provided list.
- If the list is empty, returns an empty map.
- Queries the `participantRepository` for counts of participants with `ACTIVE` status for the given game IDs.
- Converts the result into a map keyed by game ID.

## Usage Example

```java
// Inject the service
private final ListMyJoinedGamesCursorService listMyJoinedGamesCursorService;

// Fetch the first page of joined games (10 items)
CursorPagedResponse<GameResponse> firstPage = listMyJoinedGamesCursorService.execute(null, 10);

// Fetch the next page using the cursor from the previous response
CursorPagedResponse<GameResponse> secondPage = listMyJoinedGamesCursorService.execute(firstPage.getNextCursor(), 10);
```
