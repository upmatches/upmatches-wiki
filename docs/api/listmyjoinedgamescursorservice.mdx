# ListMyJoinedGamesCursorService

## Purpose

The `ListMyJoinedGamesCursorService` is a Spring service class responsible for retrieving a paginated list of games that the currently authenticated user has joined. It implements cursor-based pagination to efficiently fetch and navigate through large result sets, returning a `CursorPagedResponse<GameResponse>` containing the game data and a cursor for the next page.

This service is part of the game features module and handles the business logic for fetching joined games with participant counts, ensuring that only the authenticated user's joined games are returned.

## Key Features

- **Cursor-based pagination**: Uses a cursor (encoded start time and game ID) for efficient pagination
- **Authentication-aware**: Resolves the authenticated user via `IAuthenticatedUserResolver`
- **Participant counting**: Includes the count of active participants for each returned game
- **Transactional read-only**: Ensures data consistency without locking
- **Error handling**: Wraps execution in `ServiceOperationExecutor` for consistent error management

## Public Methods

### `execute(String cursor, int size)`

Retrieves a paginated list of games joined by the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | Encoded cursor string for pagination. Pass `null` or empty for the first page |
| `size` | `int` | Maximum number of games to return per page |

| Returns | Type | Description |
|---------|------|-------------|
| `CursorPagedResponse<GameResponse>` | Object | Contains the list of `GameResponse` objects and an optional `nextCursor` string for the next page |

**Behavior:**
1. Resolves the authenticated user's UUID
2. Decodes the cursor to extract the `startTime` and `id` for pagination
3. Queries the database for games joined by the user after the cursor position
4. Counts active participants for each returned game
5. Maps games to `GameResponse` objects with participant counts
6. Generates the next cursor if more results exist
7. Returns the paginated response

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameRepository` | Repository | Data access for game entities |
| `GameParticipantRepository` | Repository | Data access for game participant counts |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user |
| `GameCursor` | Helper | Encodes and decodes cursor values for pagination |
| `ServiceOperationExecutor` | Utility | Executes service operations with consistent error handling |

## Usage Example

```java
// Inject the service
private final ListMyJoinedGamesCursorService listMyJoinedGamesCursorService;

// Fetch first page of joined games (10 items)
CursorPagedResponse<GameResponse> firstPage = listMyJoinedGamesCursorService.execute(null, 10);

// Fetch next page using the cursor from the previous response
CursorPagedResponse<GameResponse> secondPage = listMyJoinedGamesCursorService.execute(firstPage.getNextCursor(), 10);
```

## Notes

- The service is annotated with `@Transactional(readOnly = true)` to optimize database access for read operations
- Implements the `IListMyJoinedGamesCursorService` interface as a non-sealed class
- Uses `ResourceNotFoundException` as the error type when operations fail
- The `RETRIEVE` operation status is used for logging and monitoring purposes
