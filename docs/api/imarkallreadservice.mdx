# IMarkAllReadService Interface

The `IMarkAllReadService` interface defines a contract for marking all notifications as read within the notification system. It is a **sealed interface**, meaning that only the explicitly permitted implementation (`MarkAllReadService`) can extend or implement it. This design enforces a controlled hierarchy and ensures that the behavior for marking all notifications as read is centralized and predictable.

## Purpose

- **Sealed Contract**: Restricts implementation to a single service class, preventing unauthorized extensions.
- **Single Action**: Provides a single method to execute the "mark all read" operation.
- **Return Value**: Returns an `Integer` representing the number of notifications that were updated or affected.

## Public Method

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute()` | `Integer` | Executes the operation to mark all notifications as read. Returns the count of notifications that were updated. |

## Usage Example

```java
// Assuming an instance of MarkAllReadService is injected
IMarkAllReadService markAllReadService = new MarkAllReadService();

Integer updatedCount = markAllReadService.execute();
System.out.println("Marked " + updatedCount + " notifications as read.");
```

## Notes

- The interface is sealed to `MarkAllReadService` only. Any attempt to implement this interface with another class will result in a compilation error.
- The exact behavior of `execute()` depends on the implementation in `MarkAllReadService`, which typically interacts with a data store to update notification statuses.
