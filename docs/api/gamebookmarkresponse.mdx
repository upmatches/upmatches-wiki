## Overview

The `GameBookmarkResponse` class is a Java record that represents a response object for game bookmarks within an application. It is part of the `com.upmatches.app.features.game.responses` package. This record is used to encapsulate the details of a game bookmark, including its unique identifier, the associated game's ID and status, the timestamp when it was bookmarked, and a nested `GameResponse` object that provides additional details about the game.

## Public Methods

The `GameBookmarkResponse` record provides two static factory methods to create instances of itself from different sources. These methods are designed to facilitate the conversion of `GameBookmark` and `Game` entities into a `GameBookmarkResponse`.

### Method: `fromBookmark`

This method creates a `GameBookmarkResponse` from a `GameBookmark` entity.

| Parameter        | Type           | Description                                      |
|------------------|----------------|--------------------------------------------------|
| `bookmark`       | `GameBookmark` | The game bookmark entity to convert.             |
| `participantCount` | `long`       | The number of participants in the game.          |

**Returns:**  
`GameBookmarkResponse` - A new instance of `GameBookmarkResponse` populated with data from the provided `GameBookmark`.

### Method: `fromGame`

This method creates a `GameBookmarkResponse` from a `Game` entity.

| Parameter        | Type   | Description                                      |
|------------------|--------|--------------------------------------------------|
| `game`           | `Game` | The game entity to convert.                      |
| `participantCount` | `long` | The number of participants in the game.          |

**Returns:**  
`GameBookmarkResponse` - A new instance of `GameBookmarkResponse` populated with data from the provided `Game`.

## Fields

The `GameBookmarkResponse` record consists of the following fields:

- `UUID id`: The unique identifier of the game bookmark.
- `UUID gameId`: The unique identifier of the associated game.
- `GameStatus gameStatus`: The status of the game.
- `Instant bookmarkedAt`: The timestamp when the game was bookmarked.
- `GameResponse game`: A nested response object containing additional game details.
