# GameBookmarkResponse

The `GameBookmarkResponse` record is a Data Transfer Object (DTO) used to represent a bookmarked game in API responses. It encapsulates both the bookmark metadata (such as when the game was bookmarked) and the full game details, providing a unified view for clients.

This record is particularly useful when returning bookmark lists to users, as it combines the bookmark identifier and timestamp with the underlying game information.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the bookmark entry. `null` when the response is created directly from a game without an existing bookmark. |
| `gameId` | `UUID` | The unique identifier of the associated game. |
| `gameStatus` | `GameStatus` | The current status of the game (e.g., active, completed, cancelled). |
| `bookmarkedAt` | `Instant` | The timestamp when the game was bookmarked. `null` when the response is created from a game without a bookmark. |
| `game` | `GameResponse` | The full game details, including participant count and other game-specific information. |

## Factory Methods

### `fromBookmark`

Creates a `GameBookmarkResponse` from an existing `GameBookmark` entity and a participant count.

```java
public static GameBookmarkResponse fromBookmark(GameBookmark bookmark, long participantCount)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `bookmark` | `GameBookmark` | The bookmark entity containing the bookmark metadata and associated game. |
| `participantCount` | `long` | The number of participants in the game. |

**Returns:** A fully populated `GameBookmarkResponse` with the bookmark ID, game ID, game status, bookmark timestamp, and game details.

### `fromGame`

Creates a `GameBookmarkResponse` directly from a `Game` entity without an existing bookmark. This is useful when you want to represent a game in a bookmark-like format even though the user hasn't explicitly bookmarked it.

```java
public static GameBookmarkResponse fromGame(Game game, long participantCount)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to convert. |
| `participantCount` | `long` | The number of participants in the game. |

**Returns:** A `GameBookmarkResponse` with `id` set to `null` and `bookmarkedAt` set to `null`, indicating that no bookmark exists for this game.

## Usage Example

```java
// Creating from an existing bookmark
GameBookmark bookmark = bookmarkRepository.findById(bookmarkId);
GameBookmarkResponse response = GameBookmarkResponse.fromBookmark(bookmark, 42);

// Creating from a game (no bookmark)
Game game = gameRepository.findById(gameId);
GameBookmarkResponse responseWithoutBookmark = GameBookmarkResponse.fromGame(game, 15);
```

## Notes

- The `id` field is `null` when using `fromGame()` because there is no actual bookmark record.
- The `bookmarkedAt` field is `null` when using `fromGame()` since no bookmark timestamp exists.
- The `GameResponse` object is constructed using its own `fromGame()` factory method, ensuring consistent game detail representation across the API.
