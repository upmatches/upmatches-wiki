# TransitLineRepository

The `TransitLineRepository` interface provides database access operations for `TransitLine` entities within the venue feature of the UpMatches application. It extends Spring Data JPA's `JpaRepository`, inheriting a comprehensive set of CRUD (Create, Read, Update, Delete) and query methods without requiring any custom implementation.

## Purpose

This repository serves as the data access layer for managing transit line records. By extending `JpaRepository<TransitLine, String>`, it automatically provides:
- Standard CRUD operations (save, findById, findAll, delete, etc.)
- Pagination and sorting support
- Batch operations
- Flush and clear capabilities for entity management

The primary key type is `String`, indicating that transit lines are identified by a string-based identifier (e.g., a route code or name).

## Inherited Public Methods

Since `TransitLineRepository` extends `JpaRepository` without adding custom methods, all public methods are inherited from the Spring Data JPA interfaces. Below are the key methods available:

### CRUD Operations

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `save(S entity)` | `S` | `S entity` - The entity to save | Persists a new entity or updates an existing one |
| `saveAll(Iterable<S> entities)` | `List<S>` | `Iterable<S> entities` - Collection of entities | Saves all given entities in batch |
| `findById(ID id)` | `Optional<S>` | `ID id` - The entity identifier | Retrieves an entity by its primary key |
| `existsById(ID id)` | `boolean` | `ID id` - The entity identifier | Checks if an entity exists with the given ID |
| `findAll()` | `List<S>` | None | Returns all entities |
| `findAllById(Iterable<ID> ids)` | `List<S>` | `Iterable<ID> ids` - Collection of IDs | Returns all entities with the given IDs |
| `count()` | `long` | None | Returns the total number of entities |
| `deleteById(ID id)` | `void` | `ID id` - The entity identifier | Deletes the entity with the given ID |
| `delete(S entity)` | `void` | `S entity` - The entity to delete | Deletes a given entity |
| `deleteAll(Iterable<? extends S> entities)` | `void` | `Iterable<? extends S> entities` - Entities to delete | Deletes all given entities |
| `deleteAll()` | `void` | None | Deletes all entities managed by the repository |

### Query Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findAll(Sort sort)` | `List<S>` | `Sort sort` - Sort specification | Returns all entities sorted by the given options |
| `findAll(Pageable pageable)` | `Page<S>` | `Pageable pageable` - Pagination information | Returns a `Page` of entities meeting the pagination constraints |

### Entity Management

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `flush()` | `void` | None | Flushes all pending changes to the database |
| `saveAndFlush(S entity)` | `S` | `S entity` - The entity to save | Saves an entity and immediately flushes changes |
| `deleteInBatch(Iterable<S> entities)` | `void` | `Iterable<S> entities` - Entities to delete | Deletes the given entities in a single JPQL query |

## Usage Example

```java
@Service
public class TransitLineService {
    
    private final TransitLineRepository transitLineRepository;
    
    public TransitLineService(TransitLineRepository transitLineRepository) {
        this.transitLineRepository = transitLineRepository;
    }
    
    public TransitLine findTransitLineById(String id) {
        return transitLineRepository.findById(id)
            .orElseThrow(() -> new EntityNotFoundException("Transit line not found: " + id));
    }
    
    public List<TransitLine> getAllTransitLines() {
        return transitLineRepository.findAll();
    }
    
    public TransitLine saveTransitLine(TransitLine transitLine) {
        return transitLineRepository.save(transitLine);
    }
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` interface and all inherited functionality
- **TransitLine entity**: The domain object this repository manages, located in `com.upmatches.app.features.venue.entities`

## Notes

- The repository is intentionally minimal, relying entirely on Spring Data JPA's auto-implementation
- For custom query methods, developers can add method signatures following Spring Data JPA's query derivation conventions (e.g., `findByName(String name)`)
- The `String` primary key type suggests transit lines use natural keys (like route identifiers) rather than auto-generated numeric IDs
