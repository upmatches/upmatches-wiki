# TransitLineRepository

The `TransitLineRepository` interface provides database access operations for `TransitLine` entities. It extends Spring Data JPA's `JpaRepository`, which automatically provides standard CRUD (Create, Read, Update, Delete) functionality without requiring any implementation code.

## Purpose

This repository serves as the data access layer for transit line information within the venue management feature of the application. By extending `JpaRepository<TransitLine, String>`, it inherits a comprehensive set of methods for interacting with the `TransitLine` entity in the database, where the primary key is of type `String`.

## Inheritance

The interface extends `org.springframework.data.jpa.repository.JpaRepository` with the following generic parameters:

| Parameter | Type | Description |
|-----------|------|-------------|
| Entity | `TransitLine` | The entity class this repository manages |
| ID | `String` | The type of the entity's primary key |

## Inherited Methods

Since `TransitLineRepository` extends `JpaRepository`, it automatically inherits the following commonly used methods:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `findAll()` | `List<TransitLine>` | Retrieves all transit line entities |
| `findById(String id)` | `Optional<TransitLine>` | Finds a transit line by its unique identifier |
| `save(TransitLine entity)` | `TransitLine` | Saves (inserts or updates) a transit line entity |
| `saveAll(Iterable<TransitLine> entities)` | `List<TransitLine>` | Saves multiple transit line entities |
| `deleteById(String id)` | `void` | Deletes a transit line by its identifier |
| `delete(TransitLine entity)` | `void` | Deletes a specific transit line entity |
| `deleteAll()` | `void` | Deletes all transit line entities |
| `count()` | `long` | Returns the total number of transit line entities |
| `existsById(String id)` | `boolean` | Checks if a transit line exists with the given identifier |

## Usage Example

```java
@Service
public class TransitLineService {
    
    private final TransitLineRepository transitLineRepository;
    
    public TransitLineService(TransitLineRepository transitLineRepository) {
        this.transitLineRepository = transitLineRepository;
    }
    
    public TransitLine findTransitLine(String id) {
        return transitLineRepository.findById(id)
            .orElseThrow(() -> new EntityNotFoundException("Transit line not found: " + id));
    }
    
    public TransitLine saveTransitLine(TransitLine transitLine) {
        return transitLineRepository.save(transitLine);
    }
}
```
