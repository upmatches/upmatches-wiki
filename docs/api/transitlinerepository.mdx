# TransitLineRepository

The `TransitLineRepository` interface provides database access operations for `TransitLine` entities within the venue feature of the UpMatches application. It extends Spring Data JPA's `JpaRepository`, inheriting a comprehensive set of CRUD (Create, Read, Update, Delete) and query methods without requiring any custom implementation.

## Purpose

This repository serves as the data access layer for transit line information associated with venues. By extending `JpaRepository<TransitLine, String>`, it automatically provides:

- Standard CRUD operations (save, findById, findAll, delete, etc.)
- Pagination and sorting support
- Batch operations
- Flush and clear capabilities for transaction management

The primary key type is `String`, indicating that transit lines are identified by a string-based identifier (such as a route code or name).

| `findById` | `String id` | `Optional<TransitLine>` | Retrieves a transit line by its string identifier |
| `existsById` | `String id` | `boolean` | Checks if a transit line exists with the given identifier |
| `findAll` | (none) | `List<TransitLine>` | Returns all transit line entities |

| `delete` | `TransitLine entity` | `void` | Deletes a given transit line entity |

## Usage Example

```java
@Service
public class TransitLineService {
    
    private final TransitLineRepository transitLineRepository;
    
    public TransitLineService(TransitLineRepository transitLineRepository) {
        this.transitLineRepository = transitLineRepository;
    }
    
    public TransitLine findTransitLine(String routeCode) {
        return transitLineRepository.findById(routeCode)
            .orElseThrow(() -> new EntityNotFoundException("Transit line not found: " + routeCode));
    }
    
    public List<TransitLine> getAllTransitLines() {
        return transitLineRepository.findAll(Sort.by("name").ascending());
    }
}
```

## Notes

- The repository uses `String` as the entity identifier type, which is suitable for transit route codes or similar alphanumeric identifiers.
- No custom query methods are defined in this interface. If additional query functionality is needed, developers can add method declarations following Spring Data JPA's query derivation conventions.
- This repository is part of the `com.upmatches.app.features.venue.repositories` package and works with the `TransitLine` entity located in `com.upmatches.app.features.venue.entities`.
