## Overview

The `AuthProvider` enum is part of the `com.upmatches.app.features.auth.enums` package. It defines a set of constants representing different authentication providers that can be used within the application. Enums in Java are a special type of class that represents a group of constants (unchangeable variables, like final variables).

## Enum Constants

The `AuthProvider` enum includes the following constants:

| Constant | Description                                      |
|----------|--------------------------------------------------|
| SINGPASS | Represents the SingPass authentication provider. |
| AUTH0    | Represents the Auth0 authentication provider.    |
| APPLE    | Represents the Apple authentication provider.    |

## Purpose

The purpose of the `AuthProvider` enum is to provide a type-safe way to specify which authentication provider is being used in different parts of the application. By using an enum, the code becomes more readable and less error-prone, as it restricts the possible values to the defined constants.

## Usage

Enums are typically used in switch statements or as a method parameter to ensure that only valid constants are passed. This enum can be used to handle authentication logic based on the provider selected.
