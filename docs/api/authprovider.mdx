# AuthProvider Enum

The `AuthProvider` enum defines the supported authentication providers for the UpMatches application. It is used to specify which third-party identity provider a user can authenticate with when logging into the app.

## Purpose

This enum centralizes the list of authentication providers, ensuring type safety and consistency across the codebase when handling user login flows. It prevents the use of arbitrary strings and makes the authentication logic more maintainable.

## Enum Values

| Value      | Description                                                                 |
|------------|-----------------------------------------------------------------------------|
| `SINGPASS` | Singapore's national digital identity platform for secure government and business transactions. |
| `AUTH0`    | A flexible, drop-in authentication and authorization service by Okta.       |
| `APPLE`    | Apple's Sign in with Apple, providing privacy-focused authentication for iOS users. |

## Usage

The `AuthProvider` enum is typically used in conjunction with authentication services, user profile models, or login screens to determine which provider was used for authentication. For example:

```java
// Example usage in a user profile class
public class UserProfile {
    private AuthProvider provider;
    
    public AuthProvider getProvider() {
        return provider;
    }
    
    public void setProvider(AuthProvider provider) {
        this.provider = provider;
    }
}
```
