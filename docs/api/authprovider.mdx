# AuthProvider Enum

The `AuthProvider` enum defines the supported authentication providers for the application. It is used to specify which third-party service or system is responsible for authenticating a user during the login or registration process.

## Purpose

This enum centralizes the list of authentication providers, ensuring type safety and consistency when handling authentication flows. By using an enum instead of raw strings, the code avoids typos and makes it easier to extend or modify supported providers in the future.

## Enum Values

| Value      | Description                                                                 |
|------------|-----------------------------------------------------------------------------|
| `SINGPASS` | Represents Singapore's national digital identity authentication system.     |
| `AUTH0`    | Represents Auth0, a popular identity management and authentication platform.|
| `APPLE`    | Represents Apple's Sign in with Apple authentication service.               |

## Usage

The `AuthProvider` enum is typically used in authentication-related classes to indicate which provider was used to authenticate a user. For example, it may be stored as a field in a user entity or passed as a parameter to authentication service methods.

### Example

```java
// Storing the authentication provider for a user
AuthProvider provider = AuthProvider.SINGPASS;
user.setAuthProvider(provider);

// Checking the provider in a conditional
if (user.getAuthProvider() == AuthProvider.APPLE) {
    // Handle Apple-specific logic
}
```
