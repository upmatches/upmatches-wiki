# AuthProvider

The `AuthProvider` enum defines the supported authentication providers for the UpMatches application. It is used to specify which third-party identity provider a user chooses to authenticate with during the login or registration process.

## Purpose

This enum centralizes the list of authentication providers, ensuring type safety and consistency across the application when handling user authentication flows. By using an enum rather than raw strings, the code avoids typos and makes it easy to extend with new providers in the future.

## Enum Values

| Value      | Description                                                                 |
|------------|-----------------------------------------------------------------------------|
| `SINGPASS` | Represents Singapore's national digital identity platform for authentication. |
| `AUTH0`    | Represents Auth0, a universal identity platform for web and mobile apps.      |
| `APPLE`    | Represents Apple's Sign in with Apple service for iOS and web applications.   |

## Usage

The `AuthProvider` enum is typically used in user profile models, authentication service classes, or as a parameter in login methods to indicate which provider was used for authentication.

### Example

```java
// Storing the provider in a user object
User user = new User();
user.setAuthProvider(AuthProvider.SINGPASS);

// Checking the provider in a conditional
if (user.getAuthProvider() == AuthProvider.APPLE) {
    // Handle Apple-specific logic
}
```
