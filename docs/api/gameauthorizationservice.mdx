# GameAuthorizationService

The `GameAuthorizationService` class is a Spring service component that provides authorization and validation logic for game-related operations in the UpMatches application. It implements the `IGameAuthorizationService` interface and serves as a security layer to ensure that users have the appropriate permissions to view, join, or modify games.

## Purpose

This service centralizes all authorization checks and business rule validations for game operations, including:
- Verifying user permissions to view public and private games
- Ensuring only game organizers can modify game properties
- Validating game joinability based on status and time constraints
- Enforcing immutability rules for certain game fields when participants are active
- Preventing duplicate joins and ensuring slot availability

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameParticipantRepository` | Repository | Provides access to participant data for authorization checks |
| `GameShareAccessRepository` | Repository | Manages share-link access for private games |

## Public Methods

### `assertCanViewGame(Game game, UUID userId)`

Validates whether a user has permission to view a specific game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to check access for |
| `userId` | `UUID` | The ID of the user requesting access |

**Throws:**
- `GameNotFoundException` if the game is private and the user has no access rights

**Logic:**
- Public games are accessible to all users
- The organizer always has access
- Active participants have access
- Users with share-link access have access
- All other users receive a `GameNotFoundException`

### `assertIsOrganizer(Game game, UUID userId)`

Verifies that the specified user is the organizer of the given game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to check |
| `userId` | `UUID` | The ID of the user to verify |

**Throws:**
- `NotGameOrganizerException` if the user is not the organizer

### `assertGameJoinable(UUID id, Game game)`

Checks whether a game is currently joinable based on its status and end time.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game ID (used for error messages) |
| `game` | `Game` | The game entity to check |

**Throws:**
- `GameNotJoinableException` if the game is past or inactive

### `assertPrivateAccess(UUID id, UUID userId, Game game)`

Validates that a user has access to a private game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game ID |
| `userId` | `UUID` | The user ID requesting access |
| `game` | `Game` | The game entity |

**Throws:**
- `PrivateGameAccessDeniedException` if the game is private and the user lacks access

### `assertNotAlreadyJoined(UUID id, UUID userId)`

Ensures that a user has not already joined a game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game ID |
| `userId` | `UUID` | The user ID to check |

**Throws:**
- `AlreadyJoinedException` if the user is already an active participant

### `assertVisibilityUnchanged(UUID id, Game game, UpdateGameRequest request)`

Validates that the game visibility is not being changed after creation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game ID |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request containing potential visibility changes |

**Throws:**
- `GameVisibilityImmutableException` if visibility is being changed

### `assertSlotsAboveActive(UUID id, Integer newSlots, long activeCount)`

Ensures that the new slot count is not below the current number of active participants.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game ID |
| `newSlots` | `Integer` | The proposed new slot count |
| `activeCount` | `long` | The current number of active participants |

**Throws:**
- `GameSlotsBelowParticipantsException` if new slots are less than active participants

### `assertImmutableFields(UUID id, Game game, UpdateGameRequest request, long activeCount)**

Validates that certain game fields cannot be modified when there are active participants.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game ID |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request |
| `activeCount` | `long` | The current number of active participants |

**Throws:**
- `GameImmutableFieldException` if any immutable field is being modified

**Immutable fields when participants exist:**
- `startTime`
- `endTime`
- `price`
- `currency`
- `pricing` (checked via `assertPricingUnchanged`)

## Private Methods

### `assertPricingUnchanged(UUID id, Game game, UpdateGameRequest request)`

Internal helper method that validates the pricing field has not changed using semantic equality comparison.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game ID |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request |

**Throws:**
- `GameImmutableFieldException` if pricing has changed

## Usage Example

```java
@Service
public class GameService {
    private final GameAuthorizationService authService;
    
    public void joinGame(UUID gameId, UUID userId) {
        Game game = gameRepository.findById(gameId)
            .orElseThrow(() -> new GameNotFoundException("Game not found"));
        
        authService.assertCanViewGame(game, userId);
        authService.assertGameJoinable(gameId, game);
        authService.assertNotAlreadyJoined(gameId, userId);
        authService.assertPrivateAccess(gameId, userId, game);
        
        // Proceed with joining logic
    }
}
```
