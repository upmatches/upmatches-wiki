## Overview

The `GameAuthorizationService` class is part of the `com.upmatches.app.features.game.services` package and provides various authorization checks for game-related operations. It ensures that users have the necessary permissions to view, join, or modify games, and enforces rules regarding game visibility and participant status.

## Public Methods

The following table documents the public methods available in the `GameAuthorizationService` class:

| Method Name                | Parameters                                                                                                                                      | Return Type | Description                                                                                                               |
|----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------|-------------|---------------------------------------------------------------------------------------------------------------------------|
| `assertCanViewGame`        | `Game game`, `UUID userId`                                                                                                                      | `void`      | Checks if a user can view a game based on its visibility and the user's relationship to the game.                         |
| `assertIsOrganizer`        | `Game game`, `UUID userId`                                                                                                                      | `void`      | Ensures that the specified user is the organizer of the game.                                                             |
| `assertGameJoinable`       | `UUID id`, `Game game`                                                                                                                          | `void`      | Verifies that a game is joinable, i.e., it is not past or inactive.                                                       |
| `assertPrivateAccess`      | `UUID id`, `UUID userId`, `Game game`                                                                                                           | `void`      | Checks if a user has access to a private game, either as the organizer or through a share link.                           |
| `assertNotAlreadyJoined`   | `UUID id`, `UUID userId`                                                                                                                        | `void`      | Ensures that a user has not already joined the game.                                                                      |
| `assertVisibilityUnchanged`| `UUID id`, `Game game`, `UpdateGameRequest request`                                                                                             | `void`      | Validates that the game's visibility has not been changed in an update request.                                           |
| `assertSlotsAboveActive`   | `UUID id`, `Integer newSlots`, `long activeCount`                                                                                               | `void`      | Ensures that the number of slots in a game is not reduced below the current number of active participants.                |
| `assertImmutableFields`    | `UUID id`, `Game game`, `UpdateGameRequest request`, `long activeCount`                                                                         | `void`      | Checks that certain fields (start time, end time, price, currency) are not changed if there are active participants.      |

## Usage

The `GameAuthorizationService` is typically used within the context of a game management system to enforce business rules and ensure that users interact with games in a manner consistent with their permissions and the game's current state. It relies on repositories to check participant status and access rights, and throws exceptions when authorization checks fail.
