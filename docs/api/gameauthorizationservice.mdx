# GameAuthorizationService

The `GameAuthorizationService` class is a Spring service component that provides authorization and validation logic for game-related operations in the UpMatches application. It implements the `IGameAuthorizationService` interface and serves as a security layer to ensure that users have the appropriate permissions to view, join, or modify games.

This service handles various authorization checks including:
- Game visibility (public vs. private)
- Organizer permissions
- Joinability status
- Field immutability when participants are active
- Slot capacity validation

## Constructor

| Constructor | Description |
|-------------|-------------|
| `GameAuthorizationService(GameParticipantRepository participantRepository, GameShareAccessRepository shareAccessRepository)` | Creates a new instance with the required repository dependencies |

## Public Methods

### `assertCanViewGame(Game game, UUID userId)`

Validates whether a user can view a specific game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to check access for |
| `userId` | `UUID` | The user's unique identifier |

**Throws:**
- `GameNotFoundException` - If the game is private and the user doesn't have access

**Logic:**
- Public games are always viewable
- The organizer can always view their own game
- Active participants can view the game
- Users with share-link access can view private games

### `assertIsOrganizer(Game game, UUID userId)`

Verifies that the specified user is the organizer of the game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity |
| `userId` | `UUID` | The user's unique identifier |

**Throws:**
- `NotGameOrganizerException` - If the user is not the game organizer

### `assertGameJoinable(UUID id, Game game)`

Checks whether a game is currently joinable.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `game` | `Game` | The game entity |

**Throws:**
- `GameNotJoinableException` - If the game is past or inactive

### `assertPrivateAccess(UUID id, UUID userId, Game game)`

Validates access to a private game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `userId` | `UUID` | The user's unique identifier |
| `game` | `Game` | The game entity |

**Throws:**
- `PrivateGameAccessDeniedException` - If the user doesn't have access to a private game

### `assertNotAlreadyJoined(UUID id, UUID userId)`

Ensures a user hasn't already joined a game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `userId` | `UUID` | The user's unique identifier |

**Throws:**
- `AlreadyJoinedException` - If the user is already an active participant

### `assertVisibilityUnchanged(UUID id, Game game, UpdateGameRequest request)`

Validates that the game visibility cannot be changed after creation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request containing potential visibility changes |

**Throws:**
- `GameVisibilityImmutableException` - If an attempt is made to change visibility

### `assertSlotsAboveActive(UUID id, Integer newSlots, long activeCount)`

Validates that the new slot count is not below the current number of active participants.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `newSlots` | `Integer` | The proposed new slot count |
| `activeCount` | `long` | The current number of active participants |

**Throws:**
- `GameSlotsBelowParticipantsException` - If new slots are less than active participants

### `assertImmutableFields(UUID id, Game game, UpdateGameRequest request, long activeCount)**

Validates that certain game fields cannot be changed when there are active participants.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request |
| `activeCount` | `long` | The current number of active participants |

**Throws:**
- `GameImmutableFieldException` - If an immutable field is being modified while participants exist

**Immutable fields when participants are active:**
- `startTime`
- `endTime`
- `price`
- `currency`
- `pricing`
