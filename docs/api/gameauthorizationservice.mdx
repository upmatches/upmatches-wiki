## Overview

The `GameAuthorizationService` class is part of the `com.upmatches.app.features.game.services` package and provides various authorization checks related to game management. It ensures that users have the appropriate permissions to view, join, or modify games. This service is crucial for maintaining the integrity and security of game-related operations by enforcing rules and restrictions based on game visibility, user roles, and game status.

## Detailed Method Descriptions

### `assertCanViewGame`

This method checks whether a user can view a game based on its visibility and the user's relationship to the game. It throws a `GameNotFoundException` if the user does not have the necessary permissions.

### `assertIsOrganizer`

This method verifies that the specified user is the organizer of the game. If not, it throws a `NotGameOrganizerException`.

### `assertGameJoinable`

This method determines if a game is joinable by checking its status and whether it has ended. It throws a `GameNotJoinableException` if the game cannot be joined.

### `assertPrivateAccess`

This method ensures that a user has access to a private game. It throws a `PrivateGameAccessDeniedException` if the user is neither the organizer nor has a share link.

### `assertNotAlreadyJoined`

This method checks if a user has already joined a game. If the user is already a participant, it throws an `AlreadyJoinedException`.

### `assertVisibilityUnchanged`

This method ensures that the visibility of a game has not been changed in an update request. If the visibility is altered, it throws a `GameVisibilityImmutableException`.

### `assertSlotsAboveActive`

This method checks that the new slot count for a game is not less than the current number of active participants. It throws a `GameSlotsBelowParticipantsException` if the condition is violated.

### `assertImmutableFields`

This method ensures that certain fields (start time, end time, price, currency) remain unchanged if there are active participants in the game. It throws a `GameImmutableFieldException` if any of these fields are modified.
