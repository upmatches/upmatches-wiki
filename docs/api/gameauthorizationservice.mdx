# GameAuthorizationService

The `GameAuthorizationService` class is a Spring service component that provides authorization and validation logic for game-related operations in the UpMatches application. It implements the `IGameAuthorizationService` interface and handles access control, joinability checks, and field immutability validation for game entities.

## Purpose

This service ensures that:
- Users have appropriate permissions to view, join, or modify games
- Games are in a joinable state before allowing participants to join
- Private games are only accessible to authorized users
- Certain game fields remain immutable when the game has active participants
- Visibility changes are prevented after game creation

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameParticipantRepository` | Repository | Manages game participant data |
| `GameShareAccessRepository` | Repository | Manages share access for private games |

## Public Methods

### `assertCanViewGame(Game game, UUID userId)`

Validates whether a user can view a specific game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to check access for |
| `userId` | `UUID` | The user's unique identifier |

**Throws:**
- `GameNotFoundException` if the game is private and the user doesn't have access

**Logic:**
- Public games are always viewable
- Null userId for private games throws exception
- Organizers can always view their games
- Active participants can view the game
- Users with share access can view the game

### `assertIsOrganizer(Game game, UUID userId)`

Verifies that the user is the organizer of the game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity |
| `userId` | `UUID` | The user's unique identifier |

**Throws:**
- `NotGameOrganizerException` if the user is not the organizer

### `assertGameJoinable(UUID id, Game game)`

Checks if a game is in a joinable state.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `game` | `Game` | The game entity |

**Throws:**
- `GameNotJoinableException` if the game is past or inactive

### `assertPrivateAccess(UUID id, UUID userId, Game game)`

Validates access to private games.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `userId` | `UUID` | The user's unique identifier |
| `game` | `Game` | The game entity |

**Throws:**
- `PrivateGameAccessDeniedException` if the user doesn't have access to a private game

### `assertNotAlreadyJoined(UUID id, UUID userId)`

Ensures a user hasn't already joined a game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `userId` | `UUID` | The user's unique identifier |

**Throws:**
- `AlreadyJoinedException` if the user is already an active participant

### `assertVisibilityUnchanged(UUID id, Game game, UpdateGameRequest request)`

Prevents changes to game visibility after creation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request containing new visibility |

**Throws:**
- `GameVisibilityImmutableException` if visibility is being changed

### `assertSlotsAboveActive(UUID id, Integer newSlots, long activeCount)`

Validates that new slot count is not below the current active participant count.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `newSlots` | `Integer` | The proposed new slot count |
| `activeCount` | `long` | Current number of active participants |

**Throws:**
- `GameSlotsBelowParticipantsException` if new slots are less than active participants

### `assertImmutableFields(UUID id, Game game, UpdateGameRequest request, long activeCount)**

Validates that certain fields cannot be changed when the game has active participants.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request |
| `activeCount` | `long` | Current number of active participants |

**Throws:**
- `GameImmutableFieldException` if any immutable field is being changed

**Immutable fields when active participants exist:**
- `startTime`
- `endTime`
- `price`
- `currency`
- `pricing` (validated via `assertPricingUnchanged`)

## Private Methods

### `assertPricingUnchanged(UUID id, Game game, UpdateGameRequest request)`

Internal validation method that checks if pricing has changed using semantic equality.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The game's unique identifier |
| `game` | `Game` | The current game entity |
| `request` | `UpdateGameRequest` | The update request |

**Throws:**
- `GameImmutableFieldException` if pricing has changed

## Usage Example

```java
@Service
public class GameService {
    private final GameAuthorizationService authService;
    
    public void joinGame(UUID gameId, UUID userId) {
        Game game = gameRepository.findById(gameId)
            .orElseThrow(() -> new GameNotFoundException("Game not found"));
        
        authService.assertGameJoinable(gameId, game);
        authService.assertPrivateAccess(gameId, userId, game);
        authService.assertNotAlreadyJoined(gameId, userId);
        
        // Proceed with joining logic
    }
}
```
