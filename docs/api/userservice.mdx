# UserService

The `UserService` class is a Spring service that manages user profile operations within the UpMatches application. It handles user authentication, profile completion, updates, and deletion, while ensuring data integrity through validation and audit logging.

## Purpose

This service provides the core business logic for user profile management, including:
- Retrieving authenticated user profiles
- Completing initial user onboarding profiles
- Updating existing user profiles
- Deleting user accounts
- Validating skill level selections and ensuring one skill level per activity

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `UserRepository` | Repository | Data access for user entities |
| `SkillLevelRepository` | Repository | Data access for skill level entities |
| `GameRepository` | Repository | Data access for game entities |

## Public Methods

### `getProfile()`

Retrieves the profile of the currently authenticated user.

**Returns:** `UserProfileResponse` - The user's profile data including games joined and hosted.

**Exceptions:**
- `UnauthorizedException` - If no valid authentication is found
- `ResourceNotFoundException` - If the authenticated user is not found

**Example:**
```java
UserProfileResponse profile = userService.getProfile();
```

### `completeProfile(CompleteProfileRequest request)`

Completes the initial onboarding profile for the authenticated user. This method is auditable with action `PROFILE_COMPLETED`.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CompleteProfileRequest` | Contains name, contact methods, and skill level selections |

**Returns:** `UserProfileResponse` - The completed user profile.

**Exceptions:**
- `UnauthorizedException` - If no valid authentication is found
- `ResourceNotFoundException` - If the authenticated user or skill levels are not found
- `ProfileAlreadyCompletedException` - If the user has already completed onboarding
- `IllegalArgumentException` - If a skill level does not belong to the specified activity
- `DuplicateSkillLevelActivityException` - If multiple skill levels are selected for the same activity

**Example:**
```java
CompleteProfileRequest request = new CompleteProfileRequest(
    "John Doe",
    List.of(new ContactMethod("whatsapp", "+1234567890")),
    List.of(new SkillLevelSelection(1L, UUID.fromString("..."), 1L))
);
UserProfileResponse profile = userService.completeProfile(request);
```

### `updateProfile(UpdateProfileRequest request)`

Updates the profile of the authenticated user. This method is auditable with action `PROFILE_UPDATED`.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `UpdateProfileRequest` | Contains optional name, contact methods, and skill level selections |

**Returns:** `UserProfileResponse` - The updated user profile.

**Exceptions:**
- `UnauthorizedException` - If no valid authentication is found
- `ResourceNotFoundException` - If the authenticated user or skill levels are not found
- `IllegalArgumentException` - If a skill level does not belong to the specified activity
- `DuplicateSkillLevelActivityException` - If multiple skill levels are selected for the same activity

**Example:**
```java
UpdateProfileRequest request = new UpdateProfileRequest(
    "Jane Doe",
    List.of(new ContactMethod("telegram", "@janedoe")),
    List.of(new SkillLevelSelection(2L, UUID.fromString("..."), 2L))
);
UserProfileResponse profile = userService.updateProfile(request);
```

### `deleteUser()`

Deletes the currently authenticated user's account. This method is auditable with action `PROFILE_DELETED`.

**Exceptions:**
- `UnauthorizedException` - If no valid authentication is found
- `ResourceNotFoundException` - If the authenticated user is not found

**Example:**
```java
userService.deleteUser();
```

## Private Methods

### `getAuthenticatedUserId()`

Extracts the user ID from the JWT token in the security context.

**Returns:** `UUID` - The authenticated user's ID.

**Exceptions:**
- `UnauthorizedException` - If no valid authentication or invalid user ID in token

### `buildProfileResponse(User user)`

Constructs a `UserProfileResponse` from a `User` entity, including game statistics.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user entity |

**Returns:** `UserProfileResponse` - The formatted profile response.

### `findUserOrThrow(UUID userId)`

Retrieves a user by ID or throws an exception.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The user ID to find |

**Returns:** `User` - The found user entity.

**Exceptions:**
- `ResourceNotFoundException` - If user is not found

### `findSkillLevelsOrThrow(List<SkillLevelSelection> selections)`

Validates and retrieves skill levels from selections, ensuring:
- All skill level IDs exist
- Each skill level belongs to the specified activity
- No duplicate activities are selected

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `selections` | `List<SkillLevelSelection>` | The skill level selections to validate |

**Returns:** `List<SkillLevel>` - The validated skill level entities.

**Exceptions:**
- `ResourceNotFoundException` - If one or more skill levels are not found
- `IllegalArgumentException` - If a skill level does not belong to the specified activity
- `DuplicateSkillLevelActivityException` - If multiple skill levels are selected for the same activity

### `validateOneSkillLevelPerActivity(List<SkillLevel> skillLevels)`

Ensures no duplicate activities exist in the skill level list.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `skillLevels` | `List<SkillLevel>` | The skill levels to validate |

**Exceptions:**
- `DuplicateSkillLevelActivityException` - If duplicate activities are found

### `extractContact(List<ContactMethod> contacts, String name)`

Extracts a specific contact method value by name from a list of contacts.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `contacts` | `List<ContactMethod>` | The list of contact methods |
| `name` | `String` | The name of the contact method to extract |

**Returns:** `String` - The contact value, or `null` if not found.

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `WHATSAPP` | `"whatsapp"` | WhatsApp contact method identifier |
| `TELEGRAM` | `"telegram"` | Telegram contact method identifier |
| `MESSENGER` | `"messenger"` | Messenger contact method identifier |
| `MSG_USER_NOT_FOUND` | `"The authenticated user was not found."` | Error message for missing user |
| `MSG_NO_VALID_AUTH` | `"No valid authentication found."` | Error message for missing authentication |
| `MSG_INVALID_USER_ID` | `"Invalid user ID in token subject: "` | Error message for invalid token |
| `MSG_SKILL_LEVELS_NOT_FOUND` | `"One or more skill levels not found."` | Error message for missing skill levels |
| `MSG_ACTIVITY_MISMATCH` | `"Skill level ID '%d' does not belong to activity ID '%s'."` | Error message for activity mismatch |

## Annotations

- `@Service` - Marks this class as a Spring service component
- `@Transactional` - Ensures database operations are transactional
- `@Auditable` - Enables audit logging for profile completion, updates, and deletion
