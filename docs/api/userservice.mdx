## Overview

The `UserService` class is a part of the `com.upmatches.app.features.user.services` package and implements the `IUserService` interface. It is a Spring `@Service` component designed to manage user profiles, including retrieving, completing, updating, and deleting user profiles. The class leverages repositories for user, skill level, and game data management, and it includes transactional operations and auditing capabilities.

## Public Methods

### `getProfile`

Retrieves the profile of the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type          | Description                        |
|----------------------|------------------------------------|
| `UserProfileResponse`| The profile of the authenticated user.|

### `completeProfile`

Completes the profile of the authenticated user based on the provided request.

| Parameter | Type                     | Description                      |
|-----------|--------------------------|----------------------------------|
| `request` | `CompleteProfileRequest` | The request containing profile completion data.|

| Return Type          | Description                        |
|----------------------|------------------------------------|
| `UserProfileResponse`| The updated profile of the user.   |

### `updateProfile`

Updates the profile of the authenticated user based on the provided request.

| Parameter | Type                   | Description                      |
|-----------|------------------------|----------------------------------|
| `request` | `UpdateProfileRequest` | The request containing profile update data.|

| Return Type          | Description                        |
|----------------------|------------------------------------|
| `UserProfileResponse`| The updated profile of the user.   |

### `deleteUser`

Deletes the profile of the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type | Description |
|-------------|-------------|
| `void`      |             |

## Key Concepts

- **Transactional Operations**: The class uses Spring's `@Transactional` annotation to manage transactions, ensuring data consistency during profile operations.
- **Auditing**: Methods are annotated with `@Auditable` to log actions like profile completion, update, and deletion.
- **Security**: The class retrieves the authenticated user's ID from the security context, ensuring that operations are performed on the correct user profile.
- **Exception Handling**: Custom exceptions like `ProfileAlreadyCompletedException`, `DuplicateSkillLevelActivityException`, and `ResourceNotFoundException` are used to handle specific error scenarios.

This documentation provides a concise overview of the `UserService` class, detailing its purpose, public methods, and key concepts for effective usage and understanding.
