# UserService

The `UserService` class is a Spring service that manages user profile operations within the UpMatches application. It provides methods for retrieving, creating, updating, and deleting user profiles, with integrated authentication and audit logging.

## Purpose

This service handles all user-related business logic, including:
- Retrieving the authenticated user's profile
- Completing initial profile setup (onboarding)
- Updating existing profile information
- Deleting user accounts
- Managing skill level selections with validation

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `UserRepository` | Repository | Data access for user entities |
| `SkillLevelRepository` | Repository | Data access for skill level entities |
| `GameRepository` | Repository | Data access for game-related queries |

## Public Methods

### `getProfile()`

Retrieves the profile of the currently authenticated user.

**Returns:** `UserProfileResponse` - The authenticated user's profile data including game statistics.

**Throws:**
- `UnauthorizedException` - If no valid authentication is found
- `ResourceNotFoundException` - If the authenticated user is not found

### `completeProfile(CompleteProfileRequest request)`

Completes the initial profile setup for the authenticated user. This method is auditable with action `PROFILE_COMPLETED`.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CompleteProfileRequest` | Contains user's name, email, contact methods, and skill level selections |

**Returns:** `UserProfileResponse` - The completed user profile

**Throws:**
- `UnauthorizedException` - If no valid authentication is found
- `ProfileAlreadyCompletedException` - If the user has already completed onboarding
- `ResourceNotFoundException` - If the user or skill levels are not found
- `IllegalArgumentException` - If skill level IDs don't match their activities
- `DuplicateSkillLevelActivityException` - If multiple skill levels are selected for the same activity

### `updateProfile(UpdateProfileRequest request)`

Updates the profile of the currently authenticated user. This method is auditable with action `PROFILE_UPDATED`.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `UpdateProfileRequest` | Contains optional fields to update (name, contact methods, skill levels) |

**Returns:** `UserProfileResponse` - The updated user profile

**Throws:**
- `UnauthorizedException` - If no valid authentication is found
- `ResourceNotFoundException` - If the user or skill levels are not found
- `IllegalArgumentException` - If skill level IDs don't match their activities
- `DuplicateSkillLevelActivityException` - If multiple skill levels are selected for the same activity

### `deleteUser()`

Deletes the currently authenticated user's account. This method is auditable with action `PROFILE_DELETED`.

**Throws:**
- `UnauthorizedException` - If no valid authentication is found
- `ResourceNotFoundException` - If the authenticated user is not found

## Private Helper Methods

### `getAuthenticatedUserId()`

Extracts the user ID from the JWT token in the security context.

**Returns:** `UUID` - The authenticated user's ID

**Throws:** `UnauthorizedException` - If authentication is invalid or user ID cannot be parsed

### `buildProfileResponse(User user)`

Constructs a `UserProfileResponse` from a `User` entity, including game statistics.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user entity to build response from |

**Returns:** `UserProfileResponse` - Complete profile response with game statistics

### `findUserOrThrow(UUID userId)`

Retrieves a user by ID or throws an exception.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The user's unique identifier |

**Returns:** `User` - The found user entity

**Throws:** `ResourceNotFoundException` - If user is not found

### `findSkillLevelsOrThrow(List<SkillLevelSelection> selections)`

Validates and retrieves skill levels from selections, ensuring they exist and belong to the correct activities.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `selections` | `List<SkillLevelSelection>` | List of skill level selections with activity IDs |

**Returns:** `List<SkillLevel>` - Validated skill level entities

**Throws:**
- `ResourceNotFoundException` - If skill levels are not found
- `IllegalArgumentException` - If skill level doesn't belong to specified activity
- `DuplicateSkillLevelActivityException` - If multiple skill levels selected for same activity

### `validateOneSkillLevelPerActivity(List<SkillLevel> skillLevels)`

Ensures no more than one skill level is selected per activity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `skillLevels` | `List<SkillLevel>` | List of skill levels to validate |

**Throws:** `DuplicateSkillLevelActivityException` - If duplicate activity found

### `extractContact(List<ContactMethod> contacts, String name)`

Extracts a specific contact method value from a list of contacts.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `contacts` | `List<ContactMethod>` | List of contact methods |
| `name` | `String` | The contact method name to extract (whatsapp, telegram, messenger) |

**Returns:** `String` - The contact value, or `null` if not found

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `WHATSAPP` | `"whatsapp"` | WhatsApp contact method identifier |
| `TELEGRAM` | `"telegram"` | Telegram contact method identifier |
| `MESSENGER` | `"messenger"` | Messenger contact method identifier |
| `MSG_USER_NOT_FOUND` | `"The authenticated user was not found."` | Error message for missing user |
| `MSG_NO_VALID_AUTH` | `"No valid authentication found."` | Error message for missing authentication |
| `MSG_INVALID_USER_ID` | `"Invalid user ID in token subject: "` | Error message for invalid JWT subject |
| `MSG_SKILL_LEVELS_NOT_FOUND` | `"One or more skill levels not found."` | Error message for missing skill levels |
| `MSG_ACTIVITY_MISMATCH` | `"Skill level ID '%d' does not belong to activity ID '%s'."` | Error message for activity mismatch |

## Usage Example

```java
// Inject the service
private final UserService userService;

// Get current user's profile
UserProfileResponse profile = userService.getProfile();

// Complete initial profile setup
CompleteProfileRequest request = new CompleteProfileRequest(
    "John Doe",
    "john@example.com",
    List.of(new ContactMethod("whatsapp", "+1234567890")),
    List.of(new SkillLevelSelection(1L, UUID.fromString("..."))));
UserProfileResponse completedProfile = userService.completeProfile(request);

// Update profile
UpdateProfileRequest updateRequest = new UpdateProfileRequest(
    "Jane Doe",
    List.of(new ContactMethod("telegram", "@janedoe")),
    null);
UserProfileResponse updatedProfile = userService.updateProfile(updateRequest);

// Delete user account
userService.deleteUser();
```
