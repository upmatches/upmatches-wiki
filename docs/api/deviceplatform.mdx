## Overview

The `DevicePlatform` enum defines the supported device platforms for push notifications within the UpMatches application. It is used to specify the target platform when sending notifications, ensuring that messages are delivered to the correct device type.

This enum is part of the `com.upmatches.app.features.notification.enums` package and is essential for routing notifications to Android, iOS, or Web clients.

## Enum Values

| Value     | Description                                      |
|-----------|--------------------------------------------------|
| `ANDROID` | Represents Android mobile devices.               |
| `IOS`     | Represents Apple iOS devices (iPhone, iPad).     |
| `WEB`     | Represents web browser-based clients.            |

## Usage

The `DevicePlatform` enum is typically used in notification services to determine the appropriate push notification service (e.g., Firebase Cloud Messaging for Android, Apple Push Notification service for iOS, or Web Push API for browsers).

### Example

```java
DevicePlatform platform = DevicePlatform.ANDROID;

switch (platform) {
    case ANDROID:
        // Send notification via FCM
        break;
    case IOS:
        // Send notification via APNs
        break;
    case WEB:
        // Send notification via Web Push
        break;
}
```

## Related Components

- **NotificationService**: Uses this enum to route notifications to the correct push service.
- **PushNotificationRequest**: Contains a `DevicePlatform` field to specify the target platform.
