## Overview

The `DevicePlatform` enum is part of the `com.upmatches.app.features.notification.enums` package. This enum is used to represent different platforms that a device can operate on. It is particularly useful in scenarios where platform-specific logic is required, such as sending notifications to devices based on their operating system.

## Enum Constants

The `DevicePlatform` enum defines the following constants:

| Constant | Description                              |
|----------|------------------------------------------|
| ANDROID  | Represents the Android operating system. |
| IOS      | Represents the iOS operating system.     |
| WEB      | Represents web-based platforms.          |

## Usage

The `DevicePlatform` enum can be used in switch statements or conditional logic to execute platform-specific code. This allows for cleaner and more maintainable code when dealing with multiple device platforms.

### Example

```java
DevicePlatform platform = DevicePlatform.ANDROID;

switch (platform) {
    case ANDROID:
        // Handle Android-specific logic
        break;
    case IOS:
        // Handle iOS-specific logic
        break;
    case WEB:
        // Handle web-specific logic
        break;
}
```

This enum provides a simple and effective way to manage platform-specific behavior in your application.
