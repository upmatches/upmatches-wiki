# DevicePlatform Enum

The `DevicePlatform` enum defines the supported device platforms for push notifications within the UpMatches application. It is used to specify the target operating system or environment when sending notifications, ensuring that messages are delivered to the correct platform-specific push notification service (e.g., Firebase Cloud Messaging for Android, Apple Push Notification Service for iOS, or Web Push for browsers).

## Package Location

`com.upmatches.app.features.notification.enums`

## Enum Values

| Value     | Description                                                                 |
|-----------|-----------------------------------------------------------------------------|
| `ANDROID` | Represents the Android mobile operating system.                             |
| `IOS`     | Represents the Apple iOS mobile operating system.                           |
| `WEB`     | Represents web browser environments (e.g., desktop or mobile web browsers). |

## Usage

This enum is typically used in notification payloads or configuration objects to indicate the intended recipient platform. For example:

```java
DevicePlatform platform = DevicePlatform.ANDROID;
```

It can also be used in switch statements or conditional logic to route notifications to the appropriate push service:

```java
switch (platform) {
    case ANDROID:
        // Send via Firebase Cloud Messaging
        break;
    case IOS:
        // Send via Apple Push Notification Service
        break;
    case WEB:
        // Send via Web Push API
        break;
}
```
