## Purpose

The `DevicePlatform` enum is part of the `com.upmatches.app.features.notification.enums` package. It is used to define a set of constants representing different types of device platforms that the application can interact with. This enum is useful for categorizing and handling platform-specific logic within the application, particularly in the context of notifications.

## Enum Constants

The `DevicePlatform` enum defines the following constants:

| Constant | Description                              |
|----------|------------------------------------------|
| ANDROID  | Represents the Android platform.         |
| IOS      | Represents the iOS platform.             |
| WEB      | Represents web-based platforms.          |

## Usage

This enum can be used in switch statements or conditional logic to execute platform-specific code. It helps in maintaining clean and readable code by avoiding the use of hard-coded strings for platform identification.
