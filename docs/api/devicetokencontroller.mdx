## DeviceTokenController

The `DeviceTokenController` class is a REST controller responsible for handling HTTP requests related to device token registration and unregistration. It provides endpoints to register a new device token and to unregister an existing device token. This controller is part of the notification feature of the application.

### Public Methods

#### `registerToken`

Registers a new device token.

| Parameter | Type | Description |
|-----------|------|-------------|
| `body` | `RegisterDeviceTokenRequest` | The request body containing the device token details to be registered. |
| `request` | `HttpServletRequest` | The HTTP request object. |

**Returns:** `ResponseEntity<ApiResponse<Void>>` - A response entity with a success message and HTTP status 201 (Created).

#### `unregisterToken`

Unregisters an existing device token.

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceToken` | `String` | The device token to be unregistered. Must not be blank and have a maximum size of 512 characters. |

**Returns:** `ResponseEntity<Void>` - A response entity with HTTP status 204 (No Content) indicating successful unregistration.
