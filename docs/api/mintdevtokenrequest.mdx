# MintDevTokenRequest

The `MintDevTokenRequest` class is a Java record used as a Data Transfer Object (DTO) for requesting the minting of a developer token. It encapsulates the required user identifier for token generation.

## Purpose

This record serves as the request payload for an API endpoint that creates or "mints" a developer token for a specific user. By using a Java record, it provides an immutable data carrier with automatically generated constructors, accessors, `equals()`, `hashCode()`, and `toString()` methods.

## Record Definition

```java
public record MintDevTokenRequest(@NotNull UUID userId)
```

### Fields

| Field    | Type   | Validation | Description                                      |
|----------|--------|------------|--------------------------------------------------|
| `userId` | `UUID` | `@NotNull` | The unique identifier of the user requesting the developer token. |

## Validation

The `@NotNull` annotation (from `jakarta.validation.constraints`) ensures that the `userId` field cannot be `null` when the request is validated. This validation is typically enforced by a validation framework (e.g., Hibernate Validator) at the API layer before the request reaches the service logic.

## Usage Example

```java
// Creating a new request
UUID userUuid = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
MintDevTokenRequest request = new MintDevTokenRequest(userUuid);

// Accessing the field
UUID userId = request.userId();
```
