## Purpose

The `MintDevTokenRequest` class is a part of the `com.upmatches.app.features.auth.requests` package. It is designed to encapsulate the data required to request the minting of a development token. This class is implemented as a Java Record, which provides a compact syntax for declaring immutable data carriers.

## Public Methods

The `MintDevTokenRequest` class does not explicitly declare any public methods, as it is a Java Record. However, it implicitly provides the following methods:

### Constructor

| Method Signature | Description |
|------------------|-------------|
| `MintDevTokenRequest(UUID userId)` | Constructs a new `MintDevTokenRequest` with the specified `userId`. |

### Accessor Methods

| Method | Description | Return Type |

## Parameters

The `MintDevTokenRequest` class has the following parameter:

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId`  | `UUID` | A non-null universally unique identifier representing the user for whom the development token is being requested. |
