## Purpose

The `MintDevTokenRequest` class is a simple data structure used to encapsulate the request for minting a developer token. This class is part of the authentication feature in the application and ensures that a valid user ID is provided when making such a request. It utilizes Java's `record` feature to provide an immutable and concise representation of the data.

## Public Methods

The `MintDevTokenRequest` class does not explicitly define any public methods beyond those automatically provided by the Java `record` construct. However, it implicitly provides the following methods:

### Constructor

| Method Signature | Description |
|------------------|-------------|
| `MintDevTokenRequest(UUID userId)` | Constructs a new `MintDevTokenRequest` with the specified `userId`. |

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId`  | `UUID` | A non-null universally unique identifier representing the user for whom the developer token is being minted. |

### Return Types

Since `MintDevTokenRequest` is a record, it automatically provides accessor methods for its components:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `userId()` | `UUID` | Returns the `userId` associated with this request. |

## Validation

The `userId` parameter is annotated with `@NotNull`, indicating that it must not be null. This is enforced at runtime, ensuring that every `MintDevTokenRequest` instance is created with a valid `UUID`.
