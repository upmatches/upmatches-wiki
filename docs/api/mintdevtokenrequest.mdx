# MintDevTokenRequest

The `MintDevTokenRequest` class is a Java record used to encapsulate the request payload for minting a developer token. It is part of the authentication feature within the `com.upmatches.app.features.auth.requests` package. This record ensures that the required `userId` field is provided and validated before processing the token minting operation.

## Purpose

This record serves as a Data Transfer Object (DTO) for API endpoints that handle developer token minting. By using a Java record, the class automatically generates constructors, getters, `equals()`, `hashCode()`, and `toString()` methods, reducing boilerplate code. The `@NotNull` validation annotation ensures that the `userId` cannot be null, enforcing data integrity at the request level.

## Record Structure

| Field    | Type      | Description                                      | Validation |
|----------|-----------|--------------------------------------------------|------------|
| `userId` | `UUID`    | The unique identifier of the user requesting the token. | `@NotNull` |

## Constructor

The record provides a canonical constructor that accepts a single parameter:

- **`MintDevTokenRequest(UUID userId)`** - Creates a new instance with the specified user ID. The `@NotNull` constraint is enforced at runtime when validation is triggered (e.g., via Spring's `@Valid` annotation).

## Usage Example

```java
// Creating a request instance
UUID userUuid = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
MintDevTokenRequest request = new MintDevTokenRequest(userUuid);

// Accessing the userId
UUID id = request.userId();
```

## Validation

The `@NotNull` annotation on the `userId` field triggers validation failure if a `null` value is provided. This validation is typically enforced by a validation framework (e.g., Jakarta Bean Validation) when the request is processed in a controller method annotated with `@Valid`.

## Related Components

- **Package:** `com.upmatches.app.features.auth.requests`
- **Validation Framework:** Jakarta Bean Validation (via `jakarta.validation.constraints.NotNull`)
- **Typical Usage:** Used in REST controllers or service layers that handle developer token minting requests.
