## Overview

The `IGetGameDateAvailabilityService` interface defines the contract for retrieving game date availability within a specified date range. It is a **sealed interface**, meaning only the permitted implementation class (`GetGameDateAvailabilityService`) can implement it. This design enforces a controlled hierarchy and ensures that the availability logic is centralized and consistent.

## Interface Definition

```java
public sealed interface IGetGameDateAvailabilityService permits GetGameDateAvailabilityService {

    List<GameDateAvailabilityResponse> execute(LocalDate fromDate, LocalDate toDate);

}
```

## Method Summary

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `execute` | `List<GameDateAvailabilityResponse>` | `LocalDate fromDate` – Start of the date range (inclusive) <br/> `LocalDate toDate` – End of the date range (inclusive) | Retrieves a list of game date availability responses for the specified date range. |

## Usage Notes

- The interface is **sealed**, so only the class `GetGameDateAvailabilityService` is allowed to implement it. This prevents unintended implementations and ensures a single source of truth for availability logic.
- The `execute` method returns a list of `GameDateAvailabilityResponse` objects, each representing the availability status for a specific date within the range.
- The date range is inclusive of both `fromDate` and `toDate`.

## Example Usage

```java
IGetGameDateAvailabilityService service = new GetGameDateAvailabilityService();
LocalDate start = LocalDate.of(2025, 6, 1);
LocalDate end = LocalDate.of(2025, 6, 30);
List<GameDateAvailabilityResponse> availability = service.execute(start, end);
```

## Dependencies

- `com.upmatches.app.features.game.responses.GameDateAvailabilityResponse` – The response object representing availability for a single date.
- `java.time.LocalDate` – Standard Java date class for representing dates without time.
- `java.util.List` – Standard Java collection interface for ordered sequences.
