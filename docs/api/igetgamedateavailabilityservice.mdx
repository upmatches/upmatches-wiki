# IGetGameDateAvailabilityService

## Purpose

The `IGetGameDateAvailabilityService` is a **sealed interface** that defines the contract for retrieving game date availability within a specified date range. It serves as the abstraction layer for the `GetGameDateAvailabilityService` implementation, ensuring type safety and controlled inheritance through Java's sealed interface mechanism.

This interface is part of the game features module and is responsible for querying availability data between two dates, returning a list of `GameDateAvailabilityResponse` objects.

## Interface Definition

```java
public sealed interface IGetGameDateAvailabilityService permits GetGameDateAvailabilityService {
    List<GameDateAvailabilityResponse> execute(LocalDate fromDate, LocalDate toDate);
}
```

### Sealed Interface Details

- **Permitted Implementation**: Only `GetGameDateAvailabilityService` is allowed to implement this interface.
- **Package**: `com.upmatches.app.features.game.services`
- **Dependencies**: 
  - `GameDateAvailabilityResponse` from `com.upmatches.app.features.game.responses`
  - `LocalDate` from `java.time`
  - `List` from `java.util`

## Public Methods

### `execute`

| Property | Description |
|----------|-------------|
| **Signature** | `List<GameDateAvailabilityResponse> execute(LocalDate fromDate, LocalDate toDate)` |
| **Purpose** | Retrieves game date availability for the specified date range |
| **Parameters** | `fromDate` - The start date of the availability query (inclusive) <br/> `toDate` - The end date of the availability query (inclusive) |
| **Returns** | `List<GameDateAvailabilityResponse>` - A list of availability responses for each date in the range |
| **Throws** | No checked exceptions are declared |

## Usage Example

```java
// Assuming you have an instance of the service
IGetGameDateAvailabilityService availabilityService = new GetGameDateAvailabilityService();

// Query availability for the next 7 days
LocalDate from = LocalDate.now();
LocalDate to = from.plusDays(7);
List<GameDateAvailabilityResponse> availability = availabilityService.execute(from, to);
```

## Notes

- The sealed interface pattern ensures that only the permitted implementation (`GetGameDateAvailabilityService`) can implement this interface, providing compile-time safety and clear contract enforcement.
- The `execute` method is designed to be synchronous and returns a complete list of availability responses for the entire date range.
- Date parameters are inclusive on both ends of the range.
