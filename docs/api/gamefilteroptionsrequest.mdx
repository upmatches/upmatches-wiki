## Purpose

The `GameFilterOptionsRequest` class is a record used to encapsulate various filtering options for querying game data. It includes fields for date ranges, venue and skill level identifiers, time ranges, game type, and geographical location parameters. This class is designed to facilitate the creation of structured requests for filtering game-related data based on specific criteria.

## Public Methods

Checks if all location-related fields (`latitude`, `longitude`, and `radiusKm`) are non-null.

|-----------|---------|-------------|
