## Purpose

The `GameFilterOptionsRequest` class is a Java record used to encapsulate filtering options for game-related queries. It is designed to specify various criteria such as date range, venue, skill level, time, game type, and geographical location to filter games effectively. This record is particularly useful in applications where users need to search for games based on specific parameters.

## Public Methods

The `GameFilterOptionsRequest` record provides several public methods to check the presence of certain fields. These methods enhance the usability of the record by allowing quick checks on the availability of location or other filtering criteria.

### Method Details

| Method Name         | Description                                                                 | Return Type |
|---------------------|-----------------------------------------------------------------------------|-------------|
| `hasLocation()`     | Checks if all location-related fields (`latitude`, `longitude`, `radiusKm`) are present. | `boolean`   |
| `hasAnyLocationField()` | Checks if any of the location-related fields (`latitude`, `longitude`, `radiusKm`) are present. | `boolean`   |
| `hasSkillLevels()`  | Checks if the `skillLevelIds` list is not null and not empty.               | `boolean`   |
| `hasVenues()`       | Checks if the `venueIds` list is not null and not empty.                    | `boolean`   |

## Parameters

The `GameFilterOptionsRequest` record includes the following parameters:

| Parameter Name | Type        | Description                                                                 |
|----------------|-------------|-----------------------------------------------------------------------------|
| `fromDate`     | `LocalDate` | The start date for the game filter. Must not be null.                       |
| `toDate`       | `LocalDate` | The end date for the game filter. Must not be null.                         |
| `venueIds`     | `List<Long>`| A list of venue IDs to filter games. Maximum size is 20.                    |
| `skillLevelIds`| `List<Long>`| A list of skill level IDs to filter games. Maximum size is 20.              |
| `fromTime`     | `LocalTime` | The start time for the game filter.                                         |
| `toTime`       | `LocalTime` | The end time for the game filter.                                           |
| `gameType`     | `GameType`  | The type of game to filter.                                                 |
| `latitude`     | `BigDecimal`| The latitude for location-based filtering. Must be between -90 and 90.      |
| `longitude`    | `BigDecimal`| The longitude for location-based filtering. Must be between -180 and 180.   |
| `radiusKm`     | `Integer`   | The radius in kilometers for location-based filtering. Must be between 1 and 5. |

This record is validated using Jakarta Bean Validation annotations to ensure that the input data adheres to specified constraints, providing robust error handling and data integrity.
