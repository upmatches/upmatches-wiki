## Purpose of the `AuditAspect` Class

The `AuditAspect` class is an Aspect-Oriented Programming (AOP) component designed to handle auditing within the application. It intercepts methods annotated with `@Auditable` and records audit events based on the execution of these methods. The class utilizes Spring AOP to wrap method execution and capture relevant data, such as the actor, action, outcome, and any exceptions that occur.

## Public Methods

The `AuditAspect` class provides the following public method:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `audit` | `ProceedingJoinPoint joinPoint` | `Object` | Intercepts the execution of methods annotated with `@Auditable`, records audit events, and returns the result of the method execution. |

### Method Details

#### `audit`

- **Parameters:**
  - `ProceedingJoinPoint joinPoint`: The join point representing the method execution being intercepted.

- **Return Type:** 
  - `Object`: The result of the method execution.

- **Description:** 
  - This method is an AOP advice that surrounds the execution of methods annotated with `@Auditable`. It captures the method's input arguments, execution result, and any exceptions thrown. It then constructs an `AuditEventRequest` and uses the `IRecordAuditEventService` to record the audit event. If an exception occurs during the method execution, it is rethrown after recording the audit event.
