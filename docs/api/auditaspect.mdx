# AuditAspect

The `AuditAspect` class is a Spring AOP aspect that provides centralized audit logging for methods annotated with `@Auditable`. It automatically captures and records audit events including actor information, action details, outcomes, and contextual data such as IP addresses and user agents.

## Purpose

This aspect intercepts method calls annotated with `@Auditable` and:
- Records successful and failed execution attempts
- Captures actor identity (authenticated user or anonymous)
- Extracts resource identifiers using SpEL expressions
- Sanitizes sensitive payloads before logging
- Collects HTTP context information (IP, User-Agent)
- Associates audit events with correlation IDs for tracing

## Dependencies

| Dependency | Description |
|------------|-------------|
| `IAuthenticatedUserResolver` | Resolves the currently authenticated user |
| `IRecordAuditEventService` | Service for persisting audit events |
| `PayloadSanitizer` | Sanitizes method arguments for safe logging |
| `SpelExpressionParser` | Parses SpEL expressions for dynamic resource ID extraction |

## Public Methods

### `audit(ProceedingJoinPoint joinPoint)`

The main advice method that intercepts `@Auditable`-annotated methods.

| Parameter | Type | Description |
|-----------|------|-------------|
| `joinPoint` | `ProceedingJoinPoint` | The join point representing the intercepted method |

**Returns:** `Object` - The result of the intercepted method execution

**Throws:** `Throwable` - Any exception thrown by the intercepted method

**Behavior:**
1. Resolves the `@Auditable` annotation from the method
2. Proceeds with the original method execution
3. Builds an `AuditEventRequest` with contextual information
4. Records the audit event asynchronously in a `finally` block
5. Logs a warning if audit recording fails (does not propagate exceptions)

## Internal Methods

### `resolveAnnotation(ProceedingJoinPoint joinPoint)`

Resolves the `@Auditable` annotation from the intercepted method.

| Parameter | Type | Description |
|-----------|------|-------------|
| `joinPoint` | `ProceedingJoinPoint` | The join point to inspect |

**Returns:** `Auditable` - The annotation instance, or `null` if not present

### `buildRequest(Auditable annotation, Object[] args, Object result, Throwable failure)`

Constructs an `AuditEventRequest` from the intercepted method's context.

| Parameter | Type | Description |
|-----------|------|-------------|
| `annotation` | `Auditable` | The annotation configuration |
| `args` | `Object[]` | Method arguments |
| `result` | `Object` | Method return value (null if exception occurred) |
| `failure` | `Throwable` | Exception thrown (null if successful) |

**Returns:** `AuditEventRequest` - The constructed audit event request

### `resolveActorId()`

Resolves the authenticated user's ID.

**Returns:** `UUID` - The user ID, or `null` if not authenticated

### `resolveResourceId(Auditable annotation, Object[] args, Object result)`

Evaluates the SpEL expression defined in the annotation to extract a resource identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `annotation` | `Auditable` | The annotation containing the SpEL expression |
| `args` | `Object[]` | Method arguments (available as `#args`) |
| `result` | `Object` | Method return value (available as `#result`) |

**Returns:** `String` - The evaluated resource ID, or `null` if expression is blank or evaluation fails

### `resolveHttpContext()`

Extracts HTTP request context from the current request attributes.

**Returns:** `HttpContext` - Record containing IP address and User-Agent header

### `emptyToNull(String value)`

Converts blank strings to `null`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `value` | `String` | The string to check |

**Returns:** `String` - `null` if blank, otherwise the original value

## Internal Record

### `HttpContext`

A simple record for holding HTTP request context.

| Field | Type | Description |
|-------|------|-------------|
| `ipAddress` | `String` | Client IP address |
| `userAgent` | `String` | User-Agent header value |

## Configuration

The aspect is configured with:
- **Order:** `20` (executes after other aspects with lower order values)
- **Pointcut:** Methods annotated with `@Auditable`

## Error Handling

- If audit recording fails, a warning is logged but the exception is not propagated
- If SpEL expression evaluation fails, a debug message is logged and `null` is returned for the resource ID
- If the user cannot be resolved, the actor type defaults to `ANONYMOUS`

## Usage Example

```java
@Auditable(
    action = "CREATE_USER",
    category = AuditCategory.USER_MANAGEMENT,
    resourceType = "User",
    resourceIdExpression = "#result.id",
    sensitive = true
)
public User createUser(CreateUserRequest request) {
    // Method implementation
}
```
