# AuditAspect

The `AuditAspect` class is a Spring AOP aspect that provides declarative audit logging for methods annotated with `@Auditable`. It automatically captures and records audit events including actor information, action details, outcomes, and contextual HTTP data.

## Purpose

This aspect intercepts method executions marked with the `@Auditable` annotation and:
- Records successful and failed audit events
- Resolves the authenticated user or marks the actor as anonymous
- Evaluates SpEL expressions to extract resource identifiers
- Sanitizes sensitive payloads based on annotation configuration
- Captures HTTP context (IP address, user agent) from the current request
- Associates audit events with correlation IDs from MDC

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user |
| `IRecordAuditEventService` | Service | Persists audit events to the audit log |
| `PayloadSanitizer` | Utility | Sanitizes method arguments for safe logging |
| `SpelExpressionParser` | Spring | Parses SpEL expressions for resource ID resolution |

## Public Methods

### `audit(ProceedingJoinPoint joinPoint)`

The main advice method that intercepts `@Auditable`-annotated methods.

| Parameter | Type | Description |
|-----------|------|-------------|
| `joinPoint` | `ProceedingJoinPoint` | The intercepted method execution point |

**Returns:** `Object` - The result of the intercepted method execution

**Behavior:**
1. Resolves the `@Auditable` annotation from the method signature
2. Proceeds with the original method execution
3. In a `finally` block, builds and records an audit event
4. If audit recording fails, logs a warning without affecting the original method's outcome

## Internal Methods

### `resolveAnnotation(ProceedingJoinPoint joinPoint)`

Extracts the `@Auditable` annotation from the intercepted method.

| Parameter | Type | Description |
|-----------|------|-------------|
| `joinPoint` | `ProceedingJoinPoint` | The intercepted method execution point |

**Returns:** `Auditable` or `null` if the annotation is not present

### `buildRequest(Auditable annotation, Object[] args, Object result, Throwable failure)`

Constructs an `AuditEventRequest` from the available context.

| Parameter | Type | Description |
|-----------|------|-------------|
| `annotation` | `Auditable` | The audit configuration annotation |
| `args` | `Object[]` | Method arguments |
| `result` | `Object` | Method return value (null if failed) |
| `failure` | `Throwable` | Exception thrown (null if successful) |

**Returns:** `AuditEventRequest` - The fully populated audit event request

**Logic:**
- Resolves actor ID and type (USER or ANONYMOUS)
- Determines outcome (SUCCESS or FAILURE)
- Evaluates resource ID from SpEL expression
- Sanitizes payload if not marked as sensitive
- Captures HTTP context and correlation ID
- Extracts error code and message from exceptions

### `resolveActorId()`

Attempts to resolve the authenticated user's ID.

**Returns:** `UUID` or `null` if no authenticated user is found

### `resolveResourceId(Auditable annotation, Object[] args, Object result)`

Evaluates a SpEL expression to extract a resource identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `annotation` | `Auditable` | The audit configuration containing the SpEL expression |
| `args` | `Object[]` | Method arguments (available as `#args` in SpEL) |
| `result` | `Object` | Method return value (available as `#result` in SpEL) |

**Returns:** `String` or `null` if expression is blank or evaluation fails

### `resolveHttpContext()`

Captures the current HTTP request context.

**Returns:** `HttpContext` record containing IP address and User-Agent header

### `emptyToNull(String value)`

Utility method that converts blank strings to null.

| Parameter | Type | Description |
|-----------|------|-------------|
| `value` | `String` | The string to check |

**Returns:** `String` or `null` if the input is null or blank

## Inner Types

### `HttpContext`

A record that encapsulates HTTP request metadata.

| Field | Type | Description |
|-------|------|-------------|
| `ipAddress` | `String` | Client IP address |
| `userAgent` | `String` | User-Agent header value |

## Configuration

The aspect is configured with:
- **Order:** 20 (executes after other aspects with lower order values)
- **Pointcut:** Methods annotated with `@com.upmatches.app.features.audit.annotations.Auditable`

## Error Handling

- If audit recording fails, a warning is logged but the original method's execution is not affected
- SpEL evaluation failures are logged at DEBUG level and result in a null resource ID
- Authentication failures silently resolve to anonymous actor type
