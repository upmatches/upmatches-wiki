# GameBookmarkController

The `GameBookmarkController` is a REST controller that manages game bookmarks for the UpMatches application. It provides endpoints for creating, listing, and deleting game bookmarks, allowing users to save and manage their favorite games.

## Location

**Package:** `com.upmatches.app.features.game.controllers`

**Base URL:** `/api/v1/game-bookmarks`

## Dependencies

The controller relies on three service interfaces:
- `ICreateGameBookmarkService` - Handles bookmark creation
- `IDeleteGameBookmarkService` - Handles bookmark deletion
- `IListGameBookmarksService` - Handles bookmark listing with cursor-based pagination

## Endpoints

### Create Game Bookmark

Creates a new bookmark for a game.

```
POST /api/v1/game-bookmarks
```

**Request Body:** `CreateGameBookmarkRequest` (validated)

| Field | Type | Description |
|-------|------|-------------|
| `gameId` | UUID | The ID of the game to bookmark |

**Response:** `201 Created`

```json
{
  "data": {
    // GameBookmarkResponse object
  },
  "message": "Game bookmarked successfully.",
  "path": "/api/v1/game-bookmarks"
}
```

### List Game Bookmarks

Retrieves a paginated list of game bookmarks using cursor-based pagination.

```
GET /api/v1/game-bookmarks?cursor={cursor}&size={size}
```

**Query Parameters:**

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `cursor` | String | No | - | Cursor for pagination (opaque string) |
| `size` | Integer | No | 20 | Number of items per page (validated) |

**Response:** `200 OK`

```json
{
  "data": {
    // CursorPagedResponse<GameBookmarkResponse> object
  },
  "message": "Game bookmarks retrieved successfully.",
  "path": "/api/v1/game-bookmarks"
}
```

### Delete Game Bookmark

Removes a bookmark for a specific game.

```
DELETE /api/v1/game-bookmarks/{gameId}
```

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | UUID | The ID of the game to unbookmark |

**Response:** `204 No Content`

## Error Handling

- **400 Bad Request:** Returned when validation fails (e.g., invalid pagination size)
- **404 Not Found:** May be returned by services if the game or bookmark doesn't exist
- **409 Conflict:** May be returned if attempting to create a duplicate bookmark

## Usage Example

```java
// Create a bookmark
CreateGameBookmarkRequest request = new CreateGameBookmarkRequest(gameId);
ResponseEntity<ApiResponse<GameBookmarkResponse>> response = 
    controller.createGameBookmark(request, httpServletRequest);

// List bookmarks with pagination
ResponseEntity<ApiResponse<CursorPagedResponse<GameBookmarkResponse>>> listResponse = 
    controller.listGameBookmarks("cursor123", 10, httpServletRequest);

// Delete a bookmark
ResponseEntity<Void> deleteResponse = controller.deleteGameBookmark(gameId);
```

## Notes

- The controller uses cursor-based pagination for efficient retrieval of large bookmark collections
- All responses follow a standard `ApiResponse` wrapper format
- The `ValidationHelper.validateCursorPaginationParameters()` method ensures pagination parameters are within acceptable bounds
- Service implementations handle the actual business logic and data persistence
