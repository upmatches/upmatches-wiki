# Game Bookmark Controller

The `GameBookmarkController` is a REST controller that manages game bookmarks for the UpMatches application. It provides endpoints for creating, listing, and deleting game bookmarks, allowing users to save and manage their favorite games.

## Location

`com.upmatches.app.features.game.controllers.GameBookmarkController`

## Base URL

`/api/v1/game-bookmarks`

## Dependencies

The controller depends on three service interfaces:
- `ICreateGameBookmarkService` - Handles bookmark creation
- `IDeleteGameBookmarkService` - Handles bookmark deletion
- `IListGameBookmarksService` - Handles bookmark listing with cursor-based pagination

## Endpoints

### Create Game Bookmark

Creates a new bookmark for a specific game.

```
POST /api/v1/game-bookmarks
```

**Request Body:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `gameId` | UUID | Yes | The unique identifier of the game to bookmark |

**Response:**

| Status Code | Description |
|-------------|-------------|
| `201 Created` | Bookmark created successfully |

**Response Body:**

```json
{
  "data": {
    "id": "uuid",
    "gameId": "uuid",
    "createdAt": "timestamp"
  },
  "message": "Game bookmarked successfully.",
  "path": "/api/v1/game-bookmarks"
}
```

### List Game Bookmarks

Retrieves a paginated list of game bookmarks using cursor-based pagination.

```
GET /api/v1/game-bookmarks?cursor={cursor}&size={size}
```

**Query Parameters:**

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `cursor` | String | No | - | Cursor for pagination (opaque string) |
| `size` | Integer | No | 20 | Number of items per page (max 100) |

**Response:**

| Status Code | Description |
|-------------|-------------|
| `200 OK` | Bookmarks retrieved successfully |

**Response Body:**

```json
{
  "data": {
    "items": [
      {
        "id": "uuid",
        "gameId": "uuid",
        "createdAt": "timestamp"
      }
    ],
    "nextCursor": "opaque-cursor-string",
    "hasMore": true
  },
  "message": "Game bookmarks retrieved successfully.",
  "path": "/api/v1/game-bookmarks"
}
```

### Delete Game Bookmark

Removes a bookmark for a specific game.

```
DELETE /api/v1/game-bookmarks/{gameId}
```

**Path Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `gameId` | UUID | Yes | The unique identifier of the game to unbookmark |

**Response:**

| Status Code | Description |
|-------------|-------------|
| `204 No Content` | Bookmark deleted successfully |

## Error Handling

The controller uses standard HTTP status codes for error responses:

| Status Code | Description |
|-------------|-------------|
| `400 Bad Request` | Invalid request parameters (e.g., invalid cursor, size out of range) |
| `404 Not Found` | Game or bookmark not found |
| `409 Conflict` | Bookmark already exists (for create operation) |

## Usage Examples

### Create a Bookmark

```bash
curl -X POST http://localhost:8080/api/v1/game-bookmarks \
  -H "Content-Type: application/json" \
  -d '{"gameId": "123e4567-e89b-12d3-a456-426614174000"}'
```

### List Bookmarks

```bash
curl "http://localhost:8080/api/v1/game-bookmarks?size=10"
```

### Delete a Bookmark

```bash
curl -X DELETE http://localhost:8080/api/v1/game-bookmarks/123e4567-e89b-12d3-a456-426614174000
```

## Notes

- The controller uses cursor-based pagination for listing bookmarks, which is more efficient than offset-based pagination for large datasets.
- The `size` parameter is validated to ensure it doesn't exceed reasonable limits (typically max 100).
- All responses include the request path for debugging and logging purposes.
- The delete operation returns `204 No Content` with no response body.
