## Overview

The `GameBookmarkController` class is a REST controller in a Spring Boot application that manages game bookmarks. It provides endpoints to create, list, and delete game bookmarks. This controller interacts with services responsible for handling the business logic related to game bookmarks.

## Public Methods

### `createGameBookmark`

Creates a new game bookmark.

| Parameter | Type                              | Description                                      |
|-----------|-----------------------------------|--------------------------------------------------|
| `body`    | `CreateGameBookmarkRequest`       | The request body containing the game ID to bookmark. |
| `request` | `HttpServletRequest`              | The HTTP request object.                         |

**Returns**: `ResponseEntity<ApiResponse<GameBookmarkResponse>>` - A response entity containing the result of the bookmark creation operation.

### `listGameBookmarks`

Lists all game bookmarks with optional pagination.

| Parameter | Type                | Description                                      |
|-----------|---------------------|--------------------------------------------------|
| `cursor`  | `String` (optional) | The cursor for pagination.                       |
| `size`    | `Integer`           | The number of bookmarks to retrieve (default is 20). |
| `request` | `HttpServletRequest`| The HTTP request object.                         |

**Returns**: `ResponseEntity<ApiResponse<CursorPagedResponse<GameBookmarkResponse>>>` - A response entity containing a paginated list of game bookmarks.

### `deleteGameBookmark`

Deletes a game bookmark by its ID.

| Parameter | Type   | Description                  |
|-----------|--------|------------------------------|
| `gameId`  | `UUID` | The unique identifier of the game bookmark to delete. |

**Returns**: `ResponseEntity<Void>` - A response entity indicating the result of the delete operation.
