# GameBookmarkController

The `GameBookmarkController` is a REST controller that manages game bookmarks for the UpMatches application. It provides endpoints for creating, listing, and deleting game bookmarks, allowing users to save and manage their favorite games.

## Location

`com.upmatches.app.features.game.controllers.GameBookmarkController`

## Endpoints

### Create Game Bookmark

Creates a new bookmark for a game.

**HTTP Method:** `POST`  
**Endpoint:** `/api/v1/game-bookmarks`

| Parameter | Type | Description |
|-----------|------|-------------|
| `body` | `@Valid @RequestBody CreateGameBookmarkRequest` | The request body containing the game ID to bookmark |
| `request` | `HttpServletRequest` | The HTTP servlet request (injected automatically) |

**Response:** `201 Created`  
**Response Body:** `ApiResponse<GameBookmarkResponse>` containing the created bookmark details.

### List Game Bookmarks

Retrieves a paginated list of game bookmarks using cursor-based pagination.

**HTTP Method:** `GET`  
**Endpoint:** `/api/v1/game-bookmarks`

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `cursor` | `String` | `null` | Cursor for pagination (optional) |
| `size` | `Integer` | `20` | Number of items per page (optional) |
| `request` | `HttpServletRequest` | - | The HTTP servlet request (injected automatically) |

**Response:** `200 OK`  
**Response Body:** `ApiResponse<CursorPagedResponse<GameBookmarkResponse>>` containing the paginated list of bookmarks.

### Delete Game Bookmark

Deletes a specific game bookmark by game ID.

**HTTP Method:** `DELETE`  
**Endpoint:** `/api/v1/game-bookmarks/{gameId}`

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `@PathVariable UUID` | The UUID of the game to unbookmark |

**Response:** `204 No Content` (no response body)

## Dependencies

The controller depends on the following services:

| Service | Description |
|---------|-------------|
| `ICreateGameBookmarkService` | Handles creation of game bookmarks |
| `IDeleteGameBookmarkService` | Handles deletion of game bookmarks |
| `IListGameBookmarksService` | Handles retrieval of game bookmarks |

## Validation

The controller uses `ValidationHelper.validateCursorPaginationParameters(size)` to validate pagination parameters before processing list requests.

## Error Handling

- Invalid request bodies will return validation errors due to the `@Valid` annotation
- Invalid pagination parameters will be caught by the validation helper
- Standard HTTP error codes apply for other error scenarios (e.g., 404 for not found, 500 for server errors)
