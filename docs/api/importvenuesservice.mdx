# ImportVenuesService

The `ImportVenuesService` class is a Spring service responsible for importing venue data from a JSON file into the system. It handles the complete import workflow including parsing the JSON file, validating station codes, resolving or creating transit lines and stations, and persisting venues with their associated data. The service is designed to be idempotent, skipping venues that already exist based on their source ID.

## Key Features

- **JSON File Import**: Parses a JSON array of venue objects from a multipart file upload
- **Idempotent Processing**: Skips venues that already exist in the database by source ID
- **Station Code Parsing**: Supports single and dual station codes (e.g., "A1" or "A1 / B2")
- **Automatic Resource Creation**: Creates transit lines and stations if they don't already exist
- **Audit Logging**: Annotated with `@Auditable` for tracking import operations
- **Transactional**: Entire import process is wrapped in a database transaction

## Public Methods

### `execute(MultipartFile file)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `file` | `MultipartFile` | The JSON file containing venue data to import |

| Returns | Type |
|---------|------|
| `VenueImportResponse` | Response object containing the count of successfully imported venues |

**Description**: Main entry point for importing venues. Parses the JSON file, processes each venue, and returns a response with the import count. The method is transactional and auditable.

**Throws**:
- `InvalidFileException` - If the JSON file cannot be parsed or contains invalid station codes
- `ResourceNotFoundException` - If a referenced activity is not found in the database

## Internal Processing Flow

1. **Parse JSON**: The uploaded file is parsed into a list of `VenueImportRequest` objects using Jackson's `ObjectMapper`
2. **Process Each Venue**: For each venue request:
   - Check if venue already exists by source ID (skip if found)
   - Resolve the associated activity from cache or database
   - Create the venue entity with formatted postal code
   - Resolve and associate stations with their transit lines
   - Save the venue
3. **Return Response**: Return a `VenueImportResponse` with the count of imported venues

## Station Code Format

Station codes follow the pattern: `[LineCode][StationNumber]` or `[LineCode][StationNumber] / [LineCode][StationNumber]` for dual codes.

| Component | Description | Example |
|-----------|-------------|---------|
| Line Code | Alphabetic characters representing the transit line | `A`, `B`, `RED` |
| Station Number | Optional numeric identifier for the station | `1`, `23` |
| Dual Code Separator | Two codes separated by ` / ` | `A1 / B2` |

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `VenueRepository` | Repository | Persistence for venue entities |
| `ActivityRepository` | Repository | Lookup for activity entities |
| `StationRepository` | Repository | Persistence and lookup for station entities |
| `TransitLineRepository` | Repository | Persistence and lookup for transit line entities |
| `ObjectMapper` | Jackson | JSON parsing utility |

## Error Handling

| Error Condition | Exception | Message |
|-----------------|-----------|---------|
| Invalid JSON format | `InvalidFileException` | "Failed to parse venues JSON file '{filename}'. Expected a JSON array of venue objects at the root. Reason: {reason}" |
| Invalid station code | `InvalidFileException` | "Invalid station code format: {code}" |
| Activity not found | `ResourceNotFoundException` | "Activity with ID {id} not found." |

## Usage Example

```java
// Assuming ImportVenuesService is injected as importVenuesService
MultipartFile file = // ... get file from request
VenueImportResponse response = importVenuesService.execute(file);
System.out.println("Imported " + response.importedCount() + " venues");
```
