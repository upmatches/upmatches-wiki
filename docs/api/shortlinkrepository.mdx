# ShortLinkRepository

The `ShortLinkRepository` interface provides database access operations for the `ShortLink` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD functionality and defines custom query methods for managing shortened URLs within the UpMatches application.

## Purpose

This repository handles persistence operations for short links, including:
- Looking up short links by their unique code
- Finding existing short links for a specific resource and creator
- Checking code uniqueness
- Incrementing click counters atomically

## Methods

### Standard CRUD Methods

The following methods are inherited from `JpaRepository<ShortLink, UUID>`:

| Method | Description |
|--------|-------------|
| `findById(UUID id)` | Retrieves a short link by its primary key |
| `findAll()` | Returns all short links |
| `save(ShortLink entity)` | Creates or updates a short link |
| `delete(ShortLink entity)` | Removes a short link |
| `deleteById(UUID id)` | Deletes a short link by its ID |
| `count()` | Returns the total number of short links |

### Custom Query Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findByCode(String code)` | `Optional<ShortLink>` | `code` - The unique short code | Finds a short link by its generated code (e.g., "abc123") |
| `findByResourceTypeAndResourceIdAndCreatedById(ResourceType resourceType, String resourceId, UUID createdById)` | `Optional<ShortLink>` | `resourceType` - Type of resource (enum), `resourceId` - Resource identifier, `createdById` - Creator's user ID | Finds an existing short link for a specific resource created by a specific user |
| `existsByCode(String code)` | `boolean` | `code` - The short code to check | Returns `true` if the code is already in use |
| `incrementClickCount(UUID id)` | `int` | `id` - The short link's ID | Atomically increments the click counter by 1. Returns the number of affected rows (should be 1) |

## Usage Example

```java
@Service
public class ShortLinkService {
    private final ShortLinkRepository repository;

    public ShortLinkService(ShortLinkRepository repository) {
        this.repository = repository;
    }

    public Optional<ShortLink> findByCode(String code) {
        return repository.findByCode(code);
    }

    public boolean isCodeAvailable(String code) {
        return !repository.existsByCode(code);
    }

    @Transactional
    public void recordClick(UUID shortLinkId) {
        repository.incrementClickCount(shortLinkId);
    }
}
```

## Notes

- The `incrementClickCount` method is annotated with `@Modifying`, indicating it performs an update operation rather than a select query
- All custom queries use Spring Data JPA's derived query method naming conventions for automatic implementation
- The repository uses `UUID` as the primary key type for `ShortLink` entities
