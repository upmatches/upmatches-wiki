# ShortLinkRepository

The `ShortLinkRepository` interface provides database access operations for the `ShortLink` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD functionality and defines custom query methods for managing shortened URLs within the application.

## Purpose

This repository handles persistence operations for short links, including:
- Retrieving short links by their unique code
- Finding existing short links for a specific resource and creator
- Checking code availability
- Incrementing click counters atomically

## Methods

### Standard CRUD Operations

The following methods are inherited from `JpaRepository<ShortLink, UUID>`:

| Method | Description |
|--------|-------------|
| `findById(UUID id)` | Retrieves a short link by its primary key |
| `findAll()` | Returns all short links |
| `save(ShortLink entity)` | Creates or updates a short link |
| `deleteById(UUID id)` | Deletes a short link by its ID |
| `count()` | Returns the total number of short links |

### Custom Query Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findByCode(String code)` | `Optional<ShortLink>` | `code` - The unique short code | Finds a short link by its generated code |
| `findByResourceTypeAndResourceIdAndCreatedById(ResourceType resourceType, String resourceId, UUID createdById)` | `Optional<ShortLink>` | `resourceType` - Type of resource (e.g., profile, post)<br/>`resourceId` - ID of the resource<br/>`createdById` - UUID of the user who created the link | Finds an existing short link for a specific resource and creator |
| `existsByCode(String code)` | `boolean` | `code` - The short code to check | Returns `true` if the code is already in use |
| `incrementClickCount(UUID id)` | `int` | `id` - UUID of the short link | Atomically increments the click count by 1. Returns the number of affected rows (should be 1) |

## Usage Notes

- The `incrementClickCount` method is annotated with `@Modifying`, indicating it performs a write operation. It must be called within a transactional context.
- The `findByCode` method is typically used when a user accesses a shortened URL to redirect them to the original resource.
- The `findByResourceTypeAndResourceIdAndCreatedById` method prevents duplicate short links for the same resource and creator combination.
- The `existsByCode` method is useful during code generation to ensure uniqueness.

## Example Usage

```java
@Service
public class ShortLinkService {
    private final ShortLinkRepository repository;

    public ShortLinkService(ShortLinkRepository repository) {
        this.repository = repository;
    }

    public Optional<ShortLink> findByCode(String code) {
        return repository.findByCode(code);
    }

    public void recordClick(UUID linkId) {
        repository.incrementClickCount(linkId);
    }
}
```
