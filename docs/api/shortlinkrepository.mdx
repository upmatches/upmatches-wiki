# ShortLinkRepository

The `ShortLinkRepository` interface provides database access operations for the `ShortLink` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD functionality and defines custom query methods for managing short links, including lookups by code, resource associations, and click count tracking.

## Interface Definition

```java
public interface ShortLinkRepository extends JpaRepository<ShortLink, UUID>
```

The repository works with `ShortLink` entities keyed by `UUID` identifiers.

## Custom Query Methods

| Method | Description | Parameters | Return Type |
|--------|-------------|------------|-------------|
| `findByCode(String code)` | Retrieves a short link by its unique code | `code` - The short link code (e.g., "abc123") | `Optional<ShortLink>` |
| `findByResourceTypeAndResourceIdAndCreatedById(ResourceType resourceType, String resourceId, UUID createdById)` | Finds a short link by its associated resource type, resource ID, and creator | `resourceType` - The type of resource (enum), `resourceId` - The resource identifier, `createdById` - The UUID of the user who created the link | `Optional<ShortLink>` |
| `existsByCode(String code)` | Checks whether a short link code already exists in the database | `code` - The short link code to check | `boolean` |
| `incrementClickCount(UUID id)` | Atomically increments the click count for a short link by 1 | `id` - The UUID of the short link to update | `int` (number of affected rows) |

## Method Details

### findByCode
Performs a lookup using the unique short code assigned to each link. Returns an `Optional` that is empty if no matching link is found.

### findByResourceTypeAndResourceIdAndCreatedById
Enables finding a short link based on the resource it points to and the user who created it. This is useful for preventing duplicate short links for the same resource by the same user.

### existsByCode
Provides a boolean check to determine if a particular short code is already in use, helping to enforce code uniqueness.

### incrementClickCount
Uses a custom JPQL `UPDATE` query annotated with `@Modifying` to increment the `clickCount` field atomically at the database level. This avoids race conditions that could occur with read-then-write operations. The method returns the number of database rows affected (should be 1 for a valid ID).

## Inherited Methods

As a `JpaRepository<ShortLink, UUID>`, this interface also inherits standard methods including:

- `save(ShortLink entity)` - Persists a new or updates an existing short link
- `findById(UUID id)` - Retrieves a short link by its primary key
- `findAll()` - Returns all short links
- `delete(ShortLink entity)` - Removes a short link
- `count()` - Returns the total number of short links

## Usage Example

```java
@Autowired
private ShortLinkRepository shortLinkRepository;

// Create a new short link
ShortLink link = new ShortLink();
link.setCode("xyz789");
link.setResourceType(ResourceType.POST);
link.setResourceId("post-123");
link.setCreatedById(userId);
shortLinkRepository.save(link);

// Find by code
Optional<ShortLink> found = shortLinkRepository.findByCode("xyz789");

// Increment click count
int updated = shortLinkRepository.incrementClickCount(link.getId());
```

## Dependencies

- Spring Data JPA (`JpaRepository`, `@Query`, `@Modifying`)
- `ShortLink` entity class
- `ResourceType` enum
- `UUID` from `java.util`
