# ShareLinkProperties

The `ShareLinkProperties` class is a Spring Boot configuration properties record that manages the URLs and identifiers required for generating shareable links within the Upmatches application. It provides a centralized way to configure the base URLs for the API, web frontend, and mobile app store links, with sensible defaults for development and production environments.

## Purpose

This class serves as a configuration holder for share link generation. It allows developers to customize the following aspects of share links:

- **API base URL**: The base URL for shortened share links
- **Web base URL**: The base URL for web-based share links
- **App Store URL**: The direct link to the iOS App Store listing
- **Play Store URL**: The direct link to the Google Play Store listing
- **App Store App ID**: The Apple App Store application identifier

## Configuration

The properties are bound to the `app.share-link` prefix in your application configuration files (e.g., `application.yml` or `application.properties`).

### Example Configuration

```yaml
app:
  share-link:
    base-url: https://api.upmatches.dev/s
    web-base-url: https://api.upmatches.dev
    app-store-url: https://apps.apple.com/app/idXXXXXXXXXX
    play-store-url: https://play.google.com/store/apps/details?id=com.upmatches.android
    app-store-app-id: ""
```

## Default Values

The class defines sensible defaults for all properties, ensuring the application can function without explicit configuration:

| Property | Default Value |
|----------|---------------|
| `baseUrl` | `https://api.upmatches.dev/s` |
| `webBaseUrl` | `https://api.upmatches.dev` |
| `appStoreUrl` | `https://apps.apple.com/app/idXXXXXXXXXX` |
| `playStoreUrl` | `https://play.google.com/store/apps/details?id=com.upmatches.android` |
| `appStoreAppId` | `""` (empty string) |

## Constructor Behavior

The compact constructor validates and applies defaults for each property:

- If `baseUrl` is `null` or blank, it defaults to `https://api.upmatches.dev/s`
- If `webBaseUrl` is `null` or blank, it defaults to `https://api.upmatches.dev`
- If `appStoreUrl` is `null` or blank, it defaults to `https://apps.apple.com/app/idXXXXXXXXXX`
- If `playStoreUrl` is `null` or blank, it defaults to `https://play.google.com/store/apps/details?id=com.upmatches.android`
- If `appStoreAppId` is `null`, it defaults to an empty string

## Public Methods

Since this is a Java record, the following accessor methods are automatically generated:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `baseUrl()` | `String` | Returns the base URL for shortened share links |
| `webBaseUrl()` | `String` | Returns the base URL for web-based share links |
| `appStoreUrl()` | `String` | Returns the direct link to the iOS App Store listing |
| `playStoreUrl()` | `String` | Returns the direct link to the Google Play Store listing |
| `appStoreAppId()` | `String` | Returns the Apple App Store application identifier |

## Usage Example

```java
@Service
public class ShareLinkService {
    
    private final ShareLinkProperties properties;
    
    public ShareLinkService(ShareLinkProperties properties) {
        this.properties = properties;
    }
    
    public String generateShareLink(String shortCode) {
        return properties.baseUrl() + "/" + shortCode;
    }
    
    public String getAppStoreLink() {
        return properties.appStoreUrl();
    }
}
```

## Dependencies

- **Spring Boot**: `@ConfigurationProperties` annotation from `org.springframework.boot.context.properties`
- **Java 16+**: Record feature used for immutable data carrier

## Notes

- The class is immutable by design (Java record), ensuring thread safety
- Properties are automatically bound by Spring Boot when the `@ConfigurationProperties` annotation is enabled with `@EnableConfigurationProperties` or through configuration processor scanning
- Default values are applied only when the provided value is `null` or blank, allowing explicit empty strings to be preserved if needed
