## Overview

The `ShareLinkProperties` class is a configuration properties holder used in a Spring Boot application. It is designed to manage and provide default values for various URLs related to sharing links, such as base URLs for web and app stores. This class utilizes the `@ConfigurationProperties` annotation to map properties from external configuration files, allowing for easy customization and management of these URLs.

## Public Methods

The `ShareLinkProperties` class is a Java record, which means it primarily serves as a data carrier. It does not have traditional methods like a typical class but provides implicit getter methods for each of its components. Below is a table documenting these components:

| Method Name   | Parameter Type | Return Type | Description                                                                 |
|---------------|----------------|-------------|-----------------------------------------------------------------------------|
| baseUrl       | -              | `String`    | Returns the base URL for sharing links. Defaults to `https://api.upmatches.dev/s` if not provided. |
| webBaseUrl    | -              | `String`    | Returns the web base URL. Defaults to `https://api.upmatches.dev` if not provided. |
| appStoreUrl   | -              | `String`    | Returns the URL for the App Store. Defaults to `https://apps.apple.com/app/idXXXXXXXXXX` if not provided. |
| playStoreUrl  | -              | `String`    | Returns the URL for the Play Store. Defaults to `https://play.google.com/store/apps/details?id=com.upmatches.android` if not provided. |
| appStoreAppId | -              | `String`    | Returns the App Store App ID. Defaults to an empty string if not provided. |

## Default Values

The class provides default values for each of its components to ensure that the application can function correctly even if some configuration properties are missing. These defaults are hardcoded within the class and are used when the corresponding property is either `null` or blank.
