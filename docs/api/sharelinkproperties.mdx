# ShareLinkProperties

The `ShareLinkProperties` class is a Spring Boot configuration properties record that manages the URLs and identifiers required for generating shareable links within the Upmatches application. It provides default values for all properties, ensuring that the application can function even when specific configuration values are not explicitly provided.

## Purpose

This class centralizes the configuration for share link generation, including:
- API base URLs for short link creation
- Web application base URL
- App store URLs for both iOS and Android platforms
- Apple App Store application identifier

By using Spring Boot's `@ConfigurationProperties` with the prefix `app.share-link`, these values can be easily configured through standard Spring Boot configuration files (application.yml, application.properties, environment variables, etc.).

## Configuration Properties

| Property | Type | Default Value | Description |
|----------|------|---------------|-------------|
| `baseUrl` | `String` | `https://api.upmatches.dev/s` | Base URL for generating short share links |
| `webBaseUrl` | `String` | `https://api.upmatches.dev` | Base URL for the web application |
| `appStoreUrl` | `String` | `https://apps.apple.com/app/idXXXXXXXXXX` | Apple App Store URL for the application |
| `playStoreUrl` | `String` | `https://play.google.com/store/apps/details?id=com.upmatches.android` | Google Play Store URL for the application |
| `appStoreAppId` | `String` | `""` (empty string) | Apple App Store application identifier |

## Constructor Behavior

The compact constructor of this record implements fallback logic for each property. If a property is `null` or blank (for string properties), it defaults to the predefined constant value. This ensures that the application always has valid configuration values, even when properties are not explicitly set.

## Usage Example

```yaml
# application.yml
app:
  share-link:
    base-url: https://custom-api.example.com/s
    web-base-url: https://custom-web.example.com
    app-store-url: https://apps.apple.com/app/id123456789
    play-store-url: https://play.google.com/store/apps/details?id=com.custom.app
    app-store-app-id: "123456789"
```

## Dependencies

- Spring Boot: `@ConfigurationProperties` annotation
- Java 16+ (Record feature)
