# Redis Configuration

The `RedisConfiguration` class is a Spring `@Configuration` class that provides a bean definition for a `StringRedisTemplate`. This template is configured to serialize both keys and values as strings, making it suitable for use cases where Redis stores simple string-based data, such as session tokens, user preferences, or cache entries.

## Purpose

- **Centralized Redis Setup**: Defines a single, reusable `StringRedisTemplate` bean for the entire application.
- **String Serialization**: Ensures all keys and values are serialized as plain strings, avoiding complex object serialization issues.
- **Consistent Configuration**: Applies the same serialization strategy to hash keys and hash values, maintaining uniformity across Redis operations.

## Bean Definitions

| Bean Name | Return Type | Description |
|-----------|-------------|-------------|
| `stringRedisTemplate` | `StringRedisTemplate` | A pre-configured Redis template for string-based operations. |

## Method Details

### `stringRedisTemplate`

```java
@Bean
public StringRedisTemplate stringRedisTemplate(final RedisConnectionFactory connFactory)
```

Creates and configures a `StringRedisTemplate` bean.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `connFactory` | `RedisConnectionFactory` | The Redis connection factory provided by Spring Boot auto-configuration. |

**Returns:**

| Type | Description |
|------|-------------|
| `StringRedisTemplate` | A fully configured template ready for string-based Redis operations. |

**Configuration Details:**

- **Connection Factory**: Uses the provided `RedisConnectionFactory` to establish connections to the Redis server.
- **Key Serializer**: `StringRedisSerializer` – ensures all keys are stored as plain strings.
- **Value Serializer**: `StringRedisSerializer` – ensures all values are stored as plain strings.
- **Hash Key Serializer**: `StringRedisSerializer` – ensures hash field names are stored as strings.
- **Hash Value Serializer**: `StringRedisSerializer` – ensures hash field values are stored as strings.

## Usage Example

```java
@Service
public class SessionService {
    
    private final StringRedisTemplate redisTemplate;
    
    public SessionService(StringRedisTemplate redisTemplate) {
        this.redisTemplate = redisTemplate;
    }
    
    public void saveSession(String sessionId, String userData) {
        redisTemplate.opsForValue().set(sessionId, userData);
    }
    
    public String getSession(String sessionId) {
        return redisTemplate.opsForValue().get(sessionId);
    }
}
```

## Dependencies

This configuration requires the following Spring Boot starter dependency:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

## Notes

- The `StringRedisTemplate` is a specialization of `RedisTemplate<String, String>` that simplifies string-based operations.
- All serializers are explicitly set to `StringRedisSerializer` to avoid any default Java serialization behavior.
- This configuration assumes Redis is used primarily for string data; for complex object storage, consider using `RedisTemplate<Object, Object>` with appropriate serializers.
