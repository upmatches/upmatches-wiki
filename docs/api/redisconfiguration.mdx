# Redis Configuration

The `RedisConfiguration` class is a Spring `@Configuration` class that provides a bean definition for a `StringRedisTemplate`. This template is configured to serialize both keys and values as strings, making it suitable for storing and retrieving simple string-based data in Redis.

## Purpose

This configuration ensures that all Redis operations performed by the application use string serialization for keys, values, hash keys, and hash values. This is particularly useful for authentication-related data (e.g., session tokens, user IDs) where string-based storage is sufficient and efficient.

## Bean Definitions

| Bean Name | Return Type | Description |
|-----------|-------------|-------------|
| `stringRedisTemplate` | `StringRedisTemplate` | Configures a Redis template with string serializers for all data types. |

## Method Details

### `stringRedisTemplate`

```java
@Bean
public StringRedisTemplate stringRedisTemplate(final RedisConnectionFactory connFactory)
```

Creates and configures a `StringRedisTemplate` bean.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `connFactory` | `RedisConnectionFactory` | The Redis connection factory provided by Spring Boot auto-configuration. |

**Returns:**

| Type | Description |
|------|-------------|
| `StringRedisTemplate` | A fully configured Redis template with string serializers for keys, values, hash keys, and hash values. |

**Configuration Details:**

The method performs the following configuration on the `StringRedisTemplate`:

1. Sets the provided `RedisConnectionFactory` as the connection factory.
2. Configures a `StringRedisSerializer` for:
   - **Key Serializer**: Serializes Redis keys as strings.
   - **Value Serializer**: Serializes Redis values as strings.
   - **Hash Key Serializer**: Serializes hash field keys as strings.
   - **Hash Value Serializer**: Serializes hash field values as strings.

## Usage Example

```java
@Service
public class AuthService {
    
    @Autowired
    private StringRedisTemplate redisTemplate;
    
    public void storeSessionToken(String userId, String token) {
        redisTemplate.opsForValue().set("session:" + userId, token);
    }
    
    public String getSessionToken(String userId) {
        return redisTemplate.opsForValue().get("session:" + userId);
    }
}
```

## Dependencies

This configuration requires the following Spring Boot starter dependency:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

## Notes

- The `StringRedisTemplate` is a specialized version of `RedisTemplate<String, String>` that is optimized for string-based operations.
- All serializers are explicitly set to `StringRedisSerializer` to ensure consistent behavior across all Redis data types.
- The connection factory is automatically provided by Spring Boot's auto-configuration when Redis is configured in the application properties.
