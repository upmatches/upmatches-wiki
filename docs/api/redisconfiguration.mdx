# Redis Configuration

The `RedisConfiguration` class is a Spring Boot configuration component that sets up and exposes a `StringRedisTemplate` bean for interacting with a Redis data store. This configuration ensures that all keys and values stored in Redis are serialized and deserialized as plain strings using `StringRedisSerializer`.

## Purpose

- Provides a centralized Redis template configuration for the application.
- Ensures consistent string-based serialization for Redis keys, values, hash keys, and hash values.
- Simplifies dependency injection of a fully configured `StringRedisTemplate` throughout the application.

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `stringRedisTemplate` | `StringRedisTemplate` | `RedisConnectionFactory connFactory` | Creates and configures a `StringRedisTemplate` bean with string serializers for all data types. |

## Bean Details

### `stringRedisTemplate`

This method creates a `StringRedisTemplate` instance and configures it with the following serializers:

- **Key Serializer**: `StringRedisSerializer` – Ensures Redis keys are stored as strings.
- **Value Serializer**: `StringRedisSerializer` – Ensures Redis values are stored as strings.
- **Hash Key Serializer**: `StringRedisSerializer` – Ensures hash field names are stored as strings.
- **Hash Value Serializer**: `StringRedisSerializer` – Ensures hash field values are stored as strings.

The method accepts a `RedisConnectionFactory` parameter, which is automatically injected by Spring Boot based on the application's Redis connection configuration (e.g., `application.properties` or `application.yml`).

## Usage Example

```java
@Service
public class TokenService {
    
    private final StringRedisTemplate redisTemplate;
    
    public TokenService(StringRedisTemplate redisTemplate) {
        this.redisTemplate = redisTemplate;
    }
    
    public void storeToken(String key, String token) {
        redisTemplate.opsForValue().set(key, token);
    }
    
    public String getToken(String key) {
        return redisTemplate.opsForValue().get(key);
    }
}
```

## Dependencies

- `org.springframework.context.annotation.Bean`
- `org.springframework.context.annotation.Configuration`
- `org.springframework.data.redis.connection.RedisConnectionFactory`
- `org.springframework.data.redis.core.StringRedisTemplate`
- `org.springframework.data.redis.serializer.StringRedisSerializer`

## Notes

- This configuration assumes that all Redis interactions in the application will use string-based serialization. For more complex object serialization, consider using `Jackson2JsonRedisSerializer` or `GenericJackson2JsonRedisSerializer`.
- The `RedisConnectionFactory` bean must be configured separately, typically through Spring Boot's auto-configuration or explicit bean definition.
