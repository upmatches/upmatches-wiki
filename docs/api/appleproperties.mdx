import org.springframework.boot.context.properties.ConfigurationProperties;

## Overview

The `AppleProperties` class is a configuration properties holder for Apple authentication settings in a Spring Boot application. It is designed to capture and manage properties related to Apple's authentication service, such as the issuer, audience, and JSON Web Key Set (JWKS) URI. This class uses the `@ConfigurationProperties` annotation to bind external configuration properties prefixed with `app.apple` to its fields.

## Class Details

### Purpose

The primary purpose of the `AppleProperties` class is to encapsulate configuration properties required for integrating with Apple's authentication services. It ensures that default values are provided for critical properties if they are not specified in the application's configuration.

### Public Methods

The `AppleProperties` class is a record, which means it automatically provides public accessor methods for its fields. Below is a table documenting these methods:

| Method          | Parameters | Return Type | Description                                                                 |
|-----------------|------------|-------------|-----------------------------------------------------------------------------|
| `issuer()`      | None       | `String`    | Returns the issuer URL for Apple authentication. Defaults to `https://appleid.apple.com` if not specified. |
| `audience()`    | None       | `String`    | Returns the audience value for Apple authentication. This value must be specified in the configuration. |
| `jwksUri()`     | None       | `String`    | Returns the JWKS URI for Apple authentication. Defaults to `https://appleid.apple.com/auth/keys` if not specified. |

### Constructor

The `AppleProperties` record provides a canonical constructor that initializes its fields. If the `issuer` or `jwksUri` parameters are null or blank, they are set to their respective default values.

## Usage

To use the `AppleProperties` class, ensure that your Spring Boot application's configuration file (e.g., `application.yml` or `application.properties`) contains the necessary `app.apple` properties. The class will automatically bind these properties and provide default values for `issuer` and `jwksUri` if they are not explicitly set.
