# AppleProperties

The `AppleProperties` class is a Spring Boot configuration properties record that maps to the `app.apple` prefix in your application's configuration files (e.g., `application.yml` or `application.properties`). It encapsulates the necessary OAuth 2.0 / OpenID Connect parameters required to validate Apple ID tokens during authentication.

## Purpose

This record provides a type-safe way to inject Apple Sign-In configuration values into your Spring beans. It defines three key properties: `issuer`, `audience`, and `jwksUri`. The record also includes sensible defaults for the issuer and JWKS URI, ensuring that your application can work out-of-the-box with Apple's authentication endpoints.

## Properties

| Property   | Type     | Description                                                                 | Default Value                        |
|------------|----------|-----------------------------------------------------------------------------|--------------------------------------|
| `issuer`   | `String` | The issuer identifier for Apple ID tokens.                                  | `https://appleid.apple.com`          |
| `audience` | `String` | The client ID (audience) that the ID token is intended for.                 | No default (must be configured)      |
| `jwksUri`  | `String` | The URI where Apple publishes its JSON Web Key Set (JWKS) for token verification. | `https://appleid.apple.com/auth/keys` |

## Constructor Behavior

The compact constructor of this record applies default values if the `issuer` or `jwksUri` properties are `null` or blank. This ensures that even if these values are omitted from your configuration, the application will still use Apple's standard endpoints.

## Usage Example

To use this configuration in your Spring application, add the following to your `application.yml`:

```yaml
app:
  apple:
    issuer: https://appleid.apple.com
    audience: com.your.client.id
    jwksUri: https://appleid.apple.com/auth/keys
```

Then, inject the `AppleProperties` bean into any Spring-managed component:

```java
@Service
public class AppleTokenVerifier {
    private final AppleProperties appleProperties;

    public AppleTokenVerifier(AppleProperties appleProperties) {
        this.appleProperties = appleProperties;
    }

    public void verifyToken(String idToken) {
        // Use appleProperties.issuer(), appleProperties.audience(), and appleProperties.jwksUri()
    }
}
```

## Dependencies

This class requires Spring Boot's `@ConfigurationProperties` support. Ensure you have the `spring-boot-starter-validation` or appropriate dependency in your `pom.xml` or `build.gradle` to enable configuration property binding.
