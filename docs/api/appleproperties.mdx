# AppleProperties

The `AppleProperties` class is a Spring Boot configuration properties record that encapsulates configuration parameters for Apple Sign-In authentication. It is annotated with `@ConfigurationProperties(prefix = "app.apple")`, meaning it automatically binds to properties prefixed with `app.apple` in the application's configuration files (e.g., `application.yml` or `application.properties`).

This record provides default values for the `issuer` and `jwksUri` fields if they are not explicitly configured, ensuring that the Apple Sign-In integration works out-of-the-box with Apple's standard endpoints.

## Purpose

- **Centralized Configuration**: Manages Apple Sign-In related properties in a single, type-safe record.
- **Default Values**: Automatically falls back to Apple's production endpoints (`https://appleid.apple.com` for issuer and JWKS URI) if no custom values are provided.
- **Spring Boot Integration**: Leverages Spring Boot's `@ConfigurationProperties` to bind external configuration to this record.

## Constructor

The compact constructor validates and sets default values for `issuer` and `jwksUri` if they are `null` or blank.

| Parameter | Type     | Description                                                                 |
|-----------|----------|-----------------------------------------------------------------------------|
| `issuer`  | `String` | The issuer URL for Apple Sign-In. Defaults to `https://appleid.apple.com`.  |
| `audience`| `String` | The audience (typically your app's bundle ID or service ID).                |
| `jwksUri` | `String` | The JWKS (JSON Web Key Set) URI for verifying Apple's tokens. Defaults to `https://appleid.apple.com/auth/keys`. |

## Public Methods

Since `AppleProperties` is a Java `record`, it automatically provides accessor methods for each component. The following methods are generated by the compiler:

| Method       | Return Type | Description                                      |
|--------------|-------------|--------------------------------------------------|
| `issuer()`   | `String`    | Returns the issuer URL for Apple Sign-In.        |
| `audience()` | `String`    | Returns the audience (e.g., your app's bundle ID). |
| `jwksUri()`  | `String`    | Returns the JWKS URI for token verification.     |

## Usage Example

To use this configuration in your Spring Boot application, add the following properties to your `application.yml` or `application.properties`:

```yaml
app:
  apple:
    issuer: https://appleid.apple.com
    audience: com.yourcompany.yourapp
    jwks-uri: https://appleid.apple.com/auth/keys
```

If you omit `issuer` or `jwks-uri`, the defaults will be used automatically.

## Dependencies

- **Spring Boot**: Requires `spring-boot-starter` and `spring-boot-configuration-processor` for annotation processing.
- **Java 17+**: The `record` feature requires Java 17 or later.

## Notes

- The `audience` field does not have a default value and must be explicitly configured in your application properties.
- The `@ConfigurationProperties` annotation enables Spring Boot to bind properties from any configured source (YAML, properties files, environment variables, etc.).
