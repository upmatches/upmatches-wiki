# AppleProperties

The `AppleProperties` class is a Spring Boot configuration properties record that encapsulates the configuration parameters required for Apple Sign-In authentication. It is bound to the `app.apple` prefix in the application's configuration files (e.g., `application.yml` or `application.properties`).

## Purpose

This record provides a centralized and type-safe way to manage Apple Sign-In related settings, such as the issuer, audience, and JWKS URI. It also includes sensible defaults for the issuer and JWKS URI, ensuring that the application can function correctly even if these values are not explicitly provided in the configuration.

## Configuration Prefix

- **Prefix:** `app.apple`

## Properties

| Property   | Type   | Description                                                                 | Default Value                     |
|------------|--------|-----------------------------------------------------------------------------|-----------------------------------|
| `issuer`   | String | The issuer identifier for Apple Sign-In. Typically the Apple ID.            | `https://appleid.apple.com`       |
| `audience` | String | The audience for the token, usually the client ID (service ID) of your app. | None (must be provided)           |
| `jwksUri`  | String | The URI to fetch Apple's public keys for token verification.                | `https://appleid.apple.com/auth/keys` |

## Constructor

The record's canonical constructor performs validation and applies default values:

- If `issuer` is `null` or blank, it defaults to `https://appleid.apple.com`.
- If `jwksUri` is `null` or blank, it defaults to `https://appleid.apple.com/auth/keys`.

## Usage Example

To use this configuration, add the following to your `application.yml`:

```yaml
app:
  apple:
    issuer: https://appleid.apple.com
    audience: com.your.app.service
    jwksUri: https://appleid.apple.com/auth/keys
```

Or in `application.properties`:

```properties
app.apple.issuer=https://appleid.apple.com
app.apple.audience=com.your.app.service
app.apple.jwksUri=https://appleid.apple.com/auth/keys
```

## Dependencies

This class relies on Spring Boot's `@ConfigurationProperties` annotation, which requires the `spring-boot-starter-validation` dependency for validation support (optional but recommended).

## Notes

- The `audience` property has no default value and must be explicitly configured.
- The defaults for `issuer` and `jwksUri` are based on Apple's production endpoints.
