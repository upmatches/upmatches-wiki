# UpdateProfileRequest

The `UpdateProfileRequest` class is a Java record that serves as a Data Transfer Object (DTO) for updating user profile information. It encapsulates the data submitted by a client when modifying an existing user profile, including the user's name, preferred contact methods, and skill level selections.

This record leverages Jakarta Bean Validation annotations to enforce constraints on the input data, ensuring that the request payload meets the application's requirements before processing.

## Record Definition

```java
public record UpdateProfileRequest(
    @Size(max = UpdateProfileRequest.MAX_NAME_LENGTH)
    String name,

    @Size(max = UpdateProfileRequest.MAX_CONTACT_METHODS)
    List<ContactMethod> contactMethods,

    @Valid
    @Size(max = UpdateProfileRequest.MAX_SKILL_LEVELS)
    List<SkillLevelSelection> skillLevels
)
```

## Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `name` | `String` | `@Size(max = 200)` | The user's display name. Maximum length is 200 characters. |
| `contactMethods` | `List<ContactMethod>` | `@Size(max = 10)` | A list of contact methods (e.g., email, phone, social media). Maximum of 10 items. |
| `skillLevels` | `List<SkillLevelSelection>` | `@Valid`, `@Size(max = 50)` | A list of skill level selections. Each item is validated recursively via `@Valid`. Maximum of 50 items. |

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `MAX_NAME_LENGTH` | `200` | Maximum allowed length for the `name` field. |
| `MAX_CONTACT_METHODS` | `10` | Maximum number of contact methods allowed. |
| `MAX_SKILL_LEVELS` | `50` | Maximum number of skill level selections allowed. |

## Usage Example

```java
// Creating an update profile request
UpdateProfileRequest request = new UpdateProfileRequest(
    "John Doe",
    List.of(new ContactMethod("email", "john@example.com")),
    List.of(new SkillLevelSelection("Java", 5))
);
```

## Validation Behavior

- The `name` field is optional but, if provided, must not exceed 200 characters.
- The `contactMethods` list is optional but, if provided, must contain at most 10 items.
- The `skillLevels` list is optional but, if provided, must contain at most 50 items. Each item in the list is validated using the `@Valid` annotation, which triggers validation on the `SkillLevelSelection` object's own constraints.

## Related Classes

- `ContactMethod` - Represents a single contact method (e.g., email, phone).
- `SkillLevelSelection` - Represents a skill and its associated proficiency level.
