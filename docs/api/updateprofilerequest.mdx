## Overview

The `UpdateProfileRequest` class is a Java record used to encapsulate data for updating a user's profile in the application. It is part of the `com.upmatches.app.features.user.requests` package. This class utilizes Java's record feature to provide an immutable data structure with built-in validation constraints.

## Purpose

The primary purpose of the `UpdateProfileRequest` class is to serve as a data transfer object (DTO) for user profile updates. It ensures that the data provided for updating a profile adheres to specified constraints, such as maximum lengths for the name and lists of contact methods and skill levels.

## Public Methods

Since `UpdateProfileRequest` is a record, it implicitly provides a constructor and accessor methods for its fields. Below is a description of the fields and their constraints:

### Fields

| Field Name      | Type                              | Description                                                                 | Constraints                                      |
|-----------------|-----------------------------------|-----------------------------------------------------------------------------|--------------------------------------------------|
| `name`          | `String`                          | The name of the user.                                                       | Maximum length of 200 characters.                |
| `contactMethods`| `List<ContactMethod>`             | A list of contact methods associated with the user.                         | Maximum of 10 contact methods.                   |
| `skillLevels`   | `List<SkillLevelSelection>`       | A list of skill levels selected by the user.                                | Maximum of 50 skill levels.                      |

### Static Constants

| Constant Name           | Type  | Description                                      |
|-------------------------|-------|--------------------------------------------------|
| `MAX_NAME_LENGTH`       | `int` | The maximum allowed length for the `name` field. |
| `MAX_CONTACT_METHODS`   | `int` | The maximum number of contact methods allowed.   |
| `MAX_SKILL_LEVELS`      | `int` | The maximum number of skill levels allowed.      |

## Usage

The `UpdateProfileRequest` class is typically used in scenarios where a user needs to update their profile information. The validation annotations ensure that the data adheres to the specified constraints before processing. This helps maintain data integrity and prevents errors related to invalid input.
