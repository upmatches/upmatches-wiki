# UpdateProfileRequest

The `UpdateProfileRequest` class is a Java record used to encapsulate the data required for updating a user's profile in the UpMatches application. It leverages Jakarta Bean Validation annotations to enforce constraints on the input data, ensuring that the profile update request is valid before processing.

## Purpose

This record serves as a Data Transfer Object (DTO) for profile update operations. It defines the structure and validation rules for the fields that can be modified in a user's profile, including:
- The user's display name
- A list of contact methods (e.g., email, phone)
- A list of skill level selections

## Record Definition

```java
public record UpdateProfileRequest(
    @Size(max = UpdateProfileRequest.MAX_NAME_LENGTH)
    String name,

    @Size(max = UpdateProfileRequest.MAX_CONTACT_METHODS)
    List<ContactMethod> contactMethods,

    @Valid
    @Size(max = UpdateProfileRequest.MAX_SKILL_LEVELS)
    List<SkillLevelSelection> skillLevels
)
```

## Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `name` | `String` | `@Size(max = 200)` | The user's display name. Maximum length is 200 characters. |
| `contactMethods` | `List<ContactMethod>` | `@Size(max = 10)` | A list of contact methods. Maximum of 10 items. |
| `skillLevels` | `List<SkillLevelSelection>` | `@Valid` + `@Size(max = 50)` | A list of skill level selections. Each item is validated recursively. Maximum of 50 items. |

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `MAX_NAME_LENGTH` | `200` | Maximum allowed length for the `name` field. |
| `MAX_CONTACT_METHODS` | `10` | Maximum number of contact methods allowed. |
| `MAX_SKILL_LEVELS` | `50` | Maximum number of skill level selections allowed. |

## Usage Example

```java
// Creating a valid update profile request
UpdateProfileRequest request = new UpdateProfileRequest(
    "John Doe",
    List.of(new ContactMethod("email", "john@example.com")),
    List.of(new SkillLevelSelection("Java", 5))
);
```

## Validation Notes

- The `@Valid` annotation on `skillLevels` ensures that each `SkillLevelSelection` object within the list is also validated according to its own constraints.
- All `@Size` constraints are applied to the list size (number of elements), not to individual element properties.
- The `name` field is optional (nullable) but if provided, must not exceed 200 characters.
