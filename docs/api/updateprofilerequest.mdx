# UpdateProfileRequest

The `UpdateProfileRequest` class is a Java record used to encapsulate the data required for updating a user's profile in the UpMatches application. It serves as a Data Transfer Object (DTO) for profile update operations, ensuring that incoming request data is validated before processing.

## Purpose

This record defines the structure for profile update requests, including the user's name, contact methods, and skill levels. It leverages Jakarta Bean Validation annotations to enforce constraints on the input data, such as maximum lengths and nested validation.

## Record Structure

The record is immutable and provides a compact way to define data carriers with built-in validation.

### Fields

| Field | Type | Description | Validation |
|-------|------|-------------|------------|
| `name` | `String` | The user's display name | Maximum length of 200 characters |
| `contactMethods` | `List<ContactMethod>` | List of contact methods (e.g., email, phone) | Maximum of 10 items |
| `skillLevels` | `List<SkillLevelSelection>` | List of skill level selections | Maximum of 50 items, with nested validation |

## Constants

The class defines three static constants that serve as validation boundaries:

| Constant | Value | Description |
|----------|-------|-------------|
| `MAX_NAME_LENGTH` | `200` | Maximum allowed length for the user's name |
| `MAX_CONTACT_METHODS` | `10` | Maximum number of contact methods allowed |
| `MAX_SKILL_LEVELS` | `50` | Maximum number of skill level selections allowed |

## Validation Details

- **Name Validation**: The `name` field is validated using `@Size(max = UpdateProfileRequest.MAX_NAME_LENGTH)`, ensuring it does not exceed 200 characters.
- **Contact Methods Validation**: The `contactMethods` list is validated with `@Size(max = UpdateProfileRequest.MAX_CONTACT_METHODS)`, limiting it to a maximum of 10 entries.
- **Skill Levels Validation**: The `skillLevels` list is validated with both `@Valid` and `@Size(max = UpdateProfileRequest.MAX_SKILL_LEVELS)`. The `@Valid` annotation triggers cascading validation on each `SkillLevelSelection` object within the list, while the `@Size` constraint limits the list to 50 items.

## Usage Example

```java
// Creating a valid UpdateProfileRequest
UpdateProfileRequest request = new UpdateProfileRequest(
    "John Doe",
    List.of(new ContactMethod("email", "john@example.com")),
    List.of(new SkillLevelSelection("Java", 5))
);
```

## Dependencies

- **Jakarta Validation API**: Provides the `@Size` and `@Valid` annotations for input validation.
- **ContactMethod**: A separate class representing a single contact method (not shown in this file).
- **SkillLevelSelection**: A separate class representing a skill level selection (not shown in this file).
