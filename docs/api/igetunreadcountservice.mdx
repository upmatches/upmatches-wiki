# IGetUnreadCountService Interface

## Purpose

The `IGetUnreadCountService` interface defines a contract for retrieving the total number of unread notifications for the current user. It is a sealed interface, meaning only the explicitly permitted class `GetUnreadCountService` can implement it. This design enforces a single, controlled implementation, promoting encapsulation and preventing unauthorized extensions.

This interface is part of the notification feature within the `com.upmatches.app` application and is used to obtain an `UnreadCountResponse` object that encapsulates the unread count data.

## Interface Definition

```java
package com.upmatches.app.features.notification.services;

import com.upmatches.app.features.notification.responses.UnreadCountResponse;

public sealed interface IGetUnreadCountService permits GetUnreadCountService {

    UnreadCountResponse execute();

}
```

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute()` | `UnreadCountResponse` | Executes the service to retrieve the current user's unread notification count. Returns an `UnreadCountResponse` object containing the count. |

## Permitted Implementations

The following class is the only permitted implementation of this sealed interface:

- `GetUnreadCountService`

## Usage Example

```java
// Assuming dependency injection provides the implementation
IGetUnreadCountService unreadCountService = new GetUnreadCountService();
UnreadCountResponse response = unreadCountService.execute();
int unreadCount = response.getUnreadCount(); // Example method, adjust based on actual response class
```

- **Implementation**: `GetUnreadCountService` (located in the same package)
