# IGetUnreadCountService Interface

## Purpose

The `IGetUnreadCountService` interface defines a contract for retrieving the count of unread notifications for the current user. It is a **sealed interface**, meaning only the explicitly permitted implementation (`GetUnreadCountService`) can implement it. This design enforces a strict, single-implementation pattern, ensuring that the unread count retrieval logic is centralized and cannot be extended by unauthorized classes.

## Interface Definition

```java
package com.upmatches.app.features.notification.services;

import com.upmatches.app.features.notification.responses.UnreadCountResponse;

public sealed interface IGetUnreadCountService permits GetUnreadCountService {

    UnreadCountResponse execute();

}
```

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute()` | `UnreadCountResponse` | Executes the operation to retrieve the current user's unread notification count. Returns a response object containing the unread count data. |

## Usage Notes

- The interface is **sealed** to `GetUnreadCountService`, which is the only permitted implementation.
- The `execute()` method is the single entry point for obtaining the unread count.
- The returned `UnreadCountResponse` object is expected to contain at least the unread count value, and potentially additional metadata (e.g., total count, timestamp).
- This interface follows a **command pattern** where the execution logic is encapsulated in the implementing class.

## Example Implementation (Conceptual)

```java
    @Override
    public UnreadCountResponse execute() {
        // Logic to fetch unread count from database or cache
        int unreadCount = fetchUnreadCount();
        return new UnreadCountResponse(unreadCount);
    }
    
    private int fetchUnreadCount() {
        // Implementation details
        return 0;
    }
}
```
