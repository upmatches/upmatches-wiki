# IGetUnreadCountService Interface

## Purpose

The `IGetUnreadCountService` interface defines a contract for retrieving the total number of unread notifications for the current user. It is a sealed interface, meaning only the explicitly permitted implementing class (`GetUnreadCountService`) can implement it. This design enforces a strict, single-implementation pattern, ensuring that the unread count retrieval logic is centralized and cannot be extended by unauthorized classes.

## Interface Definition

```java
package com.upmatches.app.features.notification.services;

import com.upmatches.app.features.notification.responses.UnreadCountResponse;

public sealed interface IGetUnreadCountService permits GetUnreadCountService {

    UnreadCountResponse execute();

}
```

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute()` | `UnreadCountResponse` | Executes the service to retrieve the current user's unread notification count. Returns a response object containing the unread count data. |

## Usage Notes

- The interface is **sealed** with the `permits` clause, restricting implementation to `GetUnreadCountService` only.
- The `execute()` method is the single entry point for obtaining the unread count.
- The returned `UnreadCountResponse` object is expected to contain at least the unread count value, though its exact structure is defined in the `com.upmatches.app.features.notification.responses` package.
