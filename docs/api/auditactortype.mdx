# AuditActorType

The `AuditActorType` enum defines the possible types of actors that can perform actions within the audit system. It is used to categorize who or what initiated an auditable event, enabling clear tracking and accountability in audit logs.

## Purpose

This enum provides a standardized way to identify the origin of an audit event. By classifying actors into distinct types, the system can differentiate between actions performed by authenticated users, automated system processes, and unauthenticated visitors.

## Enum Constants

| Constant    | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `USER`      | Represents an action performed by an authenticated user.                    |
| `SYSTEM`    | Represents an action performed by the system itself (e.g., scheduled jobs). |
| `ANONYMOUS` | Represents an action performed by an unauthenticated or anonymous visitor.  |

## Usage

The `AuditActorType` enum is typically used in conjunction with audit event classes to record the type of actor responsible for a given action. For example:

```java
AuditEvent event = new AuditEvent();
event.setActorType(AuditActorType.USER);
event.setActorId("user123");
```

This allows the audit system to filter, search, and report on events based on the actor type, providing valuable insights into system usage and security.
