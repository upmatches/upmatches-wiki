# AuditActorType

The `AuditActorType` enum defines the possible types of actors that can perform actions within the audit system. It is used to categorize who or what initiated an auditable event, providing clarity and traceability in audit logs.

## Purpose

This enum is part of the audit module and helps distinguish between actions performed by:
- **Authenticated users** (e.g., a logged-in user modifying their profile)
- **The system itself** (e.g., automated background jobs or scheduled tasks)
- **Anonymous users** (e.g., unauthenticated visitors accessing public endpoints)

By classifying actors, the system can apply different audit policies, filtering, or reporting logic based on the actor type.

## Enum Values

| Value       | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `USER`      | Represents an authenticated user who performed an action.                   |
| `SYSTEM`    | Represents an automated system process or internal operation.               |
| `ANONYMOUS` | Represents an unauthenticated or unidentified actor.                        |

## Usage Example

```java
AuditActorType actorType = AuditActorType.USER;

switch (actorType) {
    case USER:
        // Handle user-initiated action
        break;
    case SYSTEM:
        // Handle system-initiated action
        break;
    case ANONYMOUS:
        // Handle anonymous action
        break;
}
```

## Related Components

- **AuditLog** – The entity that stores audit records, typically includes an `AuditActorType` field.
- **AuditService** – The service layer that creates audit entries and uses this enum to categorize events.

## Notes

- This enum is immutable and thread-safe by design.
- New actor types can be added in the future if the system requires additional categories (e.g., `THIRD_PARTY`).
