## Overview

The `AuditActorType` enum is part of the `com.upmatches.app.features.audit.enums` package. It is used to categorize the type of actor involved in an audit event within the application. This classification helps in identifying the source of actions or changes in the system, which is crucial for maintaining security and accountability.

## Enum Constants

The `AuditActorType` enum defines the following constants:

| Constant   | Description                                                                 |
|------------|-----------------------------------------------------------------------------|
| `USER`     | Represents an authenticated user who performs actions within the application.|
| `SYSTEM`   | Represents automated processes or system-level actions that occur without direct user intervention.|
| `ANONYMOUS`| Represents actions performed by an unauthenticated user or an unknown source. |

## Usage

The `AuditActorType` enum can be used in logging, auditing, and monitoring features to track and record the origin of actions within the application. By distinguishing between different actor types, developers and system administrators can better understand and manage the flow of operations in the system.
