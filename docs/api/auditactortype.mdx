# AuditActorType

The `AuditActorType` enum defines the possible types of actors that can perform actions within the audit system. It is used to categorize who or what initiated an auditable event, enabling clear tracking and accountability in the application's audit trail.

## Purpose

This enum provides a standardized way to identify the origin of an auditable action. By classifying actors into distinct types, the system can differentiate between actions performed by authenticated users, automated system processes, and unauthenticated visitors. This classification is essential for security auditing, compliance, and debugging.

## Enum Constants

| Constant    | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `USER`      | Represents an action performed by an authenticated user of the application. |
| `SYSTEM`    | Represents an action performed by the system itself (e.g., scheduled tasks, background jobs). |
| `ANONYMOUS` | Represents an action performed by an unauthenticated or anonymous visitor.  |

## Usage

This enum is typically used as a field in audit log entities or event objects to record the type of actor that triggered the event. For example:

```java
AuditLogEntry entry = new AuditLogEntry();
entry.setActorType(AuditActorType.USER);
entry.setActorId(user.getId());
entry.setAction("LOGIN");
```
