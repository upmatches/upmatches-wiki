## Purpose

The `AuditActorType` enum is part of the `com.upmatches.app.features.audit.enums` package. It is used to define the different types of actors that can be involved in an audit event within the application. This enum helps in categorizing the source of actions or events for auditing purposes, which can be crucial for tracking, logging, and security analysis.

## Enum Constants

The `AuditActorType` enum defines the following constants:

<Tabs>
<TabItem value="USER" label="USER" default>

Represents an actor that is a user of the system. This type is used when the action is performed by an authenticated user.

</TabItem>
<TabItem value="SYSTEM" label="SYSTEM">

Represents an actor that is the system itself. This type is used when the action is performed automatically by the system without direct user intervention.

</TabItem>
<TabItem value="ANONYMOUS" label="ANONYMOUS">

Represents an actor that is not authenticated or identified. This type is used when the action is performed by an unknown or unauthenticated entity.

</TabItem>
</Tabs>
