# IAuthSessionStore Interface

The `IAuthSessionStore` interface defines the contract for managing authentication sessions in the UpMatches application. It provides a sealed interface pattern that restricts implementation to only the `AuthSessionStore` class, ensuring controlled and secure session management.

## Purpose

This interface serves as the abstraction layer for storing, retrieving, and managing authentication session data. It is designed to handle OAuth-like authentication flows where a state parameter is used to track and validate authentication requests across different platforms.

## Interface Definition

```java
public sealed interface IAuthSessionStore permits AuthSessionStore
```

The interface uses Java's sealed class feature (introduced in Java 17) to restrict implementation to only the `AuthSessionStore` class. This design pattern ensures:
- **Controlled implementation**: Only the permitted class can implement this interface
- **Security**: Prevents unauthorized implementations that could compromise session management
- **Maintainability**: Clear hierarchy and limited extension points

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `store(String state, AuthSession session)` | Stores an authentication session associated with a state identifier | `state` - Unique identifier for the authentication request<br/>`session` - The authentication session data to store | `void` |
| `retrieveAndRemove(String state)` | Retrieves and removes an authentication session by its state identifier | `state` - Unique identifier for the authentication request | `AuthSession` - The retrieved session data |
| `getPlatform(String state)` | Retrieves the platform identifier associated with a given state | `state` - Unique identifier for the authentication request | `String` - Platform identifier (e.g., "google", "facebook") |

## Usage Example

```java
// Store a new authentication session
authSessionStore.store("state_abc123", new AuthSession("user@example.com", "google"));

// Retrieve and remove the session after authentication
AuthSession session = authSessionStore.retrieveAndRemove("state_abc123");

// Get the platform for a specific state
String platform = authSessionStore.getPlatform("state_abc123");
```

## Implementation Notes

- The `store` method should handle concurrent access safely, as multiple authentication requests may occur simultaneously
- The `retrieveAndRemove` method should be atomic to prevent race conditions where the same state could be retrieved multiple times
- The `getPlatform` method should return the platform identifier without modifying the stored session data
- State values should be unique and cryptographically random to prevent session hijacking

## Related Components

- **AuthSessionStore**: The sole implementing class that provides the actual storage mechanism
- **AuthSession**: The data model representing an authentication session
- **AuthService**: The service layer that utilizes this interface for authentication workflows
