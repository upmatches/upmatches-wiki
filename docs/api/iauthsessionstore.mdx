# IAuthSessionStore Interface

The `IAuthSessionStore` interface defines the contract for managing authentication sessions in the UpMatches application. It provides a sealed interface pattern that restricts implementation to only the `AuthSessionStore` class, ensuring controlled and secure session management.

## Purpose

This interface serves as the abstraction layer for storing, retrieving, and managing authentication session data. It is designed to handle OAuth-like authentication flows where a state parameter is used to track and validate authentication requests. The interface provides three core operations:

- **Store**: Persist a new authentication session associated with a state identifier
- **Retrieve and Remove**: Atomically fetch and delete a session by its state identifier
- **Get Platform**: Query the platform type associated with a given state

## Interface Definition

```java
public sealed interface IAuthSessionStore permits AuthSessionStore {
    void store(String state, AuthSession session);
    AuthSession retrieveAndRemove(String state);
    String getPlatform(String state);
}
```

## Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `store` | `String state` - The unique state identifier for the authentication session<br/>`AuthSession session` - The session data to store | `void` | Persists an authentication session associated with the given state identifier. This is typically called at the beginning of an authentication flow. |
| `retrieveAndRemove` | `String state` - The state identifier of the session to retrieve and delete | `AuthSession` | Atomically retrieves and removes the authentication session associated with the given state. This ensures that each state can only be used once, preventing replay attacks. Returns `null` if no session exists for the given state. |
| `getPlatform` | `String state` - The state identifier to query | `String` | Returns the platform identifier (e.g., "google", "facebook") associated with the given state. This is useful for determining which authentication provider was used to initiate the session. |

## Implementation Details

The interface uses Java's `sealed` keyword, which means only the `AuthSessionStore` class (located in the same package) is permitted to implement this interface. This design choice provides:

- **Controlled implementation**: Only one class can implement this interface, ensuring consistent behavior across the application
- **Security**: Prevents unauthorized implementations that could compromise session management
- **Maintainability**: Makes it clear where all session storage logic resides

## Usage Example

```java
// Store a new session
authSessionStore.store("abc123", new AuthSession(userId, "google"));

// Retrieve and remove the session (e.g., after OAuth callback)
AuthSession session = authSessionStore.retrieveAndRemove("abc123");

// Get the platform for a state
String platform = authSessionStore.getPlatform("abc123");
```
