# IAuthSessionStore Interface

The `IAuthSessionStore` interface defines the contract for managing authentication sessions in the UpMatches application. It provides a sealed interface pattern that restricts implementation to only the `AuthSessionStore` class, ensuring type safety and controlled extensibility.

This interface is part of the authentication services layer and handles the lifecycle of authentication sessions, including storing, retrieving, and removing session data associated with a state parameter.

## Interface Definition

```java
public sealed interface IAuthSessionStore permits AuthSessionStore
```

The interface is declared as `sealed`, meaning only the specified class `AuthSessionStore` can implement it. This design pattern provides:
- **Controlled inheritance**: Only authorized implementations are allowed
- **Enhanced security**: Prevents unauthorized session store implementations
- **Compile-time safety**: The compiler enforces the permitted implementations

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `store` | Stores an authentication session associated with a state identifier | `String state` - The state identifier for the session<br/>`AuthSession session` - The authentication session object to store | `void` |
| `retrieveAndRemove` | Retrieves and removes an authentication session by its state identifier | `String state` - The state identifier of the session to retrieve | `AuthSession` - The retrieved authentication session, or `null` if not found |
| `getPlatform` | Retrieves the platform identifier associated with a given state | `String state` - The state identifier to look up | `String` - The platform identifier associated with the state |

## Usage Example

```java
// Example implementation usage
IAuthSessionStore sessionStore = new AuthSessionStore();

// Store a new session
AuthSession session = new AuthSession(userId, token, platform);
sessionStore.store("state123", session);

// Retrieve and remove the session
AuthSession retrievedSession = sessionStore.retrieveAndRemove("state123");

// Get platform information
String platform = sessionStore.getPlatform("state123");
```

## Implementation Notes

- The `store` method should handle cases where a session already exists for the given state
- The `retrieveAndRemove` method atomically retrieves and removes the session to prevent duplicate processing
- The `getPlatform` method should return the platform identifier without modifying the stored session
- All implementations must handle `null` state parameters appropriately

## Related Components

- **AuthSessionStore**: The sole permitted implementation of this interface
- **AuthSession**: The model class representing an authentication session
- **Auth Services**: The service layer that utilizes this interface for session management
