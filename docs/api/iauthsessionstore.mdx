## Purpose

The `IAuthSessionStore` interface is part of the `com.upmatches.app.features.auth.services` package and defines a contract for managing authentication sessions. It is a sealed interface, meaning it restricts which classes can implement it, specifically permitting the `AuthSessionStore` class. This interface is crucial for handling the storage, retrieval, and management of authentication sessions within an application.

## Public Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `store` | `String state`, `AuthSession session` | `void` | Stores an `AuthSession` object associated with a specific state. |
| `retrieveAndRemove` | `String state` | `AuthSession` | Retrieves and removes the `AuthSession` associated with the given state. |
| `getPlatform` | `String state` | `String` | Returns the platform information associated with the given state. |

This interface provides essential methods for session management, ensuring that authentication sessions can be stored, retrieved, and managed efficiently.
