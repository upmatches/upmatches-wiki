## Purpose

The `RecordAuditEventService` class is a service component in a Java application responsible for recording audit events. It interacts with the `AuditEventRepository` to persist audit events and logs the events for auditing purposes. This service ensures that each audit event is recorded in a new transaction, providing a reliable mechanism for tracking actions performed by users or systems.

## Public Methods

### `record`

Records an audit event based on the provided `AuditEventRequest`.

| Parameter          | Type                  | Description                                      |
|--------------------|-----------------------|--------------------------------------------------|
| `request`          | `AuditEventRequest`   | The request object containing audit event details.|

| Return Type        | Description           |
|--------------------|-----------------------|
| `void`             | This method does not return a value.|

### Method Details

- **Transactional Behavior**: The `record` method is annotated with `@Transactional(propagation = Propagation.REQUIRES_NEW)`, ensuring that each audit event is recorded in a separate transaction. This isolation helps maintain data integrity and consistency.
  
- **Error Handling**: If an error occurs during the recording process, the method logs an error message using SLF4J logging framework, detailing the action, actor ID, and the exception message.

- **Logging**: The `emitLog` method constructs a log entry with various fields from the `AuditEventRequest` and logs it using a dedicated audit logger. If JSON processing fails, it falls back to logging the raw fields map.

## Dependencies

- **`AuditEventRepository`**: Used to persist `AuditEvent` entities.
- **`ObjectMapper`**: Utilized for converting log fields into a JSON string format.
- **`ServiceOperationExecutor`**: Executes the save operation and handles exceptions.
- **SLF4J Logger**: Provides logging capabilities for audit and error logs.

This service is a critical component for maintaining an audit trail within the application, ensuring that all significant actions are recorded and can be reviewed for compliance and security purposes.
