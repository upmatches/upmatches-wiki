# RecordAuditEventService

The `RecordAuditEventService` is a Spring service class responsible for recording audit events in the application. It implements the `IRecordAuditEventService` interface and provides a transactional mechanism to persist audit events to the database while simultaneously emitting structured log entries for monitoring and debugging purposes.

## Purpose

This service serves as the central audit event recording mechanism, ensuring that all significant actions within the application are captured with relevant metadata. It handles the complete lifecycle of an audit event:

- **Persistence**: Saves audit events to the database using `AuditEventRepository`
- **Logging**: Emits structured JSON logs to a dedicated audit logger for real-time monitoring
- **Error Handling**: Gracefully handles failures without disrupting the main application flow

## Public Methods

### `record(AuditEventRequest request)`

Records an audit event by persisting it to the database and emitting a structured log entry.

| Aspect | Details |
|--------|---------|
| **Annotation** | `@Override`, `@Transactional(propagation = Propagation.REQUIRES_NEW)` |
| **Parameters** | `request` - `AuditEventRequest` containing all audit event details |
| **Return Type** | `void` |
| **Behavior** | Creates an `AuditEvent` entity from the request, saves it to the database, and logs the event as structured JSON |

#### Method Flow

1. **Build Event**: Converts the `AuditEventRequest` into an `AuditEvent` entity using the `buildEvent()` method
2. **Persist Event**: Saves the event to the database using `ServiceOperationExecutor.execute()` with `OperationStatus.SAVE`
3. **Emit Log**: Calls `emitLog()` to write a structured JSON log entry to the dedicated audit logger
4. **Error Handling**: Catches any `RuntimeException` and logs the failure without propagating the exception

## Private Methods

### `buildEvent(AuditEventRequest request)`

Constructs an `AuditEvent` entity from the provided request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AuditEventRequest` | The audit event request containing all necessary data |
| **Returns** | `AuditEvent` | A new audit event entity ready for persistence |

### `emitLog(AuditEventRequest request)`

Emits a structured JSON log entry to the dedicated audit logger.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AuditEventRequest` | The audit event request containing log data |
| **Behavior** | Builds a `LinkedHashMap` with audit fields and serializes it to JSON using `ObjectMapper`. Falls back to direct map logging if JSON serialization fails |

## Logged Fields

The following fields are included in the structured audit log:

| Field | Source | Description |
|-------|--------|-------------|
| `audit` | Constant `true` | Identifies this as an audit log entry |
| `action` | `request.action()` | The action being audited |
| `category` | `request.category().name()` | Category of the audit event |
| `outcome` | `request.outcome().name()` | Outcome status of the action |
| `actorId` | `request.actorId()` | Identifier of the user/system performing the action |
| `actorType` | `request.actorType().name()` | Type of actor (e.g., USER, SYSTEM) |
| `resourceType` | `request.resourceType()` | Type of resource being acted upon |
| `resourceId` | `request.resourceId()` | Identifier of the resource |
| `correlationId` | `request.correlationId()` | Correlation ID for tracing |
| `ipAddress` | `request.ipAddress()` | IP address of the requester |
| `errorCode` | `request.errorCode()` | Error code if the action failed |

## Error Handling

The service implements a fail-safe approach to audit recording:

- **Database Failures**: Caught and logged without throwing exceptions to the caller
- **Logging Failures**: Falls back to logging the map directly if JSON serialization fails
- **Transaction Isolation**: Uses `Propagation.REQUIRES_NEW` to ensure audit events are committed independently of the main transaction
