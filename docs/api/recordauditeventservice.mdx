# RecordAuditEventService

The `RecordAuditEventService` is a Spring service class responsible for recording audit events in the application. It implements the `IRecordAuditEventService` interface and provides a transactional mechanism to persist audit events to the database while simultaneously emitting structured log entries for monitoring and debugging purposes.

## Purpose

This service serves as the central audit event recording component that:

- Persists audit events to the database using `AuditEventRepository`
- Emits structured JSON log entries to a dedicated "AUDIT" logger
- Handles failures gracefully by logging errors without disrupting the main application flow
- Uses a new transaction (`REQUIRES_NEW`) to ensure audit events are recorded independently of the calling transaction

| Dependency | Type | Description |

| `AuditEventRepository` | Constructor Injection | Repository for persisting audit events |
| `ObjectMapper` | Constructor Injection | Jackson's ObjectMapper for JSON serialization |

## Public Methods

### `record(AuditEventRequest request)`

Records an audit event by persisting it to the database and emitting a structured log entry.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AuditEventRequest` | The audit event request containing all event details |

**Return Type:** `void`

**Transactional Behavior:** `@Transactional(propagation = Propagation.REQUIRES_NEW)` - This method runs in a new transaction, independent of any existing transaction.

**Error Handling:** If any `RuntimeException` occurs during event recording, the error is logged with details including the action, actor ID, and error message. The exception is not re-thrown, ensuring audit failures don't disrupt the main application flow.

## Internal Methods

### `buildEvent(AuditEventRequest request)`

Constructs an `AuditEvent` entity from the provided request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AuditEventRequest` | The audit event request |

**Return Type:** `AuditEvent`

### `emitLog(AuditEventRequest request)`

Emits a structured JSON log entry to the dedicated "AUDIT" logger.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AuditEventRequest` | The audit event request |

**Log Format:** The method creates a `LinkedHashMap` with the following fields and serializes it to JSON:

| Field | Source |
|-------|--------|
| `audit` | Always `true` |
| `action` | `request.action()` |
| `category` | `request.category().name()` |
| `outcome` | `request.outcome().name()` |
| `actorId` | `request.actorId()` |
| `actorType` | `request.actorType().name()` |
| `resourceType` | `request.resourceType()` |
| `resourceId` | `request.resourceId()` |
| `correlationId` | `request.correlationId()` |
| `ipAddress` | `request.ipAddress()` |
| `errorCode` | `request.errorCode()` |

**Error Handling:** If JSON serialization fails, the method falls back to logging the map directly using `AUDIT_LOG.info(LOG_FALLBACK, fields)`.

## Logging Configuration

The service uses two loggers:

| Logger Name | Purpose |
|-------------|---------|
| `AUDIT` | Dedicated logger for structured audit log entries |
| `RecordAuditEventService` | Application logger for error and debug messages |

## Usage Example

```java
@Autowired
private RecordAuditEventService auditEventService;

public void someBusinessMethod() {
    AuditEventRequest request = AuditEventRequest.builder()
        .actorId("user123")
        .actorType(ActorType.USER)
        .action("LOGIN")
        .category(AuditCategory.AUTHENTICATION)
        .outcome(OperationOutcome.SUCCESS)
        .resourceType("Session")
        .resourceId("session-456")
        .ipAddress("192.168.1.1")
        .userAgent("Mozilla/5.0")
        .correlationId("corr-789")
        .build();
    
    auditEventService.record(request);
}
```
