# EmailNotificationService

The `EmailNotificationService` class is a Spring service that implements the `IEmailNotificationService` interface. It is responsible for sending email notifications using the Resend email API. This service handles the complete lifecycle of sending an email notification, including recipient validation, content rendering, and error handling.

## Purpose

This service provides a robust mechanism for sending transactional emails as part of the notification system. It:
- Validates that recipients have a valid email address before attempting to send
- Gracefully handles cases where the Resend service is unavailable
- Renders rich HTML email content using the `EmailContentRenderer` utility
- Provides comprehensive logging for debugging and monitoring

| `resendProvider` | `ObjectProvider<Resend>` | Provider for lazy initialization of the Resend client instance |

## Public Methods

### `void send(Notification notification, EmailContext context)`

Sends an email notification to the recipient associated with the given notification.

| Parameter | Type | Description |
|-----------|------|-------------|
| `notification` | `Notification` | The notification entity containing recipient information, title, and message |
| `context` | `EmailContext` | Optional context data for rendering dynamic content (e.g., game URLs, additional details) |

**Behavior:**

1. **Recipient Validation**: Checks if the recipient has a valid email address. If the email is `null` or blank, the method logs a debug message and returns without sending.

2. **Service Availability**: Attempts to obtain a `Resend` instance from the provider. If the service is unavailable, it logs a debug message and returns.

3. **Content Rendering**: Uses `EmailContentRenderer` to build the HTML email content:
   - Renders a details table based on the notification type and context
   - Builds a call-to-action button if a game URL is present in the context
   - Wraps everything in a complete HTML template with the notification title and message

4. **Email Construction**: Creates a `CreateEmailOptions` object with:
   - **From**: Formatted as `"Sender Name <sender@email.com>"` using properties
   - **To**: The recipient's email address
   - **Subject**: The notification title
   - **HTML**: The rendered HTML content

5. **Sending**: Attempts to send the email via the Resend API. If sending fails, it logs a warning with the notification ID and error message.

**Return Type:** `void`

**Logging:**
- `DEBUG`: When recipient has no email or Resend is unavailable
- `WARN`: When email sending fails

## Usage Example

```java
// The service is typically injected and used in a controller or other service
@Autowired
private EmailNotificationService emailService;

// Sending a notification
Notification notification = notificationRepository.findById(123L);
EmailContext context = new EmailContext("https://example.com/game/456");
emailService.send(notification, context);
```

## Error Handling

The service employs a fail-safe approach:
- Missing recipient email: Silently skips with debug logging
- Resend service unavailable: Silently skips with debug logging
- API call failure: Logs warning but does not throw exceptions, preventing cascading failures
