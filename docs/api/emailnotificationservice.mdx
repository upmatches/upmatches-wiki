## Purpose

The `EmailNotificationService` class is a part of the notification services in the application. It is responsible for sending email notifications using the Resend service. This service ensures that notifications are sent to the correct recipients with the appropriate content, handling cases where the email service might be unavailable or the recipient's email is missing.

## Public Methods

### `send`

This method is responsible for sending an email notification based on the provided `Notification` and `EmailContext`.

| Parameter   | Type                      | Description                                                                 |
|-------------|---------------------------|-----------------------------------------------------------------------------|
| notification| `Notification`            | The notification object containing details about the recipient and message. |
| context     | `EmailContext`            | The context for the email, including additional details and game URL.       |

#### Return Type

- `void`: This method does not return any value.

#### Method Details

- **Email Check**: The method first checks if the recipient's email is available. If not, it logs a debug message and exits.
- **Service Availability**: It checks if the Resend service is available. If not, it logs a debug message and exits.
- **Email Content**: Constructs the email content using the `EmailContentRenderer` utility, which includes building a details table and a call-to-action button.
- **Email Sending**: Attempts to send the email using the Resend service. If sending fails, it logs a warning with the error message.
