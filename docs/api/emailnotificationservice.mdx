# EmailNotificationService

The `EmailNotificationService` class is a Spring service that implements the `IEmailNotificationService` interface. It is responsible for sending email notifications using the Resend email API. This service handles the complete lifecycle of email generation, from building HTML content to sending the email through the Resend client.

## Purpose

This service provides a robust mechanism for sending transactional emails as part of the notification system. It handles:
- Graceful degradation when the Resend client is unavailable
- Proper handling of recipients without email addresses
- HTML email generation with dynamic content
- Error handling and logging for failed email sends

## Dependencies

| Dependency | Description |
|------------|-------------|
| `ResendProperties` | Configuration properties for the Resend email service |
| `ObjectProvider<Resend>` | Provider for the Resend client instance |
| `EmailContentRenderer` | Utility class for building HTML email content |
| `Logger` | SLF4J logger for logging events and errors |

## Public Methods

### `send(Notification notification, EmailContext context)`

Sends an email notification to the recipient specified in the notification object.

| Parameter | Type | Description |
|-----------|------|-------------|
| `notification` | `Notification` | The notification entity containing recipient information and message details |
| `context` | `EmailContext` | Optional context object containing dynamic data for email rendering |

**Return Type:** `void`

**Behavior:**
1. Retrieves the recipient's email address from the notification
2. If the email is null or blank, logs a debug message and exits
3. Attempts to get the Resend client from the provider
4. If the Resend client is unavailable, logs a debug message and exits
5. Builds the HTML email content using `EmailContentRenderer`:
   - Generates a details table based on notification type and context
   - Creates a call-to-action button if a game URL is present
   - Wraps everything in a complete HTML template
6. Constructs the email options with sender information, recipient, subject, and HTML body
7. Sends the email through the Resend API
8. Catches and logs any exceptions during the send process

## Logging Constants

| Constant | Value | Purpose |
|----------|-------|---------|
| `LOG_NO_EMAIL` | `"Recipient {} has no email; skipping email for notification {}"` | Logged when recipient has no email address |
| `LOG_UNAVAILABLE` | `"Resend unavailable; skipping email for notification {}"` | Logged when Resend client is not available |
| `LOG_SEND_FAILED` | `"Failed to send Resend email for notification {}: {}"` | Logged when email send fails |

## Usage Example

```java
// Inject the service
@Autowired
private EmailNotificationService emailNotificationService;

// Create a notification
Notification notification = new Notification();
notification.setTitle("Welcome!");
notification.setMessage("Thank you for joining our platform");
notification.setRecipient(user);

// Create email context
EmailContext context = new EmailContext(
    "https://example.com/get-started",
    Map.of("username", "john_doe")
);

// Send the email
emailNotificationService.send(notification, context);
```

## Error Handling

The service implements defensive programming patterns:
- **Null/Empty Email:** Silently skips the email with a debug log
- **Unavailable Service:** Gracefully handles missing Resend client
- **Send Failures:** Catches exceptions and logs warnings without throwing exceptions upstream
- **Null Context:** Falls back to an empty context if none is provided

## Configuration

The service relies on `ResendProperties` for configuration, which should include:
- `fromName`: The display name for the sender
- `fromAddress`: The email address for the sender

These properties are used to construct the `From` header in the format: `"Display Name <email@example.com>"`
