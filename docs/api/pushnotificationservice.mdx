## Purpose

The `PushNotificationService` class is responsible for sending push notifications to users' devices using Firebase Cloud Messaging (FCM). It integrates with Firebase to deliver notifications to Android and iOS devices and handles the management of device tokens, including pruning invalid tokens.

## Public Methods

### `send`

Sends a push notification to the recipient's devices.

| Parameter    | Type          | Description                                   |
|--------------|---------------|-----------------------------------------------|
| notification | `Notification`| The notification object containing details such as the recipient, message, and title. |

| Return Type          | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| `PushDeliveryResult` | The result of the push delivery attempt, indicating success, failure, or unavailability. |

## Method Details

### `send(Notification notification)`

- **Purpose**: This method sends a push notification to all devices associated with the recipient of the given notification. It constructs a message with the necessary configurations for both Android and iOS platforms and attempts to send it using Firebase Messaging.
- **Process**:
  1. Retrieves the `FirebaseMessaging` instance.
  2. Fetches device tokens for the notification's recipient.
  3. Constructs the notification message with platform-specific configurations.
  4. Sends the message and processes the response to determine success or failure.
  5. Prunes invalid device tokens based on the response.

- **Error Handling**: Logs a warning if sending fails due to a `FirebaseMessagingException`.

### Private Methods

- **`resolveBadge(UUID recipientId)`**: Calculates the badge count for iOS notifications based on the number of unread notifications for the recipient.

- **`pruneInvalidTokens(BatchResponse response, List<String> tokenStrings)`**: Removes invalid device tokens from the repository based on the response from Firebase, specifically handling unregistered or invalid tokens.
