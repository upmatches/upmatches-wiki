## Purpose

The `NotificationRepository` interface is a part of the notification feature in the application. It extends the `JpaRepository` interface, providing CRUD operations for `Notification` entities identified by `UUID`. This repository interface includes custom query methods to handle notifications, such as retrieving notifications for a specific recipient, counting unread notifications, and marking notifications as read.

## Public Methods

### `findByRecipientIdOrderByCreatedAtDesc`

Retrieves a paginated list of notifications for a specific recipient, ordered by creation date in descending order.

| Parameter   | Type   | Description                          |
|-------------|--------|--------------------------------------|
| recipientId | UUID   | The unique identifier of the recipient. |
| pageable    | Pageable | The pagination information.          |

| Return Type     | Description                                      |
|-----------------|--------------------------------------------------|
| Page<Notification> | A paginated list of notifications.             |

### `countByRecipientIdAndIsReadFalse`

Counts the number of unread notifications for a specific recipient.

| Parameter   | Type   | Description                          |
|-------------|--------|--------------------------------------|
| recipientId | UUID   | The unique identifier of the recipient. |

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| long        | The count of unread notifications.               |

### `findByIdAndRecipientId`

Finds a notification by its ID and the recipient's ID.

| Parameter   | Type   | Description                          |
|-------------|--------|--------------------------------------|
| id          | UUID   | The unique identifier of the notification. |
| recipientId | UUID   | The unique identifier of the recipient. |

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| Optional<Notification> | An optional containing the notification if found. |

### `existsByRecipientIdAndTypeAndResourceId`

Checks if a notification exists for a specific recipient, type, and resource ID.

| Parameter   | Type            | Description                          |
|-------------|-----------------|--------------------------------------|
| recipientId | UUID            | The unique identifier of the recipient. |
| type        | NotificationType | The type of the notification.         |
| resourceId  | UUID            | The unique identifier of the resource. |

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| boolean     | `true` if the notification exists, otherwise `false`. |

### `markAllReadByRecipientId`

Marks all unread notifications as read for a specific recipient and sets the read timestamp.

| Parameter   | Type   | Description                          |
|-------------|--------|--------------------------------------|
| recipientId | UUID   | The unique identifier of the recipient. |
| readAt      | Instant | The timestamp when the notifications were read. |

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| int         | The number of notifications marked as read.      |
