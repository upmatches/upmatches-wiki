# NotificationRepository

The `NotificationRepository` interface provides data access methods for the `Notification` entity in the UpMatches application. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD operations and defines custom query methods for retrieving, counting, and updating notifications.

## Purpose

This repository handles all database interactions related to user notifications, including:
- Retrieving paginated notifications for a specific recipient
- Counting unread notifications
- Checking for duplicate notifications
- Marking notifications as read

## Methods

### `findByRecipientIdOrderByCreatedAtDesc`

Retrieves a paginated list of notifications for a recipient, ordered by creation time (newest first).

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipientId` | `UUID` | The ID of the notification recipient |
| `pageable` | `Pageable` | Pagination and sorting information |

**Returns:** `Page<Notification>` - A page of notifications for the recipient

### `countByRecipientIdAndIsReadFalse`

Counts the number of unread notifications for a specific recipient.

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipientId` | `UUID` | The ID of the notification recipient |

**Returns:** `long` - The count of unread notifications

### `findByIdAndRecipientId`

Finds a specific notification by its ID and recipient ID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The notification ID |
| `recipientId` | `UUID` | The recipient's user ID |

**Returns:** `Optional<Notification>` - The notification if found, empty otherwise

### `existsByRecipientIdAndTypeAndResourceId`

Checks if a notification with the given type and resource ID already exists for a recipient. This is useful for preventing duplicate notifications.

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipientId` | `UUID` | The ID of the notification recipient |
| `type` | `NotificationType` | The type of notification |
| `resourceId` | `UUID` | The ID of the related resource |

**Returns:** `boolean` - `true` if a matching notification exists, `false` otherwise

### `markAllReadByRecipientId`

Marks all unread notifications as read for a specific recipient. This method uses a bulk update query and is annotated with `@Modifying` to indicate it performs a write operation.

| Parameter | Type | Description |
|-----------|------|-------------|
| `recipientId` | `UUID` | The ID of the notification recipient |
| `readAt` | `Instant` | The timestamp when notifications were read |

**Returns:** `int` - The number of notifications updated

## Usage Example

```java
@Service
public class NotificationService {
    private final NotificationRepository notificationRepository;
    
    public NotificationService(NotificationRepository notificationRepository) {
        this.notificationRepository = notificationRepository;
    }
    
    public Page<Notification> getNotifications(UUID userId, Pageable pageable) {
        return notificationRepository.findByRecipientIdOrderByCreatedAtDesc(userId, pageable);
    }
    
    public long getUnreadCount(UUID userId) {
        return notificationRepository.countByRecipientIdAndIsReadFalse(userId);
    }
    
    @Transactional
    public int markAllAsRead(UUID userId) {
        return notificationRepository.markAllReadByRecipientId(userId, Instant.now());
    }
}
```
