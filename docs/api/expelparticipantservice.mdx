# ExpelParticipantService

## Purpose

The `ExpelParticipantService` is a Spring service responsible for handling the expulsion of a participant from a game by the game organizer. It enforces business rules such as preventing self-expulsion, validates that the participant exists and is active, and triggers appropriate audit logging and notifications.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameParticipantRepository` | Repository | Data access for game participants |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user |
| `IGameLookupService` | Service | Looks up game entities |
| `IGameAuthorizationService` | Service | Authorizes game operations |
| `ApplicationEventPublisher` | Spring | Publishes domain events for notifications |

## Public Methods

### `execute`

```java
@Transactional
@Auditable(action = "PARTICIPANT_EXPELLED", resourceType = "GAME", resourceIdExpression = "#args[0]")
public void execute(UUID gameId, UUID participantId, ExpelParticipantRequest request)
```

Expels a participant from a game. The method performs the following steps:

1. Resolves the authenticated user ID
2. Looks up the game and verifies the user is the organizer
3. Finds the participant and validates they are active and belong to the specified game
4. Prevents the organizer from expelling themselves
5. Marks the participant as having left the game
6. Persists the change
7. Publishes a notification event

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The ID of the game from which to expel the participant |
| `participantId` | `UUID` | The ID of the participant to expel |
| `request` | `ExpelParticipantRequest` | Contains the reason for expulsion |

#### Throws

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Participant not found, not active, or not part of the specified game |
| `CannotExpelSelfException` | Organizer attempts to expel themselves |
| `AuthorizationException` | User is not the organizer of the game |

## Audit Logging

The method is annotated with `@Auditable` which automatically logs the following:

- **Action**: `PARTICIPANT_EXPELLED`
- **Resource Type**: `GAME`
- **Resource ID**: The game ID (first argument)

## Notification

Upon successful expulsion, a `GameNotificationEvent` is published with:

- **Type**: `PLAYER_REMOVED_FROM_GAME`
- **Recipient**: The expelled user
- **Context**: Game ID and optional game title (derived from the game's activity name)

## Logging

The service logs the expulsion event at INFO level, including:

- Organizer ID
- Participant ID
- Expelled user ID
- Game ID
- Expulsion reason

## Usage Example

```java
@Autowired
private ExpelParticipantService expelParticipantService;

public void expelPlayer(UUID gameId, UUID participantId, String reason) {
    ExpelParticipantRequest request = new ExpelParticipantRequest(reason);
    expelParticipantService.execute(gameId, participantId, request);
}
```
