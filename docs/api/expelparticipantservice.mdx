## Purpose

The `ExpelParticipantService` class is a service component in a game management application that handles the expulsion of participants from a game. It ensures that only authorized organizers can expel participants and manages the associated business logic, including auditing and event publishing.

## Public Methods

### `execute`

Executes the expulsion of a participant from a game.

| Parameter       | Type                          | Description                                                                 |
|-----------------|-------------------------------|-----------------------------------------------------------------------------|
| `gameId`        | `UUID`                        | The unique identifier of the game from which the participant is to be expelled. |
| `participantId` | `UUID`                        | The unique identifier of the participant to be expelled.                    |
| `request`       | `ExpelParticipantRequest`     | The request object containing additional information, such as the reason for expulsion. |

#### Return Type

- `void`: This method does not return a value. It performs the operation of expelling a participant and may throw exceptions if certain conditions are not met.

## Exceptions

- `ResourceNotFoundException`: Thrown if the participant is not found in the specified game.
- `CannotExpelSelfException`: Thrown if the organizer attempts to expel themselves from the game.

## Additional Details

- **Auditing**: The method is annotated with `@Auditable`, which logs the action of expelling a participant for auditing purposes.
- **Transactional**: The method is marked with `@Transactional`, ensuring that the operation is atomic and consistent.
- **Logging**: Uses SLF4J for logging the expulsion event.
- **Event Publishing**: Publishes a `GameNotificationEvent` to notify other components of the participant's removal from the game.
