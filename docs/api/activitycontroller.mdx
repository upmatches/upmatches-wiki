# Activity Controller

The `ActivityController` class is a REST controller that handles HTTP requests for managing activities in the UpMatches application. It provides endpoints for CRUD (Create, Read, Update, Delete) operations on activities, following standard RESTful API conventions.

## Purpose

This controller serves as the entry point for all activity-related API calls. It delegates business logic to dedicated service interfaces, ensuring a clean separation of concerns between the web layer and the business logic layer. The controller handles request validation, pagination, and response formatting.

## Endpoints

### List Activities

Retrieves a paginated list of activities sorted by name.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/activities` | Returns a paginated list of activities |

**Query Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | Integer | 0 | Page number (zero-indexed) |
| `size` | Integer | 20 | Number of items per page |

**Response:** `200 OK` - Returns a `PagedResponse<ActivityResponse>` wrapped in an `ApiResponse`.

### Get Activity

Retrieves a single activity by its unique identifier.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/activities/{id}` | Returns a specific activity |

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | The unique identifier of the activity |

**Response:** `200 OK` - Returns an `ActivityResponse` wrapped in an `ApiResponse`.

### Create Activity

Creates a new activity.

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/v1/activities` | Creates a new activity |

**Request Body:** `CreateActivityRequest` (validated)

**Response:** `201 Created` - Returns the created `ActivityResponse` wrapped in an `ApiResponse`.

### Update Activity

Updates an existing activity.

| Method | Path | Description |
|--------|------|-------------|
| PUT | `/api/v1/activities/{id}` | Updates an existing activity |

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | The unique identifier of the activity to update |

**Request Body:** `UpdateActivityRequest` (validated)

**Response:** `200 OK` - Returns the updated `ActivityResponse` wrapped in an `ApiResponse`.

### Delete Activity

Deletes an activity.

| Method | Path | Description |
|--------|------|-------------|
| DELETE | `/api/v1/activities/{id}` | Deletes an activity |

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | The unique identifier of the activity to delete |

**Response:** `204 No Content` - No response body.

## Dependencies

The controller depends on the following service interfaces:

- `IListActivitiesService` - Handles paginated listing of activities
- `IGetActivityService` - Handles retrieval of a single activity
- `ICreateActivityService` - Handles creation of new activities
- `IUpdateActivityService` - Handles updating existing activities
- `IDeleteActivityService` - Handles deletion of activities

## Validation

The controller uses:
- `@Valid` annotation on request bodies for Jakarta Bean Validation
- `@Validated` annotation at the class level for method-level validation
- `ValidationHelper.validatePaginationParameters()` for pagination parameter validation

## Error Handling

All endpoints return appropriate HTTP status codes:
- `200 OK` for successful GET and PUT operations
- `201 Created` for successful POST operations
- `204 No Content` for successful DELETE operations
- Error responses are handled by the global exception handler (not shown in this controller)
