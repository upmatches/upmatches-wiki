## Purpose

The `ActivityController` class is a REST controller in a Spring Boot application that manages activities. It provides endpoints to list, retrieve, create, update, and delete activities. This controller interacts with various services to perform these operations and returns appropriate HTTP responses.

## Public Methods

### listActivities

Retrieves a paginated list of activities.

| Parameter | Type    | Description                             |
|-----------|---------|-----------------------------------------|
| page      | Integer | The page number to retrieve (default 0).|
| size      | Integer | The size of the page to retrieve (default 20).|
| request   | HttpServletRequest | The HTTP request object.     |

**Returns:** `ResponseEntity<ApiResponse<PagedResponse<ActivityResponse>>>` - A response entity containing a paged response of activities.

### getActivity

Retrieves a specific activity by its ID.

| Parameter | Type | Description                |
|-----------|------|----------------------------|
| id        | UUID | The unique identifier of the activity. |
| request   | HttpServletRequest | The HTTP request object. |

**Returns:** `ResponseEntity<ApiResponse<ActivityResponse>>` - A response entity containing the activity details.

### createActivity

Creates a new activity.

| Parameter | Type                  | Description                |
|-----------|-----------------------|----------------------------|
| body      | CreateActivityRequest | The request body containing activity details. |
| request   | HttpServletRequest    | The HTTP request object.   |

**Returns:** `ResponseEntity<ApiResponse<ActivityResponse>>` - A response entity containing the created activity details.

### updateActivity

Updates an existing activity.

| Parameter | Type                  | Description                |
|-----------|-----------------------|----------------------------|
| id        | UUID                  | The unique identifier of the activity. |
| body      | UpdateActivityRequest | The request body containing updated activity details. |
| request   | HttpServletRequest    | The HTTP request object.   |

**Returns:** `ResponseEntity<ApiResponse<ActivityResponse>>` - A response entity containing the updated activity details.

### deleteActivity

Deletes an activity by its ID.

| Parameter | Type | Description                |
|-----------|------|----------------------------|
| id        | UUID | The unique identifier of the activity. |

**Returns:** `ResponseEntity<Void>` - A response entity with no content, indicating successful deletion.
