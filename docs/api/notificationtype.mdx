# NotificationType Enum

The `NotificationType` enum defines the various types of notifications that can be sent within the application. It is part of the notification feature module and is used to categorize and handle different notification events related to game sessions and player activities.

## Purpose

This enum provides a standardized set of notification types that the system can generate. Each constant represents a specific event or action that triggers a notification to be sent to relevant users. The enum is used throughout the notification system to determine the content, recipients, and handling logic for each notification type.

## Enum Constants

| Constant | Description |
|----------|-------------|
| `PLAYER_JOINED` | A player has joined a game session |
| `PLAYER_LEFT` | A player has left a game session |
| `PLAYER_WARNING_MISMATCH` | A player has been flagged for a mismatch warning |
| `GAME_FULL` | The game session has reached its maximum capacity |
| `GAME_REMINDER_3_DAYS` | Reminder notification sent 3 days before the game |
| `GAME_REMINDER_1_DAY` | Reminder notification sent 1 day before the game |
| `GAME_UPDATED` | The game session details have been updated |
| `GAME_REMOVED` | The game session has been removed or cancelled |
| `PLAYER_REMOVED_FROM_GAME` | A player has been removed from a game session |

## Usage

The `NotificationType` enum is typically used in conjunction with a notification service or manager class to determine the appropriate action when a notification event occurs. For example:

```java
NotificationType type = NotificationType.PLAYER_JOINED;

switch (type) {
    case PLAYER_JOINED:
        // Handle player joined notification
        break;
    case PLAYER_LEFT:
        // Handle player left notification
        break;
    // ... handle other types
}
```
