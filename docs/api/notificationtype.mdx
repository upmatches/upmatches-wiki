## Purpose

The `NotificationType` enum is part of the `com.upmatches.app.features.notification.enums` package. It defines a set of constants representing different types of notifications that can be used within the application. These notifications are likely related to player activities and game events, providing a standardized way to handle various notification scenarios.

## Enum Constants

The `NotificationType` enum includes the following constants:

| Constant                  | Description                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| `PLAYER_JOINED`           | Indicates that a player has joined a game or event.                         |
| `PLAYER_LEFT`             | Indicates that a player has left a game or event.                           |
| `PLAYER_WARNING_MISMATCH` | Indicates a warning related to a mismatch involving a player.               |
| `GAME_FULL`               | Indicates that a game has reached its maximum capacity of players.          |
| `GAME_REMINDER_3_DAYS`    | A reminder notification sent 3 days before a game is scheduled to occur.    |
| `GAME_REMINDER_1_DAY`     | A reminder notification sent 1 day before a game is scheduled to occur.     |
| `GAME_UPDATED`            | Indicates that the details of a game have been updated.                     |
| `GAME_REMOVED`            | Indicates that a game has been removed from the schedule.                   |
| `PLAYER_REMOVED_FROM_GAME`| Indicates that a player has been removed from a game.                       |

## Usage

This enum can be used in the application to trigger specific actions or notifications based on the type of event that occurs. By using these predefined constants, developers can ensure consistency and clarity when handling notification-related logic.
