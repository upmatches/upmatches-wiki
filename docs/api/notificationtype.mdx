## Overview

The `NotificationType` enum is part of the `com.upmatches.app.features.notification.enums` package. It defines a set of constants representing different types of notifications that can be used within the application. Enums in Java are a special type of class that represent a group of constants (unchangeable variables, like final variables).

## Enum Constants

The `NotificationType` enum includes the following constants:

- **PLAYER_JOINED**: Indicates that a player has joined.
- **PLAYER_LEFT**: Indicates that a player has left.
- **PLAYER_WARNING_MISMATCH**: Indicates a warning due to a mismatch involving a player.
- **GAME_FULL**: Indicates that a game is full.
- **GAME_REMINDER_3_DAYS**: A reminder notification for a game scheduled in 3 days.
- **GAME_REMINDER_1_DAY**: A reminder notification for a game scheduled in 1 day.
- **GAME_UPDATED**: Indicates that a game has been updated.
- **GAME_REMOVED**: Indicates that a game has been removed.
- **PLAYER_REMOVED_FROM_GAME**: Indicates that a player has been removed from a game.
