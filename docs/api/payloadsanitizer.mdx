## Purpose

The `PayloadSanitizer` class is a utility component designed to sanitize JSON payloads by masking sensitive information. It is particularly useful in applications where logging or processing sensitive data is required without exposing confidential information such as passwords, tokens, emails, and phone numbers. The class uses the Jackson library to manipulate JSON data and is implemented as a Spring component.

## Public Methods

| Method   | Parameters | Return Type | Description |
|----------|------------|-------------|-------------|
| `sanitize` | `Object payload` | `String` | Sanitizes the given payload by masking sensitive fields and truncating the result if it exceeds a certain size. Returns the sanitized JSON as a string or `null` if processing fails. |

## Method Details

### `sanitize`

- **Parameters:**
  - `payload`: An `Object` representing the JSON payload to be sanitized.

- **Return Type:** 
  - `String`: The sanitized JSON string or `null` if an error occurs during processing.

- **Description:** 
  - This method converts the input payload into a JSON tree structure, masks sensitive fields, and then converts it back to a JSON string. If the resulting JSON string exceeds the maximum allowed byte size, it truncates the string and appends a truncation indicator. The method handles exceptions related to JSON processing and returns `null` in such cases.
