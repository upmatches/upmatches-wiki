# PayloadSanitizer

The `PayloadSanitizer` class is a Spring `@Component` that provides a utility for sanitizing and redacting sensitive information from Java objects before they are logged, stored, or transmitted. It is designed to prevent accidental exposure of personally identifiable information (PII) and security credentials in audit logs, error messages, or API responses.

## Purpose

- **Redact sensitive fields**: Automatically replaces values for keys like `password`, `token`, `nric`, `secret`, and `apikey` with `***`.
- **Mask email addresses**: Partially obscures email addresses by showing only the first character and the domain (e.g., `j***@example.com`).
- **Mask phone numbers**: Shows only the last 4 digits of phone numbers (e.g., `***1234`).
- **Truncate large payloads**: Limits the output to 8 KB to prevent excessively large log entries or responses.

## Dependencies

- **Jackson**: Uses `ObjectMapper` for JSON serialization and tree manipulation.
- **Spring**: The class is annotated with `@Component` for automatic dependency injection.

## Constructor

| Constructor | Description |
|---|---|
| `PayloadSanitizer(ObjectMapper objectMapper)` | Creates a new sanitizer instance with the provided Jackson `ObjectMapper`. |

## Public Methods

### `sanitize(Object payload)`

Sanitizes the given payload object by masking sensitive fields and truncating the output if necessary.

| Parameter | Type | Description |
|---|---|---|
| `payload` | `Object` | The Java object to sanitize. Can be `null`. |

| Returns | Type | Description |
|---|---|---|
| Success | `String` | A JSON string with sensitive fields masked and truncated if over 8 KB. |
| Failure | `null` | If the payload is `null` or cannot be serialized to JSON. |

**Example usage:**

```java
@Autowired
private PayloadSanitizer sanitizer;

public void logRequest(Object requestBody) {
    String safePayload = sanitizer.sanitize(requestBody);
    log.info("Request payload: {}", safePayload);
}
```

## Internal Behavior

### Sensitive Key Detection

The following keys (case-insensitive) are fully redacted:

| Category | Keys |
|---|---|
| Authentication | `password`, `token`, `accesstoken`, `refreshtoken`, `idtoken`, `authorization` |
| Personal Identifiers | `nric`, `fin` |
| Cryptographic | `privatekey`, `secret`, `apikey` |

### Email Masking

For keys matching `email`, the value is masked to show only the first character and the domain:

- `john.doe@example.com` → `j***@example.com`
- If the email has no `@` or the local part is 1 character or less, the entire value is replaced with `***`.

### Phone Number Masking

For keys matching `phone`, `phonenumber`, or `mobile`, the value is masked to show only the last 4 digits:

- `+65 9123 4567` → `***4567`
- If the phone number is 4 characters or less, the entire value is replaced with `***`.

### Truncation

If the resulting JSON string exceeds 8 KB (8,192 bytes) in UTF-8 encoding, it is truncated to exactly 8 KB and appended with `...[truncated]`.

## Configuration

The following constants can be adjusted by modifying the class source:

| Constant | Default Value | Description |
|---|---|---|
| `MAX_PAYLOAD_BYTES` | `8 * 1024` (8 KB) | Maximum allowed payload size in bytes. |
| `PHONE_SUFFIX_LENGTH` | `4` | Number of trailing digits to preserve in phone numbers. |
| `TRUNCATED_SUFFIX` | `...[truncated]` | Suffix appended to truncated payloads. |

## Error Handling

- If the input payload is `null`, the method returns `null`.
- If serialization fails (e.g., due to circular references or unsupported types), the method returns `null` and the exception is silently caught.

## Notes

- The sanitizer works recursively on nested objects and arrays.
- Only string values are masked; non-textual values for email/phone keys are left unchanged.
- The class is thread-safe as it uses no mutable state beyond the injected `ObjectMapper`.
