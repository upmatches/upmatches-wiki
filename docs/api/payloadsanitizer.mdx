# PayloadSanitizer

The `PayloadSanitizer` class is a Spring `@Component` utility that provides a centralized mechanism for sanitizing sensitive data within JSON payloads before logging, auditing, or transmitting them. It automatically detects and masks common sensitive fields such as passwords, tokens, personally identifiable information (PII), and secrets. Additionally, it enforces a maximum payload size to prevent excessively large logs or messages.

## Purpose

- **Security**: Prevent accidental exposure of credentials, tokens, and PII in logs or audit trails.
- **Compliance**: Help meet data protection regulations (e.g., GDPR, PDPA) by masking sensitive fields.
- **Performance**: Truncate payloads that exceed a configurable byte limit to avoid memory or storage issues.

## How It Works

1. **Input**: Accepts any Java object (typically a request/response DTO or entity).
2. **Serialization**: Converts the object to a Jackson `JsonNode` tree.
3. **Masking**: Recursively traverses the tree and applies one of three masking strategies:
   - **Redact**: Replace the entire value with `***` for keys in `REDACT_KEYS`.
   - **Email Mask**: Keep the first character and domain, replace the rest with `***` (e.g., `j***@example.com`).
   - **Phone Mask**: Keep the last 4 digits, replace the rest with `***` (e.g., `***6789`).
4. **Truncation**: If the resulting JSON string exceeds 8 KB, it is truncated with a `...[truncated]` suffix.

## Public Methods

### `sanitize(Object payload)`

| Parameter | Type    | Description                                      |
|-----------|---------|--------------------------------------------------|
| `payload` | `Object`| The object to sanitize. Can be `null`.           |

| Returns  | Type    | Description                                                                 |
|----------|---------|-----------------------------------------------------------------------------|
| `String` | `String`| A JSON string with sensitive fields masked and payload truncated if needed. Returns `null` if the input is `null` or if serialization fails. |

**Example Usage:**

```java
@Autowired
private PayloadSanitizer sanitizer;

public void logRequest(SomeRequest request) {
    String safePayload = sanitizer.sanitize(request);
    log.info("Request payload: {}", safePayload);
}
```

## Configuration

The class uses the following constants, which can be adjusted as needed:

| Constant            | Value                     | Description                                                                 |
|---------------------|---------------------------|-----------------------------------------------------------------------------|
| `REDACT_KEYS`       | `password`, `token`, `accesstoken`, `refreshtoken`, `idtoken`, `authorization`, `nric`, `fin`, `privatekey`, `secret`, `apikey` | Keys whose values are completely replaced with `***`. |
| `EMAIL_KEYS`        | `email`                   | Keys whose values are partially masked (first character + `***` + domain).  |
| `PHONE_KEYS`        | `phone`, `phonenumber`, `mobile` | Keys whose values are partially masked (`***` + last 4 digits).             |
| `MAX_PAYLOAD_BYTES` | `8192` (8 KB)             | Maximum allowed JSON payload size in bytes before truncation.               |

## Masking Examples

| Original Value       | Masked Value        | Strategy |
|----------------------|---------------------|----------|
| `"mySecretPassword"` | `"***"`             | Redact   |
| `"user@example.com"` | `"u***@example.com"`| Email    |
| `"+65-9123-4567"`    | `"***4567"`         | Phone    |

## Important Notes

- **Case Insensitivity**: Key matching is case-insensitive (e.g., `Password`, `PASSWORD`, and `password` are all redacted).
- **Nested Objects**: The sanitizer recursively processes nested objects and arrays.
- **Non-Textual Values**: For email and phone keys, masking is only applied if the value is a JSON text node. Other types (e.g., numbers, booleans) are left unchanged.
- **Null Safety**: The method gracefully handles `null` inputs and serialization errors by returning `null`.
- **Thread Safety**: This class is thread-safe as it uses no mutable state beyond the injected `ObjectMapper`.

## Dependencies

- **Jackson** (`com.fasterxml.jackson.databind`): For JSON serialization and tree manipulation.
- **Spring Framework** (`org.springframework.stereotype.Component`): For dependency injection and component scanning.
