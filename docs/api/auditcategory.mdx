## Purpose

The `AuditCategory` enum is part of the `com.upmatches.app.features.audit.enums` package. It is used to categorize different types of audit actions within an application. This categorization helps in identifying and managing audit logs based on their nature, such as write operations, authentication, authorization, and sensitive read operations.

## Enum Constants

The `AuditCategory` enum defines the following constants:

| Constant        | Description                                                                 |
|-----------------|-----------------------------------------------------------------------------|
| `WRITE`         | Represents audit actions related to write operations.                       |
| `AUTH`          | Represents audit actions related to authentication processes.               |
| `AUTHZ`         | Represents audit actions related to authorization processes.                |
| `SENSITIVE_READ`| Represents audit actions related to reading sensitive information.          |

## Usage

The `AuditCategory` enum can be used to specify the category of an audit log entry. This allows for better filtering and handling of logs based on their type. For instance, you might want to apply different retention policies or alerting mechanisms depending on the category of the audit action.
