## Overview

The `IGenericService` interface defines a generic service contract for managing entities in an application. It provides methods for common operations such as retrieving, saving, updating, and deleting entities. This interface is designed to be implemented by service classes that handle specific types of entities.

## Public Methods

### `getAll`

Retrieves a paginated list of entities.

| Parameter     | Type   | Description                        |
|---------------|--------|------------------------------------|
| `page`        | `int`  | The page number to retrieve.       |
| `size`        | `int`  | The number of items per page.      |
| `sortBy`      | `String` | The field to sort by.             |
| `sortDirection` | `String` | The direction of sorting (e.g., "asc" or "desc"). |

**Returns:** `PagedResponse<K>` - A paginated response containing the entities.

### `getById`

Retrieves an entity by its ID.

| Parameter | Type   | Description         |
|-----------|--------|---------------------|
| `id`      | `Long` | The ID of the entity.|

**Returns:** `K` - The entity corresponding to the given ID.

### `getByUuid`

Retrieves an entity by its UUID.

| Parameter | Type   | Description          |
|-----------|--------|----------------------|
| `uuid`    | `UUID` | The UUID of the entity.|

**Returns:** `K` - The entity corresponding to the given UUID.

### `save`

Saves a new entity.

| Parameter | Type | Description         |
|-----------|------|---------------------|
| `entity`  | `T`  | The entity to save. |

**Returns:** `K` - The saved entity.

### `update`

Updates an existing entity by its ID.

| Parameter | Type   | Description         |
|-----------|--------|---------------------|
| `id`      | `Long` | The ID of the entity to update. |
| `entity`  | `T`    | The updated entity data.        |

**Returns:** `K` - The updated entity.

### `updateByUuid`

Updates an existing entity by its UUID.

| Parameter | Type   | Description          |
|-----------|--------|----------------------|
| `uuid`    | `UUID` | The UUID of the entity to update. |
| `entity`  | `T`    | The updated entity data.          |

**Returns:** `K` - The updated entity.

### `softDelete`

Marks an entity as deleted by its ID without removing it from the database.

| Parameter | Type   | Description         |
|-----------|--------|---------------------|
| `id`      | `Long` | The ID of the entity to soft delete. |

### `softDeleteByUuid`

Marks an entity as deleted by its UUID without removing it from the database.

| Parameter | Type   | Description          |
|-----------|--------|----------------------|
| `uuid`    | `UUID` | The UUID of the entity to soft delete. |

### `delete`

Permanently removes an entity by its ID from the database.

| Parameter | Type   | Description         |
|-----------|--------|---------------------|
| `id`      | `Long` | The ID of the entity to delete. |

### `deleteByUuid`

Permanently removes an entity by its UUID from the database.

| Parameter | Type   | Description          |
|-----------|--------|----------------------|
| `uuid`    | `UUID` | The UUID of the entity to delete. |
