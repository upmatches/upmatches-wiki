# IGenericService Interface

The `IGenericService` interface defines a generic service layer contract for CRUD (Create, Read, Update, Delete) operations in the application. It provides a standardized way to handle business logic for different entity types while maintaining consistency across the service layer.

## Purpose

This interface serves as a template for implementing service classes that manage domain entities. By using Java generics (`<T, K>`), it allows for type-safe operations where:
- `T` represents the request/input DTO (Data Transfer Object) type
- `K` represents the response/output DTO type

The interface supports both numeric (Long) and UUID-based entity identification, providing flexibility for different entity identification strategies.

## Method Summary

| Method | Description |
|--------|-------------|
| `getAll` | Retrieves a paginated list of entities with sorting support |
| `getById` | Fetches a single entity by its numeric ID |
| `getByUuid` | Fetches a single entity by its UUID |
| `save` | Creates a new entity from the provided DTO |
| `update` | Updates an existing entity identified by numeric ID |
| `updateByUuid` | Updates an existing entity identified by UUID |
| `softDelete` | Performs a logical deletion by numeric ID |
| `softDeleteByUuid` | Performs a logical deletion by UUID |
| `delete` | Permanently removes an entity by numeric ID |
| `deleteByUuid` | Permanently removes an entity by UUID |

## Method Details

### getAll

```java
PagedResponse<K> getAll(int page, int size, String sortBy, String sortDirection)
```

Retrieves a paginated list of entities with configurable sorting.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `int` | The page number to retrieve (0-indexed) |
| `size` | `int` | The number of records per page |
| `sortBy` | `String` | The field name to sort by |
| `sortDirection` | `String` | The sort direction (`ASC` or `DESC`) |

**Returns:** `PagedResponse<K>` - A paginated response containing the requested page of entities

### getById

```java
K getById(Long id)
```

Fetches a single entity by its numeric identifier.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `Long` | The numeric identifier of the entity |

**Returns:** `K` - The response DTO of the found entity

**Throws:** May throw an exception if the entity is not found

## Notes

- The interface uses Java generics to provide type safety across different entity types
- Soft delete operations mark entities as inactive rather than removing them permanently
- The `PagedResponse` class provides pagination metadata along with the actual data
- Implementations should handle appropriate exception cases (entity not found, validation errors, etc.)
