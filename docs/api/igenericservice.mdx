# IGenericService Interface

The `IGenericService` interface defines a generic contract for service layer operations in the application. It provides a standardized set of CRUD (Create, Read, Update, Delete) operations that can be implemented by any service class, promoting code reuse and consistency across the application.

## Purpose

This interface serves as a base template for all service implementations, ensuring that every service follows the same pattern for:
- Retrieving paginated lists of entities
- Fetching individual entities by ID or UUID
- Creating new entities
- Updating existing entities
- Performing soft and hard deletions

## Type Parameters

| Parameter | Description |
|-----------|-------------|
| `T` | The request/input entity type (DTO or domain object) |
| `K` | The response/output entity type (DTO or domain object) |

## Methods

### getAll

Retrieves a paginated list of entities.

```java
PagedResponse<K> getAll(int page, int size, String sortBy, String sortDirection)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `int` | Page number (0-based index) |
| `size` | `int` | Number of items per page |
| `sortBy` | `String` | Field name to sort by |
| `sortDirection` | `String` | Sort direction (ASC or DESC) |

**Returns:** `PagedResponse<K>` - A paginated response containing the list of entities and pagination metadata.

### getById

Retrieves a single entity by its database ID.

```java
K getById(Long id)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `Long` | The database ID of the entity |

**Returns:** `K` - The entity with the specified ID.

### getByUuid

Retrieves a single entity by its UUID.

```java
K getByUuid(UUID uuid)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `uuid` | `UUID` | The UUID of the entity |

**Returns:** `K` - The entity with the specified UUID.

### save

Creates a new entity.

```java
K save(T entity)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `entity` | `T` | The entity to create |

**Returns:** `K` - The created entity with generated identifiers.

### update

Updates an existing entity by its database ID.

```java
K update(Long id, T entity)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `Long` | The database ID of the entity to update |
| `entity` | `T` | The updated entity data |

**Returns:** `K` - The updated entity.

### updateByUuid

Updates an existing entity by its UUID.

```java
K updateByUuid(UUID uuid, T entity)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `uuid` | `UUID` | The UUID of the entity to update |
| `entity` | `T` | The updated entity data |

**Returns:** `K` - The updated entity.

### softDelete

Performs a soft delete on an entity by its database ID (marks as deleted without removing from database).

```java
void softDelete(Long id)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `Long` | The database ID of the entity to soft delete |

### softDeleteByUuid

Performs a soft delete on an entity by its UUID.

```java
void softDeleteByUuid(UUID uuid)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `uuid` | `UUID` | The UUID of the entity to soft delete |

### delete

Permanently removes an entity from the database by its ID.

```java
void delete(Long id)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `Long` | The database ID of the entity to delete |

### deleteByUuid

Permanently removes an entity from the database by its UUID.

```java
void deleteByUuid(UUID uuid)
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `uuid` | `UUID` | The UUID of the entity to delete |

## Usage Example

```java
@Service
public class UserService implements IGenericService<UserRequest, UserResponse> {
    
    @Override
    public PagedResponse<UserResponse> getAll(int page, int size, String sortBy, String sortDirection) {
        // Implementation for paginated user retrieval
    }
    
    @Override
    public UserResponse getById(Long id) {
        // Implementation for fetching user by ID
    }
    
    // ... other method implementations
}
```
