# Activity Repository

The `ActivityRepository` interface provides database access operations for the `Activity` entity. It extends Spring Data JPA's `JpaRepository`, inheriting standard CRUD functionality while adding custom query methods specific to the activity domain.

## Purpose

This repository serves as the data access layer for managing `Activity` entities in the application. By extending `JpaRepository<Activity, UUID>`, it automatically inherits methods for:

- Saving and updating activities
- Finding activities by their UUID primary key
- Deleting activities
- Counting activities
- Checking existence by ID

The custom methods defined in this interface enable efficient lookups by business-specific identifiers and validation checks.

## Methods

### Inherited from JpaRepository

The following standard CRUD methods are available without explicit declaration:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all activities |
| `findById(UUID id)` | Finds an activity by its UUID |
| `save(Activity activity)` | Persists a new or existing activity |
| `deleteById(UUID id)` | Deletes an activity by its UUID |
| `count()` | Returns the total number of activities |
| `existsById(UUID id)` | Checks if an activity exists by UUID |

### Custom Query Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findByReferenceId(Integer referenceId)` | `Optional<Activity>` | `referenceId` - The business reference identifier | Retrieves an activity by its reference ID, returning an empty Optional if not found |
| `existsByName(String name)` | `boolean` | `name` - The activity name to check | Returns `true` if an activity with the given name already exists |

## Usage Example

```java
@Service
public class ActivityService {
    private final ActivityRepository activityRepository;

    public ActivityService(ActivityRepository activityRepository) {
        this.activityRepository = activityRepository;
    }

    public Optional<Activity> findByReferenceId(Integer referenceId) {
        return activityRepository.findByReferenceId(referenceId);
    }

    public boolean isNameTaken(String name) {
        return activityRepository.existsByName(name);
    }
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` base interface and query derivation
- **Activity Entity**: The domain entity this repository manages
- **UUID**: Used as the primary key type for activity entities
