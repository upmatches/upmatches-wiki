# ActivityRepository

The `ActivityRepository` interface provides database access operations for the `Activity` entity. It extends Spring Data JPA's `JpaRepository`, inheriting standard CRUD (Create, Read, Update, Delete) functionality while adding custom query methods specific to the activity domain.

## Purpose

This repository serves as the data access layer for activity management within the application. By extending `JpaRepository<Activity, UUID>`, it automatically provides:

- Standard CRUD operations (save, findById, findAll, delete, etc.)
- Pagination and sorting support
- Batch operations

The custom methods defined in this interface enable efficient lookups by business-specific identifiers and validation checks.

## Methods

### Inherited Methods from JpaRepository

The following standard methods are inherited from `JpaRepository<Activity, UUID>`:

| Method | Description |
|--------|-------------|
| `save(Activity entity)` | Persists a new activity or updates an existing one |
| `findById(UUID id)` | Retrieves an activity by its primary key |
| `findAll()` | Returns all activities |
| `deleteById(UUID id)` | Removes an activity by its primary key |
| `count()` | Returns the total number of activities |

### Custom Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findByReferenceId(Integer referenceId)` | `Optional<Activity>` | `referenceId` - The business reference identifier | Retrieves an activity by its unique reference ID. Returns an empty Optional if no activity matches. |
| `existsByName(String name)` | `boolean` | `name` - The activity name to check | Checks whether an activity with the given name already exists in the database. Returns `true` if found, `false` otherwise. |

## Usage Example

```java
@Service
public class ActivityService {
    private final ActivityRepository activityRepository;

    public ActivityService(ActivityRepository activityRepository) {
        this.activityRepository = activityRepository;
    }

    public Optional<Activity> findByReference(Integer referenceId) {
        return activityRepository.findByReferenceId(referenceId);
    }

    public boolean isNameTaken(String name) {
        return activityRepository.existsByName(name);
    }
}
```

## Dependencies

- **Spring Data JPA**: Provides the underlying implementation for database operations
- **Activity entity**: The domain model this repository manages
- **UUID**: Used as the primary key type for activity entities
