import com.upmatches.app.features.activity.entities.Activity;
import org.springframework.data.jpa.repository.JpaRepository;

import java.util.Optional;
import java.util.UUID;

## Purpose

The `ActivityRepository` interface is a part of the repository layer in a Spring application. It extends the `JpaRepository` interface, providing CRUD operations for the `Activity` entity. This interface is used to interact with the database layer, allowing for operations on `Activity` entities identified by a `UUID`.

## Public Methods

The `ActivityRepository` interface provides the following public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `findByReferenceId` | `Integer referenceId` | `Optional<Activity>` | Retrieves an `Activity` entity based on its `referenceId`. Returns an `Optional` containing the `Activity` if found, or an empty `Optional` if not. |
| `existsByName` | `String name` | `boolean` | Checks if an `Activity` entity with the specified `name` exists in the database. Returns `true` if such an entity exists, otherwise `false`. |

The `ActivityRepository` leverages Spring Data JPA's capabilities to simplify database interactions, reducing the need for boilerplate code.
