# Activity Repository

The `ActivityRepository` interface provides database access operations for the `Activity` entity. It extends Spring Data JPA's `JpaRepository`, inheriting standard CRUD functionality while adding custom query methods specific to the activity domain.

## Purpose

This repository serves as the data access layer for activity management within the application. By extending `JpaRepository<Activity, UUID>`, it automatically provides:

- Standard create, read, update, and delete operations
- Pagination and sorting support
- Batch operations
- Fluent query method generation

The custom methods defined in this interface enable efficient lookups by reference ID and name validation, which are common requirements in activity management workflows.

## Methods

### Inherited Methods

The following methods are inherited from `JpaRepository` and `CrudRepository`:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `findById(UUID id)` | `Optional<Activity>` | Retrieves an activity by its UUID primary key |
| `findAll()` | `List<Activity>` | Returns all activities |
| `save(Activity entity)` | `Activity` | Saves or updates an activity |
| `deleteById(UUID id)` | `void` | Deletes an activity by its UUID |
| `count()` | `long` | Returns the total number of activities |

### Custom Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `findByReferenceId(Integer referenceId)` | `Optional<Activity>` | `referenceId` - The unique reference identifier for the activity | Finds an activity by its business reference ID. Returns an empty `Optional` if no matching activity exists. |
| `existsByName(String name)` | `boolean` | `name` - The name to check for existence | Checks whether an activity with the given name already exists in the database. Returns `true` if found, `false` otherwise. |

## Usage Example

```java
@Service
public class ActivityService {
    private final ActivityRepository activityRepository;

    public ActivityService(ActivityRepository activityRepository) {
        this.activityRepository = activityRepository;
    }

    public Optional<Activity> findByReferenceId(Integer referenceId) {
        return activityRepository.findByReferenceId(referenceId);
    }

    public boolean isNameTaken(String name) {
        return activityRepository.existsByName(name);
    }
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` base interface and query derivation
- **Activity Entity**: The domain entity this repository manages
- **UUID**: Used as the primary key type for activity entities
