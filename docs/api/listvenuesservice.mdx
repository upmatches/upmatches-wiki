# ListVenuesService

The `ListVenuesService` class is a Spring service component responsible for retrieving a paginated list of venues from the database. It implements the `IListVenuesService` interface and provides a read-only transactional operation that fetches venue data and transforms it into a standardized response format.

## Purpose

This service encapsulates the business logic for listing venues with pagination support. It leverages Spring Data's `Pageable` parameter to handle pagination efficiently and uses a service operation executor to manage error handling and operation status tracking.

## Public Methods

### `execute(Pageable pageable)`

Retrieves a paginated list of venues and returns them as a `PagedResponse<VenueResponse>`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | Spring Data pagination object containing page number, size, and sort criteria |

**Returns:** `PagedResponse<VenueResponse>` - A paginated response containing venue data transformed into `VenueResponse` objects.

**Exceptions:** Throws `ResourceNotFoundException` if the operation fails (handled by `ServiceOperationExecutor`).

**Transactional Behavior:** The method is marked with `@Transactional(readOnly = true)` to optimize database access for read-only operations.

## Usage Example

```java
@Service
public class VenueController {
    private final ListVenuesService listVenuesService;
    
    public VenueController(ListVenuesService listVenuesService) {
        this.listVenuesService = listVenuesService;
    }
    
    public PagedResponse<VenueResponse> getVenues(int page, int size) {
        Pageable pageable = PageRequest.of(page, size);
        return listVenuesService.execute(pageable);
    }
}
```

## Implementation Details

The service uses `ServiceOperationExecutor.execute()` to wrap the database operation with standardized error handling and status tracking. The core operation:

1. Calls `venueRepository.findAll(pageable)` to retrieve a paginated `Page<Venue>` from the database
2. Transforms each `Venue` entity to a `VenueResponse` using the static method `VenueResponse::fromVenue`
3. Wraps the result in a `PagedResponse` object for consistent API responses

The operation status is set to `RETRIEVE` and any failures result in a `ResourceNotFoundException` being thrown.
