# ListVenuesService

The `ListVenuesService` class is a Spring service component responsible for retrieving a paginated list of venues from the database. It implements the `IListVenuesService` interface and provides a transactional, read-only operation to fetch venue data and convert it into a standardized response format.

## Purpose

This service encapsulates the business logic for listing venues with pagination support. It leverages Spring Data's `Pageable` to handle pagination parameters and returns a `PagedResponse<VenueResponse>` that includes both the venue data and pagination metadata. The service uses `ServiceOperationExecutor` to handle operation execution, status tracking, and error handling consistently.

## Constructor

Creates a new instance of the service with the required repository dependency.

| Parameter | Type | Description |
|-----------|------|-------------|
| `venueRepository` | `VenueRepository` | The repository used to access venue data from the database |

## Public Methods

### `execute(Pageable pageable)`

Retrieves a paginated list of venues and returns them as a `PagedResponse<VenueResponse>`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | Spring Data pagination object containing page number, size, and sort parameters |

**Returns:** `PagedResponse<VenueResponse>` - A paginated response containing venue data and pagination metadata

**Exceptions:** Throws `ResourceNotFoundException` if the operation fails (wrapped by `ServiceOperationExecutor`)

**Transactional Behavior:** Read-only transaction (`@Transactional(readOnly = true)`)

## Usage Example

```java
// Inject the service
private final ListVenuesService listVenuesService;

// Create a pageable request
Pageable pageable = PageRequest.of(0, 10, Sort.by("name").ascending());

// Execute the query
PagedResponse<VenueResponse> venues = listVenuesService.execute(pageable);

// Access results
List<VenueResponse> venueList = venues.getContent();
int totalPages = venues.getTotalPages();
long totalElements = venues.getTotalElements();
```

## Error Handling

The service uses `ServiceOperationExecutor.execute()` which:
- Wraps any exceptions in a `ResourceNotFoundException`
- Tracks the operation status as `RETRIEVE`
- Provides consistent error handling across the application
