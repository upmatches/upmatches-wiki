# ListVenuesService

The `ListVenuesService` class is a Spring service component responsible for retrieving a paginated list of venues from the database. It implements the `IListVenuesService` interface and provides a read-only transactional operation that fetches venue data and converts it into a standardized `PagedResponse<VenueResponse>` format.

## Purpose

This service encapsulates the business logic for listing venues with pagination support. It leverages Spring Data's `Pageable` parameter to handle pagination and sorting, and uses a shared `ServiceOperationExecutor` utility to manage error handling and operation status tracking.

## Public Methods

### `execute(Pageable pageable)`

Retrieves a paginated list of venues from the database and returns them as a `PagedResponse<VenueResponse>`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `pageable` | `Pageable` | Spring Data pagination object containing page number, size, and sorting information |

| Returns | Description |
|---------|-------------|
| `PagedResponse<VenueResponse>` | A paginated response containing venue data wrapped in `VenueResponse` objects |

**Behavior:**
- The method is annotated with `@Transactional(readOnly = true)` to optimize database access for read operations
- Uses `ServiceOperationExecutor.execute()` to wrap the operation with standardized error handling
- Calls `venueRepository.findAll(pageable)` to retrieve a `Page<Venue>` from the database
- Converts the `Page<Venue>` to `PagedResponse<VenueResponse>` using the `VenueResponse::fromVenue` mapper method
- On failure, throws a `ResourceNotFoundException` with the operation status set to `RETRIEVE`

## Usage Example

```java
@Service
public class VenueController {
    private final ListVenuesService listVenuesService;
    
    public VenueController(ListVenuesService listVenuesService) {
        this.listVenuesService = listVenuesService;
    }
    
    public PagedResponse<VenueResponse> getVenues(int page, int size) {
        Pageable pageable = PageRequest.of(page, size);
        return listVenuesService.execute(pageable);
    }
}
```

## Error Handling

The service uses `ServiceOperationExecutor.execute()` which provides consistent error handling:
- On successful execution: Returns the `PagedResponse<VenueResponse>`
- On failure: Throws `ResourceNotFoundException` with the `RETRIEVE` operation status
