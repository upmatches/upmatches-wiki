# IDevTokenPageRenderer

The `IDevTokenPageRenderer` is a sealed interface in the `com.upmatches.app.features.auth.services` package that defines the contract for rendering developer token pages. It is designed to provide a standardized way to display authentication tokens (access and refresh tokens) to developers during the authentication flow, particularly for mobile or web applications that need to capture token information.

This interface is part of the authentication services layer and is intended to be implemented by the `DevTokenPageRenderer` class. The sealed nature of the interface ensures that only the permitted implementation can fulfill this contract, providing a controlled extension point.

## Purpose

The primary purpose of this interface is to:
- Determine whether the token page rendering is enabled for a given HTTP request
- Generate an HTML response containing the authentication tokens and related metadata
- Support mobile redirect scenarios by providing a configurable redirect URL

## Interface Methods

### `isEnabledFor`

```java
boolean isEnabledFor(HttpServletRequest request)
```

Checks whether the developer token page rendering is enabled for the given HTTP request. This method allows for conditional rendering based on request attributes, such as user agent, IP address, or custom headers.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The incoming HTTP request to evaluate |

| Returns | Description |
|---------|-------------|
| `boolean` | `true` if the token page rendering is enabled for this request, `false` otherwise |

### `render`

```java
ResponseEntity<String> render(
    String accessToken,
    String refreshToken,
    Long expiresAtUtc,
    Boolean isNewUser,
    String mobileRedirectUrl)
```

Generates an HTML response containing the authentication tokens and associated metadata. This method is responsible for creating a user-friendly page that displays the tokens to the developer.

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The JWT access token to display |
| `refreshToken` | `String` | The refresh token to display |
| `expiresAtUtc` | `Long` | The expiration timestamp of the access token in UTC milliseconds |
| `isNewUser` | `Boolean` | Flag indicating whether this is a new user registration |
| `mobileRedirectUrl` | `String` | The URL to redirect mobile clients after token display |

| Returns | Type | Description |
|---------|------|-------------|
| `ResponseEntity<String>` | HTTP response | The rendered HTML page containing token information |

## Implementation Notes

- The interface is declared as `sealed`, meaning only the `DevTokenPageRenderer` class is permitted to implement it
- All methods are part of the public API contract
- The `render` method returns a `ResponseEntity<String>` to allow for custom HTTP status codes and headers
- The `isNewUser` parameter can be used to customize the rendering for new versus returning users
- The `mobileRedirectUrl` parameter enables mobile-friendly redirect behavior after token display

## Usage Example

```java
// Example implementation check
if (tokenPageRenderer.isEnabledFor(request)) {
    ResponseEntity<String> response = tokenPageRenderer.render(
        accessToken,
        refreshToken,
        expiresAtUtc,
        isNewUser,
        mobileRedirectUrl
    );
    return response;
}
```
