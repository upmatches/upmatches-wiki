## Overview

The `IDevTokenPageRenderer` interface is part of the `com.upmatches.app.features.auth.services` package. It defines the contract for rendering a token page in a development environment. This interface is designed to be implemented by classes that need to provide a mechanism for rendering a page with authentication tokens, typically for development or testing purposes.

## Public Methods

The interface declares the following public methods:

### `isEnabledFor`

Determines if the token page rendering is enabled for a given HTTP request.

| Parameter | Type                      | Description                              |
|-----------|---------------------------|------------------------------------------|
| request   | `HttpServletRequest`      | The HTTP request to check.               |

| Return Type | Description                              |
|-------------|------------------------------------------|
| `boolean`   | `true` if rendering is enabled; otherwise, `false`. |

### `render`

Renders the token page with the provided authentication tokens and additional information.

| Parameter         | Type                | Description                                      |
|-------------------|---------------------|--------------------------------------------------|
| accessToken       | `String`            | The access token to be included in the page.     |
| refreshToken      | `String`            | The refresh token to be included in the page.    |
| expiresAtUtc      | `Long`              | The expiration time of the access token in UTC.  |
| isNewUser         | `Boolean`           | Indicates if the user is new.                    |
| mobileRedirectUrl | `String`            | URL to redirect mobile users after rendering.    |

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| `ResponseEntity<String>` | The HTTP response containing the rendered page. |
