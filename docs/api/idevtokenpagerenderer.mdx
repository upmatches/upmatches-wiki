# IDevTokenPageRenderer Interface

## Purpose

The `IDevTokenPageRenderer` interface defines a contract for rendering developer token pages in the authentication flow. It provides methods to check if the token page rendering is enabled for a given request and to generate HTML responses containing access and refresh tokens. This interface is part of the authentication services layer and is designed to be implemented by `DevTokenPageRenderer`.

## Interface Definition

```java
public sealed interface IDevTokenPageRenderer permits DevTokenPageRenderer
```

The interface is declared as `sealed`, meaning only the specified class `DevTokenPageRenderer` is permitted to implement it. This ensures controlled extension and maintains security in the authentication flow.

## Methods

### `isEnabledFor`

Determines whether the developer token page rendering is enabled for the given HTTP request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The incoming HTTP servlet request to evaluate |

| Returns | Type | Description |
|---------|------|-------------|
| `boolean` | `boolean` | `true` if token page rendering is enabled for this request, `false` otherwise |

### `render`

Generates an HTML response containing authentication tokens for the developer.

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The JWT access token to be displayed |
| `refreshToken` | `String` | The JWT refresh token to be displayed |
| `expiresAtUtc` | `Long` | The UTC timestamp (in milliseconds) when the tokens expire |
| `isNewUser` | `Boolean` | Flag indicating whether this is a new user registration |
| `mobileRedirectUrl` | `String` | The URL to redirect mobile clients after successful authentication |

| Returns | Type | Description |
|---------|------|-------------|
| `ResponseEntity<String>` | `ResponseEntity<String>` | HTTP response containing the rendered HTML page with token information |

## Usage Example

```java
// Example implementation check
if (tokenRenderer.isEnabledFor(request)) {
    ResponseEntity<String> response = tokenRenderer.render(
        "eyJhbGciOiJIUzI1NiIs...",
        "dGhpcyBpcyBhIHJlZnJl...",
        1700000000000L,
        false,
        "com.example.app://callback"
    );
    return response;
}
```

## Dependencies

- `jakarta.servlet.http.HttpServletRequest` - Jakarta Servlet API for HTTP request handling
- `org.springframework.http.ResponseEntity` - Spring Framework's HTTP response entity wrapper

## Implementation Notes

- The interface uses a sealed class hierarchy to restrict implementation to `DevTokenPageRenderer` only
- The `render` method returns a `ResponseEntity<String>` to allow full control over HTTP response headers and status codes
- Token expiration is provided as a UTC timestamp in milliseconds for consistent timezone handling
- The `mobileRedirectUrl` parameter supports deep linking for mobile applications
