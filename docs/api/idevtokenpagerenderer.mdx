# IDevTokenPageRenderer

The `IDevTokenPageRenderer` interface defines a contract for rendering a developer token page in the authentication flow. It provides methods to check if the renderer is enabled for a given request and to generate an HTML response containing authentication tokens.

This sealed interface permits only the `DevTokenPageRenderer` class as its implementation, ensuring controlled extensibility within the authentication services package.

## Interface Definition

```java
package com.upmatches.app.features.auth.services;

import jakarta.servlet.http.HttpServletRequest;
import org.springframework.http.ResponseEntity;

public sealed interface IDevTokenPageRenderer permits DevTokenPageRenderer {

    boolean isEnabledFor(HttpServletRequest request);

    ResponseEntity<String> render(
        String accessToken,
        String refreshToken,
        Long expiresAtUtc,
        Boolean isNewUser,
        String mobileRedirectUrl);
}
```

## Methods

### `isEnabledFor`

Determines whether the developer token page renderer is enabled for the given HTTP request.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The incoming HTTP request to evaluate |

| Returns | Description |
|---------|-------------|
| `boolean` | `true` if the renderer is enabled for this request, `false` otherwise |

### `render`

Generates an HTML response containing the authentication tokens and related information.

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The JWT access token to display |
| `refreshToken` | `String` | The refresh token for obtaining new access tokens |
| `expiresAtUtc` | `Long` | The expiration timestamp of the access token in UTC milliseconds |
| `isNewUser` | `Boolean` | Flag indicating whether this is a new user registration |
| `mobileRedirectUrl` | `String` | The URL to redirect mobile clients after successful authentication |

| Returns | Description |
|---------|-------------|
| `ResponseEntity<String>` | HTTP response containing the rendered HTML page with token information |

## Usage Example

```java
// Example implementation check
if (tokenRenderer.isEnabledFor(request)) {
    ResponseEntity<String> response = tokenRenderer.render(
        "eyJhbGciOiJIUzI1NiIs...",
        "dGhpcyBpcyBhIHJlZnJl...",
        1700000000000L,
        false,
        "upmatches://auth/callback"
    );
    return response;
}
```

## Notes

- The interface is sealed, meaning only `DevTokenPageRenderer` can implement it
- This design pattern ensures that the token rendering logic remains centralized and controlled
- The `render` method returns a `ResponseEntity<String>` to allow for proper HTTP status codes and headers
