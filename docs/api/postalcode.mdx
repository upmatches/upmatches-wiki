# PostalCode

The `PostalCode` class is a Java record that represents a validated postal code value object. It ensures that any postal code stored within the system is a non-empty, 6-digit numeric string. This class is part of the `com.upmatches.app.features.venue.valueobjects` package and is designed to be immutable and self-validating.

## Purpose

The primary purpose of the `PostalCode` record is to encapsulate the concept of a postal code in a type-safe manner. By using a dedicated value object, the application avoids primitive obsession and ensures that all postal codes adhere to a consistent format (exactly 6 digits). The validation logic is centralized within the record, preventing invalid data from propagating through the system.

## Public Methods

| Method | Description | Parameters | Return Type |
| :--- | :--- | :--- | :--- |
| `PostalCode(String value)` | Compact constructor that validates and creates a new `PostalCode` instance. | `value` - The postal code string to validate. | `PostalCode` |
| `create(String postalCode)` | Static factory method to create a `PostalCode` instance. | `postalCode` - The postal code string to validate. | `PostalCode` |
| `toString()` | Returns the string representation of the postal code. | None | `String` |

## Validation Rules

The `PostalCode` record enforces the following validation rules during construction:

1.  **Non-empty**: The provided `value` must not be `null` or blank.
2.  **Format**: The `value` must match the regular expression `^\d{6}$`, meaning it must consist of exactly 6 digits.

If either validation rule is violated, an `IllegalArgumentException` is thrown with a descriptive message.

## Usage Example

```java
// Valid postal code
PostalCode code = PostalCode.create("123456");
System.out.println(code.toString()); // Output: 123456

// Invalid postal code (empty)
try {
    PostalCode invalidCode = PostalCode.create("");
} catch (IllegalArgumentException e) {
    System.out.println(e.getMessage()); // Output: Postal code cannot be empty.
}

// Invalid postal code (non-digit characters)
try {
    PostalCode invalidCode = PostalCode.create("12A456");
} catch (IllegalArgumentException e) {
    System.out.println(e.getMessage()); // Output: Postal code must be a 6-digit number.
}
```
