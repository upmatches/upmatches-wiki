## Overview

The `PostalCode` class is a value object that represents a postal code in a specific format. It ensures that the postal code is a valid 6-digit number, providing a reliable way to handle postal codes within the application. This class is immutable and uses Java's `record` feature to encapsulate the postal code value.

## Class Definition

The `PostalCode` class is defined as a Java record, which provides a concise way to create immutable data objects. It includes validation logic to ensure the postal code meets the required format.

## Validation

The `PostalCode` class includes validation logic to ensure that the postal code:

- Is not null or blank.
- Is a 6-digit number.

If the postal code does not meet these criteria, an `IllegalArgumentException` is thrown. This ensures that only valid postal codes are accepted and stored within the application.
