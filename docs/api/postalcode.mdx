# PostalCode Value Object

The `PostalCode` class is a Java record that represents a validated postal code value object. It ensures that any postal code used within the application conforms to a strict 6-digit numeric format, providing type safety and validation at the point of creation.

## Purpose

This value object encapsulates the concept of a postal code in the venue domain. By using a dedicated record type, the application gains:

- **Immutability**: Once created, the postal code value cannot be changed.
- **Validation**: Automatic validation ensures only properly formatted postal codes are accepted.
- **Type Safety**: Prevents accidental mixing of postal codes with other string values.
- **Self-Documentation**: The class name clearly communicates its purpose and constraints.

## Constructor

The compact constructor performs validation during record instantiation:

| Parameter | Type | Description |
|-----------|------|-------------|
| `value` | `String` | The raw postal code string to validate and store |

### Validation Rules

1. The value must not be `null` or blank.
2. The value must match the pattern `^\d{6}$` (exactly 6 digits).

### Exceptions

| Exception | Condition |
|-----------|-----------|
| `IllegalArgumentException` | If the value is null or blank |
| `IllegalArgumentException` | If the value does not match the 6-digit format |

## Public Methods

### `create(String postalCode)`

Factory method for creating a `PostalCode` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `postalCode` | `String` | The postal code string to validate and wrap |

| Returns | Type |
|---------|------|
| A new `PostalCode` instance | `PostalCode` |

### `toString()`

Returns the stored postal code value as a string.

| Returns | Type |
|---------|------|
| The 6-digit postal code | `String` |

## Usage Example

```java
// Valid postal code
PostalCode code = PostalCode.create("123456");
System.out.println(code.toString()); // Output: 123456

// Invalid - empty string
try {
    PostalCode invalid = PostalCode.create("");
} catch (IllegalArgumentException e) {
    // Handles: "Postal code cannot be empty."
}

// Invalid - not 6 digits
try {
    PostalCode invalid = PostalCode.create("12345");
} catch (IllegalArgumentException e) {
    // Handles: "Postal code must be a 6-digit number."
}
```

## Design Notes

- The class is implemented as a Java `record`, providing automatic `equals()`, `hashCode()`, and `toString()` implementations.
- The validation pattern uses a compiled `Pattern` constant for performance.
- The factory method `create()` provides a clear, intention-revealing API for instantiation.
- The compact constructor trims whitespace from the input before validation, improving user experience.
