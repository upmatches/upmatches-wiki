import com.upmatches.app.features.audit.entities.AuditEvent;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;

import java.util.List;
import java.util.UUID;

## Overview

The `AuditEventRepository` interface is a part of the repository layer in a Spring application, responsible for managing `AuditEvent` entities. It extends the `JpaRepository` interface, which provides CRUD operations and additional methods for interacting with the database. This repository is specifically designed to handle audit events, allowing for efficient querying based on specific criteria.

## Public Methods

The `AuditEventRepository` interface provides the following public methods:

### `findByActorIdOrderByOccurredAtDesc`

Retrieves a list of `AuditEvent` objects associated with a specific actor, ordered by the occurrence time in descending order.

| Parameter | Type   | Description                  |
|-----------|--------|------------------------------|
| `actorId` | `UUID` | The unique identifier of the actor. |

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| `List<AuditEvent>`   | A list of audit events related to the specified actor, ordered by occurrence time in descending order. |

### `findByResourceTypeAndResourceIdOrderByOccurredAtDesc`

Fetches a list of `AuditEvent` objects based on the resource type and resource ID, ordered by the occurrence time in descending order.

| Parameter      | Type     | Description                        |
|----------------|----------|------------------------------------|
| `resourceType` | `String` | The type of the resource.          |
| `resourceId`   | `String` | The unique identifier of the resource. |

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| `List<AuditEvent>`   | A list of audit events related to the specified resource type and ID, ordered by occurrence time in descending order. |

## Usage

The `AuditEventRepository` is annotated with `@Repository`, indicating that it is a Spring Data repository. It is used to perform database operations related to `AuditEvent` entities, leveraging Spring Data JPA's capabilities to simplify data access layers.
