# PagedResponse\<T\>

A generic paginated response wrapper designed for REST API responses. It encapsulates a list of items for the current page along with comprehensive pagination metadata. The class is built as a Java `record`, providing a concise and immutable data carrier.

## Purpose

The primary goal of `PagedResponse` is to standardize paginated API responses across the application. By wrapping Spring Data `Page` objects, it ensures that all endpoints return a consistent JSON structure containing both the data and pagination details. This simplifies client-side handling and improves API discoverability.

## Features

- **Generic Type Support**: Works with any data type `T`.
- **Mapping Capability**: Provides a static factory method to transform page content from one type to another using a `Function`.
- **JSON Serialization Control**: Uses `@JsonInclude(JsonInclude.Include.NON_NULL)` to omit null fields from the JSON output.
- **OpenAPI Documentation**: Annotated with `@Schema` for clear API documentation generation.

## Public Methods

### `of(Page<T> page)`

Creates a `PagedResponse` directly from a Spring Data `Page` object.

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `Page<T>` | The Spring Data page containing items and pagination metadata. |

**Returns**: `PagedResponse<T>` - A new paginated response with the original content type.

### `of(Page<T> page, Function<T, R> mapper)`

Creates a `PagedResponse` from a Spring Data `Page` object, transforming each item using the provided mapper function.

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `Page<T>` | The Spring Data page containing items of type `T`. |
| `mapper` | `Function<T, R>` | A function to convert each item from type `T` to type `R`. |

**Returns**: `PagedResponse<R>` - A new paginated response with the mapped content type `R`.

## Inner Record: `PageInfo`

A nested record that holds all pagination metadata.

| Field | Type | Description |
|-------|------|-------------|
| `number` | `Integer` | Current page number (zero-based). |
| `size` | `Integer` | Number of items per page. |
| `totalElements` | `Long` | Total number of items across all pages. |
| `totalPages` | `Integer` | Total number of pages. |
| `first` | `Boolean` | Whether this is the first page. |
| `last` | `Boolean` | Whether this is the last page. |
| `hasNext` | `Boolean` | Whether there is a next page. |
| `hasPrevious` | `Boolean` | Whether there is a previous page. |

## Usage Examples

### Basic Usage

```java
// Assume you have a Page<User> from a repository
Page<User> userPage = userRepository.findAll(pageable);
PagedResponse<User> response = PagedResponse.of(userPage);
```

### With Mapping

```java
// Convert User entities to UserDTOs
Page<User> userPage = userRepository.findAll(pageable);
PagedResponse<UserDTO> response = PagedResponse.of(userPage, user -> new UserDTO(user.getId(), user.getName()));
```
