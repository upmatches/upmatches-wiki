# PagedResponse

A generic paginated response wrapper designed for REST API responses. This record provides a standardized way to return paginated data along with comprehensive pagination metadata, making it easy for clients to navigate through large datasets.

## Purpose

The `PagedResponse` class serves as a DTO (Data Transfer Object) for paginated API responses. It encapsulates:
- The actual data items for the current page
- Detailed pagination metadata (page number, size, total elements, total pages, and navigation flags)

This pattern is commonly used in Spring Boot applications to provide consistent paginated responses across all endpoints.

## Structure

The class is implemented as a Java record with two main components:

### PagedResponse<T>
The outer record containing the paginated data.

| Field | Type | Description |
|-------|------|-------------|
| `content` | `List<T>` | List of items in the current page |
| `page` | `PageInfo` | Pagination metadata |

### PageInfo
A nested record containing pagination metadata.

| Field | Type | Description |
|-------|------|-------------|
| `number` | `Integer` | Current page number (zero-based) |
| `size` | `Integer` | Number of items per page |
| `totalElements` | `Long` | Total number of items across all pages |
| `totalPages` | `Integer` | Total number of pages |
| `first` | `Boolean` | Whether this is the first page |
| `last` | `Boolean` | Whether this is the last page |
| `hasNext` | `Boolean` | Whether there is a next page |
| `hasPrevious` | `Boolean` | Whether there is a previous page |

## Public Methods

### `of(Page<T> page)`
Creates a `PagedResponse` from a Spring Data `Page` object.

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `Page<T>` | The Spring Data Page to convert |

**Returns:** `PagedResponse<T>` - A paginated response with the same item type

### `of(Page<T> page, Function<T, R> mapper)`
Creates a `PagedResponse` from a Spring Data `Page` object, applying a mapping function to transform the items.

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `Page<T>` | The Spring Data Page to convert |
| `mapper` | `Function<T, R>` | Function to transform items from type T to type R |

**Returns:** `PagedResponse<R>` - A paginated response with transformed items

## Usage Examples

### Basic Usage
```java
// Assuming you have a Page<User> from a repository
Page<User> userPage = userRepository.findAll(pageable);
PagedResponse<User> response = PagedResponse.of(userPage);
```

### With Mapping
```java
// Transform entities to DTOs
Page<User> userPage = userRepository.findAll(pageable);
PagedResponse<UserDTO> response = PagedResponse.of(userPage, user -> new UserDTO(user.getId(), user.getName()));
```
