# PagedResponse

A generic paginated response wrapper designed for REST API responses. This record provides a standardized way to return paginated data along with comprehensive pagination metadata, making it easy for clients to navigate through large datasets.

## Purpose

The `PagedResponse` class serves as a universal response format for any paginated API endpoint. It wraps a list of items (the current page's content) together with detailed pagination information, ensuring consistent pagination handling across the entire application.

Key features:
- Generic type support for flexible content types
- Automatic mapping of domain entities to DTOs
- Comprehensive pagination metadata
- JSON serialization with `@JsonInclude(NON_NULL)` to omit null fields
- OpenAPI/Swagger documentation annotations

## Constructor

### `PagedResponse(List<T> content, PageInfo page)`

Creates a new paginated response with the given content and page information.

| Parameter | Type | Description |
|-----------|------|-------------|
| `content` | `List<T>` | The list of items for the current page |
| `page` | `PageInfo` | Pagination metadata |

## Factory Methods

### `of(Page<T> page)`

Creates a `PagedResponse` directly from a Spring Data `Page` object.

```java
public static <T> PagedResponse<T> of(final Page<T> page)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `Page<T>` | A Spring Data Page containing the items and pagination info |

**Returns:** `PagedResponse<T>` - A paginated response with the same content type as the input page.

**Example:**
```java
Page<User> userPage = userRepository.findAll(pageable);
return PagedResponse.of(userPage);
```

### `of(Page<T> page, Function<T, R> mapper)`

Creates a `PagedResponse` with transformed content using a mapping function. This is useful when you need to convert domain entities to DTOs or other response objects.

```java
public static <T, R> PagedResponse<R> of(final Page<T> page, final Function<T, R> mapper)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | `Page<T>` | A Spring Data Page containing the source items |
| `mapper` | `Function<T, R>` | A function to transform each item from type `T` to type `R` |

**Returns:** `PagedResponse<R>` - A paginated response with the mapped content type.

**Example:**
```java
Page<User> userPage = userRepository.findAll(pageable);
return PagedResponse.of(userPage, user -> new UserDTO(user.getId(), user.getName()));
```

## Inner Record: PageInfo

The `PageInfo` record encapsulates all pagination metadata returned to the client.

### Fields

| Field | Type | Description | Example |
|-------|------|-------------|---------|
| `number` | `Integer` | Current page number (zero-based) | `0` |
| `size` | `Integer` | Number of items per page | `20` |
| `totalElements` | `Long` | Total number of items across all pages | `100` |
| `totalPages` | `Integer` | Total number of pages | `5` |
| `first` | `Boolean` | Whether this is the first page | `true` |
| `last` | `Boolean` | Whether this is the last page | `false` |
| `hasNext` | `Boolean` | Whether there is a next page | `true` |
| `hasPrevious` | `Boolean` | Whether there is a previous page | `false` |

## Usage Example

```java
@RestController
@RequestMapping("/api/users")
public class UserController {

    @GetMapping
    public ResponseEntity<PagedResponse<UserDTO>> getUsers(
            @RequestParam(defaultValue = "0") int page,
            @RequestParam(defaultValue = "20") int size) {
        
        Pageable pageable = PageRequest.of(page, size);
        Page<User> userPage = userRepository.findAll(pageable);
        
        PagedResponse<UserDTO> response = PagedResponse.of(userPage, 
            user -> new UserDTO(user.getId(), user.getName(), user.getEmail()));
        
        return ResponseEntity.ok(response);
    }
}
```
