## Purpose

The `PagedResponse` class is a generic wrapper designed to encapsulate paginated responses. It is particularly useful in RESTful APIs where data is returned in pages. This class utilizes Spring Data's `Page` interface to provide a structured way to handle pagination metadata along with the actual content of the current page.

## Public Methods

The `PagedResponse` class provides two static methods to create instances of paginated responses. These methods are designed to be flexible, allowing for straightforward conversion from a `Page` object to a `PagedResponse`.

### Method: `of(Page<T> page)`

This method creates a `PagedResponse` from a given `Page` object, encapsulating the content and pagination metadata.

| Parameter | Type     | Description                       |
|-----------|----------|-----------------------------------|
| page      | `Page<T>`| The page object containing data.  |

| Return Type      | Description                                      |
|------------------|--------------------------------------------------|
| `PagedResponse<T>` | A new instance of `PagedResponse` with content and pagination metadata. |

### Method: `of(Page<T> page, Function<T, R> mapper)`

This method creates a `PagedResponse` from a given `Page` object and applies a mapping function to transform the content.

| Parameter | Type                  | Description                                         |
|-----------|-----------------------|-----------------------------------------------------|
| page      | `Page<T>`             | The page object containing data.                    |
| mapper    | `Function<T, R>`      | A function to transform each element in the content.|

| Return Type      | Description                                      |
|------------------|--------------------------------------------------|
| `PagedResponse<R>` | A new instance of `PagedResponse` with transformed content and pagination metadata. |

## PageInfo Record

The `PageInfo` record is a nested static record within `PagedResponse` that holds pagination metadata. It provides detailed information about the current page, including the page number, size, total elements, total pages, and navigation flags.

| Field         | Type      | Description                                           |
|---------------|-----------|-------------------------------------------------------|
| number        | `Integer` | Current page number (zero-based).                     |
| size          | `Integer` | Number of items per page.                             |
| totalElements | `Long`    | Total number of items across all pages.               |
| totalPages    | `Integer` | Total number of pages.                                |
| first         | `Boolean` | Whether this is the first page.                       |
| last          | `Boolean` | Whether this is the last page.                        |
| hasNext       | `Boolean` | Whether there is a next page.                         |
| hasPrevious   | `Boolean` | Whether there is a previous page.                     |
