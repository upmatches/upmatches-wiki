# ICreateActivityService

The `ICreateActivityService` interface defines the contract for creating new activities within the UpMatches application. It follows a command pattern, encapsulating the creation logic behind a single `execute` method. This interface is sealed, meaning only the explicitly permitted class (`CreateActivityService`) can implement it, ensuring controlled and secure extension of the activity creation behavior.

## Interface Definition

```java
public sealed interface ICreateActivityService permits CreateActivityService {

    ActivityResponse execute(CreateActivityRequest request);

}
```

## Methods

### `execute`

Processes a request to create a new activity and returns the corresponding response.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateActivityRequest` | The request object containing the necessary data to create an activity (e.g., title, description, date, location). |

| Returns | Type | Description |
|---------|------|-------------|
| `ActivityResponse` | `ActivityResponse` | The response object containing the details of the newly created activity (e.g., activity ID, status, timestamps). |

## Usage Example

```java
// Assuming you have an instance of ICreateActivityService
ICreateActivityService activityService = new CreateActivityService();

CreateActivityRequest request = new CreateActivityRequest();
// Populate request fields...

ActivityResponse response = activityService.execute(request);
```

## Related Components

- **`CreateActivityRequest`**: The input data transfer object (DTO) for activity creation.
- **`ActivityResponse`**: The output data transfer object (DTO) representing the created activity.
- **`CreateActivityService`**: The sole permitted implementation of this interface.
