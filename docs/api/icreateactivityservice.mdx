## Overview

The `ICreateActivityService` interface defines the contract for creating a new activity within the UpMatches application. It serves as the abstraction layer for the activity creation use case, ensuring that any implementation (currently `CreateActivityService`) adheres to a consistent method signature.

This interface is declared as `sealed`, meaning only explicitly permitted classes (in this case, `CreateActivityService`) can implement it. This design pattern enforces a controlled hierarchy and improves code maintainability by restricting inheritance.

## Interface Definition

```java
public sealed interface ICreateActivityService permits CreateActivityService {

    ActivityResponse execute(CreateActivityRequest request);

}
```

## Methods

### `execute`

The sole method of this interface, responsible for processing a `CreateActivityRequest` and returning an `ActivityResponse`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `CreateActivityRequest` | The request object containing all necessary data to create a new activity (e.g., activity name, description, date, location). |

| Returns | Type | Description |
|---------|------|-------------|
| `ActivityResponse` | `ActivityResponse` | The response object containing the result of the activity creation operation (e.g., the created activity's ID, status, or error details). |

## Usage Example

```java
// Assuming you have an instance of ICreateActivityService
ICreateActivityService service = new CreateActivityService();
CreateActivityRequest request = new CreateActivityRequest(/* ... */);
ActivityResponse response = service.execute(request);
```

## Related Components

- **`CreateActivityRequest`**: The input data transfer object (DTO) for activity creation.
- **`ActivityResponse`**: The output DTO representing the result of the creation operation.
- **`CreateActivityService`**: The concrete implementation of this interface.

## Notes

- The `sealed` keyword ensures that only `CreateActivityService` can implement this interface, providing a clear and restricted API contract.
- This interface follows the Command pattern, encapsulating the activity creation logic behind a single `execute` method.
