# VenueRepository

The `VenueRepository` interface provides database access operations for the `Venue` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD (Create, Read, Update, Delete) functionality, and includes a custom query method for looking up venues by their external source identifier.

## Purpose

This repository serves as the data access layer for venue management within the application. By extending `JpaRepository<Venue, Long>`, it automatically provides:

- Standard CRUD operations (save, findById, findAll, delete, etc.)
- Pagination and sorting support
- Batch operations

The custom `findBySourceId` method enables efficient lookups of venues using their external system identifier, which is essential for data synchronization and deduplication when integrating with third-party venue data sources.

## Public Methods

### Inherited Methods from JpaRepository

The following methods are inherited from `JpaRepository<Venue, Long>` and are available for use:

| Method | Description |
|--------|-------------|
| `findAll()` | Returns all venue entities |
| `findById(Long id)` | Finds a venue by its primary key |
| `save(Venue entity)` | Saves a venue entity (insert or update) |
| `delete(Venue entity)` | Deletes a venue entity |
| `deleteById(Long id)` | Deletes a venue by its primary key |
| `count()` | Returns the total number of venue entities |
| `existsById(Long id)` | Checks if a venue exists by its primary key |

### Custom Methods

#### `findBySourceId(String sourceId)`

Finds a venue by its external source identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `sourceId` | `String` | The unique identifier from an external system |

| Return Type | Description |
|-------------|-------------|
| `Optional<Venue>` | An Optional containing the venue if found, or empty if no venue exists with the given source ID |

**Usage Example:**

```java
@Autowired
private VenueRepository venueRepository;

// Find a venue by its external source ID
Optional<Venue> venue = venueRepository.findBySourceId("ext_venue_12345");
if (venue.isPresent()) {
    // Process the existing venue
    Venue existingVenue = venue.get();
} else {
    // Create a new venue
    Venue newVenue = new Venue();
    newVenue.setSourceId("ext_venue_12345");
    venueRepository.save(newVenue);
}
```

## Dependencies

- **Spring Data JPA**: Provides the `JpaRepository` interface and automatic query implementation
- **Venue Entity**: The domain entity that this repository manages
- **Java Optional**: Used for null-safe return values

## Notes

- The `findBySourceId` method is automatically implemented by Spring Data JPA based on the method naming convention
- The `sourceId` field should be indexed in the database for optimal query performance
- This repository is typically injected into service classes using `@Autowired` or constructor injection
