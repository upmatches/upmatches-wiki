# Clock Configuration

The `ClockConfiguration` class is a Spring `@Configuration` class that provides a centralized bean definition for a `java.time.Clock` instance. This configuration ensures that all components in the application use a consistent clock source, which is essential for time-dependent operations, testing, and maintaining time zone consistency.

By default, this configuration creates a clock that returns the current instant in the UTC time zone using `Clock.systemUTC()`. This approach simplifies testing by allowing the clock to be easily mocked or replaced with a fixed clock for deterministic time-based tests.

## Bean Definition

| Method | Return Type | Description |
|--------|-------------|-------------|
| `clock()` | `java.time.Clock` | Creates and returns a `Clock` instance set to the UTC time zone. This bean can be injected into any Spring-managed component that requires time-related functionality. |

## Usage Example

```java
@Service
public class TimeService {
    private final Clock clock;

    public TimeService(Clock clock) {
        this.clock = clock;
    }

    public Instant getCurrentTime() {
        return Instant.now(clock);
    }
}
```

## Testing Benefits

Using a configurable `Clock` bean makes unit testing time-dependent code straightforward:

```java
@Test
void testWithFixedClock() {
    Instant fixedInstant = Instant.parse("2024-01-15T10:00:00Z");
    Clock fixedClock = Clock.fixed(fixedInstant, ZoneOffset.UTC);
    
    // Inject the fixed clock into your service
    TimeService timeService = new TimeService(fixedClock);
    
    assertEquals(fixedInstant, timeService.getCurrentTime());
}
```
