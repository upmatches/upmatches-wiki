# IRecordAuditEventService Interface

## Purpose

The `IRecordAuditEventService` interface defines a contract for recording audit events within the application. It is a **sealed interface**, meaning only the explicitly permitted implementing class (`RecordAuditEventService`) can implement it. This design enforces a controlled and secure extension point for audit event recording, ensuring that all audit events are processed through a single, well-defined implementation.

This interface is part of the audit features module and is used to decouple the audit event recording logic from the rest of the application, promoting maintainability and testability.

## Interface Definition

```java
public sealed interface IRecordAuditEventService permits RecordAuditEventService {
    void record(AuditEventRequest request);
}
```

## Methods

### `record`

Records an audit event based on the provided request data.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `AuditEventRequest` | The request object containing the details of the audit event to be recorded. |

**Return Type:** `void`

**Behavior:** This method is responsible for persisting or processing the audit event information contained in the `AuditEventRequest`. The exact implementation (e.g., logging to a database, sending to a message queue, writing to a file) is defined by the implementing class `RecordAuditEventService`.

## Usage Example

```java
// Assuming RecordAuditEventService is injected
IRecordAuditEventService auditService = new RecordAuditEventService();

AuditEventRequest eventRequest = new AuditEventRequest();
// ... populate eventRequest with audit data ...

auditService.record(eventRequest);
```

## Related Components

- **`RecordAuditEventService`**: The sole permitted implementation of this interface.
- **`AuditEventRequest`**: The data transfer object (DTO) that carries the audit event details.
