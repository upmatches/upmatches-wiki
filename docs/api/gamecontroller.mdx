# GameController

The `GameController` class is a REST controller that handles all game-related HTTP requests in the UpMatches application. It provides endpoints for creating, reading, updating, and deleting games, as well as managing game participants and filtering game listings.

## Base URL

All endpoints are prefixed with `/api/v1/games`.

## Endpoints

### Create Game

Creates a new game.

**HTTP Method:** `POST`

**Endpoint:** `/api/v1/games`

**Request Body:** `CreateGameRequest` (validated)

**Response:** `201 Created`

| Parameter | Type | Description |
|-----------|------|-------------|
| body | CreateGameRequest | The game creation details |

**Response Body:**
```json
{
  "data": GameResponse,
  "message": "Game created successfully.",
  "path": "/api/v1/games"
}
```

### List Games

Retrieves a paginated list of games with optional filters.

**HTTP Method:** `GET`

**Endpoint:** `/api/v1/games`

**Query Parameters:**

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| cursor | String | No | - | Pagination cursor |
| size | Integer | No | 20 | Page size (max 100) |
| venueIds | List<Long> | No | - | Filter by venue IDs |
| skillLevelIds | List<Long> | No | - | Filter by skill level IDs |
| fromDate | LocalDate | No | - | Filter by start date |
| toDate | LocalDate | No | - | Filter by end date |
| fromTime | LocalTime | No | - | Filter by start time |
| toTime | LocalTime | No | - | Filter by end time |
| latitude | BigDecimal | No | - | Filter by latitude |
| longitude | BigDecimal | No | - | Filter by longitude |
| radiusKm | Integer | No | - | Search radius in kilometers |

**Response:** `200 OK`

**Response Body:**
```json
{
  "data": CursorPagedResponse<GameResponse>,
  "message": "Games retrieved successfully.",
  "path": "/api/v1/games"
}
```

### Get Game Filter Options

Retrieves available filter options for games.

**HTTP Method:** `GET`

**Endpoint:** `/api/v1/games/filter-options`

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| fromDate | LocalDate | Yes | Start date for filtering |
| toDate | LocalDate | Yes | End date for filtering |
| venueIds | List<Long> | No | Filter by venue IDs |
| skillLevelIds | List<Long> | No | Filter by skill level IDs |
| fromTime | LocalTime | No | Filter by start time |
| toTime | LocalTime | No | Filter by end time |
| gameType | GameType | No | Filter by game type |
| latitude | BigDecimal | No | Filter by latitude |
| longitude | BigDecimal | No | Filter by longitude |
| radiusKm | Integer | No | Search radius in kilometers |

**Response:** `200 OK`

**Response Body:**
```json
{
  "data": GameFilterOptionsResponse,
  "message": "Game filter options retrieved successfully.",
  "path": "/api/v1/games/filter-options"
}
```

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| id | UUID | The game ID |

**Request Body:** `UpdateGameRequest` (validated)

**Response Body:**

```json
{
```

### Soft Delete Game

Soft deletes a game (marks as inactive).

**HTTP Method:** `DELETE`

**Endpoint:** `/api/v1/games/{id}`

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| id | UUID | The game ID |

**Response:** `204 No Content`

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|

**Response Body:**
```json
{
```

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|

### Expel Participant

Expels a participant from a game.

**HTTP Method:** `DELETE`

**Endpoint:** `/api/v1/games/{gameId}/participants/{participantId}`

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| gameId | UUID | The game ID |
| participantId | UUID | The participant ID |

**Request Body (optional):** `ExpelParticipantRequest`

**Response:** `204 No Content`

## Error Handling

All endpoints return appropriate HTTP status codes:
- `200 OK` for successful GET and PUT requests
- `201 Created` for successful POST requests
- `204 No Content` for successful DELETE requests
- `400 Bad Request` for validation errors
- `404 Not Found` when a resource is not found
- `500 Internal Server Error` for unexpected errors
