# GameController

The `GameController` class is a REST controller that handles all game-related HTTP requests in the UpMatches application. It provides endpoints for creating, retrieving, updating, and deleting games, as well as managing game participants and filtering game listings.

## Base URL

All endpoints are prefixed with `/api/v1/games`.

## Endpoints

### Create Game

Creates a new game with the specified details.

**Endpoint:** `POST /api/v1/games`

**Request Body:** `CreateGameRequest` (validated)

**Response:** `201 Created`

| Parameter | Type | Description |
|-----------|------|-------------|
| body | CreateGameRequest | Game creation details |
| request | HttpServletRequest | HTTP request object |

**Response Body:**
```json
{
  "data": {
    "id": "uuid",
    "title": "string",
    "description": "string",
    "gameType": "string",
    "venueId": "number",
    "skillLevelId": "number",
    "date": "date",
    "time": "time",
    "maxParticipants": "number",
    "currentParticipants": "number",
    "status": "string"
  },
  "message": "Game created successfully.",
  "path": "/api/v1/games"
}
```

### List Games

Retrieves a paginated list of games with optional filtering.

**Endpoint:** `GET /api/v1/games`

**Query Parameters:**

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| cursor | String | No | - | Pagination cursor |
| size | Integer | No | 20 | Page size (max 100) |
| venueIds | List<Long> | No | - | Filter by venue IDs |
| skillLevelIds | List<Long> | No | - | Filter by skill level IDs |
| fromDate | LocalDate | No | - | Filter by start date |
| toDate | LocalDate | No | - | Filter by end date |
| fromTime | LocalTime | No | - | Filter by start time |
| toTime | LocalTime | No | - | Filter by end time |
| latitude | BigDecimal | No | - | Location filter latitude |
| longitude | BigDecimal | No | - | Location filter longitude |
| radiusKm | Integer | No | - | Location filter radius |

**Response:** `200 OK`

```json
{
  "data": {
    "items": [
      {
        "id": "uuid",
        "title": "string",
        "gameType": "string",
        "venueId": "number",
        "date": "date",
        "time": "time",
        "currentParticipants": "number",
        "maxParticipants": "number"
      }
    ],
    "nextCursor": "string",
    "hasMore": true
  },
  "message": "Games retrieved successfully.",
  "path": "/api/v1/games"
}
```

| fromTime | LocalTime | No | Filter by start time |
| toTime | LocalTime | No | Filter by end time |
| gameType | GameType | No | Filter by game type |
| latitude | BigDecimal | No | Location filter latitude |
| longitude | BigDecimal | No | Location filter longitude |
| radiusKm | Integer | No | Location filter radius |

**Response:** `200 OK`

```json

        "id": "number",
        "name": "string",
        "address": "string"
      }
    ],
    "skillLevels": [

        "description": "string"

    ],
    "gameTypes": ["string"],
    "availableDates": ["date"]
  },
  "message": "Game filter options retrieved successfully.",
  "path": "/api/v1/games/filter-options"
}
```

### Soft Delete Game

Soft deletes a game (marks as inactive).

**Endpoint:** `DELETE /api/v1/games/{id}`

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| id | UUID | Game ID |

**Response:** `204 No Content`

### Expel Participant

Expels a participant from a game.

**Endpoint:** `DELETE /api/v1/games/{gameId}/participants/{participantId}`

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| gameId | UUID | Game ID |
| participantId | UUID | Participant ID |

**Request Body (optional):** `ExpelParticipantRequest`

| Field | Type | Description |
|-------|------|-------------|
| reason | String | Reason for expulsion |

**Response:** `204 No Content`

## Error Responses

All endpoints may return the following error responses:

| Status Code | Description |
|-------------|-------------|
| 400 | Bad Request - Invalid input parameters |
| 401 | Unauthorized - Authentication required |
| 403 | Forbidden - Insufficient permissions |
| 404 | Not Found - Resource not found |
| 409 | Conflict - Resource conflict (e.g., game full) |
| 422 | Unprocessable Entity - Validation errors |
| 500 | Internal Server Error |
