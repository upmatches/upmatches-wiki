# GameController

The `GameController` class is a REST controller that handles all game-related HTTP requests in the UpMatches application. It provides endpoints for creating, reading, updating, and deleting games, as well as managing game participants and filtering game listings.

## Base URL

All endpoints are prefixed with `/api/v1/games`.

## Endpoints

### Create Game

Creates a new game with the specified details.

**HTTP Method:** `POST`

**Endpoint:** `/api/v1/games`

**Request Body:** `CreateGameRequest` (validated)

**Response:** `201 Created`

| Parameter | Type | Description |
|-----------|------|-------------|
| body | CreateGameRequest | Game creation details (validated) |

**Response Body:**
```json
{
  "data": GameResponse,
  "message": "Game created successfully.",
  "path": "/api/v1/games"
}
```

---

### List Games

Retrieves a paginated list of games with optional filtering.

**HTTP Method:** `GET`

**Endpoint:** `/api/v1/games`

**Query Parameters:**

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| cursor | String | No | - | Pagination cursor |
| size | Integer | No | 20 | Page size (max validated) |
| venueIds | List<Long> | No | - | Filter by venue IDs |
| skillLevelIds | List<Long> | No | - | Filter by skill level IDs |
| fromDate | LocalDate | No | - | Filter by start date |
| toDate | LocalDate | No | - | Filter by end date |
| fromTime | LocalTime | No | - | Filter by start time |
| toTime | LocalTime | No | - | Filter by end time |
| latitude | BigDecimal | No | - | Location filter latitude |
| longitude | BigDecimal | No | - | Location filter longitude |
| radiusKm | Integer | No | - | Location filter radius |

**Response:** `200 OK`

**Response Body:**
```json
{
  "data": CursorPagedResponse<GameResponse>,
  "message": "Games retrieved successfully.",
  "path": "/api/v1/games"
}
```

---

### Get Filter Options

**HTTP Method:** `GET`

**Endpoint:** `/api/v1/games/filter-options`

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| fromDate | LocalDate | Yes | Start date for filtering |
| toDate | LocalDate | Yes | End date for filtering |
| venueIds | List<Long> | No | Filter by venue IDs |
| skillLevelIds | List<Long> | No | Filter by skill level IDs |
| fromTime | LocalTime | No | Filter by start time |
| toTime | LocalTime | No | Filter by end time |
| gameType | GameType | No | Filter by game type |
| latitude | BigDecimal | No | Location filter latitude |
| longitude | BigDecimal | No | Location filter longitude |
| radiusKm | Integer | No | Location filter radius |

**Response:** `200 OK`

**Response Body:**
```json
{
  "data": GameFilterOptionsResponse,
  "message": "Game filter options retrieved successfully.",
  "path": "/api/v1/games/filter-options"
}
```

### Expel Participant

Removes a participant from a game (admin action).

**HTTP Method:** `DELETE`

**Endpoint:** `/api/v1/games/{gameId}/participants/{participantId}`

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| gameId | UUID | Game ID |
| participantId | UUID | Participant ID |

**Request Body (optional):** `ExpelParticipantRequest`

**Response:** `204 No Content`

## Error Handling

All endpoints return appropriate HTTP status codes:
- `200 OK` - Successful retrieval/update
- `201 Created` - Successful creation
- `204 No Content` - Successful deletion
- `400 Bad Request` - Invalid input parameters
- `404 Not Found` - Resource not found
- `500 Internal Server Error` - Server error

## Dependencies

The controller depends on the following service interfaces:

| Service Interface | Purpose |
|-------------------|---------|
| ICreateGameService | Creates new games |
| IListGamesCursorService | Lists games with cursor pagination |
| IGetGameService | Retrieves individual games |
| IGetGameFilterOptionsService | Gets filter options |
| IGetGameDateAvailabilityService | Gets date availability |
| IUpdateGameService | Updates existing games |
| ISoftDeleteGameService | Soft deletes games |
| IJoinGameService | Handles game joining |
| ILeaveGameService | Handles game leaving |
| IListGameParticipantsService | Lists game participants |
| IExpelParticipantService | Handles participant expulsion |
