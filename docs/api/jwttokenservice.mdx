# JwtTokenService

The `JwtTokenService` class is a Spring service responsible for generating JWT access tokens and refresh tokens for user authentication. It implements the `IJwtTokenService` interface and uses Nimbus JOSE + JWT library for JWT creation and signing with ES256 (ECDSA using P-256 and SHA-256) algorithm.

## Purpose

This service handles token generation for multiple authentication providers (Singpass, Auth0, and Apple). It ensures that a user can only have one authentication provider at a time and generates cryptographically secure refresh tokens.

## Dependencies

- **SigningKeyProvider**: Provides the signing key and key ID for JWT signing
- **JwtProperties**: Configuration properties for JWT (issuer, audience, token expiry)

## Public Methods

### generateAccessToken

Generates a signed JWT access token for a user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `userId` | `UUID` | The user's unique identifier |
| `singpassUuid` | `String` | Singpass UUID (nullable) |
| `auth0Uuid` | `String` | Auth0 UUID (nullable) |
| `appleUuid` | `String` | Apple UUID (nullable) |

**Returns**: `AccessTokenResult` - A record containing the serialized JWT token and its expiration timestamp (UTC epoch seconds).

**Throws**:
- `IllegalArgumentException` if multiple authentication provider UUIDs are provided
- `IllegalStateException` if token signing fails

### generateRefreshToken

Generates a cryptographically secure random refresh token.

| Parameter | Type | Description |
|-----------|------|-------------|
| None | | |

**Returns**: `String` - A Base64 URL-encoded refresh token (32 random bytes, no padding).

## Inner Types

### AccessTokenResult

A record that encapsulates the result of access token generation.

| Field | Type | Description |
|-------|------|-------------|
| `token` | `String` | The serialized JWT token |
| `expiresAtUtc` | `Long` | Token expiration time in UTC epoch seconds |

### ProviderClaim (private)

An internal record used to manage authentication provider claims.

| Field | Type | Description |
|-------|------|-------------|
| `uuidClaim` | `String` | The claim name for the provider UUID |
| `provider` | `String` | The provider identifier |
| `value` | `String` | The provider UUID value |

## Key Implementation Details

1. **Single Provider Enforcement**: The `applyProviderClaims` method ensures that only one authentication provider UUID is set per token. If multiple providers are detected, it throws an `IllegalArgumentException`.

2. **JWT Claims**: Each generated token includes:
   - `sub`: User UUID
   - `iss`: Issuer from configuration
   - `aud`: Audience from configuration
   - `iat`: Issued at time
   - `nbf`: Not before time
   - `exp`: Expiration time
   - Provider-specific claim (e.g., `singpass_uuid`, `auth0_uuid`, `apple_uuid`)
   - `auth_provider`: The authentication provider name

3. **Token Signing**: Uses ES256 (ECDSA with P-256 curve) algorithm with the signing key provided by `SigningKeyProvider`.

4. **Refresh Token Security**: Uses `SecureRandom` to generate cryptographically strong random bytes for refresh tokens.

## Usage Example

```java
@Autowired
private JwtTokenService jwtTokenService;

// Generate access token for a Singpass user
AccessTokenResult result = jwtTokenService.generateAccessToken(
    userId,
    "singpass-uuid-123",
    null,
    null
);

// Generate refresh token
String refreshToken = jwtTokenService.generateRefreshToken();
```
