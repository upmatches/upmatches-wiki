## Purpose

The `JwtTokenService` class is a part of the authentication feature in the application. It is responsible for generating JSON Web Tokens (JWTs) for user authentication. The class provides methods to create access tokens and refresh tokens, ensuring secure and efficient user session management.

## Public Methods

### `generateAccessToken`

Generates an access token for a user based on their unique identifiers from different authentication providers.

| Parameter     | Type   | Description                                      |
|---------------|--------|--------------------------------------------------|
| `userId`      | `UUID` | The unique identifier of the user.               |
| `singpassUuid`| `String` | The Singpass unique identifier for the user.   |
| `auth0Uuid`   | `String` | The Auth0 unique identifier for the user.      |
| `appleUuid`   | `String` | The Apple unique identifier for the user.      |

**Returns**: `AccessTokenResult` - An object containing the serialized JWT and its expiration time in UTC seconds.

### `generateRefreshToken`

Generates a secure random refresh token encoded in Base64 URL format.

| Parameter | Type | Description |
|-----------|------|-------------|
| *(none)*  |      |             |

**Returns**: `String` - A Base64 URL encoded string representing the refresh token.
