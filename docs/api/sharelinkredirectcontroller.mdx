# ShareLinkRedirectController

The `ShareLinkRedirectController` is a Spring REST controller responsible for handling share link redirections. It accepts a short alphanumeric code via a URL path, resolves it to a full web URL using the `IResolveShareLinkService`, and returns an HTTP 302 (Found) redirect response with the resolved URL appended with the original share code as a query parameter.

## Purpose

This controller enables the application to support shortened share links (e.g., `/s/AbCd1234`) that redirect users to the actual destination URL. The original share code is preserved in the redirect URL as a `from=` query parameter, allowing downstream systems to track which share link was used.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IResolveShareLinkService` | Service | Interface for resolving a share link code to its corresponding web URL |

## Endpoints

### GET `/s/{code}`

Redirects the user to the resolved web URL with the share code appended as a query parameter.

#### Path Parameters

| Parameter | Type | Validation | Description |
|-----------|------|------------|-------------|
| `code` | `String` | Must be exactly 8 alphanumeric characters (`[0-9A-Za-z]{8}`) | The share link code to resolve |

#### Response

| Status Code | Description |
|-------------|-------------|
| `302 Found` | Redirect to the resolved URL with `from={code}` query parameter |

#### Example

**Request:**
```
GET /s/AbCd1234
```

**Response:**
```
HTTP/1.1 302 Found
Location: https://example.com/profile?from=AbCd1234
```

## How It Works

1. The controller receives a GET request with an 8-character alphanumeric code in the path.
2. The code is validated against the pattern `^[0-9A-Za-z]{8}$`.
3. The `IResolveShareLinkService.execute(code)` method is called to resolve the code to a `PublicShareLinkResponse` containing the target web URL.
4. The `appendFromCode()` private method appends `from={code}` to the resolved URL:
   - If the URL already contains a `?` (query delimiter), the parameter is appended using `&`.
   - Otherwise, the parameter is appended using `?`.
5. An HTTP 302 redirect response is returned with the `Location` header set to the constructed URL.

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `CODE_PATTERN` | `^[0-9A-Za-z]{8}$` | Regex pattern for validating share link codes |
| `MSG_INVALID_CODE` | `"Share link code must be 8 alphanumeric characters."` | Error message for invalid codes |
| `FROM_QUERY_KEY` | `from=` | Query parameter key for the original share code |
| `QUERY_DELIMITER` | `?` | Character used to start query parameters |
| `QUERY_SEPARATOR` | `&` | Character used to separate multiple query parameters |
