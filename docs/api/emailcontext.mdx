# EmailContext

The `EmailContext` class is a Java record that encapsulates all the data needed to render an email notification for a game event. It provides a structured, immutable data container with factory methods to create instances from different sources, such as a `Game` entity or for aggregate reminders.

## Purpose

- **Centralize email data**: Collects all relevant fields (game title, venue, date, time, skill level, etc.) into a single object.
- **Simplify email template rendering**: Provides a consistent data shape for email templates, reducing the need for null checks and formatting logic in the template layer.
- **Support multiple email types**: Offers factory methods for creating contexts from a game object or for aggregate reminders (e.g., weekly summaries).

## Record Components

| Field       | Type        | Description                                      |
|-------------|-------------|--------------------------------------------------|
| `gameTitle` | `String`    | The title or name of the game.                   |
| `venue`     | `String`    | The name of the venue where the game is held.    |
| `date`      | `LocalDate` | The date of the game.                            |
| `startTime` | `LocalTime` | The start time of the game.                      |
| `endTime`   | `LocalTime` | The end time of the game.                        |
| `skillLevel`| `String`    | The skill level label (single or range).         |
| `courtCount`| `Integer`   | The number of courts (used in aggregate emails). |
| `gameUrl`   | `String`    | A URL linking to the game details.               |

## Public Methods

### `empty()`

Creates an `EmailContext` with all fields set to `null`. Useful as a fallback or placeholder.

**Returns:** `EmailContext` – an empty context instance.

### `fromGame(Game game, String gameTitle, String gameUrl)`

Constructs an `EmailContext` from a `Game` entity, extracting and formatting the relevant data.

**Parameters:**

| Parameter   | Type    | Description                                      |
|-------------|---------|--------------------------------------------------|
| `game`      | `Game`  | The game entity to extract data from.            |
| `gameTitle` | `String`| The title to use for the game.                   |
| `gameUrl`   | `String`| The URL linking to the game details.             |

**Returns:** `EmailContext` – a fully populated context, or an empty context if `game` is `null`.

**Behavior:**
- Converts the game's start time to Singapore Time (SGT) to extract the date and start/end times.
- Retrieves the venue name via `venueName()`.
- Formats the skill level label via `skillLevelLabel()`.

### `aggregateReminder(LocalDate date, Integer courtCount)`

Creates an `EmailContext` specifically for aggregate reminder emails (e.g., weekly summaries). Only the `date` and `courtCount` fields are populated; all others are `null`.

**Parameters:**

| Parameter    | Type        | Description                                      |
|--------------|-------------|--------------------------------------------------|
| `date`       | `LocalDate` | The date associated with the reminder.           |
| `courtCount` | `Integer`   | The total number of courts booked.               |

**Returns:** `EmailContext` – a context with only `date` and `courtCount` set.

## Private Helper Methods

### `venueName(Venue venue)`

Extracts the name from a `Venue` object, returning `null` if the venue is `null`.

**Parameters:**

| Parameter | Type    | Description              |
|-----------|---------|--------------------------|
| `venue`   | `Venue` | The venue entity.        |

**Returns:** `String` – the venue name, or `null`.

### `skillLevelLabel(SkillLevel from, SkillLevel to)`

Formats a skill level label. If only one level is provided, it returns that level's name. If two different levels are provided, it returns a range in the format "From – To". Returns `null` if the `from` level is `null`.

**Parameters:**

| Parameter | Type         | Description                          |
|-----------|--------------|--------------------------------------|
| `from`    | `SkillLevel` | The starting skill level.            |
| `to`      | `SkillLevel` | The ending skill level (optional).   |

**Returns:** `String` – the formatted skill level label, or `null`.

## Usage Example

```java
// Create a context from a game
Game game = gameService.findById(gameId);
EmailContext context = EmailContext.fromGame(game, "Friday Night Badminton", "https://example.com/game/123");

// Create an aggregate reminder context
EmailContext reminder = EmailContext.aggregateReminder(LocalDate.now(), 5);
```

## Notes

- All time conversions use the Singapore Time Zone (`Asia/Singapore`).
- The record is immutable, making it safe for use in concurrent environments and email template rendering.
