# EmailContext

The `EmailContext` class is a Java record that encapsulates the data required for rendering email notifications related to game events. It provides a structured, immutable representation of game details such as title, venue, date, time, skill level, court count, and a deep link URL. The class includes factory methods for creating instances from a `Game` entity or for aggregate reminders, as well as a method to produce an empty context.

## Record Components

| Component    | Type        | Description                                      |
|--------------|-------------|--------------------------------------------------|
| `gameTitle`  | `String`    | The title of the game.                           |
| `venue`      | `String`    | The name of the venue.                           |
| `date`       | `LocalDate` | The date of the game.                            |
| `startTime`  | `LocalTime` | The start time of the game.                      |
| `endTime`    | `LocalTime` | The end time of the game.                        |
| `skillLevel` | `String`    | The skill level label (single or range).         |
| `courtCount` | `Integer`   | The number of courts (used in aggregate reminders). |
| `gameUrl`    | `String`    | A deep link URL to the game.                     |

## Constants

| Constant              | Type       | Description                                      |
|-----------------------|------------|--------------------------------------------------|
| `SGT`                 | `ZoneId`   | The Singapore time zone (`Asia/Singapore`).      |
| `SKILL_RANGE_TEMPLATE`| `String`   | Template for formatting a skill level range (`%s – %s`). |

## Methods

### `empty()`

```java
public static EmailContext empty()
```

Creates an `EmailContext` with all fields set to `null`. Useful as a fallback or default value.

**Returns:** `EmailContext` – an empty context instance.

### `fromGame(Game game, String gameTitle, String gameUrl)`

```java
public static EmailContext fromGame(Game game, String gameTitle, String gameUrl)
```

Constructs an `EmailContext` from a `Game` entity. Converts the game's start and end times to Singapore time zone, extracts the venue name, and formats the skill level label (single level or range). If the `game` parameter is `null`, returns an empty context.

**Parameters:**

| Parameter   | Type     | Description                                      |
|-------------|----------|--------------------------------------------------|
| `game`      | `Game`   | The game entity to extract data from.            |
| `gameTitle` | `String` | The title of the game.                           |
| `gameUrl`   | `String` | A deep link URL to the game.                     |

**Returns:** `EmailContext` – a populated context instance, or an empty context if `game` is `null`.

### `aggregateReminder(LocalDate date, Integer courtCount)`

```java
public static EmailContext aggregateReminder(LocalDate date, Integer courtCount)
```

Creates an `EmailContext` specifically for aggregate reminder emails. Only the `date` and `courtCount` fields are populated; all other fields are set to `null`.

**Parameters:**

| Parameter    | Type        | Description                                      |
|--------------|-------------|--------------------------------------------------|
| `date`       | `LocalDate` | The date for the aggregate reminder.             |
| `courtCount` | `Integer`   | The number of courts to include in the reminder. |

**Returns:** `EmailContext` – a context instance with only date and court count set.

### `venueName(Venue venue)`

```java
private static String venueName(Venue venue)
```

Extracts the name from a `Venue` object. Returns `null` if the venue is `null`.

**Parameters:**

| Parameter | Type    | Description                                      |
|-----------|---------|--------------------------------------------------|
| `venue`   | `Venue` | The venue entity.                                |

**Returns:** `String` – the venue name, or `null`.

### `skillLevelLabel(SkillLevel from, SkillLevel to)`

```java
private static String skillLevelLabel(SkillLevel from, SkillLevel to)
```

Formats the skill level label. If only `from` is provided, returns its name. If both `from` and `to` are provided and are different, returns a range string (e.g., "Beginner – Intermediate"). If `from` is `null`, returns `null`.

**Parameters:**

| Parameter | Type         | Description                                      |
|-----------|--------------|--------------------------------------------------|
| `from`    | `SkillLevel` | The lower bound of the skill level range.        |
| `to`      | `SkillLevel` | The upper bound of the skill level range.        |

**Returns:** `String` – the formatted skill level label, or `null`.
