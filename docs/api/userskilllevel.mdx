# UserSkillLevel

The `UserSkillLevel` entity represents the association between a user and a specific skill level within the context of an activity. It serves as a join table in a many-to-many relationship between `User` and `SkillLevel`, while also linking to the associated `Activity`.

## Purpose

This entity is used to track which skill level a user has achieved for a particular activity. It ensures that each user-skill-level combination is unique and properly associated with the correct activity.

## Entity Details

- **Package:** `com.upmatches.app.features.user.entities`
- **Table:** `user_skill_levels`
- **Annotations:** `@Entity`, `@Table`, `@Getter` (Lombok)

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UserSkillLevelId` | Composite primary key consisting of `userId` and `skillLevelId` |
| `user` | `User` | The user associated with this skill level |
| `skillLevel` | `SkillLevel` | The skill level assigned to the user |
| `activity` | `Activity` | The activity context for this user-skill-level association |

## Relationships

- **Many-to-One with User:** Each `UserSkillLevel` belongs to one `User`. The foreign key `user_id` maps to the `userId` part of the composite key.
- **Many-to-One with SkillLevel:** Each `UserSkillLevel` belongs to one `SkillLevel`. The foreign key `skill_level_id` maps to the `skillLevelId` part of the composite key.
- **Many-to-One with Activity:** Each `UserSkillLevel` is associated with one `Activity`. The foreign key `activity_id` is non-nullable.

## Public Methods

### `create(User user, SkillLevel skillLevel)`

Creates a new `UserSkillLevel` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `user` | `User` | The user to associate with the skill level |
| `skillLevel` | `SkillLevel` | The skill level to assign to the user |

**Returns:** `UserSkillLevel` - A new instance with the composite key, user, skill level, and activity (derived from the skill level) set.

**Usage Example:**
```java
User user = userRepository.findById(1L).orElseThrow();
SkillLevel skillLevel = skillLevelRepository.findById(2L).orElseThrow();
UserSkillLevel userSkillLevel = UserSkillLevel.create(user, skillLevel);
```

## Notes

- The class uses a **protected no-arg constructor** required by JPA.
- The `activity` field is automatically populated from the `SkillLevel`'s associated activity during creation.
- The composite primary key is implemented via the `UserSkillLevelId` embedded class.
- Lombok's `@Getter` annotation generates getters for all fields.
