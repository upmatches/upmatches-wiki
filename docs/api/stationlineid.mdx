# StationLineId

The `StationLineId` class is a JPA embeddable composite primary key used to uniquely identify a station along a specific transit line. It combines a numeric station identifier with a transit line code to create a composite key for entities that represent station-line associations (e.g., a station belonging to a particular metro or bus line).

This class implements `Serializable` to support JPA's requirement for composite key classes to be serializable, and it overrides `equals()` and `hashCode()` to ensure correct behavior when used in collections or as a JPA entity identifier.

| Implements      | `Serializable`                                                |

| `transitLineCode` | `String` | `transit_line_code`  | 10     | Code representing the transit line (e.g., "BLUE") |

## Methods

### `equals(Object o)`

Compares this `StationLineId` with another object for equality based on both `stationId` and `transitLineCode` fields.

| Parameter | Type    | Description |
|-----------|---------|-------------|
| `o`       | `Object` | The object to compare with |

**Returns:** `boolean` - `true` if the objects are equal (same station ID and transit line code), `false` otherwise.

### `hashCode()`

Generates a hash code based on the `stationId` and `transitLineCode` fields.

**Returns:** `int` - The hash code value.

## Usage Example

```java
// Creating a composite key for station 42 on the Red Line
StationLineId id = new StationLineId(42L, "RED");

// Using the key in a JPA entity
@EmbeddedId
private StationLineId id;
```

## Notes

- The class uses Lombok's `@Getter` annotation to automatically generate getter methods for both fields.
- The `equals()` and `hashCode()` methods are implemented using `Objects.equals()` and `Objects.hash()` for null-safe comparisons.
- The `transitLineCode` field is limited to 10 characters as defined by the `@Column(length = 10)` annotation.
- This class is designed to be used as an `@EmbeddedId` in JPA entities that represent the relationship between stations and transit lines.
