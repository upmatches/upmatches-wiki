# StationLineId

The `StationLineId` class is a JPA embeddable composite primary key used to uniquely identify a relationship between a transit station and a transit line. It is designed to be used as a primary key in an entity that maps the many-to-many relationship between stations and transit lines.

## Purpose

This class serves as a composite key that combines:
- A `stationId` (Long) representing the unique identifier of a transit station
- A `transitLineCode` (String) representing the code of a transit line

By implementing `Serializable` and providing proper `equals()` and `hashCode()` methods, this class ensures that instances can be used reliably in JPA collections and as primary keys.

## Class Details

| Property | Type | Description |
|----------|------|-------------|
| `stationId` | `Long` | The unique identifier of the transit station |
| `transitLineCode` | `String` | The code of the transit line (max 10 characters) |

## Constructors

| Constructor | Description |
|-------------|-------------|
| `StationLineId()` | Protected no-argument constructor required by JPA |
| `StationLineId(Long stationId, String transitLineCode)` | Creates a new composite key with the specified station ID and transit line code |

## Methods

### `equals(Object o)`

Compares this `StationLineId` with another object for equality.

| Parameter | Type | Description |
|-----------|------|-------------|
| `o` | `Object` | The object to compare with |

**Returns:** `boolean` - `true` if the objects are equal (same station ID and transit line code), `false` otherwise

### `hashCode()`

Returns a hash code value for this `StationLineId`.

**Returns:** `int` - A hash code computed from the station ID and transit line code

## Usage Example

```java
// Creating a composite key
StationLineId key = new StationLineId(123L, "RED");

// Using in an entity
@Entity
public class StationLine {
    @EmbeddedId
    private StationLineId id;
    
    // other fields and methods
}
```

## Notes

- The class is annotated with `@Embeddable` to indicate it can be used as an embedded primary key in JPA entities
- The `@Getter` annotation from Lombok generates getter methods for both fields
- The protected no-argument constructor is required by JPA for entity instantiation
- The `equals()` and `hashCode()` methods are implemented using `Objects.equals()` and `Objects.hash()` for proper comparison and hashing
- The `transitLineCode` field is limited to 10 characters as specified by the `@Column(length = 10)` annotation
