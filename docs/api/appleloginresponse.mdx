# Apple Login Response

The `AppleLoginResponse` class is a Java record that represents the response payload returned after a successful Apple Sign-In authentication. It encapsulates the essential tokens and metadata required to manage the user's session and determine if the user is new to the application.

## Purpose

This record serves as a Data Transfer Object (DTO) for the Apple authentication flow. It provides a structured way to communicate authentication results from the backend to the client, including:
- **Access Token**: Used for authenticating subsequent API requests.
- **Refresh Token**: Used to obtain a new access token when the current one expires.
- **Expiration Time**: The timestamp when the access token expires.
- **New User Flag**: Indicates whether this is the user's first login via Apple.

## Record Components

| Field | Type | Description |
|-------|------|-------------|
| `accessToken` | `String` | The JWT access token for API authorization |
| `refreshToken` | `String` | The refresh token for obtaining new access tokens |
| `expiresAt` | `Long` | Unix timestamp (in seconds) when the access token expires |
| `isNewUser` | `Boolean` | `true` if this is the user's first login, `false` otherwise |

## Public Methods

### `of`

```java
public static AppleLoginResponse of(
    final String accessToken,
    final String refreshToken,
    final Long expiresAt,
    final Boolean isNewUser)
```

Creates a new `AppleLoginResponse` instance with the provided values.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `accessToken` | `String` | The JWT access token |
| `refreshToken` | `String` | The refresh token |
| `expiresAt` | `Long` | Unix timestamp for token expiration |
| `isNewUser` | `Boolean` | Flag indicating new user status |

**Returns:** `AppleLoginResponse` - A new instance with the specified values.

## Usage Example

```java
// Creating a response for an existing user
AppleLoginResponse response = AppleLoginResponse.of(
    "eyJhbGciOiJSUzI1NiIs...",  // access token
    "rT3fR8kL9pQ2wX5y...",      // refresh token
    1700000000L,                  // expires at
    false                         // existing user
);

// Accessing record components
String token = response.accessToken();
boolean isNew = response.isNewUser();
```

## Notes

- This record is immutable by design, ensuring thread safety and data integrity.
- The `of` static factory method provides a convenient way to instantiate the record while maintaining the same parameter order as the canonical constructor.
- The `isNewUser` field is particularly useful for onboarding flows where new users may need to complete additional profile setup.
