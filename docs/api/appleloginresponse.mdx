## Purpose

The `AppleLoginResponse` class is a Java record that encapsulates the response details from an Apple login operation. It is designed to hold essential information such as access tokens, refresh tokens, expiration time, and user status. This class provides a convenient and immutable way to manage authentication responses in applications that integrate with Apple's authentication services.

## Public Methods

The `AppleLoginResponse` class provides the following public method:

### `of`

This static method is a factory method used to create a new instance of `AppleLoginResponse`.

| Parameter     | Type    | Description                                      |
|---------------|---------|--------------------------------------------------|
| accessToken   | String  | The access token received from Apple.            |
| refreshToken  | String  | The refresh token received from Apple.           |
| expiresAt     | Long    | The timestamp (in milliseconds) when the token expires. |
| isNewUser     | Boolean | Indicates whether the user is new to the application. |

#### Return Type

- **AppleLoginResponse**: Returns a new instance of `AppleLoginResponse` initialized with the provided parameters.
