# AppleLoginResponse

The `AppleLoginResponse` class is a Java record that represents the response payload returned after a successful Apple Sign-In authentication. It encapsulates the tokens and metadata required to manage the user's session and determine if the user is new to the application.

## Purpose

This record is used to deserialize and transfer authentication data from the Apple Identity Provider (IdP) to the client application. It provides a structured way to handle:
- **Access Token**: Used for authenticating API requests.
- **Refresh Token**: Used to obtain new access tokens when the current one expires.
- **Expiration Time**: The timestamp when the access token expires.
- **New User Flag**: Indicates whether this is the user's first login via Apple.

## Record Components

| Component      | Type      | Description                                                                 |
|----------------|-----------|-----------------------------------------------------------------------------|
| `accessToken`  | `String`  | The OAuth 2.0 access token issued by Apple.                                 |
| `refreshToken` | `String`  | The OAuth 2.0 refresh token used to obtain new access tokens.               |
| `expiresAt`    | `Long`    | The Unix timestamp (in seconds) when the access token expires.              |
| `isNewUser`    | `Boolean` | `true` if the user is logging in for the first time via Apple; `false` otherwise. |

- The `isNewUser` field is particularly useful for onboarding flows where new users may need to complete additional profile setup.
