# IDeleteActivityService Interface

The `IDeleteActivityService` interface defines the contract for deleting an activity within the application. It is a sealed interface, meaning only explicitly permitted classes (in this case, `DeleteActivityService`) can implement it. This design enforces a controlled and secure implementation hierarchy, ensuring that the deletion logic is centralized and cannot be extended arbitrarily.

## Purpose

The primary purpose of this interface is to abstract the operation of deleting an activity identified by its unique ID. By defining a single method `execute`, it provides a clear and consistent API for performing deletions, allowing the underlying implementation to handle specifics such as database operations, validation, and error handling.

## Interface Definition

```java
public sealed interface IDeleteActivityService permits DeleteActivityService {
    void execute(UUID id);
}
```

## Methods

| Method | Description | Parameters | Returns |
|--------|-------------|------------|---------|
| `execute(UUID id)` | Executes the deletion of an activity identified by the given unique identifier. | `id` - The UUID of the activity to delete. | `void` |

## Usage

The interface is intended to be injected into other components (e.g., controllers, services) that need to delete activities. The actual deletion logic is implemented in the `DeleteActivityService` class.

### Example

```java
// Assuming IDeleteActivityService is injected
public class ActivityController {
    private final IDeleteActivityService deleteActivityService;

    public ActivityController(IDeleteActivityService deleteActivityService) {
        this.deleteActivityService = deleteActivityService;
    }

    public void deleteActivity(UUID activityId) {
        deleteActivityService.execute(activityId);
    }
}
```

## Implementation Notes

- The interface is sealed, so only `DeleteActivityService` is allowed to implement it.
- The `execute` method does not return a value; any errors or exceptions should be handled within the implementation.
- The use of `UUID` ensures globally unique identification of activities.
