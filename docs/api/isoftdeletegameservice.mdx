# ISoftDeleteGameService Interface

The `ISoftDeleteGameService` interface defines a contract for performing soft deletion operations on game entities. Soft deletion marks a record as deleted without physically removing it from the database, allowing for potential recovery or audit trails.

This interface is part of the game management feature in the application and follows a sealed interface pattern to restrict implementation to a single concrete class (`SoftDeleteGameService`).

## Interface Definition

```java
public sealed interface ISoftDeleteGameService permits SoftDeleteGameService {
    void execute(UUID id);
}
```

## Purpose

- Provides a standardized contract for soft-deleting game entities
- Ensures type safety and controlled implementation through Java's sealed interface feature
- Enables dependency injection and loose coupling in the service layer
- Allows only the `SoftDeleteGameService` class to implement this interface

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(UUID id)` | `void` | Performs a soft delete operation on a game identified by the provided UUID |

## Method Details

### `execute(UUID id)`

Performs the soft deletion of a game entity.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the game to be soft-deleted |

**Return Value:** None (`void`)

**Behavior:**
- Marks the specified game entity as deleted in the data store
- Does not physically remove the record from the database
- Throws appropriate exceptions if the game ID is invalid or not found (implementation-specific)

## Implementation Notes

- This is a **sealed interface**, meaning only the `SoftDeleteGameService` class is permitted to implement it
- The interface uses `UUID` for game identification, ensuring globally unique identifiers
- Implementations should handle cases where the game ID does not exist in the system

## Usage Example

```java
// Inject the service
private final ISoftDeleteGameService softDeleteGameService;

// Soft delete a game
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
softDeleteGameService.execute(gameId);
```

## Related Components

- **`SoftDeleteGameService`** - The sole implementation of this interface
- **Game Entity** - The domain object being soft-deleted
- **Game Repository** - The data access layer that performs the actual database operation
