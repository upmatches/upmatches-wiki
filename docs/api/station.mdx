# Station Entity

The `Station` class is a JPA entity that represents a physical transit station or stop within the venue management system. It maps to the `stations` database table and stores essential geographic and identification information for each station.

## Purpose

This entity serves as the core data model for managing transit stations. It captures:
- Station identification and naming
- Geographic coordinates (latitude/longitude)
- Associated transit lines through a one-to-many relationship with `StationLine`

## Class Overview

The entity uses Lombok's `@Getter` annotation to automatically generate getter methods for all fields. It implements a factory method pattern for object creation and provides a method to associate transit lines with the station.

## Fields

| Field | Type | Database Column | Constraints | Description |
|-------|------|-----------------|-------------|-------------|
| `id` | `Long` | `id` | Primary Key, Auto-generated | Unique identifier for the station |
| `name` | `String` | `name` | Not null, max 150 characters | Display name of the station |
| `latitude` | `BigDecimal` | `latitude` | Not null, precision 13, scale 10 | Geographic latitude coordinate |
| `longitude` | `BigDecimal` | `longitude` | Not null, precision 13, scale 10 | Geographic longitude coordinate |
| `stationLines` | `List<StationLine>` | N/A (OneToMany) | Cascade ALL, orphan removal | Collection of station-line associations |

## Methods

### `create(String name, BigDecimal latitude, BigDecimal longitude)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The display name for the station |
| `latitude` | `BigDecimal` | The geographic latitude coordinate |
| `longitude` | `BigDecimal` | The geographic longitude coordinate |

**Returns:** `Station` - A new Station instance with the specified properties.

This static factory method creates a new Station entity with the provided name and geographic coordinates. It ensures proper initialization of the station's core attributes.

### `addLine(TransitLine transitLine, Integer stationNumber)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `transitLine` | `TransitLine` | The transit line to associate with this station |
| `stationNumber` | `Integer` | The station's number/order on the specified transit line |

**Returns:** `void`

This method creates a new `StationLine` association between the current station and the provided transit line. The `stationNumber` parameter indicates the station's position or sequence number on that line. The new association is automatically added to the station's collection of station lines.

## Relationships

- **One-to-Many with StationLine**: A station can be associated with multiple transit lines through the `stationLines` collection. The relationship is mapped by the `station` field in the `StationLine` entity and configured with cascade ALL operations and orphan removal.

## Usage Example

```java
// Create a new station
Station station = Station.create(
    "Central Station",
    new BigDecimal("40.7128000"),
    new BigDecimal("-74.0060000")
);

// Associate with a transit line
TransitLine lineA = transitLineRepository.findById(1L).orElseThrow();
station.addLine(lineA, 1);
```

## Database Schema

The entity maps to the `stations` table with the following structure:

```sql
CREATE TABLE stations (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(150) NOT NULL,
    latitude DECIMAL(13,10) NOT NULL,
    longitude DECIMAL(13,10) NOT NULL
);
```
