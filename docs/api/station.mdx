# Station Entity

The `Station` class is a JPA entity that represents a physical transit station or stop within the venue management system. It maps to the `stations` database table and stores geographic coordinates along with associated transit line information.

## Purpose

This entity serves as the core data model for managing station locations. Each station has a name, precise latitude/longitude coordinates, and can be associated with multiple transit lines through the `StationLine` join entity. The class uses Lombok's `@Getter` annotation to automatically generate getter methods for all fields.

## Entity Structure

| Field | Type | Database Column | Constraints |
|-------|------|-----------------|-------------|
| `id` | `Long` | `id` | Primary key, auto-generated |
| `name` | `String` | `name` | Length 150, not null |
| `latitude` | `BigDecimal` | `latitude` | Precision 13, scale 10, not null |
| `longitude` | `BigDecimal` | `longitude` | Precision 13, scale 10, not null |
| `stationLines` | `List<StationLine>` | N/A (OneToMany) | Cascade all, orphan removal |

## Public Methods

### `create(String name, BigDecimal latitude, BigDecimal longitude)`

Static factory method to create a new `Station` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The station name (max 150 characters) |
| `latitude` | `BigDecimal` | Geographic latitude coordinate |
| `longitude` | `BigDecimal` | Geographic longitude coordinate |

**Returns:** `Station` - A new station entity with the provided values.

### `addLine(TransitLine transitLine, Integer stationNumber)`

Associates a transit line with this station at a specific station number.

| Parameter | Type | Description |
|-----------|------|-------------|
| `transitLine` | `TransitLine` | The transit line to associate |
| `stationNumber` | `Integer` | The station's number/order on that line |

**Returns:** `void`

## Relationships

- **OneToMany with StationLine**: A station can have multiple `StationLine` entries, each representing a different transit line that serves this station. The relationship is bidirectional with `StationLine` owning the foreign key (`mappedBy = "station"`).
- **CascadeType.ALL**: All operations (persist, merge, remove, refresh, detach) cascade to associated `StationLine` entities.
- **orphanRemoval = true**: When a `StationLine` is removed from the collection, it is automatically deleted from the database.

## Usage Example

```java
// Create a new station
Station station = Station.create(
    "Central Station",
    new BigDecimal("40.7128000000"),
    new BigDecimal("-74.0060000000")
);

// Add a transit line
TransitLine lineA = transitLineRepository.findById(1L).orElseThrow();
station.addLine(lineA, 5);

// Save the station (cascades to save StationLine)
stationRepository.save(station);
```

## Notes

- The protected no-argument constructor is required by JPA and Lombok's `@Getter` annotation.
- Geographic coordinates use `BigDecimal` with high precision (13 digits total, 10 decimal places) for accurate location storage.
- The `stationLines` list is initialized as an empty `ArrayList` to prevent null pointer exceptions.
