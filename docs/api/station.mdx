# Station Entity

The `Station` class is a JPA entity representing a physical transit station or stop within the venue system. It stores the station's geographic coordinates (latitude and longitude) and maintains a one-to-many relationship with `StationLine` entities, which link the station to specific transit lines.

## Purpose

This entity serves as the core data model for managing station information in a transit or venue management application. It provides:
- Persistent storage of station metadata (name, coordinates)
- Association management between stations and transit lines
- A factory method for creating new station instances
- Support for adding transit lines to a station

## Entity Details

| Property | Type | Description |
|----------|------|-------------|
| `id` | `Long` | Auto-generated primary key |
| `name` | `String` | Station name (max 150 characters, required) |
| `latitude` | `BigDecimal` | Geographic latitude (precision 13, scale 10, required) |
| `longitude` | `BigDecimal` | Geographic longitude (precision 13, scale 10, required) |
| `stationLines` | `List<StationLine>` | Collection of associated station-line mappings |

## Public Methods

### `create(String name, BigDecimal latitude, BigDecimal longitude)`

Factory method to create a new `Station` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | `String` | The name of the station |
| `latitude` | `BigDecimal` | The geographic latitude coordinate |
| `longitude` | `BigDecimal` | The geographic longitude coordinate |

**Returns:** `Station` - A new station entity with the specified properties.

### `addLine(TransitLine transitLine, Integer stationNumber)`

Associates a transit line with this station by creating a `StationLine` mapping.

| Parameter | Type | Description |
|-----------|------|-------------|
| `transitLine` | `TransitLine` | The transit line to associate with this station |
| `stationNumber` | `Integer` | The station number or order on the transit line |

**Returns:** `void`

## Database Mapping

The entity is mapped to the `stations` database table with the following column mappings:

| Column | Database Type | Constraints |
|--------|---------------|-------------|
| `id` | `BIGINT` | Primary key, auto-increment |
| `name` | `VARCHAR(150)` | NOT NULL |
| `latitude` | `DECIMAL(13,10)` | NOT NULL |
| `longitude` | `DECIMAL(13,10)` | NOT NULL |

## Relationships

- **One-to-Many with StationLine**: The `stationLines` field uses `CascadeType.ALL` and `orphanRemoval = true`, meaning all operations (persist, merge, remove) are cascaded to associated `StationLine` entities, and orphaned `StationLine` records are automatically deleted when removed from the collection.

## Usage Example

```java
// Create a new station
Station station = Station.create(
    "Central Station",
    new BigDecimal("40.7128000"),
    new BigDecimal("-74.0060000")
);

// Add a transit line
TransitLine lineA = transitLineRepository.findById(1L).orElseThrow();
station.addLine(lineA, 1);
```

## Notes

- The protected no-argument constructor is required by JPA and should not be used directly.
- The class uses Lombok's `@Getter` annotation to generate getters for all fields.
- Geographic coordinates use `BigDecimal` with high precision (13 digits total, 10 decimal places) for accurate positioning.
