# Cache Configuration

The `CacheConfiguration` class provides a centralized configuration for Redis-based caching in the application. It enables Spring's caching abstraction and configures a `RedisCacheManager` bean with sensible defaults, including a 30-minute time-to-live (TTL) for cached entries and key serialization using `StringRedisSerializer`.

This configuration is conditionally activated only when the property `spring.cache.type` is set to `redis`, allowing the application to fall back to other caching strategies (e.g., in-memory) when Redis is not available.

## Annotations

| Annotation | Description |
|---|---|
| `@Configuration` | Marks this class as a Spring configuration source. |
| `@EnableCaching` | Enables Spring's annotation-driven cache management. |
| `@ConditionalOnProperty` | Activates this configuration only when `spring.cache.type=redis` is set. |

## Public Methods

### `cacheManager`

Creates and configures a `RedisCacheManager` bean that manages Redis-backed caches.

```java
@Bean
public RedisCacheManager cacheManager(RedisConnectionFactory connectionFactory)
```

**Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `connectionFactory` | `RedisConnectionFactory` | The Redis connection factory provided by Spring Boot auto-configuration. |

**Returns:**

| Return Type | Description |
|---|---|
| `RedisCacheManager` | A fully configured Redis cache manager instance. |

**Configuration Details:**

- **Default TTL:** 30 minutes (`Duration.ofMinutes(30)`)
- **Key Serialization:** Uses `StringRedisSerializer` for cache keys
- **Null Values:** Caching null values is disabled (`disableCachingNullValues()`)

## Usage Example

To use this caching configuration, ensure your `application.properties` or `application.yml` includes:

```properties
spring.cache.type=redis
```

Then, enable caching on any service method using Spring's caching annotations:

```java
@Service
public class UserService {
    
    @Cacheable(value = "users", key = "#userId")
    public User getUserById(Long userId) {
        // Expensive database lookup
        return userRepository.findById(userId).orElse(null);
    }
}
```

## Dependencies

This configuration requires the following Spring Boot starters:

- `spring-boot-starter-cache`
- `spring-boot-starter-data-redis`

Add them to your `pom.xml`:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-cache</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```
