# Cache Configuration

## Purpose

The `CacheConfiguration` class provides a Spring Boot configuration for enabling Redis-based caching in the application. It is conditionally activated only when the `spring.cache.type` property is set to `redis`, ensuring that the Redis cache manager is only configured when Redis is the chosen caching strategy.

This configuration sets up a default Redis cache manager with a 30-minute time-to-live (TTL) for cached entries, uses string serialization for cache keys, and prevents caching of null values to optimize storage and performance.

## Key Features

- **Conditional Activation**: Only loads when Redis is configured as the cache type
- **Default TTL**: All cached entries expire after 30 minutes
- **String Key Serialization**: Cache keys are serialized as strings for compatibility
- **Null Value Prevention**: Null values are not cached, reducing unnecessary storage

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `cacheManager` | `RedisCacheManager` | `RedisConnectionFactory connectionFactory` | Creates and configures the Redis cache manager with default settings including TTL, key serialization, and null value handling |

## Configuration Properties

The following Spring Boot property controls when this configuration is active:

| Property | Value | Description |
|----------|-------|-------------|
| `spring.cache.type` | `redis` | Activates the Redis cache configuration |

## Usage Example

To enable Redis caching in your application, add the following to your `application.properties` or `application.yml`:

```properties
spring.cache.type=redis
```

Once enabled, you can use Spring's caching annotations (e.g., `@Cacheable`, `@CacheEvict`, `@CachePut`) in your services, and they will automatically use the configured Redis cache manager with the default 30-minute TTL.

## Dependencies

This configuration requires the following dependencies in your project:

- Spring Boot Cache Starter
- Spring Data Redis
- Redis server (running and accessible)

## Notes

- The default TTL of 30 minutes can be overridden on a per-cache basis using Spring's cache configuration properties
- String serialization for keys ensures compatibility across different Redis clients
- Disabling null value caching prevents cache pollution from null returns
