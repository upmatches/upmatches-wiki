# Cache Configuration

The `CacheConfiguration` class provides a Spring Boot configuration for enabling Redis-based caching in the application. It is conditionally activated only when the `spring.cache.type` property is set to `redis`, ensuring that caching is only configured when Redis is the chosen cache provider.

## Purpose

This configuration class serves the following purposes:

- **Enables caching** in the Spring application context using `@EnableCaching`
- **Configures Redis as the cache store** with sensible defaults
- **Sets a default time-to-live (TTL)** of 30 minutes for all cached entries
- **Ensures key serialization** using `StringRedisSerializer` for compatibility
- **Prevents caching of null values** to avoid unnecessary cache entries

## Conditional Activation

The configuration is only loaded when the following property is set in your `application.properties` or `application.yml`:

```properties
spring.cache.type=redis
```

## Public Methods

### `cacheManager`

Creates and configures a `RedisCacheManager` bean that manages Redis-based caches.

| Parameter | Type | Description |
|-----------|------|-------------|
| `connectionFactory` | `RedisConnectionFactory` | The Redis connection factory used to create connections to the Redis server |

| Returns | Type | Description |
|---------|------|-------------|
| `RedisCacheManager` | Bean | A fully configured Redis cache manager instance |

**Configuration Details:**

- **Default TTL**: 30 minutes (`Duration.ofMinutes(30)`)
- **Key Serialization**: Uses `StringRedisSerializer` for cache keys
- **Null Values**: Caching of null values is disabled (`disableCachingNullValues()`)

## Usage Example

Once this configuration is active, you can use Spring's caching annotations in your services:

```java
@Service
public class UserService {
    
    @Cacheable(value = "users", key = "#userId")
    public User getUserById(Long userId) {
        // Expensive database call
        return userRepository.findById(userId).orElse(null);
    }
    
    @CacheEvict(value = "users", key = "#userId")
    public void updateUser(Long userId, User user) {
        userRepository.save(user);
    }
}
```

## Dependencies

This configuration requires the following dependencies in your `pom.xml` or `build.gradle`:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-cache</artifactId>
</dependency>
```

## Notes

- The cache manager uses Redis's default cache configuration as a base
- All cache entries will expire after 30 minutes unless overridden at the method level using Spring's `@Cacheable` annotation with a custom `cacheManager`
- The configuration ensures that cache keys are stored as strings in Redis for better readability and debugging
