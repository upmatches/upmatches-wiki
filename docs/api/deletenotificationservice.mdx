# DeleteNotificationService

The `DeleteNotificationService` class is a Spring service responsible for deleting a notification owned by the currently authenticated user. It ensures that only the recipient of a notification can delete it, providing a secure deletion mechanism within the notification system.

## Purpose

This service encapsulates the business logic for deleting a notification by its unique identifier (`UUID`). It performs the following operations:

1. **Authentication**: Resolves the currently authenticated user's ID.
2. **Authorization**: Verifies that the notification exists and belongs to the authenticated user.
3. **Deletion**: Deletes the notification from the database within a transactional context.
4. **Error Handling**: Throws a `NotificationNotFoundException` if the notification is not found or does not belong to the user.

## Constructor

### `DeleteNotificationService(NotificationRepository, IAuthenticatedUserResolver)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `notificationRepository` | `NotificationRepository` | Repository for accessing notification data |
| `userResolver` | `IAuthenticatedUserResolver` | Service to resolve the currently authenticated user |

## Public Methods

### `execute(UUID id)`

Deletes a notification by its ID, ensuring it belongs to the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the notification to delete |

**Return Type:** `void`

**Throws:**
- `NotificationNotFoundException` - If the notification with the given ID does not exist or does not belong to the authenticated user
- `ResourceNotFoundException` - If an error occurs during the deletion operation

**Transactional Behavior:** This method is annotated with `@Transactional`, ensuring the deletion operation is executed within a database transaction.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `NotificationRepository` | Repository | Data access layer for notification entities |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's ID |

## Error Handling

The service uses a custom error message format: `"Notification '%s' not found for user '%s'."`, where the first placeholder is the notification ID and the second is the user ID. This message is used when constructing the `NotificationNotFoundException`.

## Usage Example

```java
@Autowired
private DeleteNotificationService deleteNotificationService;

// Delete a notification
UUID notificationId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
deleteNotificationService.execute(notificationId);
```
