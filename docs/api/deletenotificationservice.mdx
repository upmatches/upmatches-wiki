# DeleteNotificationService

The `DeleteNotificationService` class is a Spring service responsible for deleting a notification owned by the currently authenticated user. It ensures that only the intended recipient can delete their own notification, providing a secure and transactional delete operation.

## Purpose

- **Secure Deletion**: Verifies that the notification belongs to the authenticated user before deletion.
- **Transactional**: The delete operation is wrapped in a Spring `@Transactional` annotation to ensure data consistency.
- **Error Handling**: Throws a `NotificationNotFoundException` if the notification does not exist or does not belong to the user.
- **Operation Tracking**: Uses `ServiceOperationExecutor` to execute the delete operation with standardized error handling and logging.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `NotificationRepository` | Repository | Data access layer for `Notification` entities |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's ID |

## Constructor

### `DeleteNotificationService(NotificationRepository, IAuthenticatedUserResolver)`

Initializes the service with required dependencies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `notificationRepository` | `NotificationRepository` | Repository for notification persistence |
| `userResolver` | `IAuthenticatedUserResolver` | Service to resolve the authenticated user |

## Public Methods

### `execute(UUID id)`

Deletes a notification by its ID, but only if it belongs to the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the notification to delete |

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `NotificationNotFoundException` | If no notification with the given ID exists for the authenticated user |
| `ResourceNotFoundException` | If the delete operation fails (wrapped by `ServiceOperationExecutor`) |

**Behavior:**

1. Resolves the authenticated user's ID via `userResolver.requireUserId()`.
2. Queries the repository for a notification matching both the provided ID and the user's ID.
3. If not found, throws `NotificationNotFoundException` with a descriptive message.
4. If found, executes the delete operation through `ServiceOperationExecutor.executeVoid()` with the `DELETE` operation status.

## Example Usage

```java
@Autowired
private DeleteNotificationService deleteNotificationService;

public void removeNotification(UUID notificationId) {
    deleteNotificationService.execute(notificationId);
}
```

## Error Messages

| Constant | Value | Usage |
|----------|-------|-------|
| `MSG_NOT_FOUND` | `"Notification '%s' not found for user '%s'."` | Used when the notification does not exist for the given user |

## Notes

- The class is declared as `non-sealed`, indicating it is part of a sealed interface hierarchy (`IDeleteNotificationService`).
- The `@Service` annotation registers this class as a Spring bean.
- The `@Transactional` annotation ensures the delete operation is performed within a database transaction.
- The `ServiceOperationExecutor` provides consistent error handling and logging for service-level operations.
