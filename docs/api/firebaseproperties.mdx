## Overview

The `FirebaseProperties` class is a configuration properties holder for Firebase-related settings in a Spring Boot application. It is designed to map properties prefixed with `app.firebase` from the application's configuration files (such as `application.yml` or `application.properties`) to Java objects. This class is implemented as a Java record, which provides a concise way to define immutable data carriers.

## Purpose

The primary purpose of the `FirebaseProperties` class is to encapsulate the Firebase service account configuration details, specifically the service account path and the service account JSON content. It provides utility methods to check the presence of these configuration details.

## Public Methods

The `FirebaseProperties` class provides the following public methods:

| Method Name | Description | Parameters | Return Type |
|-------------|-------------|------------|-------------|
| `hasJson()` | Checks if the service account JSON content is available. | None | `boolean` |
| `hasPath()` | Checks if the service account path is available. | None | `boolean` |

## Method Details

### `hasJson()`

- **Description**: This method returns `true` if the `serviceAccountJson` property is not `null`, indicating that the JSON content for the Firebase service account is available.
- **Return Type**: `boolean`

### `hasPath()`

- **Description**: This method returns `true` if the `serviceAccountPath` property is not `null`, indicating that the path to the Firebase service account file is available.
- **Return Type**: `boolean`

## Constructor

The `FirebaseProperties` record constructor ensures that any blank strings provided for `serviceAccountPath` or `serviceAccountJson` are converted to `null` using the private static method `blankToNull`. This helps in maintaining the integrity of the configuration by treating blank values as absent.

## Private Methods

### `blankToNull(final String val)`

- **Description**: Converts a blank string to `null`. If the input string is `null` or consists only of whitespace, it returns `null`; otherwise, it returns the original string.
- **Parameters**:
  - `val`: The string to be checked and potentially converted.
- **Return Type**: `String`
