# FirebaseProperties

The `FirebaseProperties` class is a Spring Boot configuration properties record that maps properties prefixed with `app.firebase` from the application's configuration files (e.g., `application.yml` or `application.properties`). It encapsulates Firebase service account credentials, which can be provided either as a file path or as an inline JSON string.

## Purpose

This record simplifies the management of Firebase authentication credentials in a Spring Boot application. It provides a clean, immutable data structure that validates and normalizes the input values, ensuring that blank or null strings are treated as absent. The class also offers convenience methods to check which credential source is available.

## Configuration Properties

The following table describes the configuration properties bound by this record:

| Property | Type | Description |
|----------|------|-------------|
| `app.firebase.service-account-path` | `String` | File path to the Firebase service account JSON file. |
| `app.firebase.service-account-json` | `String` | Inline JSON string containing the Firebase service account credentials. |

## Constructor

The compact constructor normalizes the input parameters by converting blank strings to `null`. This ensures that the record's fields are either a valid non-blank string or `null`.

## Methods

### `hasJson()`

Returns `true` if the `serviceAccountJson` field is not `null`, indicating that an inline JSON credential is available.

**Return Type:** `boolean`

### `hasPath()`

Returns `true` if the `serviceAccountPath` field is not `null`, indicating that a file path to the service account JSON is available.

**Return Type:** `boolean`

## Usage Example

```yaml
# application.yml
app:
  firebase:
    service-account-path: /path/to/firebase-service-account.json
    # or
    service-account-json: '{"type": "service_account", ...}'
```

```java
@Autowired
private FirebaseProperties firebaseProperties;

public void configureFirebase() {
    if (firebaseProperties.hasJson()) {
        // Initialize Firebase with inline JSON
    } else if (firebaseProperties.hasPath()) {
        // Initialize Firebase from file path
    } else {
        throw new IllegalStateException("No Firebase credentials configured");
    }
}
```

## Notes

- The `blankToNull` helper method ensures that empty or whitespace-only strings are treated as missing values, preventing accidental configuration errors.
- Only one of the two properties (`serviceAccountPath` or `serviceAccountJson`) should be provided at a time. The convenience methods `hasJson()` and `hasPath()` help determine which one is available.
