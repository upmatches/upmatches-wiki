# FirebaseProperties

The `FirebaseProperties` class is a Spring Boot configuration properties record that maps properties prefixed with `app.firebase` from the application's configuration files (e.g., `application.yml` or `application.properties`). It encapsulates Firebase service account credentials, which can be provided either as a file path or as an inline JSON string.

## Purpose

This record simplifies the management of Firebase authentication credentials in a Spring Boot application. It ensures that only one valid credential source is used at a time (either a file path or a JSON string) and provides convenient methods to check which source is available.

## Configuration Properties

The following properties can be set in your application configuration:

| Property | Type | Description |
|----------|------|-------------|
| `app.firebase.service-account-path` | String | File path to the Firebase service account JSON file |
| `app.firebase.service-account-json` | String | Inline Firebase service account JSON string |

## Constructor

The compact constructor normalizes the input values by converting blank strings to `null`. This ensures that empty or whitespace-only strings are treated as unset.

## Methods

### `hasJson()`

Returns `true` if the `serviceAccountJson` property is set (non-null), otherwise `false`.

### `hasPath()`

Returns `true` if the `serviceAccountPath` property is set (non-null), otherwise `false`.

## Usage Example

```yaml
# application.yml
app:
  firebase:
    service-account-path: /path/to/firebase-service-account.json
```

Or using inline JSON:

```yaml
# application.yml
app:
  firebase:
    service-account-json: '{"type": "service_account", ...}'
```

## Notes

- Only one of `serviceAccountPath` or `serviceAccountJson` should be set at a time.
- Blank strings are automatically converted to `null` to avoid empty values being treated as valid.
- This record is immutable and thread-safe by design.
