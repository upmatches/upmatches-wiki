# FirebaseProperties

The `FirebaseProperties` class is a Spring Boot configuration properties record that maps properties prefixed with `app.firebase` from the application's configuration files (e.g., `application.yml` or `application.properties`). It encapsulates Firebase service account credentials, which can be provided either as a file path or as an inline JSON string.

## Purpose

This record is designed to centralize and validate Firebase authentication configuration. It ensures that only one of the two credential sources (file path or JSON string) is used, preventing ambiguous or conflicting configurations. The record provides convenience methods to check which credential source is available.

## Configuration Properties

The following properties are bound from the application configuration:

| Property | Type | Description |
|----------|------|-------------|
| `app.firebase.service-account-path` | `String` | File path to the Firebase service account JSON file. |
| `app.firebase.service-account-json` | `String` | Inline JSON string containing the Firebase service account credentials. |

## Constructor

The compact constructor normalizes the input values by converting blank strings to `null`. This ensures that empty or whitespace-only strings are treated as unset.

## Methods

### `blankToNull(String val)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `val` | `String` | The string value to check. |

**Returns:** `String` — Returns `null` if the input is `null` or blank; otherwise returns the original value.

### `hasJson()`

**Returns:** `boolean` — `true` if the `serviceAccountJson` property is not `null`; `false` otherwise.

### `hasPath()`

**Returns:** `boolean` — `true` if the `serviceAccountPath` property is not `null`; `false` otherwise.

## Usage Example

```java
// In your application.yml:
// app:
//   firebase:
//     service-account-path: /path/to/firebase-credentials.json

// Or using inline JSON:
// app:
//   firebase:
//     service-account-json: '{"type": "service_account", ...}'

// In your service:
@Autowired
private FirebaseProperties firebaseProperties;

public void initializeFirebase() {
    if (firebaseProperties.hasJson()) {
        // Initialize Firebase with inline JSON
    } else if (firebaseProperties.hasPath()) {
        // Initialize Firebase from file path
    } else {
        throw new IllegalStateException("Firebase credentials not configured");
    }
}
```

## Notes

- Only one of `serviceAccountPath` or `serviceAccountJson` should be configured at a time.
- The `blankToNull` method ensures that empty or whitespace-only strings are treated as unset, preventing accidental configuration errors.
- This record is immutable after construction, making it thread-safe and suitable for use in Spring's singleton beans.
