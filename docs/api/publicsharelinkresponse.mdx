# PublicShareLinkResponse

The `PublicShareLinkResponse` class is a Java record that represents the response payload for a publicly shared link. It encapsulates the essential information needed to access a shared resource, including the resource type, its identifier, and the generated URLs for both web and mobile access.

This record is typically used as the return type from API endpoints that create or retrieve public share links, providing a consistent and immutable data structure for the response.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of the shared resource (e.g., document, image, video) |
| `resourceId` | `String` | The unique identifier of the shared resource |
| `webUrl` | `String` | The URL for accessing the resource via a web browser |
| `mobileUrl` | `String` | The URL for accessing the resource via a mobile application |

## Methods

### `fromShortLink`

```java
public static PublicShareLinkResponse fromShortLink(ShortLink link, String webUrl, String mobileUrl)
```

Creates a `PublicShareLinkResponse` instance from a `ShortLink` entity and the generated URLs.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The short link entity containing the resource type and identifier |
| `webUrl` | `String` | The web URL for accessing the shared resource |
| `mobileUrl` | `String` | The mobile URL for accessing the shared resource |

**Returns:**

| Type | Description |
|------|-------------|
| `PublicShareLinkResponse` | A new response instance populated with data from the provided short link and URLs |

**Example Usage:**

```java
ShortLink shortLink = new ShortLink(ResourceType.DOCUMENT, "doc-123");
String webUrl = "https://example.com/share/doc-123";
String mobileUrl = "https://app.example.com/share/doc-123";

PublicShareLinkResponse response = PublicShareLinkResponse.fromShortLink(shortLink, webUrl, mobileUrl);
// response.resourceType() == ResourceType.DOCUMENT
// response.resourceId() == "doc-123"
// response.webUrl() == "https://example.com/share/doc-123"
// response.mobileUrl() == "https://app.example.com/share/doc-123"
```
