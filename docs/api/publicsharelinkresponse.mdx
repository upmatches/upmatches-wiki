# PublicShareLinkResponse

The `PublicShareLinkResponse` class is a Java record that represents the response payload returned when a public share link is created or retrieved. It encapsulates the essential information needed by a client to access a shared resource via both web and mobile channels.

## Purpose

This record serves as the data transfer object (DTO) for share link operations. It provides a clean, immutable representation of a share link's public-facing details, including the type of resource being shared, its identifier, and the corresponding URLs for web and mobile access.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of resource being shared (e.g., document, image, video) |
| `resourceId` | `String` | The unique identifier of the shared resource |
| `webUrl` | `String` | The URL for accessing the resource via a web browser |
| `mobileUrl` | `String` | The URL for accessing the resource via a mobile application |

## Factory Method

### `fromShortLink`

```java
public static PublicShareLinkResponse fromShortLink(ShortLink link, String webUrl, String mobileUrl)
```

Creates a `PublicShareLinkResponse` instance from a `ShortLink` entity and the generated URLs.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The source `ShortLink` entity containing resource type and ID |
| `webUrl` | `String` | The web URL for the shared resource |
| `mobileUrl` | `String` | The mobile URL for the shared resource |

**Returns:**

| Type | Description |
|------|-------------|
| `PublicShareLinkResponse` | A new response instance populated with data from the provided `ShortLink` and URLs |

**Example Usage:**

```java
ShortLink shortLink = new ShortLink(ResourceType.DOCUMENT, "doc-123");
String webUrl = "https://example.com/share/doc-123";
String mobileUrl = "https://app.example.com/share/doc-123";

PublicShareLinkResponse response = PublicShareLinkResponse.fromShortLink(shortLink, webUrl, mobileUrl);
// response.resourceType() == ResourceType.DOCUMENT
// response.resourceId() == "doc-123"
// response.webUrl() == "https://example.com/share/doc-123"
// response.mobileUrl() == "https://app.example.com/share/doc-123"
```

## Dependencies

- `com.upmatches.app.features.sharelink.entities.ShortLink` - The entity class representing a short link in the system
- `com.upmatches.app.features.sharelink.enums.ResourceType` - Enum defining the types of resources that can be shared
