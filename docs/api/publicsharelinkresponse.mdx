# PublicShareLinkResponse

The `PublicShareLinkResponse` class is a Java record that represents the response payload for a public share link. It encapsulates the essential information needed to share a resource via a short link, including the resource type, resource identifier, and both web and mobile URLs.

This record is typically used in API responses to provide clients with the necessary data to access a shared resource through different platforms (web and mobile).

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of the shared resource (e.g., document, image, video) |
| `resourceId` | `String` | The unique identifier of the shared resource |
| `webUrl` | `String` | The URL for accessing the resource on the web |
| `mobileUrl` | `String` | The URL for accessing the resource on mobile devices |

## Methods

### `fromShortLink`

```java
public static PublicShareLinkResponse fromShortLink(ShortLink link, String webUrl, String mobileUrl)
```

Creates a `PublicShareLinkResponse` instance from a `ShortLink` entity and the generated web and mobile URLs.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The short link entity containing the resource type and ID |
| `webUrl` | `String` | The web URL for accessing the resource |
| `mobileUrl` | `String` | The mobile URL for accessing the resource |

**Returns:**

| Type | Description |
|------|-------------|
| `PublicShareLinkResponse` | A new response instance populated with data from the provided short link and URLs |

## Usage Example

```java
// Assuming you have a ShortLink object and generated URLs
ShortLink shortLink = shortLinkService.createShortLink(resource);
String webUrl = "https://example.com/share/" + shortLink.getCode();
String mobileUrl = "https://m.example.com/share/" + shortLink.getCode();

PublicShareLinkResponse response = PublicShareLinkResponse.fromShortLink(shortLink, webUrl, mobileUrl);
```

## Related Classes
