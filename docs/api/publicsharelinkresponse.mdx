## Overview

The `PublicShareLinkResponse` class is a part of the `com.upmatches.app.features.sharelink.responses` package. It is designed to encapsulate the response details for a public share link within the application. This class is implemented as a Java Record, which provides a compact syntax for declaring immutable data carriers.

## Purpose

The primary purpose of the `PublicShareLinkResponse` class is to represent the response data associated with a public share link. It includes information about the type of resource being shared, the unique identifier of the resource, and the URLs for accessing the resource via web and mobile platforms.
