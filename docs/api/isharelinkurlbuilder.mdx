# IShareLinkUrlBuilder Interface

The `IShareLinkUrlBuilder` is a **sealed interface** that defines the contract for building shareable URLs within the application. It provides a standardized way to generate different types of URLs (share, web, and mobile) for various resources.

This interface is part of the share link feature and is designed to be implemented by a single permitted class (`ShareLinkUrlBuilder`), ensuring a controlled and secure implementation hierarchy.

## Interface Definition

```java
public sealed interface IShareLinkUrlBuilder permits ShareLinkUrlBuilder {
    // Method declarations
}
```

The interface is declared as `sealed`, meaning only the specified class (`ShareLinkUrlBuilder`) is allowed to implement it. This design pattern provides:
- **Controlled extensibility**: Only authorized implementations can exist
- **Enhanced security**: Prevents unauthorized URL building logic
- **Clear contract**: Defines exactly what methods must be implemented

## Methods

### `buildShareUrl(String code)`

Builds a shareable URL from a given code.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | The unique code used to generate the share URL |

| Returns | Type | Description |
|---------|------|-------------|
| URL | `String` | A complete shareable URL string |

### `buildWebUrl(ResourceType resourceType, String resourceId)`

Builds a web-based URL for a specific resource.

| Parameter | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of resource (e.g., profile, post, event) |
| `resourceId` | `String` | The unique identifier of the resource |

| Returns | Type | Description |
|---------|------|-------------|
| URL | `String` | A complete web URL string for the specified resource |

### `buildMobileUrl(ResourceType resourceType, String resourceId)`

Builds a mobile deep-link URL for a specific resource.

| Parameter | Type | Description |
|-----------|------|-------------|
| `resourceType` | `ResourceType` | The type of resource (e.g., profile, post, event) |
| `resourceId` | `String` | The unique identifier of the resource |

| Returns | Type | Description |
|---------|------|-------------|
| URL | `String` | A complete mobile deep-link URL string for the specified resource |

## Usage Example

```java
// Assuming implementation exists in ShareLinkUrlBuilder
IShareLinkUrlBuilder urlBuilder = new ShareLinkUrlBuilder();

// Build a share URL from a code
String shareUrl = urlBuilder.buildShareUrl("abc123");

// Build a web URL for a specific resource
String webUrl = urlBuilder.buildWebUrl(ResourceType.PROFILE, "user-456");

// Build a mobile deep-link URL
String mobileUrl = urlBuilder.buildMobileUrl(ResourceType.POST, "post-789");
```
