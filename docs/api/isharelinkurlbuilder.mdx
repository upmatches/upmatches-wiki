# IShareLinkUrlBuilder Interface

The `IShareLinkUrlBuilder` interface defines a contract for constructing various types of shareable URLs within the application. It provides a standardized way to generate share links, web URLs, and mobile deep links for different resources.

This interface is designed as a **sealed interface**, meaning only the permitted implementation (`ShareLinkUrlBuilder`) can implement it. This ensures controlled extensibility and a clear, predictable API for URL building.

## Purpose

- **Standardization**: Provides a consistent interface for building different URL formats (share, web, mobile).
- **Abstraction**: Hides the implementation details of URL construction from the calling code.
- **Type Safety**: Uses `ResourceType` enum to ensure only valid resource types are used when building URLs.
- **Controlled Implementation**: The `sealed` keyword restricts implementation to a single class, preventing unintended extensions.

## Interface Definition

```java
public sealed interface IShareLinkUrlBuilder permits ShareLinkUrlBuilder {
    // Methods defined below
}
```

## Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `buildShareUrl` | `String` | `String code` | Builds a shareable URL using a unique code. This is typically used for generating short, shareable links that can be distributed to other users. |
| `buildWebUrl` | `String` | `ResourceType resourceType`, `String resourceId` | Constructs a web-based URL for a specific resource. The `resourceType` determines the type of resource (e.g., profile, post, event), and the `resourceId` identifies the specific resource instance. |
| `buildMobileUrl` | `String` | `ResourceType resourceType`, `String resourceId` | Creates a mobile deep link URL for a specific resource. This URL is designed to open the application directly on a mobile device, using the `resourceType` and `resourceId` to navigate to the correct screen. |

## Usage Example

```java
// Assuming we have an implementation
IShareLinkUrlBuilder urlBuilder = new ShareLinkUrlBuilder();

// Build a share URL from a code
String shareUrl = urlBuilder.buildShareUrl("abc123");

// Build a web URL for a specific resource
String webUrl = urlBuilder.buildWebUrl(ResourceType.POST, "post-456");

// Build a mobile deep link
String mobileUrl = urlBuilder.buildMobileUrl(ResourceType.PROFILE, "user-789");
```

## Implementation Notes

- The interface is **sealed**, so only the `ShareLinkUrlBuilder` class can implement it.
- The `ResourceType` enum (from `com.upmatches.app.features.sharelink.enums`) defines the valid resource types that can be used with `buildWebUrl` and `buildMobileUrl`.
- All methods return `String` representations of the constructed URLs.
- The exact URL format and construction logic are defined in the implementing class.
