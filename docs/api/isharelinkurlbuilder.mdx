## Overview

The `IShareLinkUrlBuilder` interface is part of the `com.upmatches.app.features.sharelink.services` package. It defines a contract for building various types of URLs related to sharing links within the application. This interface is designed to be implemented by classes that generate URLs for different platforms, such as web and mobile, based on resource types and identifiers.

## Public Methods

The `IShareLinkUrlBuilder` interface declares the following public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `buildShareUrl` | `String code` | `String` | Constructs a shareable URL using the provided code. |
| `buildWebUrl` | `ResourceType resourceType`, `String resourceId` | `String` | Generates a web URL for the specified resource type and resource identifier. |
| `buildMobileUrl` | `ResourceType resourceType`, `String resourceId` | `String` | Creates a mobile-specific URL for the given resource type and resource identifier. |

### Method Details

- **`buildShareUrl(String code)`**: This method takes a single parameter, `code`, which is a `String` representing a unique identifier or code for the shareable link. It returns a `String` that is the constructed URL intended for sharing.

- **`buildWebUrl(ResourceType resourceType, String resourceId)`**: This method requires two parameters:
  - `resourceType`: An instance of `ResourceType` enum, indicating the type of resource for which the URL is being generated.
  - `resourceId`: A `String` representing the unique identifier of the resource.
  
  It returns a `String` that is the URL formatted for web access.

- **`buildMobileUrl(ResourceType resourceType, String resourceId)`**: Similar to `buildWebUrl`, this method also takes `resourceType` and `resourceId` as parameters. It returns a `String` that is the URL formatted specifically for mobile access.

The `IShareLinkUrlBuilder` interface is a sealed interface, which means it restricts which classes can implement it. In this case, only the `ShareLinkUrlBuilder` class is permitted to implement this interface.
