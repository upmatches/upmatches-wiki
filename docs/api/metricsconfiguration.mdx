# MetricsConfiguration

The `MetricsConfiguration` class is a Spring Boot configuration component that sets up application-wide metrics and monitoring using Micrometer. It provides two key beans: one for adding common tags to all metrics (such as the application name) and another for integrating Logback logging metrics into the Micrometer registry.

## Purpose

- **Centralized Metrics Setup**: Configures a common tag (`application`) for all metrics emitted by the application, making it easier to filter and aggregate metrics across multiple services.
- **Logging Metrics**: Registers `LogbackMetrics` to capture and expose logging-related metrics (e.g., log levels, logger counts) via Micrometer, enabling monitoring of application logging behavior.

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `metricsCommonTags(Environment environment)` | `MeterRegistryCustomizer<MeterRegistry>` | `Environment environment` | Creates a customizer that adds a common tag `application` to all metrics. The tag value is derived from the `spring.application.name` property, defaulting to `"Upmatches"` if not set. |
| `logbackMetrics()` | `LogbackMetrics` | None | Creates and returns a `LogbackMetrics` bean, which binds Logback logging events to Micrometer metrics. |

## Usage

This configuration is automatically picked up by Spring Boot's component scanning. Once active, all Micrometer metrics will include the `application` tag, and Logback metrics will be available for monitoring.

### Example

```java
// The metricsCommonTags bean ensures every metric has a tag like:
// application=my-service-name (or "Upmatches" if not configured)

// The logbackMetrics bean enables metrics such as:
// logback.events (count of log events by level)
```

## Dependencies

- **Micrometer**: For metrics collection and export.
- **Spring Boot**: For auto-configuration and environment property access.
- **Logback**: For logging framework integration.

## Notes

- The `TAG_APPLICATION` constant defines the tag key as `"application"`.
- The `PROPERTY_APP_NAME` constant references the Spring property `spring.application.name`.
- The `DEFAULT_APP_NAME` is set to `"Upmatches"` as a fallback.
