## Overview

The `MetricsConfiguration` class is a Spring configuration class designed to set up and customize metrics for a Java application using Micrometer. It provides beans that configure common tags for metrics and integrate Logback metrics into the application's monitoring system.

## Public Methods

The class defines two public methods, both of which are annotated with `@Bean` to indicate that they produce beans to be managed by the Spring container.

### `metricsCommonTags`

This method customizes the `MeterRegistry` to include common tags for all metrics, specifically the application name.

| Method Name          | Parameters                                                                 | Return Type                              | Description                                                                                          |
|----------------------|----------------------------------------------------------------------------|------------------------------------------|------------------------------------------------------------------------------------------------------|
| `metricsCommonTags`  | `Environment environment` - The Spring environment from which to retrieve properties. | `MeterRegistryCustomizer<MeterRegistry>` | Customizes the `MeterRegistry` to include a common tag for the application name.                      |

- **Parameters:**
  - `environment`: The `Environment` object used to access application properties.

- **Return Type:** 
  - Returns a `MeterRegistryCustomizer<MeterRegistry>` that adds a common tag for the application name to the `MeterRegistry`.

### `logbackMetrics`

This method provides a `LogbackMetrics` bean that integrates Logback metrics into the application's monitoring system.

| Method Name     | Parameters | Return Type    | Description                                                                 |
|-----------------|------------|----------------|-----------------------------------------------------------------------------|
| `logbackMetrics`| None       | `LogbackMetrics`| Provides a `LogbackMetrics` instance for integrating Logback metrics.       |

- **Parameters:** 
  - None

- **Return Type:** 
  - Returns a `LogbackMetrics` instance that can be used to monitor Logback logging metrics.

## Usage

To use the `MetricsConfiguration` class, ensure that it is included in your Spring application's context. The configuration will automatically apply common tags to all metrics and integrate Logback metrics, enhancing the observability of your application.
