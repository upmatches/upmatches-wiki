# MetricsConfiguration

The `MetricsConfiguration` class is a Spring Boot configuration component that sets up application-wide metrics and monitoring using Micrometer. It provides two key beans: one for adding common tags to all metrics (such as the application name) and another for enabling Logback-based metrics collection.

## Purpose

- **Centralized Metrics Configuration**: Ensures all metrics reported by the application include a consistent set of common tags, making it easier to filter and aggregate metrics in monitoring systems like Prometheus, Datadog, or Grafana.
- **Logback Metrics Integration**: Registers a `LogbackMetrics` bean to capture logging-related metrics (e.g., log event counts by level) and expose them via the Micrometer `MeterRegistry`.

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `metricsCommonTags(Environment environment)` | `MeterRegistryCustomizer<MeterRegistry>` | `Environment environment` – Spring's environment abstraction for accessing property sources. | Creates a customizer that adds a common tag `application` to all metrics. The tag value is taken from the `spring.application.name` property, defaulting to `"Upmatches"` if not set. |
| `logbackMetrics()` | `LogbackMetrics` | None | Creates and returns a `LogbackMetrics` instance, which binds Logback's logging events to Micrometer's meter registry. |

## Usage

This configuration is automatically picked up by Spring Boot's component scanning when placed in a package that is scanned (e.g., under the application's base package). No additional manual registration is required.

### Example

Once this configuration is active, all metrics reported by the application will include a tag like `application=Upmatches` (or the value of `spring.application.name`). Additionally, logging metrics such as `logback.events` will be available in the meter registry.

```java
// Example: Accessing the meter registry in a service
@Service
public class MyService {
    private final MeterRegistry meterRegistry;

    public MyService(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;
    }

    public void doSomething() {
        // Metrics will automatically have the "application" tag
        meterRegistry.counter("my.custom.counter").increment();
    }
}
```

## Dependencies

- **Micrometer**: Core metrics facade.
- **Spring Boot Actuator**: Provides auto-configuration for Micrometer.
- **Logback**: Logging framework (typically included by default in Spring Boot applications).

## Notes

- The `MeterRegistryCustomizer` bean is applied globally to all `MeterRegistry` instances in the application context.
- The `LogbackMetrics` binder automatically registers itself with the `MeterRegistry` when the application context is ready.
