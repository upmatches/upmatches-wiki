## AdminGameController

The `AdminGameController` class is a Spring Boot REST controller responsible for handling administrative operations related to games. Specifically, it provides functionality to hard delete a game by its unique identifier. This controller is part of the `com.upmatches.app.features.game.controllers` package and interacts with the `IHardDeleteGameService` to perform the deletion operation.

### Public Methods

#### `hardDeleteGame`

This method is mapped to the HTTP DELETE request for the endpoint `/api/v1/admin/games/{id}`. It facilitates the hard deletion of a game identified by its UUID.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| `id`      | UUID   | The unique identifier of the game to be deleted. |

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| `ResponseEntity<Void>` | Returns a response entity with no content, indicating the deletion was successful. | 

The `hardDeleteGame` method utilizes the `IHardDeleteGameService` to execute the deletion logic and returns a `ResponseEntity` with HTTP status 204 (No Content) upon successful deletion.
