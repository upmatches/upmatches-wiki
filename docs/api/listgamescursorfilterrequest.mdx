## Purpose

The `ListGamesCursorFilterRequest` class is a Java record used to encapsulate filter criteria for querying a list of games. This record is part of the `com.upmatches.app.features.game.requests` package and provides various fields to specify filtering options such as venue IDs, skill level IDs, date and time ranges, and geographical location. It also includes methods to check the presence of certain fields, which can be useful for determining the completeness of the filter criteria.

## Public Methods

The class provides the following public methods:

| Method Name         | Description                                                                 | Parameters | Return Type |
|---------------------|-----------------------------------------------------------------------------|------------|-------------|
| `hasLocation`       | Checks if all location-related fields (`latitude`, `longitude`, `radiusKm`) are non-null. | None       | `boolean`   |
| `hasAnyLocationField` | Checks if any of the location-related fields (`latitude`, `longitude`, `radiusKm`) are non-null. | None       | `boolean`   |
| `hasSkillLevels`    | Checks if the `skillLevelIds` list is non-null and not empty.               | None       | `boolean`   |
| `hasVenues`         | Checks if the `venueIds` list is non-null and not empty.                    | None       | `boolean`   |

## Fields

The record contains the following fields, which are used to filter the list of games:

| Field Name     | Type         | Description                                                                 |
|----------------|--------------|-----------------------------------------------------------------------------|
| `venueIds`     | `List<Long>` | A list of venue IDs to filter the games. Must contain at most 20 entries.   |
| `skillLevelIds`| `List<Long>` | A list of skill level IDs to filter the games. Must contain at most 20 entries. |
| `fromDate`     | `LocalDate`  | The start date for filtering games.                                         |
| `toDate`       | `LocalDate`  | The end date for filtering games.                                           |
| `fromTime`     | `LocalTime`  | The start time for filtering games.                                         |
| `toTime`       | `LocalTime`  | The end time for filtering games.                                           |
| `latitude`     | `BigDecimal` | The latitude for geographical filtering. Must be between -90 and 90.        |
| `longitude`    | `BigDecimal` | The longitude for geographical filtering. Must be between -180 and 180.     |
| `radiusKm`     | `Integer`    | The radius in kilometers for geographical filtering. Must be between 1 and 5. |
