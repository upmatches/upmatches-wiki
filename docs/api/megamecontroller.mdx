## Purpose

The `MeGameController` class is a REST controller in a Spring Boot application that handles HTTP requests related to games associated with the current user. It provides endpoints to retrieve games that the user has joined or hosted. The controller utilizes cursor-based pagination to efficiently manage large datasets.

## Public Methods

### listJoinedGames

Retrieves a paginated list of games that the user has joined.

| Parameter | Type    | Description                                    |
|-----------|---------|------------------------------------------------|
| cursor    | String  | An optional cursor for pagination.             |
| size      | Integer | The number of records to retrieve per page. Defaults to 20. |
| request   | HttpServletRequest | The HTTP request object.             |

**Returns:** `ResponseEntity<ApiResponse<CursorPagedResponse<GameResponse>>>`  
A response entity containing the paginated list of joined games and a success message.

### listHostedGames

Retrieves a paginated list of games that the user has hosted.

| Parameter | Type    | Description                                    |
|-----------|---------|------------------------------------------------|

| size      | Integer | The number of records to retrieve per page. Defaults to 20. |
| request   | HttpServletRequest | The HTTP request object.             |

**Returns:** `ResponseEntity<ApiResponse<CursorPagedResponse<GameResponse>>>`  
A response entity containing the paginated list of hosted games and a success message.
