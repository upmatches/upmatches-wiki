# MeGameController

The `MeGameController` is a REST controller that provides endpoints for authenticated users to retrieve their personal game-related data. It exposes two main operations: fetching games the user has joined and games the user is hosting. Both endpoints use cursor-based pagination for efficient data retrieval.

## Location

**Package:** `com.upmatches.app.features.user.controllers`

**Base URL:** `/api/v1/me/games`

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IListMyJoinedGamesCursorService` | Service | Handles business logic for retrieving games the user has joined |
| `IListMyHostedGamesCursorService` | Service | Handles business logic for retrieving games the user is hosting |
| `ValidationHelper` | Utility | Validates cursor pagination parameters |

## Endpoints

### GET `/api/v1/me/games/joined`

Retrieves a paginated list of games that the current authenticated user has joined.

#### Request Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `cursor` | `String` | No | `null` | Pagination cursor for fetching the next page of results |
| `size` | `Integer` | No | `20` | Number of items per page (validated by `ValidationHelper`) |

#### Response

```json
{
  "status": "success",
  "message": "Joined games retrieved successfully.",
  "data": {
    "items": [...],
    "nextCursor": "string",
    "hasMore": true
  },
  "path": "/api/v1/me/games/joined"
}
```

#### Success Response Codes

| HTTP Status | Description |
|-------------|-------------|
| `200 OK` | Games retrieved successfully |

## Error Handling

Both endpoints rely on `ValidationHelper.validateCursorPaginationParameters(size)` to validate the `size` parameter. If validation fails, the helper will throw an appropriate exception that should be handled by a global exception handler.

## Usage Example

### cURL

```bash
# Get first page of joined games (20 items)
curl -X GET "https://api.example.com/api/v1/me/games/joined" \
  -H "Authorization: Bearer <token>"

# Get next page using cursor
curl -X GET "https://api.example.com/api/v1/me/games/joined?cursor=abc123&size=10" \
  -H "Authorization: Bearer <token>"

# Get hosted games
curl -X GET "https://api.example.com/api/v1/me/games/hosted" \
  -H "Authorization: Bearer <token>"
```

## Implementation Notes

- Both endpoints require authentication (handled by Spring Security configuration outside this controller).
- The controller uses constructor injection for its service dependencies.
- Cursor-based pagination is used instead of traditional offset pagination for better performance with large datasets.
- The `HttpServletRequest` is injected to capture the request URI for response metadata.
