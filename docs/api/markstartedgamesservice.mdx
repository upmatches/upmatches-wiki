# MarkStartedGamesService

The `MarkStartedGamesService` is a Spring service class responsible for marking games as "started" based on their scheduled start time. It provides a transactional operation that updates the status of games whose start time has passed, ensuring that the game state is accurately reflected in the system.

## Purpose

This service is designed to be executed periodically (e.g., via a scheduled task) to automatically transition games from a "pending" or "scheduled" state to a "started" state once their start time has elapsed. It leverages the `GameRepository` to perform a bulk update operation, marking all games that have a start time before the current moment.

## Public Methods

### `execute()`

Executes the operation to mark games as started. This method is transactional and will roll back if an exception occurs during execution.

**Signature:** `@Transactional public int execute()`

**Returns:** `int` - The number of games that were marked as started.

**Behavior:**
1. Captures the current time as an `Instant`.
2. Calls `gameRepository.markStartedBefore(now, now)` to update all games whose start time is before the current moment.
3. Wraps the operation in `ServiceOperationExecutor.execute()` with the `UPDATE` operation status.
4. If a `ResourceNotFoundException` occurs, it will be re-thrown as appropriate.

**Example usage:**
```java
@Autowired
private MarkStartedGamesService markStartedGamesService;

public void processStartedGames() {
    int updatedCount = markStartedGamesService.execute();
    System.out.println("Marked " + updatedCount + " games as started.");
}
```
