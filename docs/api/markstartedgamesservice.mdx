## Purpose

The `MarkStartedGamesService` class is a service component in a Java application that interacts with the `GameRepository` to mark games as started. It is part of the `com.upmatches.app.features.game.services` package and is designed to update the status of games that have started before the current time. This service is transactional, ensuring that the operations it performs are completed successfully or rolled back in case of an error.

## Public Methods

### `execute`

The `execute` method is the primary public method of the `MarkStartedGamesService` class. It is responsible for marking games as started by invoking the `markStartedBefore` method on the `GameRepository`. This method is transactional and utilizes the `ServiceOperationExecutor` to handle the execution and potential exceptions.

| Method   | Parameters | Return Type | Description |
|----------|------------|-------------|-------------|
| `execute` | None       | `int`       | Marks games as started that have a start time before the current instant. Returns the number of games updated. |

#### Parameters

- **None**: The `execute` method does not take any parameters.

#### Return Type

- **`int`**: The method returns an integer representing the number of games that were marked as started.

## Usage

To use the `MarkStartedGamesService`, you need to have an instance of `GameRepository` available. The service can be instantiated and the `execute` method called to update the status of games. The operation is wrapped in a transaction to ensure data integrity.
