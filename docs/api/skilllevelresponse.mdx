# SkillLevelResponse

The `SkillLevelResponse` class is a Java record used as a Data Transfer Object (DTO) to represent a skill level in API responses. It provides a simplified, immutable view of the `SkillLevel` entity, exposing only the fields that are safe and relevant for external consumers.

## Purpose

- **API Response DTO**: Encapsulates skill level data returned from REST endpoints.
- **Data Hiding**: Prevents leaking internal entity details (e.g., JPA annotations, relationships) to clients.
- **Immutability**: As a Java record, all fields are final and the class is thread-safe.
- **Conversion Utility**: Provides a static factory method to convert from the `SkillLevel` entity.

## Record Fields

| Field       | Type      | Description                                      |
|-------------|-----------|--------------------------------------------------|
| `id`        | `Long`    | Unique identifier for the skill level.           |
| `name`      | `String`  | Human-readable name of the skill level.          |
| `sortOrder` | `Integer` | Numeric order used for sorting/display purposes. |

## Public Methods

### `fromSkillLevel(SkillLevel skillLevel)`

Converts a `SkillLevel` entity into a `SkillLevelResponse` DTO.

**Parameters:**

| Parameter    | Type         | Description                          |
|--------------|--------------|--------------------------------------|
| `skillLevel` | `SkillLevel` | The entity to convert (non-null).    |

**Returns:** `SkillLevelResponse` — a new instance populated with the entity's `id`, `name`, and `sortOrder`.

**Example Usage:**

```java
SkillLevel entity = new SkillLevel(1L, "Beginner", 1);
SkillLevelResponse response = SkillLevelResponse.fromSkillLevel(entity);
// response.id() == 1L
// response.name() == "Beginner"
// response.sortOrder() == 1
```

## Notes

- This record is automatically generated with `equals()`, `hashCode()`, `toString()`, and accessor methods (e.g., `id()`, `name()`, `sortOrder()`).
- The `fromSkillLevel` method performs a shallow copy; the `name` and `sortOrder` fields are immutable strings and integers, so no deep copy is necessary.
- Ensure the `SkillLevel` entity is not null before calling `fromSkillLevel` to avoid `NullPointerException`.
