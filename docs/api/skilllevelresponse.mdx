# SkillLevelResponse

The `SkillLevelResponse` class is a Java record used as a Data Transfer Object (DTO) to represent a skill level in API responses. It provides a simplified, immutable view of the `SkillLevel` entity, exposing only the fields that are safe and relevant for external consumers.

## Purpose

- **Encapsulation**: Separates the internal entity structure from the API contract.
- **Immutability**: As a record, all fields are final and the class is thread-safe.
- **Convenience**: Provides a static factory method to easily convert from the `SkillLevel` entity.

## Fields

| Field      | Type      | Description                                      |
|------------|-----------|--------------------------------------------------|
| `id`       | `Long`    | Unique identifier for the skill level.           |
| `name`     | `String`  | Human-readable name of the skill level.          |
| `sortOrder`| `Integer` | Numeric value used for ordering/sorting purposes.|

## Public Methods

### `fromSkillLevel(SkillLevel skillLevel)`

Converts a `SkillLevel` entity into a `SkillLevelResponse` DTO.

**Parameters:**

| Parameter    | Type         | Description                          |
|--------------|--------------|--------------------------------------|
| `skillLevel` | `SkillLevel` | The entity to convert from. Must not be `null`. |

**Returns:** `SkillLevelResponse` — a new instance populated with the entity's data.

**Example usage:**

```java
SkillLevel entity = new SkillLevel(1L, "Beginner", 1);
SkillLevelResponse response = SkillLevelResponse.fromSkillLevel(entity);
// response.id() == 1L
// response.name() == "Beginner"
// response.sortOrder() == 1
```

## Notes

- The record automatically provides accessor methods (`id()`, `name()`, `sortOrder()`), `equals()`, `hashCode()`, and `toString()`.
- This class is part of the `com.upmatches.app.features.skilllevels.responses` package.
- It is designed to be used in REST API responses where only the essential skill level information is needed.
