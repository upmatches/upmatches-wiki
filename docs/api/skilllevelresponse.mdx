# SkillLevelResponse

The `SkillLevelResponse` class is a Java record used as a Data Transfer Object (DTO) to represent a skill level in API responses. It provides a simplified, immutable view of the `SkillLevel` entity, exposing only the fields that are safe and necessary for external clients.

## Purpose

- **Data Transfer Object**: Decouples the internal `SkillLevel` entity from the API response structure.
- **Immutability**: As a Java record, all fields are final and the class is thread-safe.
- **Conversion**: Offers a static factory method to convert a `SkillLevel` entity into a `SkillLevelResponse`.

## Record Components

| Field       | Type      | Description                                      |
|-------------|-----------|--------------------------------------------------|
| `id`        | `Long`    | Unique identifier for the skill level.           |
| `name`      | `String`  | Human-readable name of the skill level.          |
| `sortOrder` | `Integer` | Numeric order used for sorting/display purposes. |

## Public Methods

### `fromSkillLevel(SkillLevel skillLevel)`

Converts a `SkillLevel` entity into a `SkillLevelResponse` DTO.

| Parameter     | Type         | Description                          |
|---------------|--------------|--------------------------------------|
| `skillLevel`  | `SkillLevel` | The entity to convert. Must not be null. |

**Returns**: `SkillLevelResponse` — a new instance populated with the entity's `id`, `name`, and `sortOrder`.

**Example Usage**:
```java
SkillLevel entity = new SkillLevel(1L, "Beginner", 1);
SkillLevelResponse response = SkillLevelResponse.fromSkillLevel(entity);
// response.id() == 1L
// response.name() == "Beginner"
// response.sortOrder() == 1
```

## Notes

- The record automatically provides accessor methods (`id()`, `name()`, `sortOrder()`), `equals()`, `hashCode()`, and `toString()`.
- This class is part of the `com.upmatches.app.features.skilllevels.responses` package and is intended for use in REST API controllers or service layers.
- No validation is performed in the factory method; ensure the `SkillLevel` entity is properly initialized before conversion.
