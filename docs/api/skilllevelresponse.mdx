## Purpose

The `SkillLevelResponse` class is a record in the `com.upmatches.app.features.skilllevels.responses` package. It is designed to represent a response object for skill level data. This class encapsulates the details of a skill level, including its identifier, name, and sort order, and provides a static method to create an instance from a `SkillLevel` entity.

## Public Methods

### fromSkillLevel

Converts a `SkillLevel` entity into a `SkillLevelResponse` object.

| Parameter   | Type        | Description                     |
|-------------|-------------|---------------------------------|
| skillLevel  | SkillLevel  | The skill level entity to convert.|

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| SkillLevelResponse   | A new instance of `SkillLevelResponse` with data from the provided `SkillLevel` entity. |

The `fromSkillLevel` method is a static factory method that facilitates the transformation of a `SkillLevel` entity into a `SkillLevelResponse` record, ensuring that the response object is correctly populated with the necessary data fields.
