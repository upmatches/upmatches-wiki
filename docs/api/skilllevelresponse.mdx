## Purpose of the SkillLevelResponse Class

The `SkillLevelResponse` class is a record in the `com.upmatches.app.features.skilllevels.responses` package. It serves as a Data Transfer Object (DTO) for transferring skill level data within the application. This class is designed to encapsulate the details of a skill level, making it easier to manage and transfer data related to skill levels in a structured manner.

## Public Methods

The `SkillLevelResponse` class provides the following public method:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `fromSkillLevel` | `SkillLevel skillLevel` | `SkillLevelResponse` | Converts a `SkillLevel` entity into a `SkillLevelResponse` record. |

### Method Details

#### `fromSkillLevel`

- **Parameters:**
  - `skillLevel`: An instance of the `SkillLevel` entity from which the response record will be created.

- **Return Type:**
  - Returns a new instance of `SkillLevelResponse` containing the `id`, `name`, and `sortOrder` extracted from the provided `SkillLevel` entity.

This method is a static factory method that facilitates the creation of `SkillLevelResponse` instances from `SkillLevel` entities, ensuring that the data is correctly mapped and encapsulated for further use in the application.
