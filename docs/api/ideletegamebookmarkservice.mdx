# IDeleteGameBookmarkService

The `IDeleteGameBookmarkService` interface defines the contract for deleting a game bookmark by its unique identifier. It is a **sealed interface**, meaning only the permitted implementation (`DeleteGameBookmarkService`) can extend or implement it. This design enforces a controlled hierarchy and ensures that the deletion logic is centralized and consistent across the application.

## Purpose

- Provides a single, well-defined method for removing a game bookmark.
- Enforces type safety and immutability by using `UUID` as the game identifier.
- Supports the **sealed class/interface** feature introduced in Java 17 to restrict inheritance.

## Interface Definition

```java
package com.upmatches.app.feature.game.services;

import java.util.UUID;

public sealed interface IDeleteGameBookmarkService permits DeleteGameBookmarkService {

    void execute(UUID gameId);

}
```

## Method Summary

| Method | Description |
|--------|-------------|
| `void execute(UUID gameId)` | Deletes the game bookmark associated with the given `gameId`. |

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game whose bookmark should be deleted. Must not be `null`. |

## Usage Example

```java
// Assuming an implementation is injected
IDeleteGameBookmarkService deleteService = new DeleteGameBookmarkService(/* dependencies */);

UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
deleteService.execute(gameId);
```

## Implementation Notes

- The only permitted implementation is `DeleteGameBookmarkService`.
- The `execute` method should handle cases where the `gameId` does not correspond to an existing bookmark (e.g., by throwing an exception or silently ignoring).
- The interface is designed to be used in a service layer, typically injected via dependency injection.

## Related Components

- `DeleteGameBookmarkService` – the sole implementation of this interface.
- `GameBookmarkRepository` – likely used by the implementation to persist the deletion.
