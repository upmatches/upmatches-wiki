# IDeleteGameBookmarkService

## Purpose

The `IDeleteGameBookmarkService` interface defines the contract for deleting a game bookmark within the UpMatches application. It is a **sealed interface**, meaning only the permitted implementation (`DeleteGameBookmarkService`) can implement it. This design enforces a controlled hierarchy and ensures that the deletion logic is centralized and consistent across the application.

The interface exposes a single method, `execute`, which takes a game ID as a parameter and performs the deletion operation. Implementations are responsible for handling the actual removal of the bookmark from the data store.

## Public Methods

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `execute` | `UUID gameId` – The unique identifier of the game whose bookmark is to be deleted. | `void` | Executes the deletion of the game bookmark associated with the provided game ID. |

## Usage Example

```java
// Assuming an instance of DeleteGameBookmarkService is injected
IDeleteGameBookmarkService deleteService = new DeleteGameBookmarkService();

// Delete the bookmark for a specific game
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
deleteService.execute(gameId);
```

## Implementation Notes

- The interface is **sealed** to `DeleteGameBookmarkService`, ensuring that no other class can implement it.
- The `execute` method does not return a value; any errors during deletion should be handled by the implementation (e.g., throwing runtime exceptions).
- The `UUID` parameter guarantees a globally unique identifier for the game, preventing conflicts in distributed systems.
