# IDeleteGameBookmarkService

## Purpose

The `IDeleteGameBookmarkService` is a **sealed interface** that defines the contract for deleting a game bookmark. It serves as the abstraction layer for the bookmark deletion use case, ensuring that only the permitted implementation (`DeleteGameBookmarkService`) can fulfill this contract.

This interface follows the **Command Pattern** by exposing a single `execute` method that encapsulates the deletion logic. By sealing the interface, the design enforces a controlled hierarchy where only specific implementations are allowed, improving type safety and maintainability.

## Interface Definition

```java
public sealed interface IDeleteGameBookmarkService permits DeleteGameBookmarkService {
    void execute(UUID gameId);
}
```

## Methods

### `execute`

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `gameId`  | `UUID` | The unique identifier of the game bookmark to delete. |

This method performs the deletion of a game bookmark identified by the provided `UUID`. The implementation (`DeleteGameBookmarkService`) is responsible for handling the actual deletion logic, such as validating the existence of the bookmark, interacting with the data store, and managing any side effects.

## Usage Example

```java
// Assuming dependency injection provides the implementation
IDeleteGameBookmarkService deleteService = new DeleteGameBookmarkService(/* dependencies */);
UUID gameId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
deleteService.execute(gameId);
```

## Notes

- The interface is **sealed**, meaning only `DeleteGameBookmarkService` is allowed to implement it.
- The method signature uses `UUID` for type-safe identification of game bookmarks.
- This design promotes loose coupling and testability by depending on an abstraction rather than a concrete implementation.
