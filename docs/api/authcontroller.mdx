## Overview

The `AuthController` class is a Spring Boot REST controller responsible for handling authentication-related requests in the application. It provides endpoints for logging in with Singpass, Auth0, and Apple, as well as refreshing tokens and logging out. The controller interacts with various authentication services and manages user sessions and tokens.

## Public Methods

### `loginSingpass`

Handles the Singpass login process by generating an authorization URL and storing session details.

| Parameter      | Type                  | Description                                                                 |
|----------------|-----------------------|-----------------------------------------------------------------------------|
| `platform`     | `String` (optional)   | The platform from which the login request is made (e.g., mobile).           |
| `request`      | `HttpServletRequest`  | The HTTP request object.                                                    |

**Returns:** `ResponseEntity<Object>` - The response entity containing the authorization URL or a redirect.

### `loginAuth0`

Handles the Auth0 login process by generating an authorization URL based on the provider and storing session details.

| Parameter      | Type                  | Description                                                                 |
|----------------|-----------------------|-----------------------------------------------------------------------------|
| `platform`     | `String` (optional)   | The platform from which the login request is made (e.g., mobile).           |
| `provider`     | `String` (optional)   | The provider for Auth0 login (e.g., Google, Facebook).                      |
| `request`      | `HttpServletRequest`  | The HTTP request object.                                                    |

**Returns:** `ResponseEntity<Object>` - The response entity containing the authorization URL or a redirect.

### `loginApple`

Handles the Apple login process by executing the login request and returning the response.

| Parameter | Type                  | Description                                                                 |
|-----------|-----------------------|-----------------------------------------------------------------------------|
| `body`    | `AppleLoginRequest`   | The request body containing Apple login details.                            |
| `request` | `HttpServletRequest`  | The HTTP request object.                                                    |

**Returns:** `ResponseEntity<Object>` - The response entity containing the Apple login response.

### `refresh`

Refreshes the authentication token using the provided refresh token from the request body or cookies.

| Parameter | Type                  | Description                                                                 |
|-----------|-----------------------|-----------------------------------------------------------------------------|
| `body`    | `RefreshRequest`      | The request body containing the refresh token (optional).                   |
| `request` | `HttpServletRequest`  | The HTTP request object.                                                    |
| `response`| `HttpServletResponse` | The HTTP response object.                                                   |

**Returns:** `ResponseEntity<Object>` - The response entity containing the new token or an error message.

### `logout`

Logs out the user by revoking the refresh token and clearing authentication cookies.

| Parameter | Type                  | Description                                                                 |
|-----------|-----------------------|-----------------------------------------------------------------------------|
| `request` | `HttpServletRequest`  | The HTTP request object.                                                    |
| `response`| `HttpServletResponse` | The HTTP response object.                                                   |

**Returns:** `ResponseEntity<Object>` - The response entity confirming the logout action.
