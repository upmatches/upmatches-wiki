## Overview

The `MarkAllReadService` class is a part of the notification services in the application. It is responsible for marking all notifications as read for the authenticated user. This service interacts with the `NotificationRepository` to update the read status of notifications in the database. It ensures that the operation is executed within a transactional context to maintain data integrity.

## Public Methods

### `execute`

Marks all notifications as read for the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type | Description |
|-------------|-------------|
| `Integer`   | The number of notifications that were marked as read. |

#### Method Details

- **Transactional**: This method is annotated with `@Transactional`, ensuring that the operation is executed within a transaction. This guarantees that all database operations within the method are completed successfully or none are applied in case of an error.
- **Operation Execution**: Utilizes `ServiceOperationExecutor` to perform the update operation. This executor handles the execution logic and manages exceptions, specifically throwing a `ResourceNotFoundException` if the operation fails due to missing resources.
- **User Resolution**: The method retrieves the authenticated user's ID using the `IAuthenticatedUserResolver` service, ensuring that the notifications are marked read for the correct user.
