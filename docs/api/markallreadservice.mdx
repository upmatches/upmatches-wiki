# MarkAllReadService

The `MarkAllReadService` class is a Spring service responsible for marking all unread notifications as read for the currently authenticated user. It implements the `IMarkAllReadService` interface and provides a transactional operation that updates notification read statuses in the database.

## Purpose

This service handles the bulk "mark all as read" functionality commonly found in notification systems. When invoked, it:
1. Resolves the currently authenticated user's ID
2. Updates all unread notifications belonging to that user with the current timestamp
3. Returns the count of notifications that were marked as read

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `NotificationRepository` | Repository | Data access layer for notification entities |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's UUID |

## Constructor

### `MarkAllReadService(NotificationRepository, IAuthenticatedUserResolver)`

Creates a new instance of the service with the required dependencies.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `notificationRepository` | `NotificationRepository` | Repository for notification data operations |
| `userResolver` | `IAuthenticatedUserResolver` | Service to resolve the authenticated user |

## Public Methods

### `execute()`

Marks all unread notifications as read for the currently authenticated user.

**Returns:** `Integer` - The number of notifications that were updated to read status

**Throws:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | If the operation fails or no user is authenticated |

**Behavior:**
1. Retrieves the authenticated user's UUID via `userResolver.requireUserId()`
2. Executes the database update operation within a transaction
3. Uses `ServiceOperationExecutor` to handle the operation with proper error handling and status tracking
4. The operation status is set to `UPDATE` for monitoring purposes

## Implementation Details

The service uses:
- **`@Transactional`** annotation to ensure the database operation is atomic
- **`ServiceOperationExecutor`** for consistent error handling and operation tracking
- **`Instant.now()`** to record the exact timestamp when notifications were marked as read
- **`ResourceNotFoundException`** as the error type for failed operations

## Usage Example

```java
@Autowired
private MarkAllReadService markAllReadService;

public void markNotificationsAsRead() {
    int updatedCount = markAllReadService.execute();
    System.out.println("Marked " + updatedCount + " notifications as read");
}
```
