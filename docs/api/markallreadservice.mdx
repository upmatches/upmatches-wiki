# MarkAllReadService

The `MarkAllReadService` class is a Spring service that provides functionality to mark all notifications as read for the currently authenticated user. It implements the `IMarkAllReadService` interface and is declared as a `non-sealed` class, allowing further extension if needed.

This service is typically used when a user wants to clear all unread notifications at once, such as when opening a notification center or performing a bulk read action.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `NotificationRepository` | Repository | Data access layer for notification entities |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's identity |

## Constructor

### `MarkAllReadService(NotificationRepository, IAuthenticatedUserResolver)`

Initializes the service with required dependencies.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `notificationRepository` | `NotificationRepository` | Repository for notification data operations |
| `userResolver` | `IAuthenticatedUserResolver` | Service to resolve the authenticated user |

## Public Methods

### `execute()`

Marks all notifications as read for the currently authenticated user.

**Returns:** `Integer` - The number of notifications that were updated (marked as read).

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown if the operation fails or no user is authenticated |

**Behavior:**

1. Resolves the authenticated user's ID using `userResolver.requireUserId()`
2. Executes the database update operation within a transactional context
3. Calls `notificationRepository.markAllReadByRecipientId(userId, Instant.now())` to update all unread notifications for the user
4. Uses `ServiceOperationExecutor.execute()` to handle the operation with proper error handling and status tracking

**Example usage:**

```java
@Autowired
private MarkAllReadService markAllReadService;

public void clearNotifications() {
    int updatedCount = markAllReadService.execute();
    System.out.println("Marked " + updatedCount + " notifications as read");
}
```

## Implementation Details

- The method is annotated with `@Transactional` to ensure atomicity of the database operation
- Uses `Instant.now()` to set the read timestamp for all updated notifications
- The `ServiceOperationExecutor` handles the operation with `UPDATE` status and wraps any exceptions in a `ResourceNotFoundException`
- The class is declared as `non-sealed`, allowing it to be extended by other classes in the same package or module
