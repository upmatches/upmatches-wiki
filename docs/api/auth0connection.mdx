## Overview

The `Auth0Connection` enum is part of the `com.upmatches.app.features.auth.enums` package. It represents different authentication providers and their corresponding connection identifiers used in an application that integrates with Auth0 for authentication purposes. This enum provides a structured way to manage and retrieve authentication connection details based on provider names.

## Public Methods

The `Auth0Connection` enum provides the following public methods:

### `fromProvider`

Retrieves an `Auth0Connection` instance based on the given provider name.

| Parameter | Type   | Description                       |
|-----------|--------|-----------------------------------|
| provider  | String | The name of the authentication provider. |

| Return Type                  | Description                                                                 |
|------------------------------|-----------------------------------------------------------------------------|
| `Optional<Auth0Connection>`  | An `Optional` containing the `Auth0Connection` if a match is found, otherwise an empty `Optional`. |

### `provider`

Returns the provider name associated with the `Auth0Connection`.

| Return Type | Description                            |
|-------------|----------------------------------------|
| `String`    | The name of the authentication provider. |

### `connectionId`

Returns the connection identifier associated with the `Auth0Connection`.

| Return Type | Description                                |
|-------------|--------------------------------------------|
| `String`    | The connection identifier for the provider. |
