# Auth0Connection Enum

The `Auth0Connection` enum maps social login providers to their corresponding Auth0 connection identifiers. It provides a type-safe way to reference supported authentication providers (Google and Facebook) throughout the application, along with their Auth0-specific connection strings.

## Purpose

This enum serves two primary purposes:
1. **Provider Mapping**: Associates human-readable provider names (e.g., "google", "facebook") with their Auth0 connection identifiers (e.g., "google-oauth2", "facebook").
2. **Lookup Utility**: Provides a static method to resolve an `Auth0Connection` instance from a provider string, returning an `Optional` to handle invalid or missing provider values gracefully.

## Enum Constants

| Constant   | Provider | Connection ID    |
|------------|----------|------------------|
| `GOOGLE`   | google   | google-oauth2    |
| `FACEBOOK` | facebook | facebook         |

## Public Methods

### `fromProvider(String provider)`

Resolves an `Auth0Connection` from a provider string.

| Parameter  | Type     | Description                                      |
|------------|----------|--------------------------------------------------|
| `provider` | `String` | The provider name to look up (case-insensitive). |

**Returns**: `Optional<Auth0Connection>` — An `Optional` containing the matching `Auth0Connection` if found, or `Optional.empty()` if the provider is `null`, blank, or not recognized.

**Example**:
```java
Optional<Auth0Connection> connection = Auth0Connection.fromProvider("google");
// Returns Optional.of(Auth0Connection.GOOGLE)

Optional<Auth0Connection> invalid = Auth0Connection.fromProvider("twitter");
// Returns Optional.empty()
```

### `provider()`

Returns the human-readable provider name.

**Returns**: `String` — The provider name (e.g., "google", "facebook").

### `connectionId()`

Returns the Auth0 connection identifier.

**Returns**: `String` — The Auth0 connection ID (e.g., "google-oauth2", "facebook").

## Usage Example

```java
// Look up a connection by provider name
String providerName = "google";
Auth0Connection.fromProvider(providerName)
    .ifPresent(connection -> {
        String auth0ConnectionId = connection.connectionId();
        // Use auth0ConnectionId for authentication flow
    });
```
