# Auth0Connection Enum

The `Auth0Connection` enum maps social login providers to their corresponding Auth0 connection identifiers. It provides a type-safe way to reference supported authentication providers and their Auth0 connection strings throughout the application.

## Purpose

This enum serves as a centralized mapping between human-readable provider names (e.g., "google", "facebook") and the technical connection identifiers used by Auth0 (e.g., "google-oauth2", "facebook"). It simplifies provider lookup and ensures consistency when working with Auth0 authentication flows.

## Enum Values

| Enum Constant | Provider Name | Auth0 Connection ID |
|---------------|---------------|---------------------|
| `GOOGLE` | `google` | `google-oauth2` |
| `FACEBOOK` | `facebook` | `facebook` |

## Public Methods

### `fromProvider(String provider)`

Resolves a provider name string to its corresponding `Auth0Connection` enum value.

| Parameter | Type | Description |
|-----------|------|-------------|
| `provider` | `String` | The provider name to look up (case-insensitive) |

**Returns:** `Optional<Auth0Connection>` - An `Optional` containing the matching enum value, or `Optional.empty()` if no match is found or the input is null/blank.

**Example:**
```java
Optional<Auth0Connection> connection = Auth0Connection.fromProvider("google");
// Returns Optional.of(Auth0Connection.GOOGLE)

Optional<Auth0Connection> invalid = Auth0Connection.fromProvider("twitter");
// Returns Optional.empty()
```

### `provider()`

Returns the human-readable provider name associated with this enum value.

**Returns:** `String` - The provider name (e.g., "google", "facebook")

### `connectionId()`

Returns the Auth0 connection identifier associated with this enum value.

**Returns:** `String` - The Auth0 connection ID (e.g., "google-oauth2", "facebook")

## Usage Example

```java
// Look up a provider and use its connection ID
String providerName = "google";
Auth0Connection.fromProvider(providerName)
    .ifPresent(connection -> {
        String auth0ConnectionId = connection.connectionId();
        // Use auth0ConnectionId in authentication requests
    });
```

## Notes

- The `fromProvider()` method performs a case-insensitive comparison, so "Google", "GOOGLE", and "google" all resolve to `Auth0Connection.GOOGLE`.
- Returns `Optional.empty()` for null, blank, or unrecognized provider names, encouraging safe handling of missing values.
- The enum is immutable after initialization, with both fields being `final`.
