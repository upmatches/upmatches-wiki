# DatabaseProperties

The `DatabaseProperties` class is a Spring Boot configuration properties record that maps to the `spring.datasource` prefix in application configuration files (e.g., `application.yml` or `application.properties`). It provides a type-safe way to access database connection settings including JDBC URL, credentials, driver class, and HikariCP connection pool configuration.

## Purpose

This record centralizes database connection configuration into a single, immutable data structure. By using Spring Boot's `@ConfigurationProperties` annotation, it automatically binds properties from external configuration sources, enabling clean separation of configuration from code and supporting IDE autocompletion for configuration keys.

## Configuration Prefix

All properties are prefixed with `spring.datasource`. For example, in `application.yml`:

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mydb
    username: dbuser
    password: dbpass
    driver-class-name: com.mysql.cj.jdbc.Driver
    hikari:
      maximum-pool-size: 10
      minimum-idle: 5
```

## Public API

### Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `url` | `String` | JDBC URL for the database connection |
| `username` | `String` | Database authentication username |
| `password` | `String` | Database authentication password |
| `driverClassName` | `String` | Fully qualified JDBC driver class name |
| `hikari` | `HikariProperties` | Nested HikariCP connection pool configuration (annotated with `@NestedConfigurationProperty`) |

### Inherited Methods

As a Java record, `DatabaseProperties` automatically provides:

- **Constructor**: All-args constructor with parameters matching the component order
- **Accessor methods**: `url()`, `username()`, `password()`, `driverClassName()`, `hikari()`
- **`equals()`**, **`hashCode()`**, **`toString()`**: Standard implementations based on all components

## Usage Example

```java
@Service
public class DatabaseService {
    private final DatabaseProperties databaseProperties;

    public DatabaseService(DatabaseProperties databaseProperties) {
        this.databaseProperties = databaseProperties;
    }

    public void printConnectionInfo() {
        System.out.println("Connecting to: " + databaseProperties.url());
        System.out.println("Pool size: " + databaseProperties.hikari().maximumPoolSize());
    }
}
```
