# DatabaseProperties

The `DatabaseProperties` class is a Spring Boot configuration properties record that maps to the `spring.datasource` prefix in application configuration files (e.g., `application.yml` or `application.properties`). It provides a type-safe way to inject database connection settings into your Spring application.

## Purpose

This record centralizes database connection configuration, including the JDBC URL, credentials, driver class, and HikariCP connection pool settings. By using `@ConfigurationProperties`, Spring Boot automatically binds properties from your configuration files to this record, making it easy to manage and validate database settings.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `url` | `String` | JDBC URL for the database connection |
| `username` | `String` | Database username |
| `password` | `String` | Database password |
| `driverClassName` | `String` | Fully qualified JDBC driver class name |
| `hikari` | `HikariProperties` | Nested HikariCP connection pool configuration |

## Usage Example

In your `application.yml`:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/mydb
    username: myuser
    password: mypassword
    driverClassName: org.postgresql.Driver
    hikari:
      maximum-pool-size: 10
      minimum-idle: 5
      connection-timeout: 30000
```

## Dependencies

- `spring-boot-starter` (for `@ConfigurationProperties` support)
- `spring-boot-configuration-processor` (optional, for IDE support)

## Notes

- The `@NestedConfigurationProperty` annotation on the `hikari` field indicates that the `HikariProperties` class contains nested properties that should be bound under the `spring.datasource.hikari` prefix.
- This record is immutable and thread-safe by design.
- Ensure that the `HikariProperties` class is also annotated with `@ConfigurationProperties` or uses `@NestedConfigurationProperty` appropriately.
