# DatabaseProperties

The `DatabaseProperties` class is a Spring Boot configuration properties record that maps to the `spring.datasource` prefix in application configuration files (e.g., `application.yml` or `application.properties`). It provides a type-safe way to access database connection settings, including HikariCP connection pool configuration.

## Purpose

This record centralizes database connection configuration by binding properties from external configuration sources to a structured Java object. It supports:

- Standard JDBC connection parameters (URL, username, password, driver class)
- Nested HikariCP connection pool settings via the `HikariProperties` record

## Configuration Prefix

All properties are prefixed with `spring.datasource` in your configuration files.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `url` | `String` | JDBC URL for the database connection |
| `username` | `String` | Database username |
| `password` | `String` | Database password |
| `driverClassName` | `String` | Fully qualified JDBC driver class name |
| `hikari` | `HikariProperties` | Nested HikariCP connection pool configuration |

## Example Configuration

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mydb
    username: dbuser
    password: dbpass
    driverClassName: com.mysql.cj.jdbc.Driver
    hikari:
      maximumPoolSize: 10
      minimumIdle: 5
      connectionTimeout: 30000
      idleTimeout: 600000
      maxLifetime: 1800000
```

## Usage

Inject the `DatabaseProperties` bean into any Spring-managed component:

```java
@Service
public class DatabaseService {
    private final DatabaseProperties databaseProperties;

    public DatabaseService(DatabaseProperties databaseProperties) {
        this.databaseProperties = databaseProperties;
    }

    public void printConnectionInfo() {
        System.out.println("Database URL: " + databaseProperties.url());
        System.out.println("Max pool size: " + databaseProperties.hikari().maximumPoolSize());
    }
}
```

## Related Classes

- **HikariProperties**: Nested configuration record for HikariCP connection pool settings
- **@ConfigurationProperties**: Spring Boot annotation that enables property binding
- **@NestedConfigurationProperty**: Indicates that the field contains nested configuration properties
