## Overview

The `DatabaseProperties` class is a Java record used to encapsulate the configuration properties for a database connection in a Spring Boot application. It is annotated with `@ConfigurationProperties` to bind the properties defined in the application's configuration files (e.g., `application.yml` or `application.properties`) to this class. The prefix used for these properties is `spring.datasource`.

This class is part of the `com.upmatches.app.shared.database.properties` package and is designed to hold essential database connection details such as the URL, username, password, and driver class name. Additionally, it includes a nested configuration property for HikariCP-specific settings through the `HikariProperties` class.

## Public Methods

Since `DatabaseProperties` is a Java record, it automatically provides public accessor methods for each of its components. Below is a table documenting these methods:

| Method Name       | Parameters | Return Type | Description                                      |
|-------------------|------------|-------------|--------------------------------------------------|
| `url()`           | None       | `String`    | Returns the database connection URL.             |
| `username()`      | None       | `String`    | Returns the username for the database connection.|
| `password()`      | None       | `String`    | Returns the password for the database connection.|
| `driverClassName()` | None     | `String`    | Returns the fully qualified name of the JDBC driver class. |
| `hikari()`        | None       | `HikariProperties` | Returns the HikariCP-specific configuration properties. |

## Usage

To use the `DatabaseProperties` class, ensure that your Spring Boot application's configuration file includes the necessary properties under the `spring.datasource` prefix. The properties will be automatically mapped to the fields of this class, allowing you to access them in a type-safe manner within your application.
