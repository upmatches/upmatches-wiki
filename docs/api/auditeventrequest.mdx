# AuditEventRequest

The `AuditEventRequest` class is a Java record that serves as a data transfer object (DTO) for capturing audit events within the application. It encapsulates all relevant information about an auditable action, including the actor performing the action, the action itself, the outcome, and contextual metadata such as IP address and user agent.

This record is designed to be used with audit logging systems to track and record significant events for compliance, security, and monitoring purposes.

## Record Definition

```java
public record AuditEventRequest(
    UUID actorId,
    AuditActorType actorType,
    String action,
    AuditCategory category,
    AuditOutcome outcome,
    String resourceType,
    String resourceId,
    String ipAddress,
    String userAgent,
    String correlationId,
    String requestPayload,
    String errorCode,
    String errorMessage
)
```

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `actorId` | `UUID` | Unique identifier of the user or system that performed the action |
| `actorType` | `AuditActorType` | Enum indicating whether the actor is a user, system, or other entity |
| `action` | `String` | Description of the action performed (e.g., "CREATE", "UPDATE", "DELETE") |
| `category` | `AuditCategory` | Enum categorizing the type of audit event (e.g., SECURITY, BUSINESS, SYSTEM) |
| `outcome` | `AuditOutcome` | Enum indicating the result of the action (e.g., SUCCESS, FAILURE, DENIED) |
| `resourceType` | `String` | Type of resource that was acted upon (e.g., "User", "Order", "Document") |
| `resourceId` | `String` | Unique identifier of the specific resource involved |
| `ipAddress` | `String` | IP address from which the request originated |
| `userAgent` | `String` | User agent string from the client making the request |
| `correlationId` | `String` | Identifier used to correlate related events across different services |
| `requestPayload` | `String` | JSON or serialized representation of the request payload |
| `errorCode` | `String` | Error code if the action resulted in a failure |
| `errorMessage` | `String` | Human-readable error message if the action resulted in a failure |

## Usage Example

```java
AuditEventRequest auditEvent = new AuditEventRequest(
    UUID.randomUUID(),
    AuditActorType.USER,
    "LOGIN",
    AuditCategory.SECURITY,
    AuditOutcome.SUCCESS,
    "Session",
    "session-12345",
    "192.168.1.100",
    "Mozilla/5.0...",
    "corr-abc-123",
    null,
    null,
    null
);
```

## Related Enums

The record depends on the following enum types:

- `AuditActorType` - Defines the type of actor (e.g., USER, SYSTEM, SERVICE)
- `AuditCategory` - Defines the category of the audit event (e.g., SECURITY, BUSINESS, SYSTEM, COMPLIANCE)
- `AuditOutcome` - Defines the outcome of the action (e.g., SUCCESS, FAILURE, DENIED, ERROR)
