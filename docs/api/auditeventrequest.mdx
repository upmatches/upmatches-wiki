# AuditEventRequest

The `AuditEventRequest` class is a Java record that serves as a data transfer object (DTO) for capturing audit events within the application. It encapsulates all relevant information about an auditable action, including the actor performing the action, the action itself, the outcome, and associated metadata such as IP address and request payload.

This record is designed to be immutable and provides a standardized way to represent audit events across the system. It is typically used when sending audit event data to a logging or auditing service.

## Record Definition

```java
public record AuditEventRequest(
    UUID actorId,
    AuditActorType actorType,
    String action,
    AuditCategory category,
    AuditOutcome outcome,
    String resourceType,
    String resourceId,
    String ipAddress,
    String userAgent,
    String correlationId,
    String requestPayload,
    String errorCode,
    String errorMessage
)
```

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `actorId` | `UUID` | Unique identifier of the actor (user or system) who performed the action |
| `actorType` | `AuditActorType` | Enum indicating whether the actor is a user, system, or other entity |
| `action` | `String` | Description of the action performed (e.g., "CREATE", "UPDATE", "DELETE") |
| `category` | `AuditCategory` | Enum categorizing the type of audit event (e.g., SECURITY, BUSINESS, SYSTEM) |
| `outcome` | `AuditOutcome` | Enum indicating the result of the action (e.g., SUCCESS, FAILURE, DENIED) |
| `resourceType` | `String` | Type of resource affected by the action (e.g., "User", "Order", "Document") |
| `resourceId` | `String` | Unique identifier of the specific resource affected |
| `ipAddress` | `String` | IP address from which the request originated |
| `userAgent` | `String` | User agent string identifying the client application or browser |
| `correlationId` | `String` | Unique identifier for correlating related events across distributed systems |
| `requestPayload` | `String` | JSON or serialized representation of the request payload |
| `errorCode` | `String` | Error code if the action resulted in a failure |
| `errorMessage` | `String` | Human-readable error message if the action resulted in a failure |

## Usage Example

```java
AuditEventRequest auditEvent = new AuditEventRequest(
    UUID.randomUUID(),
    AuditActorType.USER,
    "LOGIN",
    AuditCategory.SECURITY,
    AuditOutcome.SUCCESS,
    "Session",
    "session-12345",
    "192.168.1.100",
    "Mozilla/5.0...",
    UUID.randomUUID().toString(),
    "{\"username\":\"john.doe\"}",
    null,
    null
);
```

## Related Enums

The record depends on the following enum types:

- `AuditActorType` - Defines the type of actor (e.g., USER, SYSTEM, SERVICE)
- `AuditCategory` - Defines the category of the audit event (e.g., SECURITY, BUSINESS, SYSTEM)
- `AuditOutcome` - Defines the outcome of the action (e.g., SUCCESS, FAILURE, DENIED)
