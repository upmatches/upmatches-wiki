# Venue Entity

The `Venue` class is a JPA entity that represents a physical location where activities take place. It maps to the `venues` database table and encapsulates all location-related data including geographic coordinates, address information, and associations with activities and transit stations.

This entity follows a **domain-driven design** approach by providing a static factory method (`create`) for construction and exposing behavior through methods like `addStation` and `removeStation`. The class uses Lombok's `@Getter` annotation to automatically generate getters for all fields, while setters are intentionally omitted to enforce immutability after creation.

## Entity Mapping

The `Venue` entity is mapped to the `venues` table with the following column mappings:

| Field | Database Column | Type | Constraints |
|-------|----------------|------|-------------|
| `id` | `id` | `Long` | Primary key, auto-generated |
| `sourceId` | `source_id` | `String` | Not null, unique, max 50 chars |
| `activity` | `activity_id` | `Activity` | Many-to-one relationship, not null |
| `name` | `name` | `String` | Not null, max 200 chars |
| `address` | `address` | `String` | Not null, max 500 chars |
| `postalCode` | `postal_code` | `String` | Not null, max 10 chars |
| `latitude` | `latitude` | `BigDecimal` | Not null, precision 13, scale 10 |
| `longitude` | `longitude` | `BigDecimal` | Not null, precision 13, scale 10 |
| `stations` | `venue_stations` (join table) | `Set<Station>` | Many-to-many relationship |
| `createdAt` | `created_at` | `Instant` | Not null, not updatable |
| `updatedAt` | `updated_at` | `Instant` | Nullable |

## Public Methods

### `create`

| Parameter | Type | Description |
|-----------|------|-------------|
| `sourceId` | `String` | External system identifier for the venue |
| `activity` | `Activity` | The activity associated with this venue |
| `name` | `String` | Name of the venue |
| `address` | `String` | Physical address of the venue |
| `postalCode` | `String` | Postal/ZIP code of the venue |
| `latitude` | `BigDecimal` | Geographic latitude coordinate |
| `longitude` | `BigDecimal` | Geographic longitude coordinate |
| **Returns** | `Venue` | A new Venue instance with the provided values |

Static factory method that creates a new `Venue` instance. This is the **only way** to construct a `Venue` object, as the constructor is protected. The method initializes all required fields and returns a fully configured entity.

### `addStation`

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The station to associate with this venue |
| **Returns** | `void` | - |

Adds a transit station to the venue's collection of associated stations. The station is added to the internal `Set<Station>` collection, which ensures no duplicate stations are added.

### `removeStation`

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The station to disassociate from this venue |
| **Returns** | `void` | - |

Removes a transit station from the venue's collection of associated stations. If the station is not currently associated, this method has no effect.

## Lifecycle Callbacks

The entity uses JPA lifecycle callbacks to automatically manage timestamp fields:

- **`@PrePersist` (`onCreate`)**: Sets both `createdAt` and `updatedAt` to the current instant when the entity is first persisted.
- **`@PreUpdate` (`onUpdate`)**: Updates the `updatedAt` field to the current instant whenever the entity is modified.

## Usage Example

```java
// Create a new venue
Activity activity = activityRepository.findById(1L).orElseThrow();
Venue venue = Venue.create(
    "ext-venue-123",
    activity,
    "Central Park",
    "123 Main Street",
    "10001",
    new BigDecimal("40.785091"),
    new BigDecimal("-73.968285")
);

// Associate a station
Station station = stationRepository.findById(1L).orElseThrow();
venue.addStation(station);

// Save the venue
venueRepository.save(venue);
```
