# Venue Entity

The `Venue` class is a JPA entity that represents a physical location where activities take place. It maps to the `venues` database table and encapsulates venue-specific data such as name, address, geographic coordinates, and associated stations.

## Purpose

This entity serves as the core data model for venue management within the application. It provides:
- Persistence mapping to the `venues` table
- A static factory method for creating new venue instances
- Lifecycle callbacks for automatic timestamp management
- Methods to manage the many-to-many relationship with `Station` entities

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `Long` | Primary key, auto-generated using identity strategy |
| `sourceId` | `String` | External source identifier (unique, max 50 chars) |
| `activity` | `Activity` | Many-to-one relationship to the associated activity |
| `name` | `String` | Venue name (max 200 chars) |
| `address` | `String` | Physical address (max 500 chars) |
| `postalCode` | `String` | Postal/ZIP code (max 10 chars) |
| `latitude` | `BigDecimal` | Geographic latitude (precision 13, scale 10) |
| `longitude` | `BigDecimal` | Geographic longitude (precision 13, scale 10) |
| `stations` | `Set<Station>` | Many-to-many relationship to associated stations |
| `createdAt` | `Instant` | Timestamp of record creation (non-updatable) |
| `updatedAt` | `Instant` | Timestamp of last update |

## Public Methods

### `create(String sourceId, Activity activity, String name, String address, String postalCode, BigDecimal latitude, BigDecimal longitude)`

Static factory method for creating a new `Venue` instance.

| Parameter | Type | Description |
|-----------|------|-------------|
| `sourceId` | `String` | External source identifier |
| `activity` | `Activity` | Associated activity |
| `name` | `String` | Venue name |
| `address` | `String` | Physical address |
| `postalCode` | `String` | Postal/ZIP code |
| `latitude` | `BigDecimal` | Geographic latitude |
| `longitude` | `BigDecimal` | Geographic longitude |

**Returns:** `Venue` - A new venue instance with the provided values.

### `addStation(Station station)`

Adds a station to the venue's station collection.

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The station to add |

**Returns:** `void`

### `removeStation(Station station)`

Removes a station from the venue's station collection.

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The station to remove |

**Returns:** `void`

## Lifecycle Callbacks

### `onCreate()`

Automatically invoked before the entity is persisted. Sets both `createdAt` and `updatedAt` to the current instant.

### `onUpdate()`

Automatically invoked before the entity is updated. Sets `updatedAt` to the current instant.

## Database Mapping

The entity maps to the `venues` table with the following key relationships:
- **Many-to-one** with `Activity` via the `activity_id` foreign key
- **Many-to-many** with `Station` through the `venue_stations` join table, which contains `venue_id` and `station_id` columns

## Usage Example

```java
// Create a new venue
Venue venue = Venue.create(
    "ext-123",
    activity,
    "Central Park",
    "123 Main St",
    "10001",
    new BigDecimal("40.785091"),
    new BigDecimal("-73.968285")
);

// Add a station
venue.addStation(station);

// Remove a station
venue.removeStation(station);
```
