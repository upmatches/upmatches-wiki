## Overview

The `Venue` class represents a location where activities take place. It is a JPA entity mapped to the `venues` table in the database. This class is part of the `com.upmatches.app.features.venue.entities` package and is designed to store and manage information about various venues, including their geographical coordinates and associated stations.

## Public Methods

The `Venue` class provides several public methods to interact with its instances. Below is a detailed description of these methods, including their parameters and return types.

### `create`

Creates a new instance of the `Venue` class with the specified attributes.

| Method Signature                                                                 |
|----------------------------------------------------------------------------------|
| `public static Venue create(String sourceId, Activity activity, String name, String address, String postalCode, BigDecimal latitude, BigDecimal longitude)` |

#### Parameters

| Name       | Type          | Description                                      |
|------------|---------------|--------------------------------------------------|
| `sourceId` | `String`      | A unique identifier for the venue source.        |
| `activity` | `Activity`    | The activity associated with the venue.          |
| `name`     | `String`      | The name of the venue.                           |
| `address`  | `String`      | The address of the venue.                        |
| `postalCode` | `String`    | The postal code of the venue's location.         |
| `latitude` | `BigDecimal`  | The latitude coordinate of the venue.            |
| `longitude`| `BigDecimal`  | The longitude coordinate of the venue.           |

#### Return Type

| Type   | Description                        |
|--------|------------------------------------|
| `Venue`| A new instance of the `Venue` class.|

### `addStation`

Adds a station to the set of stations associated with the venue.

| Method Signature                      |
|---------------------------------------|
| `public void addStation(Station station)` |

#### Parameters

| Name      | Type     | Description                          |
|-----------|----------|--------------------------------------|
| `station` | `Station`| The station to be added to the venue.|

#### Return Type

| Type | Description |
|------|-------------|
| `void` | No return value. |

### `removeStation`

Removes a station from the set of stations associated with the venue.

| Method Signature                         |
|------------------------------------------|
| `public void removeStation(Station station)` |

#### Parameters

| Name      | Type     | Description                            |
|-----------|----------|----------------------------------------|
| `station` | `Station`| The station to be removed from the venue.|

#### Return Type

| Type | Description |
|------|-------------|
| `void` | No return value. |

## Entity Lifecycle Callbacks

The `Venue` class includes lifecycle callback methods to manage timestamps:

- **`onCreate`**: Sets the `createdAt` and `updatedAt` timestamps when a new venue is persisted.
- **`onUpdate`**: Updates the `updatedAt` timestamp when an existing venue is updated.
