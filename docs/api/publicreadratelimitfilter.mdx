## Purpose

The `PublicReadRateLimitFilter` class is a Spring component designed to enforce rate limiting on public read operations for specific API endpoints. It extends `OncePerRequestFilter` to ensure that the filter logic is applied once per request. The filter is conditional on the presence of a `StringRedisTemplate` bean, indicating that Redis is used for storing rate limit data. The class distinguishes between authenticated and anonymous users, applying different rate limits for each.

## Public Methods

### Constructor

| Method Signature | Description |
|------------------|-------------|
| `PublicReadRateLimitFilter(StringRedisTemplate redisTemplate)` | Constructs a new `PublicReadRateLimitFilter` with the provided `StringRedisTemplate` for Redis operations. |

|-------------|-------------|
| `void`      | Executes the filter logic, potentially modifying the response if rate limits are exceeded. |

## Key Functionalities

- **Rate Limiting**: The filter applies rate limits based on the request URI and the authentication status of the user. It uses Redis to track request counts and enforce limits.
- **Bucket Resolution**: Determines the appropriate rate limit bucket based on the request URI.
- **Client Identification**: Identifies the client either by JWT subject for authenticated users or by IP address for anonymous users.
- **Rate Limit Response**: Constructs and sends a `429 Too Many Requests` response when rate limits are exceeded, including a `Retry-After` header.

## Usage

This filter is typically used in applications where public API endpoints need to be protected against excessive requests, ensuring fair usage and preventing abuse. It is particularly useful in scenarios where different rate limits are required for authenticated versus anonymous users.
