# DeleteGameBookmarkService

The `DeleteGameBookmarkService` class is a Spring service responsible for removing a game bookmark for the currently authenticated user. It ensures that only the owner of the bookmark can delete it by resolving the authenticated user's ID and verifying the bookmark exists before deletion.

## Purpose

This service encapsulates the business logic for deleting a game bookmark. It performs the following operations:
- Resolves the authenticated user's ID
- Finds the bookmark by game ID and user ID
- Throws a `ResourceNotFoundException` if the bookmark does not exist
- Deletes the bookmark within a transactional context
- Wraps the deletion operation in a `ServiceOperationExecutor` for consistent error handling

## Public Methods

### `execute(UUID gameId)`

Deletes a game bookmark for the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game whose bookmark should be deleted |

**Return Type:** `void`

**Throws:**
- `ResourceNotFoundException` if no bookmark exists for the given game ID and authenticated user ID

**Behavior:**
1. Resolves the authenticated user's ID using `userResolver.requireUserId()`
2. Searches for the bookmark using `bookmarkRepository.findByGameIdAndUserId(gameId, userId)`
3. If not found, throws `ResourceNotFoundException` with a formatted message containing the game ID and user ID
4. If found, executes the deletion within `ServiceOperationExecutor.executeVoid()` with the `DELETE` operation status

## Error Handling

The service uses a consistent error handling approach:
- **Missing Bookmark:** Throws `ResourceNotFoundException` with a descriptive message
- **Operation Execution:** Uses `ServiceOperationExecutor.executeVoid()` to wrap the deletion, converting any repository exceptions into `ResourceNotFoundException`

## Transactional Behavior

The `execute` method is annotated with `@Transactional`, ensuring that the deletion operation is performed within a database transaction. This guarantees atomicity and consistency of the operation.

## Usage Example

```java
@Autowired
private DeleteGameBookmarkService deleteGameBookmarkService;

public void removeBookmark(UUID gameId) {
    deleteGameBookmarkService.execute(gameId);
}
```
