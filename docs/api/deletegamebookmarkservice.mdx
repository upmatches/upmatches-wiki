# DeleteGameBookmarkService

## Purpose

The `DeleteGameBookmarkService` class is a Spring service responsible for deleting a game bookmark for the currently authenticated user. It ensures that only the owner of the bookmark can delete it by resolving the authenticated user's ID and verifying the bookmark exists before deletion.

This service implements the `IDeleteGameBookmarkService` interface and is annotated with `@Service` and `@Transactional` to ensure proper transaction management.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameBookmarkRepository` | Repository | Data access layer for `GameBookmark` entities |
| `IAuthenticatedUserResolver` | Interface | Resolves the currently authenticated user's UUID |

## Public Methods

### `execute(UUID gameId)`

Deletes a game bookmark for the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `gameId` | `UUID` | The unique identifier of the game whose bookmark should be deleted |

**Returns:** `void`

**Throws:**
- `ResourceNotFoundException` – If no bookmark exists for the given game ID and authenticated user ID

**Behavior:**
1. Resolves the authenticated user's UUID via `userResolver.requireUserId()`
2. Searches for a `GameBookmark` matching both the provided `gameId` and the resolved `userId`
3. If no bookmark is found, throws a `ResourceNotFoundException` with a descriptive message
4. If found, deletes the bookmark using `ServiceOperationExecutor.executeVoid()` with the `DELETE` operation status

## Error Handling

The service uses a custom error message template:
```
Bookmark for game '%s' and user '%s' not found.
```

Where `%s` is replaced with the `gameId` and `userId` respectively.

## Transaction Management

The `execute` method is annotated with `@Transactional`, ensuring that the delete operation is performed within a database transaction. If any exception occurs during execution, the transaction will be rolled back.

## Usage Example

```java
@Autowired
private DeleteGameBookmarkService deleteGameBookmarkService;

// Delete bookmark for game with ID 123e4567-e89b-12d3-a456-426614174000
deleteGameBookmarkService.execute(UUID.fromString("123e4567-e89b-12d3-a456-426614174000"));
```

## Notes

- The class is declared as `non-sealed`, indicating it is part of a sealed class hierarchy (likely implementing `IDeleteGameBookmarkService`)
- The `ServiceOperationExecutor.executeVoid()` method handles the actual deletion and wraps any exceptions into `ResourceNotFoundException`
- The service ensures data integrity by only allowing users to delete their own bookmarks
