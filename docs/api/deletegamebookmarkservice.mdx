## Overview

The `DeleteGameBookmarkService` class is a part of the `com.upmatches.app.features.game.services` package. It is responsible for handling the deletion of game bookmarks for authenticated users. This service ensures that only the bookmarks associated with the current authenticated user can be deleted, maintaining data integrity and security.

## Class Purpose

The primary purpose of the `DeleteGameBookmarkService` is to provide a transactional operation that deletes a game bookmark based on the game ID and the authenticated user's ID. If the bookmark does not exist, it throws a `ResourceNotFoundException`.

## Public Methods

### `execute`

Deletes a game bookmark for the authenticated user.

| Parameter | Type   | Description                           |
|-----------|--------|---------------------------------------|
| `gameId`  | `UUID` | The unique identifier of the game.    |

| Return Type | Description |
|-------------|-------------|
| `void`      | This method does not return a value. |

#### Exceptions

- `ResourceNotFoundException`: Thrown if no bookmark is found for the specified game ID and user ID.

## Usage

To use the `DeleteGameBookmarkService`, you need to have an instance of `GameBookmarkRepository` and `IAuthenticatedUserResolver` injected into the service. The `execute` method should be called with the game ID for which the bookmark needs to be deleted. The service will handle the rest, ensuring that the operation is performed within a transactional context.
