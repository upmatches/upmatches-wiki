# ResolveShareLinkService

## Purpose

The `ResolveShareLinkService` is a Spring service class responsible for resolving shared links within the UpMatches application. It handles the process of looking up a short link code, tracking click counts, granting access to private games when applicable, and constructing both web and mobile URLs for the resolved resource.

This service implements the `IResolveShareLinkService` interface and is marked as a non-sealed class, allowing for future extension if needed.

## Key Features

- **Link Resolution**: Looks up short links by their unique code
- **Click Tracking**: Automatically increments click counts for resolved links
- **Private Game Access**: Automatically grants access to private games when a user resolves a share link
- **URL Generation**: Builds both web and mobile URLs for the resolved resource
- **Audit Logging**: Uses the `@Auditable` annotation to log sensitive read operations
- **Transaction Management**: Ensures atomicity of the resolution process

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ShortLinkRepository` | Repository | Data access for short link entities |
| `IShareLinkUrlBuilder` | Service | Builds web and mobile URLs for resources |
| `GameRepository` | Repository | Data access for game entities |
| `GameShareAccessRepository` | Repository | Manages game share access records |
| `UserRepository` | Repository | Data access for user entities |

## Public Methods

### `execute(String code)`

Resolves a share link by its unique code and returns the corresponding public response.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | The unique short link code to resolve |

**Returns**: `PublicShareLinkResponse` containing the resolved link details, web URL, and mobile URL

**Throws**: `ResourceNotFoundException` if no link is found with the given code

**Behavior**:
1. Looks up the short link by code in the repository
2. Increments the click count for the link
3. Grants private game access if the link points to a private game and the user is authenticated
4. Builds web and mobile URLs using the `IShareLinkUrlBuilder`
5. Returns a `PublicShareLinkResponse` constructed from the link and URLs

## Private Methods

### `grantPrivateGameAccessIfApplicable(ShortLink link)`

Grants access to a private game if the resolved link points to a game resource and the user is authenticated.

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The resolved short link entity |

**Behavior**:
1. Checks if the link's resource type is `GAME`; returns if not
2. Retrieves the authenticated user's ID; returns if not authenticated
3. Validates the resource ID as a valid UUID; returns if invalid
4. Checks if the game exists and is private; returns if not
5. Checks if the user already has access to the game; returns if already granted
6. Creates and saves a new `GameShareAccess` record

### `getAuthenticatedUserIdOrNull()`

Retrieves the authenticated user's ID from the security context.

**Returns**: `UUID` of the authenticated user, or `null` if not authenticated or unable to parse the subject

**Behavior**:
1. Gets the current authentication from `SecurityContextHolder`
2. Checks if the principal is a `Jwt` instance
3. Parses the JWT subject as a UUID
4. Returns the UUID or null if any step fails

## Error Handling

- **ResourceNotFoundException**: Thrown when the short link code is not found in the repository
- **IllegalArgumentException**: Caught and silently ignored when parsing invalid UUIDs for game IDs
- **Security Context**: Handles cases where no authentication is present or the principal is not a JWT

## Usage Example

```java
@Autowired
private ResolveShareLinkService resolveShareLinkService;

public void handleShareLink(String code) {
    try {
        PublicShareLinkResponse response = resolveShareLinkService.execute(code);
        // Use the response to redirect or display the shared resource
        String webUrl = response.getWebUrl();
        String mobileUrl = response.getMobileUrl();
    } catch (ResourceNotFoundException e) {
        // Handle invalid or expired share link
    }
}
```

## Notes

- The service is annotated with `@Transactional` to ensure data consistency during link resolution
- All operations are wrapped in `ServiceOperationExecutor.execute()` for consistent error handling and logging
- The `@Auditable` annotation logs the resolution as a sensitive read operation for audit purposes
- Private game access is only granted if the user is authenticated and doesn't already have access
