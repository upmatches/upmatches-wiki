# ResolveShareLinkService

## Purpose

The `ResolveShareLinkService` is a Spring service that resolves shared links (short URLs) and provides the appropriate redirect information. It handles the complete lifecycle of resolving a share link, including:

- Looking up the short link by its unique code
- Incrementing the click counter for analytics
- Automatically granting access to private games when the authenticated user follows a valid share link
- Building both web and mobile URLs for the resolved resource
- Auditing all resolution attempts for security monitoring

This service is part of the share link feature and implements the `IResolveShareLinkService` interface.

## Public Methods

### `execute(String code)`

Resolves a share link code and returns the corresponding resource information.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | The unique short link code to resolve |

**Returns:** `PublicShareLinkResponse` containing:
- The resolved resource type and ID
- Web URL for browser access
- Mobile URL for app deep linking
- Original short link metadata

**Exceptions:**
- `ResourceNotFoundException` if no link exists with the given code

**Side Effects:**
- Increments the click count on the short link
- If the resource is a private game and the user is authenticated, automatically grants the user access to that game
- Logs an audit event with category `SENSITIVE_READ`

## Internal Methods

### `grantPrivateGameAccessIfApplicable(ShortLink link)`

Grants access to a private game if the link points to a game resource and the authenticated user doesn't already have access.

| Parameter | Type | Description |
|-----------|------|-------------|
| `link` | `ShortLink` | The resolved short link entity |

**Logic:**
1. Returns immediately if the resource type is not `GAME`
2. Extracts the authenticated user's ID from the security context
3. Returns if no authenticated user is found
4. Validates the resource ID is a valid UUID
5. Checks if the game exists, is not deleted, and has `PRIVATE` visibility
6. Verifies the user hasn't already been granted access
7. Creates and saves a new `GameShareAccess` entity

### `getAuthenticatedUserIdOrNull()`

Extracts the authenticated user's UUID from the Spring Security context.

**Returns:** `UUID` or `null` if:
- No authentication is present
- The principal is not a JWT token
- The JWT subject cannot be parsed as a UUID

## Dependencies

| Dependency | Type | Purpose |
|------------|------|---------|
| `ShortLinkRepository` | Repository | Persistence for short link entities |
| `IShareLinkUrlBuilder` | Service | Builds web and mobile URLs for resources |
| `GameRepository` | Repository | Game entity persistence and lookup |
| `GameShareAccessRepository` | Repository | Manages game access permissions |
| `UserRepository` | Repository | User entity lookup |
| `ServiceOperationExecutor` | Utility | Wraps service operations with error handling and auditing |

## Audit Configuration

The `execute` method is annotated with `@Auditable`:

- **Action:** `SHARE_LINK_RESOLVED`
- **Category:** `SENSITIVE_READ`
- **Resource Type:** `SHARE_LINK`
- **Resource ID Expression:** `#args[0]` (the code parameter)

## Usage Example

```java
@Autowired
private ResolveShareLinkService resolveShareLinkService;

// Resolve a share link
PublicShareLinkResponse response = resolveShareLinkService.execute("abc123");

// Access resolved URLs
String webUrl = response.getWebUrl();
String mobileUrl = response.getMobileUrl();
```

## Notes

- The service is `@Transactional`, ensuring atomicity of the resolution and access granting operations
- The class is declared as `non-sealed`, allowing for future extension while maintaining the sealed interface hierarchy
- Private game access is only granted to authenticated users; anonymous users will receive the link information but won't gain access
- The click counter is incremented regardless of whether the user is authenticated or the resource type
