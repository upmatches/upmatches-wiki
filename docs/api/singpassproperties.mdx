## Purpose

The `SingpassProperties` class is a configuration properties holder for the Singpass authentication feature within the application. It is designed to capture and manage various configuration settings necessary for integrating with Singpass, a trusted digital identity platform. This class uses Spring Boot's `@ConfigurationProperties` annotation to map properties prefixed with `app.singpass` from external configuration sources (such as application.properties or application.yml) into its fields.

## Public Methods

The `SingpassProperties` class is a Java record, which inherently provides a concise way to create immutable data-carrying classes. The class does not explicitly define public methods beyond its constructor, but it provides implicit accessor methods for each of its fields. Below is a table documenting these accessors:

| Method Name                   | Parameters | Return Type | Description                                                                 |
|-------------------------------|------------|-------------|-----------------------------------------------------------------------------|
| `clientId()`                  | None       | `String`    | Returns the client ID used for authentication with Singpass.                |
| `redirectUri()`               | None       | `String`    | Returns the URI to which Singpass will redirect after authentication.       |
| `issuer()`                    | None       | `String`    | Returns the issuer identifier for the Singpass service.                     |
| `authorizationEndpoint()`     | None       | `String`    | Returns the endpoint for initiating the authorization request.              |
| `parEndpoint()`               | None       | `String`    | Returns the Pushed Authorization Request (PAR) endpoint.                    |
| `tokenEndpoint()`             | None       | `String`    | Returns the endpoint for obtaining tokens from Singpass.                    |
| `jwksEndpoint()`              | None       | `String`    | Returns the JSON Web Key Set (JWKS) endpoint for retrieving public keys.    |
| `userinfoEndpoint()`          | None       | `String`    | Returns the endpoint for accessing user information.                        |
| `scopes()`                    | None       | `String`    | Returns the scopes requested during authentication, defaulting to "openid". |
| `authContextType()`           | None       | `String`    | Returns the authentication context type, defaulting to "APP_AUTHENTICATION_DEFAULT". |
| `authContextMessage()`        | None       | `String`    | Returns the message associated with the authentication context.             |
| `privateSigningKeyPath()`     | None       | `String`    | Returns the file path to the private signing key.                           |
| `privateEncryptionKeyPath()`  | None       | `String`    | Returns the file path to the private encryption key.                        |

## Default Values

The `SingpassProperties` class provides default values for certain fields if they are not explicitly set:

- **Scopes**: Defaults to `"openid"` if not specified.
- **Auth Context Type**: Defaults to `"APP_AUTHENTICATION_DEFAULT"` if not specified.

These defaults ensure that the application has a baseline configuration for interacting with Singpass, even if some properties are omitted from the configuration files.
