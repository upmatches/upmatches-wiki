# SingpassProperties

The `SingpassProperties` class is a Spring Boot configuration properties record that encapsulates all configuration parameters required for integrating with the Singpass authentication system. It uses the `@ConfigurationProperties` annotation with the prefix `app.singpass`, allowing these values to be easily configured via `application.properties` or `application.yml` files.

## Purpose

This class serves as a centralized configuration holder for Singpass OAuth 2.0 / OpenID Connect authentication flow. It defines all the necessary endpoints, credentials, and parameters needed to interact with the Singpass identity provider, including authorization, token exchange, and user information retrieval.

## Configuration Properties

The following table documents all the configuration properties exposed by this record:

| Property | Type | Description |
|----------|------|-------------|
| `clientId` | `String` | The client identifier assigned by Singpass for your application |
| `redirectUri` | `String` | The URI where Singpass will redirect users after authentication |
| `issuer` | `String` | The issuer identifier for the Singpass identity provider |
| `authorizationEndpoint` | `String` | The URL for initiating the authorization request |
| `parEndpoint` | `String` | The Pushed Authorization Request (PAR) endpoint URL |
| `tokenEndpoint` | `String` | The URL for exchanging authorization codes for tokens |
| `jwksEndpoint` | `String` | The JSON Web Key Set (JWKS) endpoint URL for public key retrieval |
| `userinfoEndpoint` | `String` | The URL for retrieving authenticated user information |
| `scopes` | `String` | The OAuth 2.0 scopes requested (defaults to `"openid"`) |
| `authContextType` | `String` | The authentication context type (defaults to `"APP_AUTHENTICATION_DEFAULT"`) |
| `authContextMessage` | `String` | The authentication context message for user-facing prompts |
| `privateSigningKeyPath` | `String` | The file path to the private key used for signing requests |
| `privateEncryptionKeyPath` | `String` | The file path to the private key used for decrypting responses |

## Default Values

The record provides sensible defaults for two critical properties:

- **`scopes`**: Defaults to `"openid"` if not explicitly configured or if the provided value is blank
- **`authContextType`**: Defaults to `"APP_AUTHENTICATION_DEFAULT"` if not explicitly configured or if the provided value is blank

## Usage Example

To configure these properties in your `application.yml`:

```yaml
app:
  singpass:
    client-id: your-client-id
    redirect-uri: https://yourapp.com/callback
    issuer: https://singpass.gov.sg
    authorization-endpoint: https://singpass.gov.sg/auth
    par-endpoint: https://singpass.gov.sg/par
    token-endpoint: https://singpass.gov.sg/token
    jwks-endpoint: https://singpass.gov.sg/jwks
    userinfo-endpoint: https://singpass.gov.sg/userinfo
    scopes: openid profile
    auth-context-type: APP_AUTHENTICATION_DEFAULT
    auth-context-message: Please authenticate with Singpass
    private-signing-key-path: /path/to/signing-key.pem
    private-encryption-key-path: /path/to/encryption-key.pem
```

## Key Features

- **Immutable Configuration**: As a Java record, all properties are immutable after construction
- **Spring Boot Integration**: Automatically binds properties from external configuration sources
- **Sensible Defaults**: Provides fallback values for critical authentication parameters
- **Type Safety**: All properties are strongly typed as `String` values
