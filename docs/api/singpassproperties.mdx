# SingpassProperties

The `SingpassProperties` class is a Spring Boot configuration properties record that encapsulates all configuration parameters required for integrating with the Singpass authentication system. It uses the `@ConfigurationProperties` annotation with the prefix `app.singpass`, allowing these values to be easily configured via `application.properties` or `application.yml` files.

This record provides a centralized and type-safe way to manage Singpass OAuth 2.0 / OpenID Connect configuration, including endpoints, client credentials, and authentication context settings.

## Constructor Behavior

The compact constructor of this record applies default values for two optional fields:
- **scopes**: Defaults to `"openid"` if not provided or blank.
- **authContextType**: Defaults to `"APP_AUTHENTICATION_DEFAULT"` if not provided or blank.

## Configuration Properties

The following table describes each configuration property that can be set using the `app.singpass` prefix:

| Property | Type | Description | Default |
|----------|------|-------------|---------|
| `clientId` | `String` | The client identifier assigned by Singpass | Required |
| `redirectUri` | `String` | The redirect URI for OAuth callbacks | Required |
| `issuer` | `String` | The issuer identifier for the Singpass provider | Required |
| `authorizationEndpoint` | `String` | The authorization endpoint URL | Required |
| `parEndpoint` | `String` | The pushed authorization request (PAR) endpoint URL | Required |
| `tokenEndpoint` | `String` | The token endpoint URL | Required |
| `jwksEndpoint` | `String` | The JWKS (JSON Web Key Set) endpoint URL | Required |
| `userinfoEndpoint` | `String` | The userinfo endpoint URL | Required |
| `scopes` | `String` | The OAuth scopes to request | `"openid"` |
| `authContextType` | `String` | The authentication context type | `"APP_AUTHENTICATION_DEFAULT"` |
| `authContextMessage` | `String` | The authentication context message | Required |
| `privateSigningKeyPath` | `String` | Path to the private signing key file | Required |
| `privateEncryptionKeyPath` | `String` | Path to the private encryption key file | Required |

## Usage Example

To configure this properties class, add the following to your `application.yml`:

```yaml
app:
  singpass:
    client-id: your-client-id
    redirect-uri: https://your-app.com/callback
    issuer: https://singpass.gov.sg
    authorization-endpoint: https://singpass.gov.sg/auth
    par-endpoint: https://singpass.gov.sg/par
    token-endpoint: https://singpass.gov.sg/token
    jwks-endpoint: https://singpass.gov.sg/jwks
    userinfo-endpoint: https://singpass.gov.sg/userinfo
    scopes: openid profile
    auth-context-type: APP_AUTHENTICATION_DEFAULT
    auth-context-message: Please authenticate with Singpass
    private-signing-key-path: /path/to/signing-key.pem
    private-encryption-key-path: /path/to/encryption-key.pem
```

## Dependencies

This class requires the following Spring Boot dependency:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```

## Notes

- All properties are required except `scopes` and `authContextType`, which have sensible defaults.
- The record is immutable after construction, ensuring thread-safe access to configuration values.
- The `@ConfigurationProperties` annotation enables Spring Boot's configuration property binding and validation.
