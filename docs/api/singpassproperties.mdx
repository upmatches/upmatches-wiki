# SingpassProperties

The `SingpassProperties` class is a Spring Boot configuration properties record that encapsulates all configuration parameters required for integrating with the Singpass authentication system. It is annotated with `@ConfigurationProperties(prefix = "app.singpass")`, meaning all properties defined in the application's configuration files (e.g., `application.yml` or `application.properties`) under the `app.singpass` prefix will be automatically bound to this record's components.

This record provides a centralized and type-safe way to manage Singpass OAuth 2.0 / OpenID Connect settings, including endpoints, client credentials, and authentication context parameters.

## Purpose

- **Centralized Configuration**: Aggregates all Singpass-related configuration in one place.
- **Type Safety**: Uses a Java record to ensure immutability and compile-time safety.
- **Default Values**: Provides sensible defaults for `scopes` and `authContextType` if not explicitly configured.
- **Spring Boot Integration**: Leverages Spring Boot's `@ConfigurationProperties` for automatic binding and validation.

## Constructor

The compact constructor of the record applies default values for `scopes` and `authContextType` when they are `null` or blank:

- **scopes**: Defaults to `"openid"` if not provided.
- **authContextType**: Defaults to `"APP_AUTHENTICATION_DEFAULT"` if not provided.

## Properties

All properties are bound from the `app.singpass` prefix in the application configuration.

| Property | Type | Description |
|----------|------|-------------|
| `clientId` | `String` | The client identifier assigned by Singpass. |
| `redirectUri` | `String` | The URI to which Singpass redirects after authentication. |
| `issuer` | `String` | The issuer URL of the Singpass OpenID Provider. |
| `authorizationEndpoint` | `String` | The authorization endpoint URL for initiating the OAuth flow. |
| `parEndpoint` | `String` | The Pushed Authorization Request (PAR) endpoint URL. |
| `tokenEndpoint` | `String` | The token endpoint URL for exchanging authorization codes for tokens. |
| `jwksEndpoint` | `String` | The JWKS (JSON Web Key Set) endpoint URL for public key retrieval. |
| `userinfoEndpoint` | `String` | The UserInfo endpoint URL for retrieving user claims. |
| `scopes` | `String` | The requested OAuth scopes. Defaults to `"openid"`. |
| `authContextType` | `String` | The authentication context type. Defaults to `"APP_AUTHENTICATION_DEFAULT"`. |
| `authContextMessage` | `String` | A message associated with the authentication context. |
| `privateSigningKeyPath` | `String` | The file path to the private signing key (e.g., for JWT assertion). |
| `privateEncryptionKeyPath` | `String` | The file path to the private encryption key (e.g., for decrypting responses). |

## Example Configuration

### application.yml

```yaml
app:
  singpass:
    client-id: your-client-id
    redirect-uri: https://yourapp.com/callback
    issuer: https://singpass.gov.sg
    authorization-endpoint: https://singpass.gov.sg/auth
    par-endpoint: https://singpass.gov.sg/par
    token-endpoint: https://singpass.gov.sg/token
    jwks-endpoint: https://singpass.gov.sg/jwks
    userinfo-endpoint: https://singpass.gov.sg/userinfo
    scopes: openid profile
    auth-context-type: APP_AUTHENTICATION_DEFAULT
    auth-context-message: "Authenticate with Singpass"
    private-signing-key-path: /path/to/signing-key.pem
    private-encryption-key-path: /path/to/encryption-key.pem
```

### application.properties

```properties
app.singpass.client-id=your-client-id
app.singpass.redirect-uri=https://yourapp.com/callback
app.singpass.issuer=https://singpass.gov.sg
app.singpass.authorization-endpoint=https://singpass.gov.sg/auth

app.singpass.userinfo-endpoint=https://singpass.gov.sg/userinfo
app.singpass.scopes=openid profile

```

## Usage

To use this configuration in your Spring Boot application, enable `@ConfigurationProperties` scanning and inject the record:

```java
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Configuration;

@Configuration
@EnableConfigurationProperties(SingpassProperties.class)
public class SingpassConfig {
    // SingpassProperties will be automatically bound
}
```

Then inject it into your services:

```java
import org.springframework.stereotype.Service;

@Service
public class AuthService {
    private final SingpassProperties properties;

    public AuthService(SingpassProperties properties) {
        this.properties = properties;
    }

    public String getAuthorizationUrl() {
        return properties.authorizationEndpoint() + "?client_id=" + properties.clientId();
    }
}
```

## Notes

- The record is immutable after construction, ensuring thread safety.
- Default values are applied only if the property is not set or is blank in the configuration.
- All properties are required except `scopes` and `authContextType`, which have defaults.
