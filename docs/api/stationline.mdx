# StationLine Entity

The `StationLine` entity represents the many-to-many relationship between a `Station` and a `TransitLine`, with an additional `stationNumber` attribute that indicates the order or number of the station along the transit line.

This entity is part of the `com.upmatches.app.features.venue.entities` package and is mapped to the `station_lines` database table.

## Purpose

In a transit or venue system, a single station can belong to multiple transit lines (e.g., a subway station serving multiple routes), and a transit line can have multiple stations. The `StationLine` entity models this junction table, providing:

- A composite primary key (`StationLineId`) consisting of the station ID and transit line code.
- A reference to the associated `Station`.
- A reference to the associated `TransitLine`.
- The station's number or order along the transit line.

## Public Methods

### `create`

```java
public static StationLine create(Station station, TransitLine transitLine, Integer stationNumber)
```

Creates a new `StationLine` instance with the provided station, transit line, and station number.

**Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `station` | `Station` | The station to associate. |
| `transitLine` | `TransitLine` | The transit line to associate. |
| `stationNumber` | `Integer` | The station's number or order along the transit line. |

**Returns:**

| Return Type | Description |
|---|---|
| `StationLine` | A new `StationLine` instance with the composite key automatically generated from the station ID and transit line code. |

**Example Usage:**

```java
Station station = stationRepository.findById(1L).orElseThrow();
TransitLine transitLine = transitLineRepository.findById("RED").orElseThrow();

StationLine stationLine = StationLine.create(station, transitLine, 5);
stationLineRepository.save(stationLine);
```

## Database Mapping

The entity maps to the `station_lines` table with the following columns:

| Column Name | Type | Description |
|---|---|---|
| `station_id` | (FK) | Foreign key to the `station` table, part of composite primary key. |
| `transit_line_code` | (FK) | Foreign key to the `transit_line` table, part of composite primary key. |
| `station_number` | `INTEGER` | The station's number along the transit line. |

## Relationships

- **Station (Many-to-One):** Each `StationLine` belongs to one `Station`. The foreign key `station_id` is mapped to the `stationId` field of the composite key.
- **TransitLine (Many-to-One):** Each `StationLine` belongs to one `TransitLine`. The foreign key `transit_line_code` is mapped to the `transitLineCode` field of the composite key.

## Usage Notes

- The composite primary key (`StationLineId`) must implement `Serializable` and override `equals()` and `hashCode()`.
- The `create()` factory method ensures the composite key is correctly initialized from the associated entities.
- The protected no-argument constructor is for JPA use only; do not call it directly.
