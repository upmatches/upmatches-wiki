# StationLine

The `StationLine` entity represents the many-to-many relationship between a `Station` and a `TransitLine` in the venue system. It maps to the `station_lines` database table and stores the order (station number) of a station along a specific transit line.

## Purpose

This entity is used to model the association between stations and transit lines, including the position of the station on that line. For example, on a subway line, each station has a sequential number indicating its stop order.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `StationLineId` | Composite primary key consisting of `stationId` and `transitLineCode` |
| `station` | `Station` | The associated station (many-to-one relationship) |
| `transitLine` | `TransitLine` | The associated transit line (many-to-one relationship) |
| `stationNumber` | `Integer` | The order/position of the station on the transit line |

## Database Mapping

- **Table**: `station_lines`
- **Primary Key**: Composite key (`station_id`, `transit_line_code`) via `@EmbeddedId`
- **Foreign Keys**:
  - `station_id` references the `Station` entity
  - `transit_line_code` references the `TransitLine` entity

## Methods

### `create(Station station, TransitLine transitLine, Integer stationNumber)`

Creates a new `StationLine` instance with the specified station, transit line, and station number.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The station to associate |
| `transitLine` | `TransitLine` | The transit line to associate |
| `stationNumber` | `Integer` | The order number of the station on the line |

**Returns:** `StationLine` - A new instance with the composite key automatically generated from the station ID and transit line code.

**Example usage:**

```java
Station station = stationRepository.findById(1L).orElseThrow();
TransitLine transitLine = transitLineRepository.findById("RED").orElseThrow();

StationLine stationLine = StationLine.create(station, transitLine, 5);
stationLineRepository.save(stationLine);
```

## Notes

- The class uses Lombok's `@Getter` annotation to automatically generate getters for all fields.
- The protected no-argument constructor is required by JPA for entity instantiation.
- The `@MapsId` annotation on both `@ManyToOne` relationships ensures that the composite key fields are automatically populated from the associated entities.
