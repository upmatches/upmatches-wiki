# StationLine Entity

The `StationLine` entity represents the many-to-many relationship between a `Station` and a `TransitLine` in the venue system. It maps to the `station_lines` database table and includes an additional `stationNumber` field to indicate the order or number of the station along the transit line.

This entity uses a composite primary key (`StationLineId`) consisting of the station ID and the transit line code. It is designed to be immutable after creation, with a static factory method `create()` as the sole way to instantiate new instances.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | `StationLineId` | Composite primary key (station ID + transit line code). |
| `station` | `Station` | The station associated with this line. |
| `transitLine` | `TransitLine` | The transit line associated with this station. |
| `stationNumber` | `Integer` | The order or number of the station on the transit line. |

## Public Methods

### `create`

```java
public static StationLine create(Station station, TransitLine transitLine, Integer stationNumber)
```

Creates a new `StationLine` instance with the specified station, transit line, and station number.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `station` | `Station` | The station to associate. |
| `transitLine` | `TransitLine` | The transit line to associate. |
| `stationNumber` | `Integer` | The station number or order on the line. |

**Returns:**

| Return Type | Description |
|-------------|-------------|
| `StationLine` | A new `StationLine` instance with the provided values. |

**Example Usage:**

```java
Station station = stationRepository.findById(1L).orElseThrow();
TransitLine line = transitLineRepository.findById("RED").orElseThrow();

StationLine stationLine = StationLine.create(station, line, 5);
stationLineRepository.save(stationLine);
```

## Database Mapping

The entity is mapped to the `station_lines` table with the following columns:

| Column Name | Type | Description |
|-------------|------|-------------|
| `station_id` | (FK) | Foreign key to the `station` table. |
| `transit_line_code` | (FK) | Foreign key to the `transit_line` table. |
| `station_number` | `INTEGER` | The station number on the line. |

The composite primary key is defined by the `StationLineId` embeddable class, which contains both `stationId` and `transitLineCode`.

## Notes

- The entity uses Lombok's `@Getter` annotation to generate getters for all fields.
- The protected no-argument constructor is required by JPA and should not be used directly.
- The `@MapsId` annotation on both `@ManyToOne` relationships ensures that the foreign key columns are also used as part of the composite primary key.
- The `stationNumber` field is optional (nullable) and can be used to order stations along a transit line.
