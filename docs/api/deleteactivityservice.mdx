# DeleteActivityService

The `DeleteActivityService` class is a Spring service component responsible for deleting an `Activity` entity from the system. It implements the `IDeleteActivityService` interface and provides a transactional, auditable method to safely remove an activity by its unique identifier (UUID).

## Purpose

This service encapsulates the business logic for deleting activities, ensuring that:
- The activity exists before attempting deletion
- The operation is executed within a transactional context
- The deletion is audited for compliance and tracking purposes
- Any errors are properly handled and wrapped in appropriate exceptions

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ActivityRepository` | Repository | Data access layer for Activity entities |

## Public Methods

### `execute(UUID id)`

Deletes an activity by its unique identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to delete |

**Return Type:** `void`

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | If no activity exists with the provided ID |

**Behavior:**
1. Looks up the activity by its UUID
2. Throws `ResourceNotFoundException` if the activity is not found
3. Deletes the activity from the repository
4. Executes within a transactional context
5. Records an audit event with action type `ACTIVITY_DELETED`

## Example Usage

```java
@Autowired
private DeleteActivityService deleteActivityService;

// Delete an activity
UUID activityId = UUID.fromString("123e4567-e89b-12d3-a456-426614174000");
deleteActivityService.execute(activityId);
```

## Error Handling

The service uses `ServiceOperationExecutor.executeVoid()` to wrap the deletion logic, which provides consistent error handling and operation status tracking. If the activity is not found, a `ResourceNotFoundException` is thrown with a message indicating the missing ID.

## Audit Trail

The `@Auditable` annotation ensures that every deletion operation is logged with:
- **Action:** `ACTIVITY_DELETED`
- **Resource Type:** `ACTIVITY`
- **Resource ID:** The UUID of the deleted activity

This provides a complete audit trail for compliance and monitoring purposes.
