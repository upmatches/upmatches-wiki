# DeleteActivityService

The `DeleteActivityService` class is a Spring service component responsible for deleting an `Activity` entity from the system. It implements the `IDeleteActivityService` interface and provides a transactional, auditable method to remove an activity by its unique identifier (UUID).

## Purpose

- **Delete an Activity**: Removes an existing activity from the database.
- **Validation**: Ensures the activity exists before deletion; throws a `ResourceNotFoundException` if not found.
- **Auditing**: Logs the deletion event with the activity ID for audit trails.
- **Error Handling**: Uses `ServiceOperationExecutor` to handle operation status and exceptions consistently.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `ActivityRepository` | Spring Data JPA repository for `Activity` entity persistence operations. |

## Public Methods

### `execute(UUID id)`

Deletes an activity identified by the given UUID.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to delete. |

**Returns**: `void`

**Throws**:
- `ResourceNotFoundException` – If no activity exists with the given ID.

**Behavior**:
1. Looks up the activity by its ID in the database.
2. If not found, throws a `ResourceNotFoundException` with a descriptive message.
3. If found, deletes the activity from the database.
4. The operation is wrapped in `ServiceOperationExecutor.executeVoid` for consistent error handling and status tracking.
5. The method is annotated with `@Transactional` to ensure atomicity.
6. The `@Auditable` annotation logs the deletion with action `ACTIVITY_DELETED`, resource type `ACTIVITY`, and the activity ID as the resource identifier.

## Usage Example

```java
@Autowired
private DeleteActivityService deleteActivityService;

public void removeActivity(UUID activityId) {
    deleteActivityService.execute(activityId);
}
```

## Error Handling

The service uses a custom exception `ResourceNotFoundException` when the activity does not exist. The error message format is:
```
Activity with ID '<uuid>' not found.
```

## Notes

- The class is declared as `non-sealed`, allowing further extension if needed.
- The `ServiceOperationExecutor` handles the `DELETE` operation status and wraps any `ResourceNotFoundException` appropriately.
- This service is part of the `com.upmatches.app.features.activity.services` package and follows a clean architecture pattern with separation of concerns.
