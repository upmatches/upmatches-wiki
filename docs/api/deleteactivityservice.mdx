# DeleteActivityService

The `DeleteActivityService` class is a Spring service responsible for deleting an `Activity` entity from the database. It implements the `IDeleteActivityService` interface and provides a transactional, auditable method to safely remove an activity by its unique identifier (UUID).

## Purpose

- **Delete an activity** by its UUID.
- **Ensure the activity exists** before deletion; throws `ResourceNotFoundException` if not found.
- **Audit the deletion** via the `@Auditable` annotation.
- **Wrap execution** in a standardized operation executor for consistent error handling and logging.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `ActivityRepository` | Spring Data JPA repository for `Activity` entities. |
| `ServiceOperationExecutor` | Utility to execute service operations with standardized error handling. |
| `ResourceNotFoundException` | Custom exception thrown when an activity is not found. |

## Public Methods

### `execute(UUID id)`

Deletes an activity by its unique identifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `UUID` | The unique identifier of the activity to delete. |

**Returns:** `void`

**Throws:** `ResourceNotFoundException` if no activity with the given ID exists.

**Behavior:**
1. Looks up the activity by `id` using `activityRepository.findById(id)`.
2. If not found, throws `ResourceNotFoundException` with a message like `"Activity with ID '<id>' not found."`.
3. If found, deletes the activity via `activityRepository.delete(activity)`.
4. The entire operation is wrapped in `ServiceOperationExecutor.executeVoid()` for consistent error handling and logging.
5. The method is annotated with `@Transactional` to ensure database consistency.
6. The `@Auditable` annotation logs the deletion with action `"ACTIVITY_DELETED"`, resource type `"ACTIVITY"`, and the activity ID as the resource identifier.

## Example Usage

```java
@Autowired
private DeleteActivityService deleteActivityService;

public void removeActivity(UUID activityId) {
    deleteActivityService.execute(activityId);
}
```

## Error Handling

- **ResourceNotFoundException:** Thrown when the activity ID does not exist in the database.
- **Other exceptions:** Handled by `ServiceOperationExecutor` according to the `DELETE` operation status.

## Notes

- The class is declared as `non-sealed`, allowing it to be extended if needed.
- The error message template is stored as a static constant for maintainability.
- The `@Auditable` annotation uses a SpEL expression `#args[0]` to extract the first method argument (the UUID) as the resource ID for auditing.
