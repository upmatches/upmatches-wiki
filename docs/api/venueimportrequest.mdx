## Purpose of the VenueImportRequest Class

The `VenueImportRequest` class is a Java record used to encapsulate data for importing venue information into the system. It ensures that all necessary venue details are provided and validated according to specified constraints. This class is part of the `com.upmatches.app.features.venue.requests` package and leverages Jakarta Bean Validation annotations to enforce data integrity.

## Public Methods

Since `VenueImportRequest` is a record, it automatically provides a constructor, accessor methods, `equals()`, `hashCode()`, and `toString()` methods. Below is a table documenting the parameters of the primary constructor, which are also the fields of the record.

| Parameter Name | Type                          | Description                                                                 | Constraints                   |
|----------------|-------------------------------|-----------------------------------------------------------------------------|-------------------------------|
| sourceId       | `String`                      | A unique identifier for the source of the venue data.                       | Not blank, max size 50        |
| activityId     | `Integer`                     | The ID representing the activity associated with the venue.                 | Not null                      |
| name           | `String`                      | The name of the venue.                                                      | Not blank, max size 200       |
| address        | `String`                      | The physical address of the venue.                                          | Not blank, max size 500       |
| latitude       | `BigDecimal`                  | The latitude coordinate of the venue's location.                            | Not null                      |
| longitude      | `BigDecimal`                  | The longitude coordinate of the venue's location.                           | Not null                      |
| postalCode     | `Integer`                     | The postal code of the venue's location.                                    | Not null                      |
| stations       | `List<StationImportRequest>`  | A list of station import requests associated with the venue.                | Not null, max size 50, valid  |

The `VenueImportRequest` class ensures that all fields are validated according to the constraints specified by Jakarta Bean Validation annotations. This includes checks for non-null values, maximum string lengths, and nested validation for the list of `StationImportRequest` objects.
