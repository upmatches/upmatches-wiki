# VenueImportRequest

The `VenueImportRequest` class is a Java record that serves as a Data Transfer Object (DTO) for importing venue data into the system. It encapsulates all necessary information about a venue, including its external identifier, location details, and associated stations. The class uses Jakarta Bean Validation annotations to enforce data integrity and ensure that incoming data meets the required constraints before processing.

## Purpose

- **Data Transfer**: Provides a structured format for receiving venue import requests from external systems or APIs.
- **Validation**: Enforces mandatory fields and size constraints to prevent invalid or incomplete data from entering the system.
- **Immutability**: As a Java record, it automatically generates constructor, getters, `equals()`, `hashCode()`, and `toString()` methods, ensuring thread-safety and consistency.

## Record Components

| Component | Type | Validation | Description |
|-----------|------|------------|-------------|
| `sourceId` | `String` | `@NotBlank`, `@Size(max = 50)` | External identifier for the venue from the source system |
| `activityId` | `Integer` | `@NotNull` | Identifier for the activity associated with the venue |
| `name` | `String` | `@NotBlank`, `@Size(max = 200)` | Name of the venue |
| `address` | `String` | `@NotBlank`, `@Size(max = 500)` | Physical address of the venue |
| `latitude` | `BigDecimal` | `@NotNull` | Latitude coordinate of the venue location |
| `longitude` | `BigDecimal` | `@NotNull` | Longitude coordinate of the venue location |
| `postalCode` | `Integer` | `@NotNull` | Postal code of the venue's location |
| `stations` | `List<StationImportRequest>` | `@NotNull`, `@Size(max = 50)`, `@Valid` | List of station import requests associated with the venue |

## Validation Rules

- **`sourceId`**: Must not be blank and must not exceed 50 characters.
- **`activityId`**: Must not be null.
- **`name`**: Must not be blank and must not exceed 200 characters.
- **`address`**: Must not be blank and must not exceed 500 characters.
- **`latitude`**: Must not be null.
- **`longitude`**: Must not be null.
- **`postalCode`**: Must not be null.
- **`stations`**: Must not be null, must contain at most 50 elements, and each element must pass its own validation (indicated by `@Valid`).

## Usage Example

```java
// Create a new VenueImportRequest
VenueImportRequest request = new VenueImportRequest(
    "EXT-12345",
    1,
    "Central Park Sports Complex",
    "123 Main Street, New York, NY 10001",
    new BigDecimal("40.7128"),
    new BigDecimal("-74.0060"),
    10001,
    List.of(new StationImportRequest(...))
);
```

## Related Classes

- **`StationImportRequest`**: Represents individual station data within a venue import request. The `@Valid` annotation ensures that each station in the list is validated according to its own constraints.
