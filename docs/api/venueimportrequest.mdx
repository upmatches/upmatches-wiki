## VenueImportRequest Class

The `VenueImportRequest` class is a Java record used to encapsulate the data required for importing venue information into the system. It ensures that all necessary fields are validated and provided in a structured manner. This class is part of the `com.upmatches.app.features.venue.requests` package and utilizes Jakarta Bean Validation annotations to enforce constraints on the data fields.

### Class Fields

The `VenueImportRequest` record consists of the following fields:

- **sourceId**: A unique identifier for the source of the venue data. It must be a non-blank string with a maximum length of 50 characters.
- **activityId**: An integer representing the activity associated with the venue. It cannot be null.
- **name**: The name of the venue. This is a non-blank string with a maximum length of 200 characters.
- **address**: The address of the venue. It must be a non-blank string with a maximum length of 500 characters.
- **latitude**: The geographical latitude of the venue. It is a non-null `BigDecimal`.
- **longitude**: The geographical longitude of the venue. It is a non-null `BigDecimal`.
- **postalCode**: An integer representing the postal code of the venue. It cannot be null.
- **stations**: A list of `StationImportRequest` objects. This list must be non-null, valid, and each entry must not exceed 50 characters.

The `VenueImportRequest` record does not explicitly define methods beyond those automatically provided by the Java record feature. However, it implicitly provides the following methods:
