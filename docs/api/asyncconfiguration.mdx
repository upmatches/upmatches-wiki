# Async Configuration

The `AsyncConfiguration` class provides a centralized configuration for asynchronous task execution and scheduling within the application. By leveraging Spring's `@EnableAsync` and `@EnableScheduling` annotations, it enables the application to execute methods asynchronously and schedule tasks efficiently.

## Purpose

This configuration class sets up a custom `ThreadPoolTaskExecutor` bean that manages a pool of threads for executing asynchronous tasks. It defines the core pool size, maximum pool size, queue capacity, and thread naming prefix to optimize resource utilization and ensure predictable behavior under varying workloads.

## Configuration Details

The class uses the following constants to configure the thread pool:

| Constant | Value | Description |
|----------|-------|-------------|
| `CORE_POOL_SIZE` | 4 | The number of threads to keep in the pool, even if they are idle |
| `MAX_POOL_SIZE` | 8 | The maximum number of threads allowed in the pool |
| `QUEUE_CAPACITY` | 100 | The capacity of the queue holding tasks before they are executed |
| `THREAD_NAME_PREFIX` | `async-` | The prefix for thread names created by this executor |

## Public Methods

### `taskExecutor()`

Creates and configures a `ThreadPoolTaskExecutor` bean that serves as the primary executor for asynchronous operations.

| Property | Details |
|----------|---------|
| **Bean Name** | `taskExecutor` |
| **Return Type** | `java.util.concurrent.Executor` |
| **Description** | Initializes a thread pool executor with the configured core pool size, maximum pool size, queue capacity, and thread name prefix |

#### Configuration Behavior

- **Core Pool Size (4)**: The executor maintains at least 4 threads ready to handle tasks immediately
- **Max Pool Size (8)**: When the core pool is fully utilized and the queue is full, the executor can create up to 8 threads
- **Queue Capacity (100)**: Tasks that cannot be immediately executed are queued; once the queue reaches 100 tasks, new threads are created up to the maximum pool size
- **Thread Name Prefix**: All threads created by this executor will have names starting with `async-` for easy identification in logs and monitoring tools

## Usage Example

To use this asynchronous configuration in your application, simply inject the `taskExecutor` bean where needed:

```java
@Service
public class NotificationService {
    
    @Autowired
    private Executor taskExecutor;
    
    public void sendNotifications(List<User> users) {
        for (User user : users) {
            taskExecutor.execute(() -> sendEmail(user));
        }
    }
    
    private void sendEmail(User user) {
        // Email sending logic
    }
}
```

Alternatively, you can use the `@Async` annotation on methods to automatically use this executor:

```java
@Service
public class EmailService {
    
    @Async
    public void sendWelcomeEmail(User user) {
        // Asynchronous email sending
    }
}
```

## Dependencies

This configuration requires the following Spring Framework modules:

- `spring-context` - Provides the `@Configuration`, `@EnableAsync`, and `@EnableScheduling` annotations
- `spring-scheduling` - Provides the `ThreadPoolTaskExecutor` class and scheduling support
