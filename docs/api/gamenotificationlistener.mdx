## Purpose

The `GameNotificationListener` class is a component in a Java application that listens for game-related notification events. It processes these events to generate and deliver notifications to users, either through push notifications or email, based on the type of event and the recipients involved. The class ensures that notifications are not duplicated and handles delivery failures gracefully.

## Public Methods

### onGameNotification

Listens for `GameNotificationEvent` and processes it to send notifications to the appropriate recipients.

| Parameter | Type                  | Description                                      |
|-----------|-----------------------|--------------------------------------------------|
| event     | `GameNotificationEvent` | The event containing details about the game notification. |

| Return Type |
|-------------|
| `void`      |

## Method Details

### onGameNotification

- **Purpose**: This method is triggered asynchronously after a transaction commit. It retrieves the game associated with the event, determines the recipients, constructs the notification title and message, and attempts to deliver the notification both in-app and externally.
- **Parameters**:
  - `event`: An instance of `GameNotificationEvent` that contains information about the game and the type of notification to be sent.
- **Return Type**: `void`

The method handles the following:
- Retrieves the game using the game ID from the event.
- Logs a warning if the game is not found.
- Resolves the recipients based on the event type and game details.
- Constructs the notification title and message.
- Checks for duplicate notifications to avoid sending the same notification multiple times.
- Attempts to deliver the notification using the `ICreateNotificationService`, `IPushNotificationService`, and `IEmailNotificationService`.
- Logs any delivery failures.

### Private Helper Methods

- **deliverExternally**: Attempts to send the notification via push service first, and falls back to email if push delivery fails and the recipient has a valid email address.
- **isDedupable**: Determines if a notification type should be checked for duplicates.
- **resolveRecipients**: Identifies the recipients of the notification based on the event type and game details.
- **buildTitle**: Constructs the notification title based on the event type.
- **buildMessage**: Constructs the notification message based on the event type and game title.
