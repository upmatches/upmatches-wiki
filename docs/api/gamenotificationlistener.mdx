# GameNotificationListener

The `GameNotificationListener` is a Spring component that listens for game-related events and creates and delivers notifications to the appropriate recipients. It handles various game events such as players joining/leaving, game updates, cancellations, and skill-level warnings.

## Purpose

This listener processes `GameNotificationEvent` objects after the database transaction has committed successfully. For each event, it:
1. Resolves the appropriate recipients based on the event type
2. Creates a notification with a title and message tailored to the event
3. Delivers the notification via push notification or email
4. Prevents duplicate notifications for certain event types

## Dependencies

| Dependency | Description |
|------------|-------------|
| `GameRepository` | Repository for accessing game data |
| `GameParticipantRepository` | Repository for accessing game participant data |
| `NotificationRepository` | Repository for checking existing notifications |
| `ICreateNotificationService` | Service for creating notification records |
| `IPushNotificationService` | Service for sending push notifications |
| `IEmailNotificationService` | Service for sending email notifications |
| `ShareLinkProperties` | Configuration properties for generating game URLs |

## Public Methods

### `onGameNotification(GameNotificationEvent event)`

The main event handler method, annotated with `@Async` and `@TransactionalEventListener`.

| Parameter | Type | Description |
|-----------|------|-------------|
| `event` | `GameNotificationEvent` | The game notification event to process |

**Behavior:**
- Retrieves the game from the repository using the event's game ID
- If the game is not found, logs a warning and returns
- Resolves the set of recipient IDs based on the event type and game data
- For each recipient, checks for duplicate notifications (for dedupable event types)
- Creates a notification record and attempts external delivery

## Private Methods

### `deliverExternally(Notification notification, EmailContext emailContext)`

Attempts to deliver a notification via push notification first, falling back to email.

| Parameter | Type | Description |
|-----------|------|-------------|
| `notification` | `Notification` | The notification to deliver |
| `emailContext` | `EmailContext` | Context data for email delivery |

**Behavior:**
- Sends a push notification via `pushNotificationService`
- If push delivery succeeds (`PushDeliveryResult.SENT`), returns immediately
- If push fails, checks if the recipient has an email address
- If email is available, sends via `emailNotificationService`
- If no email is available, logs that delivery is in-app only

### `isDedupable(NotificationType type)`

Determines if a notification type should be checked for duplicates.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification |

**Returns:** `boolean` - `true` for `PLAYER_JOINED`, `GAME_FULL`, and `PLAYER_WARNING_MISMATCH`; `false` for all other types

### `resolveRecipients(GameNotificationEvent event, Game game)`

Determines the set of recipients for a given event.

| Parameter | Type | Description |
|-----------|------|-------------|
| `event` | `GameNotificationEvent` | The event containing type and actor information |
| `game` | `Game` | The game entity |

**Returns:** `Set<UUID>` - Set of recipient user IDs

**Recipient Resolution Logic:**

| Event Type | Recipients |
|------------|------------|
| `PLAYER_JOINED`, `PLAYER_LEFT`, `GAME_FULL`, `PLAYER_WARNING_MISMATCH` | Game organizer (if not the actor) |
| `GAME_UPDATED`, `GAME_REMOVED` | All active participants except the actor |
| `PLAYER_REMOVED_FROM_GAME` | The actor (the removed player) |
| Default | Empty set |

### `buildTitle(NotificationType type)`

Generates a human-readable title for the notification.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification |

**Returns:** `String` - The notification title

| Event Type | Title |
|------------|-------|
| `PLAYER_JOINED` | "A player joined your game" |
| `PLAYER_LEFT` | "A player left your game" |
| `PLAYER_WARNING_MISMATCH` | "Skill-level warning" |
| `GAME_FULL` | "Your game is full" |
| `GAME_UPDATED` | "Game updated" |
| `GAME_REMOVED` | "Game cancelled" |
| `PLAYER_REMOVED_FROM_GAME` | "You were removed from a game" |
| Default | "Notification" |

### `buildMessage(NotificationType type, String gameTitle)`

Generates a detailed message for the notification.

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | `NotificationType` | The type of notification |
| `gameTitle` | `String` | The title of the game (may be null or blank) |

**Returns:** `String` - The notification message

| Event Type | Message |
|------------|---------|
| `PLAYER_JOINED` | "A new player joined [game title]." |
| `PLAYER_LEFT` | "A player left [game title]." |
| `PLAYER_WARNING_MISMATCH` | "A player joined your game." |
| `GAME_FULL` | "Your badminton game has max out." |
| `GAME_UPDATED` | "[Game title] has been updated." |
| `GAME_REMOVED` | "Your badminton game has been cancelled." |
| `PLAYER_REMOVED_FROM_GAME` | "You have been removed from a badminton game." |
| Default | "Update from Upmatches." |

If `gameTitle` is null or blank, the default reference "your game" is used in the message.
