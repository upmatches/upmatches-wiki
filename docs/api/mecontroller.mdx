# MeController

The `MeController` class provides REST API endpoints for managing the authenticated user's profile. It handles profile retrieval, completion, update, and deletion operations through a centralized `/api/v1/me` base path.

## Purpose

This controller serves as the primary interface for authenticated users to manage their personal profile data. It delegates all business logic to the `IUserService` implementation, ensuring separation of concerns and maintainability.

## Endpoints

### GET /api/v1/me

Retrieves the profile of the currently authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The HTTP request object (injected automatically) |

**Response:** `200 OK` with `ApiResponse<UserProfileResponse>` containing the user's profile data.

### POST /api/v1/me

Completes the user's profile with initial data.

| Parameter | Type | Description |
|-----------|------|-------------|
| `body` | `CompleteProfileRequest` | The profile completion data (validated) |
| `request` | `HttpServletRequest` | The HTTP request object (injected automatically) |

**Response:** `201 Created` with `ApiResponse<UserProfileResponse>` containing the completed profile.

### PUT /api/v1/me

Updates the authenticated user's profile.

| Parameter | Type | Description |
|-----------|------|-------------|
| `body` | `UpdateProfileRequest` | The profile update data (validated) |
| `request` | `HttpServletRequest` | The HTTP request object (injected automatically) |

**Response:** `200 OK` with `ApiResponse<UserProfileResponse>` containing the updated profile.

### DELETE /api/v1/me

Deletes the authenticated user's account.

| Parameter | Type | Description |
|-----------|------|-------------|
| None | - | - |

**Response:** `204 No Content` with no response body.

## Dependencies

- **IUserService**: Service interface for user profile operations
- **CompleteProfileRequest**: Request DTO for profile completion
- **UpdateProfileRequest**: Request DTO for profile updates
- **UserProfileResponse**: Response DTO for user profile data
- **ApiResponse**: Generic API response wrapper

## Error Handling

All endpoints return appropriate HTTP status codes:
- `200 OK` for successful GET and PUT operations
- `201 Created` for successful POST operations
- `204 No Content` for successful DELETE operations
- Validation errors return `400 Bad Request` with error details

## Security

This controller is designed to work with Spring Security. All endpoints require authentication, and the `IUserService` implementation should handle authorization checks for the currently authenticated user.
