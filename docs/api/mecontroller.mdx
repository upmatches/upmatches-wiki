## Purpose

The `MeController` class is a REST controller in a Spring Boot application that manages user profile operations. It provides endpoints for retrieving, completing, updating, and deleting a user's profile. This controller interacts with the `IUserService` to perform these operations and returns appropriate HTTP responses.

## Public Methods

### `getMe`

Retrieves the current user's profile.

| Parameter | Type                  | Description                  |
|-----------|-----------------------|------------------------------|
| request   | `HttpServletRequest`  | The HTTP request object.     |

| Return Type                                      | Description                                    |
|--------------------------------------------------|------------------------------------------------|
| `ResponseEntity<ApiResponse<UserProfileResponse>>` | A response entity containing the user's profile and a success message. |

### `completeProfile`

Completes the user's profile with the provided data.

| Parameter | Type                          | Description                                      |
|-----------|-------------------------------|--------------------------------------------------|
| body      | `CompleteProfileRequest`      | The request body containing profile data.        |
| request   | `HttpServletRequest`          | The HTTP request object.                         |

| Return Type                                      | Description                                    |
|--------------------------------------------------|------------------------------------------------|
| `ResponseEntity<ApiResponse<UserProfileResponse>>` | A response entity with the completed profile and a success message. |

### `updateProfile`

Updates the user's profile with the provided data.

| Parameter | Type                          | Description                                      |
|-----------|-------------------------------|--------------------------------------------------|
| body      | `UpdateProfileRequest`        | The request body containing updated profile data.|
| request   | `HttpServletRequest`          | The HTTP request object.                         |

| Return Type                                      | Description                                    |
|--------------------------------------------------|------------------------------------------------|
| `ResponseEntity<ApiResponse<UserProfileResponse>>` | A response entity with the updated profile and a success message. |

### `deleteMe`

Deletes the current user's profile.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type             | Description                                    |
|-------------------------|------------------------------------------------|
| `ResponseEntity<Void>`  | A response entity indicating successful deletion with no content. |
