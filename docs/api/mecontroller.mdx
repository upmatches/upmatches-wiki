# MeController

The `MeController` class is a REST controller that handles all operations related to the currently authenticated user's profile. It provides endpoints for retrieving, creating, updating, and deleting the user's profile information.

## Base URL

All endpoints in this controller are mapped under `/api/v1/me`.

## Endpoints

### GET /api/v1/me

Retrieves the profile of the currently authenticated user.

**Response:**

| Status Code | Description |
|-------------|-------------|
| 200 OK | Profile retrieved successfully |

**Response Body:**

```json
{
  "success": true,
  "message": "User profile retrieved successfully.",
  "data": {
    // UserProfileResponse object
  },
  "path": "/api/v1/me"
}
```

### POST /api/v1/me

Completes the user's profile with the provided information. This endpoint is typically used during initial profile setup.

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| (varies) | CompleteProfileRequest | Yes | Profile completion data |

**Response:**

| Status Code | Description |
|-------------|-------------|
| 201 Created | Profile completed successfully |

**Response Body:**

```json
{
  "success": true,
  "message": "User profile completed successfully.",
  "data": {
    // UserProfileResponse object
  },
  "path": "/api/v1/me"
}
```

### PUT /api/v1/me

Updates the profile of the currently authenticated user.

**Request Body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| (varies) | UpdateProfileRequest | Yes | Profile update data |

**Response:**

| Status Code | Description |
|-------------|-------------|
| 200 OK | Profile updated successfully |

**Response Body:**

```json
{
  "success": true,
  "message": "User profile updated successfully.",
  "data": {
    // UserProfileResponse object
  },
  "path": "/api/v1/me"
}
```

### DELETE /api/v1/me

Deletes the currently authenticated user's account.

**Response:**

| Status Code | Description |
|-------------|-------------|
| 204 No Content | User deleted successfully |

## Method Details

### `getMe(HttpServletRequest request)`

Retrieves the profile of the currently authenticated user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| request | HttpServletRequest | The HTTP request object used for generating the response path |

**Returns:** `ResponseEntity<ApiResponse<UserProfileResponse>>` - The user's profile wrapped in an API response.

### `completeProfile(CompleteProfileRequest body, HttpServletRequest request)`

Completes the user's profile with the provided data.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| body | CompleteProfileRequest | The profile completion request data (validated) |
| request | HttpServletRequest | The HTTP request object used for generating the response path |

**Returns:** `ResponseEntity<ApiResponse<UserProfileResponse>>` - The completed profile wrapped in an API response with HTTP 201 status.

### `updateProfile(UpdateProfileRequest body, HttpServletRequest request)`

Updates the profile of the currently authenticated user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| body | UpdateProfileRequest | The profile update request data (validated) |
| request | HttpServletRequest | The HTTP request object used for generating the response path |

**Returns:** `ResponseEntity<ApiResponse<UserProfileResponse>>` - The updated profile wrapped in an API response.

### `deleteMe()`

Deletes the currently authenticated user's account.

**Returns:** `ResponseEntity<Void>` - HTTP 204 No Content response.

## Dependencies

- **IUserService**: Service interface that provides the business logic for user profile operations.
- **CompleteProfileRequest**: Request DTO for profile completion.
- **UpdateProfileRequest**: Request DTO for profile updates.
- **UserProfileResponse**: Response DTO containing user profile data.
- **ApiResponse**: Generic API response wrapper used for consistent response formatting.

## Notes

- All endpoints require authentication (the controller assumes the user is already authenticated).
- The `POST` endpoint returns HTTP 201 (Created) while other successful operations return HTTP 200 (OK).
- The `DELETE` endpoint returns HTTP 204 (No Content) with no response body.
- Request validation is performed using `@Valid` annotation on request bodies.
