# SingpassAuthService

The `SingpassAuthService` class is a Spring service that implements the `ISingpassAuthService` interface. It handles the OAuth 2.0 authorization code flow with PKCE (Proof Key for Code Exchange) and DPoP (Demonstration of Proof-of-Possession) for Singpass authentication. This service manages the complete authentication lifecycle including pushed authorization requests (PAR), authorization code exchange, and ID token decryption/verification.

## Key Features

- **Pushed Authorization Requests (PAR)**: Sends authorization parameters to the Singpass PAR endpoint
- **PKCE Flow**: Implements code challenge and code verifier generation
- **DPoP Proof**: Creates and attaches DPoP proof tokens for enhanced security
- **Client Assertion**: Generates signed JWT client assertions for authentication
- **ID Token Handling**: Decrypts and verifies Singpass ID tokens using JWKS
- **JWKS Caching**: Caches Singpass public keys for efficient verification

## Public Methods

### `generateCodeVerifier()`

Generates a cryptographically random code verifier for PKCE flow.

| Returns | Description |
|---------|-------------|
| `String` | Base64URL-encoded random bytes (32 bytes) |

### `sendPushedAuthorizationRequest(String state, String nonce, String codeVerifier)`

Sends a pushed authorization request to the Singpass PAR endpoint.

| Parameter | Type | Description |
|-----------|------|-------------|
| `state` | `String` | OAuth state parameter for CSRF protection |
| `nonce` | `String` | Nonce value for replay protection |
| `codeVerifier` | `String` | PKCE code verifier |

| Returns | Description |
|---------|-------------|
| `String` | Authorization URL with request_uri parameter |

| Exceptions | Description |
|------------|-------------|
| `IllegalStateException` | If PAR response is missing request_uri or parsing fails |

### `exchangeAuthorizationCode(String authorizationCode, String codeVerifier, String nonce)`

Exchanges an authorization code for an ID token.

| Parameter | Type | Description |
|-----------|------|-------------|
| `authorizationCode` | `String` | Authorization code from Singpass redirect |
| `codeVerifier` | `String` | PKCE code verifier used in PAR request |
| `nonce` | `String` | Nonce value used in PAR request |

| Returns | Description |
|---------|-------------|
| `String` | Subject identifier (`sub` claim) from verified ID token |

| Exceptions | Description |
|------------|-------------|
| `IllegalStateException` | If token response is missing id_token, or ID token validation fails |

## Private Methods

### `generateCodeChallenge(String codeVerifier)`

Generates a SHA-256 code challenge from the code verifier.

| Parameter | Type | Description |
|-----------|------|-------------|
| `codeVerifier` | `String` | PKCE code verifier |

| Returns | Description |
|---------|-------------|
| `String` | Base64URL-encoded SHA-256 hash of code verifier |

### `parseParResponse(String responseBody)`

Parses the PAR response to extract the request_uri and construct the authorization URL.

| Parameter | Type | Description |
|-----------|------|-------------|
| `responseBody` | `String` | JSON response from PAR endpoint |

| Returns | Description |
|---------|-------------|
| `String` | Complete authorization URL |

### `parseTokenResponse(String responseBody, String nonce)`

Parses the token response and initiates ID token decryption/verification.

| Parameter | Type | Description |
|-----------|------|-------------|
| `responseBody` | `String` | JSON response from token endpoint |
| `nonce` | `String` | Nonce for ID token validation |

| Returns | Description |
|---------|-------------|
| `String` | Subject identifier from verified ID token |

### `decryptAndVerifyIdToken(String idToken, String nonce)`

Decrypts the JWE-encrypted ID token and verifies the JWS signature.

| Parameter | Type | Description |
|-----------|------|-------------|
| `idToken` | `String` | JWE-encrypted ID token |
| `nonce` | `String` | Nonce for ID token validation |

| Returns | Description |
|---------|-------------|
| `String` | Subject identifier (`sub` claim) |

### `validateIdTokenClaims(JWTClaimsSet claims, String nonce)`

Validates the ID token claims including issuer, audience, nonce, and subject.

| Parameter | Type | Description |
|-----------|------|-------------|
| `claims` | `JWTClaimsSet` | Parsed JWT claims from ID token |
| `nonce` | `String` | Expected nonce value |

| Exceptions | Description |
|------------|-------------|
| `IllegalStateException` | If any claim validation fails |

### `getSingpassJwks()`

Fetches and caches Singpass JWKS (JSON Web Key Set) for signature verification.

| Returns | Description |
|---------|-------------|
| `JWKSet` | Singpass public keys |

### `createClientAssertionJwt()`

Creates a signed JWT client assertion for OAuth client authentication.

| Returns | Description |
|---------|-------------|
| `String` | Serialized signed JWT |

### `createDpopProof(String httpMethod, String httpUri)`

Creates a DPoP proof JWT for demonstrating possession of a private key.

| Parameter | Type | Description |
|-----------|------|-------------|
| `httpMethod` | `String` | HTTP method (e.g., "POST") |
| `httpUri` | `String` | Target URI for the request |

| Returns | Description |
|---------|-------------|
| `String` | Serialized DPoP proof JWT |

## Configuration Properties

The service uses `SingpassProperties` for configuration:

| Property | Description |
|----------|-------------|
| `clientId` | Singpass client identifier |
| `redirectUri` | OAuth redirect URI |
| `scopes` | Requested OAuth scopes |
| `issuer` | Expected ID token issuer |
| `parEndpoint` | Pushed Authorization Request endpoint |
| `tokenEndpoint` | Token exchange endpoint |
| `authorizationEndpoint` | Authorization endpoint |
| `jwksEndpoint` | JWKS endpoint for public keys |
| `authContextType` | Optional authentication context type |
| `authContextMessage` | Optional authentication context message |

## Dependencies

- **Nimbus JOSE + JWT**: For JWT creation, signing, encryption, and verification
- **Spring RestClient**: For HTTP requests to Singpass endpoints
- **Jackson**: For JSON parsing
- **SLF4J**: For logging

## Usage Example

```java
@Autowired
private SingpassAuthService authService;

// Generate PKCE parameters
String codeVerifier = SingpassAuthService.generateCodeVerifier();
String state = UUID.randomUUID().toString();
String nonce = UUID.randomUUID().toString();

// Send PAR request
String authUrl = authService.sendPushedAuthorizationRequest(state, nonce, codeVerifier);

// Redirect user to authUrl...
// After redirect, exchange authorization code
String sub = authService.exchangeAuthorizationCode(authorizationCode, codeVerifier, nonce);
```
