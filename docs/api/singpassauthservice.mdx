## Overview

The `SingpassAuthService` class is a service component in a Spring application that handles authentication with Singpass, a digital identity platform. It implements the `ISingpassAuthService` interface and provides methods to generate code verifiers and challenges, send pushed authorization requests, and exchange authorization codes for ID tokens. The class also includes functionality to decrypt and verify ID tokens using JSON Web Tokens (JWT) and JSON Web Encryption (JWE).

## Public Methods

### `generateCodeVerifier`

Generates a secure random code verifier for PKCE (Proof Key for Code Exchange).

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type | Description                    |
|-------------|--------------------------------|
| `String`    | A base64-url-encoded code verifier. |

### `sendPushedAuthorizationRequest`

Sends a Pushed Authorization Request (PAR) to the Singpass authorization server.

| Parameter      | Type   | Description                          |
|----------------|--------|--------------------------------------|
| `state`        | `String` | The state parameter for the request. |
| `nonce`        | `String` | The nonce parameter for the request. |
| `codeVerifier` | `String` | The code verifier for PKCE.          |

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| `String`    | The authorization URL with the request URI.      |

### `exchangeAuthorizationCode`

Exchanges an authorization code for an ID token.

| Parameter          | Type   | Description                                |
|--------------------|--------|--------------------------------------------|
| `authorizationCode`| `String` | The authorization code received from Singpass. |
| `codeVerifier`     | `String` | The code verifier used in the initial request. |
| `nonce`            | `String` | The nonce used in the initial request.    |

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| `String`    | The subject (sub) claim from the verified ID token. |

## Usage

The `SingpassAuthService` class is designed to be used as a Spring service. It requires configuration properties and dependencies such as `RestClient`, `SingpassProperties`, `SingpassKeyProvider`, and `ObjectMapper` to function correctly. The service handles the complexities of interacting with Singpass's OAuth 2.0 and OpenID Connect endpoints, including generating necessary JWTs and handling cryptographic operations.
