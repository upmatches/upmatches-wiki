## Overview

The `DevFcmTestNotificationController` class is a Spring Boot REST controller designed for development environments. It handles HTTP requests to send Firebase Cloud Messaging (FCM) test notifications. This controller is part of the internal API, specifically for testing purposes in a development profile.

## Public Methods

### sendTestNotification

Handles POST requests to send a test FCM notification. It validates the incoming request body and uses the `ISendFcmTestNotificationService` to process the notification sending.

| Parameter | Type | Description |
|-----------|------|-------------|
| `body`    | `@Valid @RequestBody SendFcmTestNotificationRequest` | The request body containing the details of the FCM notification to be sent. |
| `request` | `HttpServletRequest` | The HTTP request object, used to retrieve the request URI. |

#### Returns

`ResponseEntity<ApiResponse<FcmTestNotificationResponse>>`: A response entity containing the API response with the FCM test notification result, a success message, and the request URI.
