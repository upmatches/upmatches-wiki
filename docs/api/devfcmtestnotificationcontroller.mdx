# DevFcmTestNotificationController

## Purpose

The `DevFcmTestNotificationController` is a development-only REST controller designed for testing Firebase Cloud Messaging (FCM) push notifications. It provides an endpoint that allows developers to send test FCM notifications during development and debugging phases.

This controller is only active when the Spring profile `dev` is enabled, ensuring it is not exposed in production environments.

## Endpoint

| Method | Path | Description |
|--------|------|-------------|
| POST | `/internal/dev/fcm-test-notifications` | Sends a test FCM notification |

## Request

### `POST /internal/dev/fcm-test-notifications`

Sends a test FCM notification using the provided request body.

#### Request Body

The request body must be a valid `SendFcmTestNotificationRequest` object. Validation is applied via the `@Valid` annotation.

| Field | Type | Description |
|-------|------|-------------|
| (See `SendFcmTestNotificationRequest` class) | - | Contains the necessary parameters for sending a test FCM notification |

#### Response

**Success Response (200 OK)**

```json
{
  "data": {
    // FcmTestNotificationResponse fields
  },
  "message": "Dev FCM test notification sent successfully.",
  "path": "/internal/dev/fcm-test-notifications"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `data` | `FcmTestNotificationResponse` | The response object containing details about the sent notification |
| `message` | String | Success message: "Dev FCM test notification sent successfully." |
| `path` | String | The request URI path |

## Public Methods

### `sendTestNotification`

```java
public ResponseEntity<ApiResponse<FcmTestNotificationResponse>> sendTestNotification(
    @Valid @RequestBody SendFcmTestNotificationRequest body,
    HttpServletRequest request)
```

Sends a test FCM notification.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `body` | `SendFcmTestNotificationRequest` | The request body containing notification details (validated) |
| `request` | `HttpServletRequest` | The HTTP request object used to extract the request URI |

**Returns:**

| Type | Description |
|------|-------------|
| `ResponseEntity<ApiResponse<FcmTestNotificationResponse>>` | HTTP 200 response with success message and notification response data |

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ISendFcmTestNotificationService` | Service | Interface for executing the FCM test notification logic |

## Profile Restriction

This controller is annotated with `@Profile("dev")`, meaning it will only be instantiated and available when the Spring profile `dev` is active. This prevents accidental exposure of test endpoints in production environments.

## Usage Example

```bash
curl -X POST http://localhost:8080/internal/dev/fcm-test-notifications \
  -H "Content-Type: application/json" \
  -d '{
    // SendFcmTestNotificationRequest fields
  }'
```
