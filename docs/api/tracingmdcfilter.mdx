## Overview

The `TracingMdcFilter` class is a Spring component that integrates with the Micrometer Tracing library to add tracing information to the SLF4J Mapped Diagnostic Context (MDC). This filter ensures that each HTTP request is associated with a trace and span ID, which can be used for logging and debugging purposes. It extends the `OncePerRequestFilter` to guarantee that the filter is executed once per request.

## Public Methods

The `TracingMdcFilter` class contains the following public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `TracingMdcFilter` | `Tracer tracer` |  | Constructor that initializes the filter with a `Tracer` instance. |
| `doFilterInternal` | `HttpServletRequest request`, `HttpServletResponse response`, `FilterChain filterChain` | `void` | Overrides the `doFilterInternal` method to add trace and span IDs to the MDC for the duration of the request. |

### Method Details

#### TracingMdcFilter Constructor

- **Parameters:**
  - `Tracer tracer`: An instance of the `Tracer` used to obtain the current span and its context.

- **Description:** 
  - Initializes the `TracingMdcFilter` with the provided `Tracer` instance. This is essential for retrieving the current span's trace and span IDs.

#### doFilterInternal Method

- **Parameters:**
  - `HttpServletRequest request`: The HTTP request object.
  - `HttpServletResponse response`: The HTTP response object.
  - `FilterChain filterChain`: The filter chain to pass the request and response to the next filter.

- **Return Type:** `void`

- **Description:** 
  - This method is called once per request. It retrieves the current span from the `Tracer` and adds its trace and span IDs to the MDC. This allows the trace information to be included in logs, facilitating easier tracking and debugging of requests. After the request is processed, the trace and span IDs are removed from the MDC to prevent leakage into subsequent requests.
