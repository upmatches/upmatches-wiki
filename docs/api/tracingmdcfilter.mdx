## Overview

The `TracingMdcFilter` class is a Spring component designed to integrate with the Micrometer Tracing library. It extends the `OncePerRequestFilter` to ensure that the filter is executed once per request within a web application. The primary purpose of this filter is to add tracing information, specifically the trace ID and span ID, to the Mapped Diagnostic Context (MDC) for logging purposes. This allows for enhanced traceability and correlation of log messages with specific requests and spans.

## Public Methods

The `TracingMdcFilter` class provides the following public methods:

### Constructor

| Method Signature | Description |
|------------------|-------------|
| `TracingMdcFilter(Tracer tracer)` | Constructs a new `TracingMdcFilter` with the specified `Tracer` instance. The `Tracer` is used to obtain the current span and its context. |

### doFilterInternal

| Method Signature | Description |
|------------------|-------------|
| `protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) throws ServletException, IOException` | This method is overridden from `OncePerRequestFilter` and is executed for each HTTP request. It retrieves the current span from the `Tracer`, extracts the trace ID and span ID, and adds them to the MDC. After the request is processed, it ensures that the MDC entries are removed to prevent leakage of trace information across requests. |

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The HTTP request object. |
| `response` | `HttpServletResponse` | The HTTP response object. |
| `filterChain` | `FilterChain` | The filter chain to pass the request and response to the next filter. |

#### Return Type

This method does not return a value. It throws `ServletException` and `IOException` if an error occurs during request processing.

## Usage

The `TracingMdcFilter` is automatically registered as a Spring component and is conditionally enabled when a `Tracer` bean is present in the application context. It is ordered with a high precedence to ensure that tracing information is available early in the request processing lifecycle.
