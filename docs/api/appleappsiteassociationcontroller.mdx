# Apple App Site Association Controller

## Purpose

The `AppleAppSiteAssociationController` is a Spring Boot REST controller that serves the Apple App Site Association file required for Universal Links and Shared Web Credentials on iOS devices. This endpoint allows iOS applications to verify the association between your website and your iOS app, enabling features like seamless deep linking and password autofill.

The controller exposes a single endpoint at `/.well-known/apple-app-site-association` that returns a static JSON file (`apple-app-site-association.json`) located in the classpath resources. The response is cached for 24 hours to improve performance and reduce server load.

## Endpoint

### GET `/.well-known/apple-app-site-association`

Returns the Apple App Site Association JSON file that defines which URLs your iOS app can handle and which credentials it can share with your website.

#### Response

| Attribute | Type | Description |
|-----------|------|-------------|
| Status Code | `200 OK` | Successful response |
| Content-Type | `application/json` | JSON media type |
| Cache-Control | `public, max-age=86400` | Public cache for 24 hours (86400 seconds) |
| Body | `Resource` | The `apple-app-site-association.json` file content |

#### Example Response

```json
{
  "applinks": {
    "apps": [],
    "details": [
      {
        "appID": "TEAMID.com.example.app",
        "paths": ["*"]
      }
    ]
  },
  "webcredentials": {
    "apps": ["TEAMID.com.example.app"]
  }
}
```

## Configuration

The controller uses the following constants:

| Constant | Value | Description |
|----------|-------|-------------|
| `RESOURCE_PATH` | `apple-app-site-association.json` | Path to the JSON file in the classpath |
| `CACHE_HOURS` | `24L` | Cache duration in hours |

## Dependencies

- **Spring Boot Web**: Provides `@RestController`, `@GetMapping`, and `ResponseEntity`
- **Spring Core**: Provides `ClassPathResource` and `Resource` for file loading
- **Spring HTTP**: Provides `CacheControl` and `MediaType` for response configuration

## Usage

1. Place your `apple-app-site-association.json` file in the `src/main/resources` directory of your Spring Boot application.
2. The controller automatically serves the file at the required Apple endpoint.
3. iOS devices will automatically fetch this file when users install your app or visit your website.

## Notes

- The file must be served without any file extension (the endpoint path does not include `.json`).
- The response is cached for 24 hours to comply with Apple's recommended caching guidelines.
- Ensure your `apple-app-site-association.json` file is valid JSON and follows Apple's specification for Universal Links and Shared Web Credentials.
