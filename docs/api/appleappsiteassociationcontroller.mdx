# Apple App Site Association Controller

## Purpose

The `AppleAppSiteAssociationController` is a Spring Boot REST controller that serves the Apple App Site Association (AASA) file required for Universal Links and Shared Web Credentials on iOS devices. This file is hosted at the standard Apple-required path `/.well-known/apple-app-site-association` and allows iOS applications to verify that a website is associated with a specific app.

The controller reads the AASA JSON file from the classpath, serves it with the correct `application/json` content type, and applies a 24-hour cache control header to optimize performance and reduce server load.

## Endpoint

### `GET /.well-known/apple-app-site-association`

Returns the Apple App Site Association JSON file that iOS devices use to validate app-to-website associations.

#### Response

| Property | Value |
|----------|-------|
| HTTP Status | `200 OK` |
| Content Type | `application/json` |
| Cache Control | `public, max-age=86400` (24 hours) |
| Response Body | The contents of `apple-app-site-association.json` from the classpath |

#### Example Response Body

```json
{
  "applinks": {
    "apps": [],
    "details": [
      {
        "appID": "TEAMID.com.example.app",
        "paths": ["*"]
      }
    ]
  }
}
```

## Configuration

The controller expects a file named `apple-app-site-association.json` to be present on the classpath (typically in `src/main/resources/`). The cache duration is set to 24 hours, which can be adjusted by modifying the `CACHE_HOURS` constant.

## Usage Notes

- Ensure the AASA JSON file is valid and follows Apple's specification
- The file must be accessible at `https://yourdomain.com/.well-known/apple-app-site-association`
- For development testing, you may want to reduce the cache duration
- The controller does not require any authentication as the endpoint must be publicly accessible

## Dependencies

- Spring Boot Web (for `@RestController`, `@GetMapping`, and `ResponseEntity`)
- Spring Core (for `ClassPathResource` and `Resource`)
