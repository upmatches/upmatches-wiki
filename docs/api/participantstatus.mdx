# ParticipantStatus Enum

The `ParticipantStatus` enum is part of the `com.upmatches.app.features.game.enums` package. It defines the possible states a participant can have within a game session.

## Purpose

This enum is used to track the current status of a participant (player) in a game. It provides a simple, type-safe way to represent whether a participant is actively playing or has left the game.

## Enum Values

| Value    | Description                                                                 |
|----------|-----------------------------------------------------------------------------|
| `ACTIVE` | Indicates the participant is currently active and participating in the game. |
| `LEFT`   | Indicates the participant has left the game session.                        |

## Usage

This enum is typically used in game-related classes to manage participant state. For example:

- Checking if a participant is still in the game before processing their actions.
- Updating a participant's status when they leave the game.
- Filtering active participants from those who have left.

## Example

```java
ParticipantStatus status = ParticipantStatus.ACTIVE;

if (status == ParticipantStatus.ACTIVE) {
    // Participant is still playing
} else if (status == ParticipantStatus.LEFT) {
    // Participant has left the game
}
```
