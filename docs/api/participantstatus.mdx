# ParticipantStatus Enum

The `ParticipantStatus` enum is part of the `com.upmatches.app.features.game.enums` package. It is used to represent the status of a participant in a game. This enum provides a simple way to track whether a participant is currently active in the game or has left.

## Enum Constants

The `ParticipantStatus` enum defines the following constants:

| Constant | Description |
|----------|-------------|
| `ACTIVE` | Indicates that the participant is currently active in the game. |
| `LEFT`   | Indicates that the participant has left the game. |

## Usage

The `ParticipantStatus` enum can be used in game-related logic to check or update the status of a participant. By using an enum, the code becomes more readable and less error-prone compared to using arbitrary string or integer values.
