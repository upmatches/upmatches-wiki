# ParticipantStatus Enum

The `ParticipantStatus` enum defines the possible states for a participant within a game session in the UpMatches application. It is part of the `com.upmatches.app.features.game.enums` package and is used to track whether a participant is currently active in the game or has left the session.

## Purpose

This enum provides a simple, type-safe way to represent the lifecycle status of a game participant. By using an enum rather than raw strings or integers, the codebase ensures consistency and prevents invalid status values from being assigned.

## Enum Values

| Value | Description |
|-------|-------------|
| `ACTIVE` | The participant is currently active and participating in the game session. |
| `LEFT` | The participant has left the game session and is no longer active. |

## Usage

The `ParticipantStatus` enum is typically used in conjunction with a participant model or entity to track the current state of each player in a game. For example:

```java
public class GameParticipant {
    private String userId;
    private ParticipantStatus status;
    
    // Constructor, getters, and setters
}
```

## Example

```java
// Setting a participant's status
GameParticipant player = new GameParticipant();
player.setUserId("user123");
player.setStatus(ParticipantStatus.ACTIVE);

// Checking participant status
if (player.getStatus() == ParticipantStatus.LEFT) {
    // Handle player leaving the game
}
```
