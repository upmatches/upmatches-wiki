# ParticipantStatus Enum

The `ParticipantStatus` enum is part of the `com.upmatches.app.features.game.enums` package. It is used to represent the status of a participant in a game. This enum provides a clear and concise way to manage participant states, ensuring that the code remains readable and maintainable.

## Enum Constants

The `ParticipantStatus` enum defines the following constants:

- **ACTIVE**: Indicates that the participant is currently active in the game.
- **LEFT**: Indicates that the participant has left the game.
