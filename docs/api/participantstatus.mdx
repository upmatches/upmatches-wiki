# ParticipantStatus Enum

The `ParticipantStatus` enum is part of the `com.upmatches.app.features.game.enums` package. It defines the possible states a participant can be in within a game session.

## Purpose

This enum is used to track the current status of a game participant. It provides a clear and type-safe way to represent whether a participant is actively playing or has left the game.

## Enum Values

| Value | Description |
|-------|-------------|
| `ACTIVE` | The participant is currently active and participating in the game. |
| `LEFT` | The participant has left the game session. |

## Usage

This enum is typically used in game-related classes to manage participant state transitions. For example:

- When a player joins a game, their status is set to `ACTIVE`.
- When a player disconnects or voluntarily leaves, their status changes to `LEFT`.

## Example

```java
ParticipantStatus status = ParticipantStatus.ACTIVE;

// Check participant status
if (status == ParticipantStatus.LEFT) {
    // Handle participant leaving
}
```
