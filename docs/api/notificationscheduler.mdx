# NotificationScheduler

The `NotificationScheduler` class is a Spring Boot component that automates the sending of game reminder notifications. It uses a cron expression to trigger scheduled tasks that send reminders for upcoming games at two different intervals: three days before and one day before the game.

## Purpose

This scheduler ensures that users receive timely reminders about their upcoming games without manual intervention. It leverages the `ISendGameRemindersService` to handle the actual notification logic, while the scheduler itself manages the timing and frequency of these reminders.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `ISendGameRemindersService` | Service interface responsible for executing reminder notifications |
| `Logger` (SLF4J) | Logging framework for recording scheduler activity |

## Configuration

The scheduler uses a configurable cron expression defined in the application properties:

| Property | Default Value | Description |
|----------|---------------|-------------|
| `app.notification.reminder-cron` | `0 0 9 * * *` | Cron expression for daily execution at 9:00 AM |

## Public Methods

### `sendReminders()`

This is the main scheduled method that executes daily to send game reminders.

**Annotation:** `@Scheduled(cron = "${app.notification.reminder-cron:0 0 9 * * *}")`

**Behavior:**
1. Sends reminders for games occurring in approximately 3 days (71-73 hours from now)
2. Sends reminders for games occurring in approximately 1 day (23-25 hours from now)
3. Logs the number of reminders sent for each notification type

**Parameters:** None

**Return Type:** `void`

**Logging:**
- Logs the count of sent reminders for each notification type using the format: `Sent {count} {notificationType} reminders.`

## Internal Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `REMINDER_CRON` | `${app.notification.reminder-cron:0 0 9 * * *}` | Configurable cron expression with default of 9:00 AM daily |
| `HOURS_3_DAYS_MIN` | `71L` | Minimum hours for 3-day reminder window |
| `HOURS_3_DAYS_MAX` | `73L` | Maximum hours for 3-day reminder window |
| `HOURS_1_DAY_MIN` | `23L` | Minimum hours for 1-day reminder window |
| `HOURS_1_DAY_MAX` | `25L` | Maximum hours for 1-day reminder window |

## Usage Example

```java
// The scheduler is automatically invoked by Spring's scheduling mechanism
// No manual invocation is required
```

## Notes

- The scheduler uses a configurable cron expression, allowing administrators to adjust the execution time without code changes
- The time windows (71-73 hours and 23-25 hours) provide flexibility for the reminder service to find games within those ranges
- All reminder activity is logged for monitoring and debugging purposes
- The class is thread-safe as it has no mutable state
