# NotificationScheduler

The `NotificationScheduler` class is a Spring Boot component responsible for automatically sending game reminder notifications at scheduled intervals. It leverages Spring's `@Scheduled` annotation to execute reminder logic based on a configurable cron expression.

## Purpose

This scheduler handles two types of game reminders:
- **3-day reminders**: Sent to users whose games are scheduled approximately 3 days (71-73 hours) in the future.
- **1-day reminders**: Sent to users whose games are scheduled approximately 1 day (23-25 hours) in the future.

The class delegates the actual reminder sending logic to the `ISendGameRemindersService` interface, promoting separation of concerns and testability.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `ISendGameRemindersService` | Constructor injection | Service interface that handles the business logic for sending game reminders |
| `Logger` (SLF4J) | Internal | Logs the number of reminders sent for each notification type |

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `REMINDER_CRON` | `${app.notification.reminder-cron:0 0 9 * * *}` | Cron expression for scheduling reminders (default: daily at 9:00 AM) |
| `HOURS_3_DAYS_MIN` | `71L` | Minimum hours before game time for 3-day reminders |
| `HOURS_3_DAYS_MAX` | `73L` | Maximum hours before game time for 3-day reminders |
| `HOURS_1_DAY_MIN` | `23L` | Minimum hours before game time for 1-day reminders |
| `HOURS_1_DAY_MAX` | `25L` | Maximum hours before game time for 1-day reminders |

## Public Methods

### `sendReminders()`

This method is annotated with `@Scheduled(cron = REMINDER_CRON)` and is automatically invoked by Spring's task scheduler according to the configured cron expression.

| Aspect | Details |
|--------|---------|
| **Access Modifier** | `public` |
| **Return Type** | `void` |
| **Parameters** | None |
| **Scheduling** | Triggered by cron expression defined in `app.notification.reminder-cron` property (default: `0 0 9 * * *` - daily at 9:00 AM) |

**Behavior:**
1. Calls `sendGameRemindersService.execute()` with `NotificationType.GAME_REMINDER_3_DAYS` and the 3-day hour range (71-73 hours).
2. Logs the number of 3-day reminders sent.
3. Calls `sendGameRemindersService.execute()` with `NotificationType.GAME_REMINDER_1_DAY` and the 1-day hour range (23-25 hours).
4. Logs the number of 1-day reminders sent.

## Usage Example

```java
// The scheduler is automatically triggered by Spring's scheduling mechanism.
// No manual invocation is required in normal operation.

// To manually trigger reminders (for testing purposes):
notificationScheduler.sendReminders();
```

## Configuration

The cron expression can be customized via the `app.notification.reminder-cron` property in your application configuration:

```yaml
# application.yml
app:
  notification:
    reminder-cron: "0 0 9 * * *"  # Default: daily at 9:00 AM
```

## Logging

The scheduler logs the number of reminders sent for each type using SLF4J. Example log output:

```
Sent 42 GAME_REMINDER_3_DAYS reminders.
Sent 38 GAME_REMINDER_1_DAY reminders.
```

## Notes

- The hour ranges (71-73 and 23-25) provide a 2-hour window to account for scheduling variations and ensure all relevant games are captured.
- The `ISendGameRemindersService` interface abstracts the actual notification delivery mechanism, allowing for different implementations (e.g., push notifications, email, SMS).
- This scheduler is thread-safe as it uses no shared mutable state.
