# CookieHelper

The `CookieHelper` class is a Spring `@Service` component that manages authentication cookies for the UpMatches application. It implements the `ICookieHelper` interface and provides methods to set, clear, and retrieve authentication tokens stored as HTTP cookies.

## Purpose

This helper class handles the lifecycle of three authentication cookies:
- **accessToken**: HttpOnly cookie containing the JWT access token
- **refreshToken**: HttpOnly cookie containing the refresh token
- **tokenExpiry**: JavaScript-readable cookie containing the Unix timestamp of token expiration

The class ensures secure cookie handling by respecting the request's security context (HTTP vs HTTPS) and applying strict SameSite policies.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `JwtProperties` | Configuration properties for JWT token expiry durations |
| `HttpServletRequest` | Used to determine if the request is secure (HTTPS) |
| `HttpServletResponse` | Used to add cookies to the response |

## Public Methods

### `setAuthCookies`

Sets all three authentication cookies on the HTTP response.

| Parameter | Type | Description |
|-----------|------|-------------|
| `response` | `HttpServletResponse` | The HTTP response to add cookies to |
| `request` | `HttpServletRequest` | The HTTP request to determine security context |
| `tokenData` | `TokenData` | Contains access token, refresh token, and expiration timestamp |

**Returns:** `void`

The method creates three cookies with the following characteristics:
- **accessToken**: HttpOnly, secure (if HTTPS), SameSite=Strict, path=/, expires based on `jwtProperties.accessTokenExpiryMinutes()`
- **refreshToken**: HttpOnly, secure (if HTTPS), SameSite=Strict, path=/, expires based on `jwtProperties.refreshTokenExpiryDays()`
- **tokenExpiry**: Not HttpOnly (JavaScript-readable), secure (if HTTPS), SameSite=Strict, path=/, expires based on `jwtProperties.accessTokenExpiryMinutes()`

### `clearAuthCookies`

Clears all three authentication cookies by setting their max age to 0.

| Parameter | Type | Description |
|-----------|------|-------------|
| `response` | `HttpServletResponse` | The HTTP response to add cleared cookies to |
| `request` | `HttpServletRequest` | The HTTP request to determine security context |

**Returns:** `void`

This method creates three cookies with empty values and `maxAge(0)` to instruct the browser to delete them immediately.

### `getRefreshTokenFromCookie`

Retrieves the refresh token value from the request's cookies.

| Parameter | Type | Description |
|-----------|------|-------------|
| `request` | `HttpServletRequest` | The HTTP request containing cookies |

**Returns:** `String` - The refresh token value, or `null` if no refresh token cookie is found.

## Inner Types

### `TokenData`

A record class that encapsulates the token data required for setting authentication cookies.

| Field | Type | Description |
|-------|------|-------------|
| `accessToken` | `String` | The JWT access token |
| `expiresAtUtc` | `Long` | Unix timestamp (UTC) when the access token expires |
| `refreshToken` | `String` | The refresh token |

## Security Considerations

- **HttpOnly**: Access and refresh tokens are HttpOnly to prevent XSS attacks from accessing them via JavaScript
- **Secure flag**: Cookies are marked as secure only when the request is made over HTTPS
- **SameSite Strict**: All cookies use `SameSite=Strict` to prevent CSRF attacks
- **Token Expiry Cookie**: The `tokenExpiry` cookie is intentionally not HttpOnly so that the SPA can read it and proactively refresh tokens before they expire

## Usage Example

```java
// Inject the service
private final CookieHelper cookieHelper;

// Setting cookies after successful authentication
TokenData tokenData = new TokenData(
    "eyJhbGciOiJIUzI1NiIs...", // access token
    1700000000L,                  // expires at UTC
    "dGhpcyBpcyBhIHJlZnJl...",  // refresh token
);
cookieHelper.setAuthCookies(response, request, tokenData);

// Clearing cookies on logout
cookieHelper.clearAuthCookies(response, request);

// Retrieving refresh token from request
String refreshToken = cookieHelper.getRefreshTokenFromCookie(request);
```
