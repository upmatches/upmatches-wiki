## Purpose

The `CookieHelper` class is a service component in a Java Spring application responsible for managing authentication cookies. It provides methods to set, clear, and retrieve cookies related to authentication tokens. This class is crucial for handling user sessions securely by storing access and refresh tokens in HTTP-only cookies.

## Public Methods

### `setAuthCookies`

Sets authentication cookies in the HTTP response, including access token, refresh token, and token expiry.

| Parameter  | Type                      | Description                                                                 |
|------------|---------------------------|-----------------------------------------------------------------------------|
| `response` | `HttpServletResponse`     | The HTTP response object where cookies will be added.                       |
| `request`  | `HttpServletRequest`      | The HTTP request object to determine if the connection is secure.           |
| `tokenData`| `TokenData`               | An object containing access token, refresh token, and expiry time.          |

**Returns:** `void`

### `clearAuthCookies`

Clears authentication cookies from the HTTP response, effectively logging out the user.

| Parameter  | Type                      | Description                                                                 |
|------------|---------------------------|-----------------------------------------------------------------------------|
| `response` | `HttpServletResponse`     | The HTTP response object where cookies will be cleared.                     |
| `request`  | `HttpServletRequest`      | The HTTP request object to determine if the connection is secure.           |

**Returns:** `void`

### `getRefreshTokenFromCookie`

Retrieves the refresh token from the cookies in the HTTP request.

| Parameter  | Type                      | Description                                                                 |
|------------|---------------------------|-----------------------------------------------------------------------------|
| `request`  | `HttpServletRequest`      | The HTTP request object containing cookies.                                 |

**Returns:** `String` - The refresh token if present, otherwise `null`.

## TokenData Record

The `TokenData` record is a simple data structure used to encapsulate the access token, expiry time, and refresh token.

| Field          | Type     | Description                             |
|----------------|----------|-----------------------------------------|
| `accessToken`  | `String` | The access token for authentication.    |
| `expiresAtUtc` | `Long`   | The expiry time of the access token in UTC. |
| `refreshToken` | `String` | The refresh token for obtaining new access tokens. |
