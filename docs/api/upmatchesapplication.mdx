# UpmatchesApplication

The `UpmatchesApplication` class serves as the main entry point for the Upmatches Spring Boot application. It is responsible for bootstrapping and launching the application, as well as enabling the configuration properties for various authentication and shared features.

## Purpose

This class is the core startup class for the Upmatches backend service. It uses Spring Boot's auto-configuration and component scanning to initialize the application context. By annotating the class with `@EnableConfigurationProperties`, it registers multiple property classes that hold configuration values for authentication providers, logging, and share link functionality.

## Key Annotations

- **`@SpringBootApplication`**: A convenience annotation that combines `@Configuration`, `@EnableAutoConfiguration`, and `@ComponentScan`. It enables Spring Boot's auto-configuration and component scanning for the package and its sub-packages.
- **`@EnableConfigurationProperties`**: Enables support for `@ConfigurationProperties` beans. The listed classes will be registered as beans in the application context, allowing their properties to be bound from external configuration sources (e.g., `application.yml` or environment variables).

## Public Methods

| Method | Return Type | Parameters | Description |
|--------|-------------|------------|-------------|
| `main(String[] args)` | `void` | `String[] args` - Command-line arguments passed to the application | The standard Java entry point. It calls `SpringApplication.run()` to launch the Spring Boot application. |

## Configuration Properties Enabled

The following configuration property classes are enabled via `@EnableConfigurationProperties`:

| Property Class | Description |
|----------------|-------------|
| `LogAspectProperties` | Configuration for logging aspects |
| `SingpassProperties` | Configuration for Singpass authentication |
| `Auth0Properties` | Configuration for Auth0 authentication |
| `AppleProperties` | Configuration for Apple Sign-In |
| `AuthDevProperties` | Configuration for development authentication |
| `JwtProperties` | Configuration for JWT token handling |
| `InfisicalProperties` | Configuration for Infisical secrets management |
| `ShareLinkProperties` | Configuration for share link functionality |

## Usage

To run the application, execute the `main` method:

```bash
# Using Maven
mvn spring-boot:run

# Using Java directly
java -jar upmatches-app.jar
```

The application will start an embedded web server (default port 8080) and begin accepting requests.
