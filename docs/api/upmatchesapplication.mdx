## Overview

The `UpmatchesApplication` class serves as the entry point for the Upmatches application. It is a Spring Boot application that initializes and runs the application context. This class is responsible for bootstrapping the application and enabling configuration properties for various authentication and logging features.

## Class Details

The `UpmatchesApplication` class is annotated with `@SpringBootApplication`, which is a convenience annotation that adds all of the following:

- `@Configuration`: Tags the class as a source of bean definitions for the application context.
- `@EnableAutoConfiguration`: Tells Spring Boot to start adding beans based on classpath settings, other beans, and various property settings.
- `@ComponentScan`: Tells Spring to look for other components, configurations, and services in the `com.upmatches.app` package, allowing it to find the controllers.

Additionally, the class is annotated with `@EnableConfigurationProperties`, which is used to enable support for `@ConfigurationProperties` annotated classes. This allows the application to bind external configuration properties to Java objects.

### Configuration Properties

The following configuration properties are enabled in this application:

- `LogAspectProperties`: Configuration properties related to logging aspects.
- `SingpassProperties`: Configuration properties for Singpass authentication.
- `Auth0Properties`: Configuration properties for Auth0 authentication.
- `AppleProperties`: Configuration properties for Apple authentication.
- `AuthDevProperties`: Configuration properties for development authentication.
- `JwtProperties`: Configuration properties for JWT authentication.
- `InfisicalProperties`: Configuration properties for Infisical authentication.
- `ShareLinkProperties`: Configuration properties for share link features.

## Public Methods

The `UpmatchesApplication` class contains the following public method:

| Method Signature             | Description                                                                 |
|------------------------------|-----------------------------------------------------------------------------|
| `public static void main(String[] args)` | The main method that serves as the entry point for the Spring Boot application. It takes an array of `String` arguments and uses `SpringApplication.run()` to launch the application. |

### Parameters

- `args`: An array of `String` arguments passed to the application. These can be used to pass command-line arguments to the application.

### Return Type

- The `main` method does not return a value as it is `void`. It is responsible for launching the application.
