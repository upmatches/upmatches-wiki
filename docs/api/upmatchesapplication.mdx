# UpmatchesApplication

The `UpmatchesApplication` class serves as the entry point for the Upmatches Spring Boot application. It is responsible for bootstrapping and launching the application using Spring Boot's auto-configuration capabilities.

## Purpose

This class initializes the Spring application context and enables configuration properties for various authentication and feature modules. It acts as the main configuration hub that loads all necessary property classes required by the application's authentication system and shared features.

## Key Annotations

| Annotation | Description |
|------------|-------------|
| `@SpringBootApplication` | Enables Spring Boot auto-configuration, component scanning, and configuration property binding |
| `@EnableConfigurationProperties` | Activates support for `@ConfigurationProperties` beans, allowing externalized configuration |

## Configuration Properties Enabled

The following configuration property classes are registered and bound to their respective property prefixes:

| Property Class | Purpose |
|----------------|---------|
| `LogAspectProperties` | Logging aspect configuration |
| `SingpassProperties` | Singpass authentication settings |
| `Auth0Properties` | Auth0 authentication provider settings |
| `AppleProperties` | Apple Sign-In configuration |
| `AuthDevProperties` | Development authentication settings |
| `JwtProperties` | JWT token configuration |
| `InfisicalProperties` | Infisical secrets management settings |
| `ShareLinkProperties` | Share link feature configuration |

## Public Methods

### `main(String[] args)`

| Parameter | Type | Description |
|-----------|------|-------------|
| `args` | `String[]` | Command-line arguments passed to the application |

**Returns:** `void`

This is the standard Java entry point method. It calls `SpringApplication.run()` to start the Spring Boot application context, which triggers auto-configuration, component scanning, and property binding for all enabled configuration properties.

## Usage

The application is started by executing the `main` method, typically through a build tool like Maven or Gradle, or directly from an IDE:

```bash
# Using Maven
mvn spring-boot:run

# Using Gradle
gradle bootRun
```

## Package Structure

The class resides in the `com.upmatches.app` package and imports configuration property classes from the following sub-packages:

- `com.upmatches.app.features.auth.properties` - Authentication-related properties
- `com.upmatches.app.features.sharelink.properties` - Share link feature properties
- `com.upmatches.app.shared.logging.properties` - Shared logging configuration
