# ListMyHostedGamesCursorService

## Purpose

The `ListMyHostedGamesCursorService` is a Spring service class responsible for retrieving a paginated list of games hosted by the currently authenticated user. It implements cursor-based pagination to efficiently fetch game records, including participant counts for each game. The service ensures that only the authenticated user's hosted games are returned, and it handles the encoding/decoding of cursor values for seamless pagination.

## Key Features

- **Cursor-based pagination**: Uses a cursor (encoded timestamp + ID) for efficient, stable pagination
- **Authenticated user context**: Automatically resolves the current user's identity
- **Participant counting**: Includes the count of active participants for each game
- **Transactional read-only**: Ensures data consistency without locking
- **Error handling**: Wraps operations with standardized error handling via `ServiceOperationExecutor`

## Public Methods

### `execute(String cursor, int size)`

Retrieves a cursor-paginated list of games hosted by the authenticated user.

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | Encoded cursor string for pagination. Pass `null` or empty for the first page. |
| `size` | `int` | Maximum number of records to return per page. |

| Returns | Description |
|---------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing the list of `GameResponse` objects and the next cursor value. |

**Behavior:**
1. Resolves the authenticated user's UUID
2. Decodes the cursor (if provided) to extract the `startTime` and `id` of the last record
3. Queries the database for games hosted by the user, ordered by start time and ID
4. Counts active participants for each retrieved game
5. Maps games to `GameResponse` objects with participant counts
6. Encodes the next cursor if more records exist
7. Returns a `CursorPagedResponse` with the content and next cursor

**Example usage:**
```java
// First page
CursorPagedResponse<GameResponse> firstPage = service.execute(null, 20);

// Subsequent pages
CursorPagedResponse<GameResponse> nextPage = service.execute(firstPage.getNextCursor(), 20);
```

## Private Methods

### `countParticipants(List<Game> games)`

Counts active participants for a list of games.

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | List of games to count participants for. |

| Returns | Description |
|---------|-------------|
| `Map<UUID, Long>` | A map of game IDs to their active participant counts. Returns an empty map if the input list is empty. |

**Behavior:**
- Extracts game IDs from the provided list
- Returns an empty map if the list is empty
- Queries the `GameParticipantRepository` for counts of participants with `ACTIVE` status
- Converts the result to a map keyed by game ID

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameRepository` | Repository | Data access for `Game` entities |
| `GameParticipantRepository` | Repository | Data access for participant counts |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user |
| `GameCursor` | Helper | Encodes/decodes cursor values for pagination |
| `ServiceOperationExecutor` | Utility | Provides standardized error handling and logging |

## Error Handling

The service wraps its main operation in `ServiceOperationExecutor.execute()`, which:
- Logs the operation with status `RETRIEVE`
- Throws `ResourceNotFoundException` if the operation fails
- Provides consistent error handling across the application

## Notes

- The service is annotated with `@Transactional(readOnly = true)`, ensuring no database modifications occur
- The class is declared as `non-sealed`, allowing for future extension if needed
- Cursor encoding uses the game's `startTime` and `id` to ensure stable ordering even if records are inserted or deleted between pages
