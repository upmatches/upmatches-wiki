# ListMyHostedGamesCursorService

## Purpose

The `ListMyHostedGamesCursorService` is a Spring service class responsible for retrieving a cursor-based paginated list of games hosted by the currently authenticated user. It implements the `IListMyHostedGamesCursorService` interface and provides transactional read-only access to the database.

This service handles the complexity of cursor-based pagination by decoding an incoming cursor token, querying the database for the next page of hosted games, counting active participants for each game, and encoding a new cursor for subsequent requests.

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `GameRepository` | Repository | Data access for `Game` entities |
| `GameParticipantRepository` | Repository | Data access for game participant counts |
| `IAuthenticatedUserResolver` | Service | Resolves the currently authenticated user's ID |
| `GameCursor` | Helper | Encodes and decodes cursor tokens for pagination |

## Public Methods

### `execute(String cursor, int size)`

Retrieves a cursor-based paginated list of games hosted by the authenticated user.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The cursor token from the previous page request. Pass `null` or empty string for the first page. |
| `size` | `int` | The maximum number of results to return per page |

**Returns:**

| Return Type | Description |
|-------------|-------------|
| `CursorPagedResponse<GameResponse>` | A paginated response containing the list of `GameResponse` objects and an optional next cursor token |

**Behavior:**

1. Resolves the authenticated user's UUID via `userResolver.requireUserId()`
2. Decodes the provided cursor token using `gameCursor.decode()`
3. Queries the database for games hosted by the user, using the cursor's start time and ID for pagination
4. Counts active participants for each retrieved game
5. Maps each `Game` entity to a `GameResponse` using `GameResponse.fromGameForViewer()`
6. Encodes a new cursor token from the last game in the result set (if the page is full)
7. Returns a `CursorPagedResponse` containing the content and next cursor

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown via `ServiceOperationExecutor` when the operation fails (wrapped from underlying exceptions) |

## Private Methods

### `countParticipants(List<Game> games)`

Counts active participants for a list of games.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `games` | `List<Game>` | The list of games to count participants for |

**Returns:**

| Return Type | Description |
|-------------|-------------|
| `Map<UUID, Long>` | A map of game IDs to their active participant counts. Returns an empty map if the input list is empty. |

**Behavior:**

- Extracts game IDs from the provided list
- Returns an empty map if the list is empty
- Queries `participantRepository` for active participant counts grouped by game ID
- Converts the result to a `Map<UUID, Long>` for efficient lookup

## Usage Example

```java
@Service
public class GameController {
    private final ListMyHostedGamesCursorService listMyHostedGamesService;

    public GameController(ListMyHostedGamesCursorService listMyHostedGamesService) {
        this.listMyHostedGamesService = listMyHostedGamesService;
    }

    public CursorPagedResponse<GameResponse> getMyHostedGames(String cursor, int size) {
        return listMyHostedGamesService.execute(cursor, size);
    }
}
```

## Notes

- The service is annotated with `@Transactional(readOnly = true)` to optimize database access for read operations
- The `non-sealed` modifier indicates this class is part of a sealed interface hierarchy
- Cursor-based pagination is more efficient than offset-based pagination for large datasets as it avoids the "offset drift" problem
- The `ServiceOperationExecutor` wraps the operation in a standardized error handling and logging framework
