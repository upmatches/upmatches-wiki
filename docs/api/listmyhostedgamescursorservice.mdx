## Overview

The `ListMyHostedGamesCursorService` class is a service component in a Java application that manages the retrieval of games hosted by a user. It leverages cursor-based pagination to efficiently fetch a subset of games, allowing users to navigate through large datasets seamlessly. This service is particularly useful in scenarios where users need to view their hosted games in a paginated manner, ensuring optimal performance and user experience.

## Public Methods

### `execute`

The `execute` method is the primary operation of the `ListMyHostedGamesCursorService` class. It retrieves a paginated list of games hosted by the authenticated user, based on the provided cursor and size parameters.

| Parameter | Type   | Description                                                                 |
|-----------|--------|-----------------------------------------------------------------------------|
| `cursor`  | String | A string representing the current position in the pagination sequence.      |
| `size`    | int    | The number of games to retrieve in the current page.                        |

#### Returns

- `CursorPagedResponse<GameResponse>`: A response object containing the list of games and the next cursor for pagination.
