## Overview

The `ListMyHostedGamesCursorService` class is a Spring service designed to retrieve a paginated list of games hosted by the authenticated user. It uses a cursor-based pagination mechanism to efficiently navigate through large datasets. This service is part of the `com.upmatches.app.features.game.services` package and implements the `IListMyHostedGamesCursorService` interface.

## Purpose

The primary purpose of this class is to provide a method to fetch games hosted by the current user, utilizing cursor-based pagination. This allows for efficient data retrieval and navigation through potentially large lists of games without the performance drawbacks of traditional offset-based pagination.

## Public Methods

### `execute`

The `execute` method retrieves a paginated list of games hosted by the authenticated user, starting from a specified cursor position and returning a specified number of results.

| Parameter | Type   | Description                                                                 |
|-----------|--------|-----------------------------------------------------------------------------|
| `cursor`  | String | The cursor indicating the starting point for the pagination.                |
| `size`    | int    | The maximum number of games to retrieve in this request.                    |

#### Returns

- `CursorPagedResponse<GameResponse>`: A response object containing the list of games and the next cursor for pagination.

## Method Details

### `execute(String cursor, int size)`

- **Description**: This method is responsible for executing the retrieval of hosted games for the authenticated user. It decodes the provided cursor to determine the starting point and fetches the specified number of games. It also calculates the number of active participants for each game and encodes the next cursor for further pagination.
- **Transactional Behavior**: The method is annotated with `@Transactional(readOnly = true)`, indicating that it operates in a read-only transaction context, which optimizes performance by avoiding unnecessary locking.

### Private Helper Method

#### `countParticipants(List<Game> games)`

- **Description**: This private method counts the number of active participants for each game in the provided list. It returns a map where the keys are game IDs and the values are the counts of active participants.
- **Returns**: `Map<UUID, Long>`: A map of game IDs to their respective active participant counts.
