# DatabaseType Enum

The `DatabaseType` enum is a core component of the UpMatches application's database abstraction layer. It provides a centralized, type-safe way to represent and identify supported database systems (H2, PostgreSQL, and MySQL) along with their associated JDBC connection string prefixes and driver class names.

## Purpose

This enum serves two primary purposes:

1. **Database Identification**: It maps JDBC URL prefixes to specific database types, enabling automatic detection of the database system from a connection string.
2. **Driver Management**: It encapsulates the JDBC driver class name for each supported database, simplifying driver registration and connection setup.

## Enum Constants

| Constant | JDBC Prefix | Driver Class |
|----------|-------------|--------------|
| `H2` | `jdbc:h2:` | `org.h2.Driver` |
| `POSTGRESQL` | `jdbc:postgresql:` | `org.postgresql.Driver` |
| `MYSQL` | `jdbc:mysql:` | `com.mysql.cj.jdbc.Driver` |

## Public Methods

### `fromJdbcUrl(String jdbcUrl)`

Resolves a JDBC URL string to its corresponding `DatabaseType` enum constant.

| Parameter | Type | Description |
|-----------|------|-------------|
| `jdbcUrl` | `String` | The JDBC connection URL to evaluate |

**Returns**: `DatabaseType` - The matching enum constant, or `null` if the URL is null or does not match any known prefix.

**Example Usage**:
```java
DatabaseType type = DatabaseType.fromJdbcUrl("jdbc:postgresql://localhost:5432/mydb");
// Returns DatabaseType.POSTGRESQL

DatabaseType unknown = DatabaseType.fromJdbcUrl("jdbc:oracle:thin:@localhost:1521:xe");
// Returns null
```

### `getPrefix()`

Returns the JDBC URL prefix associated with this database type.

**Returns**: `String` - The JDBC prefix (e.g., `jdbc:h2:`, `jdbc:postgresql:`, `jdbc:mysql:`).

### `getDriverClassName()`

Returns the fully qualified JDBC driver class name for this database type.

**Returns**: `String` - The driver class name (e.g., `org.h2.Driver`, `org.postgresql.Driver`, `com.mysql.cj.jdbc.Driver`).

## Usage Example

```java
// Automatic database type detection
String connectionUrl = "jdbc:mysql://localhost:3306/upmatches";
DatabaseType dbType = DatabaseType.fromJdbcUrl(connectionUrl);

if (dbType != null) {
    System.out.println("Detected database: " + dbType.name());
    System.out.println("Driver class: " + dbType.getDriverClassName());
    
    // Register JDBC driver
    Class.forName(dbType.getDriverClassName());
    Connection connection = DriverManager.getConnection(connectionUrl);
}
```

## Dependencies

This enum relies on constants defined in `com.upmatches.app.shared.database.constants.DatabaseConstant`:

- `JDBC_H2` = `"jdbc:h2:"`
- `JDBC_POSTGRESQL` = `"jdbc:postgresql:"`
- `JDBC_MYSQL` = `"jdbc:mysql:"`

## Notes

- The `fromJdbcUrl()` method performs a prefix-based matching, which is efficient and reliable for standard JDBC URLs.
- Returns `null` for null input or unrecognized JDBC URL formats, allowing callers to handle unknown database types gracefully.
- The enum is immutable and thread-safe by design, suitable for use in concurrent environments.
