## Purpose

The `DatabaseType` enum is designed to represent different types of databases supported by the application. It provides a convenient way to manage database-specific configurations, such as JDBC URL prefixes and driver class names. This enum helps in identifying the database type from a given JDBC URL and retrieving the associated driver class name.

## Public Methods

### `fromJdbcUrl`

Determines the `DatabaseType` based on the provided JDBC URL.

| Parameter | Type   | Description                          |
|-----------|--------|--------------------------------------|
| jdbcUrl   | String | The JDBC URL to be evaluated.        |

| Return Type | Description                                      |
|-------------|--------------------------------------------------|
| DatabaseType | The corresponding `DatabaseType` or `null` if no match is found. |

### `getPrefix`

Retrieves the JDBC URL prefix associated with the database type.

| Return Type | Description                          |
|-------------|--------------------------------------|
| String      | The JDBC URL prefix for the database type. |

### `getDriverClassName`

Retrieves the driver class name associated with the database type.

| Return Type | Description                          |
|-------------|--------------------------------------|
| String      | The driver class name for the database type. |
