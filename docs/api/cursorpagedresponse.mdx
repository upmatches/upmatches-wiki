## Overview

The `CursorPagedResponse` class is a generic record in the `com.upmatches.app.features.game.responses` package. It is designed to encapsulate a paginated response using a cursor-based pagination mechanism. This is particularly useful in scenarios where you need to efficiently handle large datasets by loading data in chunks, and where traditional offset-based pagination might not be optimal.

## Public Methods

The `CursorPagedResponse` record automatically provides the following methods due to its nature as a Java record:

### Constructor

The constructor for `CursorPagedResponse` is automatically provided and initializes the record with the specified content and next cursor.

| Parameter   | Type     | Description                                      |
|-------------|----------|--------------------------------------------------|
| `content`   | `List<T>`| The list of items of type `T` representing the current page of data. |
| `nextCursor`| `String` | A string representing the cursor for the next page of data. |

### Accessor Methods

Records in Java automatically generate accessor methods for their components. For `CursorPagedResponse`, the following accessor methods are available:

| Method          | Return Type | Description                                      |
|-----------------|-------------|--------------------------------------------------|

| `nextCursor()`  | `String`    | Returns the cursor for the next page of data.    |

## Usage

The `CursorPagedResponse` class is typically used in APIs where data needs to be fetched in a paginated manner. By using a cursor, it allows for efficient data retrieval without the pitfalls of offset-based pagination, such as skipping or duplicating records when data changes between requests.
