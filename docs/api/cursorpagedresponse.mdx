## Overview

The `CursorPagedResponse` class is a generic record in the `com.upmatches.app.features.game.responses` package. It is designed to encapsulate a paginated response using a cursor-based pagination strategy. This class is particularly useful for handling large datasets by allowing clients to request data in chunks and navigate through the dataset using cursors.

## Purpose

The primary purpose of the `CursorPagedResponse` class is to provide a structured way to return a subset of data along with a cursor pointing to the next set of data. This approach is beneficial in scenarios where you need to efficiently manage and navigate through large collections of data without loading the entire dataset into memory.

The `CursorPagedResponse` class is a record, which means it automatically provides implementations for several methods, including a constructor, `equals()`, `hashCode()`, and `toString()`. Below is a documentation of the public methods available in this class:

| Parameter   | Type      | Description                                      |

### Methods

Since `CursorPagedResponse` is a record, it provides the following methods:

| Method          | Return Type | Description                                      |
|-----------------|-------------|--------------------------------------------------|
| `content()`     | `List<T>`   | Returns the list of items representing the current page of data. |

These methods allow you to access the paginated content and the cursor for the subsequent page, facilitating easy navigation through the dataset.
