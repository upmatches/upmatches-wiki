# CursorPagedResponse

A generic Java record representing a paginated response using cursor-based pagination. This class encapsulates a list of content items and a cursor string pointing to the next page of results.

## Purpose

Cursor-based pagination (also known as keyset pagination) is an efficient way to paginate through large datasets where traditional offset-based pagination can become slow or inconsistent. The `CursorPagedResponse` record provides a standardized container for returning paginated results from an API endpoint.

The `nextCursor` field acts as a pointer to the next page. When it is `null` or empty, it indicates that there are no more pages to retrieve.

## Record Definition

```java
public record CursorPagedResponse<T>(
    List<T> content,
    String nextCursor
) {}
```

## Fields

| Field        | Type        | Description                                                                 |
|--------------|-------------|-----------------------------------------------------------------------------|
| `content`    | `List<T>`   | The list of items for the current page.                                     |
| `nextCursor` | `String`    | A cursor string to retrieve the next page. `null` or empty means no more pages. |

## Usage Example

```java
// Example: Creating a response with a next cursor
List<User> users = List.of(user1, user2, user3);
CursorPagedResponse<User> response = new CursorPagedResponse<>(users, "cursor_abc123");

// Example: Creating a response for the last page
CursorPagedResponse<User> lastPage = new CursorPagedResponse<>(users, null);
```

## Type Parameters

| Parameter | Description                                      |
|-----------|--------------------------------------------------|
| `T`       | The type of elements contained in the page.      |

## Notes

- This record is immutable by design (all fields are final).
- The `content` list should not be `null`; use `List.of()` or `Collections.emptyList()` for empty pages.
- The `nextCursor` value is typically an opaque string (e.g., a base64-encoded ID or timestamp) that should not be interpreted by the client.
