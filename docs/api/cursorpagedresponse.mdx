# CursorPagedResponse

The `CursorPagedResponse` record is a generic data carrier used to represent a single page of results in a cursor-based pagination system. It encapsulates the list of items for the current page and an optional cursor string that points to the next page of results.

This record is typically returned by API endpoints that implement cursor-based pagination, where the client uses the `nextCursor` value to request the subsequent page. When `nextCursor` is `null` or empty, it indicates that there are no more pages available.

## Record Definition

```java
public record CursorPagedResponse<T>(
    List<T> content,
    String nextCursor
)
```

## Components

| Component    | Type        | Description                                                                 |
|--------------|-------------|-----------------------------------------------------------------------------|
| `content`    | `List<T>`   | The list of items for the current page. Can be empty if no results exist.   |
| `nextCursor` | `String`    | An opaque cursor string to retrieve the next page. `null` indicates the end of the result set. |

## Usage Example

```java
// Creating a response with results and a next cursor
List<User> users = List.of(user1, user2, user3);
CursorPagedResponse<User> response = new CursorPagedResponse<>(users, "cursor_abc123");

// Creating a response indicating the last page
CursorPagedResponse<User> lastPage = new CursorPagedResponse<>(users, null);
```

## Notes

- The record is immutable and thread-safe by design.
- The generic type parameter `T` allows this record to be used with any entity or DTO type.
- The `nextCursor` value is opaque and should not be parsed or modified by clients.
