# HardDeleteGameService

The `HardDeleteGameService` class provides a service for permanently deleting a game entity from the database. This operation is irreversible and is restricted to users with the `ADMIN` authority. The service ensures that the game exists before deletion and wraps the operation in a transactional context with auditing support.

## Purpose

- **Permanent Deletion**: Removes a game record entirely from the database (hard delete), as opposed to a soft delete.
- **Authorization**: Only users with the `ADMIN` authority can perform this operation.
- **Auditing**: The deletion action is logged with details about the resource and the affected game ID.
- **Error Handling**: Throws a `ResourceNotFoundException` if the game does not exist.

## Public Methods

### `execute(UUID id)`

Permanently deletes a game entity identified by its UUID.

**Annotations:**

- `@Transactional` – Ensures the operation is executed within a database transaction.
- `@PreAuthorize("hasAuthority('ADMIN')")` – Restricts access to users with the `ADMIN` authority.
- `@Auditable(action = "GAME_HARD_DELETED", resourceType = "GAME", resourceIdExpression = "#args[0]")` – Logs the deletion action with the game ID.

**Parameters:**

| Parameter | Type   | Description                        |
|-----------|--------|------------------------------------|
| `id`      | `UUID` | The unique identifier of the game. |

**Throws:**

| Exception                    | Condition                                      |
|------------------------------|------------------------------------------------|
| `ResourceNotFoundException`  | If no game exists with the given ID.           |

**Behavior:**

1. Uses `lookupService.findGameIgnoringDeletedOrThrow(id)` to verify the game exists (including soft-deleted records).
2. Calls `ServiceOperationExecutor.executeVoid()` to perform the deletion via `gameRepository.delete(game)`.
3. If the game is not found, a `ResourceNotFoundException` is thrown.

## Usage Example

```java
@Autowired
private HardDeleteGameService hardDeleteGameService;

public void deleteGame(UUID gameId) {
    hardDeleteGameService.execute(gameId);
}
```

## Notes

- This service performs a **hard delete**, meaning the record is permanently removed from the database. Use with caution.
- The `findGameIgnoringDeletedOrThrow` method in `IGameLookupService` is used to locate the game regardless of its soft-delete status, ensuring that even previously soft-deleted games can be hard deleted.
- The `ServiceOperationExecutor.executeVoid` method handles the execution and exception mapping, converting any persistence errors into `ResourceNotFoundException`.
