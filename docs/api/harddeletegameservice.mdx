# HardDeleteGameService

The `HardDeleteGameService` class is a Spring service component responsible for permanently removing a `Game` entity from the database. This operation is irreversible and is restricted to users with `ADMIN` authority. The service ensures that the game exists before deletion and wraps the operation in a transactional context with auditing support.

## Class Overview

- **Package:** `com.upmatches.app.features.game.services`
- **Type:** `non-sealed class` implementing `IHardDeleteGameService`
- **Annotations:** `@Service`
- **Dependencies:**
  - `GameRepository` – for database operations
  - `IGameLookupService` – for looking up game entities

## Public Methods

### `execute(UUID id)`

Permanently deletes a game from the database by its unique identifier.

| Parameter | Type   | Description                                      |
|-----------|--------|--------------------------------------------------|
| `id`      | `UUID` | The unique identifier of the game to be deleted. |

**Return Type:** `void`

**Behavior:**
1. Retrieves the game entity using the lookup service, including soft-deleted records.
2. If the game does not exist, throws a `ResourceNotFoundException`.
3. Executes the deletion within a transactional context.
4. Logs the operation as auditable with action `GAME_HARD_DELETED`.

**Security:** Requires `ADMIN` authority.

**Exceptions:**
- `ResourceNotFoundException` – thrown if the game with the given ID does not exist.

## Annotations

| Annotation            | Description                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| `@Transactional`      | Ensures the deletion operation is executed within a database transaction.   |
| `@PreAuthorize`       | Restricts access to users with `ADMIN` authority.                          |
| `@Auditable`          | Records the deletion event for auditing purposes.                          |

## Usage Example

```java
@Autowired
private HardDeleteGameService hardDeleteGameService;

public void deleteGame(UUID gameId) {
    hardDeleteGameService.execute(gameId);
}
```
