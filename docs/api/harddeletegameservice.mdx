## Overview

The `HardDeleteGameService` class is a service component in a Java application that handles the permanent deletion of game entities from the database. It is part of the `com.upmatches.app.features.game.services` package and is designed to be used by administrators to remove game records completely, bypassing any soft-delete mechanisms.

## Class Details

The `HardDeleteGameService` class implements the `IHardDeleteGameService` interface and is marked with the `@Service` annotation, indicating that it is a Spring service component. It is also marked as `non-sealed`, allowing other classes to extend it if necessary.

### Dependencies

- **GameRepository**: Used to perform database operations related to the `Game` entity.
- **IGameLookupService**: Utilized to find games, including those that are marked as deleted.

## Public Methods

### `execute`

The `execute` method is responsible for permanently deleting a game from the database. It is annotated with `@Transactional` to ensure that the operation is executed within a transaction context, and `@PreAuthorize` to restrict access to users with the 'ADMIN' authority. The `@Auditable` annotation is used to log the deletion action for auditing purposes.

| Method Signature | Description |
|------------------|-------------|
| `public void execute(UUID id)` | Permanently deletes a game identified by the given UUID. |

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id`      | `UUID` | The unique identifier of the game to be deleted. |

#### Return Type

This method does not return any value (`void`).

## Usage

The `HardDeleteGameService` is intended to be used in scenarios where a game needs to be completely removed from the system. It ensures that only users with the appropriate authority can perform this operation and logs the action for auditing purposes.
