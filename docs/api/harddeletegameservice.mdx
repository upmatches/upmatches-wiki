# HardDeleteGameService

The `HardDeleteGameService` class is a Spring service component responsible for permanently removing a `Game` entity from the database. Unlike soft deletion, this operation physically deletes the record and cannot be undone. Access is restricted to users with the `ADMIN` authority, and the operation is audited for compliance and traceability.

## Purpose

- **Permanent Deletion**: Physically removes a game record from the database.
- **Admin-Only Access**: Ensures only authorized administrators can perform hard deletions.
- **Audit Trail**: Logs the deletion event with details about the resource and the user who performed the action.
- **Transactional Safety**: Wraps the deletion in a database transaction to maintain data integrity.

| `gameRepository` | `GameRepository` | Repository for performing database operations on `Game` entities |
| `lookupService` | `IGameLookupService` | Service for looking up game entities, including soft-deleted ones |

## Public Methods

### `execute(UUID id)`

Permanently deletes a game from the database.

| Aspect | Details |
|--------|---------|
| **Access Modifier** | `public` |
| **Return Type** | `void` |
| **Parameters** | `id` (`UUID`) – The unique identifier of the game to delete |
| **Annotations** | `@Transactional`, `@PreAuthorize("hasAuthority('ADMIN')")`, `@Auditable(action = "GAME_HARD_DELETED", resourceType = "GAME", resourceIdExpression = "#args[0]")` |

**Behavior:**

1. **Lookup**: Retrieves the game entity using `lookupService.findGameIgnoringDeletedOrThrow(id)`. This method will throw a `ResourceNotFoundException` if the game does not exist.
2. **Deletion**: Calls `gameRepository.delete(game)` to physically remove the entity from the database.
3. **Execution**: Uses `ServiceOperationExecutor.executeVoid()` to wrap the deletion operation, providing consistent error handling and logging.

**Exceptions:**

| Exception | Condition |
|-----------|-----------|
| `ResourceNotFoundException` | Thrown if no game exists with the given ID |
| `AccessDeniedException` | Thrown if the current user does not have the `ADMIN` authority |

**Example Usage:**

```java
@Autowired
private HardDeleteGameService hardDeleteGameService;

public void deleteGame(UUID gameId) {
    hardDeleteGameService.execute(gameId);
    // Game is permanently removed from the database
}
```

## Security

- **Authorization**: The `@PreAuthorize("hasAuthority('ADMIN')")` annotation ensures only users with the `ADMIN` authority can invoke this method.
- **Auditing**: The `@Auditable` annotation automatically logs the deletion event, capturing the action type (`GAME_HARD_DELETED`), resource type (`GAME`), and the ID of the deleted game.

## Transaction Management

The `@Transactional` annotation ensures that the deletion operation is executed within a database transaction. If any exception occurs during the process, the transaction is rolled back, preventing partial deletions or inconsistent data states.
