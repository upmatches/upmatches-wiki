## Purpose

The `CreateGameRequest` class is a Java record used to encapsulate the data required to create a new game request within the application. It ensures that all necessary fields are provided and validated according to specified constraints. This class is part of the `com.upmatches.app.features.game.requests` package and utilizes various validation annotations to enforce data integrity.

## Public Methods

Since `CreateGameRequest` is a record, it automatically provides a constructor, accessor methods, `equals()`, `hashCode()`, and `toString()` methods. Below is a table documenting the parameters of the record:

| Parameter         | Type           | Description                                                                                     |
|-------------------|----------------|-------------------------------------------------------------------------------------------------|
| `activityId`      | `UUID`         | Unique identifier for the activity. Must not be null.                                           |
| `venueId`         | `Long`         | Unique identifier for the venue. Must not be null.                                              |
| `skillLevelFromId`| `Long`         | Identifier for the starting skill level. Must not be null.                                      |
| `skillLevelToId`  | `Long`         | Identifier for the ending skill level. Must not be null.                                        |
| `currency`        | `String`       | Currency code in 3-letter ISO-4217 format. Must not be null and must match the pattern.         |
| `price`           | `BigDecimal`   | Price of the game. Must not be null, must be >= 0, and have at most 8 digits and 2 decimals.    |
| `pricing`         | `PricingRequest`| Pricing details. Must be valid if provided.                                                    |
| `slots`           | `Integer`      | Number of slots available. Must not be null, must be between 1 and 100 inclusive.               |
| `startTime`       | `Instant`      | Start time of the game. Must not be null.                                                       |
| `endTime`         | `Instant`      | End time of the game. Must not be null.                                                         |
| `visibility`      | `GameVisibility`| Visibility setting for the game. Must not be null.                                             |
| `gameType`        | `GameType`     | Type of the game. Must not be null.                                                             |
| `joinAsOrganizer` | `Boolean`      | Indicates if the requester wants to join as an organizer.                                       |
| `remark`          | `String`       | Additional remarks about the game. Must be at most 500 characters.                              |

This class leverages Java's record feature to provide a concise and immutable data structure, ensuring that all fields are initialized and validated upon creation.
