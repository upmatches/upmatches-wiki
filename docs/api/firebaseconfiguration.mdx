# FirebaseConfiguration

The `FirebaseConfiguration` class is a Spring Boot configuration component responsible for initializing the Firebase Messaging SDK within the application. It reads Firebase service account credentials either from a JSON string or a file path, configures the Firebase app, and provides a `FirebaseMessaging` bean for sending push notifications.

## Purpose

- **Conditional Initialization**: Only initializes Firebase if valid credentials are provided (either as a JSON string or a file path).
- **Graceful Degradation**: If credentials are missing or initialization fails, it logs a warning and returns `null` for the `FirebaseMessaging` bean, allowing the application to continue without push notification functionality.
- **Singleton Management**: Ensures only one `FirebaseApp` instance is created per JVM, reusing an existing one if already initialized.

## Dependencies

- `FirebaseProperties` – A configuration properties class (bound via `@EnableConfigurationProperties`) that provides `serviceAccountJson()` and `serviceAccountPath()` methods.
- `GoogleCredentials` – For authenticating with Firebase using the service account.
- `FirebaseMessaging` – The bean produced for sending push notifications.

## Public Methods

### `firebaseMessaging()`

Creates and returns a `FirebaseMessaging` bean.

| Aspect | Details |
|--------|---------|
| **Return Type** | `FirebaseMessaging` (or `null` if disabled) |
| **Description** | Initializes Firebase with the provided credentials and returns a messaging instance. If no credentials are configured, or if initialization fails, returns `null`. |
| **Logging** | Logs at INFO level when disabled or initialized; logs at WARN level on failure. |

**Behavior**:
1. Checks if either `serviceAccountJson` or `serviceAccountPath` is set via `FirebaseProperties`.
2. If neither is set, logs "Firebase service account not configured; push notifications disabled." and returns `null`.
3. Opens an `InputStream` to the credential source (JSON string or file).
4. Builds `FirebaseOptions` with the credentials.
5. Initializes a `FirebaseApp` (reuses existing if already initialized).
6. Returns `FirebaseMessaging.getInstance(app)`.
7. On `IOException`, logs the error and returns `null`.

## Private Methods

### `openCredentialStream()`

Opens an `InputStream` for the service account credentials.

| Aspect | Details |
|--------|---------|
| **Return Type** | `InputStream` |
| **Parameters** | None |
| **Throws** | `IOException` if the file cannot be read |
| **Description** | Returns a `ByteArrayInputStream` if `properties.hasJson()` is true, otherwise returns a `FileInputStream` for the path from `properties.serviceAccountPath()`. |

## Configuration Properties

The class relies on `FirebaseProperties` which should define:

| Property | Type | Description |
|----------|------|-------------|
| `serviceAccountJson` | `String` | The full JSON content of the Firebase service account key. |
| `serviceAccountPath` | `String` | File system path to the service account JSON file. |

**Note**: At least one of these must be provided for Firebase to initialize.

## Usage Example

```java
// In application.yml or application.properties:
firebase:
  service-account-json: "{ \"type\": \"service_account\", ... }"
  # OR
  service-account-path: "/path/to/serviceAccountKey.json"
```

The `FirebaseMessaging` bean can then be injected into any Spring component:

```java
@Service
public class NotificationService {
    private final FirebaseMessaging firebaseMessaging;

    public NotificationService(FirebaseMessaging firebaseMessaging) {
        this.firebaseMessaging = firebaseMessaging;
    }

    public void sendNotification(Message message) {
        if (firebaseMessaging != null) {
            // Send push notification
        }
    }
}
```

## Logging

| Condition | Log Level | Message |
|-----------|-----------|---------|
| No credentials configured | INFO | "Firebase service account not configured; push notifications disabled." |
| Initialization successful | INFO | "Firebase initialized from {source}; push notifications enabled." (source is "service account JSON" or "service account file") |
| Initialization failed | WARN | "Failed to initialize Firebase; push notifications disabled: {error message}" |
