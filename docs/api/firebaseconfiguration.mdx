# FirebaseConfiguration

The `FirebaseConfiguration` class is a Spring Boot configuration component responsible for initializing the Firebase Messaging service within the application. It reads Firebase service account credentials either from a JSON string or a file path, configures the Firebase SDK, and provides a `FirebaseMessaging` bean for sending push notifications.

## Purpose

- **Conditional Initialization**: Only initializes Firebase if valid credentials are provided (either as a JSON string or a file path).
- **Graceful Degradation**: If credentials are missing or initialization fails, it logs a warning and returns `null` instead of throwing an exception, allowing the application to continue running without push notification capabilities.
- **Singleton Management**: Reuses an existing `FirebaseApp` instance if one has already been initialized, preventing duplicate initialization errors.

## Dependencies

- `FirebaseProperties` – A configuration properties class (bound via `@EnableConfigurationProperties`) that provides the service account JSON string or file path.
- `GoogleCredentials` – Used to authenticate with Firebase.
- `FirebaseMessaging` – The bean produced for sending push notifications.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `firebaseMessaging()` | `FirebaseMessaging` | Creates and returns a `FirebaseMessaging` bean. Returns `null` if credentials are missing or initialization fails. |

### `firebaseMessaging()`

This method is the core bean definition. It performs the following steps:

1. **Check Credentials**: Verifies whether the `FirebaseProperties` instance contains a service account JSON string (`hasJson()`) or a file path (`hasPath()`). If neither is present, it logs a message and returns `null`.
2. **Open Credential Stream**: Calls `openCredentialStream()` to obtain an `InputStream` for the credentials.
3. **Build Firebase Options**: Creates a `FirebaseOptions` object with the credentials from the stream.
4. **Initialize Firebase App**: Checks if any `FirebaseApp` instances already exist. If not, it initializes a new one; otherwise, it retrieves the existing instance.
5. **Return FirebaseMessaging**: Creates and returns a `FirebaseMessaging` instance associated with the initialized app.
6. **Error Handling**: If an `IOException` occurs during stream opening or Firebase initialization, it logs a warning and returns `null`.

## Private Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `openCredentialStream()` | `InputStream` | Opens an `InputStream` to the service account credentials. If `properties.hasJson()` is true, it returns a `ByteArrayInputStream` from the JSON string. Otherwise, it returns a `FileInputStream` from the file path. |

## Configuration Properties

The class relies on `FirebaseProperties` which should define the following:

| Property | Type | Description |
|----------|------|-------------|
| `serviceAccountJson` | `String` | The Firebase service account credentials as a JSON string. |
| `serviceAccountPath` | `String` | The file system path to the Firebase service account JSON file. |

## Usage Example

```java
// In application.yml or application.properties
firebase:
  service-account-json: "{ \"type\": \"service_account\", ... }"
  # OR
  service-account-path: "/path/to/firebase-service-account.json"
```

The `FirebaseMessaging` bean can then be injected into any Spring component:

```java
@Service
public class NotificationService {
    private final FirebaseMessaging firebaseMessaging;

    public NotificationService(FirebaseMessaging firebaseMessaging) {
        this.firebaseMessaging = firebaseMessaging;
    }

    public void sendNotification(String token, String title, String body) {
        if (firebaseMessaging == null) {
            // Firebase not configured, handle gracefully
            return;
        }
        // Send notification using firebaseMessaging
    }
}
```

## Logging Behavior

| Condition | Log Level | Message |
|-----------|-----------|---------|
| No credentials configured | INFO | "Firebase service account not configured; push notifications disabled." |
| Initialization successful | INFO | "Firebase initialized from service account JSON/file; push notifications enabled." |
| Initialization failed | WARN | "Failed to initialize Firebase; push notifications disabled: {error message}" |

## Notes

- The class uses `@Configuration` and `@EnableConfigurationProperties` to integrate with Spring's dependency injection.
- The `FirebaseMessaging` bean can be `null` if Firebase is not configured, so consumers should perform null checks.
- The `openCredentialStream()` method uses try-with-resources to ensure the stream is properly closed after use.
