## Purpose

The `FirebaseConfiguration` class is a Spring configuration class responsible for setting up Firebase Messaging within a Java application. It leverages the `FirebaseProperties` to configure Firebase using either a JSON string or a file path for the service account credentials. This setup enables the application to send push notifications via Firebase Cloud Messaging (FCM).

## Public Methods

### `firebaseMessaging`

This method initializes and provides a `FirebaseMessaging` bean, which is used to interact with Firebase Cloud Messaging services.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      | N/A  | This method does not take any parameters. |

| Return Type          | Description                                                                 |
|----------------------|-----------------------------------------------------------------------------|
| `FirebaseMessaging`  | Returns an instance of `FirebaseMessaging` if initialization is successful. |
| `null`               | Returns `null` if Firebase service account is not configured or initialization fails. |

## Method Details

- **Initialization Check**: The method first checks if the service account credentials are available either as a JSON string or a file path. If neither is available, it logs a message and returns `null`, indicating that push notifications are disabled.
  
- **Credential Stream**: It uses the `openCredentialStream` private method to obtain an `InputStream` for the service account credentials. This stream is then used to create `GoogleCredentials`.

- **Firebase Options**: The method builds `FirebaseOptions` using the credentials and initializes a `FirebaseApp`. If an app is already initialized, it retrieves the existing instance.

- **Logging**: It logs the source of the credentials (JSON or file) upon successful initialization or logs an error message if initialization fails.

## Private Methods

### `openCredentialStream`

This private method opens an `InputStream` for the service account credentials based on the configuration provided in `FirebaseProperties`.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      | N/A  | This method does not take any parameters. |

| Return Type | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `InputStream` | Returns an `InputStream` for the service account credentials. |

- **JSON Credentials**: If the credentials are provided as a JSON string, it converts the string into a byte array and returns a `ByteArrayInputStream`.

- **File Credentials**: If the credentials are provided as a file path, it opens a `FileInputStream` for the specified path.

- **Exception Handling**: Throws `IOException` if there is an issue accessing the credentials.
