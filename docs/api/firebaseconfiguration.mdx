## Purpose

The `FirebaseConfiguration` class is a Spring configuration class responsible for setting up Firebase Messaging within an application. It utilizes the `FirebaseProperties` to configure Firebase using either a service account JSON string or a file path. This configuration enables the application to send push notifications via Firebase Cloud Messaging (FCM).

## Public Methods

### `firebaseMessaging`

This method initializes and provides a `FirebaseMessaging` bean, which is used to send messages to devices through Firebase Cloud Messaging.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type        | Description                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| `FirebaseMessaging`| Returns an instance of `FirebaseMessaging` if initialization is successful. Returns `null` if the Firebase service account is not configured or if initialization fails. |

## Method Details

- **`firebaseMessaging`**: 
  - **Purpose**: Initializes the Firebase Messaging service using credentials provided in the `FirebaseProperties`.
  - **Behavior**: 
    - Checks if the service account credentials are provided either as a JSON string or a file path.
    - Initializes the `FirebaseApp` and retrieves the `FirebaseMessaging` instance.
    - Logs the initialization status.
    - Returns `null` if the credentials are not provided or if an exception occurs during initialization.

## Private Methods

### `openCredentialStream`

This private method opens an input stream to the service account credentials, either from a JSON string or a file path.

| Parameter | Type | Description |
|-----------|------|-------------|
| None      |      |             |

| Return Type | Description                                                                 |
|-------------|-----------------------------------------------------------------------------|
| `InputStream`| Returns an `InputStream` to the service account credentials. Throws `IOException` if an error occurs while opening the stream. |

## Logging

The class uses SLF4J for logging various states of the Firebase initialization process:

- **`LOG_DISABLED`**: Logs when the Firebase service account is not configured.
- **`LOG_INIT_FAILED`**: Logs when initialization fails due to an exception.
- **`LOG_INITIALIZED`**: Logs successful initialization of Firebase, indicating the source of the credentials (JSON or file).
