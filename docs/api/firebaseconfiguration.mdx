# FirebaseConfiguration

The `FirebaseConfiguration` class is a Spring Boot configuration component responsible for initializing the Firebase Messaging service within the application. It reads Firebase service account credentials either from a JSON string or a file path, configures the Firebase SDK, and exposes a `FirebaseMessaging` bean for use throughout the application.

## Purpose

This class provides a centralized, conditional setup for Firebase Cloud Messaging (FCM). It ensures that:

- Firebase is only initialized when valid credentials are provided.
- The application can gracefully degrade (push notifications disabled) if credentials are missing or invalid.
- Credentials can be supplied either as an inline JSON string or as a file path, offering flexibility for different deployment environments.

## Dependencies

- **Spring Boot**: Uses `@Configuration` and `@EnableConfigurationProperties` to integrate with the application context.
- **Firebase Admin SDK**: Leverages `GoogleCredentials`, `FirebaseOptions`, `FirebaseApp`, and `FirebaseMessaging`.
- **SLF4J**: For logging initialization status and errors.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `firebaseMessaging()` | `FirebaseMessaging` | Creates and returns a `FirebaseMessaging` bean. Returns `null` if credentials are not configured or initialization fails. |

### `firebaseMessaging()`

This is the primary bean method that orchestrates Firebase initialization.

**Behavior:**

1. **Check Credential Availability**: If neither `serviceAccountJson` nor `serviceAccountPath` is provided in the `FirebaseProperties`, it logs a message indicating push notifications are disabled and returns `null`.

2. **Open Credential Stream**: Calls `openCredentialStream()` to obtain an `InputStream` of the service account JSON.

3. **Build Firebase Options**: Creates a `FirebaseOptions` object with the credentials from the stream.

4. **Initialize Firebase App**: 
   - If no Firebase apps have been initialized yet, it creates a new default app.
   - Otherwise, it retrieves the existing default instance.

5. **Return FirebaseMessaging**: Obtains and returns the `FirebaseMessaging` instance associated with the initialized app.

6. **Error Handling**: If an `IOException` occurs during stream opening or Firebase initialization, it logs a warning and returns `null`.

**Parameters:** None

**Returns:** 
- `FirebaseMessaging` instance if initialization succeeds.
- `null` if credentials are missing or initialization fails.

## Private Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `openCredentialStream()` | `InputStream` | Opens an input stream to the service account credentials. Prefers JSON string over file path. |

### `openCredentialStream()`

**Behavior:**

- If `properties.hasJson()` returns `true`, it creates a `ByteArrayInputStream` from the JSON string.
- Otherwise, it creates a `FileInputStream` from the file path specified in `properties.serviceAccountPath()`.

**Throws:** `IOException` if the file cannot be read.

## Configuration Properties

The class relies on `FirebaseProperties` for credential configuration. Expected properties include:

| Property | Type | Description |
|----------|------|-------------|
| `serviceAccountJson` | `String` | Inline JSON content of the Firebase service account key. |
| `serviceAccountPath` | `String` | File system path to the Firebase service account JSON file. |

## Logging

The class uses SLF4J logging to provide visibility into the initialization process:

- **INFO**: When Firebase is successfully initialized, indicating the source (JSON or file).
- **INFO**: When credentials are not configured, indicating push notifications are disabled.
- **WARN**: When initialization fails due to an `IOException`, including the error message.

## Usage Example

```java
// The FirebaseMessaging bean is automatically available for injection
@Service
public class NotificationService {
    private final FirebaseMessaging firebaseMessaging;

    public NotificationService(FirebaseMessaging firebaseMessaging) {
        this.firebaseMessaging = firebaseMessaging;
    }

    public void sendNotification(String token, String title, String body) {
        if (firebaseMessaging == null) {
            // Handle disabled state
            return;
        }
        // Send message using firebaseMessaging
    }
}
```

## Notes

- The bean returns `null` when Firebase is not configured, so consuming code should handle null checks.
- The class is thread-safe as it uses no mutable shared state.
- Credentials are read once at application startup; changes to the credential file or JSON require a restart.
