## Overview

The `AppleLoginRequest` class is a Java record used to encapsulate the data required for authenticating a user via Apple's Sign In with Apple service. It is part of the `com.upmatches.app.features.auth.requests` package and is designed to be used in REST API request bodies.

This record leverages Jakarta Bean Validation annotations to enforce constraints on the input fields, ensuring that the identity token and user identifier are provided and that all string fields do not exceed specified maximum lengths.

## Record Definition

```java
public record AppleLoginRequest(
    @NotBlank @Size(max = 4096) String identityToken,
    @Size(max = 1024) String authorizationCode,
    @NotBlank @Size(max = 256) String userIdentifier,
    @Size(max = 200) String displayName,
    @Size(max = 320) String email)
```

## Fields

| Field              | Type   | Constraints                          | Description                                                                 |
|--------------------|--------|--------------------------------------|-----------------------------------------------------------------------------|
| `identityToken`    | String | `@NotBlank`, `@Size(max = 4096)`     | The JSON Web Token (JWT) provided by Apple after user authentication.       |
| `authorizationCode`| String | `@Size(max = 1024)`                  | A one-time authorization code from Apple, used for server-side validation.  |
| `userIdentifier`   | String | `@NotBlank`, `@Size(max = 256)`      | The unique user identifier provided by Apple for the authenticated user.    |
| `displayName`      | String | `@Size(max = 200)`                   | The user's display name as provided by Apple (optional).                    |
| `email`            | String | `@Size(max = 320)`                   | The user's email address as provided by Apple (optional).                   |

## Methods

### `toString()`

```java
@Override
public String toString()
```

**Description:** Overrides the default `toString()` method to return a masked string representation of the request, hiding sensitive information for security purposes.

**Returns:** A string in the format `AppleLoginRequest[identityToken=***,userIdentifier=***]`.

## Usage Example

```java
AppleLoginRequest request = new AppleLoginRequest(
    "eyJraWQiOiJ...",  // identityToken
    "authorization_code_123",  // authorizationCode
    "user_identifier_456",  // userIdentifier
    "John Doe",  // displayName
    "john.doe@example.com"  // email
);

// The toString() method will output:
// AppleLoginRequest[identityToken=***,userIdentifier=***]
System.out.println(request.toString());
```

## Security Considerations

- The `toString()` method is overridden to prevent accidental logging of sensitive tokens and identifiers.
- The `identityToken` and `userIdentifier` fields are masked in the string representation.
- All fields have maximum length constraints to prevent potential denial-of-service attacks through excessively large inputs.
