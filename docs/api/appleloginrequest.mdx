## Overview

The `AppleLoginRequest` class is a Java record used to encapsulate the data required for an Apple login request. It is part of the `com.upmatches.app.features.auth.requests` package and utilizes Jakarta Bean Validation annotations to enforce constraints on its fields. This class is designed to handle authentication requests by storing essential information such as the identity token, authorization code, user identifier, display name, and email.

## Class Definition

The `AppleLoginRequest` class is defined as a record, which is a special kind of class in Java that is immutable and provides a concise syntax for creating data-carrying classes.

## Public Methods

The `AppleLoginRequest` class provides the following public methods:

| Method Signature | Description |
|------------------|-------------|
| `String toString()` | Returns a masked string representation of the `AppleLoginRequest` object, hiding sensitive information such as the identity token and user identifier. |

## Fields

The fields of the `AppleLoginRequest` record are defined with specific validation constraints to ensure data integrity:

| Field Name       | Type   | Constraints                           | Description |
|------------------|--------|---------------------------------------|-------------|
| `identityToken`  | String | `@NotBlank`, `@Size(max = 4096)`      | The identity token provided by Apple for authentication. Must not be blank and can have a maximum length of 4096 characters. |
| `authorizationCode` | String | `@Size(max = 1024)`                | The authorization code received from Apple. Can have a maximum length of 1024 characters. |
| `userIdentifier` | String | `@NotBlank`, `@Size(max = 256)`      | A unique identifier for the user. Must not be blank and can have a maximum length of 256 characters. |
| `displayName`    | String | `@Size(max = 200)`                   | The display name of the user. Can have a maximum length of 200 characters. |
| `email`          | String | `@Size(max = 320)`                   | The email address of the user. Can have a maximum length of 320 characters. |

## Usage

The `AppleLoginRequest` class is typically used in authentication workflows where an application needs to process login requests using Apple's authentication services. The validation constraints ensure that the data provided meets the expected format and size requirements, enhancing the security and reliability of the authentication process.
