## Overview

The `AppleLoginRequest` class is a Java record that encapsulates the data required to authenticate a user via Apple's Sign In with Apple (SIWA) flow. It is used as a request DTO (Data Transfer Object) in the authentication module of the UpMatches application.

This record ensures that incoming login requests contain the mandatory fields (`identityToken` and `userIdentifier`) while allowing optional fields (`authorizationCode`, `displayName`, `email`) to be provided. It also includes validation constraints to enforce data integrity and size limits.

## Record Definition

```java
public record AppleLoginRequest(
    @NotBlank @Size(max = 4096) String identityToken,
    @Size(max = 1024) String authorizationCode,
    @NotBlank @Size(max = 256) String userIdentifier,
    @Size(max = 200) String displayName,
    @Size(max = 320) String email
)
```

## Fields

| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| `identityToken` | `String` | Yes | `@NotBlank`, max 4096 characters | The JWT identity token provided by Apple after user authentication. |
| `authorizationCode` | `String` | No | max 1024 characters | The authorization code returned by Apple (used for server-side verification). |
| `userIdentifier` | `String` | Yes | `@NotBlank`, max 256 characters | Apple's unique identifier for the user. |
| `displayName` | `String` | No | max 200 characters | The user's display name as provided by Apple (optional). |
| `email` | `String` | No | max 320 characters | The user's email address as provided by Apple (optional). |

## Methods

### `toString()`

```java
@Override
public String toString()
```

**Description:** Overrides the default record `toString()` method to mask sensitive information. Returns a fixed string that hides the actual values of `identityToken` and `userIdentifier` for security purposes.

**Returns:** `String` - The masked representation: `AppleLoginRequest[identityToken=***,userIdentifier=***]`

## Usage Example

```java
// Creating a new Apple login request
AppleLoginRequest request = new AppleLoginRequest(
    "eyJraWQiOiJh...",           // identityToken (required)
    "authorization_code_123",     // authorizationCode (optional)
    "000123.abc...",              // userIdentifier (required)
    "John Doe",                   // displayName (optional)
    "john.doe@example.com"        // email (optional)
);

// Logging the request (sensitive data is masked)
System.out.println(request);
// Output: AppleLoginRequest[identityToken=***,userIdentifier=***]
```

## Validation Notes

- The `identityToken` and `userIdentifier` fields are mandatory and must not be blank.
- All string fields have maximum length constraints to prevent excessively large payloads.
- The `authorizationCode`, `displayName`, and `email` fields are optional and can be `null` or empty.
- Validation is typically performed using Jakarta Bean Validation (e.g., in a Spring Boot controller with `@Valid` annotation).
