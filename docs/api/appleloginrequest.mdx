# AppleLoginRequest

The `AppleLoginRequest` class is a Java record that represents the data transfer object (DTO) for handling Apple Sign-In authentication requests. It encapsulates the essential fields required to authenticate a user via Apple's identity service, including the identity token, authorization code, user identifier, and optional user profile information.

## Purpose

This record serves as the request payload for Apple Sign-In authentication endpoints. It ensures that incoming requests contain the necessary credentials (identity token and user identifier) while providing optional fields for user display name and email. The record also implements a secure `toString()` method that masks sensitive information to prevent accidental exposure of tokens in logs.

## Record Definition

```java
public record AppleLoginRequest(
    @NotBlank @Size(max = 4096) String identityToken,
    @Size(max = 1024) String authorizationCode,
    @NotBlank @Size(max = 256) String userIdentifier,
    @Size(max = 200) String displayName,
    @Size(max = 320) String email)
```

## Fields

| Field | Type | Validation | Description |
|-------|------|------------|-------------|
| `identityToken` | `String` | `@NotBlank`, `@Size(max = 4096)` | The Apple identity token (JWT) provided by the Apple authentication service. Required and must not exceed 4096 characters. |
| `authorizationCode` | `String` | `@Size(max = 1024)` | The authorization code returned by Apple during the sign-in flow. Optional, maximum 1024 characters. |
| `userIdentifier` | `String` | `@NotBlank`, `@Size(max = 256)` | The unique user identifier provided by Apple. Required and must not exceed 256 characters. |
| `displayName` | `String` | `@Size(max = 200)` | The user's display name as provided by Apple. Optional, maximum 200 characters. |
| `email` | `String` | `@Size(max = 320)` | The user's email address as provided by Apple. Optional, maximum 320 characters (standard email length limit). |

## Methods

### `toString()`

```java
@Override
public String toString()
```

Returns a masked string representation of the request object to prevent sensitive data leakage in logs.

**Returns:** `String` - A masked string in the format `AppleLoginRequest[identityToken=***,userIdentifier=***]`

**Security Note:** The `toString()` method explicitly masks the `identityToken` and `userIdentifier` fields to prevent accidental exposure of sensitive authentication credentials in application logs, error messages, or debugging output.

## Usage Example

```java
// Creating a new Apple login request
AppleLoginRequest request = new AppleLoginRequest(
    "eyJraWQiOiJ...",  // identityToken (required)
    "authorization_code_123",  // authorizationCode (optional)
    "user_identifier_456",  // userIdentifier (required)
    "John Doe",  // displayName (optional)
    "john.doe@example.com"  // email (optional)
);

// The toString() method will output a masked version
System.out.println(request.toString());
// Output: AppleLoginRequest[identityToken=***,userIdentifier=***]
```

## Validation Constraints

The record uses Jakarta Bean Validation annotations to enforce data integrity:

- **`@NotBlank`**: Ensures the field is not null and contains at least one non-whitespace character
- **`@Size(max = ...)`**: Limits the maximum length of the string field

These constraints help prevent malformed requests from reaching the application logic and protect against potential security vulnerabilities such as buffer overflow attacks.
