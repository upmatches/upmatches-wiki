## Purpose

The `RefreshRequest` class is a part of the `com.upmatches.app.features.auth.requests` package. It is designed to encapsulate a request for refreshing authentication tokens. This class uses Java's `record` feature to define an immutable data structure with a single field, `refreshToken`, which is validated to ensure it is not blank.

## Public Methods

The `RefreshRequest` class provides the following public methods:

| Method Signature | Description |
| ---------------- | ----------- |
| `String toString()` | Overrides the default `toString` method to return a masked representation of the `RefreshRequest` object, ensuring that the sensitive `refreshToken` is not exposed in logs or other outputs. |

## Parameters

The `RefreshRequest` class has the following parameter:

| Parameter Name | Type   | Description                           |
| -------------- | ------ | ------------------------------------- |
| `refreshToken` | String | A non-blank string representing the refresh token required for authentication. |

## Return Types

The `toString` method returns a `String` type, providing a masked representation of the `RefreshRequest` instance.
