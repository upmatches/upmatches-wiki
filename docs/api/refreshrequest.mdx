# RefreshRequest

The `RefreshRequest` class is a Java record used to encapsulate the data required for a token refresh operation in the authentication module. It ensures that the refresh token is not blank through Jakarta Bean Validation annotations.

## Purpose

This record serves as a Data Transfer Object (DTO) for refresh token requests. It provides a secure way to handle refresh tokens by masking the token value in the `toString()` method to prevent accidental exposure in logs or error messages.

## Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `refreshToken` | `String` | The refresh token used to obtain new access tokens. Must not be blank. |

## Validation

The `refreshToken` field is annotated with `@NotBlank`, ensuring that:
- The value is not null
- The value contains at least one non-whitespace character

## Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `toString()` | `String` | Returns a masked representation of the request, hiding the actual refresh token value. |

## Usage Example

```java
RefreshRequest request = new RefreshRequest("eyJhbGciOiJIUzI1NiIs...");
System.out.println(request.toString()); // Output: RefreshRequest[refreshToken=***]
```

## Security Considerations

The `toString()` method is overridden to return a masked string (`RefreshRequest[refreshToken=***]`) instead of the actual token value. This prevents sensitive token data from being exposed in:
- Application logs
- Debug output
- Error messages
- Monitoring systems
