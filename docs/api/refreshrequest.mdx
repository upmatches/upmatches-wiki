# RefreshRequest

The `RefreshRequest` class is a Java record used for encapsulating the refresh token data sent in authentication refresh requests. It ensures that the refresh token is not blank through Jakarta Bean Validation annotations and provides a secure `toString()` implementation that masks the actual token value for logging and debugging purposes.

## Record Definition

```java
public record RefreshRequest(@NotBlank String refreshToken)
```

The record has a single component:
- `refreshToken`: The JWT refresh token string, validated to be non-blank using the `@NotBlank` annotation from Jakarta Bean Validation.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `refreshToken()` | `String` | Returns the refresh token value (auto-generated getter from record) |
| `toString()` | `String` | Returns a masked representation of the request, hiding the actual token value |

## Method Details

### `toString()`

```java
@Override
public String toString()
```

Returns a masked string representation of the `RefreshRequest` object. The actual refresh token value is replaced with `***` to prevent sensitive data exposure in logs or debugging output.

**Returns:** A string in the format `RefreshRequest[refreshToken=***]`

## Usage Example

```java
// Creating a refresh request
RefreshRequest request = new RefreshRequest("eyJhbGciOiJIUzI1NiJ9...");

// Accessing the token
String token = request.refreshToken();

// Safe logging - token is masked
System.out.println(request.toString());
// Output: RefreshRequest[refreshToken=***]
```

## Validation

The `@NotBlank` annotation ensures that:
- The `refreshToken` cannot be `null`
- The `refreshToken` cannot be an empty string
- The `refreshToken` cannot contain only whitespace characters

This validation is enforced when the object is processed by a Jakarta Bean Validation validator, typically in a Spring Boot controller or service layer.
