# RefreshRequest

The `RefreshRequest` class is a Java record used to encapsulate the data required for refreshing an authentication token. It ensures that the refresh token is not blank through Jakarta Bean Validation annotations.

## Purpose

This record serves as a Data Transfer Object (DTO) for authentication refresh requests. It contains a single field, `refreshToken`, which must be provided and cannot be blank. The record overrides the default `toString()` method to mask the sensitive token value for security purposes.

## Record Definition

```java
public record RefreshRequest(@NotBlank String refreshToken)
```

## Constructor Parameters

| Parameter | Type | Validation | Description |
|-----------|------|------------|-------------|
| `refreshToken` | `String` | `@NotBlank` | The refresh token used to obtain a new access token |

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `refreshToken()` | `String` | Returns the refresh token value |
| `toString()` | `String` | Returns a masked representation of the request, hiding the actual token value |

## Security Considerations

The `toString()` method is overridden to prevent accidental exposure of the refresh token in logs or debugging output. The masked string format is:

```
RefreshRequest[refreshToken=***]
```

This ensures that sensitive authentication credentials are not leaked through standard Java string representations.
