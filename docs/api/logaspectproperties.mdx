import com.upmatches.app.shared.logging.constants.AspectConstant;
import org.springframework.boot.context.properties.ConfigurationProperties;

## Overview

The `LogAspectProperties` class is a configuration properties holder used in a Spring Boot application. It is designed to manage logging aspect properties, specifically focusing on the threshold for slow execution logging. This class utilizes Spring Boot's `@ConfigurationProperties` to bind external configuration properties to a strongly typed Java object.

## Purpose

The primary purpose of the `LogAspectProperties` class is to encapsulate the configuration for logging aspects, particularly the threshold for what is considered a "slow execution" in milliseconds. This allows for centralized and easily configurable logging behavior in the application.

## Constructor

The constructor of the `LogAspectProperties` class ensures that the `slowExecutionThresholdMs` is set to a valid value. If the provided value is `null` or less than or equal to zero, it defaults to a predefined constant value from `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS`.

## Public Methods

The `LogAspectProperties` class is a record, which means it primarily consists of a constructor and accessor methods for its fields. Below is a documentation of its public methods:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `slowExecutionThresholdMs()` | None | `Long` | Returns the threshold in milliseconds for logging slow executions. |

## Usage

This class is typically used in a Spring Boot application where logging configurations need to be externalized and easily adjustable. By using the `@ConfigurationProperties` annotation, it allows the application to bind properties from external configuration files (such as `application.yml` or `application.properties`) to this class, making it flexible and maintainable.
