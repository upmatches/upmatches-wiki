# LogAspectProperties

The `LogAspectProperties` class is a Spring Boot configuration properties record that manages logging aspect configuration for the application. It provides a centralized way to configure the threshold for detecting slow method executions in the logging aspect.

## Purpose

This class serves as a configuration holder for the logging aspect's behavior, specifically defining what constitutes a "slow" method execution. It uses Spring Boot's `@ConfigurationProperties` annotation to bind properties from the application configuration files (e.g., `application.yml` or `application.properties`) with the prefix `app.logging.aspect`.

## Configuration Properties

| Property | Type | Default Value | Description |
|----------|------|---------------|-------------|
| `slowExecutionThresholdMs` | `Long` | `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS` | The threshold in milliseconds above which a method execution is considered slow |

## Constructor

The record provides a compact constructor that validates and sets the default value for `slowExecutionThresholdMs`:

```java
public LogAspectProperties {
    if (slowExecutionThresholdMs == null || slowExecutionThresholdMs <= 0) {
        slowExecutionThresholdMs = AspectConstant.SLOW_EXECUTION_THRESHOLD_MS;
    }
}
```

### Validation Logic
- If the provided `slowExecutionThresholdMs` is `null` or less than or equal to `0`, the constructor automatically falls back to the default value defined in `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS`
- This ensures that the logging aspect always has a valid threshold value, preventing configuration errors

## Usage

To configure the slow execution threshold in your application, add the following property to your `application.yml` or `application.properties`:

**application.yml:**
```yaml
app:
  logging:
    aspect:
      slow-execution-threshold-ms: 5000
```

**application.properties:**
```properties
app.logging.aspect.slow-execution-threshold-ms=5000
```

## Dependencies

- **Spring Boot**: Uses `@ConfigurationProperties` annotation for property binding
- **AspectConstant**: References the default threshold value from the constants class

## Example

```java
// Accessing the configured threshold
LogAspectProperties properties = new LogAspectProperties(3000L);
Long threshold = properties.slowExecutionThresholdMs(); // Returns 3000

// Using default value when invalid
LogAspectProperties defaultProperties = new LogAspectProperties(null);
Long defaultThreshold = defaultProperties.slowExecutionThresholdMs(); // Returns AspectConstant.SLOW_EXECUTION_THRESHOLD_MS
```
