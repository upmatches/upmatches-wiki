# LogAspectProperties

## Purpose

The `LogAspectProperties` class is a Spring Boot configuration properties record that manages logging aspect configuration for the application. It provides a centralized way to configure the slow execution threshold for logging aspects, with a default fallback value defined in `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS`.

This record is bound to the `app.logging.aspect` prefix in application properties files (e.g., `application.yml` or `application.properties`), allowing external configuration of logging behavior without code changes.

## Constructor

The compact constructor validates and normalizes the `slowExecutionThresholdMs` parameter. If the provided value is `null` or less than or equal to zero, it defaults to the constant value defined in `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS`.

## Configuration Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `app.logging.aspect.slow-execution-threshold-ms` | `Long` | `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS` | The threshold in milliseconds for considering a method execution as "slow". When a method's execution time exceeds this value, the aspect will log a warning or perform configured slow execution handling. |

## Public Methods

Since `LogAspectProperties` is a Java record, it automatically provides the following public methods:

| Method | Return Type | Description |
|--------|-------------|-------------|
| `slowExecutionThresholdMs()` | `Long` | Returns the configured slow execution threshold in milliseconds. This value is guaranteed to be non-null and positive after construction. |
| `toString()` | `String` | Returns a string representation of the record, including the `slowExecutionThresholdMs` value. |
| `equals(Object o)` | `boolean` | Compares this record to another object for equality based on the `slowExecutionThresholdMs` field. |
| `hashCode()` | `int` | Returns a hash code value for this record based on the `slowExecutionThresholdMs` field. |

## Usage Example

### application.yml
```yaml
app:
  logging:
    aspect:
      slow-execution-threshold-ms: 5000
```

### application.properties
```properties
app.logging.aspect.slow-execution-threshold-ms=5000
```

### Java Usage
```java
@Autowired
private LogAspectProperties logAspectProperties;

public void someMethod() {
    Long threshold = logAspectProperties.slowExecutionThresholdMs();
    // Use threshold for logging aspect configuration
}
```

## Dependencies

- **Spring Boot**: `@ConfigurationProperties` annotation from `org.springframework.boot.context.properties`
- **AspectConstant**: `com.upmatches.app.shared.logging.constants.AspectConstant` for default threshold value
