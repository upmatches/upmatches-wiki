# LogAspectProperties

## Purpose

The `LogAspectProperties` class is a Spring Boot configuration properties record that manages logging aspect configuration for the application. It provides a centralized way to configure the threshold for slow execution detection in logging aspects.

This record is annotated with `@ConfigurationProperties(prefix = "app.logging.aspect")`, allowing configuration values to be set in `application.properties` or `application.yml` files under the `app.logging.aspect` prefix.

## Configuration Properties

| Property | Type | Default Value | Description |
|----------|------|---------------|-------------|
| `app.logging.aspect.slow-execution-threshold-ms` | `Long` | Value from `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS` | The threshold in milliseconds for determining slow execution. If not provided or set to a non-positive value, the default constant value is used. |

## Constructor Behavior

The compact constructor of this record performs validation and fallback logic:

- **Input Validation**: Checks if the provided `slowExecutionThresholdMs` is `null` or less than or equal to `0`
- **Fallback**: If validation fails, the threshold is set to the default value defined in `AspectConstant.SLOW_EXECUTION_THRESHOLD_MS`

## Usage Example

### application.yml
```yaml
app:
  logging:
    aspect:
      slow-execution-threshold-ms: 5000
```

### application.properties
```properties
app.logging.aspect.slow-execution-threshold-ms=5000
```

## Dependencies

- **Spring Boot**: `@ConfigurationProperties` annotation for externalized configuration
- **AspectConstant**: Provides the default threshold value when configuration is invalid or missing

## Notes

- This class is a Java record, providing immutable data carrier with automatic `equals()`, `hashCode()`, and `toString()` methods
- The configuration prefix `app.logging.aspect` must be enabled in the Spring Boot application using `@EnableConfigurationProperties(LogAspectProperties.class)` or through the configuration processor
