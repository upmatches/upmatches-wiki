# StationLineRepository

The `StationLineRepository` interface provides database access operations for the `StationLine` entity. It extends Spring Data JPA's `JpaRepository` to inherit standard CRUD (Create, Read, Update, Delete) functionality, as well as pagination and sorting capabilities.

## Purpose

This repository serves as the data access layer for managing `StationLine` records in the application's venue management system. By extending `JpaRepository`, it automatically provides:

- Basic CRUD operations (save, findById, findAll, delete, etc.)
- Fluent query methods
- Pagination and sorting support
- Batch operations

## Type Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| Entity | `StationLine` | The entity class this repository manages |
| ID | `StationLineId` | The composite primary key type for the entity |

## Inherited Methods

The following methods are inherited from `JpaRepository` and are available for use without additional implementation:

### Basic CRUD Operations

| Method | Return Type | Description |
|--------|-------------|-------------|
| `save(S entity)` | `S` | Saves a given entity. Use the returned instance for further operations |
| `saveAll(Iterable<S> entities)` | `List<S>` | Saves all given entities |
| `findById(ID id)` | `Optional<T>` | Retrieves an entity by its primary key |
| `existsById(ID id)` | `boolean` | Returns whether an entity with the given id exists |
| `findAll()` | `List<T>` | Returns all instances of the type |
| `findAllById(Iterable<ID> ids)` | `List<T>` | Returns all instances with the given IDs |
| `count()` | `long` | Returns the number of entities |
| `deleteById(ID id)` | `void` | Deletes the entity with the given id |
| `delete(T entity)` | `void` | Deletes a given entity |
| `deleteAll(Iterable<? extends T> entities)` | `void` | Deletes all given entities |
| `deleteAll()` | `void` | Deletes all entities managed by the repository |

### Pagination and Sorting

| Method | Return Type | Description |
|--------|-------------|-------------|
| `findAll(Pageable pageable)` | `Page<T>` | Returns a `Page` of entities meeting the paging restriction |
| `findAll(Sort sort)` | `List<T>` | Returns all entities sorted by the given options |

## Usage Example

```java
@Service
public class StationLineService {
    
    private final StationLineRepository stationLineRepository;
    
    public StationLineService(StationLineRepository stationLineRepository) {
        this.stationLineRepository = stationLineRepository;
    }
    
    public StationLine saveStationLine(StationLine stationLine) {
        return stationLineRepository.save(stationLine);
    }
    
    public Optional<StationLine> findById(StationLineId id) {
        return stationLineRepository.findById(id);
    }
    
    public List<StationLine> findAllStationLines() {
        return stationLineRepository.findAll();
    }
    
    public void deleteStationLine(StationLineId id) {
        stationLineRepository.deleteById(id);
    }
}
```

## Notes

- This repository uses a composite primary key (`StationLineId`) rather than a single-field ID
- No custom query methods are defined in this interface; all operations rely on the inherited `JpaRepository` methods
- The repository is part of the `com.upmatches.app.features.venue.repositories` package, indicating it belongs to the venue management feature module
