# GameWebFallbackController

The `GameWebFallbackController` is a Spring REST controller that serves server-rendered HTML pages for game share links. When a user opens a game link in a web browser (instead of the Upmatches mobile app), this controller generates a fallback web page with game details, Open Graph meta tags, and smart app banner support to encourage the user to open the link in the native app.

## Purpose

- Provides a human-readable web page for game share links when opened in a browser
- Handles public, private, and not-found game scenarios
- Generates SEO-friendly meta tags (Open Graph, Twitter Card, canonical URL)
- Includes smart app banner for iOS to deep-link into the Upmatches app
- Escapes all user-generated content to prevent XSS vulnerabilities

## Dependencies

| Dependency | Type | Description |
|------------|------|-------------|
| `IGameLookupService` | Service | Retrieves game entities by ID |
| `IShareLinkUrlBuilder` | Service | Builds mobile deep-link URLs |
| `ShareLinkProperties` | Configuration | Provides app store ID and web base URL |

## Endpoints

### GET `/games/{id}`

Returns an HTML page for a game share link.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `String` (path) | UUID of the game |

**Response:**

| Status | Description |
|--------|-------------|
| `200 OK` | Returns HTML page for public or private game |
| `404 Not Found` | Returns HTML page when game ID is invalid or game not found |

**Response Content-Type:** `text/html`

## Internal Methods

### `publicGamePage(Game game, String appLink, String canonicalUrl)`

Generates an HTML page for a public game with full details.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The public game entity |
| `appLink` | `String` | Deep link URL for the mobile app |
| `canonicalUrl` | `String` | Canonical web URL for the game |

**Returns:** `String` - Complete HTML page

**Page Content:**
- Title: "Join the {activity} game on Upmatches"
- Description: "{venue} · {date/time} · {skill level}"
- Displays: activity, venue, date/time, organizer, skill level, slots, price
- CTA button: "Open in Upmatches"
- Note about downloading the app

### `privateGamePage(String appLink, String canonicalUrl)`

Generates an HTML page for a private game.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `appLink` | `String` | Deep link URL for the mobile app |
| `canonicalUrl` | `String` | Canonical web URL for the game |

**Returns:** `String` - Complete HTML page

**Page Content:**
- Title: "Open in Upmatches"
- Description: "This game is private — open in Upmatches to view it."
- CTA button: "Open in Upmatches"

### `notFoundPage()`

Generates an HTML page when a game is not found or the ID is invalid.

**Returns:** `String` - Complete HTML page

**Page Content:**
- Title: "Game not found"
- Description: "This game may have ended or been removed."

### `basePage(PageMeta meta, String body)`

Builds the complete HTML document with head meta tags and body content.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `meta` | `PageMeta` | Metadata including title, description, canonical URL, and app link |
| `body` | `String` | HTML body content |

**Returns:** `String` - Complete HTML document

**Meta Tags Generated:**
- `<title>` and `<meta name="description">`
- Open Graph: `og:title`, `og:description`, `og:type`, `og:url`
- Twitter Card: `twitter:title`, `twitter:description`, `twitter:card`
- Canonical link (if available)
- Apple smart app banner (if app ID and link are configured)

### `buildSmartAppBanner(String appLink)`

Builds the Apple smart app banner meta tag.

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `appLink` | `String` | Deep link URL for the mobile app |

**Returns:** `String` - Meta tag HTML or empty string if not applicable

## Internal Record

### `PageMeta`

A private record holding page metadata.

| Field | Type | Description |
|-------|------|-------------|
| `title` | `String` | Page title |
| `description` | `String` | Page description |
| `canonicalUrl` | `String` | Canonical URL (nullable) |
| `appLink` | `String` | Mobile app deep link (nullable) |

## Constants

| Constant | Value | Description |
|----------|-------|-------------|
| `DISPLAY_ZONE` | `Asia/Singapore` | Timezone for displaying dates |
| `DATE_TIME_FORMATTER` | `EEE, MMM d · h:mm a` | Date/time display format |
| `TITLE_PUBLIC_PREFIX` | `Join the ` | Prefix for public game page title |
| `TITLE_PUBLIC_SUFFIX` | ` game on Upmatches` | Suffix for public game page title |

## Security Considerations

- All user-generated content (activity name, venue, organizer, etc.) is HTML-escaped using `HtmlUtils.htmlEscape()` to prevent XSS attacks
- Game IDs are validated as UUIDs before processing
- Invalid UUIDs return a 404 page instead of throwing exceptions
