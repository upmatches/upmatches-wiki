# GameWebFallbackController

The `GameWebFallbackController` is a Spring REST controller that serves server-side rendered HTML pages for game share links. When a user opens a game link in a web browser (instead of the Upmatches mobile app), this controller generates a fallback web page with game details, Open Graph meta tags for social sharing, and a smart app banner to encourage users to open the link in the native app.

## Purpose

- **Web Fallback**: Provides a human-readable HTML page when a game share link is opened in a browser.
- **Social Sharing**: Generates Open Graph and Twitter Card meta tags for rich link previews on social media platforms.
- **App Deep Linking**: Includes smart app banner meta tags to prompt users to open the link in the Upmatches mobile app.
- **SEO**: Sets canonical URLs to prevent duplicate content issues.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `IGameLookupService` | Service interface for looking up game entities by ID |
| `IShareLinkUrlBuilder` | Service interface for building mobile deep link URLs |
| `ShareLinkProperties` | Configuration properties containing app store ID and web base URL |

## Public Methods

### `gamePage(String id)`

Handles GET requests to `/games/{id}` and returns an HTML page for the specified game.

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | `String` | The UUID of the game to display |

| Returns | Description |
|---------|-------------|
| `ResponseEntity<String>` | HTTP response with HTML content and appropriate status code |

**Behavior:**
- Parses the `id` parameter as a UUID. Returns a 404 "not found" page if parsing fails.
- Looks up the game using `IGameLookupService`. Returns a 404 "not found" page if the game doesn't exist.
- For public games, renders a detailed page with game information (activity, venue, time, organizer, skill level, slots, price).
- For private games, renders a simplified page indicating the game is private.
- Includes Open Graph, Twitter Card, and canonical URL meta tags.
- Adds an Apple smart app banner for iOS users.

## Private Methods

### `publicGamePage(Game game, String appLink, String canonicalUrl)`

Generates the HTML page for a public game with full details.

| Parameter | Type | Description |
|-----------|------|-------------|
| `game` | `Game` | The game entity to display |
| `appLink` | `String` | The mobile deep link URL |
| `canonicalUrl` | `String` | The canonical URL for SEO |

| Returns | Description |
|---------|-------------|
| `String` | Complete HTML page as a string |

### `privateGamePage(String appLink, String canonicalUrl)`

Generates the HTML page for a private game with limited information.

| Parameter | Type | Description |
|-----------|------|-------------|
| `appLink` | `String` | The mobile deep link URL |
| `canonicalUrl` | `String` | The canonical URL for SEO |

| Returns | Description |
|---------|-------------|
| `String` | Complete HTML page as a string |

### `notFoundPage()`

Generates the HTML page when a game is not found or the ID is invalid.

| Returns | Description |
|---------|-------------|
| `String` | Complete HTML page as a string |

### `basePage(PageMeta meta, String body)`

Builds the complete HTML document with meta tags and body content.

| Parameter | Type | Description |
|-----------|------|-------------|
| `meta` | `PageMeta` | Metadata record containing title, description, canonical URL, and app link |
| `body` | `String` | The HTML body content |

| Returns | Description |
|---------|-------------|
| `String` | Complete HTML document as a string |

### `buildSmartAppBanner(String appLink)`

Constructs the Apple smart app banner meta tag.

| Parameter | Type | Description |
|-----------|------|-------------|
| `appLink` | `String` | The mobile deep link URL |

| Returns | Description |
|---------|-------------|
| `String` | The meta tag HTML string, or empty string if app ID or app link is missing |

## Internal Record

### `PageMeta`

A private record that holds page metadata.

| Field | Type | Description |
|-------|------|-------------|
| `title` | `String` | Page title for HTML and meta tags |
| `description` | `String` | Page description for meta tags |
| `canonicalUrl` | `String` | Canonical URL for SEO (nullable) |
| `appLink` | `String` | Mobile deep link URL (nullable) |
