# IUnregisterDeviceTokenService

The `IUnregisterDeviceTokenService` interface defines the contract for removing a device token from the notification system. This is a sealed interface that restricts implementation to the `UnregisterDeviceTokenService` class, ensuring controlled and secure token deregistration.

## Purpose

When a user logs out, uninstalls the app, or opts out of push notifications, the associated device token must be removed from the server-side notification registry. This interface provides a single method to perform that operation, allowing the system to stop sending push notifications to that specific device.

## Interface Definition

```java
package com.upmatches.app.features.notification.services;

public sealed interface IUnregisterDeviceTokenService permits UnregisterDeviceTokenService {

    void execute(String deviceToken);

}
```

## Method Summary

| Method | Description |
|--------|-------------|
| `execute(String deviceToken)` | Removes the specified device token from the notification system, preventing further push notifications from being sent to that device. |

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `deviceToken` | `String` | The unique device token to be unregistered from the notification service. Must not be null or empty. |

## Implementation Details

- **Sealed Interface**: This interface is sealed and only permits the `UnregisterDeviceTokenService` class to implement it. This design ensures that all token deregistration logic flows through a single, controlled implementation.
- **Return Type**: The `execute` method returns `void`, indicating that the operation is performed as a side effect (e.g., database deletion, API call to notification service).
- **Thread Safety**: Implementations should consider thread safety, as device token unregistration may be called from different threads (e.g., logout flow, background service).

## Usage Example

```java
// Inject or obtain the service implementation
IUnregisterDeviceTokenService unregisterService = new UnregisterDeviceTokenService();

// Unregister a device token
unregisterService.execute("device-token-abc123");
```

## Related Components

- **UnregisterDeviceTokenService**: The sole permitted implementation of this interface.
- **RegisterDeviceTokenService**: The counterpart service for registering new device tokens.
- **NotificationService**: The main service that manages push notification delivery and token lifecycle.
