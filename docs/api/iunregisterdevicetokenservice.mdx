# IUnregisterDeviceTokenService

## Purpose

The `IUnregisterDeviceTokenService` interface defines the contract for unregistering a device token from the notification system. This is a sealed interface that restricts implementation to the `UnregisterDeviceTokenService` class, ensuring controlled and secure token removal.

This interface is part of the notification feature module and is used to invalidate or remove device tokens that are no longer valid or when a user logs out, helping maintain an up-to-date and clean device token registry.

## Interface Definition

```java
public sealed interface IUnregisterDeviceTokenService permits UnregisterDeviceTokenService {
    void execute(String deviceToken);
}
```

## Methods

### `execute`

| Property | Description |
|----------|-------------|
| **Signature** | `void execute(String deviceToken)` |
| **Parameters** | `deviceToken` – The unique device token string to be unregistered from the notification system |
| **Returns** | `void` – This method does not return a value |
| **Description** | Executes the unregistration process for the provided device token. Implementations should handle token removal, database updates, and any necessary cleanup operations |

## Implementation Details

- The interface is declared as `sealed`, meaning only the specified permitted class (`UnregisterDeviceTokenService`) can implement it
- This design pattern enforces a single, controlled implementation path for device token unregistration
- The `execute` method is intentionally simple, accepting only the device token as a parameter

## Usage Example

```java
IUnregisterDeviceTokenService unregisterService = new UnregisterDeviceTokenService();
unregisterService.execute("device-token-12345");
```

## Related Components

- **`UnregisterDeviceTokenService`** – The sole permitted implementation of this interface
- **Notification feature module** – Part of the `com.upmatches.app.features.notification.services` package
