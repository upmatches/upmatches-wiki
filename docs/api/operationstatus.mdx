# OperationStatus Enum

The `OperationStatus` enum is a simple enumeration defined in the `com.upmatches.app.shared.enums` package. It represents the different types of operations that can be performed within the application, typically used to indicate the nature of a database or service operation.

## Purpose

This enum provides a standardized set of operation types that can be used throughout the application to describe what kind of action is being taken. It helps in maintaining consistency when handling different CRUD (Create, Read, Update, Delete) operations and other miscellaneous actions.

## Enum Constants

| Constant | Description |
|----------|-------------|
| `RETRIEVE` | Represents a read or fetch operation (e.g., getting data from a database or API). |
| `SAVE` | Represents a create or persist operation (e.g., inserting a new record). |
| `UPDATE` | Represents a modification operation (e.g., updating an existing record). |
| `DELETE` | Represents a removal operation (e.g., deleting a record). |
| `OTHER` | Represents any operation that does not fit into the standard CRUD categories. |

## Usage Example

```java
OperationStatus status = OperationStatus.RETRIEVE;

switch (status) {
    case RETRIEVE:
        // Handle retrieve logic
        break;
    case SAVE:
        // Handle save logic
        break;
    case UPDATE:
        // Handle update logic
        break;
    case DELETE:
        // Handle delete logic
        break;
    case OTHER:
        // Handle other operations
        break;
}
```

## Notes

- This enum is immutable and thread-safe by design.
- It is commonly used in conjunction with operation logging, auditing, or routing logic.
- The `OTHER` constant provides flexibility for future operation types that may not be covered by the standard CRUD set.
