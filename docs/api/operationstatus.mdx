# OperationStatus Enum

The `OperationStatus` enum defines a set of standard operation types used throughout the application to indicate the nature of a data operation being performed. It is part of the `com.upmatches.app.shared.enums` package and provides a type-safe way to represent common CRUD (Create, Read, Update, Delete) operations along with a catch-all option for other operations.

## Purpose

This enum is designed to standardize how different data operations are referenced across the application. By using a dedicated enum instead of string literals or integer constants, the code becomes more readable, maintainable, and less prone to errors. It is particularly useful in scenarios such as:

- Logging and auditing data access patterns
- Controlling behavior in generic data access layers
- Implementing operation-specific logic in service classes
- Tracking the type of operation in request/response objects

## Enum Constants

| Constant | Description |
|----------|-------------|
| `RETRIEVE` | Represents a read or fetch operation (e.g., getting data from a database or API) |
| `SAVE` | Represents a create or insert operation (e.g., persisting new data) |
| `UPDATE` | Represents a modification operation (e.g., updating existing data) |
| `DELETE` | Represents a removal operation (e.g., deleting data from storage) |
| `OTHER` | Represents any operation that does not fit into the standard CRUD categories |

## Usage Example

```java
import com.upmatches.app.shared.enums.OperationStatus;

public class DataService {
    
    public void processOperation(OperationStatus status) {
        switch (status) {
            case RETRIEVE:
                System.out.println("Performing retrieve operation");
                break;
            case SAVE:
                System.out.println("Performing save operation");
                break;
            case UPDATE:
                System.out.println("Performing update operation");
                break;
            case DELETE:
                System.out.println("Performing delete operation");
                break;
            case OTHER:
                System.out.println("Performing other operation");
                break;
        }
    }
}
```

## Notes

- The enum is immutable and thread-safe by design
- It can be serialized/deserialized automatically by most Java frameworks
- Consider extending this enum with additional constants if your application requires more granular operation types
