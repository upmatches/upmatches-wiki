## Overview

The `SkillLevel` class is an entity representing a skill level within an application. It is part of the `com.upmatches.app.features.skilllevels.entities` package and is mapped to the `skill_levels` table in the database. This class is used to define different levels of skills associated with various activities.

## Class Structure

The `SkillLevel` class is annotated with JPA annotations to facilitate ORM (Object-Relational Mapping) with a relational database. It uses Lombok's `@Getter` to automatically generate getter methods for its fields.

### Fields

- **id**: A unique identifier for each skill level, automatically generated.
- **activity**: A reference to the `Activity` entity, representing the activity associated with this skill level.
- **name**: The name of the skill level, with a maximum length of 100 characters.
- **sortOrder**: An integer used to define the order of skill levels.

### Constructor

- **SkillLevel()**: A protected no-argument constructor used by JPA.
