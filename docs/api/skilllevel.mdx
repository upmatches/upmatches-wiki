# SkillLevel Entity

The `SkillLevel` class is a JPA entity that represents a proficiency level associated with a specific activity within the UpMatches application. It maps to the `skill_levels` database table and is used to define and organize different skill tiers (e.g., Beginner, Intermediate, Advanced) for activities.

## Purpose

This entity serves as a structured way to categorize skill levels for various activities. Each skill level is linked to an activity, has a descriptive name, and includes a sort order for display sequencing. The class uses a static factory method for object creation and relies on Lombok's `@Getter` annotation to generate getters for all fields.

## Entity Mapping

| Database Column | Java Field | Type | Constraints |
|----------------|------------|------|-------------|
| `id` | `id` | `Long` | Primary key, auto-generated |
| `activity_id` | `activity` | `Activity` | Foreign key, not null |
| `name` | `name` | `String` | Max 100 characters, not null |
| `sort_order` | `sort_order` | `Integer` | Not null |

## Public Methods

### `create(Activity activity, String name, Integer sortOrder)`

Creates a new `SkillLevel` instance with the specified parameters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `activity` | `Activity` | The activity this skill level belongs to |
| `name` | `String` | The display name of the skill level (e.g., "Beginner") |
| `sortOrder` | `Integer` | Numeric value for ordering skill levels |

**Returns:** `SkillLevel` - A new SkillLevel entity instance with the provided values.

## Usage Example

```java
// Assuming you have an Activity instance
Activity activity = activityRepository.findById(1L).orElseThrow();

// Create a new skill level
SkillLevel beginner = SkillLevel.create(
    activity,
    "Beginner",
    1
);

// Save using repository
skillLevelRepository.save(beginner);
```

## Notes

- The class uses a **protected no-arg constructor** required by JPA for entity instantiation.
- **Lombok's `@Getter`** annotation automatically generates getter methods for all fields (`getId()`, `getActivity()`, `getName()`, `getSortOrder()`).
- The `sortOrder` field enables custom ordering of skill levels within an activity, useful for UI display purposes.
- The `activity` field establishes a **many-to-one relationship** with the `Activity` entity, meaning multiple skill levels can belong to the same activity.
