# SkillLevel

The `SkillLevel` entity represents a proficiency level associated with a specific activity within the UpMatches application. It is used to define and categorize different skill tiers (e.g., Beginner, Intermediate, Advanced) for activities, enabling users to filter or match based on skill requirements.

## Entity Overview

This JPA entity is mapped to the `skill_levels` database table. It stores the name of the skill level and its display order, linked to a parent `Activity`. The class uses Lombok's `@Getter` annotation to automatically generate getter methods for all fields.

### Database Table: `skill_levels`

| Column       | Type         | Constraints          | Description                                      |
|--------------|--------------|----------------------|--------------------------------------------------|
| `id`         | `BIGINT`     | Primary Key, Auto    | Unique identifier for the skill level.           |
| `activity_id`| `BIGINT`     | Foreign Key, Not Null| References the parent `Activity`.                |
| `name`       | `VARCHAR(100)`| Not Null             | The name of the skill level (e.g., "Beginner").  |
| `sort_order` | `INTEGER`    | Not Null             | Determines the display order of skill levels.    |

## Public Methods

### `create(Activity activity, String name, Integer sortOrder)`

Creates a new `SkillLevel` instance with the specified parameters.

| Parameter   | Type       | Description                                      |
|-------------|------------|--------------------------------------------------|
| `activity`  | `Activity` | The parent activity this skill level belongs to. |
| `name`      | `String`   | The name of the skill level (max 100 characters).|
| `sortOrder` | `Integer`  | The display order for this skill level.          |

**Returns:** `SkillLevel` — A new, fully initialized `SkillLevel` entity.

**Example Usage:**
```java
Activity activity = activityRepository.findById(1L).orElseThrow();
SkillLevel beginner = SkillLevel.create(activity, "Beginner", 1);
skillLevelRepository.save(beginner);
```

## Fields (Getters Only)

Since the class uses Lombok's `@Getter` annotation, all fields have public getter methods but no public setters. The only way to set field values is through the static factory method `create()`.

| Field       | Type       | Description                                      |
|-------------|------------|--------------------------------------------------|
| `id`        | `Long`     | Unique identifier (auto-generated).              |
| `activity`  | `Activity` | The parent activity entity.                      |
| `name`      | `String`   | The skill level name.                            |
| `sortOrder` | `Integer`  | Numeric order for sorting/display.               |

## Notes

- The class uses a **protected no-arg constructor** required by JPA. External instantiation should use the static `create()` method.
- The `sortOrder` field allows flexible ordering of skill levels (e.g., 1 = Beginner, 2 = Intermediate, 3 = Advanced).
- The relationship to `Activity` is **many-to-one**, meaning multiple skill levels can belong to the same activity.
