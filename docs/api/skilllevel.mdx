# SkillLevel Entity

The `SkillLevel` entity represents a proficiency level associated with a specific activity within the UpMatches application. It is used to categorize and rank skill levels (e.g., Beginner, Intermediate, Advanced) for activities, enabling users to define progression or difficulty tiers.

This entity is mapped to the `skill_levels` database table and uses JPA (Jakarta Persistence) annotations for object-relational mapping. It leverages Lombok's `@Getter` annotation to automatically generate getter methods for all fields.

## Entity Overview

| Field       | Type       | Description                                                                 |
|-------------|------------|-----------------------------------------------------------------------------|
| `id`        | `Long`     | Primary key, auto-generated using identity strategy.                        |
| `activity`  | `Activity` | The activity this skill level belongs to (many-to-one relationship).        |
| `name`      | `String`   | The name of the skill level (e.g., "Beginner", "Advanced"), max 100 chars. |
| `sortOrder` | `Integer`  | Numeric value used for ordering skill levels (e.g., 1, 2, 3).              |

## Database Mapping

- **Table name:** `skill_levels`
- **Primary key:** `id` (auto-generated via `IDENTITY` strategy)
- **Foreign key:** `activity_id` references the `activity` table (not nullable)
- **Columns:** `name` (varchar 100, not null), `sort_order` (integer, not null)

## Constructor

### `protected SkillLevel()`

A no-argument constructor is provided for JPA use. It is `protected` to prevent direct instantiation from outside the entity class or its subclasses.

## Public Methods

### `static SkillLevel create(Activity activity, String name, Integer sortOrder)`

Factory method to create a new `SkillLevel` instance with the specified parameters.

| Parameter   | Type       | Description                                      |
|-------------|------------|--------------------------------------------------|
| `activity`  | `Activity` | The activity to associate with this skill level. |
| `name`      | `String`   | The name of the skill level.                     |
| `sortOrder` | `Integer`  | The ordering value for this skill level.         |

**Returns:** A new `SkillLevel` instance with the provided values set.

**Example usage:**
```java
Activity activity = activityRepository.findById(1L).orElseThrow();
SkillLevel beginner = SkillLevel.create(activity, "Beginner", 1);
SkillLevel advanced = SkillLevel.create(activity, "Advanced", 2);
```

## Relationships

- **Many-to-One with Activity:** Each `SkillLevel` belongs to exactly one `Activity`. The relationship is defined via the `activity_id` foreign key column and is mandatory (not nullable).

## Notes

- The entity uses Lombok's `@Getter` annotation, so all fields have public getter methods generated automatically (e.g., `getId()`, `getActivity()`, `getName()`, `getSortOrder()`).
- There are no setter methods exposed; the only way to set field values is through the `create()` factory method or via JPA's internal mechanisms.
- The `sortOrder` field is intended for ordering skill levels in a meaningful sequence (e.g., from lowest to highest proficiency).
