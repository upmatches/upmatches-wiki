# IAppleAuthService Interface

The `IAppleAuthService` interface defines the contract for Apple Identity Token verification within the authentication module. It provides a standardized way to verify Apple-provided identity tokens and extract verified claims from them.

This interface is part of the `com.upmatches.app.features.auth.services` package and serves as the abstraction layer for Apple Sign-In authentication flow.

## Sealed Interface

`IAppleAuthService` is declared as a **sealed interface**, which means it has a restricted set of implementations. The only permitted implementation is `AppleAuthService`. This design ensures type safety and controlled extensibility within the authentication service hierarchy.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `verifyIdentityToken(String identityToken)` | `AppleVerifiedClaims` | Verifies the provided Apple identity token and returns the verified claims extracted from it. |

### Method Details

#### `verifyIdentityToken`

```java
AppleVerifiedClaims verifyIdentityToken(String identityToken)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `identityToken` | `String` | The JWT identity token received from Apple's authentication service |

**Returns:** `AppleVerifiedClaims` - A record containing the verified claims extracted from the identity token

**Throws:** Implementation-specific exceptions may be thrown if token verification fails

## AppleVerifiedClaims Record

The `AppleVerifiedClaims` record is a nested data structure within the interface that encapsulates the verified claims from an Apple identity token.

### Record Components

| Component | Type | Description |
|-----------|------|-------------|
| `sub` | `String` | The subject identifier - Apple's unique identifier for the user |
| `email` | `String` | The user's email address as provided by Apple |

### Usage Example

```java
// Example implementation
public class AppleAuthService implements IAppleAuthService {
    @Override
    public AppleVerifiedClaims verifyIdentityToken(String identityToken) {
        // Token verification logic here
        // Extract sub and email from the verified token
        return new AppleVerifiedClaims("user_sub_123", "user@example.com");
    }
}
```

## Usage

The interface is designed to be used in authentication flows where Apple Sign-In is implemented. Typical usage involves:

1. Receiving an identity token from the client-side Apple Sign-In flow
2. Calling `verifyIdentityToken()` to validate the token
3. Using the returned `AppleVerifiedClaims` to create or authenticate user sessions

```java
// Service usage
IAppleAuthService authService = new AppleAuthService();
String identityToken = "eyJ..."; // Token from Apple
AppleVerifiedClaims claims = authService.verifyIdentityToken(identityToken);
String userId = claims.sub();
String userEmail = claims.email();
```

## Implementation Notes

- The sealed interface pattern ensures that only `AppleAuthService` can implement this interface
- The `AppleVerifiedClaims` record is immutable by design, providing thread-safe data transfer
- Token verification should include signature validation, expiration checking, and nonce verification in the implementation
