## Purpose

The `IAppleAuthService` interface is part of the authentication services in the `com.upmatches.app.features.auth.services` package. It defines a contract for verifying identity tokens issued by Apple, ensuring that implementations provide a method to verify these tokens and return verified claims.

## Public Methods

### `verifyIdentityToken`

Verifies an identity token issued by Apple and returns the verified claims.

| Method Signature | Description |
|------------------|-------------|
| `AppleVerifiedClaims verifyIdentityToken(String identityToken)` | Verifies the provided Apple identity token and returns the associated claims. |

#### Parameters

| Parameter Name | Type   | Description                    |
|----------------|--------|--------------------------------|
| `identityToken`| String | The identity token to be verified. |

#### Return Type

| Return Type          | Description                                      |
|----------------------|--------------------------------------------------|
| `AppleVerifiedClaims`| A record containing the subject and email claims. |

## AppleVerifiedClaims Record

The `AppleVerifiedClaims` record encapsulates the claims extracted from a verified Apple identity token.

| Field Name | Type   | Description                    |
|------------|--------|--------------------------------|
| `sub`      | String | The subject claim, typically a unique identifier for the user. |
| `email`    | String | The email claim, representing the user's email address. |
