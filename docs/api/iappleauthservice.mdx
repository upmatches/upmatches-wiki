# IAppleAuthService Interface

The `IAppleAuthService` interface defines the contract for Apple Identity Token verification within the authentication module. It provides a standardized way to verify Apple-provided identity tokens and extract verified claims from them.

This interface is part of the `com.upmatches.app.features.auth.services` package and serves as the abstraction layer for Apple Sign-In authentication flows.

## Sealed Interface

`IAppleAuthService` is declared as a **sealed interface**, which means it restricts which classes or interfaces can implement it. Currently, only `AppleAuthService` is permitted to implement this interface. This design pattern ensures controlled extension and maintains a strict hierarchy in the authentication service layer.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `verifyIdentityToken(String identityToken)` | `AppleVerifiedClaims` | Verifies the provided Apple identity token and returns the verified claims extracted from it. |

### Method Details

#### `verifyIdentityToken`

```java
AppleVerifiedClaims verifyIdentityToken(String identityToken)
```

This method takes an Apple identity token as input and performs verification against Apple's authentication services. Upon successful verification, it returns an `AppleVerifiedClaims` record containing the verified user information.

**Parameters:**
- `identityToken` (String): The JWT identity token received from Apple's authentication flow.

**Returns:**
- `AppleVerifiedClaims`: A record containing the verified claims from the identity token.

## Inner Record: AppleVerifiedClaims

The interface defines an inner record `AppleVerifiedClaims` that encapsulates the verified claims extracted from an Apple identity token.

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `sub` | String | The subject identifier - Apple's unique identifier for the user |
| `email` | String | The user's email address as provided by Apple |

### Usage Example

```java
public class AppleAuthService implements IAppleAuthService {
    
    @Override
    public AppleVerifiedClaims verifyIdentityToken(String identityToken) {
        // Implementation logic for token verification
        // ...
        return new AppleVerifiedClaims(userId, email);
    }
}
```

## Implementation Notes

- The sealed interface pattern ensures that only `AppleAuthService` can implement this interface, providing compile-time safety and clear architecture.
- The `AppleVerifiedClaims` record is immutable and provides a type-safe way to handle verified user data.
- This interface is designed to be used in conjunction with Apple's Sign In with Apple feature, handling the JWT identity token verification process.
