# IAppleAuthService

The `IAppleAuthService` interface defines the contract for Apple Identity Token verification within the authentication module. It provides a single method to verify an Apple-provided identity token and extract verified claims from it.

## Purpose

This sealed interface is designed to enforce a strict implementation hierarchy, ensuring that only the `AppleAuthService` class can implement it. This pattern is used to guarantee that Apple authentication logic is centralized and cannot be extended by unauthorized classes.

## Interface Definition

```java
public sealed interface IAppleAuthService permits AppleAuthService
```

- **Sealed**: The interface is sealed, meaning only the classes specified in the `permits` clause can implement it.
- **Permits**: `AppleAuthService` is the sole permitted implementation.

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `verifyIdentityToken(String identityToken)` | `AppleVerifiedClaims` | Verifies the provided Apple identity token and returns the verified claims extracted from it. |

### Method Details

#### `verifyIdentityToken`

```java
AppleVerifiedClaims verifyIdentityToken(String identityToken);
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `identityToken` | `String` | The Apple identity token (JWT) to be verified. |

**Returns:**

| Type | Description |
|------|-------------|
| `AppleVerifiedClaims` | A record containing the verified claims from the identity token. |

## Inner Record: `AppleVerifiedClaims`

```java
record AppleVerifiedClaims(String sub, String email) { }
```

This record encapsulates the verified claims extracted from an Apple identity token.

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `sub` | `String` | The subject identifier (unique Apple user ID). |
| `email` | `String` | The user's email address as provided by Apple. |

## Usage Example

```java
// Assuming an implementation of IAppleAuthService
IAppleAuthService appleAuthService = new AppleAuthService();

// Verify an identity token
String identityToken = "eyJraWQiOi..."; // Apple JWT token
IAppleAuthService.AppleVerifiedClaims claims = appleAuthService.verifyIdentityToken(identityToken);

// Access verified claims
String userId = claims.sub();
String email = claims.email();
```

## Implementation Notes

- The `verifyIdentityToken` method should handle token validation including signature verification, expiration checks, and audience validation.
- The `AppleVerifiedClaims` record is immutable and thread-safe by design.
- The sealed interface pattern ensures compile-time safety by restricting implementations to the `AppleAuthService` class only.

## Dependencies

- This interface is part of the `com.upmatches.app.features.auth.services` package.
- The implementation (`AppleAuthService`) is expected to use standard JWT libraries for token verification.
