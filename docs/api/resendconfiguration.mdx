# ResendConfiguration

The `ResendConfiguration` class is a Spring Boot configuration component responsible for initializing and providing a `Resend` client bean. It conditionally creates the bean based on the presence of a configured API key, enabling or disabling email notification functionality accordingly.

## Purpose

This configuration class serves as the bridge between application properties and the Resend email service. It reads configuration from `ResendProperties`, validates the presence of an API key, and either creates a functional `Resend` client or returns `null` to gracefully disable email notifications when the key is missing.

## Class Overview

| Aspect | Description |
|--------|-------------|
| **Package** | `com.upmatches.app.features.notification.configurations` |
| **Annotations** | `@Configuration`, `@EnableConfigurationProperties(ResendProperties.class)` |
| **Dependencies** | `ResendProperties` (injected via constructor) |
| **Logging** | Uses SLF4J `Logger` for initialization status messages |

## Public Methods

### `resend()`

Creates and returns a `Resend` client bean based on the configured API key.

| Property | Value |
|----------|-------|
| **Return Type** | `Resend` (or `null`) |
| **Bean Name** | `resend` (default method name) |
| **Scope** | Singleton (default Spring bean scope) |

**Behavior:**
- If `ResendProperties.hasApiKey()` returns `false`, logs an informational message and returns `null`
- If the API key is present, logs an informational message and returns a new `Resend` instance initialized with the API key

**Example Usage:**
```java
@Autowired
private Resend resend;

public void sendNotification() {
    if (resend != null) {
        // Send email using Resend client
    } else {
        // Handle disabled notifications
    }
}
```

## Configuration Properties

The class relies on `ResendProperties` for configuration. Ensure the following property is defined in your application configuration:

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `resend.api-key` | `String` | No | API key for Resend email service. If not provided, email notifications are disabled. |

## Logging Behavior

The class logs the following messages at the `INFO` level:

| Condition | Log Message |
|-----------|-------------|
| API key not configured | `"Resend API key not configured; email notifications disabled."` |
| API key configured | `"Resend client initialized; email notifications enabled."` |

## Dependencies

- **Spring Boot**: `@Configuration`, `@EnableConfigurationProperties`, `@Bean`
- **Resend Java SDK**: `com.resend.Resend`
- **SLF4J**: Logging framework
- **ResendProperties**: Custom configuration properties class

## Notes

- The `resend()` method returns `null` when the API key is missing, so consumers should always check for `null` before using the bean
- This design allows the application to start and function without email capabilities if the API key is not configured
- The class is thread-safe as it only reads configuration during bean creation
