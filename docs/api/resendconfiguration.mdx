# ResendConfiguration

The `ResendConfiguration` class is a Spring Boot configuration component responsible for initializing and providing a `Resend` client bean. It conditionally creates the bean based on the presence of a configured API key, enabling or disabling email notification functionality accordingly.

## Purpose

This configuration class serves as the central point for setting up the Resend email service integration within the application. It reads configuration properties from `ResendProperties`, logs the initialization status, and provides a `Resend` bean to the Spring context. If the API key is not configured, it gracefully disables email notifications by returning `null` instead of throwing an error.

## Dependencies

| Dependency | Description |
|------------|-------------|
| `com.resend.Resend` | The Resend Java SDK client for sending emails |
| `com.upmatches.app.features.notification.properties.ResendProperties` | Configuration properties holder for Resend API settings |
| `org.slf4j.Logger` | Logging framework for status messages |
| `org.springframework.boot.context.properties.EnableConfigurationProperties` | Enables support for `@ConfigurationProperties` beans |
| `org.springframework.context.annotation.Bean` | Marks a method as a Spring bean producer |
| `org.springframework.context.annotation.Configuration` | Indicates that the class declares one or more `@Bean` methods |

## Class Structure

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `LOGGER` | `Logger` | SLF4J logger instance for logging configuration status |
| `LOG_DISABLED` | `String` | Log message when Resend API key is not configured |
| `LOG_INITIALIZED` | `String` | Log message when Resend client is successfully initialized |
| `properties` | `ResendProperties` | Injected configuration properties for Resend |

### Constructor

```java
public ResendConfiguration(ResendProperties properties)
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `properties` | `ResendProperties` | Configuration properties containing the Resend API key |

The constructor receives the `ResendProperties` instance through dependency injection and stores it for use in the bean creation method.

## Public Methods

### `resend()`

```java
@Bean
public Resend resend()
```

**Returns:** `Resend` or `null`

**Description:** Creates and returns a `Resend` client bean. The method checks if the API key is configured via `properties.hasApiKey()`. If the key is present, it logs an initialization message and returns a new `Resend` instance initialized with the API key. If the key is missing, it logs a disabled message and returns `null`, effectively disabling email notification functionality.

**Behavior:**

| Condition | Action | Return Value |
|-----------|--------|--------------|
| API key configured | Logs `LOG_INITIALIZED` | `new Resend(properties.apiKey())` |
| API key not configured | Logs `LOG_DISABLED` | `null` |

## Usage Example

```java
// The Resend bean is automatically created by Spring
// when ResendProperties has an API key configured
@Autowired
private Resend resendClient;

// Use the client to send emails
if (resendClient != null) {
    // Send email using resendClient
}
```

## Configuration Properties

The class relies on `ResendProperties` which should be configured in your application properties file:

```yaml
# application.yml
resend:
  api-key: your-api-key-here
```

## Logging Behavior

The class logs important status information to help with debugging and monitoring:

- **INFO** level: When the Resend client is successfully initialized or when email notifications are disabled due to missing API key
- No error is thrown when the API key is missing; the system gracefully degrades by returning `null`

## Notes

- The class is annotated with `@Configuration` and `@EnableConfigurationProperties(ResendProperties.class)`, making it a standard Spring Boot configuration component
- The `Resend` bean is conditionally created, allowing the application to function without email capabilities if the API key is not configured
- The `null` return value when the API key is missing requires consumers to perform null checks before using the `Resend` client
