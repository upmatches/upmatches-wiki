## Overview

The `ResendConfiguration` class is a Spring configuration class responsible for setting up the `Resend` client used for email notifications. It utilizes the `ResendProperties` to configure the client and conditionally enables or disables email notifications based on the presence of an API key.

## Purpose

The primary purpose of the `ResendConfiguration` class is to initialize the `Resend` client if an API key is provided. This setup is crucial for enabling email notifications within the application. If the API key is not configured, the class ensures that email notifications are disabled, and a log message is generated to indicate this status.

## Public Methods

The class provides the following public method:

| Method | Parameters | Return Type | Description |
|--------|------------|-------------|-------------|
| `resend()` | None | `Resend` | Initializes and returns a `Resend` client if the API key is configured; otherwise, returns `null`. |

### Method Details

#### `resend()`

- **Parameters**: None
- **Return Type**: `Resend`
- **Description**: This method checks if the API key is configured in the `ResendProperties`. If the API key is present, it initializes a new `Resend` client and logs that email notifications are enabled. If the API key is absent, it logs that email notifications are disabled and returns `null`.
