# ResendConfiguration

The `ResendConfiguration` class is a Spring Boot configuration component responsible for initializing the [Resend](https://resend.com) email client. It conditionally creates a `Resend` bean based on the availability of a configured API key, enabling or disabling email notification functionality accordingly.

## Purpose

This configuration class serves as the integration point between the application and the Resend email service. It reads configuration properties via `ResendProperties`, logs the initialization status, and provides a `Resend` bean to the Spring application context only when a valid API key is present.

## Dependencies

- **Spring Boot**: `@Configuration`, `@EnableConfigurationProperties`, `@Bean`
- **Resend SDK**: `com.resend.Resend`
- **SLF4J**: Logging
- **ResendProperties**: Custom configuration properties class

## Public Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `resend()` | `Resend` | Creates and returns a `Resend` client instance if an API key is configured; returns `null` otherwise. |

### Method Details

#### `resend()`

**Description**:  
This bean method checks whether the `ResendProperties` instance contains a valid API key. If the key is present, it logs an initialization message and returns a new `Resend` client. If the key is missing, it logs a disabled message and returns `null`, effectively disabling email notifications.

**Parameters**:  
None

**Returns**:  
- `Resend` instance if API key is configured
- `null` if API key is not configured

**Logging**:
- **INFO**: `"Resend API key not configured; email notifications disabled."` when API key is missing
- **INFO**: `"Resend client initialized; email notifications enabled."` when API key is present

## Usage Example

```java
// The Resend bean is automatically available for injection
@Autowired
private Resend resendClient;

// Use the client to send emails
if (resendClient != null) {
    // Send email via Resend API
}
```

## Configuration Properties

This class relies on `ResendProperties` for configuration. Ensure the following property is set in your application configuration:

```yaml
# application.yml
resend:
  api-key: your-resend-api-key-here
```

## Notes

- The bean returns `null` when no API key is configured, allowing downstream components to check for availability before use.
- The class uses SLF4J for logging, making it compatible with various logging frameworks.
- The `@EnableConfigurationProperties(ResendProperties.class)` annotation ensures that `ResendProperties` is registered as a Spring bean.
