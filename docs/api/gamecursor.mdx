## Overview

The `GameCursor` class is a component designed to encode and decode game-related data into a Base64 URL-safe string. This is useful for creating cursors that can be used for pagination or state management in a game application. The class leverages Jackson for JSON processing and Spring's `@Component` annotation for dependency injection.

## Public Methods

### `encode`

Encodes the provided `startTime` and `id` into a Base64 URL-safe string.

| Parameter | Type   | Description                      |
|-----------|--------|----------------------------------|
| startTime | Instant| The start time of the game event.|
| id        | UUID   | The unique identifier of the game.|

**Returns**: `String` - A Base64 URL-safe encoded string representing the game cursor.

### `decode`

Decodes the provided Base64 URL-safe string back into a `Value` object containing the `startTime` and `id`.

| Parameter | Type  | Description                          |
|-----------|-------|--------------------------------------|
| cursor    | String| The Base64 URL-safe encoded cursor.  |

**Returns**: `Optional<Value>` - An `Optional` containing the decoded `Value` object if successful, or an empty `Optional` if the cursor is invalid or blank.

## Value Record

The `Value` record is a simple data structure that holds the decoded `startTime` and `id`.

| Field     | Type   | Description                      |
|-----------|--------|----------------------------------|
| startTime | Instant| The start time of the game event.|
| id        | UUID   | The unique identifier of the game.|
