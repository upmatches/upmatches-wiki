# GameCursor

The `GameCursor` class is a Spring `@Component` that provides encoding and decoding of pagination cursors for game-related data. It uses a URL-safe Base64 encoding scheme to serialize and deserialize cursor payloads containing a timestamp (`Instant`) and a unique identifier (`UUID`). This is commonly used in cursor-based pagination for APIs where you need to pass a token that represents a specific point in a dataset.

## How It Works

- **Encoding**: Takes a `startTime` (Instant) and an `id` (UUID), serializes them into a JSON payload, and then Base64 URL-encodes the result without padding.
- **Decoding**: Takes a Base64 URL-encoded string, decodes it, deserializes the JSON payload, and returns an `Optional<Value>` containing the original `startTime` and `id`. Returns `Optional.empty()` for null or blank input, and throws `IllegalArgumentException` for invalid cursors.

## Public Methods

### `encode`

| Parameter | Type | Description |
|-----------|------|-------------|
| `startTime` | `Instant` | The timestamp to encode in the cursor |
| `id` | `UUID` | The unique identifier to encode in the cursor |
| **Returns** | `String` | A URL-safe Base64 encoded cursor string |
| **Throws** | `IllegalStateException` | If JSON serialization fails |

Encodes the given `startTime` and `id` into a URL-safe Base64 cursor string.

### `decode`

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursor` | `String` | The Base64 URL-encoded cursor string to decode |
| **Returns** | `Optional<Value>` | An `Optional` containing the decoded `Value` (with `startTime` and `id`), or empty if the input is null or blank |
| **Throws** | `IllegalArgumentException` | If the cursor is invalid (e.g., malformed JSON, missing fields, or decoding failure) |

Decodes a Base64 URL-encoded cursor string back into its original `Value` components.

## Inner Types

### `Value` (public record)

| Field | Type | Description |
|-------|------|-------------|
| `startTime` | `Instant` | The timestamp from the decoded cursor |
| `id` | `UUID` | The unique identifier from the decoded cursor |

A public record representing the decoded cursor data.

### `Payload` (private record)

| Field | Type | Description |
|-------|------|-------------|
| `startTime` | `Instant` | The timestamp to serialize |
| `id` | `UUID` | The unique identifier to serialize |

A private record used internally for JSON serialization/deserialization.

## Usage Example

```java
// Assuming GameCursor is injected as a bean
GameCursor cursor = new GameCursor(new ObjectMapper());

// Encode a cursor
Instant now = Instant.now();
UUID gameId = UUID.randomUUID();
String encoded = cursor.encode(now, gameId);
// encoded is a URL-safe Base64 string like "eyJzdGFydFRpbWUiOiIyMDI0LTAxLTE1VDEwOjMwOjAwWiIsImlkIjoiMTIzZS00NTY3LTg5YWItY2RlZiJ9"

// Decode a cursor
Optional<GameCursor.Value> decoded = cursor.decode(encoded);
decoded.ifPresent(value -> {
    System.out.println("Start time: " + value.startTime());
    System.out.println("ID: " + value.id());
});
```
