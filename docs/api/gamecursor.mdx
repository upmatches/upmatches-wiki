# GameCursor

The `GameCursor` class is a Spring `@Component` that provides encoding and decoding functionality for pagination cursors in a game-related feature. It uses a URL-safe Base64 encoding scheme to serialize and deserialize cursor payloads containing a timestamp (`Instant`) and a unique identifier (`UUID`). This is commonly used for implementing keyset pagination where the cursor encodes the starting point for the next page of results.

The class leverages Jackson's `ObjectMapper` for JSON serialization/deserialization and ensures that the cursor is compact, URL-safe, and opaque to clients.

## Public Methods

### `encode(Instant startTime, UUID id)`

Encodes a cursor payload into a URL-safe Base64 string.

| Parameter   | Type     | Description                                      |
|-------------|----------|--------------------------------------------------|
| `startTime` | `Instant` | The timestamp representing the cursor position. |
| `id`        | `UUID`    | The unique identifier for the cursor position.   |

**Returns:** `String` - A URL-safe Base64 encoded string representing the cursor.

**Throws:** `IllegalStateException` if JSON serialization fails.

### `decode(String cursor)`

Decodes a Base64 encoded cursor string back into a `Value` object.

| Parameter | Type     | Description                           |
|-----------|----------|---------------------------------------|
| `cursor`  | `String` | The Base64 encoded cursor string.     |

**Returns:** `Optional<Value>` - An `Optional` containing the decoded `Value` if the cursor is valid, or `Optional.empty()` if the cursor is `null` or blank.

**Throws:** `IllegalArgumentException` if the cursor is malformed, contains invalid data, or cannot be decoded.

## Inner Types

### `Value` (Record)

A public record representing the decoded cursor data.

| Field       | Type     | Description                                      |
|-------------|----------|--------------------------------------------------|
| `startTime` | `Instant` | The timestamp from the cursor.                  |
| `id`        | `UUID`    | The unique identifier from the cursor.          |

### `Payload` (Private Record)

An internal record used for JSON serialization/deserialization. It mirrors the `Value` record structure.

| Field       | Type     | Description                                      |
|-------------|----------|--------------------------------------------------|
| `startTime` | `Instant` | The timestamp to be serialized.                 |
| `id`        | `UUID`    | The unique identifier to be serialized.         |

## Usage Example

```java
// Assuming GameCursor is injected as a bean
GameCursor cursor = new GameCursor(new ObjectMapper());

// Encode a cursor
Instant now = Instant.now();
UUID id = UUID.randomUUID();
String encoded = cursor.encode(now, id);

// Decode a cursor
Optional<GameCursor.Value> decoded = cursor.decode(encoded);
decoded.ifPresent(value -> {
    System.out.println("Start time: " + value.startTime());
    System.out.println("ID: " + value.id());
});
```

## Notes

- The encoding uses URL-safe Base64 without padding, making it suitable for use in URLs and query parameters.
- The `decode` method returns `Optional.empty()` for `null` or blank input, allowing callers to handle missing cursors gracefully.
- Invalid or malformed cursors result in an `IllegalArgumentException` to clearly indicate the error.
- The class is thread-safe as it relies on the thread-safe `ObjectMapper` and immutable records.
