# GameCursor

The `GameCursor` class is a Spring `@Component` that provides encoding and decoding functionality for cursor-based pagination in a gaming application. It serializes a combination of a timestamp (`Instant`) and a unique identifier (`UUID`) into a URL-safe Base64-encoded string, and can decode such strings back into their original components.

This approach is commonly used for implementing keyset pagination (also known as cursor pagination), where a cursor represents a specific position in a dataset, allowing efficient and consistent traversal of large result sets.

## Constructor

| Constructor | Description |
|---|---|
| `GameCursor(ObjectMapper objectMapper)` | Creates a new `GameCursor` instance with the provided Jackson `ObjectMapper` for JSON serialization/deserialization. |

## Public Methods

### `encode`

```java
public String encode(Instant startTime, UUID id)
```

Encodes a given `startTime` and `id` into a URL-safe Base64-encoded cursor string.

**Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `startTime` | `Instant` | The timestamp representing the cursor position. |
| `id` | `UUID` | The unique identifier for the cursor position. |

**Returns:**

| Type | Description |
|---|---|
| `String` | A URL-safe Base64-encoded string representing the cursor. |

**Throws:**

| Exception | Description |
|---|---|
| `IllegalStateException` | If JSON serialization fails. |

### `decode`

```java
public Optional<Value> decode(String cursor)
```

Decodes a cursor string back into its original `Value` (containing `startTime` and `id`).

**Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `cursor` | `String` | The URL-safe Base64-encoded cursor string to decode. |

**Returns:**

| Type | Description |
|---|---|
| `Optional<Value>` | An `Optional` containing the decoded `Value` if the cursor is valid and non-blank, or `Optional.empty()` if the cursor is `null` or blank. |

**Throws:**

| Exception | Description |
|---|---|
| `IllegalArgumentException` | If the cursor is invalid (e.g., malformed Base64, invalid JSON, or missing required fields). |

## Inner Types

### `Value`

```java
public record Value(Instant startTime, UUID id)
```

A public record representing the decoded cursor value.

**Fields:**

| Field | Type | Description |
|---|---|---|
| `startTime` | `Instant` | The timestamp from the decoded cursor. |
| `id` | `UUID` | The unique identifier from the decoded cursor. |

### `Payload` (private)

```java
private record Payload(Instant startTime, UUID id)
```

A private record used internally for JSON serialization and deserialization. It mirrors the structure of `Value`.

## Usage Example

```java
// Assuming GameCursor is injected via Spring
GameCursor cursor = new GameCursor(new ObjectMapper());

// Encode a cursor
Instant now = Instant.now();
UUID uuid = UUID.randomUUID();
String encoded = cursor.encode(now, uuid);

// Decode a cursor
Optional<GameCursor.Value> decoded = cursor.decode(encoded);
decoded.ifPresent(value -> {
    System.out.println("Start time: " + value.startTime());
    System.out.println("ID: " + value.id());
});
```
