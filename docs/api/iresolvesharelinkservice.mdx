# IResolveShareLinkService Interface

The `IResolveShareLinkService` interface defines the contract for resolving shared links within the UpMatches application. It provides a single method to process a share link code and return the corresponding public share link data.

## Purpose

This sealed interface establishes a clear API boundary for share link resolution. By using Java's `sealed` keyword, it restricts implementation to only the `ResolveShareLinkService` class, ensuring controlled extensibility and preventing unauthorized implementations.

## Interface Definition

```java
public sealed interface IResolveShareLinkService permits ResolveShareLinkService {
    PublicShareLinkResponse execute(String code);
}
```

## Method Summary

| Method | Return Type | Description |
|--------|-------------|-------------|
| `execute(String code)` | `PublicShareLinkResponse` | Resolves a share link code and returns the associated public share link data |

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | The unique share link code to be resolved |

## Return Type

The method returns a `PublicShareLinkResponse` object containing the resolved share link information.

## Implementation Details

- **Sealed Interface**: Only `ResolveShareLinkService` is permitted to implement this interface
- **Single Responsibility**: The interface focuses solely on the share link resolution operation
- **Type Safety**: The sealed modifier ensures compile-time safety by restricting implementations

## Usage Example

```java
@Autowired
private IResolveShareLinkService resolveShareLinkService;

public void handleShareLink(String code) {
    PublicShareLinkResponse response = resolveShareLinkService.execute(code);
    // Process the resolved share link data
}
```

## Related Components

- `ResolveShareLinkService` - The sole permitted implementation of this interface
- `PublicShareLinkResponse` - The response object returned by the `execute` method
