# IResolveShareLinkService Interface

## Purpose

The `IResolveShareLinkService` interface defines the contract for resolving shared links within the UpMatches application. It serves as the abstraction layer for processing share link codes and returning the corresponding public share link data. This interface is part of the sealed interface hierarchy, restricting its implementation to the `ResolveShareLinkService` class only.

## Interface Definition

```java
public sealed interface IResolveShareLinkService permits ResolveShareLinkService {
    PublicShareLinkResponse execute(String code);
}
```

## Methods

### `execute`

Resolves a share link code and returns the associated public share link response.

| Parameter | Type | Description |
|-----------|------|-------------|
| `code` | `String` | The unique share link code to be resolved |

| Returns | Description |
|---------|-------------|
| `PublicShareLinkResponse` | The response object containing the resolved share link data |

## Usage Example

```java
// Inject the service
private final IResolveShareLinkService resolveShareLinkService;

// Resolve a share link
String shareCode = "abc123xyz";
PublicShareLinkResponse response = resolveShareLinkService.execute(shareCode);
```

## Implementation Details

- **Sealed Interface**: This interface is declared as `sealed`, meaning only the explicitly permitted class `ResolveShareLinkService` can implement it. This provides compile-time safety and ensures controlled extension of the interface hierarchy.
- **Single Method Contract**: The interface defines a single method `execute` that takes a share link code as input and returns a `PublicShareLinkResponse` object.
- **Package Structure**: The interface resides in the `com.upmatches.app.features.sharelink.services` package, indicating its role within the share link feature module.

## Related Components

| Component | Description |
|-----------|-------------|
| `ResolveShareLinkService` | The sole permitted implementation of this interface |
| `PublicShareLinkResponse` | The response DTO returned by the `execute` method |
