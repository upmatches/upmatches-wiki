# Skill Levels

Badminton uses a 7-level skill rating system. The `skillLevel` field in the API is an integer (`1`–`7`).

| Level | Value | Description |
|-------|-------|-------------|
| Beginner | `1` | New to the sport, learning basic grip and footwork |
| Middle Beginner | `2` | Familiar with basic strokes, developing consistency |
| High Beginner | `3` | Consistent clears and serves, starting to play rallies |
| Low Intermediate | `4` | Can place shots with intention, developing game sense |
| Middle Intermediate | `5` | Comfortable in singles and doubles, solid footwork |
| High Intermediate | `6` | Strong all-round game, competitive in club-level play |
| Expert | `7` | Advanced techniques, tactical awareness, tournament-level |
